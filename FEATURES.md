# Features
A private library of design styles captured from real products, made of evidence-labelled `systems/` packages and a lower-confidence refero snapshot, browsed through two Next.js apps and read by coding agents over MCP and the `ds` CLI.

## Catalog and packages
- **Design-system packages**: open any captured product under `systems/<slug>/` and read its README (generated Brief, what was captured, generated Health), W3C DTCG `tokens.json`, `components.md`, `patterns.md`, screenshots, component crops, icons and boards. Status: stable. Surface: CLI. Entry point: `systems/<slug>/README.md`. Tests: `tools/package_tests.py` (runs every `systems/<slug>/tools/test_*.py`), `tools/test_package_tests.py`.
- **Catalog index**: look up every package by slug, category, platform, tags, goodFor, preview paths and capture provenance in one machine-readable file. Status: stable. Surface: CLI. Entry point: `catalog.json`. Tests: `tools/test_catalog.py`.
- **Style guide page**: open a package's rendered token page with a light/dark toggle to see every token with its real values. Status: stable. Surface: web. Entry point: `systems/<slug>/style-guide.html`. Tests: none.
- **Generated Brief**: read a per-package summary of principles, colour roles, scales, component pointers, contrast and focus values, and regenerate every one from catalog, tokens and README. Status: stable. Surface: CLI. Entry point: `make brief` (`tools/brief.py`). Tests: `tools/test_brief.py`.
- **DESIGN.md export**: hand a DESIGN.md-reading tool a generated one-theme export of any package, regenerated from its tokens and README. Status: stable. Surface: CLI. Entry point: `make design-md` (`tools/catalog.py design-md`), `systems/<slug>/DESIGN.md`. Tests: `tools/test_catalog.py`.
- **DESIGN.md lint**: lint every package's DESIGN.md with Google's pinned linter through `npx` in a temp dir. Status: stable. Surface: CLI. Entry point: `make lint-design-md`. Tests: `tools/test_catalog.py`.
- **Package app icons**: see each product's 128 px icon on gallery cards and the README catalog table, and fetch or refresh it from the product's site. Status: stable. Surface: CLI. Entry point: `python3 tools/fetch_icon.py <slug>` (`--host`, `--url`, `--all`). Tests: `tools/test_fetch_icon.py`.
- **Gated-surface queue**: read the generated list of surfaces captures skipped behind sign-in, account, checkout or submission, and fail when it is stale. Status: stable. Surface: CLI. Entry point: `python3 tools/gated.py [--check]`, `docs/GATED.md`. Tests: none.

## Library CLI (make and tools/catalog.py)
- **Target list**: list every make target with a one-line description. Status: stable. Surface: CLI. Entry point: `make help`. Tests: none.
- **Environment setup**: create `.venv` with the site builder's and capture tools' Python dependencies in one step. Status: stable. Surface: CLI. Entry point: `make setup`. Tests: none.
- **Style search**: rank packages by free-text words (tags outrank descriptions) and print each match's tags, themes and README path. Status: stable. Surface: CLI. Entry point: `python3 tools/catalog.py find <words>`. Tests: `tools/test_catalog.py`.
- **Token export**: print every token of a package with aliases resolved, as CSS custom properties (first theme on `:root`, others under `[data-theme]`) or JSON. Status: stable. Surface: CLI. Entry point: `python3 tools/catalog.py export <slug> [--format json]`. Tests: `tools/test_catalog.py`.
- **Contrast check**: check WCAG AA contrast between foreground and background token pairs in one theme. Status: stable. Surface: CLI. Entry point: `python3 tools/catalog.py contrast <tokens.json> --theme <t> FG:BG...`. Tests: `tools/test_catalog.py`.
- **Private-text scan**: find redacted strings and signed URLs left in a package's text files without printing them. Status: stable. Surface: CLI. Entry point: `python3 tools/catalog.py scan systems/<slug> --redact <file>`. Tests: `tools/test_catalog.py`.
- **App data build**: write the gallery app's data, screenshot thumbnails, refero index and token exports into `web/data/`. Status: stable. Surface: CLI. Entry point: `make build` (`tools/catalog.py build`). Tests: `tools/test_catalog.py`.
- **Clean generated output**: remove `site/`, `web/data/`, `docs/scorecard/` and refero scratch. Status: stable. Surface: CLI. Entry point: `make clean`. Tests: none.

## Capture
- **Public web capture**: capture a public site headless with Playwright into a new package, with measurements and a components builder. Status: stable. Surface: CLI. Entry point: `tools/kit/capture/public/` copied into `systems/<slug>/tools/` (`docs/CAPTURE.md`). Tests: `tools/test_kit_capture.py`.
- **Signed-in web capture**: sign in to a real browser, snapshot each state to disk, then render and measure the copies headless with credential fields and signed URLs stripped. Status: stable. Surface: CLI. Entry point: `tools/kit/capture/signed-in/` (`snapshot.js`). Tests: `tools/test_kit_privacy.py`, `tools/test_package_snapshots.py`.
- **Native iOS capture**: capture an iPhone app through iPhone Mirroring and sample values from window screenshots, then build tokens and crops. Status: stable. Surface: macOS. Entry point: `tools/kit/capture/native/`, `tools/kit/native/`. Tests: `tools/test_kit_native.py`, `tools/test_sample.py`.
- **Electron desktop capture**: read screenshots and CSS variables live from a desktop app started with `--remote-debugging-port`. Status: stable. Surface: macOS. Entry point: `tools/kit/capture/electron/shot.mjs`. Tests: none.
- **Native desktop capture**: capture a native macOS app's own window the same way as the iOS route (guessing: beta, since the kit only describes it as a variant of the iOS route). Status: beta. Surface: macOS. Entry point: `tools/kit/capture/native/winid.swift`, `sample.py`. Tests: `tools/test_sample.py`.
- **Screenshot sidecars and quantizing**: get a `<name>.png.capture.json` beside every shot (viewport, pixel ratio, document and PNG size) and shrink screenshots to 256-colour PNGs. Status: stable. Surface: CLI. Entry point: `tools/kit/capture/screenshot.mjs`, `quantize.py`. Tests: `tools/test_capture_screenshot.py`, `tools/test_kit_quantize.py`, `tools/test_kit_quantize_sidecars.py`.
- **Token and style-guide builders**: build a new package's `tokens.json`, `components.md` and `style-guide.html` from its captured readings. Status: stable. Surface: CLI. Entry point: `tools/kit/build/` copied into `systems/<slug>/tools/`. Tests: `tools/package_tests.py`.
- **Image redaction**: paint credentials and personal data out of finished screenshots and crops from per-package rectangle rules, OCR-check every image against banned patterns, or print OCR lines with boxes. Status: stable. Surface: CLI. Entry point: `python3 tools/redact_images.py apply|check|lines systems/<slug>`, `tools/redact-rules/<slug>.json`. Tests: `tools/test_redact_images.py`.
- **Capture batch manifests**: work through queued apps to capture in manifest batches (guessing: beta, since batch 1 is done and 398 apps remain). Status: beta. Surface: job. Entry point: `webapps-manifest.json`, `ios-manifest.json`, `docs/HANDOVER.md`. Tests: none.
- **Authenticated capture pass**: capture the sign-in, account, checkout and submission surfaces listed in the gated queue. Status: planned. Surface: CLI. Entry point: `docs/TODO.md`, `docs/GATED.md`. Tests: none.
- **Reduced-motion and z-index probes**: have the capture kit record `prefers-reduced-motion` behaviour and z-index layers. Status: planned. Surface: CLI. Entry point: `docs/TODO.md`. Tests: none.

## Refero store
- **Refero fetch and export**: fetch new or changed styles from styles.refero.design and re-export their DESIGN.md, CSS and token files, or re-materialise them offline. Status: stable. Surface: CLI. Entry point: `python3 tools/refero/fetch.py [--force|--enrich-media|--export-only]`. Tests: `tools/test_refero.py`, `tools/test_refero_fetch_net.py`, `tools/test_refero_writes.py`.
- **Refero labelling**: label styles by product type, design style and tags with an Anthropic API pass, and print the label distribution. Status: stable. Surface: CLI. Entry point: `python3 tools/refero/classify.py [--stats|--force]`. Tests: `tools/test_refero_classify.py`.
- **Refero derived stores**: backfill component HTML, rebuild the similar-styles graph, scrape curated collections and fetch the paid-catalog screens directory. Status: stable. Surface: CLI. Entry point: `tools/refero/backfill_components.py`, `index_similar.py`, `fetch_collections.py`, `fetch_screens.py`. Tests: none.
- **Coverage diff**: diff the refero screens directory against the `systems/` packages into `coverage.json`. Status: stable. Surface: CLI. Entry point: `python3 tools/refero/coverage.py`. Tests: none.
- **Refero store check**: fail when `refero.db`, the style folders, `refero/catalog.json` and the derived stores disagree. Status: stable. Surface: CLI. Entry point: `python3 tools/refero/check.py` (part of `make check`). Tests: `tools/test_refero_check.py`.
- **Refero media mirror**: download screenshots, posters, videos and favicons into a host-side mirror outside git, check it for gaps, compress videos, and upload it to an R2 bucket. Status: stable. Surface: CLI. Entry point: `python3 tools/refero/mirror_media.py [--only|--check|--compress-videos]`, `tools/refero/upload_r2.py`. Tests: `tools/test_refero_mirror.py`, `tools/test_upload_r2.py`.

## Agent layer (MCP and API)
- **Library tools**: search styles across both stores, get a style's catalog entry, read resolved token groups, read package docs, list and view media, and get an apply-style handoff prompt (`search_styles`, `get_style`, `get_tokens`, `read_doc`, `list_media`, `view_media`, `handoff_prompt`). - **CLI installer**: install the `ds` client with one curl command that writes the server URL into its config. Status: stable. Surface: API. Entry point: `GET /api/install.sh`, `GET /api/ds`. Tests: `tools/test_routes.py`, `tools/test_cli_ds.py`.
- **Home-server API**: serve the `/api/` routes behind nginx for the deployed docs site. Status: stable. Surface: API. Entry point: `server/api.py`. Tests: `tools/test_routes.py`.
