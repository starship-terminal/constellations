# Rights and removal requests

This repository is public on GitHub at
[starship-terminal/constellations](https://github.com/starship-terminal/constellations).
It is a reference library of measurements taken from real products, kept for
design study.

## What belongs to whom

Every package describes another company's product. Product names, logos,
icons, illustrations, screenshots and fonts belong to their owners. They
appear here only to document what was measured.

Nothing in this repository is licensed for reuse of those assets. Polaris
ships with Shopify's own licences, and Inter with the OFL, in
`systems/polaris/licenses/`; those files, not this repository, set the terms
for what they cover.

So: borrow structure and proportions. Do not copy a product's logo, icons,
illustrations or brand colours into something that ships.

## Removal requests

To ask for something to be removed, open an issue in this repository:
<https://github.com/starship-terminal/constellations/issues>. Name the
product and the package or files. The owner will act on it.

## Privacy

What is masked in screenshots, crops and recorded text is set in
[AGENTS.md](../AGENTS.md).

## Rules

- Keep proprietary fonts in `systems/<slug>/fonts/`, which is gitignored.
- Raw page copies and redaction lists stay outside the repository
  ([CAPTURE.md](CAPTURE.md)).
