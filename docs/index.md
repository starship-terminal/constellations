# Design systems

A library of design styles captured from real products, so any project, and any
coding agent working in it, can say "make it look like Linear" and find measured
tokens, components and screenshots in one place.

    ---

-   **[Scorecard](scorecard/index.md)**

    ---

    How each system measures up against the checklist a complete design system has

-   **[What a design system contains](DESIGN-SYSTEM.md)**
