# Raw readings

Captured 2026-11-21 from public grow.google pages in headless Chromium.

| File | What it is |
|---|---|
| css-vars.json | Custom properties parsed from stylesheet response bodies. CSSOM was cross-origin and empty. Glue palette is on `:root`. |
| live-readings.json | Computed styles, hover, focus, and a prefers-color-scheme dark sample. |
| components-computed.json | First-pass computed styles per page. |
| font-faces.json | Font-face family names from the same sheets. Files are not stored. |
