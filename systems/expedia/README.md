# Expedia design reference

A token set and component reference for Expedia's public site — for building travel-search, booking and marketing surfaces in the style of the real thing. It was read from **www.expedia.com** on **2026-11-13/14**, signed out, in headless Chromium at 1440 x 900 and 390 x 844: the home page with its search panels open, a public hotel results page, and both at phone width.

The unusual part of the capture: expedia.com answers every automated request with a 429 **"Bot or Not?"** challenge (headless and headed Chromium, several user agents, regional domains — all challenged). The DOM evidence is therefore a **Wayback Machine snapshot** of the public home (`20260207171241`) and hotel-search (`20261030191926`) pages served locally, painted with Expedia's **live travel-assets.com CSS and fonts** — so component styles, tokens and measurements are current even though the markup is archived. Field panels (calendar, travellers, destination) were measured on the snapshot hydrated with the site's own JavaScript.

The reason Expedia is worth a capture: it is the reference implementation of the EGDS/UITK design system — a 57-role colour layer (`primary`/`on-primary`/`surface-*`/`outline`/status) rebound per `data-theme-*` attribute across eight+ declared palettes (light-1 on the page, marketing-3 on the promo bands, dark-1/2 and the yellow bright-1, plus the One Key loyalty tiers), the Centra No2 UI face with Reckless XPD display serif, a rigid 48px field / pill-radius-button geometry, and the multi-product tabbed search card that every travel flow starts from.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export expedia` prints them all with aliases resolved.

### Principles

1. Do reserve `egds.primary` #1668E3 for the action that ends a flow
2. Do build search fields as 48px-high, 8px-radius outlined boxes.
3. Do use full-round pills for buttons and chips.
4. Do round cards at 16px
5. Do re-theme sections with the theme attribute, not overrides.
6. Do pair the Reckless XPD display serif with Centra No2 UI text
7. Don't add a second accent blue.
8. Don't draw borders where a fill does the work
9. Don't ship the dark/marketing/loyalty sets as finished themes
10. Don't draw focus as a colour wash.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Three evidence modes, kept distinct:

- **Static SSR (scripts blocked).** The archived page markup, painted by live CDN CSS. The header menus, search shell, results rail and cards are server-rendered, so this mode is stable. All default/hover/focus/forced-pressed states and most crops come from here.
- **Hydrated (site JS enabled).** The same archived page with Expedia's JavaScript running. Its GraphQL/API refetches fail on the local copy, but UI-only panels still open: the calendar dialog, the travellers stepper, the destination panel, the Flights tab. Nothing was submitted — the kit never searches, books, signs in or saves.
- **Live CDN CSS.** The token layer comes from the stylesheets themselves: 11,319 declarations across the `egds`, `palette`, `legacy`, `app` and `uitk` owners, resolved per theme attribute in a real browser (`raw/css-vars.json`).

State mechanics: `hover` is a real pointer hover, `focus-visible` a real keyboard focus (Shift+Tab, Tab), `pressed` is forced with DevTools `CSS.forcePseudoState` so no link or button ever fired, `filled` is text typed into a field and deleted again.

## What to distrust

- **The markup is a snapshot, not today's page.** Styles are live, but a component added or restructured after the archive date is not covered. Where the archive's SSR and the live SPA differ (hydration empties regions whose refetch fails), the static reading is the trustworthy one.
- **The results page is someone else's public query** (Toronto, 221 properties) — prices, photos and hotel names are page content, not Expedia chrome values.
- **Sort-open and any applied state are screenshot-only**; the results page was measured statically because hydration refetches fail.
- **The currency control's focus ring is unmeasured** — it could not be reached by keyboard in the static capture. The field triggers show no focus ring in measurement, which is how the SSR markup behaves; hydrated triggers may differ.
- **No measured focus colour is published.** The Search button's keyboard focus draws the browser's own `5px auto` ring in Chrome's default #101010, not the declared `--egds-outline-focus` (#1668e3 in light-1), so `core.measured.focus.outlineColor` is left out and listed under `_gaps` in `raw/component-tokens.json`; the declared `egds.outlineFocus` roles stay. `core.measured.focus.outlineWidth` is the measured width of that browser ring.
- **Scrim/gradient roles are raw strings** (`egds.*Scrim` as `other`), and 27 values the resolver cannot read (`[object Object]` composites, `url()` fonts) are listed in `core.$extensions.notTokenised`.

## Fonts

**Centra No2** is the UI face (400/500 weights do most of the work) and **Reckless XPD** the display serif for the hero. Both are Expedia's proprietary fonts, served from travel-assets.com — they loaded during the capture, so measurements name the real faces. [style-guide.html](style-guide.html) falls back to Inter and Source Serif 4.

## Do and don't

1. **Do reserve `egds.primary` #1668E3 for the action that ends a flow** — Search, Done, Sign in — and let it carry the on-primary #FFFFFF text. See [search-submit-default](components/crops/search-submit-default.png).
2. **Do build search fields as 48px-high, 8px-radius outlined boxes.** All three triggers share `input`/`field` geometry: 344 x 48 with an `outline`-coloured border. See [field-destination-default](components/crops/field-destination-default.png).
3. **Do use full-round pills for buttons and chips.** `cornerRadius.10000x` is the pill; the sort control and tab track show it. See [sort-control-default](components/crops/sort-control-default.png).
4. **Do round cards at 16px** (`card` corner radius = `radius.4x`) and popovers at 8px. Cards sit flat; menus and the calendar popover float on a soft `0 2px 12px` shadow at 8% ink (the `menu.container`/`sheet.standard` elevation, not `elevation.8`). See [property-card-default](components/crops/property-card-default.png) and [calendar-dialog-open](components/crops/calendar-dialog-open.png).
5. **Do re-theme sections with the theme attribute, not overrides.** The promo band is the same components under `data-theme-light="marketing-3"` — `surface` and `primary` rebind wholesale. See [marketing-band-default](components/crops/marketing-band-default.png).
6. **Do pair the Reckless XPD display serif with Centra No2 UI text**, and keep UI text at 400/500. See [hero-title-default](components/crops/hero-title-default.png).
7. **Don't add a second accent blue.** `primary`, `secondary` and `outline-focus` are all the same #1668E3 family; status comes from `positive`/`critical`/`featured`/`info`. See [refund-note-default](components/crops/refund-note-default.png) and [urgency-note-default](components/crops/urgency-note-default.png).
8. **Don't draw borders where a fill does the work** — hover and container states move between `surface-container` greys and `*-container` tints, not darker outlines. See [tertiary-button-hover](components/crops/tertiary-button-hover.png).
9. **Don't ship the dark/marketing/loyalty sets as finished themes** — only `light-1` and `marketing-3` painted on the captured pages; the rest are declared bindings kept for reference. The evidence is `themeChecks` in [raw/css-vars.json](raw/css-vars.json) and the light-pinned surface in [home-light-default](screenshots/home-light-default.png).
10. **Don't draw focus as a colour wash.** Keyboard focus is a 1px #101010 outline (heavier ring on primary buttons). See [search-submit-focus-visible](components/crops/search-submit-focus-visible.png).

## Rebuild

The kit under [tools/capture/](tools/capture) re-reads the locally-served Wayback pages and the live CDN CSS; the builders re-derive the package from `raw/`:

```sh
cd systems/expedia
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  node tools/capture/public/public.mjs        # page screenshots into ~/.design-systems/expedia/raw-shots
PLAYWRIGHT=... node tools/capture/vars.mjs    # raw/css-vars.json
PLAYWRIGHT=... node tools/capture/public/measure.mjs   # raw/components-computed.json + crops
PLAYWRIGHT=... node tools/capture/layout.mjs           # raw/layout.json
python3 tools/capture/quantize.py ~/.design-systems/expedia/raw-shots  # screenshots/; originals stay out of the repo
node tools/capture/public/build-measurements.mjs       # raw/measurements.md
python3 tools/build_component_tokens.py       # raw/component-tokens.json from the readings
python3 tools/build_tokens.py                 # tokens.json from component-tokens.json + css-vars.json
python3 tools/build_components_md.public.py   # components.md
python3 tools/build_style_guide.py            # style-guide.html
```

Then `make design-md` at the repo root refreshes [DESIGN.md](DESIGN.md), and `make check` re-grades the package.
