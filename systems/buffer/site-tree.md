# Buffer public site tree

Mapped on 2026-11-22 from [https://buffer.com/](https://buffer.com/) while signed out. Desktop shots are 1440 × 900 CSS pixels at 2× (PNG 2880 × 1800). Phone shots are 390 × 844 CSS pixels at 2× (PNG 780 × 1688). They are the first viewport, not the full page. The homepage title was "Buffer: Social media management for everyone". The first visible heading is "Your social media workspace". This is a live marketing site, not a parked domain and not a captcha wall.

Nothing was typed. No email, password, code, phone, or address was entered. No form was submitted. No identity provider was clicked. No captcha was solved. No account was created. No post was scheduled. `login-extracted` stays `not-started`.

origin/main had no `systems/buffer/`. This walk adds the package. catalog.json and webapps-manifest.json were left alone.

Query strings that carry `cta`, campaign, or a session path segment are not recorded. Login and signup land on `auth.buffer.com` with a one-time path segment. The recorded URL is the public entry, without that segment.
