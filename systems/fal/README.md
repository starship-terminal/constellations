# fal design reference

A token set and component reference for fal's public surface. Read from **fal.ai** on **2026-11-21**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: the marketing home, pricing, enterprise, docs, explore, blog, legal, tools, learn, careers, serverless, and the login wall. The dashboard was not entered.

fal paints two systems. The marketing site is Webflow: bronze `#403700` heroes, neon `#adff00` primary buttons, grey `#e5ece7` islands, cyan `#99edff` display type, Focal Web. The app shell (login, explore, docs) is a separate light UI in Public Sans Rounded, with a public theme switch on the docs shell. Dark docs was opened with that switch. **Boundary:** Get Started, `/dashboard`, and Workflows stop at `/login`. The wall offers GitHub, Google, Microsoft, and SSO. No email field. Nothing was submitted.

## How the values were read

Custom properties were read from the live CSSOM on fal.ai and fal.ai/login (`tools/capture/harvest.mjs` → [raw/css-vars.json](raw/css-vars.json)). Component states were read with `getComputedStyle` after hover, focus, and a mouse-down that was cancelled so links were not followed (`tools/capture/states.mjs`). Docs dark colours were read after clicking "Switch to dark theme" (`raw/docs-dark-computed.json`). Screenshots were taken in Playwright and quantised to 256 colours.

The DataGrail consent banner (`aside.dg-consent-banner`) was removed from the DOM before screenshots. Accept All was not clicked.

## What to distrust

- This is the public site, not the signed-in product. Dashboard, keys, workflows, and billing are unknown.
- Marketing and the app shell are different systems. Do not mix neon buttons into the docs shell.
- Dark tokens are from the docs shell only. The marketing site has no dark theme.
- `dark.accent` carries the light app primary because that name did not resolve under `.dark` in the probe. It is labelled as carried.
- Screenshots are 256-colour PNGs. Read colours from tokens.json.
- Webflow variable names include a `<deleted|variable-...>` suffix. The builder strips it. The resolved value is what was tokenised.

## Fonts

**Focal Web** runs the marketing nav and display (Arial fallback). **publicSansRounded** runs the login and explore controls. **focal** is the app heading stack. **chivoMono** is the app mono stack. None of these files are in the package.

## Do and don't

1. **Do paint the marketing hero bronze and the primary action neon.** The home hero sits on `#403700` and Get Started is `#adff00`. [home-light-default.png](screenshots/home-light-default.png).
2. **Do keep the header Get Started black.** The header pill is `#000000`, not neon. [button-start-default.png](components/crops/button-start-default.png).
3. **Do treat docs as a separate shell.** It has its own sidebar and a theme switch. [docs-dark-default.png](screenshots/docs-dark-default.png).
4. **Don't invent a signed-in dashboard from this package.** Get Started stops at the OAuth wall. [login-light-default.png](screenshots/login-light-default.png).
5. **Don't put an email field on the login wall.** None is offered. GitHub, Google, Microsoft, and SSO only.
