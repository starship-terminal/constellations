# Lemonade

## Overview

Public marketing site at https://www.lemonade.com/, captured 2026-11-21, signed out. One light theme. Desktop 1440 by 900 and phone 390 by 844.

This file was written by hand from [tokens.json](tokens.json). It was not generated by `make design-md`, because that command rewrites the catalog and the catalog was left alone.

## Colors

| Role | Value | Source |
|---|---|---|
| page | `#ffffff` | body background |
| text | `#4a4a4a` | h1 and nav |
| muted | `#8c8c8c` | `--gray-color` |
| surface | `#ffffff` | header background |
| accent | `#ff0083` | Check our prices |
| accent-hover | `#dc0073` | Check our prices hover |
| on-accent | `#ffffff` | button text |
| border | `#d9d9d9` | login email field |
| disabled | `#e7e7e7` | empty login button |

| on-drawer | `#ffffff` | phone menu links |

## Typography

| Role | Family | Size | Weight | Line height |
|---|---|---|---|---|
| display | Merriweather | 55px | 400 | 71.5px |
| body | Lato | 18px | 400 | 28px |
| label | Lato | 16px | 400 | 20.8px |
| button | Lato | 18px | 700 | 23.4px |

## Rounded

Control radius is 5px on the primary button and the login field.

## Spacing

Primary button padding is 18px vertical and 44px horizontal. The button height is 61px.

## Components

The primary button uses accent as the background, on-accent as the text, and the control radius. Hover uses accent-hover. The empty login button uses disabled as the background and on-accent as the text.

## Do's and Don'ts

Use one pink for the primary action. Keep the page white and the type `#4a4a4a`. Keep control corners at 5px. Leave the login field empty. Do not treat the quote chat shot as a finished screen.
