# ROVR

ROVR is a live radio product (Radio Reinvented, v1.0.1). This package covers the public signed-out web app at `https://www.rovr.live/` on 2026-11-19: home, moods, schedule, about, privacy, and the signed-out `/login` gate. The live theme was `html.dark`. No account was created.

### Principles

1. Do use the painted yellow `#FFF057` for buttons, rules and display type.
2. Do set the page to black `#000000` with near-white `#FAFAFA` body text in the live theme.
3. Do keep corners square on the auth links and the track card, and use a full pill on Message, Listen and the icon buttons.
4. Do set kernStandard for UI and gtAlpina for names.
5. Don't use `--primary` (`#FFFF57`) where the page uses the painted yellow.
6. Don't ship the light palette as if a light page was captured.
7. Don't invent a screenshot for a frame the browser did not produce.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The T3 preview browser opened `https://www.rovr.live/` on its own tab (`reuseExistingTab` false). `preview_snapshot` failed with "The browser is not producing screenshot frames", so nothing was screenshotted. `preview_evaluate` still read the attached page: `getComputedStyle` on the root, the header, nav, buttons, type samples, and the stylesheet's custom properties.

Pages read: `/`, `/login`, `/moods`, `/schedule`, `/about`, `/privacy`. The pane was 1169 by 731 at devicePixelRatio 2. `html` had class `dark`. `color-scheme` computed to `dark`.

Dark semantic colours are the browser's resolution of `hsl(var(--token))` on that class. Light semantic colours are the `:root` declarations in the stylesheet, converted with the same HSL formula. They were not the theme on screen.

The painted brand yellow on buttons, the header rule and most text is `rgb(255, 240, 87)`. The `--primary` token resolves to `rgb(255, 255, 87)`. Both are recorded. Mood titles use a third yellow, `rgb(242, 232, 74)`, also written as `#F2E84A` in a class.

## What to distrust

- Light tokens are declared, not shown. Do not treat them as a captured surface.
- `--primary` and the painted yellow are different colours. Buttons use the painted one.
- No screenshot backs these numbers. The readings are the evidence.
- Hover, focus, pressed and disabled were not forced. A global focus rule clears the outline.
- The viewport was 1169, not 1440, and no 390 pass was taken.
- Alpha colours (nav at 0.5, clock at 0.3) are in the readings and not in `tokens.json`, because the catalog colour parser accepts hex and `rgb()` only.

## Fonts

kernStandard is the UI face (body, nav, buttons, headings). The page loads 400, 700 and 700 italic, with a fallback named kernStandard Fallback, then `system-ui`. gtAlpina is the curator and label face (300 italic declared). Roboto is the player clock (weights 100 to 500 declared; the clock computed at 300). All three are the product's own faces. They are named here and not committed.

## Do and don't

- Do use the painted yellow `#FFF057` for buttons, rules and display type. That is what the page paints.
- Do set the page to black `#000000` with near-white `#FAFAFA` body text in the live theme.
- Do keep corners square on the auth links and the track card, and use a full pill on Message, Listen and the icon buttons.
- Do set kernStandard for UI and gtAlpina for names.
- Don't use `--primary` (`#FFFF57`) where the page uses the painted yellow. They are not the same.
- Don't ship the light palette as if a light page was captured.
- Don't invent a screenshot for a frame the browser did not produce.
