## Button

Capy's button has seven looks, which its gallery shows on each surface it ships on (card, window, panel, overlay): ghost (text only), soft (`base.secondary`), outline (a `base.border-2` hairline), solid (`base.button`), selected (`base.secondary`, the soft look's fill, marked `data-selected`), accent (`base.primary` teal with white text) and inverse (`base.inverse`, the ink). Painted intents add a red fill (`base.destructive`) and red text for Discard and Remove key. Sizes are the control heights, xs 24, sm 28 and base 32 (`controlHeight.*`); every button has the 6px radius (`radius.button`). Loading replaces the first icon with a dot grid and lowers the opacity. Hover deepens the fill (`base.button-hover`, `base.secondary-hover`); focus-visible draws a `base.ring` outline. In the app, Settings rows use ghost and outline buttons, the setup card an outline one, and the Start button is the accent icon button.
