# Replit public site tree

Mapped on 2026-11-22 from the public homepage, https://replit.com/. Title: "AI App and Website Builder | Replit". The first visible heading is "What will you build?". The homepage is a live marketing page, not a parked domain and not a captcha wall. The page painted cream. `prefers-color-scheme` was dark, and the site has no public theme toggle, so the shots are named light.

Photographs come from an incognito preview tab. Desktop shots are 1440 by 900 CSS pixels at 2x (PNG width 2880). Phone shots are 390 by 844 CSS pixels at 2x (PNG width 780). They are the first viewport, not the full page.

Nothing was typed. No email, password, code, phone, or address was entered. No form was submitted. No identity provider was clicked. No captcha was solved. No repl was created and the editor was not started. `login-extracted` stays not-started. catalog.json was left alone. webapps-manifest.json was left alone.

origin/main did not have `systems/replit/`. This walk adds the site tree and screenshots. It does not measure tokens.
