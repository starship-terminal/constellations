# SavvyCal

SavvyCal is scheduling software (savvycal.com). This package captures the public marketing site and the signed-out login form. No account was used.

Surfaces: home, features, pricing, integrations, teams, a public demo booking page, password reset, a 404, and login. Theme: light marketing. Widths: 1440 and 390 CSS pixels. Captured 19 November 2026.

## How the values were read

The T3 preview browser opened `https://savvycal.com/` in its own tab. Computed styles were read with `getComputedStyle` at 1440 by 900, device pixel ratio 2, visual viewport scale 1. Login was opened in the same tab and painted a signed-out form. It was not a Cloudflare challenge.

`preview_snapshot` then returned "The browser is not producing screenshot frames." Measurements already read were kept.

Headless Chromium then loaded the public pages, including login, because those pages had already loaded in the preview browser without a challenge. Screenshots are 256-colour PNGs. Pixel size is 2 times the CSS viewport. `window.innerWidth` was 1440 and 390.

Brand colours were read from computed custom properties on `:root` (`--color-brand-oatmeal`, `--color-brand-orange`, `--color-brand-neon-green`, `--color-brand-sand`) and from computed colours on the elements that use them. Olive and zinc roles are oklch custom properties, converted to sRGB hex.

## What to distrust

The first preview load set `html` class `dark`. Marketing body background stayed oatmeal. Calendar tokens (`--color-cal-*`) resolved to the dark set while that class was present. Headless Chrome loaded the same pages with an empty `html` class. This package records the light marketing surfaces. The dark calendar tokens are a gap, not a second theme of the marketing site.

Forced `:hover` on Sign up did not change the computed background. The class declares `hover:bg-[#e03a18]`. That hex is a declared class, not a computed hover.

The email focus crop paints a green ring. Forced `:focus` computed a blue box-shadow that did not match the crop. `{color.focus-field}` is sampled from the crop (`rgb(0, 201, 81)`), not from that computed shadow.

Pill radius computed as a multi-million-pixel value from `rounded-full`. The token is `9999px`.

GT Alpina and GT America are proprietary. They are named in the tokens and are not committed.

## Do and don't

- **Use oatmeal for the page and orange for the primary pill.** The page is `#fcf7ed`. Sign up is `#f54320` with a white label, full pill, 14px weight 500. [button-primary-default.png](components/crops/button-primary-default.png)
- **Use neon green for the second action.** Get started free and Sign In are `#b9ff78` with near-black type. [button-neon-default.png](components/crops/button-neon-default.png)
- **Set headlines in GT Alpina Condensed at weight 700.** The home headline is 88px with line-height 83.6px. [home-light-default.png](screenshots/home-light-default.png)
- **Keep login on oatmeal, with white OAuth buttons and a neon submit.** The form is 448px wide. OAuth buttons are 48px, radius 8px. [login-light-default.png](screenshots/login-light-default.png)
- **Do not invent a dark marketing theme.** The captured pages do not offer a toggle. [pricing-light-default.png](screenshots/pricing-light-default.png)
- **Do not submit signup or a calendar connection from this package.** Login offers Google, Microsoft, and Fastmail beside email. Those buttons were not pressed.
