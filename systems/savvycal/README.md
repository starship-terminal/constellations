# SavvyCal design reference

A token set and component reference for SavvyCal's public site. It was read from **savvycal.com** on **2026-11-21**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: the marketing shell, pricing, a public booking demo, the integrations directory, articles, legal pages, and the login and signup walls as they load.

SavvyCal paints one light surface: oatmeal page `#fcf7ed`, sand bands `#f4ebda`, orange pills `#f54320`, neon green `#b9ff78` on the login submit, olive ink for text, Inter Variable for UI, and GT Alpina Condensed for the display heading. The signed-in scheduler was not reached.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export savvycal` prints them all with aliases resolved.

### Principles

1. Keep the page oatmeal and the accent to one orange pill.
2. Use neon green only on the login submit.
3. Set the display line in a condensed face and the UI in Inter.
4. Round controls as pills.
5. Do not style the signed-in scheduler from this package.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Headless Chromium opened the public pages. [tools/capture/vars.mjs](tools/capture/vars.mjs) read the CSSOM. Marketing pages declare `--nav-height` only. Brand colours are Tailwind utilities, read with `getComputedStyle` on elements that carry those classes. [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) read each control in default, hover, keyboard focus, and a CDP pressed state. [tools/capture/public/public.mjs](tools/capture/public/public.mjs) took the screenshots. [tools/build_tokens.py](tools/build_tokens.py) writes tokens.json.

`oklch()` computed colours were converted to sRGB and labelled Derived. `rgb()` values are Measured. Nothing was submitted. The password field was not typed. Google, Microsoft, and Fastmail were not clicked.

## What to distrust

- This is the public site. The scheduler behind https://savvycal.com/login was not captured.
- There is no dark theme switch. Login CSS includes `dark:` utilities that were not activated.
- Pill radius is a computed value of `3.35544e+07px`. The token uses `9999px` for the same pill. That step is Derived.
- Screenshots are 256-colour PNGs. Read colours from tokens.json.
- Status colours, motion durations, and a declared spacing scale were not in the CSS. They are Not captured.
- The booking demo at `/demo` is a published sample page. It is not a signed-in account.

## Fonts

Inter Variable is the UI face, loaded from rsms.me/inter. GT Alpina Condensed is the display face, served from SavvyCal's asset host. GT America Standard is on the login OAuth buttons. The package does not include the font files. The style guide falls back to system faces.

## Do and don't

- **Keep the page oatmeal and the accent to one orange pill.** The fold uses one filled orange control. See [home-light-default.png](screenshots/home-light-default.png).
- **Use neon green only on the login submit.** Marketing CTAs are orange. The Sign In pill is `#b9ff78`. See [login-light-default.png](screenshots/login-light-default.png).
- **Set the display line in a condensed face and the UI in Inter.** The h1 is 88px GT Alpina Condensed. Nav and buttons are 14px Inter Variable. See [home-light-default.png](screenshots/home-light-default.png).
- **Round controls as pills.** CTAs, the search field, and billing toggles share a full pill radius. Fields on the login wall use 8px. See [integrations-light-default.png](screenshots/integrations-light-default.png).
- **Do not style the signed-in scheduler from this package.** Login and signup are walls. See [site-tree.md](site-tree.md).
