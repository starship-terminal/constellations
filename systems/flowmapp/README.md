# FlowMapp design reference

A token set and site map for FlowMapp's public site (https://www.flowmapp.com/), a Webflow marketing site for a UX planning product. Captured signed out on 2026-11-21 in Playwright Chromium at 1440 x 900 and 390 x 844. The painted marketing theme is light. A dark slot set is declared on `:root` and was not bound on any captured public page.

The product app at app.flowmapp.com sits behind sign-in. The walk stopped at that wall. https://flowmapp.com/login is a 404. Sign in is https://app.flowmapp.com/signin (email and password, or Google). No email, password, or code was entered. Google was not clicked. No form was submitted. catalog.json is not part of this capture.

## How the values were read

Custom properties were read from the live stylesheets on https://www.flowmapp.com/ in headless Chromium (Playwright). [tools/build_tokens.py](tools/build_tokens.py) turns [raw/css-vars.json](raw/css-vars.json) into tokens.json. Component boxes were `getComputedStyle` on the home nav, the Log in button, Try for free, the hero h1, and the Start planning button (anchor and `.btn__wrapper`).

Screenshots were taken with Playwright at the viewports above. Cookie bars were hidden in CSS after a shot, never accepted.

## What to distrust

- The dark set is declared, not painted. No captured public page bound the `-dark` slots.
- `light.accent` is `--dodger-blue` (#0080ff), the painted hero fill. `--primary-blue` (#0050ff) is a second blue used as the apps primary slot. Pricing pills were not measured into a separate token.
- The Start planning anchor's own background is a 20% blue wash. The solid fill and shadow sit on `.btn__wrapper`.
- `light.focus` aliases the declared ring slot. The keyboard outline on the hero anchor was the browser default.
- Screenshots are full colour. Read colours from tokens.json.
- Signed-in canvas, editor, and settings values are Not captured.

## Fonts

Inter, weights 400, 500, 600, and 700, declared as @font-face on the marketing CSS. The apps slots name Inter for heading, body, and button. The webfont files are not committed. The guide uses the family name with a system fallback.

## Do and don't

- **Do** keep the page on `#f6f8fa` and the nav on white. [desktop-home.png](screenshots/desktop-home.png) shows the bar.
- **Do** use one blue pill for the primary marketing action. [desktop-home.png](screenshots/desktop-home.png) shows Start planning.
- **Do** pair an outline Log in with a black Try for free. [desktop-home.png](screenshots/desktop-home.png).
- **Don't** invent a painted dark marketing theme. The dark slots were not on screen.
- **Don't** treat the 404 at /login as the sign-in form. Sign in is app.flowmapp.com/signin. [desktop-signin-with-chrome.png](screenshots/desktop-signin-with-chrome.png).
- **Don't** read editor colours from the marketing page. The signed-in app was not captured.

## Rebuild

```bash
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
```

Run both from `systems/flowmapp`. They read `raw/css-vars.json`.
