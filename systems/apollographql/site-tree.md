## Login and signup walls

Known probe, confirmed 2026-11-21: https://studio.apollographql.com/login asks for email and password, or GitHub or SSO. No code was sent. The form was not typed into. GitHub and SSO were not clicked.

Start for free and Get Started open https://studio.apollographql.com/signup. That branch stops.

Docs pages whose body mentions sign-in copy (`/docs/graphos/platform/platform-api`, `/docs/graphos/platform/quickstart`, `/tutorials/lift-off-part1`) still render as public documentation. They are not the Studio login wall. They are captured as documentation, and any embedded sign-in control is not clicked.
