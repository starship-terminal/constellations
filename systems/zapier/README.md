### Principles

1. Orange is the one brand action.
2. Display type is Degular, feature type is Serrif, UI type is Inter.
3. Nav Sign up is a pill. In-page brand buttons are 4px.
4. Pricing cards are square.
5. Disabled brand buttons go warm grey, not faded orange.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The T3 preview browser opened each URL in its own tab. `preview_evaluate` read computed styles, class names and geometry. Marketing stylesheets are cross-origin, so `cssRules` threw SecurityError. The four Next.js CSS files were fetched and matched to the live classes (`zapier-marketing-ui-bgNeutral*`, brand, secondary, subtle, input, radio, pricing card, pricing tab). Identity pages (`/app/login`, `/sign-up`) reuse those marketing classes and were measured live. Custom properties on `:root` were almost absent; the named ones (`--zapier-marketing-font-*`, `--zapier-header-height`, `--lead`, `--ease-out`, `--ease-in-out`) were read from the fetched CSS.

## What to distrust

The 19 November readings were taken at 1169 CSS pixels. This pass photographed 1440 and 390. Button metrics change at 1024px in the stylesheet (non-xsmall buttons become 48px and 18px). Token colours were not re-sampled from the new PNGs. Screenshots are 256-colour.

Hover, pressed and focus-visible were not held, except the email field, which was already focused and showed the 1px ink ring. Those other states are stylesheet declarations.

Login body text computed to rgb(55, 44, 43), which is not a marketing ramp step. It is stored as `{color.neutral.ink-app}` and should not be treated as the marketing body colour.

Degular Display and Serrif are proprietary. The style guide falls back to Inter and a system serif.

## Fonts

Inter is the UI face, loaded from Google Fonts on the login host and as `Inter` plus `Inter Fallback` on the marketing host. Degular Display is the display face (computed on h1). Serrif is the feature serif (computed on feature headings, weight 300). JetBrains Mono is declared as `--zapier-marketing-font-mono` and was not seen in visible text. Degular Display and Serrif are not committed.

## Do and don't

- **Orange is the one brand action.** "Start free with email", nav Sign up and "Get started for free" use `#ff4f00`. Pricing plan CTAs are ink (`#201515`), and Google or SSO actions are outline buttons. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
- **Display type is Degular, feature type is Serrif, UI type is Inter.** Do not set a Serrif heading in the 600 weight the UI uses. Feature headings computed at weight 300.
- **Nav Sign up is a pill. In-page brand buttons are 4px.** The marketing nav pill measured radius 18px. Login's header Sign up measured radius 40px. Do not round every button into a pill.
- **Pricing cards are square.** Plan cards computed border-radius 0. Feature cards on the home page computed 12px. Do not give plan cards the feature radius.
- **Disabled brand buttons go warm grey, not faded orange.** The empty login Continue button computed fill `#eceae3` and label `#939084`. The stylesheet also sets opacity 0.75.
