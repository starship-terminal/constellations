# Retool design reference

Tokens and component notes for Retool, captured **2026-11-19**. The preview viewport was 1169 by 731, devicePixelRatio 2. Marketing and docs were dark. Login was light. Signed out the whole time.

Retool (retool.com) is a builder for internal software. This package covers the public homepage, pricing, the signed-out login and signup pages, and the public docs. No account was created. No email was typed. No demo was booked. No card, phone, government ID, company SSO, or database connection was entered.

### Principles

1. Do paint the marketing page `#151515` with text `#e9ebdf`.
2. Do use `#e9ebdf` on `#151515` for the primary pill.
3. Do stroke the secondary pill with `#8b867f`.
4. Do paint login on white with a `#f7f8f4` field and a `#151515` button.
5. Don't treat the light token set as a shipped marketing theme.
6. Don't book a demo or start a plan from this reference.
7. Don't submit signup.
8. Don't ship Saans or PX Grotesk.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The T3 preview browser opened each URL in its own tab. Custom properties were read from `getComputedStyle(document.documentElement)` and from the declared `.dark` and `.light` rules. Component boxes were read with `getComputedStyle` on the live elements. Viewport was `innerWidth` 1169, `innerHeight` 731, `devicePixelRatio` 2.

Homepage `html` loaded with `class` containing `dark` and a payload `themeMode` of `dark`. Pricing and docs were the same dark. Login has its own `--gray-*`, `--blue-*` and `--dt-*` sets and paints a white page. Signup was opened only to see the fields. It asks for email and password, so it is not email-only and was not submitted.

A class swap on the homepage, removing `dark` and adding `light`, changed `--surface-background-base` to `#e9ebdf` and the body background to rgb(233, 235, 223). The painted h1 stayed rgb(233, 235, 223). Those light tokens are labelled as a class probe.

`preview_snapshot` failed with `The browser is not producing screenshot frames`. No screenshot was invented. Headless Playwright was not started.

## What to distrust

The light semantic set is not a theme the marketing site published on its own. The page forced dark. Painted controls did not restyle when the class changed.

[raw/measured.json](raw/measured.json) holds no `--raw-*` ramp readings, no login palette and only four light custom properties. The builder labels every token whose value raw/ does not hold "Reconstruction": 51 tokens, most of the `--raw-*` ramps and the login colours among them. They were typed in from the capture session. `light.scrim` was not read after the class swap. It repeats the dark set's `--surface-lightbox-scrim`.

The pill radius token is `9999px`. The computed value was `1.67772e+07px`, which is the browser's full-pill number. Use the token, not that computed number, when drawing.

Docs `--ifm-color-primary` and `--ifm-link-color` computed as empty strings. The blue on the page is `--raw-blue-primary` (`#518dd2`), measured on the marketing submit control and the login focus ring.

Login `--text-primary` is `#222`. The heading computed rgb(21, 21, 21). Both are stored. They are not the same role.

The docs banner fill came back as `color(srgb ...)`. It is not in the tokens.

## Fonts

Marketing display is saansFont, with a saansFont Fallback. Docs call it SaansReg. Login title is Saans. None of those files are in this package. Marketing UI is pxGroteskFont, 400 loaded. Login body and fields are Inter, 400 and 600 loaded. The style guide uses Inter and the system sans. PX Grotesk and Saans are not shipped.

## Do and don't

- **Do paint the marketing page `#151515` with text `#e9ebdf`.** That is the live dark body. [components.md](components.md)
- **Do use `#e9ebdf` on `#151515` for the primary pill.** It is 40px tall with a full radius. [components.md](components.md)
- **Do stroke the secondary pill with `#8b867f`.** Book a demo computed that border. [components.md](components.md)
- **Do paint login on white with a `#f7f8f4` field and a `#151515` button.** Focus is 2px `#518dd2` offset 2px. [components.md](components.md)
- **Don't treat the light token set as a shipped marketing theme.** It came from a class swap. [raw/measured.json](raw/measured.json)
- **Don't book a demo or start a plan from this reference.** Those flows were not entered. [patterns.md](patterns.md)
- **Don't submit signup.** It asks for a password, and Cloud signups were paused. [patterns.md](patterns.md)
- **Don't ship Saans or PX Grotesk.** They are named, not included. [components.md](components.md)
