# Microsoft Teams design reference

A token set and component reference for the public Microsoft Teams marketing site. Read signed out on 2026-11-19 from https://www.microsoft.com/en-us/microsoft-teams/, which redirects to `/microsoft-teams/group-chat-software/`. Also read: plans and pricing, the download page, and Teams for free. Desktop captures are 1440 by 900 at 1x. The phone capture is 390 by 844 at 2x. One painted light theme. The signed-in Teams app (chat, meetings, calling) needs a Microsoft work, school, or personal account and was not opened.

The marketing pages paint a purple action, `#5d5bd4`, on Segoe UI Variable. The stylesheet also declares a Fluent-style `--ds-app-*` layer whose interactive blue is `#0078d4`. That blue is recorded as a declared token. It is not the button fill.

### Principles

1. Do paint actions purple, not Fluent blue.
2. Do set headings in Segoe UI Variable Display at 62px.
3. Do keep the universal header at 54px on white.
4. Do use `#333275` for text links and secondary outlines.
5. Don't invent a dark theme.
6. Don't treat `#0078d4` as the button.
7. Don't treat the free-page meeting photo as the app.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Playwright opened the public URLs signed out, at 1440 by 900 (device pixel ratio 1) and 390 by 844 (device pixel ratio 2). No account was used. The script read `getComputedStyle` on the heading, the universal header, `a.btn`, `a.link`, the Ask Microsoft field, and the footer. It also resolved every `--ds-app-color-*`, `--ds-app-space-*`, and `--ds-app-type-*` custom property on `:root` from `main-teams.css` (`clientlib-reimagine/main-teams`). Hover and focus on "Download now" were forced with Playwright hover and focus, then read again. Screenshots were taken in the same session. The T3 preview tab loaded the same URL and confirmed the redirect, the heading, and the `--ds-app-*` layer; its screenshot API returned no frames, so the PNGs come from Playwright.

## What to distrust

The declared interactive blue `#0078d4` (`--ds-app-color-interactive-primary-bg-default`) is in the stylesheet. The painted buttons are `#5d5bd4`. Several `--ds-app-color-*` stops resolved to `#00ff26` (highlight, gradient opt4, some alt backgrounds). Those are placeholder stops in the theme sheet, not colours on the page. Do not use them.

`color-scheme` was `normal`. No dark theme was painted, and no theme toggle was found. A reconstruction that adds a dark theme would be a guess.

The free page's meeting photo is a marketing image of stock people. It is not the signed-in app. Header menus were not opened. "Buy now" and "Download" were not clicked, so no checkout and no installer ran.

Screenshots are full-colour PNGs from this capture, not the kit's 256-colour quantize pass. Read values from tokens.json anyway.

## Fonts

Headings compute to Segoe UI Variable Display. Body, buttons, and the Ask Microsoft field compute to Segoe UI Variable Text. The universal header computes to Segoe UI. Fallbacks are Segoe UI, segoeui, Helvetica Neue, Helvetica, Arial, sans-serif. The sheets also declare Leelawadee UI Web and Segoe UI Web (Arabic, Cyrillic, and others) from the Office fabric CDN. Those files are proprietary and are not in this package. The tokens name the computed families and the same fallbacks.

## Do and don't

1. **Do paint actions purple, not Fluent blue.** "Download now" and "Try for free" are `#5d5bd4`, hover `#5553c1`, label white, 8px radius. See [button-primary-default](components/crops/button-primary-default.png).
2. **Do set headings in Segoe UI Variable Display at 62px.** The home hero is 62px / 72px, weight 500, tracking -1.55px, colour `#0e1726`, on a `#f4fafd` wash. See [heading-hero](components/crops/heading-hero.png).
3. **Do keep the universal header at 54px on white.** Filled "Try for free" is 31px with a 3px radius. "Sign in" is a 1px black outline. See [header-default](components/crops/header-default.png).
4. **Do use `#333275` for text links and secondary outlines.** "Learn more" and the pricing "Try for free" outline share that colour. See [link-default](components/crops/link-default.png).
5. **Don't invent a dark theme.** The public site painted one light theme. `color-scheme` was `normal`. See [home-light-default](screenshots/home-light-default.png).
6. **Don't treat `#0078d4` as the button.** That value is `--ds-app-color-interactive-primary-bg-default`. The buttons do not use it. See [tokens.json](tokens.json).
7. **Don't treat the free-page meeting photo as the app.** It is a marketing image. Chat, meetings, and calling need a Microsoft account and were not captured. See [free-light-default](screenshots/free-light-default.png).

```bash
cd systems/microsoft-teams
python3 tools/build_tokens.py

```

## Gaps

The signed-in Teams client was not captured. Sign-in links go to `https://go.microsoft.com/fwlink/p/?linkid=873020` and were not followed. No work or school tenant was used. No payment, card, or phone number was entered. "Buy now" was not clicked.
