# BYBORRE design reference

A token set and component reference for BYBORRE's public surface — for building pages and catalogue flows in the style of the real thing. It was read from **byborre.com** on **2026-11-11**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: the home page, the /collection Textile Room catalogue, a textile detail page (/collection/blink), the story and studio pages (creative-control, knit-innovation, projects, brands, designers, founders-story, responsibility, ways-of-working, team, popup-store), FAQ, contact, the signed-out /login panel, terms and privacy, plus a 390px mobile pass on home and the Textile Room.

BYBORRE is worth a capture because the Amsterdam textile studio paints an unusually restrained system: a cream `#f5f5f0` canvas under a single `black-BRAND` ink `#1b1b1b` that is every text, every button fill, the footer panel and the marquee band — with one signature move, the `#fae210` yellow every ink button flips to on hover (keeping a deeper `#c8b50d` edge), and a declared `--color-primary-*` green ramp in the Tailwind theme that surfaces only as the `#00e606` focus outline on links and cards. One family — Helvetica Neue at 400/500/700 — runs an 80/84 display down to a 10px footer link, controls share a 10px radius on a 1px `#ccccc4` border, and keyboard focus draws an inset ink ring: a transparent 2px outline plus a `white 0 0 0 0, ink 0 0 0 2px` box-shadow. **Boundary:** the Design Studio — BYBORRE's configure-and-order product — sits behind the "Log in to continue" panel and was never reached; the studio, dashboard, ordering, checkout and every signed-in surface are a recorded gap, never inferred.

## Brief

### Principles

1. Do keep it two-tone.
2. Do let the yellow answer the ink.
3. Do draw focus inside the control.
4. Do set controls at 48px on a 10px radius.
5. Do run the display type at 80/84 medium.
6. Do end pages on the rounded ink footer.
7. Don't style the studio from this package.
8. Don't reach for the green ramp.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out site in headless Chromium:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) captures every stylesheet body — the Nuxt `entry.*.css` bundle from network responses plus the page's inline `<style>` blocks re-parsed with `CSSStyleSheet` — and writes every custom property to [raw/css-vars.json](raw/css-vars.json). byborre.com declares a Tailwind theme layer: the `--color-primary-50..950` green ramp and `--color-gray-DEFAULT` as `rgb()` channel triplets ("0 230 6") that utilities composite with an alpha, plus a `.dark` flip of `--color-primary-DEFAULT` (500 → 400). Everything else — the ink/cream neutrals, the yellow hover accent, the radii and the type ramp — is measured computed values from [raw/components-computed.json](raw/components-computed.json). [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec, [tools/build_tokens.py](tools/build_tokens.py) the sets.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md). Several BYBORRE components paint nothing at the root — the colour chip's ring is a `::before`, the card's scrim and badge are descendants — so the readings record painted layers rather than trusting the wrapper.
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route with `.capture.json` sidecars, including the local UI toggles: the About flyout and cart on home, the BLUE colour chip on /collection (`collection-light-filtered`), the PHOTO/RENDER viewer on /collection/blink (`textile-light-render`), a FAQ row (`faq-light-open`) and the mobile menu. Full-page shots are capped at eight chunks; /collection stitches to 31,333px under that cap. [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.

Nothing was signed into, bought or submitted: the login panel was captured as a surface, never filled or submitted; every Order-sample, cart, Get-in-touch and external link was measured or screenshotted, never followed; the filter chip, viewer toggle, flyout and FAQ row were toggled as local UI state. The cookie consent bar (Reject/Accept/COOKIE SETTINGS) and any newsletter overlay were hidden, never answered — no consent button was ever clicked.

## What to distrust

- **Readings past a masked bot signal.** The committed screenshots and readings were taken with `navigator.webdriver` masked, the flag bot checks read to spot automation. The capture scripts no longer mask it (not run since), so a recapture may record a walled route as a boundary instead of a reading.
- **This is the public surface, not the studio.** The Design Studio — canvas, saved designs, dashboard, ordering, checkout, account — sits behind the login panel and is uncaptured. Treat the product's own design system as unknown.
- **One theme, two painted surfaces.** The cream canvas and the ink panels are one theme; nothing toggles dark. `tokens.json` keeps the ink-panel roles in the `dark` set — read them as the footer/marquee/hero surface, not a user-selectable dark mode.
- **The declared ramp is mostly unseen.** The `--color-primary-*` green ramp is real CSS (channel triplets) but on the measured surface the green only paints as the `#00e606` 1px-auto focus outline on links and cards; the visible accent is the yellow `#fae210` hover. Don't read a green UI into the package.
- **Focus is a shadow, not an outline.** The visible keyboard ring is an inset `0 0 0 2px` ink box-shadow; the outline itself is 2px transparent. FAQ rows and view tabs get the UA fallback `#005fcc` 1px-auto outline instead — no styled ring.
- **"Show all filters" is real but hidden.** `filter-toggle` is recorded missing: the button exists in the DOM at 0x0 at 1440 wide — a smaller-viewport affordance, not absent.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs; read exact colours from tokens or the raw files.
- **The collection page is truncated by design.** The 31,333px full-page shot is the shooter's eight-chunk cap; the grid past it is a documented boundary.
- **`text-field` filled was typed with the default `name@example.com`**, not a first name: the capture put its `fillText` where it was ignored. The script now passes it as an option (not run since); the reading stands as labelled by its `via`.

## Fonts

One served family does everything: **Helvetica Neue** at 400, 500 and 700, declared as `@font-face` in the site's own stylesheet and served from byborre.com's `fonts/` path. The 80px display and every button label run 500; body, nav and meta text run 400; the 700 face is declared but nothing captured paints it. The font is not distributed with the package — the tokens carry the full stack (`"Helvetica Neue", Arial, ui-sans-serif, …`) and the style guide falls back to system sans.

## Do and don't

1. **Do keep it two-tone.** Cream `#f5f5f0` fields and `#1b1b1b` ink are the whole interface palette; restraint is the look. See [home-light-default](screenshots/home-light-default.png).
2. **Do let the yellow answer the ink.** Every ink button flips to `#fae210` on hover with a `#c8b50d` edge — the accent lives on the action, not on backgrounds or text. See [order-cta](components/crops/order-cta-hover.png).
3. **Do draw focus inside the control.** The keyboard ring is an inset `0 0 0 2px` ink shadow (plus a transparent 2px outline offset 2px), not an outside glow. See [nav-link](components/crops/nav-link-focus-visible.png).
4. **Do set controls at 48px on a 10px radius.** Buttons, fields and tabs share the `1px #ccccc4` border language — fields white, tabs and chips cream. See [text-field](components/crops/text-field-default.png) and [view-tab](components/crops/view-tab-default.png).
5. **Do run the display type at 80/84 medium.** Page titles measure 80px in Helvetica Neue 500; section heads run 48. See [page-title](components/crops/page-title-default.png).
6. **Do end pages on the rounded ink footer.** The footer is a `#1b1b1b` panel with a 24px top radius — the same ink as the buttons, closed over the cream page. See [footer](components/crops/footer-default.png).
7. **Don't style the studio from this package.** Every value is the public surface's; the Design Studio behind the login panel is uncaptured.
8. **Don't reach for the green ramp.** `--color-primary-*` is declared but paints only the `#00e606` focus outline on links/cards — the visible accent is the yellow, and status colours don't exist on this surface.

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/byborre/`):

```sh
python3 tools/build_component_tokens.py        # raw/components-computed.json -> raw/component-tokens.json
python3 tools/build_tokens.py                  # -> tokens.json
python3 tools/build_style_guide.py             # -> style-guide.html
python3 tools/build_components_md.py           # -> components.md
node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir>    # full-colour PNGs -> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.

Live recapture (needs the site; Playwright at `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs`):

```sh
node tools/capture/vars.mjs                    # stylesheet harvest -> raw/css-vars.json
node tools/capture/public/measure.mjs          # computed styles + crops -> raw/components-computed.json
RAW=<scratch> node tools/capture/public/public.mjs   # screenshots -> <scratch> (incl. the flyout/filter/viewer/menu toggles)
```

byborre.com loads headless from this client; the consent bar is hidden per capture, never answered. The Design Studio stays behind the login panel.
