# Ulta Beauty

A signed-out capture of the public Ulta Beauty shop at [https://www.ulta.com](https://www.ulta.com), on 2026-11-22. The browser stayed on www.ulta.com. Desktop 1440 by 900. The wordmark is `#f37830`. Utility links are `#736d69`. Search is an underline in `#b2aba5`. Add to bag is a black pill. Body type is Circular.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

## Type

Circular for nav, prices, buttons, and the product title. Circular Std, Helvetica, and Arial are the fallbacks. Body 16px, weight 300, line height 24px. Utility links 12px, weight 300. Shop labels 14px, weight 300. Product title and price 24px, weight 500. Category title 20px, weight 500. About heading 32px, weight 500. Font files are not in this package.
