# LinkedIn design reference

A token set and component reference for LinkedIn's public signed-out surfaces. It was read from **www.linkedin.com** on **2026-11-18**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: the guest home, a public jobs search (designer jobs in the United States), the LinkedIn company page, Reid Hoffman's public profile, the User Agreement, and the sign-in wall at rest.

LinkedIn's guest site paints one light theme from a Mercer stylesheet on static.licdn.com. The page is white, the canvas is `#f3f2f0`, text is `rgba(0, 0, 0, 0.9)`, and the brand is `#0a66c2`. Primary actions are 48px pills with a 24px radius and a white label. Sign in is the same pill with a transparent fill and a 1px brand ring. Type is a system-ui stack. Bold is 600. **Boundary:** the feed, messaging, Easy Apply, and the authenticated profile sit behind sign-in. Sign in, Join now, Apply, Follow, and Message were measured, never followed. No form was submitted. Consent overlays were hidden, never clicked.

## How the values were read

Colours come from the Mercer guest stylesheet. `tools/capture/vars.mjs` walks the page's stylesheets and resolves `--color-*` plus the artdeco font and link resets. Those custom properties are not on `documentElement`'s computed style; they live in the `:root` rule. `tools/build_tokens.py` writes them into `tokens.json`.

Geometry comes from computed styles on the live DOM, via `tools/capture/public/measure.mjs`, at 1440 x 900 and a 390 x 844 pass. The Join now pill measured 115 x 48 with a 24px radius. The guest header measured 80px tall. The hero heading uses the 48px display class. The legal banner uses the 64px class.

Screenshots were taken by `tools/capture/public/public.mjs` and quantized by `tools/capture/quantize.py`. Read colours from the tokens, not from the 256-colour PNGs.

Nothing was typed into the sign-in form. The jobs keyword field was not painted on the results page that loaded, so it was not measured. The Date posted chip was opened as a local dropdown and closed with Escape. Apply, Follow, Message, Sign in, and Join now were never clicked.

## What to distrust

The jobs search is geo-served. The query was designer jobs in the United States. The cards in the screenshot are what that query returned on 2026-11-18. A later visit can show different listings.

`header-nav` measured 1128px wide, not the full 1440 viewport. The guest header's painted bar is inset. Use the 80px height. Do not treat 1128 as the page width.

Pressed states were forced with DevTools `:active` and `:hover`. A script that runs only on mousedown is not in those readings. No destination control was clicked to get a pressed look.

The keyword field and the company About us tab were not in the painted box this pass. They are omitted, not filled in.

about.linkedin.com, business.linkedin.com, and news.linkedin.com returned 403. The people directory redirected to an auth wall. Those surfaces are not in the package.

Four core steps were never measured on an element and were entered by hand at capture time: `fontSize.lg` (20px), `radius.md` (8px), `radius.full` (9999px) and `spacing.1` (4px). They carry the Reconstruction label in tokens.json. Every other size, weight, radius and spacing step is read from a named component in raw/components-computed.json. `size.icon-nav` is the measured 20px width of the nav icon (20 x 18 painted), not the 24px the capture notes assumed.

Every committed reading and screenshot was taken with `navigator.webdriver` masked in the browser context. The 2026-11 audit removed the mask from `tools/capture/public/lib.mjs`; a rerun shows the site an unmasked automated browser and may hit a bot check, which is recorded as a boundary.

## Fonts

The guest sheet names one sans stack: `-apple-system`, `system-ui`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Helvetica Neue`, `Fira Sans`, and the usual fallbacks. `core.font.family.sans` stores `-apple-system`. The full stack is in that token's `$extensions.stack`. Font files are not shipped. The site does not load a branded webfont on these guest pages.

## Do and don't

1. **Do paint actions as 48px brand pills.** Join now, See jobs, Apply, and the sign-in submit are `#0a66c2` fills with a white label and a 24px radius. See [nav-join](components/crops/nav-join-default.png).
2. **Do keep Sign in as a ring.** The secondary pill is transparent with a 1px `#0a66c2` border and a brand label. See [nav-signin](components/crops/nav-signin-default.png).
3. **Do set the page on white and the bands on canvas.** The page is `#ffffff`. Explore and footer bands use `#f3f2f0`. See [home-light-default](screenshots/home-light-default.png).
4. **Do use the system-ui stack.** Guest type is `-apple-system` / `system-ui`. Display on the home heading is 48px at weight 400. Bold in this system is 600. See [hero-h1](components/crops/hero-h1-default.png).
5. **Do keep status colours for status.** Positive is `#057642`, caution `#b93a04`, negative `#cf0007`, help `#8344cc`. They are not the brand.
6. **Don't style the feed from this package.** The feed, messaging, and Easy Apply sit behind sign-in and were not captured.
7. **Don't invent a dark theme.** The guest site painted one light theme. `dark` in `tokens.json` is empty.
8. **Don't treat the job cards as a fixed catalog.** Listings are whatever the public search returned for this IP and date. See [jobs-light-default](screenshots/jobs-light-default.png).

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/linkedin/`):

```sh
python3 tools/build_tokens.py                     # raw/css-vars.json + raw/components-computed.json -> tokens.json
python3 tools/build_style_guide.py                # -> style-guide.html
python3 tools/build_components_md.py              # -> components.md
node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.
