# Relume design reference

A token set and component reference for Relume's public site. Read from **relume.ai** (relume.io redirects there) on **2026-11-21**, signed out, in headless Chromium. Desktop 1440×900 at 1x. Phone 390×844 at 2x. Light and dark: the public theme button sets `data-theme` and `body.p-theme-dark`.

Relume's marketing system is warm paper (`#f1f0ee`) and near-black text (`#101010`), with a magenta accent (`#ff00f4` light, `#ff3ff7` dark) on the primary button. Type is Geist Variable. The signed-in builder was not entered.

**Boundary:** `https://www.relume.ai/app/login` shows email, password, Continue with Google, and Continue with SSO. Password was not submitted. Google and SSO were not clicked. Signup asks for an email. That email was not typed.

## How the values were read

The Webflow stylesheet `relume-library.shared.5b2b8ecc3.min.css` is cross-origin, so the page CSSOM cannot read it. [tools/capture/vars.mjs](tools/capture/vars.mjs) saved the stylesheet from the network response, parsed every custom property, and resolved each name on a probe element in light and in `body.p-theme-dark`.

Body, h1, and the Start for free link were read with `getComputedStyle` on the homepage at 1440×900.

Screenshots came from [tools/capture/public/public.mjs](tools/capture/public/public.mjs) through Playwright. The cookie banner was hidden, never accepted or rejected. No form was submitted. Contact and affiliate placeholder text (sample email, phone, country) was hidden with CSS before those shots, so those strings are not in the images.

## What to distrust

- This is the public site, not the builder. Project, billing, and editor screens behind `/app` are unknown.
- Screenshots are 256-colour PNGs. Read colours from tokens.json.
- `*-full` shots are a scrolled viewport, not a stitched full page. Webflow's `scrollHeight` did not match the screenshot clip, so full-page tiling was dropped. The log records the document height.
- Hipages colours in `core.color.campaign.hipages` are a campaign in the same stylesheet. They are not Relume product roles.
- Body line height and weight were not read. Not captured.
- Hover, focus, pressed, and disabled colours were not measured. Not captured.
- Motion durations were not read. Not captured.
- The dark phone signup shot reports `devicePixelRatio` inconsistently in one run. The saved PNG is 780×1688, which is 390×844 at 2x.

## Fonts

**Geist Variable** is the measured body and display family, with Arial as the fallback. **Geist Mono Variable** is declared as an `@font-face` in the Webflow CSS. **Relative**, **Relative Mono**, **Relume Icons**, and **Homietrial** are also declared. None of these fonts are in the package.

## Do and don't

- **Do** ground the page on warm paper in light and near-black in dark. [home-light-default.png](screenshots/home-light-default.png), [home-dark-default.png](screenshots/home-dark-default.png).
- **Do** use one magenta accent for the primary action. [home-light-default.png](screenshots/home-light-default.png).
- **Do** set display type in Geist Variable at a light weight. The homepage h1 is 56px, weight 400.
- **Don't** invent the builder from the homepage demo. The editor chrome on the home page is a public illustration.
- **Don't** follow Log in or Start for free and treat that as captured. Those open the wall.
- **Don't** read colours off the 256-colour screenshots. Use tokens.json.
