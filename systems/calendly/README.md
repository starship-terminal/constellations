# Calendly design reference

A token set and component reference for Calendly's public site. Read from calendly.com on 2026-11-21, signed out, in headless Chromium at 1440×900 and 390×844. Surfaces: the marketing homepage, pricing, product and solution pages, help, blog, about, the empty login and signup walls, and one public booking profile. No account was created. No form was submitted.

Calendly's marketing site paints one light theme: magnolia page `#fcfbf8`, midnight text and buttons `#071a31`, cornflower focus `#6bb1ff`, and a serif display face (Wulkan Text) over Geist and Calendly Sans. The public booking page is a separate, quieter card.

## How the values were read

Every value came off the signed-out site in headless Chromium on 2026-11-21.

- **Tokens.** Custom properties were read from the homepage CSSOM (`getComputedStyle` on `:root` plus authored declarations). 423 non-Tailwind names resolved. [tools/build_tokens.py](tools/build_tokens.py) keeps the Calendly semantic set and drops Tailwind's stock hue palette. Lengths authored as `calc(.25rem * N)` are stored as the derived px at a 16px root.
- **Components.** The primary CTA was measured with `getComputedStyle` (fill, text, radius, padding, height). Other components are observed in the screenshots. Hover, focus-visible and pressed were not forced.
- **Screenshots.** [tools/capture/public/shoot.mjs](tools/capture/public/shoot.mjs) takes viewport shots. The cookie banner was hidden with CSS and never clicked. [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.
- **Tree.** [tools/capture/public/map-site.mjs](tools/capture/public/map-site.mjs) walked the public links from the homepage and wrote the control map behind [site-tree.md](site-tree.md).

Nothing was sent, booked, or signed into.

## What to distrust

- **One painted theme.** Dark shadow tokens (`--var-shadow-ui-dark-*`) are declared and were not observed on a dark page. No dark set is emitted.
- **Derived lengths.** Spacing and radii that were `calc(.25rem * N)` are stored as px. The source string names the authored calc.
- **Role aliases.** `light.role.*` points at measured colour tokens. `accent` is the midnight button, not a blue. The blue on the hero is a gradient, not a token role.
- **Quantised screenshots.** Read colours from [tokens.json](tokens.json) or [raw/full](raw/full).
- **Auth second step.** The name and password step was not shown. See [login-review.json](login-review.json).
- **Booking form.** November 2026 had no open times and the month controls were disabled, so the form was not reached.

## Fonts

Three faces ship on the marketing pages: **Geist** (UI), **Calendly Sans** (variable, including a slight oblique), and **Wulkan Text** (display serif, 400–600). All three are proprietary and are not in this package. The guide falls back to the system stack. `--font-mono` is the platform mono and was not seen in the marketing UI.

## Do and don't

- **Do ground the page on magnolia.** The header, page and cards sit on `#fcfbf8`, not pure white. See [home-light-default](screenshots/home-light-default.png).
- **Do use midnight for the one action.** Get started and Continue are `#071a31` with magnolia text, 16px radius, 48px tall. See the header on the same shot.
- **Do set display headlines in the serif.** The hero uses Wulkan Text; UI labels stay in Geist. See the homepage headline.
- **Don't invent a blue primary button.** Cornflower `#6bb1ff` is the focus border. The hero blue is a gradient behind the type.
- **Don't invent a dark theme from the dark shadow tokens.** No captured page sets one.
- **Don't fill the auth wall.** The public step asks for an email only. See [login-light-default](screenshots/login-light-default.png).

## Rebuild

```bash
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
```

Run from `systems/calendly`. `build_tokens.py` reads [raw/css-vars.json](raw/css-vars.json). Screenshots are recaptured with `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/public/shoot.mjs`, then `python3 tools/capture/quantize.py raw/full screenshots`.
