## Typography

Review, then a system sans stack. Arial is the fallback used in the style guide.

| Style | Size | Weight | Line height |
|---|---|---|---|
| body | 14px | 400 | 16px |
| announcement | 12px | 600 | 14px |
| nav | 12px | 600 | 22px |
| hero | 50px | 500 | 50px |
| collection title | 38px | 600 | 36px |
| product title | 26px | 600 | 32px |
| card title | 16px | 600 | 20px |
| button | 17px | 600 | 17px |
| hero button | 16px | 400 | 16px |

Hero heading and the homepage SHOP NOW are uppercase. Collection and product titles are not. Collection and product titles use letter-spacing -1px. The hero button uses letter-spacing 1.28px.

## Radius

`0px` on the homepage SHOP NOW. `4px` on Add to Bag and Buy It Now. `2px` on the New Drop badge.

## Components

Filled button: background `#000000`, text `#ffffff`, radius 4px, height 50px, Review 17px weight 600.

Outline hero button: transparent, text `#ffffff`, 1px solid `#ffffff`, radius 0, height 48px.

Outline buy button: transparent, text `#000000`, 1px solid `#000000`, radius 4px, height 50px, Review 17px weight 600.

## Do and don't

Keep the announcement bar black with white type. Use pink only for the promo nav item. Fill Add to Bag. Leave Buy It Now as an outline. Keep the homepage hero button square and uppercase.
