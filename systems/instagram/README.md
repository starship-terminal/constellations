# Instagram design reference

A token set and component reference for Instagram's public surfaces, for building a signed-out social login wall and a marketing page in the Instagram blue `#0095f6`, the system UI stack, and the 22px pill controls of the real login form. It was read from **instagram.com** and **about.instagram.com** on **2026-11-19**, signed out, in headless Chromium at 1440 x 900 and 390 x 844, and checked in the T3 preview browser.

Instagram publishes its app colours as custom properties on `:root` and again under `.__ig-dark-mode`. The login wall resolves `__fb-light-mode`: white page, `#262626` text, `#0095f6` accent, `#dbdbdb` divider. The same names remap under dark (`--primary-text` becomes `#e4e6eb`, `--card-background` becomes `#242526`). Type roles are the `--system-N-font-size` scale from 10px to 32px. Radius is a set of named steps: 4px cards, 6px inputs, 8px dialogs, 12px modal, 22px on the painted login pill (measured, not a named token), 24px on `--igds-dialog-border-radius`. about.instagram.com adds the spectrum (`--about-ig-yellow` through `--about-ig-purple`) and the Instagram Sans stacks.

**Boundary.** The logged-in app was never entered. Desktop signup at `/accounts/emailsignup/` shows an email field and was photographed at rest. Nothing was typed, and Submit was never pressed. The phone viewport of the same URL asks for a mobile number first ("What's your mobile number?") with a disabled "Sign up with email" control, so the phone path stops there. A public profile (`/instagram/`) loads behind a signup dialog and was not scrolled past. No account was created, no Facebook login was followed, and no message was posted.

## Brief

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export instagram` prints them all with aliases resolved.

### Principles

1. Do use `#0095f6` for the one link colour on a light page.
2. Do paint the primary action as a 22px pill.
3. Do keep the login wall split.
4. Do set marketing headlines in Instagram Sans, and the app UI in the system stack.
5. Don't invent a dark form.
6. Don't infer the logged-in app from these pages.
7. Don't copy the Instagram glyph, the wordmark, or the spectrum gradient into anything that ships.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Declared values come from the CSSOM of the live public pages. `tools/capture/harvest-vars.mjs` opens the login wall, the same URL with `.__ig-dark-mode` forced on the root, the desktop signup form, and about.instagram.com. It hides any cookie dialog and never clicks Allow or Decline. Resolved values land in `raw/css-vars.json`. `tools/build_tokens.py` maps the semantic names onto `light` and `dark`, and the shared scales onto `core`.

Computed component values come from `tools/capture/public/measure.mjs`. The painted control is the descendant that carries the background: the login pill is a `role="none"` div inside a `role="button"`, `rgb(0, 100, 224)` at 22px radius, disabled until a field has a value (`cursor: not-allowed`). Hover is a real mouse move. Focus is `element.focus()`. Nothing was typed and nothing was submitted.

Screenshots come from `tools/capture/public/public.mjs` at 1440 x 900 and 390 x 844, then `quantize.py` writes 256-colour PNGs. The T3 preview browser was used to confirm the login wall and the signup form before the headless pass. No new headless browser was used for a login challenge.

## What to distrust

- The 4px spacing scale in `core.spacing` is a Reconstruction, entered by hand. Instagram does not publish a space scale as custom properties. The steps match the 4px radius increment and the system type sizes.
- `components.md` and `raw/components-computed.json` were not written by the committed tools, and no builder reproduces them. `components.md` is maintained by hand. `raw/components-computed.json` came from an earlier, uncommitted version of the measure script: it holds flat `button-login-default` keys with the paint node's values at the top level, while `tools/capture/public/measure.mjs` writes dotted keys (`button.login.default`) with nested `style` and `paint` objects and a different set of components. This package has no components builder; the unadapted kit copies were deleted. A recapture needs the measure script's output mapped onto the committed shape, and a components builder written for it. Until then `tools/test_components_md.py` checks that every `rgb()` and px value in a `components.md` row with a crop is in that crop's raw reading.
- Three statements in `components.md` are not in the raw readings, and were read off the crops: the Help search field's `#fafafa` fill and 16px radius (the measured input is transparent with a 0px radius, so the fill sits on an unmeasured wrapper); the username field's 1px blue focus border on its wrapper (only the input was measured, and it reads the same at rest and at focus); and the white label on the blue buttons (the measured paint node's `color` is `rgb(0, 0, 0)`, and the text node was not read). The about.instagram.com TRY IT NOW row's 90px radius is the hover reading (`link-about-cta-hover`); at rest the measured node reads 0px.
- `--ig-primary-background` is an RGB triple (`255, 255, 255`), not a colour the token builder can carry. `background.page` is `--surface-background`, which paints the same ground.
- Forcing `.__ig-dark-mode` on the login wall darkens the promo pane and the footer. The form column stays light. [login-light-promo-dark.png](screenshots/login-light-promo-dark.png) records that split. It is not a dark theme of the form.
- The login pill's computed background is `rgb(0, 100, 224)`, the Meta blue, while `--primary-button-background` and `--accent` declare `#0095f6`. The token keeps the declared accent. The crop shows the painted pill, which is also disabled (washed) until the fields have a value.
- `core.motion` durations are the named `--fds-duration-*` steps. The probe's class-hash timings stay in [raw/motion.json](raw/motion.json). The reduce verdict is `partial`: the login wall and the signup form ignore reduced motion, about.instagram.com is partial. Stylesheet lists were cut at 400 entries, so the reading is incomplete.
- Pressed colour was not fired. The login control is disabled at rest, and a press would submit.
- Screenshots are 256-colour PNGs. Read colours from `tokens.json`.
- Instagram Sans and Instagram Sans Condensed are not in the repo. The tokens name the system stack as the fallback. The style guide loads no web font: it renders in the system stack.
- The phone signup shot asks for a mobile number. That is the product's phone path, not a filled form.

## Do and don't

- **Do use `#0095f6` for the one link colour on a light page.** Forgot password and Create new account are that blue. The crop is [link-create-default.png](components/crops/link-create-default.png).
- **Do paint the primary action as a 22px pill.** The login control and the signup-gate Sign up are full-width pills. The crops are [button-login-default.png](components/crops/button-login-default.png) and [button-dialog-signup-default.png](components/crops/button-dialog-signup-default.png).
- **Do keep the login wall split.** A promo pane on the left, a form column on the right, a quiet footer of text links. [login-light-default.png](screenshots/login-light-default.png).
- **Do set marketing headlines in Instagram Sans, and the app UI in the system stack.** about.instagram.com uses `--about-ig-font-family`. The login wall uses `--font-family-system`. [about-light-default.png](screenshots/about-light-default.png) and [login-light-default.png](screenshots/login-light-default.png).
- **Don't invent a dark form.** Forcing `.__ig-dark-mode` darkens the promo pane and leaves the form light. [login-light-promo-dark.png](screenshots/login-light-promo-dark.png).
- **Don't infer the logged-in app from these pages.** The feed, stories, reels and DMs sit behind sign-in. `/instagram/` stops at the signup dialog. [instagram-light-default.png](screenshots/instagram-light-default.png).
- **Don't copy the Instagram glyph, the wordmark, or the spectrum gradient into anything that ships.** [logo-mark.png](components/crops/logo-mark.png) and [about-light-default.png](screenshots/about-light-default.png).
