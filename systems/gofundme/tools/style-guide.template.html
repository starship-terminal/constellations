GoFundMe, declared and measured

Every value on this page is a CSS custom property generated from tokens.json: the site's declared token layer is the hrt design system — ~700 --hrt-* semantic custom properties on :root / [data-theme="consumer"] (the brand greens #4A9D44 / #274A34 / #CCF88E, neutral ramps, blue/pink/purple/yellow accents, the size, spacing, radius, type and motion scales). The consumer site paints exactly one theme; the declared [data-theme="pro"] layer never paints here. The real pixels are in screenshots/ and components/crops/.

Read from gofundme.com, signed out, in headless Chromium. The signed-in dashboard and donation checkout are documented boundaries; "Donate now", "Continue" and every CTA was measured, never pressed. The /c/* marketing pages are the WordPress content stack (an older hrt-base-*/wp-* layer); /sign-in is the auth boundary — its Welcome card measured signed-out, never submitted.

Palette

The declared --hrt-color-* roles are the palette: surface/text/border/icon/button/data/texture families with -hover, -pressed, -subtle, -strong, -on-strong state suffixes — brand greens, the neutral ramp, and the blue/pink/purple/yellow/informative/negative/positive accents. Measured roles alias the declared values they match.

Spacing, radius and motion

The --hrt-spacing-*, --hrt-radius-*, --hrt-motion-*/--hrt-time-*/--hrt-ease-* and --hrt-size-* scales are declared; the measured.* entries anchor them to real controls.
