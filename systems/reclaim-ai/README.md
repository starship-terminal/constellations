# Reclaim AI design reference

A token set and page reference for Reclaim's public site. Read from reclaim.ai on 2026-11-21, signed out, in headless Chromium at 1440 x 900 and 390 x 844. The marketing site is Webflow. The signed-in calendar was not reached: Log In and Get Started stop at provider buttons, and those were not clicked.

The public site paints one light theme. The stylesheet also declares dark colour names (`--_apps---colors--*-dark`). Those are recorded and not treated as a painted theme.

## How the values were read

Custom properties came from the live homepage stylesheets, re-parsed in a probe (`tools/capture/vars.mjs`). The painted button, body, and headings came from `getComputedStyle` on the live homepage at 1440 (`raw/computed-home.json`). Screenshots came from Playwright (`tools/capture/public/public.mjs`). The Osano cookie dialog was hidden and never clicked.

The desktop Get Started button paints `#0061fe`. The declared primary is `var(--royal-blue)`, which resolves to `#5562eb`. Both are in the token file. `light.accent` is the painted button.

## What to distrust

- Dark names in `core.declaredDark` are declared, not painted.
- `light.muted` and `light.border` are the declared variables, not a sampled muted label. Book a Demo's outline paints `#000000`.
- Screenshots are 256-colour. Read colours from tokens.
- The calendar and chat on the homepage are public demos.
- `icon.png` is an upscale of a 32px glyph.
- No component crops. Hover and focus were not measured on product controls.
- FAQ open state was not captured. `home-light-faq.png` was a mislabeled Resources menu and was removed.
- Full-page stitches (`*-full.png`) are taller than the viewport. `home-light-full` is 1520 px wide and `features-light-full` is 1560 px wide. Read viewport shots for width.
- The style guide template still carries kit chrome (a dark mode flag, a Claude phone mock). The token CSS variables are generated from `tokens.json`.

## Fonts

Body is Poppins. The nav CTA is Atlas Grotesk Web. Headlines are Sharp Grotesk DB Book 23 and Book 20. Those faces are the product's. The tokens name them. The style guide falls back to Poppins and the system stack.

## Do and don't

1. **Do use the painted blue for the one action.** Get Started is `#0061fe`, not the declared blurple. See [home-light-default](screenshots/home-light-default.png).
2. **Do keep the page white and the type near-black.** Body text is `#181d25` on `#ffffff`.
3. **Do outline the secondary action.** Book a Demo is a white button with a black hairline.
4. **Don't invent a dark marketing theme.** The `*-dark` variables are declared and unused on these pages.
5. **Don't style the calendar app from this package.** The app is behind the login wall.
6. **Don't treat the homepage calendar as the product.** It is a public demo.
