# Nike design reference

A token set and component reference for Nike's public signed-out storefront. Refreshed on 2026-11-21 from www.nike.com, signed out. nike.com redirects to www.nike.com/sg/. That Singapore English storefront is what this package captures.

Surfaces: home, the Men and Women menus, search, the location dialog, Men's Shoes, the Air Force 1 '07 LX product page, Help, Find a Nike Store, Membership, and the public sustainability page. Desktop 1440 x 900 and phone 390 x 844. One light theme. Sign In stops at accounts.nike.com. Nothing was submitted.

Nike paints the storefront with PDS (`--pds-*`) and Podium CDS (`--podium-cds-*`). The page is white (`#ffffff`). Text is `#111111`. The buy button is a black pill. Type is Helvetica Now. Product photos are square. Orange (`#ff5000`) is a brand token. On these pages it is not the button fill. Just In uses badge orange `#d33918`.

## Do and don't

1. **Do keep the page white and the swoosh black.** The header sits on `#ffffff`. The swoosh uses `currentColor` (`#111111`). See [home-light-default](screenshots/home-light-default.png) and [logo-default](components/crops/logo-default.png).
2. **Do use a black pill for the buy action.** Add to Bag is `#111111`, white label, 60px tall, 30px radius (`light.accent` on `light.on-accent`). See [button-add-default](components/crops/button-add-default.png).
3. **Do put white pills on photography.** Shop and Explore are `#ffffff` on the hero, 36px, same 30px radius. See [home-light-default](screenshots/home-light-default.png).
4. **Do set body type at 16px in Helvetica Now Text.** Secondary text is `#707072` (`light.muted`). See [plp-light-default](screenshots/plp-light-default.png).
5. **Don't invent a dark theme.** The storefront computed `color-scheme: normal`. No theme toggle was found.
6. **Don't press Add to Bag, Sign In, or Let's go.** Those controls were measured or seen and never used to buy or join. Checkout and the member account sit behind sign-in. See [pdp-light-default](screenshots/pdp-light-default.png).
7. **Don't treat Nike orange as the button fill.** `--pds-color-element-brand-orange` is `#ff5000`. The measured buy button is black. Just In is `#d33918`. See [plp-light-default](screenshots/plp-light-default.png).

## How the values were read

Custom properties were read from computed style on `documentElement` at `https://www.nike.com/sg/` in the T3 preview browser, then confirmed on the same URL in headless Chromium. Colour, radius, space, duration, and easing tokens are those computed `--pds-*` and `--podium-cds-*` values. Component colours and sizes were read from computed style on the live DOM: header, Shop pill, search, Add to Bag (including hover), Favourite, size chips, and the product title and price. Screenshots are viewport captures. Desktop shots are 1440 x 900 at 1x. The phone shot is 390 x 844 CSS pixels at devicePixelRatio 2, so the PNG is 780 x 1688.

The 2026-11-19 readings still hold the tokens. The 2026-11-21 refresh replaced the screenshots with live viewport captures. The T3 preview tab loaded the homepage, then `preview_snapshot` failed with "The browser is not producing screenshot frames." Headless Chromium loaded the public pages without a Cloudflare challenge. Those PNGs were quantised to 256 colours. Read colours from [raw/css-vars.json](raw/css-vars.json), not from the PNGs.

`/sg/register` redirected to accounts.nike.com and returned Access Denied. The query string carries signing parameters and is not stored. See [login-review.json](login-review.json) and [site-tree.md](site-tree.md).

## What to distrust

The Shop pill's hover was not measured. A synthetic mouseover on an off-screen carousel copy did not change the fill, and the visible copy sat in a scrolling hero that Playwright would not hover. Add to Bag hover is the measured one (`#707072`).

The help search looks outlined. Computed `border-top-width` on the input and its wrappers was `0px`. That border is not in the tokens.

Size text nodes report transparent backgrounds. The 1px `#cacacb` border and the disabled `#f5f5f5` fill are on the chip wrapper (`nds-grid-item`). Selecting a size did not change the text node's computed background.

Helvetica Now, Helvetica Now Display, and Nike Futura ND are proprietary and are not in the package. The style guide falls back to Helvetica. Currency on this locale is S$.

`prefers-reduced-motion: reduce` rules exist in the stylesheets (nine media rules, including `animation-duration: 0s` on a universal selector). The reduce emulation was not run, so the page verdict is not recorded.

## Fonts

Helvetica Now Text is the UI face. Helvetica Now Text Medium is the button and price face. Helvetica Now Display Medium is the product title. Nike Futura ND is the brand display token (`--pds-typography-brand-display-5`). All are proprietary. The tokens name them, then Helvetica, Arial, sans-serif. They are not committed. The swoosh is the header SVG in [icons/swoosh.svg](icons/swoosh.svg), not a text face.
