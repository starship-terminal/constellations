# T3 Code

A design reference for T3 Code, the hosted coding-agent app, version 0.1.8. Captured on 22 Nov 2026 from the owner's tailnet deployment at `kai-home-server`, paired in the preview browser. The app was in dark, then switched to light and restored to dark. Desktop width was 1440 by 900 CSS pixels, device pixel ratio 2. Phone width was not captured.

The product is a black or near-white workspace: a 256 px thread sidebar, a quiet top bar, a centred composer, and a floating details card. Settings is a dialog with a vertical section list, not a separate site. Colour roles are CSS custom properties on `html`. Neutrals in dark are white at a fixed alpha over black. The accent is indigo.

This package contains no T3 Code source. The screenshots show the owner's threads. Borrow structure and proportions, not the brand.

### Principles

1. Do keep the page black and raise only the composer, menus, and the details card.
2. Do build dark neutrals from white at a fixed alpha.
3. Do give the composer the only large radius.
4. Do keep the accent for the one action that commits.
5. Don't open settings as a page.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Custom properties were read with `getComputedStyle(document.documentElement)` in dark, then again after removing the `dark` class for light. Component boxes were read with `getBoundingClientRect` on the sidebar, the new-thread heading, the composer, and icon buttons. The stylesheet `assets/main-DVSpUGJE.css` is in `raw/main.css`. Screenshots were taken from the live DOM because the preview window stopped painting frames. They are 1440 by 900, not the 2x window capture the kit prefers. The Mac app is a separate package, [t3code-desktop](../t3code-desktop/README.md).

## What to distrust

Hex values marked Derived are browser resolutions of `oklch()` and `color-mix()` tokens. The source token is named in each `$extensions.source.from`. Status colours in light were not re-sampled from a painted control. Focus-visible, pressed, and disabled rings were not held. The slash-command hover shot did not change the menu. Phone width (390) was not captured. Screenshots include the owner's thread titles. General dropdowns were not opened. The connected Environments list and the local-versus-remote project palette are in the desktop package.

## Fonts

`--font-sans` is `-apple-system`, then `Inter Variable`. Inter Variable is declared in the stylesheet and was not loaded in the capture browser, so the painted text is the system sans. `--font-mono` is `ui-monospace`, then SF Mono and Menlo. Do not ship Inter as if it were measured on screen.

## Do and don't

- **Do keep the page black and raise only the composer, menus, and the details card.** The main column paints `--background: #000`. [screenshots/draft-new-thread-dark.png](screenshots/draft-new-thread-dark.png)
- **Do build dark neutrals from white at a fixed alpha.** Borders are white at 8%, hovers at 4%, inputs at 11%. [tokens.json](tokens.json)
- **Do give the composer the only large radius.** The shell is square. The composer and settings dialog use the larger radius steps. [screenshots/thread-conversation-dark.png](screenshots/thread-conversation-dark.png)
- **Do keep the accent for the one action that commits.** Model and send sit in the composer. Sidebar actions are icon buttons. [screenshots/draft-new-thread-dark.png](screenshots/draft-new-thread-dark.png)
- **Don't open settings as a page.** It is a dialog over the thread, with its own vertical list. [screenshots/settings-general-dark.png](screenshots/settings-general-dark.png)
