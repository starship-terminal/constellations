# Capture notes

The hosted app was paired with `t3 pair --tailscale --tailscale-serve-port 8109` on the home server. Screenshots were exported from the live DOM with modern-screenshot because the preview window stopped producing frames. Theme was switched in Appearance and restored to Dark.

The four `macos-*.png` files are window captures of T3 Code (Nightly) on the owner's Mac, taken with Cua Driver after the hosted Environments page turned out empty. The window was driven in the background. Add Environment was opened and both tabs were shot. No environment was paired, and no switch was changed. The dialog and Settings were closed afterwards.

No builder. Tokens were written from `raw/computed-roles.json` and `getComputedStyle` readings.
