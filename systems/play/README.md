# Play

Play is a native iOS and macOS design tool (createwithplay.com). This package captures the public marketing site as it was archived, signed out. The live host did not resolve on 19 November 2026.

Surfaces: homepage, pricing, and download from January 2026 Internet Archive replays, plus the April 2026 shutdown notice. Themes: dark only. Widths: 1440 and 390 CSS pixels. No account was used.

1. Use the green only for the primary action.
2. Keep the page black.
3. Set headlines in TWK Everett Medium, large, with tight tracking.

## How the values were read

`preview_open` on `https://www.createwithplay.com/` returned `ERR_NAME_NOT_RESOLVED`. DNS for createwithplay.com had no A record on 19 November 2026. A Wayback tab opened in the T3 preview browser, and `preview_snapshot` returned "The browser is not producing screenshot frames."

The measurements come from headless Chrome (Playwright, channel `chrome`) on public Internet Archive replays. Those pages are marketing HTML, not a login page and not a Cloudflare challenge. Computed styles were read with `getComputedStyle` at 1440 by 900 and 390 by 844. Screenshots are 256-colour PNGs. The PNG pixel size is 2 times the CSS viewport. `window.devicePixelRatio` in the page reported 1, so the package labels width from the PNG and the requested viewport, not from that JS value.

Framer `--token-*` colours were read from the homepage stylesheet. Stitches `--colors-*` names were read from the archived dashboard HTML shell. The login form that shell belongs to did not paint, so those names stay in [raw/dashboard-stitches.json](raw/dashboard-stitches.json) and are not semantic tokens.

## What to distrust

The computed styles and stylesheet declarations above were typed into tokens.json by hand and not saved: raw/ holds the capture notes and the unused Stitches names, not the readings. Every token is therefore labelled Reconstruction, entered by hand at capture time. A recapture of a replay should save the readings to raw/.

The pages are archive replays, not a live server. Wayback's toolbar was hidden before the screenshots. Some images in the hero are broken archive assets, so the lower half of the home screenshot is mostly black.

The green nav button did not change under hover, and focus left `outline: none`. That is what the computed style returned. It is not a designed focus ring.

`{border.default}` repeats the chip fill `#ffffff12` so the catalog border swatch resolves. The primary button's computed border width was 0.

TWK Everett Medium, Inter Tight, and Inter Display are commercial faces. The tokens name them. The style guide falls back to Inter.

## Do and don't

- **Use the green only for the primary action.** The nav "Get Started for Free" button is `#17ffa6` on black, with near-black label text. [button-primary-default.png](components/crops/button-primary-default.png)
- **Keep the page black.** The marketing site paints `rgb(0, 0, 0)` and sets `theme-color` to `#000000`. [home-dark-default.png](screenshots/home-dark-default.png)
- **Set headlines in TWK Everett Medium, large, with tight tracking.** The January hero is 64px, line-height 70.4px. A second node of the same string used -4px tracking. [home-dark-default.png](screenshots/home-dark-default.png)
- **Do not invent a login form.** The signed-out dashboard frame did not paint, and the April 2026 notice says new accounts are closed. [shutdown-dark-default.png](screenshots/shutdown-dark-default.png)
- **Do not treat archive hero images as the product UI.** Broken archive assets leave empty regions. Read colour from the tokens. [home-dark-default.png](screenshots/home-dark-default.png)
