Gladia, measured

Every value on this page is a CSS custom property generated from tokens.json: the declared --color-neutral-0..1000 ramp and --color-<hue>-* purple/blue/green/red/yellow/orange/pink ramps (with the --color-purple #947afc brand hue), the --alpha-white/black-* translucents that build the glass surfaces, the --space-* 4px spacing scale, --radius-* (8/16px and the full pill), --shadow-*, the --font-size-10..80 type ramp in 'Suisse Intl' with 'Geist Mono' for code, --font-weight-*/--line-height-*/--letter-spacing-*, the --duration-* ramp and --ease-* curves, and the semantic --text-*/--bg-*/--border-* roles every component consumes. The real pixels are in screenshots/ and components/crops/.

Read from gladia.io, signed out, in headless Chromium. The signed-in app is a documented boundary — only app.gladia.io / and /signup paint without credentials. The demo-request, calculator and auth fields were typed into and cleared, never submitted; every CTA, SSO and submit control was measured, never followed. The marketing site paints dark by default — the dark token set is that painted surface — and body.light-mode (the /library page) re-points the roles to the light set. 'Suisse Intl' and 'Geist Mono' are served faces and are not loaded here: samples fall back to system fonts.

Palette

color.* is the declared ramp — the neutral gray scale and the hue ramps whose --color-purple default #947afc is the brand. color.alpha.* holds the white/black translucents that paint the glass nav and cards; color.label.*/color.badge.* are the chip colours. The semantic roles under dark.* are the painted :root surface (black bg, white text); light.* resolves the same declarations inside body.light-mode, the scope /library paints.

Spacing, radius, layout and motion

The space scale is a 4px system (--space-1 to --space-48) plus the page/section/card-gap aliases. Radii run 0-24px with a full pill step. Content width caps at --max-w-container; the navbar geometry (--nb-*, --nav-bar-*), hero sizing (--hero-*) and the closing-CTA block (--cta-*) travel as layout tokens. Durations run --duration-0..480ms; easings include a spring curve.

Type

Two served faces: 'Suisse Intl' carries every heading, control and body (--font-sans, weights book/regular/medium/semibold); 'Geist Mono' draws code (--font-mono). The --font-size-* ramp runs 10-80px with six line-height steps and em-tracking. Sizes are the declared steps; samples fall back to system sans.
