# The Ordinary

A signed-out capture of the public The Ordinary shop at [https://theordinary.com/en-sg](https://theordinary.com/en-sg), Singapore storefront, prices in USD, on 2026-11-22. Desktop 1440 by 900. The page is `#ffffff`, type is Raleway on the shop and Geologica on the account walls, and the product title is `#333333`. Add To Cart is a 48px square outline.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

## Colour

| Role | Value | Where |
|---|---|---|
| Page | `#ffffff` | document background |
| Ink | `#000000` | department links, promo bar |
| Text | `#212529` | body, price |
| Product | `#333333` | product title, Add To Cart type, selected size fill |
| On ink | `#ffffff` | promo type, selected chip, Join Now |
| Muted | `#757575` | Sign In label, brand-tab wash |
| Field | `#000000` | signup underline, Add To Cart border |
| Chip border | `#e1ded9` | 30ml chip |
| Facebook | `#1877f2` | Continue With Facebook, not clicked |

## Type

Raleway on the body, 16px, weight 400. Department links are Raleway 16px at weight 600. Hero is 36px at weight 700. Product title is 28px at weight 700. Account fields and Sign In / Join Now use Geologica. Font files are not in this package.

## Controls

Add To Cart, Sign In, and Join Now are 48px with a `0` radius. Explore New In is 42px with a `20px` radius. Build My Regimen is a 37px pill (`110px` radius). Size chips are 33px pills. Fields are 40px with a 1px black underline.
