Telegram style guide

Telegram for iOS 26, read from stills captured through iPhone Mirroring on 2026-10-23 (dark) and 2026-10-24 (light). Every value below comes from tokens.json; points are 1:1 with CSS pixels. The font is not known, so the page uses the platform sans. Glass is drawn as its centre colour: the real material blurs what is behind it. The thread's wallpaper is a stand-in gradient.
