# Telegram public site tree

Mapped on 2026-11-22 from the public homepage, https://telegram.org/. Title: "Telegram Messenger". Incognito preview tab, then headless Chromium for the photographs. Desktop shots are 1440 by 900 CSS pixels at 2x (PNG width 2880). Phone shots are 390 by 844 CSS pixels at 2x (PNG width 780). The homepage is a live marketing page, not a parked domain and not a captcha wall.

Nothing was typed. No email, password, code, or phone number was entered. No form was submitted. No identity provider was clicked. No captcha was solved. No chat was opened and no channel was joined. `login-extracted` stays not-started. catalog.json was left alone.

The only web login wall the public controls open is Telegram Web. It asks to scan a QR code, or to log in by phone number or passkey. The QR slot in the saved shots is painted over. Phone number and passkey were not clicked.
