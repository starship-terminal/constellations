# Components

Measured on the styled archive pages at 1440 by 900 CSS pixels. Graphik is the face. Files are not in this package.

## Wordmark

The header lockup is an inline SVG, 88 by 42, fill `#1f1a5e`. The rendered link box is 96 by 46. [icons/mark.svg](icons/mark.svg). [screenshots/home-light-1440.png](screenshots/home-light-1440.png)

## Nav link

Graphik 14px, weight 500, color `#181831`, line-height 19.6px. Black Friday Sale uses `#ca2b16`. [screenshots/category-light-1440.png](screenshots/category-light-1440.png)

## Primary button

"Learn about our mattresses" is a button, 46px tall, padding `12px 28px`, radius `48px`, fill `#181831`, type white, 16px, weight 500. It opens a modal on the category page and was not used to add a product. [screenshots/category-light-1440.png](screenshots/category-light-1440.png)

Shop sale on the promo bar is the same pill at 30px, padding `6px 16px`, white fill, ink type, 12px, weight 500.

## Badge

On sale is 12px, weight 500, white on `#ca2b16`, padding `6px 10px`, radius `4px`. [screenshots/category-light-1440.png](screenshots/category-light-1440.png)

## Filter chip

Hide Filters is 44px, padding `10px 24px`, radius `48px`, 1px ink border. [screenshots/category-light-1440.png](screenshots/category-light-1440.png)

## Email field

The footer field wrap is 56px, radius `16px`, 1px ink border. The input is 14px with padding `18px 16px 20px`. It was not filled and not submitted.

## Gaps

Hover, focus, pressed, disabled, and error states were not captured. The account wall, cart, and quiz modal were not opened. Phone width was not captured. Dark theme is not present.
