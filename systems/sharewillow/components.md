# Components

Measured on www.sharewillow.com and app.sharewillow.com/login on 2026-11-19. No crops: the preview browser did not produce screenshot frames.

## Button

The hero Book a demo is 56px, padding 0 28px, 16px, label `#f5f2e0`, shadow `0 12px 28px -14px rgba(24,6,0,0.55)`. A lemon Book a demo is 48px, face `#faf082`, ink `#180600`. The hidden sheet Sign in is a white pill with a 1px border at espresso 16%.

Login submit is 44px, radius 8px, face `#1a1a1a`, label white, 14px medium. Signup Create account is a 46px espresso pill with label `rgb(250, 248, 243)`. It was not pressed.

## Link

Nav links are 14px, padding 6px 14px, espresso at 65% opacity, pill radius. Hover rule is espresso at 5%. Login links (Forgot your password, Sign Up) are 14px `rgb(87, 100, 244)`.

## Text field

Login email and password are 40px, padding 8px 12px, radius 8px, 1px border `rgb(222, 222, 222)`, white face, text `rgb(79, 79, 79)`. Focus shadow is `0 0 0 2px #fff, 0 0 0 4px #1a1a1a`. Signup email is 48px, radius 10px, 1px espresso border, placeholder `you@company.com`. Nothing was typed.

## Checkbox

Login Remember me is a 16px checkbox, radius 4px. It was already checked: face and border `rgb(26, 26, 26)`, `aria-checked=true`. A click did not clear it. The unchecked fill is a gap.
