## What this tree does not include

The signed-in app (dashboard, plans, payouts, people, settings, billing) is behind [https://app.sharewillow.com/login](https://app.sharewillow.com/login). Public docs describe those screens. The docs are not the app. No dark-theme toggle was found on the marketing site (`color-scheme: normal`, no `data-theme`). The hero uses a dark panel (`--color-hero-*`) inside the light page. That is a section, not a second theme.
