# Sharewillow design reference

A token set and component reference for Sharewillow's public marketing site. Captured from [https://www.sharewillow.com/](https://www.sharewillow.com/) on 2026-11-21, signed out, in headless Chromium at 1440×900 and 390×844. The site loaded. The signed-in app at [https://app.sharewillow.com/login](https://app.sharewillow.com/login) was recorded as a wall and not entered.

Sharewillow paints ivory (`#f7f5f1`) with espresso ink (`#180600`) and one lemon accent (`#faf082`). Display type is Mackinac. UI type is Matter. Primary actions are full pills. A dark hero panel uses a separate `--color-hero-*` set inside the light page. There is no theme toggle.

### Principles

1. Do set type in espresso on ivory.
2. Do spend lemon on one accent.
3. Do make the primary action a pill.
4. Do set the headline in Mackinac and the UI in Matter.
5. Don't style the signed-in app from this package.
6. Don't invent a dark theme.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Custom properties were read from the live homepage stylesheets (`tools/capture/vars.mjs`) on 2026-11-21. Brand colours, font stacks, radii, spacing, leading, tracking and easings are declared on `:root` as `--color-*`, `--font-*`, `--radius-*`, `--spacing`, `--ease-*`. Component sizes and the button hover fill were read from computed styles (`tools/capture/public/measure.mjs`). Screenshots are 256-colour PNGs. Read colours from tokens.json, not from the images.

Viewport check: desktop captures recorded `innerWidth` 1440, `innerHeight` 900, `devicePixelRatio` 1. Phone captures recorded `innerWidth` 390, `innerHeight` 844, `devicePixelRatio` 2. Sidecars stayed in the scratch folder, not in the package.

## What to distrust

- Status colours (`lime`, `peach`, `rose`, `sky`) are declared palette tokens. Only lime appears in the marketing demo charts. Warning, danger and info roles were not confirmed on a component.
- Display size 80px is the rendered homepage headline, not a named CSS token.
- Button radius is a pill. The browser reported a huge computed pixel value, so the token is `9999px`.
- Focus ring colour is Not captured. Keyboard focus did not change the primary button's computed outline in this pass.
- The login wall uses a near-black (`#1a1a1a`) that is not `--color-ink`. It is a different surface. Do not treat it as the marketing espresso.
- Hero mock copy ("Jordan Walsh", dollar amounts) is marketing demo content, not a signed-in account.
- Screenshots are quantised. Gradients in the homepage wash will band.

## Fonts

Matter (weights 300, 400, 500, 600, 700 declared) and Mackinac (400, 500, 700 loaded) ship as woff2 from the site. Both are proprietary and are not in this package. Tokens fall back to `ui-sans-serif` and `ui-serif`. Mono is the system stack from `--font-mono`.

## Do and don't

- **Do set type in espresso on ivory.** The page ground is `#f7f5f1` and the ink is `#180600`. [screenshots/home-light-default.png](screenshots/home-light-default.png).
- **Do spend lemon on one accent.** The announcement wash, the "Coming soon" badge, and the headline underline use `#faf082`. [screenshots/home-light-default.png](screenshots/home-light-default.png).
- **Do make the primary action a pill.** "Book a demo" is a full pill, espresso fill, cream label. [components/crops/button-primary-default.png](components/crops/button-primary-default.png).
- **Do set the headline in Mackinac and the UI in Matter.** [screenshots/pricing-light-default.png](screenshots/pricing-light-default.png).
- **Don't style the signed-in app from this package.** The app is behind [https://app.sharewillow.com/login](https://app.sharewillow.com/login). [screenshots/login-light-wall.png](screenshots/login-light-wall.png).
- **Don't invent a dark theme.** The dark phone mock and the hero panel are sections. The page itself is light.
