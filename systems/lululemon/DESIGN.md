# Lululemon

A signed-out capture of the public Lululemon shop at [https://shop.lululemon.com](https://shop.lululemon.com), region US (USD), on 2026-11-22. Desktop 1440 by 900. The page is `#fafafa`, type is Saans on the UI and Calibre on the body, and the wordmark is `#140f0f`. Primary actions are 44px pills.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

## Colour

| Role | Value | Where |
|---|---|---|
| Page | `#fafafa` | document background |
| Surface | `#ffffff` | footer, login card |
| Ink | `#140f0f` | nav, titles, Add to bag fill |
| Text | `#000000` | body |
| On ink | `#ffffff` | Add to bag and Continue text, hero |
| Quiet | `#f4f3f2` | Shop button, Use a passkey |
| Nav shell | `#efeeec` at 80% | header pill |
| Muted | `#757575` | struck price, email border |

## Type

Calibre on the body, 16px, weight 400. Saans on nav, headings, and buttons. Nav 14px at weight 500. Product title 28px at weight 400. Login heading 40px. Hero 72px. Font files are not in this package.

## Controls

Buttons use a `1000px` radius and are 44px tall. The email field is 44px with a `4.8px` radius and a `#757575` border. Header icon targets are 32px. The nav pill is 48px.
