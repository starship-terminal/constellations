# ThirdLove

Handwritten because `make design-md` needs a catalog entry, and this capture left `catalog.json` alone.

## Colors

| Role | Value | Source |
|---|---|---|
| page | `#ffffff` | Body and footer background |
| ink | `#2c272d` | Body, titles, sale price, Sign In fill |
| ink-soft | `#25261e` | Sign In heading |
| on-ink | `#ffffff` | Promo type, hero type, nav over the hero |
| promo | `#85002c` | Promo bar |
| gold | `#f1dd99` | Join Now |
| black | `#000000` | Select Size |
| muted | `#999999` | Compare price |
| chip | `#4b4b4b` | Size chip type |
| field-border | `#cccccc` | Sign-in field border |

## Typography

Rules is the UI face: nav 14px, body 16px, product title 16px weight 500, Select Size 16px weight 500. The hero line is Rules 95px weight 400. Sale price is Helvetica Neue 28px. Founders Grotesk Text sits on the promo bar. Files are not in this package.

## Geometry

Promo bar 40px. Header 100px, transparent over the hero. Wordmark 297 by 55px. Find My Fit 52px, radius `100px`. Shop Sale 39px, radius `25px`. Select Size 48px, radius `100px`. Size chips 40 by 53px, radius `2px`. Footer email 50px, radius `0`. Sign-in fields 40px, radius `44px`. Sign In button 51px.

## Do and don't

Keep the page white and the type ink. Use burgundy only on the promo bar. Use a black pill for Select Size and gold for Join Now. Stop at the empty sign-in wall. Google was not clicked. Select Size was not clicked. Add to Bag was not clicked.
