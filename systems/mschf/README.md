## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export mschf` prints them all with aliases resolved.

### Principles

1. Set the page black and the type grey.
2. Set titles in one uppercase mono size.
3. Turn a title white on hover, and clear the gold on the logo.
4. Keep corners square.
5. Use the gold rule for released work.
6. Do not invent a light theme, a card, or a form.
7. Do not restyle store.mschf.com with these tokens.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The page was opened in the T3 preview browser and in headless Chromium. Cloudflare did not challenge either. Computed styles were read on `body`, `header a`, `header button`, `.row`, `.row .left`, `section.projects-previous`, `.links` and `.row.project-tbd` at 1440x900, and again at 390x844. Stylesheet rules were read from the CSSOM (the Nuxt sheets `index.*.css` and `default.*.css`, plus the inlined component styles). Hover, focus-visible and active were forced with `CSS.forcePseudoState` and checked against a real hover and a real focus. Motion was read by `tools/capture/motion-probe.mjs` on `/` and on `/missing-page`.

Nothing was typed, submitted, or purchased. The logo button was clicked. It does not open a surface.

## What to distrust

The vw sizes are stored as the px computed at 1440. At another width they change. The phone row is a separate token (`typography.rowPhone`) from the 390 reading.

`light` is the name of the only semantic set. The page is black. There is no second theme to toggle.

The 3px rule computed as 2.5px (`0.208333vw` at 1440) and painted as 3px in the 1x screenshot. The token uses 3px.

`section.projects-upcoming-and-links` uses a red-to-black `border-image`. Its computed `border-left-color` is the Tailwind preflight `rgb(229, 231, 235)`, which is not what you see.

The marquee duration (50s, `steps(50)`) is one running row, not a system scale.

Screenshots are 256-colour PNGs. Read colour from the tokens.

MSCHFSansMono is not in this package. Specimens fall back to ui-monospace.

The 128px icon is a nearest-neighbour scale of the 32px favicon. There is no larger icon on the host.

## Fonts

One face: MSCHFSansMono, weight 400, normal, from `/_nuxt/MSCHFSansMono.DOBS5JtI.otf`. The stack is `MSCHFSansMono, monospace, Arial, Helvetica, sans-serif`. The file is proprietary and is not committed. Tokens name the stack and fall back to monospace.

## Do and don't

- **Set the page black and the type grey.** The ground is `#000000` and the ink is `#84898e`. See [home-dark-default.png](screenshots/home-dark-default.png).
- **Set titles in one uppercase mono size.** At 1440 that size is 65px on a 56px line. See [list-row-default.png](components/crops/list-row-default.png).
- **Turn a title white on hover, and clear the gold on the logo.** See [home-dark-link-hover.png](screenshots/home-dark-link-hover.png) and [home-dark-logo-hover.png](screenshots/home-dark-logo-hover.png).
- **Keep corners square.** Every painted radius is 0.
- **Use the gold rule for released work.** The rule is `rgba(168, 145, 65, 0.3)`. The three link rows at the bottom are gold, blue, and red, one each. See [home-dark-upcoming.png](screenshots/home-dark-upcoming.png).
- **Do not invent a light theme, a card, or a form.** The page does not have them.
- **Do not restyle store.mschf.com with these tokens.** That shop is a separate Shopify theme.
