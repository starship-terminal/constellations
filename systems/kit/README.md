# Kit design reference

A token set and component reference for Kit's signed-out public surfaces, for building marketing and log-in pages in the style of the real thing. It was read from **kit.com** (the email-first operating system for creators, formerly ConvertKit) and the signed-out card at **app.kit.com/users/login** on 2026-11-18, in headless Chromium at 1440 x 900 and 390 x 844. Captured: home, pricing, features, email marketing, request a demo (page only), the Mailchimp comparison, brand, about, privacy (view only), and the log-in card, plus 390px passes on home, pricing, features and log-in.

Kit ships one light marketing system on Tailwind CSS v4. Soft-black `#1e1e1e` bands carry the nav, the home hero and the footer. Warm white `#f2efe9` is the on-ink type and a page field on interior pages. Action blue `#44b1ff` paints the announcement strip and the Start free trial pill, with soft-black type on that blue. Display type is KitSansFont (80px on the home hero, 64px on interior mastheads, 48px on the phone). UI and body are Libre Franklin. The log-in card is a separate Inter surface on warm white `#f9f7f4` and does not share the marketing token layer.

The product app behind log-in was never reached. Signup stopped at a Cloudflare check. The request-a-demo form was not submitted. `/migrations` stopped at a Cloudflare check.

### Principles

1. Do spend blue on the trial and the announcement.
2. Do put the hero on soft-black.
3. Do keep the two faces apart.
4. Do use 8px corners on marketing controls.
5. Don't style the signed-in product from this package.
6. Don't invent a dark theme.
7. Don't follow a trial link and call it captured.
8. Don't copy the wordmark or the photography.

## How the values were read

Every colour, radius, length and font on this package is one of three kinds, and `$extensions.source` on each token says which:

- **Declared.** `css-var --name (light)`: a custom property in kit.com's stylesheets, harvested by `tools/capture/vars.mjs` from the live home page's network sheets plus inline style blocks, re-parsed with CSSStyleSheet, and resolved on a probe document at 1440 x 900. The site declares no theme scope, so the light and dark passes resolve the same values. The dark token set is left empty on purpose.
- **Measured.** `computed …` or `measured …`: a computed style or bounding box read from the live DOM by `tools/capture/public/measure.mjs`, with a matching crop in `components/crops/`.
- **Derived.** The spacing steps `s1` through `s9` are multiples of the declared `--spacing` of 4px. They were not read as separate custom properties.

Consent overlays were hidden in CSS and never answered. Nothing was signed into, submitted, purchased, or followed through an OAuth flow. The log-in fields were typed into with a placeholder address and then cleared. Log in was never clicked.

## What to distrust

- **The declared soft-black channel and the painted ink disagree.** `--color-soft-black-rgb` is declared as `24, 24, 24`. The resolved `--color-soft-black` and the painted hero, nav type and log-in submit are `rgb(30, 30, 30)` (`#1e1e1e`). Use the resolved colour, not the RGB channel variable.
- **The log-in card is a different surface.** It uses Inter, a 10px field radius, a 12px submit radius, and a warm-white page. Do not mix those literals with the marketing roles. There is no `component.login.*` group in the token file because the card has no shared variable layer. The measured values live in [components.md](components.md).
- **The login-panel selector missed.** The card was not a single measurable panel node, so that component records missing. The fields, submit, and the page screenshot are the evidence.
- **The remember-me checkbox measured 1px tall.** The input itself is visually hidden. The labelled row is what the screenshot shows.
- **Presses are forced.** `pressed` states were read with `CSS.forcePseudoState`. A script-driven mousedown look is uncaptured.
- **Pricing plan fills are not the trial blue.** The Free and Creator buttons paint an 8% soft-black wash (`oklab` alpha). Only the Pro plan and the nav trial pill paint `#44b1ff`.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs. Read exact colours from the tokens or `raw/`, not from the pixels.
- **The machine clock.** The capture runners stamp the local date. That clock read 2026-11-17 during the run. The catalog date and the evidence `read` fields are set to 2026-11-18, the capture date for this batch.

## Fonts

- **KitSansFont** is the display face (`--font-kit-sans`). It draws the home hero at 80px/500, interior mastheads at 64px/500, and the phone hero at 48px/500. The fallback named in computed style is KitSansFont Fallback.
- **Libre Franklin** is the UI and body face (`--font-libre-franklin`, aliased by `--font-sans`). Controls are 14px/600. The announcement bar is 16px/400.
- **Inter** is the log-in card face. It is not declared on kit.com. The card's computed stack is `Inter, -apple-system, system-ui, Segoe UI, Roboto, Helvetica Neue, Arial, Noto Sans, sans-serif`.
- None of these faces is bundled here. The style guide falls back to system sans. Licences were not published on the pages that were read.

## Do and don't

1. **Do spend blue on the trial and the announcement.** `#44b1ff` marks Start free trial and the top strip. Soft-black type sits on that blue. See [nav-trial](components/crops/nav-trial-default.png) and [announce-bar](components/crops/announce-bar-default.png).
2. **Do put the hero on soft-black.** The home masthead is white KitSansFont on `#1e1e1e`, not on the warm page field. Interior pages such as pricing invert that: ink type on warm white. See [home-light-default](screenshots/home-light-default.png) and [pricing-light-default](screenshots/pricing-light-default.png).
3. **Do keep the two faces apart.** KitSansFont is display only. Libre Franklin is every control and body line on kit.com. Inter belongs only on the log-in card. See [hero-h1](components/crops/hero-h1-default.png) and [login-submit](components/crops/login-submit-default.png).
4. **Do use 8px corners on marketing controls.** The trial pill, nav items and the features search are 8px. The log-in submit is 12px and its fields are 10px. See [hero-cta](components/crops/hero-cta-default.png).
5. **Don't style the signed-in product from this package.** The dashboard, editor, automations and subscribers were never reached. The log-in card is the boundary. See [login-light-default](screenshots/login-light-default.png).
6. **Don't invent a dark theme.** Kit ships light only. The empty `dark` set is a file shape, not a palette. See [home-light-full](screenshots/home-light-full.png).
7. **Don't follow a trial link and call it captured.** Plan and signup URLs were measured and never opened past the Cloudflare boundary. See [price-cta](components/crops/price-cta-default.png).
8. **Don't copy the wordmark or the photography.** The Kit mark, the log-in portrait and the product screenshots are Kit's published artwork. Borrow structure and proportion. See [nav-logo](components/crops/nav-logo-default.png).

## Rebuild

From the repo root. Playwright is `~/.design-systems/pw/node_modules/playwright/index.mjs`. Scratch stays in `~/.design-systems/kit/` and never enters git.

```sh
cd systems/kit
export PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs
export PYTHON=python3
export CAPTURE_DATE=2026-11-18
node tools/capture/vars.mjs
node tools/capture/public/public.mjs
node tools/capture/public/measure.mjs
node tools/capture/motion-probe.mjs --urls https://kit.com/,https://kit.com/pricing,https://app.kit.com/users/login
python3 tools/capture/quantize.py ~/.design-systems/kit/raw-shots
python3 tools/build_component_tokens.py
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/build_components_md.py
node tools/capture/public/build-measurements.mjs
```

`make brief`, `make design-md`, `make grade` and `make check` run from the repo root.
