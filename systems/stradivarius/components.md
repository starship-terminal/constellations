# Components

Public controls on the United States English shop, measured 2026-11-22. Nothing was submitted.

## Header

The wordmark is a link to https://www.stradivarius.com/us/. Search is a pill: background `rgba(245, 245, 245, 0.3)`, radius 4px, color `rgb(51, 51, 51)`, padding 5px 15px, uppercase. Account, wishlist, and basket are icon buttons. Account opens login, which redirected to OAuth and was abandoned. See [screenshots/home-light-1440.png](screenshots/home-light-1440.png).

## Menu row

A numbered row. The index ("01") is 12px, weight 400, uppercase. The label ("NEW IN") is 16px, weight 600, uppercase, family STRADIVARIUS WEB 2025. Special prices uses `#d0024c`. Clothing and Shoes are buttons that open a submenu in the same drawer. See [screenshots/menu-light-1440.png](screenshots/menu-light-1440.png).

## Filters button

Black fill `rgb(0, 0, 0)`, white text, 16px, weight 400, radius 2px, line-height 18.4px. It was not used to apply a filter. See [screenshots/category-light-1440.png](screenshots/category-light-1440.png).

## Category title and tile price

The category h1 is 32px, weight 400, line-height 44px, black, STRADIVARIUS WEB 2025. A tile price is 12px, weight 600, line-height 14px, black.

## Product title, price, size chip

The product h1 is 28px, weight 600, uppercase, line-height 38px, color `rgb(29, 29, 29)`. The price is 22px, weight 600, black. A size chip is 14px, weight 400, padding 1px 6px, transparent fill, black text. No size was selected. Add to bag did not appear and was not clicked. See [screenshots/product-light-1440.png](screenshots/product-light-1440.png).

## Footer column

A button that expands a list of links under the same page. Columns read: Help, Us, Gift Card, Use of AI, Follow us, Our app, Legal. See [site-tree.md](site-tree.md).

## Market picker

The worldwide page is a country list, not a storefront. United States was chosen. Continue was not a typed form. See [screenshots/gate-light-1440.png](screenshots/gate-light-1440.png).
