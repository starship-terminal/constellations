# Grow with Google design reference

A token set and component reference for grow.google — Google's public program site for Career Certificates, AI training and partner/story pages — for building marketing pages, program catalogs and course-detail surfaces in the style of the real thing. It was read from **grow.google's US edition** on **2026-11-17**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: every public route the site serves — `/`, `/certificates`, `/certificates/ux-design/`, `/certificates/data-analytics/`, `/ai/`, `/ai-professional/`, `/stories/`, `/our-mission/`, `/partners/`, `/employers/`, `/news-insights/` — in the painted light theme, with the Career Certificates mega-menu, the mobile navigation drawer, one FAQ expansion row and the hero video modal as transient states, plus 390px passes on home, the catalog, the certificate detail and the AI hub.

grow.google is worth a capture because it is a clean read of Google's **glue** marketing framework: the versioned gstatic marketing-cms bundle (`gwg-us-1.2.12-*/styles/default/All.min.css`, ~676 KB) declares only the colour layer as custom properties — the `--glue-{blue,green,grey,red,yellow,purple}-{50..900}` ramps, the standard Material hues — and everything else is compiled literals the measurement pass reads as computed styles. The vocabulary is small and exact: inks **#202124**/#3c4043/#5f6368 on **#ffffff** ground, the **painted accent #3186ff** on links and the filled pill buttons (brighter than the declared glue-blue-600 **#1a73e8**, which still paints card links and the 2px focus ring), **#185abc** hover/pressed with glue elevation-1, the **#eff2f7** blue-grey footer band, the **#18191d** editorial dark hero on certificate pages (a section paint, not a theme), 48px pill radii, a 120px-radius jumplinks pill bar, #dadce0 hairlines, a 0.2s control transition, and **Google Sans Flex** (variable opsz 6-144, wght 100-1000) on everything. **Boundary:** enrolment and accounts — every "Get started on Coursera" CTA leads off grow.google and was measured, never followed; nothing was enrolled in, signed into, bought or submitted; the footer's region/language `<select>` was never changed (its form posts to services.google.com); the YouTube embed was opened and closed, never played.

## How the values were read

- **Variables** come from the stylesheets themselves (`tools/capture/vars.mjs`): network responses are collected on the live pages, first-party sheets reparsed (the gstatic gwg-us bundle, the Google Fonts faces, the glue cookie-notification sheet), and every custom property resolved on the live page. Only the `--glue-*` colour ramps exist — the site declares no spacing/type/radius variables, so everything else is measured, never invented.
- **Geometry** is the live DOM (`tools/capture/public/measure.mjs`): bounding boxes and computed styles per component and state — hover by real mouse, focus-visible by keyboard, pressed by CDP `CSS.forcePseudoState` (no real press, so no link can fire), opened states via the component's own toggle.
- **The canonical surface is the US edition**: bare headless contexts (no user agent, no locale) receive it. From this capture host a real browser UA or an explicit locale is 302'd from `/` to `/intl/ALL_sg/`; deep links serve the US edition regardless. The `apac-*` screenshots record the regional variant; nothing in tokens.json comes from it.
- **Screenshots** (`tools/capture/public/public.mjs`) are bounded: tall mobile pages tile into `.partN.png` parts stitched for the package, with the clip recorded in each `.capture.json` sidecar.
- **The icon collection** (`tools/capture/icons.mjs`) hashes each inline svg's geometry, names it from its control's label, and records where each was seen in `icons/INDEX.tsv`.
- **Cookie consent** was never answered: the glue cookienotificationbar is removed (display:none) for captures — remove-only, same as the kit's promo handling.

## What to distrust

- **Captured with the automation flag masked.** The public capture (`tools/capture/public/`) hid `navigator.webdriver` from every page, so the committed readings and screenshots it took were taken past that mask. The scripts no longer hide it (edited, not run); a recapture that meets a bot check records it as a boundary.
- **Two blues are real, not a bug.** The site paints **#3186ff** on its links and filled buttons — brighter than the declared glue-blue-600 #1a73e8 the card links and focus ring still use. Copying #1a73e8 onto a button or #3186ff onto a focus ring is wrong either way; the tokens keep them in separate roles.
- **#185abc is hover/pressed, not a brand step** — it happens to equal declared glue-blue-800, and the tokens say which role it paints.
- **The dark hero is not a dark theme.** Certificate pages open on a #18191d band with white type; no theme control, no dark media query, no dark token set exists. Do not extend it into one.
- **The APAC shots differ by design.** `/intl/ALL_sg/` ships a different promo and fewer sections; it is a variant surface, not a drift in the tokens.
- **Pressed states** are DevTools-forced pseudo-classes; the `outline: auto` ring Chrome draws on a forced :active is an artifact, not a page style.
- **Reduced motion is only partially honoured**: the probe saw some elements keep animating under prefers-reduced-motion (`raw/motion.json`, "partial").
- **The promo banner's fill was not measured.** `promo-banner` read the transparent paragraph inside the bar, not the ancestor that paints it, so `banner.bg` is `rgba(0, 0, 0, 0)` and the bar's colour is not recorded; it needs a recapture. Its white copy (`banner.link`) and geometry are real readings.
- **Screenshot colours** are 256-colour PNGs; read exact values from tokens.json or the raw files.

## Do and don't

1. **Do keep it light and airy.** The whole site is white ground, dark-grey ink and one blue accent — the glue pattern is restraint, not decoration ([home](screenshots/home-light-default.png)).
2. **Do paint actions as filled pills.** A 48px-radius #3186ff pill with white 16px medium text is the one button ([Get started](components/crops/hero-cta-default.png)); hover/pressed darken to #185abc and lift the elevation.
3. **Do reach for the 2px focus ring, not an outline.** Keyboard focus paints a #1a73e8 box-shadow ring offset 1px ([focus](components/crops/nav-link-focus-visible.png)).
4. **Do set display type in Google Sans Flex.** The ramp is 60/72 hero, 48/56 catalog, 36/44 home headline, 28/36 section, 16/24 body — regular weights, -0.5px tracking on the display steps ([cert hero](components/crops/cert-h1-default.png)).
5. **Do use the editorial dark band for the certificate hero.** #18191d with white display type is a real surface — as a section, never as a theme switch ([cert page](screenshots/cert-ux-light-default.png)).
6. **Don't sign anything up.** Coursera enrolment, Google accounts and outbound links are all boundaries — measured, never followed; nothing on those hosts is captured here ([Coursera CTA](components/crops/cert-cta-default.png)).
7. **Don't invent a dark theme or a spacing scale.** Neither exists: the sheet declares only colours and every spacing token in the file is a measured control padding ([tab bar](components/crops/tab-bar-default.png)).
8. **Don't treat the APAC variant as canonical.** `/intl/ALL_sg/` is a different promo stack and shorter page — variant evidence only ([APAC home](screenshots/apac-home-light-default.png)).
9. **Don't copy the brand.** The "Grow with Google" lockup, the certificate artwork, portraits and icons are Google's; the tokens describe the system, not the artwork ([logo](components/crops/header-logo-default.png)).

### Principles

1. Do keep it light and airy.
2. Do paint actions as filled pills.
3. Do reach for the 2px focus ring, not an outline.
4. Do set display type in Google Sans Flex.
5. Do use the editorial dark band for the certificate hero.
6. Don't sign anything up.
7. Don't invent a dark theme or a spacing scale.
8. Don't treat the APAC variant as canonical.
9. Don't copy the brand.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

### Using tokens

| Role | light |
|---|---|
| page | #ffffff `light.color.surface.base` |
| surface | #f8f9fa `light.color.surface.muted` |
| text | #202124 `light.color.ink.primary` |
| muted | #3c4043 `light.color.ink.secondary` |
| accent | #3186ff `light.button.primary.bg` |
| border | #dadce0 `light.color.line.hairline` |

Fonts: `core.font.family.sans` is Google Sans Flex, then 3 fallbacks. Scales, counted as [DESIGN.md](DESIGN.md) holds them: 11 type styles (`core.typography`), 4 radius steps (`core.radius`), 6 spacing steps (`core.space`).

### Using components

Read [components.md](components.md) for the component inventory; [patterns.md](patterns.md) for how components combine into screens; 104 element crops in [components/crops/](components/crops); [style-guide.html](style-guide.html), which renders every token and the main components.
