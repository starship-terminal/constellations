# Visitors

Visitors is the privacy-friendly analytics product at [visitors.now](https://visitors.now/). This package records the public marketing site and the signed-out login and register pages on 2026-11-19.

Nothing was signed into. `/login` and `/register` ask for an email and show Google and GitHub buttons. A Cloudflare Turnstile field is in the form, so the email was not submitted. No card, phone number, or checkout was opened. The trial buttons were measured and not followed.

The attached T3 preview tab loaded the homepage, then stopped producing screenshot frames. The values and the screenshots come from a headless Chromium pass on the same public pages, which returned HTTP 200 with no challenge. Desktop captures are 1440x900 at 1x. Phone captures are 390x844 CSS at 2x (780x1688 PNG). Only light was painted. `prefers-color-scheme: dark` did not change the homepage.

## How the values were read

Custom properties were read from the homepage stylesheet `https://visitors.now/assets/styles-pNqCiRay.css` and resolved on `:root`. The product set is `--bg-*`, `--fg-*`, `--purple-*`, `--sky-*`, `--green-*`, `--red-*`, `--amber-*`, radius, shadow and type steps. Tailwind `--tw-*` names are in the same sheet and are not tokens.

Computed styles were read on `/`, `/login`, `/register`, `/blog`, `/docs`, `/contact`, `/s/godly.website` and the `/pricing` 404. The trial button, header Register, See demo, the email field, the Features cards and the pricing slider thumb are in [raw/detail.json](raw/detail.json).

## What to distrust

The header Register fill is `#9580ff`. The trial button is `#918df6` (`--purple-4`). They are two purples. Do not collapse them.

Nav labels are `rgb(187, 188, 195)`. That grey is not `--fg-1` (`#b3b3b3`) or `--fg-2` (`#999`). It is recorded as `core.color.nav`.

`rounded-full` computed to `33554400px`. The token is `9999px`, the pill intent, marked from that computed value.

The pricing card paint is `rgba(0, 0, 0, 0.03)`. Declared `--bg-a1` is `#00000008` (about 0.031). The semantic muted fill uses the painted alpha.

The homepage product frame (the dashboard with "Endless") is a marketing image. It is not the signed-in app. The public demo at `/s/godly.website` is a live public stats page and still not an account.

Screenshots are 256-colour PNGs. Read colours from [tokens.json](tokens.json).

Open Runde is loaded as `OpenRunde` at 400, 500 and 600. The files were not copied. The style guide falls back to Inter, then sans-serif.

## Fonts

Open Runde (`OpenRunde`) is the resolved family on body, headings, buttons and the email field. Weights 400, 500 and 600 are declared in `@font-face`. Inter is the fallback in the computed stack and was not the resolved family. The declared mono stack is `SF Mono, Menlo, OpenRunde, "Open Runde", sans-serif`. Docs badges still resolved to Open Runde.

## Do and don't

- **Do use Open Runde for UI text.** Body is 16px weight 400 with -0.32px tracking. The homepage h1 is 60px weight 600 with -3px tracking. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
- **Do use the purple pill for the main action.** Trial fill `#918df6`, white label, 44px, full pill. Header Register is the smaller `#9580ff` pill. Quiet actions are `rgba(0, 0, 0, 0.03)`.
- **Do keep the header as a dark floating pill.** Fill `#14141f`, labels `#bbbcc3`, on a white page. See [screenshots/home-light-mobile.png](screenshots/home-light-mobile.png).
- **Do not treat the homepage dashboard as the signed-in product.** It is a marketing image. The public demo is [screenshots/demo-light-default.png](screenshots/demo-light-default.png).
- **Do not invent a dark theme.** One theme was painted.
- **Do not submit the login form from this package.** Continue stays disabled until an email is entered, and a Turnstile field is on the page.
