# FARFETCH design reference

A token set and component reference for FARFETCH's public, signed-out luxury-fashion e-commerce surface — for building storefront home pages, product listing grids, product detail buy boxes and editorial modules in the style of the real thing. It was read from **farfetch.com** on **2026-11-14**, signed out, in headless Chromium at 1440 x 900 and 390 x 844 — through the **Wayback Machine**, because live farfetch.com answers Akamai 403 to automation and its `cdn-static`/`cdn-images` CDNs 429: the DOM evidence is archived SSR markup served locally and painted by Farfetch's own stylesheets and Emotion blocks with scripts stripped; fonts and product images are the site's own assets fetched through the archive. Captured: the department-chooser home, the women's and men's modular listing fronts, the "New In" classic edit listing, a Dolce & Gabbana product detail page, and 390px passes on home, the women's listing and the PDP.

FARFETCH is worth a capture because its stylesheets ship a real semantic token layer — the **pulse** layer declares ~590 `--colors-<family>-<role>-<state>-<slot>` custom properties on `:root` (families: actions, forms, navigation, content, cards, messaging, notifications, modality, pos, rating, access, general, page — every role exported in enabled/hover/pressed/active/focus/selected/disabled/loading states across icon/label/stroke/surface slots), plus the `--typography-*` roles, the `--spacers-c*/-l*` scales, `--gutter-*`, `--borders-*`, `--motion-functional/emotional-*`, `--icons-*`, `--button-*` and `--page-*`; the older camelCase layer adds the named palette (`--color-preto` ink, `--color-ouro` gold, the `--color<Tier>*` Access loyalty ramps and the five `--gradientAccess*` tier gradients) and the legacy type scale. The public surface paints **one light theme**: white surfaces, `#222222` ink on the square Add To Bag and every label, `#727272` secondary text, `#e6e6e6` hairlines, `#f5f5f5` skeletons, and the `#e71d34` sale red — 'Farfetch Basis' for all UI type, 'Nimbus Roman D' serif for editorial deks, square corners with a 1000px pill reserved for rounded controls. **Boundary:** the markup is archived, not live; hydration-owned surfaces (size listboxes, dropdown menus, filter drawers, accordions, wishlist toggles) stay closed and are declared rather than faked; sign-in, account, wishlist, bag, checkout and FARFETCH Access loyalty are gated and were never opened; no link was followed and no form was submitted.

### Principles

1. Do let the pulse layer carry the design.
2. Do keep it monochrome until it is a sale.
3. Do keep the one theme honest.
4. Do pair the voices.
5. Do build square.
6. Do read card = image + heart + kicker + dek + price.
7. Don't style the signed-in product from this package.
8. Don't fabricate hydration states.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## Do and don't

1. **Do let the pulse layer carry the design.** The product ships its token layer: use the `light.<family>.<role>.<state>.<slot>` semantics — `action.primary.*` for the filled ink button, `action.secondary.*` for the outlined ghost, `form.primary-default.*` for fields, `navigation.primary.*` for the chrome — rather than restating hex. See [tokens.json](tokens.json) and [add-to-bag](components/crops/add-to-bag-default.png).
2. **Do keep it monochrome until it is a sale.** The UI is white, `#222` ink, `#727272` secondary and `#e6e6e6` hairlines; colour enters almost nowhere except `#e71d34` on the Sale link, sale prices and the `-40%` marks. See [nav-sale](components/crops/nav-sale-default.png) and [sale-price](components/crops/sale-price-default.png).
3. **Do keep the one theme honest.** Every public surface paints light; there is no dark hook, and the dark set stays empty by evidence. See [home-light-default](screenshots/home-light-default.png).
4. **Do pair the voices.** 'Farfetch Basis' owns every UI string — labels, nav, buttons, prices, headings; 'Nimbus Roman D' appears only as the editorial serif in campaign deks. See [hero-module](components/crops/hero-module-default.png).
5. **Do build square.** Buttons, fields, comboboxes and cards are 0-radius squares; the 1000px `radius.rounded` is reserved for pills. See [size-selector](components/crops/size-selector-default.png) and [news-submit](components/crops/news-submit-default.png).
6. **Do read card = image + heart + kicker + dek + price.** Product cards compose the same five parts everywhere: 3:4 photography, a ghost-dark wishlist heart, the uppercase brand kicker, the muted description, the price. See [product-card](components/crops/product-card-default.png).
7. **Don't style the signed-in product from this package.** Account, wishlist, bag, checkout and FARFETCH Access live behind sign-in and were never opened; the icon hit areas at rest are the evidence. See [topbar-bag](components/crops/topbar-bag-default.png).
8. **Don't fabricate hydration states.** The archived copy is script-less: the Select size listbox, department dropdowns, the filter drawer, accordions and carousel scroll stay closed. Opened/selected looks are declared in `light.action.*.selected.*` and `light.modality.*` tokens, not painted in the crops. See [size-selector](components/crops/size-selector-default.png).
