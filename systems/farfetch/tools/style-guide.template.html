FARFETCH style guide

Generated from tokens.json; every swatch, radius and shadow below is a token, not a restated number. The boxed page mocks are reconstructions drawn with those tokens, not captured pixels.

farfetch.com, measured

Every value on this page is a CSS custom property generated from tokens.json: the declared pulse token layer — the ~590 --colors-<family>-<role>-<state>-<slot> semantics (actions, forms, navigation, content, cards, messaging, notifications, modality, pos, rating, access, general, page), the --typography-* roles, the --spacers-c*/-l* and --gutter-* scales, --borders-*, --motion-functional/emotional-*, --icons-*, --button-* and --page-* — plus the legacy camelCase palette/type layer. The look: white surfaces, #222222 ink, #727272 secondary text, #e6e6e6 hairlines and the #e71d34 sale red, 'Farfetch Basis' UI type with 'Nimbus Roman D' editorial serif, square corners everywhere except the 1000px pill. The real pixels are in screenshots/ and components/crops/.

Read from farfetch.com on 2026-11-14, signed out, in headless Chromium — through the Wayback Machine, because live farfetch.com answers Akamai 403 to automation and its CDNs 429: the DOM is archived SSR markup painted by its own stylesheets with scripts removed, so hydration-owned surfaces (size listboxes, dropdown panels, filter drawers) stay closed. Nothing was signed into, added to a bag or wishlist, submitted or bought; hover/focus/pressed states were forced, the search and newsletter fields were typed into and cleared, never submitted. 'Farfetch Basis' and 'Nimbus Roman D' are proprietary fonts; samples fall back to system faces.

Palette

The core.palette groups are the legacy declared colours — the named --color-* ramp (preto ink, branco white, ouro gold, the grey steps), the --color[Tier]* Access loyalty palettes and the five --gradientAccess* tier gradients. The light set exports the whole pulse semantic layer — every --colors-* role/state/slot. The site paints one theme; the dark set is empty.

Spacing, radius and borders

core.space.component is the --spacers-c* control scale (4–48px) and core.space.layout the --spacers-l* block scale (to 72px), beside the older --spacer-* names and the --gutter-* steps under core.layout.gutter. core.radius is squareness — every corner is 0 except the 1000px rounded pill; core.borderWidth is the 1px/2px stroke pair. Motion splits functional (0.15–0.6s controls) from emotional (0.2–0.85s page emphasis), each with accelerated/decelerated/standard easings.

Elevation

The pages are nearly flat — no declared shadow scale was found in the token sheets; layering is the #e6e6e6 hairline, the ui-overlay01 rgba(34,34,34,.4) scrim and the 0.95-white ui-overlay02. Any shadows that appear were measured per component.

Type

Two voices: 'Farfetch Basis' for everything — body 15px/1.3333, Title/Heading 22px, Display 30px, DisplayLarge 38px, the uppercase 15px Kicker, Caption and Footnote at 13px — and 'Nimbus Roman D' for the 20px/1.2 Editorial dek; the legacy display stack adds 'Nimbus Sans Extended D'.
