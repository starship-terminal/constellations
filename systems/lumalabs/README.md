# Luma AI design reference

A token set and component reference for Luma AI's public signed-out website, for building a black-and-white marketing shell, a pricing page and a prompt composer in the style of the real thing. It was read from **lumalabs.ai** on **2026-11-18**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: home, pricing, about, API, enterprise, Ray, Uni-1, news, MCP, careers, case studies, learning center, the video-generator page, the agents page, terms, docs, and 390px passes on home, pricing, Ray and news.

Inner pages paint `html.light`: a white page (`light.surface.page` `#ffffff`), black text (`light.text.primary` `#000000`), and Graphik. Brand roles are HSL channel triplets on `.light` and `.dark` (`--surface-primary`, `--primary`, `--secondary`, and the inverted set). A shadcn oklch layer (`--background`, `--foreground`, `--border`, `--destructive`) sits beside them. The home hero and `/ray` paint dark media. `html.dark` resolves a black page and white text (`dark.surface.page` `#000000`, `dark.text.primary` `#ffffff`). There is no theme switch on the marketing pages.

**Boundary:** the app and generation sit behind sign-in. https://app.lumalabs.ai redirects to a WorkOS sign-up host and was not crossed. Sign In, Try for free, Start Now, Use the API, Subscribe and the enterprise Submit were measured, never followed. The home prompt was filled and cleared. Consent overlays were hidden, never answered. There is no public user gallery.

## What to distrust

- **The home hero is dark while inner pages are light.** `home-dark-*` is the painted hero. `pricing-light-*` and `about-light-*` are the painted page. Both token sets are real resolutions of the same sheets.
- **`--background` on dark is `#0a0a0a`.** The brand page role `--surface-primary` on dark is `#000000`. /ray paints black. Prefer the brand role for the page field.
- **Graphik's computed family name is a Next.js hash.** The page computes `__graphik_7126cf` plus its fallback. `core.font.family.graphik` names the face `Graphik, sans-serif` (derived from that local name) and keeps the computed stack in `$extensions.computed`. `core.font.family.editorial` is an alias of it: the home h1 computed to Graphik, and PP Editorial was not read from any element.
- **The plan card has no reading of its own.** `price-card` in [raw/components-computed.json](raw/components-computed.json) holds the page `body`'s computed style: the capture's target was `body`, and only the crop ([price-card-default](components/crops/price-card-default.png)) was taken from the Plus card. [components.md](components.md) leaves those values out. `tools/capture/public/measure.mjs` now records the card's own style in `extra.card`; it was not rerun, so the card needs a recapture (the pk-k recapture tracking issue, 2026-11 audit). The screenshot of the cards is [pricing-light-default](screenshots/pricing-light-default.png).
- **Automation was masked.** The committed readings and screenshots were taken with `navigator.webdriver` hidden by `tools/capture/public/lib.mjs`. The mask has been removed from the script (2026-11 audit); a bot check is now a boundary, not something to get past.
- **No layout grid was read.** `tools/capture/layout.mjs` was not run, so there is no `raw/layout.json`.
- **A missing path is not a Luma 404.** `/no-such-page-capture` rendered a Vercel "Invalid slug" page. It was not kept.
- **Quantised screenshots band gradients.** Read exact colours from tokens.json or the raw JSON.
- **Docs is a different product surface.** ReadMe tokens are in `raw/css-vars.json` under `docsLight` and are not in tokens.json.

## Fonts

**Graphik** is the UI face (`core.font.family.graphik`). The home h1 on 2026-11-18 also computed to Graphik, 52px, weight 500, line-height 62.4px, tracking -2.08px. PP Editorial is loaded on the page as a second Next.js local font and was not the computed h1 family on this pass. Neither file is redistributed. The style guide falls back to system fonts.

## Do and don't

1. **Do paint inner pages white and the home hero black.** Pricing is a white field. The home hero is a black video. See [pricing-light-default](screenshots/pricing-light-default.png) and [home-dark-default](screenshots/home-dark-default.png).
2. **Do set UI in Graphik at a tight tracking.** Nav labels are uppercase. The hero is 52px / 500. See [hero-h1](components/crops/hero-h1-default.png).
3. **Do use a white pill for Sign In and Try for free.** Sign In is 32px. Try for free is 48px. See [nav-signin](components/crops/nav-signin-default.png) and [hero-cta](components/crops/hero-cta-default.png).
4. **Do invert one plan card to black.** Pro is the black card between two subtle cards. See [pricing-light-default](screenshots/pricing-light-default.png).
5. **Do keep the prompt on a 12px radius.** The composer is a dark rounded field, not a pill. See [prompt](components/crops/prompt-default.png).
6. **Don't follow Sign In, Try for free or Start Now.** Those controls were measured. Following them is a sign-in, and Start Now is a checkout. See [price-cta](components/crops/price-cta-default.png).
7. **Don't invent a public gallery or a signed-in app shell.** Example stills on /ray are marketing. The app host was not entered. See [ray-dark-default](screenshots/ray-dark-default.png).
8. **Don't treat the docs hub as the marketing theme.** docs.lumalabs.ai is a ReadMe site. See [docs-light-default](screenshots/docs-light-default.png).
