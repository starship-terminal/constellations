# TidyCal

TidyCal is scheduling software (tidycal.com). This package captures the public marketing site and the signed-out login and register forms. No account was used.

Surfaces: home, pricing, login, register, and password reset. Theme: light. Widths: 1440 and 390 CSS pixels. Captured 19 November 2026.

### Principles

1. Use white for the page and `#1569ef` for the primary button.
2. Use `#0053ee` for text links.
3. Set headlines in Poppins at weight 600.
4. Keep login on a white card with outline OAuth buttons.
5. Do not invent a dark marketing theme.
6. Do not submit signup, connect a calendar, or enter a card from this package.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The T3 preview browser opened `https://tidycal.com/` in its own tab. Computed styles were read with `getComputedStyle`. That viewport was 1169 by 731, device pixel ratio 2, visual viewport scale 1. Login, pricing, and register loaded in the same tab. None was a Cloudflare challenge.

`preview_snapshot` returned "The browser is not producing screenshot frames." Measurements already read were kept.

Headless Chromium then loaded the public pages, including login and register, because those pages had already loaded in the preview browser without a challenge. Screenshots are 256-colour PNGs. Pixel size is 2 times the CSS viewport. `window.innerWidth` was 1440 and 390.

Brand colours were read from computed custom properties on `:root` (`--tc-accent`, `--tc-text`, `--tc-page-bg`, `--tc-border`) and from computed colours on the elements that use them. The painted primary button is `#1569ef`. The token `--tc-accent` is `#0053ee`, and links use that.

## What to distrust

The Google signup button's stylesheet rule sets a white fill. The computed background on the live button is `#1a73e8`. The crop matches the computed blue.

`.hp-2026 .btn-primary:hover` declares `#0e58cd`. Hovering the register submit in headless Chrome did not change the computed fill. The AppSumo pricing button did change, to `#d69e00`.

The Get the deal pill colour `#ffbc00` was sampled from the home screenshot. The pricing AppSumo button computed the same hex.

Dark rules under `html[data-bs-theme=dark]` were not on these pages. Do not treat them as a captured theme.

The directory page loaded and was not saved. It shows other people's names and photos.

## Fonts

Body is Inter 18pt, then Roboto and a system stack. Headings are Poppins. Both are loaded from Google Fonts. The package does not commit the font files. Tokens fall back to Inter, Roboto, and sans-serif.

## Do and don't

- **Use white for the page and `#1569ef` for the primary button.** The hero sits on `#fafafa`. [home-light-default.png](screenshots/home-light-default.png)
- **Use `#0053ee` for text links.** The token and the link colour agree. [link-inline-default.png](components/crops/link-inline-default.png)
- **Set headlines in Poppins at weight 600.** [home-light-default.png](screenshots/home-light-default.png)
- **Keep login on a white card with outline OAuth buttons.** [login-light-default.png](screenshots/login-light-default.png)
- **Do not invent a dark marketing theme.** The public pages stayed light.
- **Do not submit signup, connect a calendar, or enter a card from this package.**
