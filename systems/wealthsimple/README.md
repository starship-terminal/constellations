# Wealthsimple design reference

A token set for Wealthsimple's public signed-out web chrome, for building marketing pages and a signed-out login in the style of the real thing. It was read on **2026-11-19**, signed out. The design surface is the Canada marketing page at [wealthsimple.com/en-ca](https://www.wealthsimple.com/en-ca) (the root redirected there) and the signed-out login at [my.wealthsimple.com/app/login](https://my.wealthsimple.com/app/login?locale=en-ca).

Marketing paints an off-white page (`#FCFCFC`), slate text (`#1C1B1B`), and pill controls. A dark marketing section paints `#080F16`. Login paints one dark theme: `html` has `data-appearance="dark"` and `data-mint-theme="core"`, page `#0D0D0D`, primary button `#F2F2F2`.

**Boundary:** brokerage. No account was created. No name, email, password, phone, card, bank, or KYC value was entered. Signup was opened only to record the wall. The passkey button was not clicked.

### Principles

1. Do paint the marketing page off-white and the primary pill slate.
2. Do use 1000px pills and 12px fields.
3. Do set marketing type in The Future and the large serif line in Tiempos.
4. Do keep login on the dark app page.
5. Don't style the brokerage from this package.
6. Don't invent a login light theme.
7. Don't enter the signup form.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Computed styles were read in the T3 preview tab with `preview_evaluate` on the live page. Marketing colours, type, radii, and control sizes come from `getComputedStyle` on `/en-ca` after the viewport measured `innerWidth` 1440, `innerHeight` 900, `devicePixelRatio` 2. Login colours, type, field chrome, and the button come from custom properties and computed styles at `/app/login?locale=en-ca`, viewport 1169 by 731, `devicePixelRatio` 2. Signup was opened at `/app/signup` and not filled.

The preview browser returned "The browser is not producing screenshot frames" on `preview_snapshot`. A later headless Chromium load of the same public URLs returned HTTP 403 with the page text "Wealthsimple is using a security service to protect itself from online attacks." Those frames were deleted. No screenshot in this package is a capture of the product.

## What to distrust

`--ws-header-height` is `5.75rem` (92px). The painted `header` at 1440 was 60px. The token uses 60px. `--ws-color-background` on `.ws-content-dark-theme` stayed `#FCFCFC` while the painted background was `rgb(8, 15, 22)`. Dark page colour is the login `--bg-app` `#0D0D0D`, and the marketing section colour is recorded separately as `#080F16`. Get started computed `border-radius: 1600px`. The pill token is `--ws-border-radius-pill` at `1000px`, which the login button also computed. Login promo letter-spacing computed as `normal`. The token uses `--text-heading-xlarge-letter-spacing` of `-0.8px`. Wordmark SVG fill is `#1b1b1b`, one step off the text token `#1C1B1B`.

## Fonts

The Future is the marketing face, loaded as woff2 from `/fonts/TheFuture-Regular.woff2`, Medium, and Bold. Tiempos is the marketing serif, from `/fonts/TiemposText-Regular.woff2`. Login uses Wealthsimple Sans, computed as `"Wealthsimple Sans", sans-serif`. Marketing also declares `wealthsimple-sans` and `wealthsimple-display-sans`. Tokens name the families and a system fallback. The font files are not in this package.

## Do and don't

- **Do paint the marketing page off-white and the primary pill slate.** Page is `#FCFCFC` and Get started is `#1C1B1B` with `#FCFCFC` text. See [raw/css-vars.json](raw/css-vars.json).
- **Do use 1000px pills and 12px fields.** Marketing and login buttons resolve to a pill. The login field wrapper is 12px radius, 52px tall. See [raw/css-vars.json](raw/css-vars.json).
- **Do set marketing type in The Future and the large serif line in Tiempos.** The 1440 hero is The Future 64/74.24 weight 500. The display line is Tiempos 128/148.48. See [raw/css-vars.json](raw/css-vars.json).
- **Do keep login on the dark app page.** `data-appearance="dark"` paints `#0D0D0D` with a `#F2F2F2` Log in pill. See [raw/css-vars.json](raw/css-vars.json).
- **Don't style the brokerage from this package.** Positions, transfers, and settings sit behind login. See [patterns.md](patterns.md).
- **Don't invent a login light theme.** Login only painted `data-appearance="dark"`. See [raw/css-vars.json](raw/css-vars.json).
- **Don't enter the signup form.** The wall asks for a preferred name, email, and password, then Next. See [patterns.md](patterns.md).
