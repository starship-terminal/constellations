# Wealthsimple design reference

A token set and component reference for Wealthsimple's public marketing site (https://www.wealthsimple.com/en-ca). Captured 2026-11-21, signed out, in headless Chromium at 1440×900 and 390×844. The signed-in app at `my.wealthsimple.com` was not entered. Log in showed email and password and no Google button. Nothing was typed and no form was submitted.

The site is one light scheme. Ink `#1c1b1b` on off-white `#fcfcfc`, pill controls, a floating header, and two proprietary faces: The Future for UI and Tiempos for editorial headlines. Dark navy heroes are page sections (`--ws-color-midnight`), not a second theme.

## How the values were read

Custom properties were read from the public stylesheet chunk `3d8dv3vht62lo.css` (`:root`, 91 names), fetched from `www.wealthsimple.com/build-assets/_next/static/chunks/` on 2026-11-21. The deploy id was `de4a6e16b80c0f6994378ffb36f84aaaf7ec6388`. Computed styles for body, headings, Get started, Log in, the Trade nav item, a footer link, and a field were read with Playwright on `/en-ca/pricing` and `/en-ca/contact`. Hover was a real pointer hover. Focus was `element.focus()`. No consent button was clicked. The consent overlay was hidden with CSS.

## What to distrust

- There is no site-wide dark theme. Dark sections restyle the same custom properties locally. Those overrides are not a second token set.
- Get started focus did not paint a ring on the element. The declared ring width is 0.25rem. Treat the ring colour as declared, not as a visible crop.
- Pressed was not a distinct computed colour. It is not a separate step.
- Status hues (celery, apricot, terracotta, sky) are on `:root`. No success, warning, or error toast was shown, because no form was submitted.
- Search typed "TFSA". The result list did paint (Tax-Free Savings Account and related public links). The query was not submitted as a form.
- Contact and get-in-touch field focus timed out. Those fields were not filled.
- Product icons are not in `icons/`. The site icon is icon.png.
- Screenshots are 256-colour PNGs. Read colours from tokens.json.
- The Future and Tiempos are proprietary and are not in the repo. The guide falls back.

## Do and don't

- **Do set UI in ink on off-white.** Page `#fcfcfc`, text `#1c1b1b`. [screenshots/home-light-banner-closed.png](screenshots/home-light-banner-closed.png)
- **Do make the primary action a black pill.** Get started is the only filled control in the header. [components/crops/button-primary-default.png](components/crops/button-primary-default.png)
- **Do keep secondary actions as outline pills.** Log in is a keyline, not a second fill. [components/crops/button-secondary-default.png](components/crops/button-secondary-default.png)
- **Do use The Future at 14/500 for controls and 18/400 for body.** Editorial headlines switch to Tiempos. [components/crops/header-default.png](components/crops/header-default.png)
- **Don't treat a dark hero as a dark theme.** Midnight sections sit inside the light site. [screenshots/home-light-default.png](screenshots/home-light-default.png)
- **Don't invent a focus ring the crop does not show.** The token exists. The Get started crop does not paint it.

## Rebuild

```bash
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/test_tokens.py
```

Capture (Playwright, not the T3 preview browser):

```bash
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  node tools/capture/public/capture.mjs
python3 tools/capture/quantize.py ~/.design-systems/wealthsimple/raw-shots
```

Catalog registration is intentionally absent. A capture pull request that edits catalog.json is rejected.
