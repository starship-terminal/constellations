# Contra

Contra is a freelance network (contra.com). This package captures the public signed-out site. The display name in the webapps manifest uses a Cyrillic С. The slug is contra.

Surfaces: home, payments, partners, challenges, and the log-in page. Themes: light only. Widths: 1440 and 390 CSS pixels on the home page. No account was created. No email, phone, card, wallet, government ID, or company SSO was entered.

### Principles

1. Use the near-black pill for the primary action.
2. Keep the outline button for the second action.
3. Keep the page white.
4. Set the home headline in GT Standard L at 58px, weight 500, tracking -0.58px.
5. Do not invent a dark theme from `--rollout-*`.
6. Do not submit the sign-up form from this capture.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The T3 preview tab opened `https://contra.com/` and landed on `/?view=projects` with no Cloudflare challenge. `preview_snapshot` returned "The browser is not producing screenshot frames" twice. Computed styles on that live tab were read with `preview_evaluate`.

The same public marketing URLs were then measured in headless Chrome (Playwright, channel `chrome`) at 1440 by 900 and, for the home page, 390 by 844. `window.devicePixelRatio` was 2. Screenshots are 256-colour PNGs at twice the CSS viewport. The login page is a public signed-out form, not a Cloudflare challenge, so it was measured and screenshotted the same way. The sign-up page painted a Cloudflare Turnstile widget, so nothing was typed and no screenshot was kept.

Named colours and fonts come from `getComputedStyle(document.documentElement)` on the home page. The stylesheet is cross-origin (`builds.contra.com`), so `cssRules` threw a SecurityError in the preview tab. The named custom properties still resolved on the root.

## What to distrust

Sign up and Post a job did not change fill under pointer hover. Focus drew a 2px outline in the button colour. That is what the computed style returned.

`--color-alert*` and `--color-brand*` are declared on the root. The captured pages did not paint the alert colours. Brand green, purple, watermelon, and yellow are in the tokens as declared values, not as a measured button fill.

`--rollout-*` resolved to a dark pair (`#1e1d1b` surface, `#fff` text) while the home page stayed white under `prefers-color-scheme: dark`. Those names are in [raw/measurements.json](raw/measurements.json). They are not a dark theme.

Payments, partners, and challenges set the document font to `sans-serif` at 12px. Their headlines still computed as GT Standard 6 L Regular at 80px. Use the headline token, not the document font, for those pages.

GT Standard L, GT Standard M, GT Standard 6 L Regular, and GT Standard Mono are commercial faces. The tokens name them. The style guide falls back to Arial, which is already in the site's stack.

The prompt box radius was not a property of the textarea. The textarea measured radius 0.

## Do and don't

- **Use the near-black pill for the primary action.** Sign up is `#222834` with white type, 48px tall, 24px radius. [button-primary-default.png](components/crops/button-primary-default.png)
- **Keep the outline button for the second action.** Post a job is white with a `#373f51` stroke, same height and radius. [button-outline-default.png](components/crops/button-outline-default.png)
- **Keep the page white.** The home page paints `rgb(255, 255, 255)`. The auth pages sit a white card on `#f5f6f9`. [home-light-default.png](screenshots/home-light-default.png)
- **Set the home headline in GT Standard L at 58px, weight 500, tracking -0.58px.** The payments page uses a different face at 80px. [home-light-default.png](screenshots/home-light-default.png)
- **Do not invent a dark theme from `--rollout-*`.** Those variables resolved dark while the page stayed light. [raw/measurements.json](raw/measurements.json)
- **Do not submit the sign-up form from this capture.** It asks for a name as well as an email, and it shows a Turnstile widget. Nothing was entered.
