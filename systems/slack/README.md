# Slack design reference

A token set and component reference for Slack's public marketing site (https://slack.com/), captured at the locale the site served, https://slack.com/intl/en-sg/. Use it to build a marketing surface that borrows the look: a white page, black Salesforce Avant Garde display, Salesforce Sans body, a filled aubergine button `#730394` that darkens to `#4b1958` on hover, 4px control radii, and a dotted aubergine focus ring. It was captured signed out, in Playwright Chromium at 1440 x 900 and 390 x 844, on 2026-11-21.

The product app was not entered. Sign in stops at https://slack.com/signin. Get started stops at https://slack.com/get-started and https://app.slack.com/get-started. No email was typed, no form was submitted, and Google, Apple and Microsoft were not clicked. The homepage demo of the Slack app is a public marketing illustration, not a signed-in workspace.

This package contains no Slack code, and none of its artwork has been redrawn. The screenshots and the visual system they show belong to Slack ([docs/RIGHTS.md](../../docs/RIGHTS.md)). Borrow structure and proportions, not the logo, artwork or brand assets.

## How the values were read

- Component colours, type, radii and sizes were read as computed styles on the live page by [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs). Hover, focus-visible and pressed were forced with `CSS.forcePseudoState`. Focus on the contact field used a real focus. Nothing was typed or submitted.
- Custom properties were read from stylesheet response bodies plus inline sheets by [tools/capture/vars.mjs](tools/capture/vars.mjs). The marketing CSS names most colours with hashed `--t*` custom properties. Font families are named `--font-family-heading`, `--font-family-body` and `--font-family-monospace`.
- Page section backgrounds were read into [raw/page-colors.json](raw/page-colors.json).
- Screenshots were taken by [tools/capture/public/public.mjs](tools/capture/public/public.mjs) and quantised by [tools/capture/quantize.py](tools/capture/quantize.py). The cookie banner was hidden and never accepted.

## What to distrust

- **The product is absent.** Channels, messages, settings and onboarding sit behind sign-in and get-started. The homepage window labelled Slackbot is a marketing illustration.
- **Hashed colour names are not a semantic scale.** `--t*` values in `raw/css-vars.json` are declared colours. Semantic roles in `tokens.json` come from computed styles on named controls, not from guessing which hash is "primary".
- **No dark theme was painted.** A `.dark` probe in the variable reader did not produce a second painted theme. There is no dark token set.
- **Screenshots are 256-colour PNGs.** Read colours from tokens.json or the raw JSON.
- **Contact-sales fields are the public form, not workspace settings.** They were not filled.

## Fonts

- **Salesforce Avant Garde** is the display face, declared as `--font-family-heading` and painted on the homepage h1. It is a commercial webfont. The style guide names the stack and falls back to system fonts.
- **Salesforce Sans** is the UI face, declared as `--font-family-body` and painted on buttons, nav and body. Same licence limit.
- **Monaco, Menlo, Consolas** is the declared monospace stack. No public code block was measured as a type role.

## Do and don't

- **Do keep the page white and the display face heavy.** The homepage heading is black Salesforce Avant Garde at 64px on white. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
- **Do use one aubergine for the primary action.** Get started is `#730394` with white label, 4px radius, and darkens on hover. See [components/crops/button-primary-default.png](components/crops/button-primary-default.png).
- **Do outline the secondary action.** Request a demo and Find your subscription are white with an inset aubergine ring, not a second fill. See [components/crops/button-outline-default.png](components/crops/button-outline-default.png).
- **Do focus with a dotted aubergine ring, offset 5px.** See the focus-visible readings in [components.md](components.md).
- **Don't treat the homepage Slack window as the app.** It is a marketing illustration. The real workspace starts at the sign-in wall in [site-tree.md](site-tree.md).
- **Don't invent a dark marketing theme.** None was painted on the captured pages.

## Rebuild

```bash
cd systems/slack
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/vars.mjs
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/public/measure.mjs
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/public/public.mjs
python3 tools/capture/quantize.py ~/.design-systems/slack/raw-shots
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
```

From the repo root, `make design-md` regenerates DESIGN.md after the catalog entry exists.
