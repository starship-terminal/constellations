# Modyfi design reference

A token set and component reference for Modyfi's public marketing site. Modyfi was a browser design and motion tool. Figma acquired it in April 2025 and the product shut down on 13 June 2025. On 19 November 2026, `https://modyfi.com` and `https://www.modyfi.com` both returned Webflow's 404 page, and `https://app.modyfi.com` did not resolve.

The values were read from the Internet Archive replay of the product's own pages, signed out, in headless Chromium. The homepage snapshot is `20250219221151` (`https://www.modyfi.com/`). Other public pages use later 200 snapshots listed in [raw/archive-urls.json](raw/archive-urls.json). Desktop shots are 1440 x 900. The site publishes one dark theme.

### Principles

1. Do paint the page black and the headline white.
2. Do use magenta for the Sign up outline, and fill it on hover.
3. Do set display type in Jokker at a tight tracking.
4. Do keep body copy grey.
5. Don't treat the hero canvas as the signed-in product.
6. Don't invent a light theme.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Live `modyfi.com` is a Webflow 404. The T3 preview browser opened that 404, then opened the Wayback homepage `20250219221151` and read computed styles there: black page, `#c9c9c9` body text, `#ff0357` accent, Jokker 56px headline. A headless Playwright pass then replayed the same snapshot and the other public routes, hid the Wayback toolbar, and saved `getComputedStyle` into [raw/readings.json](raw/readings.json) and [raw/css-vars.json](raw/css-vars.json).

Custom properties were read from `:root` of the homepage stylesheet `modyfi-1-7f87acb0d89f4715-89e73237ef4ca.webflow.7c507b4eb.min.css`, which is still on `cdn.prod.website-files.com`. Component geometry was read on the painted elements, not sampled from the PNG.

No account was created. Log in and Sign up were measured and not followed. No form was submitted. No card, phone number, or government ID was entered.

## What to distrust

This is archival evidence. The homepage snapshot is 19 February 2025. The product shut down four months later. A value is what that snapshot painted.

The hero canvas is a marketing image of the editor. It is not the signed-in app.

Screenshots are 256-colour PNGs. Read colours from `tokens.json`.

Jokker is a commercial face and is not in this package. The style guide falls back to the system sans.

Untitled UI and Relume names in the stylesheet (`--untitled-ui-*`, `--relume-library-lite-*`) are library leftovers. They are in `raw/css-vars.json` and are not the marketing palette.

Sign up at rest is a transparent pill with a 2px `rgba(255, 3, 87, 0.47)` border. Hover fills it `#ff0357`. An earlier pass that hovered the control before reading rest recorded the fill as the default. `raw/crops-measured.json` is the resting read.
`tools/build_from_readings.py` now takes each default it can from that file, so [raw/components-computed.json](raw/components-computed.json) also says transparent.

The Primary call to action's focus-visible row has no saved reading. Its values were entered by hand, after a programmatic `focus()`, so its `rgb(153, 200, 255) auto 1px` outline is the browser's default ring, not a Modyfi style. It is labelled Reconstruction.

[raw/motion.json](raw/motion.json) says `no-motion`, but the capture read no computed transition. Read it as not captured. `tools/capture/run.mjs` now writes `not-captured`.

## Fonts

Jokker is the display and nav face (computed on `h1` and `.rl_navbar2_button`). Inter is the body stack (computed on `body`). The white "Start playing for free" pill uses `system-ui` at 16px weight 600. Jokker is proprietary and not committed.

## Do and don't

1. **Do paint the page black and the headline white.** The field is `--background-a` (`#000000`) and the headline is `--heading` (`#ffffff`). See [home-dark-default.png](screenshots/home-dark-default.png).
2. **Do use magenta for the Sign up outline, and fill it on hover.** At rest the border is `rgba(255, 3, 87, 0.47)`. Hover fills `#ff0357`. The primary call to action stays a white pill. See [components/crops/signup-button-default.png](components/crops/signup-button-default.png) and [components/crops/signup-button-hover.png](components/crops/signup-button-hover.png).
3. **Do set display type in Jokker at a tight tracking.** The homepage `h1` is 56px, weight 600, letter-spacing -3px. See [components/crops/hero-title-default.png](components/crops/hero-title-default.png).
4. **Do keep body copy grey.** Paragraphs are `#c9c9c9`, not white. See [components/crops/hero-body-default.png](components/crops/hero-body-default.png).
5. **Don't treat the hero canvas as the signed-in product.** It is a picture on the marketing page. See [home-dark-full.png](screenshots/home-dark-full.png).
6. **Don't invent a light theme.** The site publishes one dark palette.

## Rebuild

```sh
python3 tools/build_from_readings.py
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/capture/quantize.py <raw-shots-dir>
```

The capture needs Playwright:

```sh
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/run.mjs
```

Each raw file has one writer. `tools/capture/run.mjs` writes `readings.json`, `layout.json`, `archive-urls.json` and `motion.json`. `tools/capture/crops.mjs` writes `crops-measured.json`. Then `tools/build_from_readings.py` writes `components-computed.json` and `css-vars.json` from those two.
