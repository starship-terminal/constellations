# Trip.com

Public signed-out surfaces of Trip.com (sg.trip.com, locale en-SG), measured on 2026-11-19 from the live page in the T3 preview browser. The capture covers the marketing home, the hotels landing page, customer support, and the email sign-in form. Nothing was booked, paid for, or submitted. The account was not created. One light theme. Widths read: 1169 CSS px at the token dump, then 1440 CSS px after a resize (devicePixelRatio 2, visualViewport scale 1). A 390 px pass was not taken.

## How the values were read

The home page at `https://sg.trip.com/?locale=en-sg` loaded in the T3 preview browser with no Cloudflare challenge. Custom properties were read from the readable stylesheets' `:root` rules and from `getComputedStyle(document.documentElement)`. The home stylesheet is `onlineHome.c56710cfc623923d2e70ff1230d47f41.css` on `ak-s-cw.tripcdn.com`. Cross-origin sheets that threw on `cssRules` (the search-box chunk, the hotel chunk, the marketing chunk) were not parsed; values from those sheets come from computed styles on live elements.

A second pass at innerWidth 1440 confirmed the search card, the Search button, the header, and the slogan. `/hotels/`, `/pages/support/`, and `/account/signin` were opened in the same tab and measured the same way. The email field was focused so its border colour could be read. It was not filled and the form was not submitted.

The preview browser returned "The browser is not producing screenshot frames" on every snapshot. A fresh headless Chromium against `https://www.trip.com/` was redirected to `verify.trip.com` and asked to complete a verification test, so that session was closed and its frame was deleted. No screenshot or crop is in this package.

## What to distrust

The `--smtcTypographyBody1` family (32px, 30px, 28px, 26px, 24px, 22px) is declared on `:root` and looks like a mobile scale. The desktop page paints 14px and 16px Trip Geom. Those large shorthands are left in [raw/css-vars.json](raw/css-vars.json) and are not tokens.

`--compButtonDisabledFilledBackgroundColor` is `#b9bec7`. The disabled Continue with email button paints `rgb(206, 210, 217)`. Both are recorded. The painted value is `light.component.button-disabled-filled-background`.

The home search field row border is `rgb(218, 223, 230)`. `--smtcColorBorderDefault` is `#d4d7de`. They are not the same colour.

The footer background is `rgb(245, 247, 250)`. `--smtcColorBgPage` is `#ebedf1`. The hotels body background is `rgb(246, 247, 250)`, which does match `--coreColorNeutral1`.

`--compTabsItemFontSize` is `30px`. The painted product tab label is 500 14px/21px. The token is kept under `light.component` as declared. The painted size is in [components.md](components.md).

Search-button hover `rgb(41, 83, 214)` and header Sign in hover `rgb(44, 89, 229)` come from stylesheet rules, not from a pointer that moved. The preview tab was not producing frames, so a real hover was not confirmed visually.

Trip Geom is proprietary. The tokens name it and fall back to the system stack the page itself uses. The font files are not in this package.

There is no dark theme in the readable stylesheets. `--coreTripBestBrownDark` is one colour token, not a theme switch. Do not invent a dark palette from it.

## Fonts

Trip Geom, weights 400, 500 and 700, is the brand face, loaded as woff2/woff/ttf from Trip's CDN (`homeFont.*.css`, `font-display: swap`). It is proprietary and is not shipped. Tokens use `"Trip Geom", system-ui, -apple-system, Roboto, Helvetica, Arial, sans-serif`, which is the computed `font-family` on `html`. Trip Geom TF is declared as `--coreFontFamilyMono` and was not seen on a measured control. The icon font `fi` is a glyph font, not a text face.

## Do and don't

**Use the brand blue for the one primary action on a search card.** The Search button is `#2c61fe` (`light.color.bg-brand`), white type, weight 700, height 48px on the home card, radius 4px (`core.radius.s`).

**Keep field type at 700 16px Trip Geom.** The destination field and the email field both paint that weight and size, on a 4px radius, with a 1px border.

**Use the cyan support band only for support.** `.onlineCS-headBanner` is `#047c88` (`core.color.cyan6`), with a white 700 48px/68px heading. It is not the page background.

**Do not ship Trip Geom.** Name it, then fall back to the system stack. The files are not licensed for this package.

**Do not treat the 30px `--compTabsItemFontSize` as the painted tab.** The home tabs are 14px medium.

**Do not add a dark theme.** The public pages did not switch one.
