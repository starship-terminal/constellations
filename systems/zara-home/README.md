# Zara Home design reference

A token set for Zara Home's public web storefront (zarahome.com), for building in the style of a square-corner home retailer. It was read on 2026-11-19, signed out, in the T3 preview browser at a measured 1169×731 CSS viewport (devicePixelRatio 2). Surfaces: the worldwide market gate, the International homepage at `/ww/`, the duvet-cover category, one product page, search, and the unavailable page. Nothing was added to the bag, checked out, or submitted. No card, phone, address, or account was entered. The newsletter link was not followed.

Zara Home paints one light theme. Ink is #1e1e1e. Type is ZH-Sans, one family at several weights, tracking 0.2px. Corners on storefront controls are square. The filled button is ink on white type, uppercase, 12px, weight 600.

### Principles

1. Do keep ink at #1e1e1e.
2. Do set every role in ZH-Sans.
3. Do keep corners square.
4. Do track 0.2px.
5. Do keep the filled button small and uppercase.
6. Don't invent a dark theme.
7. Don't paint sale red onto a price that was ink.

## How the values were read

Everything was read from the live page in the T3 preview browser, signed out, with `getComputedStyle` and the page's own custom properties.

- Front version `2.11.18` from `window.inditex.iFrontVersion`. Angular `22.1.5` from `zh-root`.
- House colours are `--primary-color` #1e1e1e, `--primary-darker-color` #8e8e93, `--footer-v2-focus` #2684ff, `--footer-v2-rule` #d8d8dc. Material also declares `--warn-color` #b32624 and `--accent-lighter-color` #cf0a2c. Those last two were not the fill of a measured storefront button or price.
- `tools/build_tokens.py` writes tokens.json from [raw/readings.json](raw/readings.json). `tools/build_style_guide.py` and `tools/build_components_md.py` write the guide and the inventory. The inventory's text, values included, was typed into `build_components_md.py` at capture time from the same readings; it does not read raw/, so a recapture must update that text by hand.

## What to distrust

- The viewport is 1169×731, the size the preview pane actually had. It is not a 1440 or 390 capture.
- [screenshots/specimen-light-default.png](screenshots/specimen-light-default.png) is a local render of the style guide, not a capture of zarahome.com. `preview_snapshot` returned "The browser is not producing screenshot frames". A headless Playwright load of `https://www.zarahome.com/ww/` returned HTTP 403 Access Denied (Akamai). Those images were not kept.
- Homepage header text is white because it sits on a photo. The same header is white-filled with ink text on the category page. A token that always paints the header white will be wrong on the homepage.
- Button hover (#3a3a3c) and the focus outline (#2684ff) come from stylesheet rules. They were not hovered or focused live.
- SUBSCRIBE ME computed `border: 0`. The authored custom property `--footer-cta-border` is `1px solid currentColor`. The token does not invent the border onto the control.
- The chat control's radius is `100%`. That percentage is not a dimension token.
- `--mat-button-filled-container-color` is #b32624. The measured GO, CHOOSE A SIZE and dialog primary buttons were #1e1e1e.
- The market dialog's button label computed weight 300 while the button itself computed weight 600.

## Fonts

**ZH-Sans** is the only UI face, weights 100 through 700, files `ZaraAPPSans-*.woff2` from `static.zarahome.net` (`zhfont.css`). The computed stack is ZH-Sans, Arial, "Lucida Sans Unicode", sans-serif. It is proprietary. The tokens name it and fall back to Arial. The font files are not committed. Weights 300 and 400 were the ones `document.fonts` reported as loaded.

## Do and don't

1. **Do keep ink at #1e1e1e.** Filled buttons, prices, footer headings and category text use that ink. Body text on some Material nodes is `rgba(0, 0, 0, 0.87)`. Pure black is the page body colour and the market switch, not the button fill. See [raw/readings.json](raw/readings.json).
2. **Do set every role in ZH-Sans.** There is no second family. Product titles are 22px weight 600 uppercase. Prices on the product page are 18px weight 600. Footer links drop to weight 300. See [style-guide.html](style-guide.html).
3. **Do keep corners square.** Buttons, the search field, cards, swatches and the dialog are `border-radius: 0`. The OneTrust Allow All button is 2px, and a round chat control is the exception. See [components.md](components.md).
4. **Do track 0.2px.** Body, buttons, prices and footer headings share that tracking. A button with no tracking looks wrong. See [components.md](components.md).
5. **Do keep the filled button small and uppercase.** 12px, weight 600, 36px tall, 16px of horizontal padding. The dialog button grows to 40px. ADD on a photo is a translucent white bar, not the filled button. See [patterns.md](patterns.md).
6. **Don't invent a dark theme.** The public pages did not show one.
7. **Don't paint sale red onto a price that was ink.** `--accent-lighter-color` is #cf0a2c and `--warn-color` is #b32624. Neither was the colour of a measured price or GO button.
