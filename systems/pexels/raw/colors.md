# Colour readings

Read 2026-11-19 from the live CSSStyleSheet on https://www.pexels.com/.

The theme block `[data-mode="light"], body` declares the light greyscale and the named inks. `[data-mode="dark"]` swaps the greyscale and keeps the named inks. The page on screen had no `data-mode` attribute, so the light block applied. Dark values below are declared, not painted on the captured pages.
