# Excalidraw design reference

A token set and component reference for Excalidraw's public signed-out editor, for building a whiteboard, canvas tool or floating-chrome app in the style of the most-used open-source drawing tool. It was read on 2026-11-14, signed out, in headless Chromium at 1440 × 900 and 390 × 844, on the single surface **excalidraw.com** serves: the editor at `/`. The look is quiet and hand-drawn: a white canvas under floating translucent "Islands", Assistant UI text, the Excalifont hand-drawn wordmark, 36px tool buttons in a 44px island, and one signature violet (`#6965db`, `#a8a5ff` in dark) used for the active tool, checked options and every primary action.

Excalidraw is fully usable without an account — the whole captured surface is the product. What an account adds (Excalidraw+, cloud library, collaboration, billing) was never reached, and nothing was drawn, saved, exported, shared or generated: Open, Save to…, the export PNG/SVG/Copy actions, Live collaboration, Share, the AI tools, Reset the canvas and every Sign up were measured, never pressed. The only presses were local UI toggles: tool buttons, the hamburger, menus, the Theme radio, panels and dialog close buttons.

### Principles

1. Do let the declared vars carry the design.
2. Do spend the violet on state and action.
3. Do float chrome in Islands.
4. Do keep controls small and square.
5. Do write hints in the keybinding gray.
6. Do draw focus as a shadow ring.
7. Don't style Excalidraw+ or collaboration from this package.
8. Don't fabricate the canvas.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## Do and don't

1. **Do let the declared vars carry the design.** The product ships its token layer on `.excalidraw`: use the `color.*` roles and `control.*` component vars rather than restating hex; dark rebinds the same names under `.theme--dark`. See [tokens.json](tokens.json) and the same chrome under [dark](screenshots/editor-dark-editor.png).
2. **Do spend the violet on state and action.** `#6965db` (light) / `#a8a5ff` (dark) marks the active tool, checked options, switches-on and every primary action; surfaces stay neutral. See [tool-rect](components/crops/tool-rect-pressed.png) and [export-png](components/crops/export-png-default.png).
3. **Do float chrome in Islands.** Every control surface is a `control.island.bg` card at `radius.lg` (8px) under `shadow.island` over the bare canvas — never bars or frames. See [tool-island](components/crops/tool-island-default.png).
4. **Do keep controls small and square.** 36px buttons at `radius.md` (6px), 32px menu rows, 22px swatch wells; the only big radii are pills and switches going fully round. See [menu-item](components/crops/menu-item-default.png) and [canvas-swatch](components/crops/canvas-swatch-default.png).
5. **Do write hints in the keybinding gray.** Shortcut hints, placeholders and secondary text are `color.keybinding`, not a second text colour. See [menu-item](components/crops/menu-item-hover.png).
6. **Do draw focus as a shadow ring.** Focused controls gain a brand-coloured glow, not an outline; only the occasional button draws a 1px auto outline. See [tool-rect](components/crops/tool-rect-focus-visible.png).
7. **Don't style Excalidraw+ or collaboration from this package.** The account surfaces were never reached — the signup prompts visible in [the menu](screenshots/editor-light-menu.png) are where the evidence stops.
8. **Don't fabricate the canvas.** Nothing was drawn: element rendering, selection chrome, context menus and text editing are uncaptured — the package covers the empty-canvas shell in [editor](screenshots/editor-light-editor.png).

## Known gaps

- `lib-empty` (Library empty state): the 2026-11-13 reading is the "Browse libraries" block, not the empty-state text; its selector's `.sidebar div` matching /libraries/ caught the wrong element. Needs a recapture. `measure.mjs` now selects the empty-state text only; it was edited, not run.
- `undo-btn`, `redo-btn`, `theme-choice` and `export-switch`: keyboard focus never reached them, so their `focus-visible` readings are the element at rest: components.md leaves them out and `raw/measurements.md` shows them as Skipped. Needs a recapture; `measure.mjs` now records such a state as skipped (edited, not run).
- `core.font.family.mono` (`"Cascadia", ui-monospace, monospace`) was entered by hand at capture time: no measured element computes it and `raw/css-vars.json` has no `@font-face` for Cascadia. Its source says so.
- **Automation was masked during capture.** Until 2026-11-20, `tools/capture/public/lib.mjs` hid `navigator.webdriver` in every page it opened, so every committed reading was taken with that mask. The mask is removed (a bot check is now recorded as a boundary, not bypassed); whether any page needed it to load is not known, and a recapture without it is the check.
