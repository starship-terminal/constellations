## How the values were read

The T3 preview browser opened `https://www.ubereats.com/` with `reuseExistingTab` false. `preview_evaluate` read `getComputedStyle` on the document element and on visible controls. The same tab then navigated to `/promo`, `/location` and `/near-me`. Custom properties were read from the live CSSOM (3217 declared names, including Tailwind `--tw-*` mirrors). Component values that are not a custom property (the black pill, the `#f6f6f6` pill, the 52 px hero, the peach location band) were read from the element that showed them.

Nothing was dismissed, because no cookie banner was in the DOM. No address was typed. No login, signup, checkout, gift card, merchant or courier form was opened. Auth links point at `auth.uber.com` and were left alone.

`preview_snapshot` failed twice with "The browser is not producing screenshot frames". Headless Playwright was not started. The page had already loaded in the preview browser without a Cloudflare challenge, but the task says to keep the measurements and not invent screenshots.

## What to distrust

The body colour on screen is `rgb(17, 17, 17)`. The token `--contentPrimary` resolves to `#000000`. Both are recorded. Primary button text is `rgb(252, 252, 252)`, while `--brandContentOnPrimary` is `#ffffff`.

The search field's computed `font-family` is `Arial`. The page's declared body family is UberMoveText. The input has not picked up the page font. The token for UI type stays UberMoveText. The input's Arial reading is in [raw/computed.json](raw/computed.json).

`--base-corner-radius-full` is `1000px`. Visible pills computed to `500px` or `9999px`. Both are recorded. The hero is 52 px / 64 px and is not one of the `--base-typography-headline-*` steps (those stop at 28 px / 32 px).

Dark ramp names (`--gray50Dark`, `--blue600Dark`, and the rest) exist in the stylesheet. The live page never switched to dark, so there is no dark semantic set. Do not treat those ramp names as a captured dark theme.

The `$0 Delivery Fee` link is `rgb(252, 252, 252)` on a parent whose fill was not isolated. Its parent colour is a gap.

No screenshot exists, so a crop cannot prove a value. The evidence is the computed style, not a picture.

## Fonts

UberMove is the display family. UberMoveText is the UI family. UberMoveMono is declared and was not seen on these pages. The stacks fall back to `system-ui, "Helvetica Neue", Helvetica, Arial, sans-serif`. The families are Uber's, and they are not committed here. Tokens name the stack the page computed.

## Do and don't

- **Use black for the primary action and gray for the secondary one.** Sign up and Search are `rgb(17, 17, 17)` with `rgb(252, 252, 252)` type. Log in, Get a ride and Find restaurants are `rgb(246, 246, 246)` with `rgb(17, 17, 17)` type. The blue brand token `#276ef1` is in the stylesheet and was not the fill of those buttons. Evidence is the computed style in [raw/computed.json](raw/computed.json), because this capture has no screenshot.
- **Keep the address field a white pill.** On the home page the shell is 540 by 48, radius 32 px, white, with a 48 px black circular search button. On `/location` the same job is an 8 px white field beside an 8 px black Find Food button, on a `rgb(250, 146, 105)` band. See [raw/computed.json](raw/computed.json).
- **Set display type in UberMove and UI type in UberMoveText.** The hero is UberMove 52 / 64 / 700. Buttons are UberMoveText 14 or 16 / 500. See [raw/computed.json](raw/computed.json).
- **Leave the dark ramp names unused until a live dark page is measured.** `--gray50Dark` and the other `*Dark` names are declared. The signed-out pages stayed `data-theme="light"`. See [raw/computed.json](raw/computed.json).
- **Read computed styles when a screenshot is missing.** This package has none. The preview browser returned "The browser is not producing screenshot frames". See [raw/computed.json](raw/computed.json).
