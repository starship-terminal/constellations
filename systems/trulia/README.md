# Trulia design reference

A token set for Trulia's public signed-out homepage. Read from https://www.trulia.com/ on 2026-11-19 in the T3 preview browser, signed out, CSS viewport 1169 by 731 at device pixel ratio 2. The page title was "Trulia: Real Estate Listings, Homes For Sale, Housing Data". No account was created, no agent was contacted, and no phone number was entered.

Trulia paints a white page in Figtree, grey-900 ink (`#3b4144`), and a teal action (`#007882`, the declared `--colors-primary-dark` / tarzana-700). The homepage custom properties are a Panda set (`--made-with-panda`). Neighborhood names (tarzana, belmont, oakmore, lexington) name the colour ramps. One light theme was painted. `prefers-color-scheme` was dark and the page stayed light. No theme control was found.

The capture stopped after the homepage. A navigation to https://www.trulia.com/GA/Atlanta/ returned a PerimeterX wall ("Access to this page has been denied", "Press & Hold to confirm you are a human"). Reloading the homepage and opening a new preview tab returned the same wall. A headless Chromium GET returned HTTP 403 and was not used for measurements. The preview browser also reported that it was not producing screenshot frames, so this package has no screenshots and no crops.

## How the values were read

Computed styles were read in the live preview page with `getComputedStyle` on `document.documentElement`, `body`, and the homepage controls (header, nav links, sign-in button, h1, hero tabs, search combobox, primary CTAs, footer links). Custom properties were read both from the CSSOM rules of the same-origin sheet `81431547e68182d9.css` (2541 rules) and from the computed style on the root. Colours in tokens are the computed `rgb()` values converted to hex. Declared aliases such as `--borders-default: 1px solid var(--colors-grey-400)` are noted in the raw file. Nothing was sampled from a screenshot.

## What to distrust

- **No screenshots.** The preview browser returned "The browser is not producing screenshot frames." Do not treat the style guide as a capture of the page.
- **Viewport is 1169 by 731**, the preview tab's fill size. It is not a 1440 or 390 capture.
- **`--colors-primary` (`#00adbb`) is declared. The painted primary button uses `--colors-primary-dark` (`#007882`).** Using the lighter step as the action colour would miss the homepage.
- **Muted text (`#6b7780`) is a declared ramp step**, not a colour isolated on a painted homepage string. Body and footer links used grey-900.
- **Mega, jumbo, and small type sizes are custom properties.** No homepage element was measured at 68px, 50px, or 14px.
- **`--focus-shadow` is declared and was not seen on a focused control.** Focus, hover, and pressed states were not measured.
- **A second search combobox used grey-50 fill.** Which one is the hero field was not isolated.
- **Listing, neighborhood, mortgage, and sign-in surfaces are absent.** PerimeterX blocked them. Do not invent their layout.
- **Figtree files are not shipped.** The style guide falls back to Arial.

## Fonts

Figtree, weights 400, 700, and 900, served as woff2 from `www.trulia.com` (`d9fef5bf2f64cf9a-s.woff2` and `de42cfb9a3b980ae-s.p.woff2`). `Figtree Fallback` is `local("Arial")`. The family is named in the tokens. The font files are not in this package.

## Coverage

- **Captured:** signed-out homepage custom properties, body type, header, nav links, sign-in button at rest, hero headline, Buy/Rent/Sold tabs at rest, search field at rest, city-card title, primary CTAs at rest, footer caption links, legal type. Light theme only. Width 1169.
- **Not captured:** screenshots and crops (no screenshot frames). 1440 and 390 widths. Dark theme (none found). Hover, focus-visible, pressed, disabled, error. Sign-in dialog (not opened). Listing results and listing detail (PerimeterX on `/GA/Atlanta/`). Neighborhoods, mortgage calculators, help center. Saved Homes and Saved Searches. Any form submit, phone, or agent contact.

## Do and don't

1. **Do paint the page white and the ink grey-900.** Body text is `#3b4144` on `#ffffff` ([tokens.json](tokens.json)).
2. **Do use tarzana-700 for the action, not tarzana-500.** Find a home is `#007882` with white text, 8px radius, 8px 16px padding, 42px tall.
3. **Do keep controls at 8px radius.** Nav, sign-in, hero tabs, search, and primary buttons all computed `border-radius: 8px`. The token scale also has 2px and 16px.
4. **Do set the hero headline in Figtree 900 at 28px.** The h1 is white on the photograph, line-height 1.14, letter-spacing -0.1px.
5. **Do leave the search empty in any recreation of this capture.** The field was measured, not submitted.
6. **Don't style a listing, a map, or a sign-in form from this package.** Those pages were not measured. `/GA/Atlanta/` returned a PerimeterX wall.
7. **Don't invent a dark theme.** The page stayed light while the browser preferred dark, and no theme control was found.
8. **Don't ship the wordmark or the Figtree files.** The logo is Trulia's. The tokens name the family and the fallback.
