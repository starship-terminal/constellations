# Uniqlo

Hand copy of the measured homepage and wall tokens. Not written by `make design-md`. That command needs a catalog.json entry, and this pass does not edit catalog.json. Take values from [tokens.json](tokens.json).

## Color

| Role | Value |

| text | #000000 |
| muted | #767676 |
| red | #ee0000 |
| on-red | #ffffff |
| ink | #000000 |
| on-ink | #ffffff |
| field | #ffffff |
| field-border | #1b1b1b |

| focus | #005db5 |

## Type

UI family: Segoe UI, Helvetica Neue, Helvetica, Arial. Body 16px. Files are not in this package.

## Radius

Search and the login pill are 999px. Fields and the promo strip are 0px.

## Size

Header 64px. Search 38px. Login and register controls 52px. Fields and the promo strip 44px.
