### Principles

1. Keep the page near-black and the type white.
2. Use pills for actions.
3. Paint the filled header action as a white wash, not the blue gradient.
4. Treat the auth card as its own light surface.
5. Leave the focus ring unpainted when matching this page.
6. Do not invent a signed-in thread.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The page was opened in the T3 Code preview browser (`preview_open` with `reuseExistingTab` false, tab left on `https://www.meta.ai/`). `preview_evaluate` read `getComputedStyle` on `documentElement`, `body`, and the controls named in [components.md](components.md). Stylesheets were readable in that tab (25 sheets, 0 cross-origin errors), including eight `prefers-reduced-motion` rules.

A request with curl to `https://www.meta.ai/` returned HTTP 403. Headless Playwright was not launched against that host.

`preview_snapshot` was called four times. Each call returned: "The browser is not producing screenshot frames." `screencapture` of the T3 Code window returned "could not create image from window." So this package has computed styles and no page screenshots.

Viewport checks: after `preview_resize` to 1440 by 900, `innerWidth` was 1440, `innerHeight` 900, `devicePixelRatio` 2, `visualViewport.scale` 1. After resize to 390 by 844, `innerWidth` was 390, `innerHeight` 844, `devicePixelRatio` 2, scale 1.

## What to distrust

- There are no screenshots. Do not treat [style-guide.html](style-guide.html) as a picture of the product. It redraws measured values.
- The focus outline colour is `#1793ff`, and `outline-style` is `none`, so the ring is not painted. The token records the colour that was computed, not a visible ring.
- `--accent` is `#0064d4`. The painted link and focus colour is `--accent-dark` `#1793ff`. The catalog accent swatch uses the painted one.
- `--btn-primary-bg` and `--btn-destructive-bg` are declared gradients. They were not painted on the signed-out page. The header's filled pill is the translucent Download app button.
- Light tokens are the auth card, not a light theme of the assistant. The product page had class `dark` and no toggle.
- `optimisticMono` is declared in `@font-face` and `document.fonts.check` returned false for it on this page. Body text used `optimisticAI`, which did load (weights 400 and 600).
- The first full custom-property dump was truncated at 180 characters for long values. Tokens use the complete readings from a later evaluate. [raw/computed-root.json](raw/computed-root.json) marks which values were replaced.
- Demo chat bubbles and product prices on the marketing page are published page copy, not a user thread.

## Fonts

`optimisticAI` is the product face, loaded from a woff2 on `www.meta.ai` (`OptimisticAI_VF_Optimized`). Computed stack on body: `optimisticAI, optimisticAI Fallback, Optimistic, system-ui, sans-serif`. The auth card uses `Optimistic` for headings and fields, and `system-ui` on the page chrome.

These faces are Meta's. They are not committed. The tokens name them and fall back to `system-ui` and `ui-monospace`. `optimisticMono` and `optimisticMonoCode` are declared and were not loaded on the signed-out page.

## Do and don't

- **Keep the page near-black and the type white.** The signed-out assistant uses `#181819` for the page and the sidebar, and `#ffffff` for headings and controls. See [components.md](components.md).
- **Use pills for actions.** Header, section, and sidebar actions computed `border-radius: 9999px`. The composer is the exception, at 32 px, and the auth card uses 16 px.
- **Paint the filled header action as a white wash, not the blue gradient.** Download app computed `rgba(255, 255, 255, 0.12)`. `--btn-primary-bg` was declared and not used on this surface.
- **Treat the auth card as its own light surface.** It is white, Optimistic, 16 px radius, and it does not reuse the assistant's dark tokens. See [patterns.md](patterns.md).
- **Leave the focus ring unpainted when matching this page.** Focus computed outline colour `#1793ff` and outline-style `none`.
- **Do not invent a signed-in thread.** The chat bubbles on the page are marketing demos. This capture did not send a message.

## Rebuild

From the package directory:

```bash
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/build_components_md.py
```

`build_tokens.py` in this package checks that [tokens.json](tokens.json) still matches [raw/computed-root.json](raw/computed-root.json) for the semantic colours. It does not browse the site. None of the three scripts writes a file. [tokens.json](tokens.json), [style-guide.html](style-guide.html) and [components.md](components.md) are written by hand from the readings; `build_style_guide.py` and `build_components_md.py` only check that their file still names the measured values. After a recapture, update all three by hand. Re-reading the live page needs the T3 preview browser. Do not point headless Playwright at `www.meta.ai` while curl returns 403.
