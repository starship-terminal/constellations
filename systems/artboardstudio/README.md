# Artboard Studio design reference

A token set and component reference for Artboard Studio's public marketing site (https://artboard.studio), a Webflow + Relume site selling an online mockup generator. Use it to build a marketing or library surface that borrows its look: a pure-white page, near-black olive ink `#0d1400` on every control and line, Vend Sans display headings (60.8px hero), 42px near-black buttons that lift to `#222` on hover, 8px control radii over 12px cards, a 50px pill tab bar, a 65px full-width search field, `#f4f3f2` hover fills, and the editor's `#aaff00` brand green kept for highlights. It was captured signed out, in headless Chromium at 1440 x 900 (mobile at 390 x 844) on 2026-11-11.

It holds 18 screenshots across five desktop routes and one phone route — /, /mockup, /figma-mockup, /iphone-mockup, /business-card-mockup — plus transient states (a category tab switched, the library pane mid-scroll, the mobile menu open), and 19 measured components with 50+ states and one crop each. The product itself (the editor on app.artboard.studio, the Figma plugin, downloads) sits behind sign-in and was never reached: the app is recorded as a boundary, and nothing here claims its functionality. One capture note: the mockup library and category grids scroll inside an inner `.container-category-pages` pane, so document-level full-page shots only cover the first viewport — mid-scroll frames are kept as separate `-scrolled` shots (see [components.md](components.md) > Gaps).

This package contains no Artboard Studio code, and none of its artwork has been redrawn. The screenshots, mockup imagery and visual system they show belong to Artboard Studio ([docs/RIGHTS.md](../../docs/RIGHTS.md)). Borrow structure and proportions, not the logo, artwork or brand assets.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export artboardstudio` prints them all with aliases resolved.

### Principles

1. Do keep the surface white and the ink olive-black.
2. Do use near-black for primary actions.
3. Do pair Vend Sans headings with a system UI stack.
4. Do radius by scale: 8 controls, 12 cards.
5. Do mute hovers with warmth.
6. Don't ship the marketing style as the app.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

- Every component was located on the live page by [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) in headless Chromium: Webflow ships semantic class names, so selectors key off `.button.is-link`, `.tab-button.w-tab-link`, `.heading-*`, `.w-nav-button`, `.div-block-19.w-dyn-item`, `.footer` and stable text. Computed styles were read per state — default, hover, focus-visible, pressed (forced via `CSS.forcePseudoState`), focused on the field, selected/opened on the tab and menu — and one 2x crop saved per state.
- CSS custom properties were read from the live stylesheets by [tools/capture/vars.mjs](tools/capture/vars.mjs) into [raw/css-vars.json](raw/css-vars.json): the Webflow bundle declares ~95 `:root` names (the Relume `--color-scheme-*` slots, `--base-color-neutral-*`, the `--mg-*` editor palette, generic font stacks, misc palette hexes), resolved in a probe document at 1440 x 900.
- Screenshots were taken on the same pages by [tools/capture/public/public.mjs](tools/capture/public/public.mjs), quantised to 256 colours by [tools/capture/quantize.py](tools/capture/quantize.py). Full pages taller than one GPU texture were stitched from `.partN` tiles; the library/category pages scroll inside `.container-category-pages` (the document stays at viewport height), so their extra content is captured as `-scrolled` viewport shots instead of a `-full`.
- No consent overlay appeared on the captured routes; the Brevo chat widget vars are binned as vendor in css-vars.json and nothing embedded was interacted with.

## What to distrust

- **Readings past a masked bot signal.** The committed screenshots and readings were taken with `navigator.webdriver` masked, the flag bot checks read to spot automation. The capture scripts no longer mask it (not run since), so a recapture may record a walled route as a boundary instead of a reading.
- **The editor is absent.** Signup and every editor link lead behind an account; no canvas, plugin UI or download surface is in this package — only the marketing site that links to them.
- **Body text is not Vend Sans.** Headings set `"Vend Sans"`; controls, buttons and body copy paint with the generic `--font-sans-serif` stack. Don't set buttons in Vend Sans.
- **The brand green is an editor accent.** `--mg-gree` #aaff00 belongs to the app chrome and the logo, not the marketing CTAs — every measured CTA is near-black `#0d1400`.
- **The focus ring is mostly the browser's.** Most controls show the default 1px `#005fcc` auto outline; the menu button shows the site's own 2px `#4d65ff` ring, recorded as `light.focus-ring`.
- **Scheme classes are washes, not themes.** `.color-scheme-2..10` swap the same five slots for different sections; the site does not bind a dark theme.
- **Screenshots are 256-colour PNGs** — read exact colours from tokens.json or the raw JSON, never from a screenshot pixel.
- **`tab-switched` is not the tab that was selected.** The `:not(.w--current)` locator re-resolved after the toggle, so the `selected` reading is another, still unselected tab. Needs a recapture; the script now pins the tab before the toggle (not run since).

## Fonts

- **Vend Sans** — headings only (hero 60.8px, library title 56px, sections 19.2px), weights 300-700 from Google Fonts (OFL).
- **Generic sans stack** — every control and body line inherits `-apple-system,BlinkMacSystemFont,"Segoe UI",Roboto,...`.
- The tokens name the measured stacks; the style guide renders with system fallbacks.

## Do and don't

- **Do keep the surface white and the ink olive-black.** Page `#ffffff`, ink `#0d1400` — a green-tinted near-black, not pure #000. ([header](components/crops/header-default.png), [hero-title](components/crops/hero-title-default.png))
- **Do use near-black for primary actions.** CTAs, tabs and chips are `#0d1400` fills that lift to `#222` on hover; secondary links are ink text fading to `#aaa`. Don't introduce a coloured CTA — the green is not for buttons. ([plugin-cta](components/crops/plugin-cta-hover.png), [nav-link](components/crops/nav-link-hover.png))
- **Do pair Vend Sans headings with a system UI stack.** Display is 600/700-weight at 19-61px; controls and body stay in the generic sans at 16px. ([hero-title](components/crops/hero-title-default.png), [tab](components/crops/tab-default.png))
- **Do radius by scale: 8 controls, 12 cards.** Buttons and fields are 8px; chips, tiles and cards 12px. Nothing sharper or rounder was measured. ([filter-chip](components/crops/filter-chip-default.png), [mockup-card](components/crops/mockup-card-default.png))
- **Do mute hovers with warmth.** Card rows lift to `#f4f3f2` and text links fade to `#aaa`; no colour shift, no underline. ([lib-card](components/crops/lib-card-hover.png))
- **Don't ship the marketing style as the app.** Nothing here was measured inside the editor; a screen claiming Artboard Studio's canvas from these tokens would be invented. The honest gap is recorded in components.md.
