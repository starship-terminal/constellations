# Discord design reference

A token set and component reference for Discord's public signed-out site (https://discord.com/). Captured on 2026-11-21 in headless Chromium, desktop 1440×900 and phone 390×844. No account was used. Login, register, and identity-provider buttons were photographed as walls and not submitted.

The marketing pages paint a dark blurple field (`#1a2081` on the home body) with white display type in ABC Ginto Discord Nord and UI type in gg sans. The shipped brand name `--blurple` resolves to `#5865f2`. The app's `.theme-dark` and `.theme-light` custom properties were resolved on a probe element. Marketing pages do not bind `.theme-dark`.

This package contains no Discord code, and none of its artwork has been redrawn. The screenshots and the visual system they show belong to Discord ([docs/RIGHTS.md](../../docs/RIGHTS.md)).

## How the values were read

- Custom properties were parsed from the live stylesheets of https://discord.com/ by [tools/capture/vars.mjs](tools/capture/vars.mjs) and resolved on a probe element with no theme class, then with `.theme-light`, `.theme-dark`, `.theme-darker`, and `.visual-refresh`.
- The home page's body background, body font, and h1 computed style were read on the live document at 1440×900. They are in `raw/css-vars.json` under `brand`.
- `<meta name="theme-color">` was `#161cbb`.
- Screenshots were taken by [tools/capture/public/public.mjs](tools/capture/public/public.mjs) and quantised to 256 colours. Read colours from tokens.json, not from the PNGs.
- A colour the probe returned as `color-mix()` or `hsl()` is stored as that string and marked Not captured as sRGB. It was not converted.

## What to distrust

- **The login QR code is painted out.** The desktop login shot covers the QR tile with the card colour `rgb(36, 36, 41)`. The code was not scanned. The phone login shot has no QR panel.
- **The dark set is a probe, not a marketing page.** `.theme-dark` values come from the stylesheet applied to a probe element. The login wall paints a dark shell and was photographed. Its role colours were not measured into the dark set.
- **Body type size is Not captured.** Only the body font family was read. Display metrics are the home h1 only.
- **`--radius-round` is a pill sentinel.** The stylesheet declares `2147483647px`. The token stores `9999px` and says so.
- **Screenshots are 256-colour PNGs.**

## Fonts

- **ABC Ginto Discord Nord** (`Abcgintodiscordnord`): painted on the home h1. A commercial webfont. Not embedded here.
- **gg sans** (`Ggsans`): painted as the body font. Commercial. Not embedded here.
- **gg mono**: declared as `--font-code`. Not measured on a painted code element.
- **ABC Ginto Nord**: declared as `--font-headline`.

## Do and don't

- **Do** set display type in a heavy ginto-nord face, uppercase, with tight line height. The home h1 is 56px on 48px leading. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
- **Do** use blurple `#5865f2` as the brand accent and the home field as `#1a2081`. See the same screenshot.
- **Do** open desktop nav groups as hover menus, not as new pages. See [screenshots/home-light-menu-discover.png](screenshots/home-light-menu-discover.png).
- **Don't** treat the probe dark tokens as a painted marketing theme. Marketing pages do not bind `.theme-dark`.
- **Don't** follow Log In, register, or an identity provider and call the result this package. Those are walls. See [screenshots/login-dark-wall.png](screenshots/login-dark-wall.png).
