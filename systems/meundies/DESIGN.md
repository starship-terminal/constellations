## Typography

headingNow is the UI face: nav 16px weight 300, body 16px weight 300, LOGIN 14px weight 500, Login heading 40px weight 700. Files are not in this package.

## Geometry

Promo bar 44px. Logo row 66px. Nav row 40px. Wordmark 180 by 34px. LOGIN 44px, radius `9999px`. GOOGLE and FACEBOOK 48px, outline, radius `9999px`. Login fields 42px, pill. Size chips 38 by 61px, radius `4px`. Sale badge 28px, radius `4px`. Login dialog radius `8px`.

## Do and don't

Keep the page cream and the type black. Use lime for the promo and the sale badge. Use ink for the one loud control. Stop at the empty login modal. GOOGLE and FACEBOOK were not clicked. SELECT A SIZE was not clicked.
