# Sora

Sora is OpenAI's video product. On 19 November 2026 the public URL `https://sora.com/` redirected to `https://sora.chatgpt.com/sunset` and rendered one signed-out notice: "Sora is no longer available. ## How the values were read

The T3 preview browser opened `https://sora.com/` with `reuseExistingTab` false. It landed on `https://sora.chatgpt.com/sunset` with no Cloudflare interstitial. `preview_evaluate` read `getComputedStyle` on `body`, `main`, `main p` and `main a`, and read the custom properties on `documentElement` while `html` had class `dark`. The same elements were read again after `classList` removed `dark` and added `light`.

Stylesheets are cross-origin (`sora-cdn.oaistatic.com`), so `cssRules` threw. The three linked sheets were fetched and parsed: `4f834fecb0689d51.css` (Tailwind v3.4.17 and the token blocks), `eda963f33b3839f5.css` (`@font-face` for OpenAI Sans), and `70bad1f4937d2bd7.css` (ReactCrop, not used on this page). Light colours are the `:root` block. Dark colours are the `.dark` block, which overrides `:root`.

`preview_snapshot` failed twice with "The browser is not producing screenshot frames." A headless Playwright load of `https://sora.com/` returned HTTP 403 and the title "Just a moment…". No screenshot was taken. No email, card, phone number or payment was entered. The Export link was not followed.

## What to distrust

The light theme was measured by applying class `light` in the page, which drops the `.dark` overrides and reveals `:root`. The product script picks `localStorage.theme` or else `dark`. This capture did not set `localStorage`, so the light reading is a live class toggle, not a stored preference.

OpenAI Sans is declared in `@font-face` and preloaded. The computed family on every measured element was the system sans stack in `.font-sans`. Do not treat OpenAI Sans as the face the sunset page painted.

A later rule in the same sheet sets `.dark { --sidebar-gap: 0px }`. The computed custom property on the sunset page stayed `21px`. The token keeps 21px. The 0px declaration did not win on the measured element.

Hover, pressed and disabled were not computed. The Export link's class names a hover of `rgb(var(--bg-inverse) / .8)` and a disabled background of `rgb(var(--bg-secondary))`. Those are stylesheet declarations, not computed states. Focus on the Export link computed to a transparent 2px outline with a 2px offset, from `focus-visible:outline-none`.

Sidebar width (196px), sidebar gap (21px) and mobile tab bar height (54px) are declared tokens. They were not painted on the sunset page.

## Fonts

The painted family is the system stack from `.font-sans`: ui-sans-serif, system-ui, -apple-system, Segoe UI, Roboto, Ubuntu, Cantarell, Noto Sans, sans-serif, plus the emoji faces. Those are platform fonts.

OpenAI Sans is declared at weights 400, 500, 600 and 700, normal and italic, from `cdn.openai.com/common/fonts/openai-sans/v2/`. It was not the computed family. The files are not in this package. Tokens fall back to the system stack that was computed.

## Do and don't

- **Paint the sunset page as black with white text in the loaded theme.** The live `html.dark` page computed `background-color: rgb(0, 0, 0)` and `color: rgb(255, 255, 255)`. The secondary line computed `rgba(255, 255, 255, 0.6)`. See [tokens.json](tokens.json) `dark.color.background.primary` and `dark.color.text.secondary`.
- **Use the inverse fill for the Export control.** In dark it computed `background-color: rgb(255, 255, 255)`, `color: rgb(0, 0, 0)`, `border-radius: 12px`, `height: 36px`, `padding: 8px 12px`, weight 600. See [tokens.json](tokens.json) `dark.color.control.button-background`.
- **Keep the system sans stack for this page.** The computed `font-family` was `.font-sans`, not OpenAI Sans. See [tokens.json](tokens.json) `core.font.family.sans`.
