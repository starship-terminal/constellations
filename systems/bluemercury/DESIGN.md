# Bluemercury

Public shop chrome, measured on [https://bluemercury.com](https://bluemercury.com) on 2026-11-22. One theme: light. Desktop only in this pass, 1440 by 900.

## Colour

The page is white, `#ffffff`. Ink is `#1c262e`. The deep-sea accent is `#2f394b`. It fills the 35px promo bar, the selected category chip, and Add to Bag. Type on that fill is white.

Muted grey `#6d7275` is the search underline and the brand name above a product title. Gift Guide is the only department label in link blue, `#0b51c1`. Unselected chips sit on `#f5f5f5`.

## Type

Body, nav, search, price, and buttons use Neue Haas, with Roboto as the fallback. Body is 16px, weight 400. The promo line is 12px, uppercase, letter-spacing 0.7px. Department labels are 16px, letter-spacing 0.8px. Shop Now and Add to Bag are about 15px, uppercase, letter-spacing 0.75px.

Category titles use Juana, a serif, at 50px and weight 300. The product title and the price are Neue Haas at 20px. The brand name above the title is 14px, letter-spacing 0.7px, muted grey, uppercase.

Font files are not in this package.

## Controls

Search is an underline, 450 by 48, radius 0, 1px bottom border, placeholder "What can we help you find?". Shop Now on the hero is a white rectangle, 300 by 63, ink label, radius 0. Add to Bag is deep sea, 60px tall, white label, radius 0. Category chips are 36px tall, radius 0, uppercase 14px. The selected chip is deep sea with white type. The rest are grey with deep-sea type.

The wordmark is an SVG, viewBox `0 0 177 18`, fill `#2F394B`, rendered 236 by 24.

## What this pass did not read

Hover, focus, pressed, disabled, and error states. Dark theme. Phone width. Motion. The open mega menu. Cart, checkout, sign-in, and signup.
