# Asana design reference

A token set and component reference for Asana's public marketing site (https://asana.com), a Next.js site for a work/project-management product. Use it to build a marketing or product surface that borrows its look: a near-white page, near-black ink `#0d0d0d` on headings and `#3d3d3d` body text, Segoe UI throughout, 3px control radii, near-black `#0d0d0d` primary buttons that lift to `#3d3d3d` on hover, `#f3f3f3` panels, `#cfcfcf` hairlines, and a full shipped design token layer — colour ramps (`--black-20..1100`, `--blue-0..980`, `--coral-*`, `--bright-*`), `--lightmode-*` semantic roles, a 16px-base `--spacing-*` scale, `--media-*` breakpoints, 12-column grid, `--shadow-10..40` and `--transition-*` durations. It was captured signed out, in headless Chromium at 1440 x 900 (mobile at 390 x 844) on 2026-11-11.

It holds 19 screenshots across seven routes — /, /pricing, /product/ai, /features, /resources, /sales, /create-account — plus transient states (the nav flyout open, a pricing FAQ open, the mobile menu open), and 21 measured components with 60+ states and one crop each. The product itself (app.asana.com, workspaces, every Launch/Log in/Get started path) sits behind sign-in and was never reached: the app is recorded as a boundary, and nothing here claims its functionality. One capture note: the site ships a full `--darkmode-*` role set in its CSS, but every captured route paints light — the dark set is emitted as declared evidence, not a painted page (see [components.md](components.md) > Gaps).

This package contains no Asana code, and none of its artwork has been redrawn. The screenshots, product imagery and visual system they show belong to Asana ([docs/RIGHTS.md](../../docs/RIGHTS.md)). Borrow structure and proportions, not the logo, artwork or brand assets.

### Principles

The README has no "Do and don't" section, so this package states no principles.

### Using tokens

| Role | light |
|---|---|
| page | #ffffff `light.page` |
| surface | #f3f3f3 `light.surface` |
| text | #3d3d3d `light.text` |
| muted | #6e6e6e `light.muted` |
| accent | #0d0d0d `light.accent` |
| border | #cfcfcf `light.border` |

Fonts: `core.fontFamily.ui` is Segoe UI, then 5 fallbacks. Scales, counted as [DESIGN.md](DESIGN.md) holds them: 5 type styles (`core.typography`), no radius steps under `core.radius`, 13 spacing steps (`core.spacing`).

### Using components

Read [components.md](components.md) for the component inventory; [patterns.md](patterns.md) for how components combine into screens; 80 element crops in [components/crops/](components/crops); [style-guide.html](style-guide.html), which renders every token and the main components.

### Accessibility

| Theme | text on page | text on surface | muted on page | muted on surface |
|---|---|---|---|---|
| light | 10.86:1 pass | 9.78:1 pass | 5.09:1 pass | 4.59:1 pass |

4 of 4 pairs pass 4.5:1 (WCAG AA for body text), the pairs the scorecard's F15 check grades. Not checked, no palette: dark (declared in the shipped CSS, unbound on the captured routes). Focus tokens: `dark.a11y.focus.black` #0d0d0d; `dark.a11y.focus.white` #ffffff; `light.a11y.focus.black` #0d0d0d; `light.a11y.focus.white` #ffffff.
