Palette

--lightmode-* carries every role: bg white and bg-med #f3f3f3, ink text #3d3d3d / text-strong #0d0d0d, button-primary near-black lifting to #3d3d3d, error/success/warning status, a11y-focus-primary #879fc8; the ramps feed them, --darkmode-* mirrors the same roles dark.

Layout metrics

A real scale ships: --spacing-0..10 on a 16px base, --media-xsmall..xxxlarge (480..1920) breakpoints, a 12-column grid with 32px gutters, --zIndex-1..10, --border-radius 3px and four --shadow-* levels.

Type styles

TWK Lausanne (webfont, Helvetica Neue fallback) across the UI; --fontSize-h1..h6 (56..16), --fontSize-xl 82, --fontWeight-300..700, --fontFamily-mono/-print for code and print.
