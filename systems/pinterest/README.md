### Principles

1. Use the Pinterest red for the primary action.
2. Use the warm gray for the secondary action and the search shell.
3. Keep the page white and the footer black.
4. Set display type in Pin Sans at 900 with -0.5px tracking.
5. Leave the signup wall unsubmitted.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Computed styles and `:root` custom properties were read in the T3 preview browser on https://www.pinterest.com/, https://www.pinterest.com/ideas/, and https://policy.pinterest.com/en/privacy-policy. The homepage was read at 1440 by 900 and at 390 by 844 CSS pixels, device pixel ratio 2. Gestalt declared 2713 custom properties on `:root`. Semantic colours were resolved with `getComputedStyle`. The homepage stylesheet `index-858e9ed112257e62.css` was fetched for the brand-module gradient.

`preview_snapshot` returned "The browser is not producing screenshot frames". Measurements already read were kept. [screenshots/home-light-default.png](screenshots/home-light-default.png) is a reconstruction drawn from those measurements, not a photograph of the page. No headless Playwright session was started.

## What to distrust

Hover and pressed reds are declared Gestalt tokens. A live pointer was not placed on a button. The primary button element computed `color: #000000` while `--comp-button-color-text-primary-default` resolved to `#ffffff`. The white label is the token. Focus ring colour is declared and was not forced. The 390px pass still laid out the desktop header past the viewport, so it is not a phone layout. Policy type (84px / #111111) is a different site and is not in the homepage tokens. Placeholder `#757575` is a computed style, not `--sema-color-text-subtle`.

## Fonts

Pin Sans is Pinterest's face, named in `--base-font-family-default-latin` and computed on the body. It is proprietary and is not in this package. The token stack falls back to `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, then `sans-serif`. Code uses the `--base-font-family-code` stack, starting at SF Mono.

## Do and don't

- **Use the Pinterest red for the primary action.** Log in and Join computed `#e60023`, radius 16px, height 48px.
- **Use the warm gray for the secondary action and the search shell.** Sign up and the search shell computed `#e5e5e0`.
- **Keep the page white and the footer black.** Page background computed `#ffffff`. Footer computed `#000000`.
- **Set display type in Pin Sans at 900 with -0.5px tracking.** The homepage hero computed 48px / 900 / -0.5px.
- **Leave the signup wall unsubmitted.** Email, password, birthday, and Google continue were on the page and were not entered.
