# Pinterest design reference

A token set and component reference for Pinterest's public web, read from **www.pinterest.com** on **2026-11-21**, signed out, in headless Chromium at 1440×900 and 390×844. The product surface is the signed-out marketing home, Explore, Shop, one official board, one idea page, Help, and the policy and marketing hosts the homepage links. The signed-in home feed, pin close-up save, and account settings sit behind [https://www.pinterest.com/login/](https://www.pinterest.com/login/). That page asks for an email and a password. Nothing was typed. No form was submitted.

Pinterest's public UI is Gestalt: one red (`#e60023`) for the primary action, a warm gray secondary (`#e5e5e0`), black text, 16px rounded buttons at 48px, and a pill search. The type family is Pin Sans. The site paints light only. Dark values in the token file are declared inverse names, not a theme a visitor can switch.

The control map is [site-tree.md](site-tree.md).

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export pinterest` prints them all with aliases resolved.

### Principles

1. Do use one red for the action that continues.
2. Do round controls 16px and the search pill fully.
3. Do set body in Pin Sans at 16px, headings at 700.
4. Do keep surfaces white and separate cards with radius and a light shadow, not a heavy border.
5. Don't treat the declared dark set as a shipped theme.
6. Don't fill the login dialog.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Custom properties were read with `getComputedStyle` on `:root` of the signed-out homepage. Gestalt declares `--base-color-*` ramps, `--sema-*` semantic names, and `--comp-button-*` component colours. Those resolved values are in [raw/sema.json](raw/sema.json). [tools/build_tokens.py](tools/build_tokens.py) maps the ramps, the space and radius scales, the type roles, and the light semantic colours. Button height (48px) and the header link colour (`rgb(33, 25, 34)`) were read from `getComputedStyle` on the painted elements.

Screenshots were taken with Playwright at a requested 1440×900 (devicePixelRatio 1) and 390×844 (devicePixelRatio 2). Sidecars in the scratch folder recorded `innerWidth`. The committed phone PNGs are 780×1688 physical pixels, which is 390×844 at 2x. Desktop PNGs are 1440 wide.

Auth dialogs that covered Explore and the board were hidden with `display: none` for the `*-page` shots, not dismissed. The dialog itself is kept as `ideas-light-auth-dialog.png`. Google one-tap was blocked on the recapture so it would not paint. The login URL's QR code was not committed.

## What to distrust

- **Dark is declared, not painted.** `dark.background.page` is the inverse black token. The public site does not apply a dark theme. Do not treat it as a shipped dark mode.
- **Hover and focus screenshots match default.** `home-light-join-hover.png` and `home-light-login-focus.png` differ from the default only by carousel motion, not by a control state. Hover and pressed fills in the tokens are stylesheet values, not a painted hover.
- **Brand red is not a step on the red ramp.** `#e60023` is `--base-color-pinterest` and `--sema-color-background-primary`. The red ramp's 400 is `#dd0e0e`.
- **Pin Sans is not in the style guide.** The family is commercial and self-hosted. The guide falls back to the system sans.
- **Screenshots are 256-colour PNGs.** Read colours from tokens.json.
- **Some full pages are truncated.** Business, policy, and several phone pages were capped at 7200 CSS pixels. The phone full-page tiles grew past that and were not committed.
- **Create and Newsroom used a geo path.** This network loaded `create.pinterest.com/en-sg/` and `newsroom.pinterest.com/en-sg/`.
- **Icons are indexed, not extracted.** [icons/INDEX.tsv](icons/INDEX.tsv) records the wordmark and search glyph. The artwork stays inside screenshots.

## Fonts

**Pin Sans** is the family computed on `body`: `"Pin Sans", -apple-system, system-ui, "Segoe UI", Roboto, …`. The page loads weights 400, 500, 700 and 800. It is Pinterest's face and is not committed. Tokens name Pin Sans and fall back to the system sans.

## Do and don't

1. **Do use one red for the action that continues.** `#e60023` (`light.background.accent`) is Log in, Join, and Continue with email. Secondary actions are the warm gray. See [button-primary-default](components/crops/button-primary-default.png) and [home-light-default](screenshots/home-light-default.png).
2. **Do round controls 16px and the search pill fully.** Buttons use `core.radius.400`. Search uses the pill radius. See [search-field-default](components/crops/search-field-default.png).
3. **Do set body in Pin Sans at 16px, headings at 700.** Display goes to 48–72px at weight 900. See [ideas-light-page](screenshots/ideas-light-page.png).
4. **Do keep surfaces white and separate cards with radius and a light shadow, not a heavy border.** See [card-board-default](components/crops/card-board-default.png).
5. **Don't treat the declared dark set as a shipped theme.** The public pages pin light. See [home-light-default](screenshots/home-light-default.png).
6. **Don't fill the login dialog.** It is a wall. See [dialog-login-default](components/crops/dialog-login-default.png).
