# Hulu

Public plan chooser, login wall, Help Center, and press site. Signed out, 2026-11-22. This file copies the measured tokens. It was not written by `make design-md`, because that command needs a catalog.json entry and this pass does not edit catalog.json.

## Type

Graphik Web, Helvetica on the plan chooser. Body 16px / 24px, weight 400. Heading 32px / 40px, weight 600. SELECT is 14px, weight 600.

The login heading is Inspire, 28px / 40px, weight 600.

## Radius

SELECT is a 1000px pill, 48px tall. The email field and the help search are 4px.

## What is not here

No error, warning, or success colour. No named spacing scale. No motion duration. No signed-in player.
