# Unsplash design reference

A token set and component reference for Unsplash's public site. It was read from **https://unsplash.com/** on **2026-11-21**, signed out, in headed Chromium at 1440 x 900 and 390 x 844. Headless Chromium stops on the site's browser check (`/.within.website`, HTTP 401). Headed Chromium clears that check and loads the public pages.

Captured: home (menu, search focus, visual-search dialog), illustrations, explore, a topic grid, a photo page, Unsplash+, about, license, developers, the images landing, the awards winners page, and the login page with empty fields. Phone width: home, menu, search focus, a photo page, and login.

The public system is a white page, `#111111` text, a `#f5f5f5` search pill, gray `#767676` secondary labels, and one black button. A `.dark` class exists in the CSS and is not applied on these pages.

## How the values were read

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) opened home, plus, about, login, and developers in headed Chromium, parsed stylesheet responses plus inline sheets, and wrote [raw/css-vars.json](raw/css-vars.json). [tools/build_tokens.py](tools/build_tokens.py) keeps the `:root` palette and the `.light` semantic names.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) read computed styles and cropped each control. Hover is a real pointer. Pressed is CDP `forcePseudoState`, so no button submitted. Email and password were not typed.
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) wrote full-colour shots under `~/.design-systems/unsplash/raw-shots`. [tools/capture/quantize.py](tools/capture/quantize.py) stored 256-colour copies in [screenshots/](screenshots).
- **Consent.** The OneTrust dialog was hidden with CSS and never clicked.

## What to distrust

- **Dark is declared, not painted.** `--background-color` and `--text-color` on `.dark` were not applied. They are not in `tokens.json`.
- **Search and photo radii.** The search pill is visibly rounder than the 8px button token. That radius was not a custom property on the measured input. It is not a token.
- **Photo-card crop.** The first `/photos/` link's box was a caption line, not the image. Use the page screenshots for the grid.
- **Login is a wall.** The fields are empty on purpose. Do not treat the page as a completed form.
- **Screenshots are 256-colour.** Read colours from `tokens.json`.
- **No catalog entry.** This capture was told not to edit `catalog.json`. `make check` will report the missing entry until a later commit adds it.

## Fonts

The public pages compute `ui-sans-serif, system-ui, sans-serif` on the body. No webfont family was loaded on the home page (`document.fonts` was empty). The developers page computes a longer system stack (`-apple-system`, Helvetica Neue, Helvetica, and others). The tokens use the home stack.

## Do and don't

1. **Do keep the page white and the ink near-black.** `#ffffff` and `#111111` do almost all of the work. See [home-light-default](screenshots/home-light-default.png).
2. **Do put search in a gray pill.** The field sits on `#f5f5f5`, not on a bordered box. See [home-light-default](screenshots/home-light-default.png).
3. **Do use one black button for the commit action.** Login and Get Unsplash+ are `#111111` with white type and an 8px radius. See [login-submit-default](components/crops/login-submit-default.png).
4. **Do keep secondary actions quiet.** Submit an image is a white chip with gray type. Log in is a gray label until hover. See [submit-button-default](components/crops/submit-button-default.png).
5. **Don't ship the `.dark` class as a dark theme.** The public pages never apply it.
6. **Don't invent a second accent.** Blue, green, and red exist as status tokens. The UI chrome stays black, white, and gray.

## Rebuild

```sh
cd systems/unsplash
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  node tools/capture/vars.mjs
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  node tools/capture/public/public.mjs
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  node tools/capture/public/measure.mjs
python3 tools/capture/quantize.py ~/.design-systems/unsplash/raw-shots
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
```

Headed Chromium is required. Headless stops on the browser check.
