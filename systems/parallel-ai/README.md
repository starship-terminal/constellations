# Parallel

Parallel is the web infrastructure product at [parallel.ai](https://parallel.ai/). This package records the public marketing site, the public pricing page, the signed-out login at platform.parallel.ai, and the public docs at docs.parallel.ai. Captured 2026-11-19 from an attached preview browser. No account was created. No card was entered.

Desktop CSS viewport was 1169x731 at devicePixelRatio 2. Phone type was computed at 390x844. The marketing pages are light. The login page loaded with `dark` on `html`. Screenshots were not saved: `preview_snapshot` returned "The browser is not producing screenshot frames."

## How the values were read

The attached T3 preview browser loaded `https://parallel.ai/`, `https://parallel.ai/pricing`, `https://platform.parallel.ai/login?redirectTo=%2F`, and `https://docs.parallel.ai/getting-started/overview`. Computed styles were read with `getComputedStyle` on those pages. Custom properties were read from the resolved style on `:root`.

The marketing LOG IN button is the painted orange control. Its background is `rgb(251, 99, 27)`, which matches `--color-brand`. A stylesheet also declares `--brand: #ff590a`. That orange was not the painted button, so it is not a token.

The login page has an email field, Continue with Google, and Continue with SSO. The email form was not submitted. Google and SSO were not clicked. Pricing upgrade, contact sales, and Get API Key were not opened.

## What to distrust

`--brand` `#ff590a` is in a stylesheet and is not the painted brand. `--color-brand` `#fb631b` is the button. Do not mix them.

The login font computed as `sansSerifFont, "sansSerifFont Fallback"`. The next family name was not in that string. The docs h1 computed as Inter while the docs body computed as Gerstner Programm. Both are recorded. Neither was substituted.

Hover fill `#f4793f` is the resolved `--color-brand-hover`. The LOG IN class includes `hover:bg-brand-hover`. A synthetic mouseover did not change the computed background, so the hover paint was not held.

`--color-error-100` and `--color-success-100` are declared. No error or success control was on screen.

The dark token set is the login shell, which loads with class `dark`. The marketing site did not offer a theme switch. Calling that set a dark theme of the marketing page would overstate what was on screen.

No screenshot exists. The preview browser said it was not producing screenshot frames. Do not treat a missing image as a blank page.

## Fonts

Gerstner Programm is the resolved marketing family, with a fallback named gerstnerProgramm Fallback, then sans-serif. FT System Mono is the marketing nav, button, and badge family, with ftSystemMono Fallback, then monospace. Both are loaded by the site. This package does not include the font files.

The login UI resolved to sansSerifFont. The docs body resolved to Gerstner Programm with system fallbacks. The docs h1 resolved to Inter.

## Do and don't

- **Do use Gerstner Programm for marketing headings and FT System Mono for buttons.** The h1 is 36px weight 500 at 1169px. LOG IN is 13px mono, uppercase, letter-spacing 0.16px.
- **Do use `#fb631b` for the brand button.** That is the painted LOG IN and START BUILDING fill, with a white label, 4px radius, and 34px height.
- **Do keep the login shell separate.** It is a dark page (`#18181b`) with 40px, 6px-radius controls. Continue with email is white on that shell. The orange brand button is the marketing control.
- **Do not use `#ff590a` as the brand.** It is a stylesheet variable. The painted button is `#fb631b`.
- **Do not invent screenshots or a signed-in app.** The frame capture failed, and the email form was not submitted.
