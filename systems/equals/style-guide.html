Palette

core.color.brand is the marketing scale (the cream and black neutrals plus the nine accent hues), core.color.app the sign-in app's Tailwind-style ramps, core.color.docs the Mintlify greys and primaries. The light set carries the measured marketing.*/signin.*/docs.* roles — each aliases the declared token it matches — and the dark set the docs' dark roles. Flip the page's dark-mode class to compare the docs roles.

Metrics and radius

Marketing CTAs and fields are 60px pills (52-56px tall), the plan/menu/mockup radius is 12px, the sign-in controls 8px and the docs search a 9999px pill. The declared --spacing base is 4px; breakpoints are the declared @media widths of the public sheets.
