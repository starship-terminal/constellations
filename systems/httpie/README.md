# HTTPie design reference

A token set and component reference for HTTPie's signed-out surfaces — for building an API-client product, developer marketing pages and documentation surfaces in the style of the real thing. It was read from **httpie.io** on **2026-11-17**, signed out, in headless Chromium at 1440 x 900 and 390 x 844 (mobile at 2x). Captured: every public route — /, /desktop, /cli, /ai, /docs (+/docs/desktop, /docs/cli), /jobs, /blog and a changelog post, /download, /about, /terms, /privacy, /pricing (which 404s and is kept as the product's not-found page) — plus **/app**, the HTTPie-for-Web client that runs signed out in its "Incognito space" — in the painted **dark** theme the site boots, with verified light repaints on home, desktop, cli, ai, docs-desktop, jobs, blog, blog-post, download and /app; the method menu, the request panel tabs, the environments manager, the Incognito-space tab and the first-run "Introducing HTTPie AI" dialog as transient states; plus 390px passes on home, cli, blog, docs-desktop and /app.

httpie.io is worth a capture because it pairs a compact hand-written token layer with a real unsigned product surface. The sheets declare the **`--color-*` roles on `:root`, re-pointed under `.dark:root`**: the `bg-z0..z3` surface stack (light warm paper → white; dark warm near-black → raised), `primary`/`inverted-primary`/`secondary`/`tertiary`/`placeholders` ink, the `accent`/`hover` green (**#52ab66** light / **#73dc8c** dark), the `alt-accent(-hover)` blue (**#698feb** / **#3b5eba**), `warning(-hover)` red (**#c7382e** / **#ff665b**), `focus`, `borders(-subtle)`, `header-hover`, `item-hover`/`-selected(-hover)`, `selection`, `draggable`/`droppable`, `backdrop`, `shadows` and the ten-colour `code-*` syntax palette — plus the app-local `--app-cursor*` and VariablesTable `--cell-*` names. Everything else is literal rgb() on an old-Tailwind + CSS Modules stack, harvested into `core.palette.*` (the warm darks and off-whites, the brand blues and greens, the pink hover border). The architecture: every page boots **html.dark** — AUTO follows prefers-color-scheme and headless Chromium's light preference still resolves dark, the product's painted default — and the footer's own **ThemeToggle radio stack (LIGHT MODE / AUTO / DARK MODE)** repaints `html.light`, persisting to `localStorage.theme`, which /app reads as the same signal. The brand faces are proprietary and never shipped: **Pie Headline** (FK Screamer, the display face), **Pie Body** (PolyPie, text/UI), **Pie Monospace** (code, the URL field), **Pie Symbols** (icons) — names and roles are evidence, the woff2 files are not. **Boundaries:** sign-in and every account surface (named spaces, sync, shared collections) was never entered; the HTTPie AI "Try it out" action was never pressed; Send was never pressed on /app — issuing a request is a network side effect, so the response pane stands at its resting "Not sent" state; the desktop app and CLI binaries behind /download were never fetched; /discord redirects off-site. Nothing was signed into, typed, searched, sent, bought or submitted; the only presses were local UI toggles the product's own chrome provides (the ThemeToggle radios, the method and Incognito-space controls, the request and environments tabs, the ⌘K DocSearch dialog opened for icons and closed unqueried), and pressed states are DevTools-forced pseudo-classes, never real presses.

## How the values were read

- **Variables** come from the stylesheets themselves (`tools/capture/vars.mjs`): every same-origin CSS response plus the inline CSSOM is reparsed, rules binned theme/skins/app/vendor/utility/tailwind, every custom property resolved in a probe document carrying the real sheets — once under `<html class="light">` and once under `class="dark"`, the classes the footer's ThemeToggle paints. Literal colour declarations are harvested into `palette` with their selectors. `tokens.json` never publishes a raw `lab()`/`color-mix()` declaration — every colour is the painted value.
- **Geometry** is the live DOM (`tools/capture/public/measure.mjs`): bounding boxes and computed styles per component and state — hover by real mouse, focus-visible by keyboard, pressed by CDP `CSS.forcePseudoState` (no real press, so no button can fire), opened/focused states via the component's own toggle.
- **Screenshots** (`tools/capture/public/public.mjs`) verify the painted theme before writing a sidecar: HTML class, computed `colorScheme` and sampled background luminance must agree. The docs pages scroll inside overflow panes, so `-full` captures walk the pane for lazy content, expand it to document height, shoot bounded tiles and restore the shell.
- **Light states** are painted by the footer's own LIGHT MODE radio — verified by the painted surface, never by the mechanism, and DARK MODE is restored after (on /app the choice persists through `localStorage.theme`, the same signal the app reads; the light pass detours through the homepage to press the control).
- **The icon collection** (`tools/capture/icons.mjs`) hashes each inline svg's geometry, names it from `tools/capture/icon-names.tsv` or its control's label, and records where each was seen in `icons/INDEX.tsv`.
- **Send was never pressed.** Nothing on /app issues a network request — the response pane is measured and captured only at its resting "Not sent" state.

## What to distrust

- **Sign-in and everything behind it**: named spaces, synced collections, shared workspaces — the incognito product's own boundary, never entered. The avatar, Sign-in prompts and "Create environment" were measured, never pressed.
- **HTTPie AI "Try it out"**: generation is an account/paid feature; the promo dialog is evidence, the action is not.
- **The response surface after Send**: uncaptured by policy — pressing Send would issue a real request; only the "Not sent" resting state is evidence.
- **The desktop app and CLI binaries**: /download marketing pages only; no native build was fetched or run.
- **/pricing** is a 404 (captured as the not-found page); **/discord** and the social links redirect off-site.
- **The changelog post carries no fenced code block** — `prose-pre` is recorded as missing in components.md; the `docs-code-block` component on /docs/desktop is the package's syntax-block evidence instead.
- **The docs `-full` shots are the top 42k px of ~76–96k px articles** — a deliberate bound; the sidecars record it.
- **The Pie faces render from licensed woff2** loaded by the site; crops and screenshots show them, the style guide falls back to system fonts — the font files are not shipped.
- **Pressed states** are DevTools-forced; a script-applied mousedown style would not show.
- **Reduced motion is ignored by the product** — `raw/motion.json` records the probe's verdict; nothing honours `prefers-reduced-motion`.
- **The mobile app read is limited** — /app is a desktop-first shell; at 390 the side panel becomes a sheet and the builder compresses.
- **The Send button fill exists only in `dark`.** `component.sendButton.bg` aliases the accent role, and the button was measured on the dark site only, so the light set has no Send fill. The nav bar and /app rail paint transparent in both themes (the page's `bg.z0` shows through), so neither has a fill token.

## Fonts

- **Pie Headline** — FK Screamer, the display face (hero and section headlines): licensed, not shipped; the token is the stack the hero computes, `"Pie Headline", Impact`.
- **Pie Body** — PolyPie, the text/UI face: licensed, not shipped; the token is the computed `"Pie Body", sans-serif`.
- **Pie Monospace** — code, the URL field, JSON: licensed, not shipped; the token is the computed `"Pie Monospace", monospace`. Add your own fallbacks when you use these.
- **Pie Symbols** — the icon face: licensed, not shipped.

## Do and don't

1. **Do paint dark first.** httpie.io boots `html.dark` — the warm near-black `bg.z0` #191515 with warm off-white ink #f5f5f0 ([home](screenshots/home-dark-default.png)); light is the switched surface the footer's own radio paints ([light](screenshots/home-light-default.png)).
2. **Do stack surfaces on the z-ramp.** `bg.z0` → `bg.z3` is the elevation ladder — page, rail, panel, raised — in both themes ([app](screenshots/app-dark-default.png), [tokens](tokens.json)); don't invent greys outside it.
3. **Do spend the green on actions.** `accent` (#73dc8c dark / #52ab66 light) is the "Go to App" and Send fill; `altAccent` blue is the secondary action ([CTA](components/crops/nav-cta-default.png), [Send](components/crops/app-send-button-default.png)).
4. **Do give code its own palette.** The ten `code.*` colours are the syntax scheme in both themes — primary text, gray, green, pink, blue, red, orange, purple, aqua, yellow ([docs block](components/crops/docs-code-block-default.png)).
5. **Do compose the request line as method + URL + Send.** The /app builder is a three-column row — a green method menu, a mono URL field, the accent submit ([builder](screenshots/app-dark-default.png)) — with Params/Headers/Auth/Body tabs below ([tabs](screenshots/app-dark-tab-headers.png)).
6. **Do use panel tabs for parallel surfaces.** Environments, spaces and requests all open as cards in the same strip ([env manager](screenshots/app-dark-environments.png)).
7. **Don't style the signed-in product from this package.** Named spaces, sync and account surfaces are boundaries ([space panel](screenshots/app-dark-space-panel.png)); HTTPie AI generation likewise ([promo](screenshots/app-dark-ai-promo.png)).
8. **Don't invent a used response pane.** Send was never pressed — "Not sent" is the evidence ([response](screenshots/app-dark-tab-response.png)); the used surface is a documented gap.
9. **Don't copy the brand or the Pie faces.** The wordmark, icon set and licensed font files are HTTPie's and its licensors' ([wordmark](screenshots/home-dark-default.png)); the tokens describe the system, not its artwork.
10. **Don't ship the docs manuals unbounded.** The articles run ~76–96k px inside their own panes; the package bounds full shots at three chunks and records it ([docs](screenshots/docs-desktop-dark-full.png)).

python3 tools/build_component_tokens.py   # raw/component-tokens.json  <- raw/css-vars.json + measurements
python3 tools/build_tokens.py             # tokens.json               <- component-tokens.json + motion.json
node tools/capture/public/build-measurements.mjs   # raw/measurements.md <- components-computed.json

2. Do stack surfaces on the z-ramp.
3. Do spend the green on actions.
4. Do give code its own palette.
5. Do compose the request line as method + URL + Send.
6. Do use panel tabs for parallel surfaces.
7. Don't style the signed-in product from this package.
8. Don't invent a used response pane.
9. Don't copy the brand or the Pie faces.
10. Don't ship the docs manuals unbounded.
