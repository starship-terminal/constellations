Every value on this page is a CSS custom property generated from tokens.json: the hand-written semantic layer (--color-bg-z0..z3 surfaces, --color-primary/-secondary/-tertiary/-placeholders ink, the --color-accent green and --color-alt-accent blue, --color-warning, --color-focus, --color-borders, the --color-item-* list states, --color-selection/-backdrop/-shadows, and the --color-code-* syntax palette), the core.palette.* literals the marketing utility classes hard-code (the warm darks and off-whites, the pink pill), the proprietary Pie faces as names (never shipped), and the measured geometry (component.*) read off the live DOM — the nav, the buttons, the request builder and the tab strip. The real pixels are in screenshots/ and components/crops/.

Read from httpie.io, signed out, in headless Chromium at 1440×900 (mobile pass at 390×844). The site paints dark by default — html.dark is the boot and AUTO resolves dark — and the footer’s own ThemeToggle radios (LIGHT MODE / AUTO / DARK MODE) repaint html.light, persisted to localStorage.theme; the dark token set is the painted surface, light the switched one. The Pie faces (Pie Headline / FK Screamer, Pie Body / PolyPie, Pie Monospace, Pie Symbols) are licensed and not bundled: samples fall back to system fonts. Sign-in, the HTTPie AI “Try it out” action, and the desktop/CLI binaries behind /download are documented boundaries, not captures.

The surface

httpie.io is a dark-on-warm marketing surface over the HTTPie-for-Web client: /app runs signed out as an “Incognito space” — a bg.z1 rail (the space switcher, Collection/Drafts, the draft list) beside a tab strip of request cards, the request line (method menu, httpie.io/hello URL field in Pie Monospace, the accent Send) and the Params/Headers/Auth/Body panel tabs above request and response panes. The marketing pages wrap it in a site nav (wordmark, Desktop / Terminal / AI / Docs / Jobs / Blog links, the solid “Go to App” primary button) and a footer carrying the LIGHT MODE / AUTO / DARK MODE radio stack.

Palette

The semantic roles under dark.* are the painted default (#191515 warm-black ground, #f5f5f0 warm-white ink, the #73dc8c green and #4b78e6 blue accents); light.* resolves the same declarations inside html.light (#edede8 warm-paper ground, #1c1818 ink, the darker #52ab66 / #4b78e6 accents). bg.z0–z3 is the surface stack, text.* the ink ramp, code.* the ten-hue syntax palette, and core.palette.* the literals the marketing utility classes hard-code outside the token layer.

Spacing, radius, layout and motion

httpie.io declares no spacing scale — the stack is old Tailwind utilities — so spacing and radius are measured: component.* carries the chrome geometry (nav height, the /app rail width, button and field heights, card corners; pills clamp to 9999px). motion.* is the measured set from the reduced-motion probe (docs/decisions/0001): the durations and easing curves elements actually run, the transitions and animations, and what prefers-reduced-motion changes.

Type

Four proprietary faces, recorded by name only: Pie Headline (FK Screamer — the display face), Pie Body (PolyPie — text and UI), Pie Monospace (code, the URL field) and Pie Symbols (icons). No type ramp is declared; the core.typography.* composites carry the measured styles — the 109px hero, the section headings, body and code. Samples fall back to system fonts because the Pie faces are licensed and never shipped.
