Hand-written from measured CSS on https://www.diabrowser.com/ on 2026-11-22. `catalog.json` was not edited, so this file was not regenerated by `make design-md`.

## Type

Exposure VAR for the home headline. ABC Oracle for UI. ABC Favorit Mono for footer labels. At 1440 the home h1 is 39px, weight 500, line-height 43px, tracking -1.55px. Nav links are 16px. The font files are licensed and are not in this package.

## Radius

The home download pill is 9999px. The menu Download Dia button is 20px.

## What this file does not claim

Hover, focus, pressed, disabled, and dark theme were not measured. There is no public login wall. Do not invent an account chrome from the marketing pages.
