# Acne Studios design reference

A token set and component reference for Acne Studios, the fashion house — for building storefront, campaign and editorial surfaces in the style of the real thing. Captured from the public Singapore storefront (`acnestudios.com/sg/en`) on 2026-11-09, signed out, in headless Chromium at 1440 wide and 390 wide: the home page with its full-bleed campaign hero, the WOMEN'S NEW ARRIVALS and BAGS category pages, one product page (Leather Funnel Neck Jacket), About, FAQ, Contact, the store directory, the empty-cart route and the account sign-in gate, plus the search panel, filter rail, WOMAN mega-menu and the mobile Menu drawer opened through the page's own toggles.

The reason Acne is worth a capture at all: it is one of the most disciplined e-commerce systems on the public web — near-pure monochrome with a single electric blue (#0018a8) doing every link, accent action and selected state; 12px Helvetica Now Text uppercase at a uniform 0.3px tracking for almost every word on the site; zero radius, zero shadow and zero transition on controls; and hairline 1px rules (some drawn as background gradients) separating everything. Prices on the PDP and the size grid flip to Helvetica Monospaced Pro — small numeric flourishes in an otherwise strictly single-voice page.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export acnestudios` prints them all with aliases resolved.

### Principles

1. Do keep it monochrome.
2. Do spend the one blue on links and actions.
3. Do set labels in 12px uppercase at 0.3px tracking.
4. Do keep every corner square and every edge a hairline.
5. Do hover with colour, instantly.
6. Don't add shadows, rings or easing.
7. Don't expect the obvious label.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## What to distrust

- **Readings past a masked bot signal.** The committed screenshots and readings were taken with `navigator.webdriver` masked, the flag bot checks read to spot automation. The capture scripts no longer mask it (not run since), so a recapture may record a walled route as a boundary instead of a reading.
- The capture is of the Singapore storefront (`/sg/en/`): prices are SGD, the nav and promo copy are the region's. Other regions may serve different campaigns and layouts.
- Mobile `m-*` readings cover layout and the menu drawer only; a phone has no hover/focus to measure, and the 390 capture took one drawer open.
- Several components were re-measured after selector fixes (logo, hero wordmark, menu drawer); components whose `run` predates that fix carry their original capture time, and any component the selectors still miss is marked `missing` in `raw/components-computed.json` rather than re-dated.
- Nothing was bought, bagged or signed into: ADD TO BAG, CHECKOUT, GOOGLE and the newsletter submit were never pressed; their states come from CDP-forced pseudo-classes.

## Fonts

- The site sets Neue Haas Grotesk (`NeueHaasUnica`, `--font-*` stacks resolve to it) with a Helvetica/Arial system fallback; the style guide renders the fallback, not the licensed face.

## How the values were read

Every surface is public, so every page was captured signed out in headless Chromium: a script tours the routes at 1440 x 900 and 390 x 844 at 2x, blocks the OneTrust consent SDK at the network layer (its banner never mounts and no consent button is ever pressed), sweeps leftover overlays remove-only, scrolls to defeat lazy rendering, and writes raw PNGs plus a `.capture.json` per shot. `vars.mjs` dumps every custom property the pages declare — only two are the app's own (`--safe-area-inset-bottom` on drawer containers); the rest are Tailwind framework internals and the Adyen checkout block, kept in `raw/css-vars.json` as evidence rather than tokens. `measure.mjs` measures each component on the live DOM: default, real mouse hover, real keyboard focus, and CDP-forced `:active`/`:hover` for pressed — the size cell's picked state is reached through the grid's own toggle. Crops are clipped from the live page at 2x.

One theme is captured: the storefront has no dark variant. Aliases in the `light` set point into `core` where the semantic role is the palette value; every leaf names its measurement in `$extensions.source`. Values the site never gave (a spacing scale, z-indices, dark theme) are absent rather than invented.

## Do and don't

- **Do keep it monochrome.** Text, fills and chrome are black on white; the four warm greys carry muted text (#6b6b6b, #5c5c5c), control borders (#c2c2c2), hairlines (#f2f2f2) and field fills (#f7f7f7) — nothing else is a neutral ([header](components/crops/header-default.png), [footer](components/crops/footer-default.png)).
- **Do spend the one blue on links and actions.** Acne blue #0018a8 paints every text link, the ADD TO BAG fill, the wishlist keyline, the picked size cell and the hover step of every black button; its deeper step #051574 is hover-only ([footer-link](components/crops/footer-link-default.png), [add-to-bag](components/crops/add-to-bag-default.png), [size-cell-selected](components/crops/size-cell-selected-default.png)).
- **Do set labels in 12px uppercase at 0.3px tracking.** One voice: Helvetica Now Text 12/20, weight 400, uppercase — nav, buttons, headings, prices, column titles; only sentence-case copy and the 18px field text differ ([nav-item](components/crops/nav-item-default.png), [footer-col-title](components/crops/footer-col-title-default.png), [login-title](components/crops/login-title-default.png)).
- **Do keep every corner square and every edge a hairline.** Radius is 0 everywhere (the only curve is the filter rail's 10px radio dot); borders are always 1px — black on drawers and outline buttons, grey #c2c2c2 on size cells, #f2f2f2 hairlines between rows ([filter-rail](components/crops/filter-rail-default.png), [size-cell](components/crops/size-cell-default.png)).
- **Do hover with colour, instantly.** Black buttons flip to Acne blue, blue deepens to #051574, links deepen, black labels grey to #6b6b6b — all with transition-duration 0s ([load-more](components/crops/load-more-hover.png), [geo-selector](components/crops/geo-selector-hover.png)).
- **Don't add shadows, rings or easing.** Nothing elevates: drawers sit on opaque white keyed by a 1px black edge, and the focus ring, when it exists, is a 1px keyline 3px inside the control ([menu-panel](components/crops/menu-panel-default.png), [wishlist-button](components/crops/wishlist-button-focus-visible.png)).
- **Don't expect the obvious label.** ADD TO BAG retitles to "PLEASE SELECT SIZE" on hover until a size is picked — a real measured state, not a mock ([add-to-bag](components/crops/add-to-bag-hover.png)).

## Rebuild

The kit under [tools/capture/](tools/capture) re-reads the live site; the builders re-derive the package from `raw/`:

```sh
cd systems/acnestudios
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  RAW=~/.design-systems/acnestudios/raw-full \
  node tools/capture/public/public.mjs        # raw captures + .capture.json (defaults to raw/full; keep originals out of the repo)
PYTHON=~/.design-systems/venv/bin/python \
  python3 tools/capture/quantize.py ~/.design-systems/acnestudios/raw-full   # screenshots/; originals stay out of the repo
PLAYWRIGHT=... node tools/capture/vars.mjs    # raw/css-vars.json
PLAYWRIGHT=... node tools/capture/public/measure.mjs          # raw/components-computed.json + crops
node tools/capture/public/build-measurements.mjs              # raw/measurements.md
python3 tools/build_tokens.py                 # tokens.json from component-tokens.json
python3 tools/build_components_md.py          # components.md
python3 tools/build_style_guide.py            # style-guide.html
cd ../.. && python3 tools/fetch_icon.py acnestudios    # icon.png (repo-root tool)
```

Then `make design-md` at the repo root refreshes [DESIGN.md](DESIGN.md), and `make check` re-grades the package.
