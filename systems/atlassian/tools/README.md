# How this package was captured

2026-11-22. Public pages only.

Headless Chromium opened https://www.atlassian.com/ and the header and footer destinations. Viewport 1440 by 900 and 390 by 844, device pixel ratio 2. Screenshots were quantised to 256 colours.

Sign in and signup were opened and left empty. Continue and Sign up were not clicked. No identity provider was clicked. No form was submitted.

Contact was opened and discarded because it prints street addresses and a phone number.

`catalog.json` was left alone, so `make design-md` and `make brief` were not run for this package.
