Grab style guide

Grab for iOS, read from stills captured through iPhone Mirroring on 2026-10-23. Grab has one theme: it stays light with the phone in dark mode. Every value below comes from tokens.json; points are 1:1 with CSS pixels. The fonts are not known, so the page uses the platform sans for text and a rounded system face for titles. There is no theme toggle: dark is not applicable.
