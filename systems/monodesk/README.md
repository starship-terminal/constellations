# MonoDesk design reference

A token set and component reference for MonoDesk's public marketing site and signed-out app screens. Read from **www.monodesk.com** and **app.monodesk.com** on **2026-11-19**, signed out, in headless Chromium at 1440×900 and 390×844. Captured: /, /pricing, /features, /about-us, /help, /blog, /for-creative-pros/freelancers, /features/projects, /playground, plus **app.monodesk.com/login** and **/create**. The marketing site paints one light theme (blue grid wash, no theme control). The app login and create screens paint light. Emulating `prefers-color-scheme: dark` did not repaint them, so there is no live dark page theme in this package.

MonoDesk is an all-in-one workspace for freelance creatives, backed by Envato. The marketing site declares a small `:root` token set (`--brand-blue` #1c64f5, `--brand-highlighter` #d1ff6e, `--brand-fun-green` #026232, `--brand-orange` #ff5b26, `--type` #161616, a spacing scale, a radius scale). The app is a Tamagui/Expo shell with a large custom-property scale. Nothing was signed into, typed, or submitted. Google, Login, Create Account, and "Email me the link" were never pressed.

## Brief

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export monodesk` prints them all with aliases resolved.

### Principles

1. Paint the marketing page blue.
2. Spend highlighter on the action.
3. Invert that pill on hover.
4. Keep the header as a darker blue bar
5. Price in black on a white slab.
6. Keep the login card white, 16px radius, on #e5eaed.
7. Don't style the signed-in workspace from this package.
8. Don't invent error, loading, or disabled states.
9. Don't treat the app's dark custom properties as a painted theme.
10. Don't ship the Geist files or the wordmark as if they were ours.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Custom properties were read from `getComputedStyle(document.documentElement)` on the live pages. Marketing `:root` declares the brand, type, spacing, and radius names. The app document exposes a Tamagui scale (887 names on the login page), including light and dark pairs. Component geometry is computed style plus bounding box, from headless Chromium at 1440×900, device pixel ratio 2 for crops and 1 for page shots. Hover is a real pointer. Focus is a real focus. Pressed states that needed a click were not taken on submit or navigation controls. Screenshots went through `tools/capture/quantize.py`.

## What to distrust

The signed-in workspace was never entered. Login and create were not submitted, so validation, error, and loading states are absent. `dark` in tokens.json is the app's declared dark custom properties. The login page stayed `color-scheme: light` and `background rgb(229, 234, 237)` when `prefers-color-scheme: dark` was emulated, so those dark tokens are not a painted theme. The home hero "Get started free" hover inverts fill and label (green fill, highlighter text). That swap was measured on the inner span, whose rest color was read as #026232. A first pass measured the wrapping link, which is transparent, and those readings are not used as tokens. The phone home shot includes the site's own "On your phone right now?" sheet. It is a real interstitial, not a cookie banner. Pressed and disabled states of the Login button did not change computed color. Plan-card radius was not isolated as its own element. Geist and Geist Mono files are not in the package.

- **No custom property reading survived.** Every page dump in [raw/css-vars.json](raw/css-vars.json) is empty, so the 33 tokens sourced only to a declared or computed `--name` (the spacing and layout scales, `radius.xl` and `radius.2xl`, the brand colours, and the whole `dark` set) were typed in from the capture session. Their sources now start "Reconstruction". Values that also cite a computed style on an element, such as `light.background.page` or `light.text.primary`, are backed by [raw/components-computed.json](raw/components-computed.json).
- **Three forced states read the wrong thing and need a recapture.** `states.mjs` forced pseudo-classes through Playwright fields that do not exist, so nothing was forced. `cta-primary-focus-visible` and `cta-primary-pressed` equal `cta-primary-focus` exactly, and `button-login-pressed` equals `button-login-hover`. The script now forces the element itself and records nothing when forcing fails. It has not been rerun.
- **Consent.** `shoot.mjs` clicked the first short button labelled accept, agree, allow or ok. The committed run clicked none. It now hides consent overlays and clicks nothing.

## Fonts

Geist is the marketing face (`Geist, system-ui, sans-serif`) and the app face (Geist plus the system stack). It is a variable woff2 on the marketing site and a set of TTF weights in the app. Geist Mono is declared. Both are licensed and not shipped. The style guide falls back to system sans and mono.

## Do and don't

1. **Paint the marketing page blue.** Page wash is #1c64f5, body ink on that wash is white. See [home](screenshots/home-light-default.png).
2. **Spend highlighter on the action.** Get started free is #d1ff6e with #026232 text, pill radius. See [crop](components/crops/cta-primary-default.png).
3. **Invert that pill on hover.** Hover fill is #026232 and the label goes highlighter. See [hover](components/crops/cta-primary-hover.png).
4. **Keep the header as a darker blue bar** on the grid, with a white wordmark and the same highlighter pill. See [header](components/crops/site-header-bar.png).
5. **Price in black on a white slab.** $0 is #161616 at 32px bold. Future prices are #161616 at 60% opacity. See [pricing](screenshots/pricing-light-default.png).
6. **Keep the login card white, 16px radius, on #e5eaed.** The Login button is #161616 with white text and 12px radius. See [login](screenshots/app-login-light-default.png).
7. **Don't style the signed-in workspace from this package.** Past Login and Create Account is a boundary.
8. **Don't invent error, loading, or disabled states.** No form was submitted.
9. **Don't treat the app's dark custom properties as a painted theme.** The login stayed light under a dark preference.
10. **Don't ship the Geist files or the wordmark as if they were ours.** They are MonoDesk's and its licensors'.
