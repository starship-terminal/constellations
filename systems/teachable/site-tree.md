# Teachable public site tree

Mapped on 2026-11-22 from the public homepage, https://teachable.com, which redirects to https://www.teachable.com/. Title: "Teachable — Build & Sell Online Courses, Coaching, Memberships & More". Incognito preview tab. Desktop shots are 2880 by 1800 pixels, from a 1440 by 900 CSS viewport at devicePixelRatio 2. Phone shots are 780 by 1688 pixels, from a 390 by 844 CSS viewport at devicePixelRatio 2. The page painted light. `color-scheme` on the root was `normal`. The page background computed to `rgb(255, 255, 255)`.

The site is a live marketing site, not a parked domain and not a captcha wall. The cookie panel ("This site uses cookies", OK) was dismissed so it would not cover the header. No email, password, name, phone, code, or address was typed. No form was submitted. No identity provider was clicked. No captcha was solved. No school was created. No course was enrolled. `login-extracted` stays not-started. catalog.json was left alone. webapps-manifest.json was left alone.

The existing package in this folder (tokens, crops, and the 2026-11-19 screenshots) was not overwritten. New public shots use distinct names.
