gumroad.com, measured

Every value on this page is a CSS custom property generated from tokens.json: the brand set (--pink #ff90e8, --purple, --green, --orange, --red, --yellow), the semantic roles declared as RGB channel triplets (--accent/--primary/--filled/--success/--warning/--danger/--info plus the --contrast-* partners), the --spacer-1..8 spacing scale, --border-radius-1..3, the hard offset shadows --box-shadow-1/2, the --text-xs..9xl type ramp on ABC Favorit, and the measured geometry (component.*) read off the live DOM. The real pixels are in screenshots/ and components/crops/.

Read from gumroad.com and one creator subdomain (ichigo.gumroad.com), signed out, in headless Chromium at 1440×900 (mobile pass at 390×844). The site paints light by default — the light token set is that painted surface — and a real @media (prefers-color-scheme: dark) theme repaints the roles (--body-bg #242423, --border-alpha .35): the dark set is that painted surface, verified through colour-scheme emulation — there is no in-page toggle. The product subdomain pins its own light palette over the shared sheet, so its pages do not repaint; that is recorded as observed behaviour, not a third theme. ABC Favorit is a proprietary face and is not bundled: samples fall back to system fonts.

The surface

Every marketing page is a hero header — the GUMROAD wordmark, the marketplace search, "Log in" and the black "Start selling" button — over a pill row of category links and a centred hero. Below sit bordered cards on the #f4f4f0 ground, hard 4px offset shadows, and the pink --accent. The theme preview button below is this guide's own control: the product itself follows the OS colour scheme.

Palette

color.brand.* holds the six declared brand colours and the color.scale.* utilities; color.alpha.gray* is the alpha ramp the muted roles mix from. The semantic roles under light.* are the painted default (cream ground, black ink, pink accent); dark.* resolves the same declarations inside @media (prefers-color-scheme: dark) — the accent and status colours hold, the ground, ink and border repaint. channels.* keeps the raw RGB triplets the roles are declared as; role.* is each resolved colour; neutral.* the --neutral-* wrappers.

Spacing, radius, layout and motion

Spacing is the product's own --spacer-1..8 scale (4px steps, 4–32px) plus the Tailwind --spacing unit; radii run --border-radius-1..3 (the squared-off 4px card corner to the pill); layout.* carries the declared grid and container widths (--main-stack-width, --spacing-product-page, --dynamic-grid, --grid-cols-sidebar). duration.*/ease.* are the declared motion constants and animation.* the --animate-* presets.

Type

One proprietary face, ABC Favorit, does everything — wordmark, display, body and controls (code falls back to system mono). The --text-* ramp runs xs–9xl with paired --leading-* line-heights; weights are the named --font-weight-* steps. Below that, the core.typography.* composites — the display, heading, nav, control and price styles measured off the live DOM. Samples fall back to system sans because the face is not bundled.
