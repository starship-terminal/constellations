# Gumroad patterns

Public pages only. Captured 2026-11-21. The map of which control opens which page is [site-tree.md](site-tree.md).

## Marketing shell

A full-bleed header: wordmark, GitHub count, text links, Log in, and a black Start selling block that turns pink on hover. The page fill is `#f4f4f0`. The hero is one 96px line, "Go from 0 to $1". See [home-light-default.png](screenshots/home-light-default.png).

Dark follows the system color scheme. The same header paints Start selling pink by default. See [home-dark-default.png](screenshots/home-dark-default.png).

## Marketplace

Discover is a filterable grid: category bar, search, sort tabs, product cards. A category name opens a dialog of subcategories. More opens the rest of the taxonomy. See [discover-light-default.png](screenshots/discover-light-default.png) and [discover-light-category-dialog.png](screenshots/discover-light-category-dialog.png).

A card opens a public product page on a creator subdomain. The buy control goes to checkout and was not used. See [product-light-default.png](screenshots/product-light-default.png).

## Phone

The same home at 390×844 folds the nav into a hamburger. See [mobile-home-light-default.png](screenshots/mobile-home-light-default.png) and [mobile-home-light-menu.png](screenshots/mobile-home-light-menu.png).

## Auth wall

Log in asks for email and password, or Apple, Google, X, Stripe, or a passkey. The page was photographed and not filled. See [login-light-default.png](screenshots/login-light-default.png). Sign up is [signup-light-default.png](screenshots/signup-light-default.png).
