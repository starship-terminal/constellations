# Gumroad design reference

A token set and component reference for Gumroad's public site. Read from **gumroad.com** on **2026-11-21**, signed out, in headless Chromium at 1440×900 and 390×844, in light and in dark (`prefers-color-scheme`). The creator dashboard, checkout, and every signed-in page were not opened.

## How the values were read

[tools/capture/vars.mjs](tools/capture/vars.mjs) opened https://gumroad.com/ in light and in dark and wrote every custom property to [raw/css-vars.json](raw/css-vars.json). Component boxes and colours were read with `getComputedStyle` on the live page and saved to [raw/components-computed.json](raw/components-computed.json). Screenshots came from [tools/capture/public/public.mjs](tools/capture/public/public.mjs). [tools/build_tokens.py](tools/build_tokens.py) maps those readings into [tokens.json](tokens.json).

Nothing was signed into. Login and signup were photographed. Apple, Google, X, Stripe, and passkey were not clicked. No form was submitted. No password was typed.

## What to distrust

- This is the public site. The library, editor, payouts, and settings sit behind `/login`.
- Dark is the system color scheme, not an on-page toggle. Login and signup stay light.
- Screenshots in `screenshots/` are 256-colour PNGs. Read colours from the tokens.
- Home, pricing, features, and blog full shots expand the inner `main` scroller before capture. Blog is 16271px. Home is 7913px. Features is 9476px. Discover's full shot is the first 3600px of an 8576px grid. Help's full shot stayed at the viewport because the page did not grow.
- Status colours are declared tokens. They do not paint a status component on the home page.
- The caption type role is a smaller measured step, not a named caption style.

## Fonts

ABC Favorit, served from Gumroad's asset host. Fallbacks in `--font-family`: Avenir, Montserrat, Corbel, URW Gothic, source-sans-pro, sans-serif. The face is not committed.

## Do and don't

1. **Do paint the page in paper.** Light pages are `#f4f4f0`, not white. See [home-light-default](screenshots/home-light-default.png).
2. **Do spend pink on the action.** `#ff90e8` is the hover of Start selling in light, and its resting fill in dark. See [nav-cta-light-default](components/crops/nav-cta-light-default.png).
3. **Do set the hero in one line.** The display is 96px ABC Favorit at a 96px line height. See [home-light-default](screenshots/home-light-default.png).
4. **Do keep the header button square.** Start selling has a 0 radius and a 1px black border language elsewhere. See [nav-cta-light-default](components/crops/nav-cta-light-default.png).
5. **Don't style the dashboard from this package.** Library, editor, and payouts were not reached.
6. **Don't invent a theme toggle.** Dark follows the system. Login stays light.
