# Import library

Drag SVGs from boards/ or components/ into Figma or another SVG-capable editor. These are vector drawings, not a native component/variant library. See README.md for fonts, evidence, dimensions, limitations and rights.

The small library ZIP includes vectors, tokens and the guide, without the signed-in screenshots, which are no longer in this repository. The complete audit ZIP held them and should remain private.

Install Inter Variable and appropriately licensed Berkeley Mono / Tiempos Headline fonts for fidelity. Commercial font binaries are not included. Paper/Figma import was not run; SVG XML and browser rendering were validated.
