joinhandshake.com, measured

Every value on this page is a CSS custom property generated from tokens.json: the marketing site's declared layer (the NoiGrotesk/SansPlomb faces, the --spacing unit, --container-3xs..7xl, the leading/tracking/weight scales, the nav geometry vars, and the CTA colours declared as [--cta:#2e6aff] utility props), the Framer-built page's --token-* colour styles under color.framer.*, the painted role measurements under light.*, and the consumer app's Rosetta layer under access.*. The real pixels are in screenshots/ and components/crops/.

Read signed out in headless Chromium at 1440×900 (mobile pass at 390×844). Both surfaces paint light only — no theme class, no theme control, no prefers-color-scheme rule — so there is no dark set. The app host sits behind a Cloudflare managed challenge that clears intermittently: app.joinhandshake.com/access was captured when it cleared; /explore, /signup and support.joinhandshake.com never cleared and are documented boundaries. NoiGrotesk and SansPlomb are served faces, not bundled: samples fall back to system fonts.

Palette

color.site.* holds the declared CTA/ink utility values; color.framer.* is the Framer page's declared colour-style palette (the UUIDs are the declared names); light.* holds the painted role measurements; access.* resolves the app's declared Rosetta colours.

Spacing, radius, layout and motion

Spacing is the Tailwind --spacing unit (0.25rem); containers run --container-3xs..7xl with --container-padding; layout.* carries the declared nav/banner geometry and grid gaps; motion.* is the measured set from the reduced-motion probe. The app's spacing/size scales live under access.*.
