# Haus Labs

A signed-out capture of the public Haus Labs shop at [https://hauslabs.com](https://hauslabs.com), on 2026-11-22. The browser stayed on hauslabs.com. Desktop 1440 by 900. The promo bar is `#000000`. The header is `#ffffff`. Body type is SuisseIntl. Ink is `#000000`. Add to Bag is `#000000` with white type. The hero field is `#f1f1f1`.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).
