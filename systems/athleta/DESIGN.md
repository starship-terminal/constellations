# Athleta

A signed-out capture of the public Athleta shop at [https://athleta.gap.com](https://athleta.gap.com) on 2026-11-22. Desktop 1440 by 900, `devicePixelRatio` 2. The page is white. Body type is Phantom Sans 0.9. Display type is Sohne Schmal. The universal bar is `#000000`. The primary action is `#0c0c0c`. Hero buttons are white pills.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).
