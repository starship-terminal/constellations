# TravelPerk

TravelPerk is a travel and expense product. The public site now calls itself Perk. This package covers the signed-out marketing pages, captured 19 November 2026. `https://www.travelperk.com/` redirected to `https://www.perk.com/`. Pages read: the homepage, pricing, the platform overview, and the login boundary at app.perk.com/login. Themes: light only. Widths measured: 1440 and 390, plus a first homepage read at 1169. No account was used. The email field was not filled.

## How the values were read

The homepage was opened in the T3 preview browser. `https://www.travelperk.com/` redirected to `https://www.perk.com/`. `getComputedStyle` on `document.documentElement` returned 328 custom properties, including `--brand-perk` and the Tailwind palette. Component values were read from painted elements. Pricing was read at `https://www.perk.com/pricing/?tab=Travel+and+Spend&region=nam`. The platform page was read at innerWidth 1440 and 390. Log in was opened at `https://app.perk.com/login`, measured, and left. No form was submitted. No cookie banner was painted, so none was clicked.

The marketing sheet is an inline stylesheet of 2576 rules. OTSono is loaded from the page as woff2. The login page uses Perk Sans and a separate custom-property set (`--color-*`, `--typescale-*`, `--spacing-*`).

## What to distrust

Screenshots are missing. The preview browser returned "The browser is not producing screenshot frames", so layout claims rest on computed boxes, not images.

The homepage body background is transparent. Page off-white is the nav and the cards, `rgb(245, 245, 235)`.

The first homepage read was at innerWidth 1169, not 1440. Display type still matched the `md:text-heading-l` rule (80/72), which starts at 1092px. The 1440 read is the platform page.

Button radius computed to 26px. The stylesheet's `.rounded-medium` is 28px and `.rounded-full` is 9999px. The button token keeps 26px.

Login field border computed to 2px `rgb(20, 20, 15)`. The app token `--color-input-border-base` is `#838377`. The painted value is the one in the tokens.

The login title computed to 20px at the wide read and 18px at 390. The typescale token `--typescale-title-medium-font-size` is 19px. The token stores the painted 20px.

An error line was already visible on the login page before any input. It is the product's copy, not a submit result.

OTSono and Perk Sans files are not in this package.

## Fonts

OTSono (marketing) ships from perk.com as woff2, weights 400, 500 and 600. Computed headings use 500. Perk Sans (login) ships from app.perk.com, weights 400 and 500 loaded. Both families are proprietary. Tokens name them and fall back to system-ui. The files are not committed.

## Do and don't

**Use the lime pill for the primary marketing action.** Book a demo is `#beff50` with off-black type, 26px radius, 40px tall. The outlined pill is the second action.

**Set marketing type in OTSono.** The homepage h1 is 80/72 at 500 with -0.03em tracking. Body copy is 18/24 in `#6e6e64`. Phone headings drop to 36/38.

**Keep plan cards flat and off-white.** Premium and Pro sit on `#f5f5eb` with a 28px radius and 32px padding. Prices use the 60px heading style.

**Leave the login page on Perk Sans.** The identifier page is white, with an 8px radius and a 44px off-black Sign in button. It does not reuse the lime pill.
