# Teenage Engineering design reference

A token set and component reference for Teenage Engineering, taken from the public site at https://teenage.engineering/ on 2026-11-21. Signed out. Headless Chromium, desktop 1440x900 and phone 390x844. One theme. The home page is a black campaign. The store, newsletter and checkout are white. No account exists on the site: `/login` is a 404.

## How the values were read

Custom properties were read from the live CSSOM on the home page at 1440x900 (`tools/capture/vars.mjs`). The palette and the type scale are declared on `:root` in `root.*.css`. Lengths that use `--client-width` were resolved at that viewport and labelled viewport-relative. The fonts.net sheet is cross-origin and was skipped.

Component colours, type and sizes were read with `getComputedStyle` on the live controls (`tools/capture/public/measure.mjs`). Screenshots show layout. Token colours come from the CSS and the computed styles, not from the 256-colour PNGs.

## What to distrust

- The home page sets `--theme-body-bc` to black in an inline style. The stylesheet declares it as white. `light.background.page` is the declared white. `light.background.pageInverse` is the measured home black.
- Viewport-relative sizes (`--fs-*`, `--space-*`, header height) are the 1440px reading. They change with the window.
- Hover on text links did not change the computed colour. A hover that swaps an image is not in the tokens.
- `--success`, `--error`, `--te-blue` and `--te-yellow` are declared. They were not seen on a painted control.
- Pressed states were not captured. The CDP call failed.
- The country select loaded a public store region and was left as the site set it. The region name is not recorded.
- Full-page tiles of `/now`, `/products`, `/store` and `/designs` were not committed. Those pages are thousands of pixels tall. The viewport shots are the record.

## Fonts

te-20 and te-40 are the product's own faces, served as woff2 from the site. They are proprietary and are not in this package. The guide falls back to Helvetica Neue, Helvetica, Arial. Unicode is the fallback named in the stack. franxurter is also declared in `@font-face` and was not measured on a control.

## Do and don't

- **Do set the store on white and the campaign on black.** The store, newsletter and checkout use a white page and black type. The home page and the phone menu use a black page and off-white type. See [store-light-default.png](screenshots/store-light-default.png) and [home-light-default.png](screenshots/home-light-default.png).
- **Do use one black bar for the main action.** Subscribe and add to cart are the same fill (`#0f0e12`), the same off-white type, and square corners. See [newsletter-light-default.png](screenshots/newsletter-light-default.png).
- **Do keep type in te-20, thin for nav and light for everything else.** Nav is weight 100. Buttons, fields and prices are weight 300. See [components.md](components.md).
- **Do leave corners square.** Fields, buttons, tiles and the checkbox measured 0px radius. The pill radius exists as `--round` and was not on these controls.
- **Don't add a shadow or a focus ring the site does not paint.** Measured controls have no box-shadow. Focus on the checkbox and the region select darkens the border to black.
- **Don't invent a dark mode.** The site has no theme toggle. The black home page is a campaign, not a second theme.

## Rebuild

```bash
cd systems/teenage-engineering
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/vars.mjs
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/public/measure.mjs
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
```

Page shots: `PLAYWRIGHT=... node tools/capture/public/public.mjs`, then `python3 tools/capture/quantize.py ~/.design-systems/teenage-engineering/raw-shots`.
