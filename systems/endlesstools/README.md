# Endless Tools design reference

A token set and component reference for Endless Tools' public surface — for building dark, confident designer-tool marketing pages in the style of the real thing. It was read from **endlesstools.io** and **app.endlesstools.io** on **2026-11-13**, signed out, in headless Chromium at 1440 x 900 and 390 x 844: the marketing one-pager (hero, asset-input strips, statement sections, pricing, testimonial carousel, newsletter, footer), the app's login card in both its OTP and password forms, and the privacy-policy and terms document pages.

Endless Tools ("a visual exploration tool for graphic designers") is worth a capture because its public surface is a tight study in dark restraint: a `#000` marketing field under `#fff` ink with `#959595` muted text, the app shell one step darker at `#0a0a0a` under `#efefef` ink, fully-rounded 35-38px pills on the marketing controls (the app shell's own fields and buttons take a 10px radius), `#121212` 33px-radius cards under a `#222` hairline ring, one magenta `#ff13b1` accent that marks only the hero CTA and the `#ff3dae` save pill, one blue `#2c5cff` reserved for education, and a single family — Inter — on a declared 42/46-to-12/14 ramp. **Boundary:** the product itself — the canvas editor — lives behind sign-in on app.endlesstools.io and was never entered. Everything behind the login is a recorded gap, never inferred.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export endlesstools` prints them all with aliases resolved.

### Principles

1. Do keep the field near-black.
2. Do pill every marketing action.
3. Do reserve pink for the primary action.
4. Do reserve blue for education.
5. Do invert the primary button.
6. Do build cards from near-blacks, not borders.
7. Don't invent a light theme.
8. Don't style the editor from this package.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out surfaces in headless Chromium:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) captures every stylesheet body (the linked `/_next/static` CSS bundles from the network responses plus the inline `<style>` blocks, re-parsed with `CSSStyleSheet`) and resolves every custom property on a probe carrying the real sheets into [raw/css-vars.json](raw/css-vars.json). The marketing bundle declares a real Tailwind v4 @theme layer (`--color-*`, `--text-*`, `--radius-*`, `--ease-*`, `--blur-*`); the app bundle declares the same grey ramp under Tailwind v3. The pink and blue accents and the card greys are arbitrary-value utilities, never declared — those tokens are **measured computed values** from [raw/components-computed.json](raw/components-computed.json). [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec, [tools/build_tokens.py](tools/build_tokens.py) the sets.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state, plus `focused`/`filled` on the fields and `selected` on the consent checkbox. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md).
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route with `.capture.json` sidecars; [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours (the privacy/terms `-full` shots are stitches of the part tiles it writes for pages taller than one GPU texture).

Nothing was signed into, created, submitted or consented to: the only presses were local UI toggles — the Yearly/Monthly billing switch, the login card's "Log in with password" switch and the newsletter consent checkbox — and each was left as found. The newsletter and login forms were never submitted; no consent overlay was seen (any would have been hidden, never answered); the Start-for-free and plan CTAs (which open app.endlesstools.io's signup) were never followed.

## What to distrust

- **This is the marketing shell and the signed-out app shell, not the product.** The canvas editor — its tools, panels, library and AI features — sits behind sign-in and is uncaptured. Treat the product's own design system as unknown.
- **One theme only.** Both surfaces paint dark; no light theme, no switcher. `tokens.json` ships a dark set only.
- **Two surfaces, two page fields.** `#000` is the marketing page (Tailwind `bg-[#000]`); `#0a0a0a` (`--color-black`, `bg-back`) is the app-shell page. The token file keeps both as `dark.surface.page` and `dark.surface.app` — do not collapse them.
- **The accents are measured, not declared.** `#ff13b1`/`#ff4bc4`/`#ff3dae` and `#2c5cff`/`#5a65ff` live in the sheets as literal hover/bg utilities; the tokens cite the components they were measured on.
- **Two different focus conventions, neither a designed ring.** Marketing links draw the browser's own 1px `auto` outline; `#005fcc` (`dark.focus.ua`) is the colour Chrome reports for it, the UA default, not a colour the product paints. App-shell buttons keep Tailwind's `outline: 2px solid transparent` preset and show no measured change on keyboard focus; only the email field swaps its border to grey-1, and that on click focus. `billing-yearly`'s keyboard focus failed, so its focus look is uncaptured.
- **`gradient.overlay` was entered by hand.** No rule or component in `raw/` holds the bottom media fade; its source says so and it needs a recapture.
- **The pill radius is nominal `9999px`.** Chrome resolves Tailwind's `rounded-full` (`calc(infinity * 1px)`) to 33554432px in computed style; the token records 9999px, the value a reader expects.
- **Quantised screenshots and crops.** `screenshots/` and `components/crops/` are 256-colour PNGs; the crops' in-run quantize step failed (the runner's `python3` lacked Pillow) so they were quantised after capture with the same recipe — the `cropError` keys in [raw/components-computed.json](raw/components-computed.json) record the failure. Read exact colours from tokens or the raw files.
- **Animated content moves between runs.** The hero's orbiting asset cards, gradient title and the auto-advancing testimonial carousel mean two captures of the same view differ.
- **Automation was masked during capture.** Until 2026-11-20, `tools/capture/public/lib.mjs` hid `navigator.webdriver` in every page it opened, so every committed reading was taken with that mask. The mask is removed (a bot check is now recorded as a boundary, not bypassed); whether any page needed it to load is not known, and a recapture without it is the check.

## Fonts

**Inter** is the single family every measured text paints — the variable face (100-900) with next/font's Arial-metric "Inter Fallback", served as subset woff2 on both hosts (the `@font-face` harvest is in [raw/css-vars.json](raw/css-vars.json)); none is distributed with the package, so the style guide falls back to system sans. **Flow Rounded** ships in the app bundle as `--font-skeleton` (a geometric placeholder face for skeleton/loading text); no public component paints it. The marketing `@theme` also declares plain ui-sans-serif and ui-monospace stacks.

## Do and don't

1. **Do keep the field near-black.** `#000` on marketing, `#0a0a0a` on the app shell, white or `#efefef` ink on top; muted drops to `#959595`, never a lighter grey on a lighter surface. See [home-dark-default](screenshots/home-dark-default.png).
2. **Do pill every marketing action.** Nav pills, the hero CTA, plan CTAs, the newsletter field and submit, even the 18px consent checkbox — the marketing controls are fully rounded, the buttons 35-38px tall. The app shell draws the line differently: its fields and buttons take a 10px radius (the legal sign-in pill is 40px tall). See [hero-cta](components/crops/hero-cta-default.png) and [news-field](components/crops/news-field-default.png).
3. **Do reserve pink for the primary action.** `#ff13b1` paints exactly once — the hero's Start creating — with the `#ff3dae` save pill as its only echo; `#ff4bc4` is the hover. See [save-pill](components/crops/save-pill-default.png).
4. **Do reserve blue for education.** `#2c5cff` marks the education chip and CTA only; hover `#5a65ff`. See [edu-cta](components/crops/edu-cta-default.png).
5. **Do invert the primary button.** The default action is a white pill with near-black text; on the app shell it drops to `#efefef` ink. See [plan-cta](components/crops/plan-cta-default.png) and [send-code](components/crops/send-code-default.png).
6. **Do build cards from near-blacks, not borders.** `#121212` tiles at 33px under a `#222` ring; fields read `#1e1e1e` under `#2a2a2a`; hover lifts to `#1d1d1d`, never to a colour. See [plan-card](components/crops/plan-card-default.png).
7. **Don't invent a light theme.** Neither surface has one; every value here is dark.
8. **Don't style the editor from this package.** The product's canvas, tools and panels are behind sign-in and uncaptured.

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/endlesstools/`):

```sh
python3 tools/build_component_tokens.py        # raw/components-computed.json -> raw/component-tokens.json
python3 tools/build_tokens.py                  # -> tokens.json
python3 tools/build_style_guide.py             # -> style-guide.html
python3 tools/build_components_md.py           # -> components.md
node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir>    # full-colour PNGs -> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.

Live recapture (needs the sites; Playwright at `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs`, and `PYTHON` pointing at an interpreter with Pillow so the crops quantise in-run):

```sh
node tools/capture/vars.mjs                    # stylesheet harvest -> raw/css-vars.json
node tools/capture/public/measure.mjs          # computed styles + crops -> raw/components-computed.json
RAW=<scratch> node tools/capture/public/public.mjs   # screenshots -> <scratch>
```

endlesstools.io and app.endlesstools.io load fine headless from this client; the editor behind sign-in stays a boundary.
