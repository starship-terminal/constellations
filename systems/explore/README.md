# Explore design reference

A token set and component reference for **explore.family** — the ad-free social platform for creatives that ran from roughly 2019 until its shutdown on **2023-04-19** — for building portfolio feeds, profile pages, marketing chrome and split auth screens in the style of the real thing. The domain later lapsed (DNS NXDOMAIN, RDAP 404), so nothing was read from a live site: every page was **replayed from a local Internet Archive mirror of the 2023-02-23 build**, signed out, in headless Chromium at 1440 x 900 and 390 x 844, on **2026-11-14**. Captured: home, /discover, /login, /register, /forgot-password, /about, /terms, /privacy, /conduct, the signed-out profile and post shells, the server-rendered /malikafavre and /sawdust profiles, the June 2023 closure announcement, and mobile passes on home, discover, login and register.

Explore's look is a study in restraint: a signature mid-grey field (`#9d9d9d`) for the fixed header, hero and media placeholders over white pages (the auth welcome panel is the darker `#717171`); one yellow accent (`#ffc60a`) spent on "Sign up free", the about-page CTA and the PRO badge; dark submits (`#262626`, 7px corners) on every auth form; a warm-neutral ramp (`#262626` ink to `#efefef`/`#ebebeb` hairlines); UntitledSans for UI with UntitledSansMedium post titles and LabilGrotesk-Medium display lines; 7–8px radii on cards and fields against 20px category pills and 50px CTA pills. **The site declares no token layer**: every value here was mined from the compiled `app.4ef09b07.css` or measured as a computed style. **Boundary:** everything behind sign-in (the member feed, composer, notifications, subscriptions, the dark portfolio theme) was never reached, and much of its API was never archived — signed-out profile/post routes render honest shells, while member-facing profiles survive only in the archived server-rendered HTML. Some post media was never archived and shows as grey placeholders.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export explore` prints them all with aliases resolved.

### Principles

1. Do design in grey and white.
2. Do spend the yellow on action.
3. Do pair pills with small radii.
4. Do use the three voices.
5. Do let the feed breathe.
6. Don't style the member app from this package.
7. Don't read placeholders as design.
8. Don't fabricate form outcomes.
9. Don't copy the brand.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

| Step | What ran |
|---|---|
| Archive mirror | `/`, `/css/app.4ef09b07.css`, the app/vendor JS bundles, fonts, images, uploads and the `/category/*` + `/discover*` API records of the 2023-02-23 web.archive.org snapshot, plus the 2023-06-08 closure snapshot and the SSR profile HTML, mirrored under `~/.design-systems/explore/mirror/` |
| Screenshots | `tools/capture/public/public.mjs` — routes `explore.family` and `back.explore.family` to the mirror, replays 14 desktop pages at 1440 x 900 (default + stitched `-full`, capped at 8 tiles) and 4 at 390 x 844, plus the SSR profiles with JavaScript disabled; mirror misses recorded per capture |
| CSS harvest | `tools/capture/vars.mjs` — every declaration in the compiled stylesheet (1850 rules), font faces, colour normalisation and histograms; the `--` strings in its selectors are BEM modifiers (`.btn--yellow`), not custom properties |
| Measurements | `tools/capture/public/measure.mjs` — 57 components on public routes only; hover/focus-visible/pressed/focused/filled states; nothing signed into, submitted or followed |
| Tokens | `tools/build_component_tokens.py` → `raw/component-tokens.json` → `tools/build_tokens.py` → `tokens.json` |
| Docs | `tools/build_components_md.py`, `tools/build_style_guide.py`, `tools/capture/public/build-measurements.mjs` |

- **Provenance.** Every token leaf names its source in `$extensions.source`: `css <selector>` for declarations mined from the compiled stylesheet, `measured <what>` for computed-style readings on the replayed pages.

## What to distrust

- **The archive, not the live product.** Every pixel is the February 2023 build replayed offline; the product changed after that snapshot and then closed. Treat the package as a historical record of one build, not the platform's final state.
- **The signed-in product and missing APIs.** `/sawdust` and `/p/2193` render as signed-out shells because the member/post API records were never archived — their layouts are honest boundaries, not real profile/post pages. The SSR profiles are real archived markup but only for the three members whose HTML was captured.
- **Grey media tiles.** Where a post's MP4/GIF/WebP was not archived the card paints its `#9d9d9d` placeholder; a sparse-looking grid is an archive gap, not the design. The Conduct page's illustration is one of these misses.
- **The forms.** Email/password fields were measured at rest and typed into then cleared — validation, error, loading and success states are unverified because nothing was submitted, and no backend ever answered.
- **`font.weight.medium`.** The design expresses "medium" through the UntitledSansMedium and LabilGrotesk-Medium families, both served at weight 400; there is no 500 weight to copy.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs; read exact colours from tokens or the raw values, never the pixels.
- **Values picked from the sheet.** The colours, type ramp, radii, spacings, containers and motion were chosen from the compiled stylesheet at capture time. The builder now checks each one is still declared in `raw/css-declarations.json` under the right properties and stops if not; the leadings are derived from declared font-size/line-height pairs. `core.zIndex.modal` (999) has no declaration behind it and is labelled as entered by hand.
- **`pill` and `pill-idle` have no focus reading.** Keyboard focus never reached them, so their `focus-visible` readings are the element at rest: components.md and `raw/measurements.md` leave them out. Needs a recapture; `measure.mjs` now records such a state as skipped (edited, not run).
- **Automation was masked during capture.** Until 2026-11-20, `tools/capture/public/lib.mjs` hid `navigator.webdriver` in every page it opened, so every committed reading was taken with that mask. The mask is removed (a bot check is now recorded as a boundary, not bypassed); whether any page needed it to load is not known, and a recapture without it is the check.

## Fonts

- **UntitledSans** — the UI voice (body 16/22 400, controls 14px), served as `UntitledSans.91064df2.woff2` (Klim Type Foundry, proprietary).
- **UntitledSansMedium** — post titles and heavier UI text, `UntitledSansMedium.d73a4fdc.woff2`.
- **LabilGrotesk-Medium** — the 40–41px hero/about display lines and the wordmark, `LabilGrotesk-Medium.19ad2c69.woff2` (Kometa, proprietary).
- **system** — a declared `system` family maps to local OS faces for fallback.
- None is bundled here; the style guide falls back to system faces. Declared `@font-face` rules are in `raw/css-declarations.json`.

## Coverage

- 14 desktop routes and 4 mobile routes replayed signed out from the archive, plus the closure-announcement shell and two SSR profile pages; one fixed light theme on every public surface (no `prefers-color-scheme` rule exists in the compiled CSS).
- 57 components measured in 104 states, including forced-pressed controls, keyboard focus and typed-then-cleared auth fields.
- Missing surfaces (declared in the catalog's `capture.gaps`): every signed-in member surface, SPA routes whose API was never archived, unarchived media, `/reset-password`, and the dark portfolio theme.
- Icons: layout gap — the interface icons are inline SVGs in the compiled Vue bundle and were not lifted this pass; they are visible in the crops and screenshots.

## Do and don't

1. **Do design in grey and white.** Pages are white with the `#9d9d9d` field reserved for the header, hero, auth welcome panel and media placeholders — restraint is the system. See [home-light-default](screenshots/home-light-default.png) and [hero](components/crops/hero-default.png).
2. **Do spend the yellow on action.** `#ffc60a` marks "Sign up free", the register submit and the PRO badge — one accent, always functional. See [nav-signup](components/crops/nav-signup-default.png) and [reg-submit](components/crops/reg-submit-default.png).
3. **Do pair pills with small radii.** Buttons and category filters are full pills (50px/20px) against 7–8px cards, fields and tags. See [pill](components/crops/pill-default.png) and [login-submit](components/crops/login-submit-default.png).
4. **Do use the three voices.** UntitledSans for UI text, UntitledSansMedium for post titles and tags, LabilGrotesk-Medium only for display lines and the wordmark. See [hero-title](components/crops/hero-title-default.png) and [post-title](components/crops/post-title-default.png).
5. **Do let the feed breathe.** Cards are 33.3% wide with 15px side padding and a 50px row pitch inside a 1640px-max, 20px-gutter column; metadata sits under media, never on it. See [post-card](components/crops/post-card-default.png) and [discover-light-default](screenshots/discover-light-default.png).
6. **Don't style the member app from this package.** Everything behind sign-in — composer, feed, notifications, subscriptions, the dark portfolio theme — was never captured; only the signed-out shells exist. See [profile-shell-light-default](screenshots/profile-shell-light-default.png).
7. **Don't read placeholders as design.** Grey media tiles mean the archive lacks the asset; real posts hold any-dimension imagery. See [discover-light-full](screenshots/discover-light-full.png).
8. **Don't fabricate form outcomes.** Log in, Sign up and Reset were measured, never pressed; what a submission returned is unverifiable now. See [field-email](components/crops/field-email-default.png).
9. **Don't copy the brand.** The E wordmark, the yellow and the member artwork are Explore's and its members' published work; borrow structure and proportion, not identity. See [auth-logo](components/crops/auth-logo-default.png).

## Rebuild

From the repo root, Playwright at `PLAYWRIGHT` (index.mjs) and Pillow at `PYTHON`. The mirror lives outside the repo at `~/.design-systems/explore/mirror/` (rebuild it by re-downloading the 2023-02-23 / 2023-06-08 snapshots from web.archive.org); the replay is fully offline once it exists.

```sh
cd systems/explore
PLAYWRIGHT=$PW node tools/capture/public/public.mjs                 # -> ~/.design-systems/explore/raw-shots/
python3 tools/capture/quantize.py ~/.design-systems/explore/raw-shots  # -> screenshots/ + .capture.json sidecars
PLAYWRIGHT=$PW PYTHON=$PY node tools/capture/vars.mjs              # -> raw/css-declarations.json
PLAYWRIGHT=$PW PYTHON=$PY node tools/capture/public/measure.mjs    # -> raw/components-computed.json + crops
node tools/capture/public/build-measurements.mjs                    # -> raw/measurements.md
python3 tools/build_component_tokens.py                             # -> raw/component-tokens.json
python3 tools/build_tokens.py                                       # -> tokens.json
python3 tools/build_style_guide.py                                  # -> style-guide.html
python3 tools/build_components_md.py                                # -> components.md
make -C ../.. design-md grade check                                 # repo-level: DESIGN.md, health, validation
```
