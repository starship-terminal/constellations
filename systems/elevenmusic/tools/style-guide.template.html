ElevenMusic, measured

elevenmusic.io is one Next.js app shell over Tailwind v4, painting dark by default (html.dark) on a true-black field with white-alpha ramps — and a real warm-paper light theme flipped by the footer's own System/Light/Dark control. It declares a shadcn-style semantic layer (--background/--foreground/--card/--primary/--muted/--border/--sidebar-*) plus its own --surface-*, --lighten-*, --lift-*, --composer-* and --gray-alpha-* extensions. Type is Inter variable for the UI and waldenburg light for display. The real pixels are in screenshots/ and components/crops/.

Read from elevenmusic.io, signed out, in headless Chromium. Everything behind sign-in — Create, Composer, Library, Chat, publishing, Likes, Remixes and Shares — is a documented boundary; the email field was filled and cleared without submitting, and no OAuth or Create button was ever pressed. Inter, waldenburg and GeistMono are served faces and are not loaded here: samples fall back to system sans.

    Palette

    The Tailwind --color-* palette and the shared --darken-* overlay ramp are identical in both themes and live in core; the semantic roles re-bind per theme — the dark set is the app's default paint, the light set the warm-paper remap (its --lighten-* steps resolve in dark only).

    Spacing and radius

    A 4px spacing base, the --radius-* scale from 2px to 24px, and the components painting inside it — pills and full circles on controls, 6-16px on cards. Borders are quiet: white at 8-12% on the dark field.

    Shadows

    Shadows re-bind per theme: the dark set pairs near-invisible drops with white hairline insets, the light set uses soft warm drops.

    Type

    Two served faces plus a mono: waldenburg light on display headlines, Inter variable on the UI, GeistMono for code and IDs. Sizes are the declared Tailwind --text-* steps 12-72px.
