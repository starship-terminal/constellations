# ElevenMusic design reference

A token set and component reference for ElevenMusic's public surface — for building dark, quiet, tool-like music apps in the style of the real thing. It was read from **elevenmusic.io** on **2026-11-13**, signed out, in headless Chromium at 1440 x 900 and 390 x 844: the home composer, Explore, Charts, Tracks, Genres, a genre shelf, Sounds, Tools, an artist profile, a playlist, the blog, Pricing, and the log-in / sign-in cards, at desktop and phone widths, in the app's default dark paint and the footer's own light theme.

ElevenMusic ("Studio-grade. Fully licensed.") is worth a capture because it is a study in restraint on a true-black field: an almost-monochrome system where white itself is the action colour — the Start-free and Create buttons invert to white pills with black text — surfaces climb only a few percent of white-alpha (`#131313`/`#1c1c1c`/`#262626` steps), every hairline is `rgba(255,255,255,.08–.12)`, and the one saturated voice is the `#5d88e7` ElevenLabs brand blue kept for badges and links. A fixed 248px rail, a 52px header, an inner scroller per page, a 72px transport bar, pill controls everywhere (999px radii), waldenburg light display type over Inter, and a real light theme — warm paper `#fdfcfb` with brown-grey alphas — flipped by the footer's own System/Light/Dark control. **Boundary:** everything behind sign-in — Create, Composer, Library, Chat, publishing, Likes, Remixes, Shares, search itself — was measured, never entered, never submitted.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export elevenmusic` prints them all with aliases resolved.

### Principles

1. Do paint near-true black.
2. Do invert the primary.
3. Do hairline at white-alpha.
4. Do keep one blue for identity.
5. Do pill at 999px.
6. Do set display type light.
7. Do invert the light theme honestly.
8. Don't style the signed-in app from this package.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

- **Declared tokens.** `tools/capture/vars.mjs` reads every stylesheet the pages serve — the same-origin Next.js bundles and the inline blocks on `/`, `/explore` and `/pricing` — and resolves every custom property twice, once with the page painted light and once dark (the app paints `html.dark` by default). The product declares a real semantic layer: the shadcn-style `--background/--foreground/--card/--primary/--muted/--border/--sidebar-*` roles plus its own `--surface-*`, `--lighten-*`, `--darken-*`, `--lift-*`, `--composer-*`, `--gray-alpha-*` and `--chart-*` extensions, the Tailwind `--color-*` palette, and the `--text-*`, `--radius-*`, `--blur-*`, `--tracking-*`, `--leading-*`, `--font-weight-*`, `--container-*` scales. Those are the `css-var` leaves in `tokens.json`.
- **Measured values.** `tools/capture/public/measure.mjs` opens each public page in headless Chromium (Playwright), holds each component in a state, and reads the computed style — size, padding, radius, colours, shadow, outline, font, transition — plus a cropped screenshot per state. Hover is a real pointer hover; `focus-visible` a real keyboard focus (53 of 59 focused controls draw a 1px `lab(100 0 0)`/`lab(98.26 0 0)` ring at 1–2px offset); `pressed` is forced with DevTools; `selected` the rail's own state on its page; `focused`/`filled` a field clicked into and given sample text that is deleted again; `expanded` the FAQ and options toggles' own clicks.
- **Screens.** `tools/capture/public/public.mjs` takes viewport and full-page shots of every public route — the pages scroll inside one inner element, which the shooter expands for the full shot (the two pages that still exceed a GPU texture are tiled `*.part0/.part1`). The `*-light-*` shots reuse the context after the footer's own Light-theme button — a local UI toggle persisted by the product's cookie. `home-dark-menu` is the opened Resources dropdown, `home-dark-search` the sign-in dialog the Search button opens, `login-dark-options` the expanded email form, `explore-dark-playing` the mounted player bar.
- **Honesty.** The Cookiebot overlay and Google One-Tap prompt were hidden with CSS, never answered. No account was created, no OAuth button pressed, no form submitted, no prompt sent, nothing liked, remixed, shared or published; the only presses were local UI toggles and one card's Play for the transport evidence. A failed measurement stays a failure in the JSON (for example the player prev/next hovers that could not be held), never a fabricated reading. `tools/capture/quantize.py` stores the shots as 256-colour PNGs, so read exact colours from `tokens.json` or `raw/`, never off a screenshot.

## What to distrust

- **This is the public shell, not the signed-in app.** Create, Composer, Chat, Library, publishing, account and billing live behind sign-in and are uncaptured. The login/sign-in forms were measured; they were never submitted and no OAuth button was pressed. What the product looks like past that wall is unknown.
- **Search is gated, not captured.** The rail's Search button opens the log-in dialog — captured as `home-dark-search` — so a real search surface and its results are uncaptured.
- **The two `lab()` focus tokens are real.** ElevenMusic paints its focus rings in CSS `lab()` — `lab(100 0 0)` dark / `lab(98.26 0 0)` light — measured and tokenised verbatim, not quantisation artifacts.
- **Tall pages are tiled.** The pages scroll inside one inner element; expanding it for `/charts` and mobile `/` still exceeded a GPU texture, so those full shots are `*.part0.png`/`*.part1.png` pairs, never single frames.
- **`faq-answer` was read open.** `faq-item`'s `expanded` reading opened the row and left it open, so `faq-answer`'s default (152px tall against the 68px closed row) is the open item. components.md marks it and no token reads it; `measure.mjs` now closes the row after the reading (edited, not run).
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs; read exact colours from tokens or the raw files.
- **Recorded misses.** `player-prev`/`player-next` could not be held under a forced hover — their hover readings are recorded as failures in `raw/components-computed.json`, not values; `player-shuffle` found no stable element and is recorded missing.
- **Automation was masked during capture.** Until 2026-11-20, `tools/capture/public/lib.mjs` hid `navigator.webdriver` in every page it opened, so every committed reading was taken with that mask. The mask is removed (a bot check is now recorded as a boundary, not bypassed); whether any page needed it to load is not known, and a recapture without it is the check.

## Fonts

**Inter** (variable) is the UI face — nav, fields, buttons, labels, captions — with Arial fallback declared. **waldenburg** light/regular is the display face — the "Make music yours." and section headlines. **GeistMono** is the mono face (times, counters, code-adjacent labels) over a long fallback tail. The `@font-face` harvest is in [raw/css-vars.json](raw/css-vars.json); none is distributed with the package — the style guide falls back to system sans.

## Do and don't

1. **Do paint near-true black.** `#000000` page with white-alpha surface steps (`#131313`/`#1c1c1c`/`#262626`); never a warm dark. See [home-dark-default](screenshots/home-dark-default.png).
2. **Do invert the primary.** The one saturated control is a white pill with black text — Start free, Create, Play — not a colour. See [cta-btn](components/crops/cta-btn-default.png).
3. **Do hairline at white-alpha.** Borders are `rgba(255,255,255,.08–.12)`, never a grey; the composer row and plan card read as fills on black. See [plan-card](components/crops/plan-card-default.png).
4. **Do keep one blue for identity.** `#5d88e7` is reserved for the model badge, links and brand marks — it never fills a button. See [version-badge](components/crops/version-badge-default.png).
5. **Do pill at 999px.** Every interactive control — nav, chips, CTAs, send circle — runs to a full pill radius; cards take 16px. See [prompt-chip](components/crops/prompt-chip-default.png).
6. **Do set display type light.** waldenburg at light weight, not bold, carries the headlines; Inter does all the UI work. See [hero-title](components/crops/hero-title-default.png).
7. **Do invert the light theme honestly.** The footer's own toggle rebinds every role to warm paper `#fdfcfb` with brown-grey alphas — a real remap, not an inversion filter. See [home-light-default](screenshots/home-light-default.png).
8. **Don't style the signed-in app from this package.** Create, Composer, Library and publishing are behind the wall; every value here is the public shell's. See [auth-card](components/crops/auth-card-default.png).

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/elevenmusic/`):

```sh
python3 tools/build_component_tokens.py           # raw/components-computed.json + css-vars.json -> raw/component-tokens.json
python3 tools/build_tokens.py                     # -> tokens.json
python3 tools/build_style_guide.py                # -> style-guide.html
python3 tools/build_components_md.py              # -> components.md
node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir>       # full-colour PNGs -> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.

Live recapture (needs the site; Playwright at `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs`):

```sh
node tools/capture/vars.mjs                        # stylesheet harvest -> raw/css-vars.json
node tools/capture/public/measure.mjs              # computed styles + crops -> raw/components-computed.json
RAW=<scratch> node tools/capture/public/public.mjs # screenshots -> <scratch>
```
