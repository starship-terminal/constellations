# Supercut public site tree

Mapped on 2026-11-22 from the public homepage, https://supercut.ai/. Title: "Screen Recorder for Business Communication | Supercut". The homepage is a live marketing page, not a parked domain and not a captcha wall.

The map was read in an incognito preview tab. Photographs of the marketing pages were taken with headless Chromium after the cookie banner was removed from the DOM. Login and signup sit behind a Cloudflare check in that headless browser, so those two walls were photographed in the same incognito preview tab, which had already passed the check. Desktop shots are 1440 by 900 CSS pixels at 2x (PNG width 2880). Phone shots are 390 by 844 CSS pixels at 2x (PNG width 780).

Nothing was typed. No email, password, code, phone, or address was entered. No form was submitted. No identity provider was clicked. No captcha was solved. No recording was started and no video was uploaded. `login-extracted` stays not-started. catalog.json was left alone.
