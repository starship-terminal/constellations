# Patterns

Public site patterns from the 2026-11-21 walk.

## App shell

A 56px sticky header, orange primary action on the right, three mega menus in the center. At 390px the center links collapse into a Mobile Menu sheet. The footer repeats product, use case, resource, and company columns, then a newsletter field that was not submitted.

## Navigation

Product, Use Cases, and Resources are buttons. Each opens one panel and sets `aria-expanded`. Docs, Demo, and Pricing are links. Login and Get Started leave the marketing host for the dashboard auth wall.

## Search

Docs exposes "Search... ⌘K" and opens a search dialog. The bot directory has an empty search field and a Filters button. Neither query was submitted.

## Pricing

Volume buttons (20K through 1M+) sit above the plan cards. Compare all features expands a comparison table.

## Auth wall

The dashboard login is a dialog over a blurred identification table. Google, GitHub, and Microsoft sit above Continue with email. Email then reveals email and password. The branch stops there.
