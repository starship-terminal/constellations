Hand copy of the measured homepage tokens. Not written by `make design-md`. This pass does not edit catalog.json.

## Typography

AkkuratPro is the UI face. Chronicle Display is the display face. ChronicleText is the serif face. None of the files are in this package.

| Style | Size | Weight | Line |

| meta | 12px | 700 | 16px |

## Geometry

Buttons, size chips, and the email field use 2px radius. The service ribbon is 32px. The header bar is 106px under that ribbon. Add to Bag is 40px. Shop now is 42px. A size chip is 90 by 40.

## Components

Shop now is white with ink type, 42px, 2px radius. Add to Bag is ink with white type, 40px, and was not clicked.
