Cohere, declared and measured

Every value on this page is a CSS custom property generated from tokens.json. cohere.com declares its design layer as Tailwind config utility classes, not :root variables — a named palette (volcanic brand greys, the workhorse neutral ramp, quartz/coral/mushroom/marble/blue/green/danger/success plus onyx/pureBlack/pureWhite), the text-web3-* type scale, the font-* family stacks (Unica77 Cohere Web, CohereMono, CohereVariable), a custom radius scale and the z-*/max-w-web3-* layers. Roles are measured on the painted chrome: the dark ease-button-gradient CTA pills, the pureBlack promo banner, the footer band and the sign-in card. Brand art is the hero illustration.
