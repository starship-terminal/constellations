# IKEA design reference

A token set and page reference for the IKEA Singapore public storefront (`https://www.ikea.com/sg/en/`), captured signed out on 2026-11-21 in headless Chromium. Desktop shots are 1440×900. Phone shots are 390×844. One light theme. The login page was opened and the branch stopped. No password was typed. Country and store were not changed.

## How the values were read

Custom properties were read with `getComputedStyle(document.documentElement)` on `https://www.ikea.com/sg/en/` in headless Chromium on 2026-11-21. IKEA stores colours as comma-separated RGB channels (`--colour-neutral-7: 17, 17, 17`). `tools/build_tokens.py` turns those channels into hex and labels them Measured. Body font size 14px and the h1 size 40px / 50px / weight 700 were read from computed styles on the same page. No dark-theme selector was present.

## What to distrust

- Body line height in `core.typography.body` repeats the 14px font size. The computed line height was not stored.
- `light.focus.ring` is Not captured. It aliases brand blue so the file has a token, and it is not a measured ring.
- Pill button radius was not a custom property. The style guide draws a pill because the login buttons are pills. That radius is not in `tokens.json`.
- Screenshots are the layout. Read colours from `tokens.json`.
- The cookie card is a shadow-root element. The capture hides its host and does not click it. A shot that still shows "Accept all cookies" was taken before that hide and should be discarded.
- A selected store name can appear in the header from a site preference. The capture script replaces that label with "Store" when it can. If a shot still shows a store name, treat that string as private and do not copy it.

## Fonts

Noto IKEA is the family the site loads. The stack also names Noto Sans, Roboto, Open Sans and system-ui. Noto IKEA is the product's font and is not committed. The guide falls back to Noto Sans and system-ui.

## Do and don't

- **Do set type in near-black on white.** Primary text is #111111 on #ffffff. Body copy is #484848. See [home-light-default.png](screenshots/home-light-default.png).
- **Do use the black pill for the main action.** Primary fill is #111111, hover #333333, pressed #000000. See [login-light-login-wall.png](screenshots/login-light-login-wall.png).
- **Do keep yellow on the logo.** #ffdb00 is the brand yellow. It is not a page fill. See the header in [home-light-default.png](screenshots/home-light-default.png).
- **Do use blue for the emphasised action.** #0058a3 is `--colour-static-ikea-brand-blue` and the informative semantic colour.
- **Don't round product photography.** `--product-image-radius-m` and `--product-image-radius-s` are 0px.
- **Don't follow the login branch.** The account page asks for a password. Stop there.
