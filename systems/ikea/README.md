# IKEA design reference

A token set and component reference for IKEA's public signed-out storefront. Read from www.ikea.com on 2026-11-19, signed out, in headless Chromium at 1440 x 900 and 390 x 844.

ikea.com redirects to www.ikea.com, which is a country picker titled "Hej! Welcome to IKEA Global". It is a real page, not a dead redirect. From this capture host the shopping link the page names is IKEA Singapore, `https://www.ikea.com/sg/en/`. That locale is what this package captures. The US English storefront (`/us/en/`) also exists; it is a different market and was not measured.

Surfaces: the global picker, the Singapore home and its search field, Sofas and armchairs, the BILLY bookcase product page, search for "lamp", the store locator, the signed-out login card, and Offers. Desktop and phone.

IKEA paints the storefront with Skapa. Colour roles are `--colour-*` rgb triplets (brand blue `#0058a3`, brand yellow `#ffdb00`, neutrals from `#ffffff` to `#111111`). The emphasised buy button is a brand blue pill, 56px high with a 64px radius (`core.radius.cap`). Type is Noto IKEA at a 14px body. Product photos are square. One light theme.

## Do and don't

1. **Do keep the page white and the wordmark yellow on blue.** The header sits on `#ffffff`. The oval wordmark is `#ffdb00` on `#0058a3` (`light.yellow` on `light.accent`). See [home-light-default](screenshots/home-light-default.png) and [logo-default](components/crops/logo-default.png).
2. **Do use brand blue for the buy action.** Add to cart is `#0058a3`, white label, 64px radius (`core.radius.cap`). See [button-primary-default](components/crops/button-primary-default.png).
3. **Do keep product photos square.** Cards and the PDP gallery use 0px image radius. See [product-card-default](components/crops/product-card-default.png).
4. **Do set body type at 14px in Noto IKEA.** Secondary text is `#484848` (`light.muted`). See [product-light-default](screenshots/product-light-default.png).
5. **Don't invent a dark theme.** The storefront paints one light theme. No theme toggle was found.
6. **Don't press Add to cart, Log in, or a cookie button.** Those controls were measured and never activated. Checkout, the account, and payment sit behind sign-in. See [login-light-default](screenshots/login-light-default.png).
7. **Don't treat the global picker as the shop.** www.ikea.com lists countries. The shop in this capture is Singapore English. See [global-light-default](screenshots/global-light-default.png).

## How the values were read

Custom properties were harvested from the stylesheets on `https://www.ikea.com/sg/en/` and the BILLY product page, then resolved on `documentElement`. Colour tokens are the declared `--colour-*` rgb triplets, written as hex. Radius, space, duration and easing are the declared `--radius-*`, `--space-*`, `--duration-*-web` and `--ease-*` values. Component colours were read from computed style on the live DOM. Screenshots are 256-colour PNGs. OneTrust was hidden with CSS. It was never clicked.

## What to distrust

- **Most type weights and line heights were typed.** Every `core.typography.*` size is the declared Skapa step. Only heading-l (24/30 700, the login heading) and heading-s (16/20 700, the product title) are read from a component; the other weights and line heights (display 80/64/48px, heading 40/24px, body 24/22/18px, price 32px) have no reading and say Reconstruction. `core.font.family.sans` is abridged by hand from the measured body stack.
The buy button's own `background-color` is transparent. The blue fill is painted by the inner `.pipf-btn__inner` span. A reading of the button element alone looks unfilled. Hover on that button did not change the computed background in this pass, so hover is the declared `--colour-interactive-emphasised-bg-hover` (`#004f93`), not a second computed reading. Noto IKEA is proprietary and is not in the package. The style guide falls back to Noto Sans. Currency-symbol faces lead the live font stack and are not design faces.

## Fonts

Noto IKEA is IKEA's proprietary UI face. The tokens name it, then Noto Sans, system-ui, sans-serif. It is not committed. The wordmark is the yellow oval SVG in [icons/logo.svg](icons/logo.svg), not a text face.
