# Riverside

Riverside is HD podcast and video software. This package covers the public marketing site and the signed-out studio login, measured on 19 November 2026 from a signed-out browser. No account was created.

The marketing site (riverside.fm, which redirects to riverside.com) is a light Webflow page. The studio login and register at riverside.com/login and riverside.com/register are a separate dark product sheet. Both themes below are paints that were on screen. Light is marketing. Dark is the studio auth shell.

The viewport that was measured was 1169 by 731 CSS pixels at device pixel ratio 2. A 1440 and a 390 pass were not taken: the preview tab was in fill mode, and `preview_snapshot` returned "The browser is not producing screenshot frames", so the size could not be rechecked with a screenshot.

## How the values were read

Values were read with `preview_evaluate` in the T3 Code preview browser on 19 November 2026. Custom properties were collected from accessible stylesheets and resolved on `:root`. Component values are `getComputedStyle` on the live elements named in each token's `$extensions.source`.

Pages read: https://riverside.com/homepage, https://riverside.com/pricing, https://riverside.com/recording, https://riverside.com/login, and https://riverside.com/register. https://riverside.com/signup is a marketing 404.

Three marketing stylesheets were cross-origin and could not be walked. The custom properties that resolved on `:root` were still read. Studio component tokens that only exist under a theme selector (tabs, menus, segmented controls) were read from the declared rule, not from a painted element, and are listed as gaps when they were not on screen.

## What to distrust

There are no screenshots. `preview_snapshot` failed with "The browser is not producing screenshot frames". Do not treat a missing image as a capture of the layout.

The marketing type ramp is a set of `clamp()` custom properties between a 375px and a 1440px viewport. The type tokens are the computed sizes at 1169px, not the clamp endpoints.

Keyword easings (`ease`, `ease-out`, `ease-in-out`) are expanded to cubic-bezier control points. Those expansions are Derived.

The marketing plan border `#1b2127` and the highlight wash `#f2eeff` were computed colours, not named marketing custom properties. The highlight matches the studio `--color-primary-c100` hex.

`--black-02` was declared as `#111` and stored as `#111111`. `--black-2` was declared as `black` and stored as `#000000`.

## Fonts

Instrument Sans is the marketing UI face, with Arial as the fallback the page declares. Sharp Grotesk is the marketing display face. The studio uses Inter for UI and Sharp Grotesk Book for the login heading. The font files are the product's and are not in this package. Tokens name the stacks the browser computed, including the fallbacks.

## Do and don't

**Use the purple pill for the marketing primary action.** The homepage CTA is `#9671ff` with white type, 100px radius, and 20px by 40px padding.

**Use the near-black pill for the nav action.** Start for Free in the bar is `#1d1d1d` on white type, 300px radius, 40px tall.

**Keep the studio auth shell on `#0d0d0d`.** Fields and social buttons are `#222222`, 8px radius, 40px tall. The submit button is `#7848ff`.

**Do not invent a light studio theme from the marketing page.** The studio declares `[data-theme="light"]` rules. No signed-out control painted that theme.

**Do not copy a screenshot colour.** There are no screenshots in this package.

## Gaps

The signed-in dashboard, a recording, a card form, SSO, and Google, Apple and Spotify continue buttons were not entered. Register was opened to the email step and not submitted, because it asks for a name and a password as well as an email. Screenshot frames were unavailable, so crops and full-page images are absent.
