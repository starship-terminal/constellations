Grammarly style guide

Grammarly, measured

Every value on this page is a CSS custom property generated from tokens.json, read signed-out from grammarly.com. The stylesheets carry two layered systems: the legacy GDS layer (--green-60 ramps, the --color-* semantic palette, --button-*, --tag-*, --space-*, --radius-*, --elevation-*, --z-index-*) and the newer Origin layer (--origin-* primitives and the --origin-color-* semantic palette). The header pick flips data-theme between the painted light theme and the dark values the stylesheets declare under [data-gds-theme="dark"]/[data-origin-mode="dark"] — no public page mounts those attributes, so dark is reconstruction, not painted evidence. The mock controls below are rebuilt from the tokens; the real pixels are in screenshots/ and components/crops/.

Each token's provenance (the declaring selector, the page it resolved on, or the measurement it came from) is in the tables at the bottom and in tokens.json under $extensions.source. Matter is Grammarly's display face; it is not loaded here, so the heading samples fall back to Inter — the same fallback the token stacks name.

Colour

color.* is the GDS semantic palette the public pages read; origin.* is the Origin semantic palette declared beside it. Flip the theme pick to watch the declared dark values — base ground and ink invert, brand lifts from #027e6f to #2cc9b6, the subdued tints deepen instead of lightening.

color.* — the GDS semantic layer
origin.* — the Origin semantic layer
button.* — the GDS button tokens
tag.* — the tag fills

Palette

The Origin ramps feed the Origin semantic layer; the legacy GDS ramps (under palette.gds) feed the GDS one — --button-primary-background-default is literally var(--green-60). Both live in core and do not change with the theme.

Type

Two faces: Matter for the display roles (heading-xxsmall through heading-xlarge, 14–28px), Inter for the text roles (12–18px). Headings draw at weight 600, tracking 0 throughout. The larger paragraph sizes (24/36px) the marketing ledes use are in the font table below.

Radius, space and size

A 4px-grid system: space-N and radius-N are N×4px (buttons sit at radius-2 8px on the Origin scale, 6px measured on the GDS-skinned controls). Controls come in five heights, 24–52px. The named roles (button-small/medium/large) hold 4/6/8px.

Elevation

Origin elevations are a single soft layer — ink at 15%, low/medium/high by blur and offset — while the legacy GDS pairs a shadow with a 1px outline. Dropdowns and the sticky header ride the low pair.

Motion

The GDS transition is 200ms; the Origin accordion and multiselect run 300ms on a hard cubic-bezier(0.87, 0, 0.13, 1). Click a track to run it. What the pages actually run is measured in raw/motion.json; the stylesheets also declare a prefers-reduced-motion scope.

Buttons, as declared

Seven variants on the --button-* tokens: primary is the brand green with white ink, pro and premium the gold, enterprise the deep purple, ghost and tertiary transparent. Hover/active come from the same tokens — the site's buttons also shrink a touch on press, which the measurements record but the tokens do not declare.
