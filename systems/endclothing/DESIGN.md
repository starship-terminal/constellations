# END.

A signed-out capture of the public END. shop at [https://www.endclothing.com](https://www.endclothing.com), on 2026-11-22. The first load was Singapore. The footer country control was set to the United States, and the photographed pages are `/en-us` with USD prices. Desktop 1440 by 900. The page is white, the announcement ticker is black, and the ink is `#1a1a1a`. The current department is `#232ebc`. Body type is proxima-nova. Primary actions are 46 to 50px with a 2px radius.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

## Type

proxima-nova for body, nav, prices, and buttons. Body 16px, weight 400, line-height 24px. Nav is 12px, uppercase, letter-spacing 1.2px. Ticker is 12px, weight 600, uppercase. Section titles are 12px, weight 600, letter-spacing 1.2px. Product title and collection title are 18px, weight 600. Buttons are 14px, weight 600, letter-spacing 1.4px, uppercase. Font files are not in this package.

## Controls

Buttons use a 2px radius. Shop Now is a white fill, ink text, 50px tall, padding 15px 40px. Select a Size is an `#1a1a1a` fill, white text, 46px tall, 399px wide. Sign Up is the same fill, 48px tall, 210px wide, and was disabled while the email field was empty. The header banner is 64px. The ticker is 40px. The wordmark is 57 by 21. Search is a 260 by 38 field in the header and was not submitted. Account, wishlist, and cart are 35px icon targets and were not opened.

The size control on the product page reads Select a Size. It was not clicked, so the size list was not opened.
