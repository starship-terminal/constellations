# COS public chrome

Signed-out capture of [https://www.cos.com](https://www.cos.com) on 2026-11-22. The URL geo-redirected to the Singapore storefront, [https://www.cos.com/en-sg/](https://www.cos.com/en-sg/). Desktop 1440 by 900, `devicePixelRatio` 2. Values are computed styles from the live page, recorded in [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

This file is a hand copy. `make design-md` was not run, because that command needs a catalog.json entry and this pass does not edit catalog.json.
