# Editor X / Wix Studio design reference

A token set and component reference for the public signed-out surface editorx.com now serves — for building marketing pages and galleries in the style of the real thing. It was read from **editorx.com** on **2026-11-13**, and the public control map was refreshed on **2026-11-21**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. editorx.com is now a redirect shell for **Wix Studio**: `https://www.editorx.com/` 301s to `https://www.wix.com/studio`, and `https://www.editorx.com/login` 301s to that same marketing home. `/pricing` still answers on editorx.com and still paints the *Couldn't load Premium plans* error pane. The 2026-11-21 map is [site-tree.md](site-tree.md). Walls stopped at are [login-review.json](login-review.json). Captured: home, features, design, plans, pricing, inspiration, templates, academy and enterprise, plus a 390px pass on home and plans.

The surface is worth a capture because Wix's pro builder paints a deliberately stark public system: **Madefor** at mostly one weight over pure `#000` ink and white surfaces, sharp 0px corners as the default with stadium pills where a control is meant to be pushed, a single `#3910ed` purple reserved for the Start Creating actions, a `#deff00` lime reserved for the closing band, and a `#0e0e0e` near-black chrome (the footer) whose `#f6f6f6` links dim to `#828282`. Underneath the marketing chrome the page is a thunderbolt build that declares its theme in custom properties — the `--color_0..65` palette, `--font_0..10` site fonts and the `--wst-*` semantic layer (action `#1a6aff`, text/fill/disabled roles) — harvested here from the inline styles and linked parastorage bundles. Display type is **spx-scaled**: font sizes track the viewport (`--theme-spx-ratio`), so the measured px values are the 1440 and 390 readings, not fixed sizes. **Boundary:** the Studio editor and everything behind Log In / Start Creating were never reached and are never inferred.

## Brief

### Principles

1. Do spend the purple on actions only.
2. Do go stadium or go square.
3. Do set display huge, tight and quiet.
4. Do let Madefor carry the whole voice.
5. Do paint the footer near-black.
6. Do keep the lime in reserve.
7. Do ring focus twice.
8. Don't style the Studio editor from this package.
9. Don't treat the display px sizes as fixed.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out site in headless Chromium:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) captures every stylesheet body — the thunderbolt inline `<style>` blocks re-parsed with `CSSStyleSheet` plus the linked static.parastorage.com bundles read off the network — and writes every custom property to [raw/css-vars.json](raw/css-vars.json), resolving each on a probe document. The site theme is openly named: `--color_0..65` (the studio palette), `--font_0..10` (the spx-scaled site fonts) and the `--wst-*` semantic layer (action, text, fill, disabled and button roles), so tokens var-reference it by name where a variable resolves the painted value, and everything else — the Wix Studio purple, the lime band, the chrome neutrals, the double focus rings, the radii and the type ramp — is measured computed values from [raw/components-computed.json](raw/components-computed.json). [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec, [tools/build_tokens.py](tools/build_tokens.py) the sets.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md). The pages are thunderbolt sites — every class is a hash and components are `comp-*` boxes — so every spec selects by role, aria-label, text or structure, never a class.
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route with `.capture.json` sidecars, including the local UI toggles: the Product mega-menu on home, an FAQ expander, and the mobile menu. Full-page shots are capped at eight chunks; home, design and mobile-home overflowed the GPU texture limit and stitched from chunks. [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.

Nothing was signed into, created, submitted or paid for: the Log In / Start Creating / plan actions were measured as surfaces, never followed; the only presses were local UI toggles (the Product dropdown, the FAQ expander, the mobile menu). The cookie banner was hidden per capture, never answered — no consent was ever posted.

## What to distrust

- **This is the marketing surface, not the editor.** The Studio editor, workspaces, dashboards and checkout sit behind Log In / Start Creating and are uncaptured. Marketing pages describe the product; nothing here verifies how it behaves.
- **This is Wix Studio, not 2021-era Editor X.** editorx.com 301s to wix.com/studio; the package documents the surface it serves today, not the defunct Editor X brand it once served. Only /pricing still answers on the editorx.com domain — and it served its error pane at capture time. Rechecked 2026-11-21: `/` and `/login` still 301 to `https://www.wix.com/studio`, and `/pricing` still paints the same error pane.
- **"Dark" is a painted surface, not a toggle.** The `#0e0e0e` footer is a dark section of a light page — nothing toggles it (the mobile header stays white). The `dark` token set is its painted role set, not a user-selectable mode.
- **Display sizes are spx-scaled, not fixed.** font-size tracks the viewport through `--theme-spx-ratio`: 80.25px hero and 157.5px design display are the 1440px readings (34.5px hero at 390). Treat the numbers as proportional.
- **The hero pill's anchor reads unstyled-link colours.** Its own `color` computes rgb(0,0,238) default / rgb(255,0,0) pressed — browser link-state quirks of the anchor; the label inside paints white, and the purple fill lives on a child layer whose hover reading caught mid-transition at alpha 0.
- **Unstyled containers read fallback fonts.** Thunderbolt leaves wrappers at Arial/Times; the text nodes inside carry Madefor. Type tokens cite the text-node readings (`textStyle`), not the wrapper's.
- **`logo` is the wrong element.** Its selector's `nav a` fallback matched the "Pricing" nav link first, so the `logo` entry in components.md holds that link's values, not the wordmark's. No token reads it. The selector is fixed in `measure.mjs` (edited, not run); the entry needs a recapture.
- **Quantised screenshots.** `screenshots/` and `components/crops/` are 256-colour PNGs; read exact colours from tokens or the raw files.
- **Automation was masked during capture.** Until 2026-11-20, `tools/capture/public/lib.mjs` hid `navigator.webdriver` in every page it opened, so every committed reading was taken with that mask. The mask is removed (a bot check is now recorded as a boundary, not bypassed); whether any page needed it to load is not known, and a recapture without it is the check.

## Fonts

One family does everything the styled surface paints: **Madefor**, served from static.parastorage.com under five face names — `Madefor-Display` / `Madefor-Text` on the marketing chrome (header, footer, mobile menu), `wix-madefor-display-v2` / `wix-madefor-text-v2` on the thunderbolt content, plain `Madefor` on the plans page. Weights seen: 400 (display and body), 500 (FAQ questions, plan labels), 530 (the wds button's variable weight) and 700 (plan text, menu links, badges). The `@font-face` blocks — 243 of them across the unicode-range splits — are harvested in [raw/css-vars.json](raw/css-vars.json). The font is licensed and not distributed with the package; the tokens carry the full stacks and the style guide falls back to system sans.

## Do and don't

1. **Do spend the purple on actions only.** `#3910ed` is the Start Creating header CTA and the hero 'Start creating' stadium — and the hover colour a mega-menu link takes. Never a background, border or body-text colour. See [nav-cta](components/crops/nav-cta-default.png) and [menu-link hover](components/crops/menu-link-hover.png).
2. **Do go stadium or go square.** The default corner is 0px — header CTA, plan cards, bands, galleries. Where a control pills it goes all the way: the hero stadium, the 50px link pill, 50% social circles. See [hero-cta](components/crops/hero-cta-default.png) and [social-icon](components/crops/social-icon-default.png).
3. **Do set display huge, tight and quiet.** Displays run 60-157px at 1.0 line-height with ~-0.03em tracking, all in the regular 400 weight — size and space do the work, not weight or style. See [hero-title](components/crops/hero-title-default.png) and [design-h1](components/crops/design-h1-default.png).
4. **Do let Madefor carry the whole voice.** Display face for headlines, Text face for body; the only weight shifts are 500/530 on quiet labels and 700 on plan text — no italics, no second family. See [faq-question](components/crops/faq-question-default.png).
5. **Do paint the footer near-black.** The footer is `#0e0e0e` with `#f6f6f6` links that dim to `#828282` on hover — a painted section treatment, not a dark mode (the mobile header stays white). See [footer](components/crops/footer-default.png).
6. **Do keep the lime in reserve.** `#deff00` appears once, as the closing CTA band — an accent of last resort, never on controls or text. See [cta-band](components/crops/cta-band-default.png).
7. **Do ring focus twice.** Content controls take a 2px white + 4px `#116dff` box-shadow pair; the header takes 1px + 3px ink; the dark chrome takes `#828282`. Never a bare outline. See [hero-cta focus-visible](components/crops/hero-cta-focus-visible.png) and [nav-link focus-visible](components/crops/nav-link-focus-visible.png).
8. **Don't style the Studio editor from this package.** Every value is the public surface's; the product behind Log In / Start Creating is uncaptured — [pricing-light-default](screenshots/pricing-light-default.png) is as deep as the capture goes.
9. **Don't treat the display px sizes as fixed.** They are spx-scaled to the viewport: 80px hero is the 1440 reading; the same headline is 34.5px at 390. See [m-hero](components/crops/m-hero-default.png).

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/editorx/`):

```sh
python3 tools/build_component_tokens.py        # raw/components-computed.json -> raw/component-tokens.json
python3 tools/build_tokens.py                  # -> tokens.json
python3 tools/build_style_guide.py             # -> style-guide.html

node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir>    # full-colour PNGs -> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.

Live recapture (needs the site; Playwright at `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs`, Pillow for the crop quantization via `PYTHON=<python with PIL>`):

```sh
node tools/capture/vars.mjs                    # stylesheet harvest -> raw/css-vars.json

RAW=<scratch> node tools/capture/public/public.mjs   # screenshots -> <scratch> (incl. the menu toggles)
```
