## How the values were read

A T3 preview tab opened `https://www.paypal.com/` with `reuseExistingTab` false. The page redirected to `https://www.paypal.com/sg/home` and was not a Cloudflare challenge. Computed styles were read with `preview_evaluate` on that tab, then on `/us/home`, `/signin`, and the account-selection URL.

Cross-origin sheets on paypalobjects.com are invisible to the CSSOM (SecurityError). The public theme file `paypal60-DBt27BDW.css` and `helpers-D6s78pYR.css` were fetched with curl. A declared name is in the tokens only when a computed style on the live element confirmed the same value, or when the computed value is the one stored and the sheet is cited in raw/computed.json as context.

`preview_snapshot` was called twice. Both calls returned: "The browser is not producing screenshot frames. For a desktop tab, show or restore the T3 Code window and try again." Measurements already read were kept. No screenshot was invented. Headless Playwright was not launched.

## What to distrust

Headline sizes are fluid. The px values are what the browser computed at innerWidth 1169, not a 1440 layout. Paragraph 16.647px and headline 60.328px were rounded to three decimals in the tokens.

The secondary button's inset shadow computed as `rgba(0, 0, 0, 0)`, so it is not a token. The login card background also computed transparent; the white page is the html background behind it.

`color-scheme` was `normal`. There is no dark set. Declared hover colours in helpers.css (`#333333`, `#0070e0`) were not confirmed on a hovered element, so they are not tokens.

No screenshot backs these numbers. A later capture with frames should replace the empty screenshots folder.

## Fonts

PayPal Pro and PayPal Pro Text VF are PayPal's faces, served from paypalobjects.com as woff2. The tokens name them and fall back to Helvetica, Arial, sans-serif. The files are not in this package.

The login page uses `pp-open-regular` and `pp-open-medium`, falling back to Helvetica Neue, Arial, sans-serif. The cookie accept button computed `PayPalOpen-Medium`. Those files are not here either.

## Do and don't

- **Use the measured ink, navy, and cyan.** Body text is `light.color.ink` on `light.color.page`. The navy plate is `light.color.navy` with `light.color.on-navy`. The cyan plate is `light.color.cyan`. Readings are in [raw/measurements.md](raw/measurements.md).
- **Use the black pill for a marketing primary action.** 48px tall, radius `core.radius.pill`, label weight 700. The login Next button is a different blue, `light.color.login-action`, radius `core.radius.login-pill`.
- **Keep the login field empty in any reconstruction of this capture.** The email control was measured blank. No address was entered.
- **Stop at the signup wall.** Account selection is the last public step this capture entered. Do not invent the `/welcome/signup` form.
- **Do not invent a dark theme.** These pages painted light only.
- **Do not treat the 1169px headline sizes as a desktop token for every width.** They are the fluid computed size at this viewport.
