Palette

The storefront is nearly achromatic — black chrome on white, #2d2d2d ink, #dddddd hairlines — then one loud action green (#018849, hover #006637), the light-blue promo band (#cde2f5) and a small accent family for sale, error and app promos. Swatches list the declared var each alias resolves through.

Type

Futura PT (book 400, demi 500, bold 700) everywhere, the older FuturaStd stack on promo furniture, a 6-step measured size scale (10.5625–24px) and a 6-step tracking scale — Futura PT is licensed and not loaded here, so the named stacks below are the token values, not the rendered face.

Spacing and radius

No declared spacing scale — ASOS composes layout in component CSS. Corners are the signature: square (0px) on every button, pill, field and tile; only icon-only buttons go fully round (50%/100px). No shadows anywhere; depth comes from fills alone.

Shadows

None measured — the shop is flat. (The list below stays empty unless a future run finds one.)

Measured extras

Colours no variable declares — the #005fcc focus ring (the #0770cf variant on my.asos.com is --1cf22is), the deep-navy nav hover #051a6e, the #0000ee anchor blue — plus the measured component dimensions.
