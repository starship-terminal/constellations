# Factory design reference

A token set and component reference for Factory's public site. It was read from **factory.com** on **2026-11-21**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. **factory.ai** redirects to factory.com. Captured: the home page and its menus, pricing, news, company, contact, docs (light and dark), security, and the empty login walls. The map of which control opens which page is [site-tree.md](site-tree.md). The empty walls are [login-review.json](login-review.json).

Factory paints a warm paper page (`#f9f9f9`) with near-black ink (`#020202`), a 3px primary button on `#101010`, and a single orange accent (`#ef6f2e`). Type is Geist. The marketing routes paint light only. docs.factory.com has a real dark theme.

**Boundary:** the product app lives behind auth.factory.ai. Sessions, missions, settings, and billing were never reached. Nothing was typed into a login field. No identity provider was clicked. No form was submitted.

## How the values were read

Every value came off the running signed-out site in headless Chromium:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) read the same-origin `/_next/static/css` chunks through the CSSOM and resolved each custom property on a probe with `data-theme=light` and `data-theme=dark`. Brand paints (`--accent-*`, `--neutral-*`, `--surface-*`, `--dark-base-*`) are constants. Role aliases (`--color-background`, `--color-foreground`, `--color-base-*`) invert between those themes.
- **Components.** Computed styles on the live home page: the primary and secondary buttons, the header link, hover and focus-visible on Download for Mac. Heights and colours are in `light.component.*`.
- **Screenshots.** Viewport shots of the pages and menus named in the file table. [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.
- **Fonts.** Geist (variable, 100–900) and Geist Pixel Square are declared in `@font-face`. The guide uses system fallbacks. The webfonts are not committed.

Nothing was sent, downloaded into the package, signed into, or trialled. The only presses were local UI toggles: header menus, the pricing segment, the docs theme switch, the docs search dialog (opened and closed), the contact list (opened, nothing chosen), and the phone menu. A click aimed at a pricing FAQ landed on the header Product control. The news search field and the careers filters were not filled.

## What to distrust

- **Marketing dark is declared, docs dark is painted.** `dark.*` role tokens come from the theme-layer default. docs.factory.com paints that dark theme when its switch is set to Dark. factory.com marketing pages do not offer the switch, so a marketing screenshot is not dark evidence.
- **`--font-sans` did not resolve on the probe.** next/font sets `--font-geist-sans` at runtime. The body face was read as `Geist, "Geist Fallback", sans-serif` from `getComputedStyle`.
- **The Vercel login page did not paint.** `https://factory.ai/login` redirects to `https://factory.com/login` (HTTP 404, title Login – Vercel). Its CSS returned 404. The empty fields were forced visible to photograph them. That shot is unstyled evidence of the fields, not of Vercel's visual system.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs. Read colours from tokens.
- **CTA text colour is on a child.** The primary link's own computed colour is the page ink. The painted label is `#f9f9f9`.

## Fonts

Geist, Geist Pixel Square. Declared as woff2 on factory.com. Not committed. The tokens use the measured Geist stack and a mono fallback.

## Do and don't

- **Do ground on warm paper.** The marketing page is `#f9f9f9` with `#020202` ink. See [home-light-default.png](screenshots/home-light-default.png).
- **Do use the near-black primary button.** Download for Mac is `#101010` with a 3px radius and a light label. The quiet action is an outlined button. See [home-light-default.png](screenshots/home-light-default.png).
- **Do keep the orange accent rare.** `#ef6f2e` is a token, not the button fill.
- **Do set UI type in Geist.** Display headlines are uppercase, medium weight, tight tracking.
- **Don't invent a signed-in app.** The product behind auth.factory.ai was not entered. See [login-dark-empty.png](screenshots/login-dark-empty.png).
- **Don't treat the Vercel login shot as Factory's visual system.** The stylesheet failed. See [vercel-login-unstyled.png](screenshots/vercel-login-unstyled.png).
