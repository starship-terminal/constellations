# Factory design reference

A token set and component reference for Factory's public marketing site, docs and sign-in edge — for building AI-agentic-product marketing pages, product-overview pages, mega-menu chrome, pricing, contact forms and the sign-in edge in the style of the real thing. It was read from **factory.com** (the marketing site — the product is catalogued as factory.ai, the app and CLI host), **docs.factory.com** and **auth.factory.ai** on **2026-11-14**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: the home page, /enterprise, /pricing, thirteen /product/* pages, /agent-readiness, /news, /company, /events, /contact, /security, /partners, /ambassador, /oss, /science, /privacy-policy, three docs.factory.com pages in light and dark, the app.factory.ai → auth.factory.ai sign-in card, and 390px passes on home, pricing, contact and docs home.

Factory is worth a capture because it ships a full declared token layer: `--neutral-*` and `--accent-*` scales, semantic `--color-background`/`--color-foreground`/`--color-base-*`/`--color-surface-*` roles resolved under `data-theme="light"` and the `:root` dark default, the Tailwind `--color-<hue>-<step>` palette, a `--text-*`/`--leading-*`/`--tracking-*` type ramp, `--radius-*` steps, `--container-*` layout tokens, breakpoints, blurs and easing/animation presets — 161 resolved values per theme probe, plus the HubSpot `--hsf-*` vendor layer on /contact. The marketing site paints one surface: every page is `<html data-theme="light">` on the pale #f9f9f9 field, with dark scoped into `[data-dark-hero]` heroes, `.invert-color-scheme`/`[data-container-variant="inverted"]` panels and the footer — dark is a section skin, never a user toggle. docs.factory.com shares the token layer and ships the real three-way theme selector; auth.factory.ai is a third surface — its own dark sign-in card that does not share the marketing tokens. Three self-hosted variable voices: **Geist** (wght 100–900, everything from the ~60px masthead to 12px nav labels), **Geist Mono** (taglines, eyebrows, install commands, code) and **Geist Pixel Square** (the pixel label face). The signature #ee6018 orange is spent on eyebrows, labels and diagram accents, not fills — CTAs are near-black pills. **Boundary:** everything behind app.factory.ai was never reached — the sign-in and contact forms were measured as forms, never submitted; every CTA and link was measured, never followed; the Cookiebot consent layer was hidden, never answered.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export factory` prints them all with aliases resolved.

### Principles

1. Do let the declared layer carry the design.
2. Do spend the orange on labels, not fills.
3. Do keep dark as a section skin, not a mode.
4. Do pair the Geist voices.
5. Do use the paired pills.
6. Don't style the signed-in product from this package.
7. Don't fabricate form outcomes.
8. Don't copy the brand.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## What to distrust

- **The signed-in product.** Nothing behind app.factory.ai was reached; the Droid console, missions and settings need an account this capture does not have. The product frames and videos on the marketing pages are mocks, not the product.
- **Animated surfaces.** Hero video panels and the scroll-revealed sections hold animated content; a screenshot freezes one frame, so a dark rectangle or a half-revealed section is a capture artifact, not the design.
- **The forms.** Contact and sign-in fields were measured at rest and typed into then cleared — validation, error, loading and success states are unverified because nothing was submitted.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs; read exact colours from tokens or the raw values, never the pixels.
- **Unpainted fills are not tokens.** The auth.factory.ai sign-in panel, e-mail field and Google button and the dark docs sidebar compute a transparent `backgroundColor` (the colour comes from an ancestor), so `core.component.signin.panel-bg`, `field-bg`, `google-fill` and `dark.background.docsPanel` were dropped in the 2026-11 audit.

## Fonts

- **Geist VF** — the single voice (masthead ~60px/500, body and controls 12–18px/400), self-hosted variable woff2 (wght 100–900) via next/font.
- **Geist Mono VF** — the mono face for taglines, eyebrows, the install command, SUBMIT and code frames.
- **Geist Pixel Square** — the pixel label face.

## Coverage

- 31 desktop routes and 4 mobile routes captured signed out; the light marketing surface, the scoped dark sections, docs light and dark via its real theme selector, and the auth.factory.ai dark sign-in card.
- 59 components measured in 144 states, including opened mega-menus, the mobile nav overlay, forced-pressed controls and typed-then-cleared form fields.
- Missing surfaces (declared in the catalog's `capture.gaps`): every post-login Droid/app surface, individual news articles and event pages (indexes captured), and the marketing site has no dark mode to paint.
- Icons: layout gap — no standalone SVG set lifted; the asterisk mark and product glyphs are visible in crops/screenshots.

## Do and don't

1. **Do let the declared layer carry the design.** Factory ships its tokens: use the `color.neutral.*`/`color.accent.*` scales, the `--color-base-*` ink ramp and the per-theme `color.<role>` semantics rather than restating hex. See [tokens.json](tokens.json) and [home-light-default](screenshots/home-light-default.png).
2. **Do spend the orange on labels, not fills.** `#ee6018` marks eyebrows ("ACCELERATE DEVELOPMENT"), mono labels and diagram accents; actions stay near-black pills on the pale field. See [dark-eyebrow](components/crops/dark-eyebrow-default.png) and [nav-cta](components/crops/nav-cta-default.png).
3. **Do keep dark as a section skin, not a mode.** Marketing pages are `data-theme="light"`; dark lives inside `.invert-color-scheme`/`[data-container-variant="inverted"]` panels and the footer — and in docs' real theme selector. See [dark-hero](components/crops/dark-hero-default.png) and [docs-home-dark-default](screenshots/docs-home-dark-default.png).
4. **Do pair the Geist voices.** Geist carries display and UI; Geist Mono owns eyebrows, taglines, the install command and code frames; Geist Pixel Square is the pixel label. See [hero-sub](components/crops/hero-sub-default.png) and [install-cmd](components/crops/install-cmd-default.png).
5. **Do use the paired pills.** The dark-filled DOWNLOAD and bordered CONTACT SALES/BOOK DEMO pills travel together in header, hero, docs and the mobile overlay — a primary/secondary pair at 25–31px tall. See [hero-cta](components/crops/hero-cta-default.png) and [m-cta](components/crops/m-cta-default.png).
6. **Don't style the signed-in product from this package.** Everything behind app.factory.ai was never reached; the auth.factory.ai card is the only app surface measured, and it does not share this token layer. See [signin-dark-default](screenshots/signin-dark-default.png).
7. **Don't fabricate form outcomes.** SUBMIT and Continue-with-email were measured, never pressed; what a submission returns is unverified. See [send-btn](components/crops/send-btn-default.png) and [signin-submit](components/crops/signin-submit-default.png).
8. **Don't copy the brand.** The asterisk mark, the wordmark, the customer logos and the product frames are Factory's published artwork; borrow structure and proportion, not identity. See [mkt-logo](components/crops/mkt-logo-default.png).
