# Factory components

Public controls measured on factory.com on 2026-11-21, signed out. Values are token names. Crops were not cut. The screenshots in [screenshots/](screenshots) show the controls in place.

## Button

Primary: Download for Mac. Height 31px, padding 0 14px, radius 3px, background `{color.base.darkSecondary}`, label `{color.surface.page}`. Hover swaps to page background and near-black text. Focus-visible draws a 1px outline, offset 4px, colour `#101010`.

Secondary: Book demo and Contact sales. Same height, 1px border `{color.neutral.400}`, page background, ink text.

## Link

Header links (Pricing) are 12px Geist, ink, no underline in the default state.
