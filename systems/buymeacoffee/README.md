# Buy Me a Coffee design reference

A token set and component reference for Buy Me a Coffee's public site, for building marketing and supporter pages in the style of the real thing. It was read from **buymeacoffee.com** on **2026-11-21**, signed out, in headless Chromium at 1440×900 and 390×844.

The public site is a Nuxt marketing shell: floral white `#faf8f0`, ink `#222222`, one yellow `#ffdd00` pill, Circular as the type family. The creator dashboard sits behind login. A public creator page linked from the homepage (`/cara.app`) was captured as a published page. Login and signup were photographed and not filled.

## How the values were read

Every value came off the signed-out site in headless Chromium on 2026-11-21.

- **Tokens.** buymeacoffee.com declares no design custom properties. The homepage inlines Tailwind v3.4.1. [raw/tailwind-utilities.json](raw/tailwind-utilities.json) is the colour, type-size and radius utilities parsed from that sheet. [raw/computed.json](raw/computed.json) is getComputedStyle on the page root, `#bmc-header`, the h1, the Sign up link and the FAQ link at 1440×900. [tools/build_tokens.py](tools/build_tokens.py) writes [tokens.json](tokens.json).
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots. [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.
- **Site tree.** [site-tree.md](site-tree.md) was written from the homepage DOM before the screenshot run.

Nothing was signed into, bought or submitted. Login and signup were opened and not filled. Google, Facebook, Apple and Twitter were not clicked. Search was opened and not submitted. A cookie banner did not mount. CookieYes nodes, if present, are hidden and never accepted.

## What to distrust

- **This is the marketing shell plus one public creator page, not the app.** Dashboard, payouts, shop admin and settings are behind login and are uncaptured.
- **One theme only.** No theme toggle. `tokens.json` has no dark set. The footer is a dark section.
- **Circular is a separate family per weight.** Computed `font-weight` is 400 on the bold headline because the family is "Circular Bold". The weight tokens marked Derived say so.
- **The menu shadow** is a reconstruction of `shadow-smd` from a typical panel, labelled in its source. Read the panel from the screenshot if the exact blur matters.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs. Read colours from tokens.
- **Comparison pages.** Ko-fi and Patreon were screenshotted. The other six comparison URLs use the same template and were mapped, not each captured.

## Fonts

**Circular** (Regular, Book, Medium, Bold, Black) is the UI family, self-hosted by the product. **Borel Regular** is a script accent. Neither is distributed with this package. The style guide falls back to the system sans.

## Do and don't

- **Do put the yellow on one pill.** Sign up and Start my page are the only yellow fills on the header. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
- **Do keep the page floral white and the header white.** The page is `#faf8f0`, the bar is `#ffffff`. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
- **Do set display type in Circular Bold at a tight line height.** The homepage h1 is 96px on 95px with -2.4px tracking. See [screenshots/home-light-full.png](screenshots/home-light-full.png).
- **Don't invent a dark theme.** The public site has no toggle.
- **Don't style the dashboard from this package.** Login stops the tree. See [screenshots/login-light-auth-wall.png](screenshots/login-light-auth-wall.png).
- **Don't submit the support form.** Quantity and message are local. Support and Join start payment.
