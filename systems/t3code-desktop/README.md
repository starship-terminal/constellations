# T3 Code (desktop)

A design reference for the T3 Code macOS app, Nightly 0.1.10 (`0.1.10-nightly.20261113.4616`). Captured on 22 Nov 2026 from the owner's window, 1512 by 949 points, 3024 by 1898 pixels. Dark was the starting theme. Appearance was switched to light and restored to dark.

The product is a coding-agent workspace in one window: a thread sidebar, a thread column, and an optional side chat. Settings is a dialog. New thread opens a project palette whose rows are labelled Local or with the remote environment name. The hosted web app is a separate package, [t3code](../t3code/README.md).

This package contains no T3 Code source. The screenshots show the owner's threads and project paths. The Providers detail pane has the signed-in account and the home paths painted out. Borrow structure and proportions, not the brand.

## How the values were read

There is no debug port on the running app, so values were sampled from window pixels with the kit's `sample.py` and a mode scan, before the screenshots were quantized to 256 colours. The window scale is 2. The sidebar edge is at image x 483.

## What to distrust

Text and accent colours are the extreme pixel of an anti-aliased glyph or switch, so the true ink is the same or slightly further from the fill. Light muted is a nav grey, not a held caption. Font family, type scale, radii, spacing, and focus-ring width were not measured. The empty-composer send control is red in the light shell. That is a button state, not the accent. Screenshots include the owner's thread titles and project paths. The Add Environment dialog shows the product's own placeholders.

## Fonts

The painted face was not named. Treat it as the system sans. Do not ship a guessed family.

## Do and don't

- **Do keep the thread column one quiet fill and raise the composer, menus, and dialogs.** The thread column samples as `#191b26` in dark. [screenshots/dark-shell.png](screenshots/dark-shell.png)
- **Do label a project row with where it runs.** Local and the remote environment name sit on the same palette row. [screenshots/dark-project-picker-remote.png](screenshots/dark-project-picker-remote.png)
- **Do open settings as a dialog with a vertical section list.** [screenshots/dark-settings-general.png](screenshots/dark-settings-general.png)
- **Don't treat the empty-composer send control as the accent.** In light it paints red. [screenshots/light-shell.png](screenshots/light-shell.png)
- **Don't copy the hosted web tokens into this package.** The Nightly window was sampled on its own.
