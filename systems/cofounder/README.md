# Cofounder design reference

A token set and component reference for Cofounder's public surface — for building clean light marketing pages with the warm off-white ground, glass chrome and dark pill controls of the real thing. It was read from **cofounder.co** on **2026-11-17**, signed out, in headless Chromium at 1440 x 900 and 390 x 844: the marketing routes (home, pricing, the four how-to guides, resources, support, privacy-policy and terms), plus the public sign-in card on **app.cofounder.co/os/login** as a boundary.

Cofounder is worth a capture because the site is a **Next.js/Tailwind v4 build that declares a real theme layer** on `:root` — `--background`/`--color-surface` `#f5f5f2`, `--color-ink-ui-solid` `#202020`, the `--color-lime-*` accent pair (declared as `lab()`, resolving to `#d8f999`/`#bbf451`), `--color-feature-*` support colours, the `--font-*` families exported through next/font loader classes, the `--radius-*`/`--spacing`/`--blur-*` primitives and the `--ease-*`/`--default-transition-*` motion vars — while its **semantic palette ships as literal utility values**: ink `#262323` at 80/70/50% opacities, raised surface `#fbfbf8`, card border `#dee2de`, the `#1a6fd1` tools band, the `#f3f3f0` logo tiles and the `#383838` CTA edge. It paints a **single light theme**: the `#1a6fd1` "All the tools and systems" band and the pixel-art hero landscape are coloured bands inside it, not a second theme. The signature chrome is **glass over pixel art**: the fixed header and hero prompt button paint translucent white gradients with `backdrop-blur` 16–24px and layered inset+drop shadows, the controls are 41px-tall 8px-radius pills (light `#f5f5f2` surface or a `#4f4f4f → #202020d9` dark gradient), and the pricing cards are whole-card anchors that reveal a hidden dark CTA chip only while hovered. **Boundary:** the Cofounder OS lives behind `app.cofounder.co` sign-in; every CTA on the site links there and was never followed, the login card was measured at rest and never submitted, and the hero "copy setup prompt" button was never pressed — it would write the clipboard.

## Brief

### Principles

1. Do set body text on the warm paper ground.
2. Do use the two control fills the way the site does.
3. Don't treat the `#1a6fd1` tools band or the pixel-art hero as a second theme.
4. Do let the plan card reveal its action on hover.
5. Don't infer the Cofounder OS, its integrations or billing from these pages.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

Fonts: `core.font.family.display` is neoris, then 2 fallbacks; `core.font.family.ui` is Inter, then 1 fallback; `core.font.family.mono` is IBM Plex Mono, then 1 fallback; `core.font.family.departure` is departureMono, then 1 fallback. ## Do and don't

- **Do set body text on the warm paper ground.** `#f5f5f2` with ink at 80% opacity is the whole site's reading surface; pure white and pure black text appear nowhere ([home](screenshots/home-light-default.png)).
- **Do use the two control fills the way the site does.** The light `#f5f5f2` hairline pill carries most actions ([cta-light](components/crops/cta-light-default.png)); the dark `#4f4f4f → #202020` gradient is reserved for the primary CTA ([cta-dark](components/crops/cta-dark-default.png)).
- **Don't treat the `#1a6fd1` tools band or the pixel-art hero as a second theme.** They are coloured bands inside the single light theme; white text on the band is the only inversion ([blue-section](components/crops/blue-section-default.png)).
- **Do let the plan card reveal its action on hover.** The CTA chip exists only while its whole-card anchor is hovered ([plan-cta](components/crops/plan-cta-default.png)); the resting card shows no button ([plan-card](components/crops/plan-card-default.png)).
- **Don't infer the Cofounder OS, its integrations or billing from these pages.** Everything behind the sign-in card was measured at rest only ([sign-in](screenshots/signin-light-default.png)).

## How the values were read

Every number in [tokens.json](tokens.json) and [raw/measurements.md](raw/measurements.md) is either a **declared** CSS custom property harvested from the live stylesheets (`tools/capture/vars.mjs` — the `:root` Tailwind v4 theme layer plus the next/font loader classes, with `var()` alias chains resolved and `lab()` declarations converted to sRGB) or a **measured** computed style read off the painted DOM (`tools/capture/public/measure.mjs`). Screenshots come from `tools/capture/public/public.mjs`, a bounded Playwright shooter at 1440 x 900 and 390 x 844 that tiles pages over the GPU-texture cap into `.partN` files (terms ~23.9k px, mobile-home ~12.5k px at DPR 2). Component crops are element screenshots taken at measurement time. States: `hover` is a real pointer hover, `focus-visible` a real keyboard focus (or `el.focus()` where noted), `pressed` a `CSS.forcePseudoState` CDP call — each state's `via` field in the JSON says which. The plan card's CTA chip exists only while its card is hovered; it was held open by the card's own hover through its states. The mobile menu is a trusted press on the hamburger, and the full-screen overlay it opens is tagged and measured. Hidden duplicate nodes (the mobile-only footer CTA copy, the prerender heading set on the guides) were skipped deliberately. No cookie/consent banner renders on the public surface.

## What is not here

- **The tools-band tabs were read on moving targets; they need a recapture.** The band rotates its selected tab by itself and the capture re-found `aria-pressed` for each state, so `tool-tab` focus-visible is a different button (x = 595) from its default (x = 336.5), and `tool-tab-off` is that first button read again after it rotated off. The selected text (white) and unselected text (40% white) are real readings, but not of one control in two states. The capture now marks each button once (edited, not rerun).
- **Captured with the automation flag masked.** The public capture (`tools/capture/public/`) hid `navigator.webdriver` from every page, so the committed readings and screenshots it took were taken past that mask. The scripts no longer hide it (edited, not run); a recapture that meets a bot check records it as a boundary.
- **The product.** Cofounder's OS — the agent workspace, integrations, settings and billing — lives behind app.cofounder.co sign-in; every CTA links there and was never followed, the login card was measured at rest and never submitted, and no checkout was entered. docs.cofounder.co (the docs/CLI surface) was not captured.
- **Dark theme.** The site paints one light theme; the #1a6fd1 tools band and the pixel-art hero art are bands inside it, not a second theme.
- **A few controls that never paint.** The campaign carousel's Previous/Next arrow buttons exist in the DOM but never render a visible box signed out; the how-to guide has no landmark element around its content column. Both are recorded as missing in [components.md](components.md) rather than faked.
- **The clipboard.** The hero "copy setup prompt" button writes the clipboard on press; it was measured at rest/hover/focus/forced states only.
