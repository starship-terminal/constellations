# Rox

Rox is a revenue-agent product for large sales teams. This package records the public marketing site at www.rox.com and the signed-out Auth0 login it links to. Captured 2026-11-19, signed out, light theme only, at 1440 and 390 CSS pixels. No account was created. No form was submitted.

The live host is www.rox.com. Login and Start now redirect to run.rox.com, then to roxai.us.auth0.com.

### Principles

1. Use square buttons on the marketing site.
2. Set the page to #f7f6f4 and the ink to #0c0a09.
3. Set display type in a serif at weight 420, with negative tracking.
4. Keep the Auth0 card separate from the marketing palette.
5. Do not invent a dark theme.
6. Do not draw the signed-in product from these screenshots.

## How the values were read

Computed styles were read in the T3 preview browser on the live page, at a measured 1440 by 900 CSS viewport, device pixel ratio 2. Custom properties were read from the Framer stylesheets: 103 `--token-*` colours resolve on `body`. Visible type, button padding, radii and shadows were read off the elements, not off the tokens.

The preview browser then stopped producing screenshot frames. Viewport PNGs of the public marketing pages were taken with headless Playwright after those pages had already loaded in the preview browser with no Cloudflare challenge. The login page was not opened in Playwright. Its values are computed styles only.

Screenshots were quantized to sRGB 256-colour PNGs. Each has a `.capture.json` sidecar with the measured viewport.

## What to distrust

The style guide draws type in system-ui. The site's display face is Season Mix Trial, weight 420, and its UI face is Geist. Neither file is in this package.

Framer token ids are opaque. A colour listed under `core.color` is a value that was both declared as a `--token-*` and seen on an element, except the status colours (blue, green, red, orange), which are declared and not painted on a control this capture measured. Those four say so in their source.

The hero Start now anchor computed as transparent. The white face in the crop is the visible control. The anchor's own background is not the button colour.

Auth0 focus, hover, error and success colours are custom properties. No control was captured in those states.

256-colour PNGs can shift a photograph. Flat UI colours were checked against the computed values before quantizing.

## Fonts

Season Mix Trial is the display face. Computed family is `Season Mix-TRIAL Regular`, weight 420. It is a trial face loaded by Framer. Not committed.

Geist is the UI face, weights 400 and 500 observed, 600 and 700 declared. Loaded by Framer with a placeholder family. Not committed.

system-ui is the announcement strip and some body copy.

ulp-font is the Auth0 card, falling back to -apple-system, system-ui, Roboto, Helvetica, sans-serif. Not committed.

Tokens name the families and fall back to sans-serif or system-ui.

## Do and don't

- **Use square buttons on the marketing site.** Computed radius on Start now, Start for free and Get in touch is 0. The 10px and 14px radii belong to the Auth0 card only. See [button-primary-contact.png](components/crops/button-primary-contact.png).
- **Set the page to #f7f6f4 and the ink to #0c0a09.** Those are the body background and the hero heading colour. Do not promote the Framer blue #0b63e8 to the primary action. The action buttons are ink, paper or charcoal.
- **Set display type in a serif at weight 420, with negative tracking.** The hero is 56px, line-height 67.2px, letter-spacing -1.12px. See [home-light-default.png](screenshots/home-light-default.png).
- **Keep the Auth0 card separate from the marketing palette.** Its page is #efedea, its card is #fafaf9, its continue button is black, its radius is 10px. It is not the marketing site.
- **Do not invent a dark theme.** The home photograph is not a dark palette. No theme switch was found.
- **Do not draw the signed-in product from these screenshots.** Login was not entered. The agent UI, tables and empty states are gaps.
