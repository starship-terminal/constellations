# Pull&Bear

A signed-out capture of the public Pull&Bear shop at [https://www.pullandbear.com/gb/](https://www.pullandbear.com/gb/) on 2026-11-22. The start URL geo-redirected to a Singapore closure notice. This file records the United Kingdom storefront. Desktop 1440 by 900, `devicePixelRatio` 2. The page is white. Body type is Neue Haas. Display type is 46px, weight 600. The promo bar is `#71c5fa`. Add is black.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

## Colour

| Role | Value | Where |
|---|---|---|
| Ink | `#000000` | Body, header, wordmark on white |
| Page | `#ffffff` | Homepage split, product column, brand history |
| Text | `#000000` | Display heading, product title |
| Muted | `#5a5a5a` | Brand history paragraphs |
| On ink | `#ffffff` | Wordmark on the homepage photographs |
| Promo | `#71c5fa` | Mix & Match bar, sampled |
| Link | `#2d64e3` | Named token. Promotions in the menu |
| Sale | `#cb2c3b` | Sampled from the -44% chip |

## Type

Neue Haas on the body, the search field, and the brand history page. The kicker "CONCEPT" is 22px, weight 400, line-height 38px. The display heading is 46px, weight 600, line-height 70px. Paragraphs are 12px, line-height 26px, `#5a5a5a`, in a 500px column. Tracking is 0.7px. Font files are not in this package. Helvetica is the fallback the site names.

## Controls

Search is an underlined field, 128 by 20, 0.5px black rule. Account and basket are 24px icons. The promo bar is 36px. Add is a black rectangle. It was not clicked. The menu columns are black, with Promotions in blue.
