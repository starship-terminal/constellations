# Replo design reference

A token set and component reference for Replo's public marketing site. It was read from **www.replo.app** on **2026-11-21**, signed out, in headless Chromium at 1440×900 and 390×844. The site paints one dark theme: black page, cream ink, a cream pill for the primary action. The dashboard, editor, and every signed-in surface sit behind https://dashboard.replo.app/auth/login and were not entered.

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export replo` prints them all with aliases resolved.

### Principles

1. Do paint the page black and the type cream.
2. Do use one cream pill for the primary action.
3. Do keep the secondary action as a hairline pill.
4. Do set display type in Archivo at 56px.
5. Don't treat the light `:root` tokens as the site.
6. Don't style the editor from this package.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out site in headless Chromium, via Playwright. The T3 preview browser was not used.

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) reads the stylesheets through the CSSOM and writes [raw/css-vars.json](raw/css-vars.json). Brand colours (`--color-replo-cream`, `--color-ink`, `--color-replo-button`, the surface and accent names) resolve to sRGB on a probe. A separate live read, [raw/live.json](raw/live.json), records computed styles of the body, the h1, the header, and the Start for free, Log in, Book a demo, and Product controls at 1440×900.
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots at 1440×900 and 390×844. Presses are local: the three nav menus, one homepage accordion, and the phone menu. Login and signup URLs were opened and not filled. The login wall's email field was painted over before the file was kept. The contact footer address was painted over the same way.
- **Builders.** [tools/build_tokens.py](tools/build_tokens.py) writes [tokens.json](tokens.json). [tools/build_style_guide.py](tools/build_style_guide.py) writes the guide.

Nothing was signed into, bought, or submitted. Google was not clicked. No password, code, newsletter, profile, birthday, plan, survey, or onboarding field was filled.

## What to distrust

- **This is the public marketing site, not the product.** The editor, store, tests, and billing sit behind the dashboard auth wall. Do not style those screens from this package.
- **The light set is declared, not painted.** The bundle's `:root` is a light shadcn palette (`#ffffff` background, `#0a0a0a` text). The homepage `html` has no `.dark` class, `color-scheme` is `dark`, and the body paints `#000000`. `tokens.json` keeps the declared light names under `light` and labels each one. Design from `dark`.
- **Accent greens, blues, and magentas are stylesheet names.** They were resolved from `--color-accent-*`. They were not counted across components. Treat them as brand leftovers, not as the page accent. The painted accent is the cream button.
- **Focus, destructive, and status roles were not seen painted** on the marketing controls. `dark.focus` and `dark.destructive` cite declared custom properties and say so.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs. Read colours from the tokens.
- **Hover, focus-visible, and pressed were not measured.** The button readings are the resting state.

## Fonts

The painted text uses **Archivo**, with an "archivo Fallback" and Arial. The `html` class also loads Editorial New, Fraunces, Instrument Sans, and Space Mono as next/font variables. Those faces were not measured on the body or the h1. None of the font files are in this package.

## Do and don't

1. **Do paint the page black and the type cream.** The body background is `#000000` and the text is `#f5fad9`. See [home-dark-default](screenshots/home-dark-default.png).
2. **Do use one cream pill for the primary action.** Start for free is `#eef5c5` on `#121212` at a full pill radius. See [home-dark-default](screenshots/home-dark-default.png).
3. **Do keep the secondary action as a hairline pill.** Book a demo is black with a cream 24% border. See [home-dark-default](screenshots/home-dark-default.png).
4. **Do set display type in Archivo at 56px.** The h1 is weight 500 and line-height 59.36px. See [home-dark-default](screenshots/home-dark-default.png).
5. **Don't treat the light `:root` tokens as the site.** They are in the bundle and unused on the pages that were captured.
6. **Don't style the editor from this package.** The dashboard auth wall is the boundary.

## Rebuild

```sh
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/build_components_md.py
```

```sh
node tools/capture/vars.mjs
RAW=~/.design-systems/replo/raw-shots node tools/capture/public/public.mjs
python3 tools/capture/quantize.py ~/.design-systems/replo/raw-shots
```
