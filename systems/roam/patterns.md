# Patterns

The public site is one marketing page plus hash walls and a public docs graph.

| Pattern | Shows |
|---|---|
| Marketing shell | Dark header over a white page. Wordmark left, text links centred, Sign In right. [screenshots/home-light-default.png](screenshots/home-light-default.png) |
| Hero | 44px Inter headline, 18px subcopy, one blue Sign Up, a Chrome pill, a black desktop button. Same file. |
| Social proof | Quote cards, then a rotating "Trusted by" line. [screenshots/home-light-full.png](screenshots/home-light-full.png) |
| Pricing | Two plan cards on a pale band. Yearly price is the filled blue cell. Trial and Join were not clicked. [screenshots/pricing-light-default.png](screenshots/pricing-light-default.png) |
| Downloads | Three bordered columns. Links leave the site or start a file. [screenshots/downloads-light-default.png](screenshots/downloads-light-default.png) |
| Auth wall | Centred card, empty fields, Google and Apple as links, not clicked. [screenshots/signin-light-default.png](screenshots/signin-light-default.png) |
| Public docs | The `help` graph, with a banner that nothing is saved. [screenshots/docs-light-sidebar.png](screenshots/docs-light-sidebar.png) |
| Phone | Nav collapses to a menu. Sign In stays. [screenshots/mobile-home-light-menu.png](screenshots/mobile-home-light-menu.png) |

Signed-in daily notes, a user graph, settings, and checkout are not in this package.
