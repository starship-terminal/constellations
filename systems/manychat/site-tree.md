# Manychat public site tree

Mapped on 2026-11-22 from [https://manychat.com/](https://manychat.com/) in an incognito preview tab, signed out. Desktop shots are 1440 × 900 CSS pixels at 2× (PNG 2880 × 1800). They are the first viewport, not the full page. The homepage title was "Chat Marketing Made Easy with Manychat". The first visible heading is "Social smarter, not harder." This is a live marketing site, not a parked domain.

Nothing was typed. No email, password, code, phone, or address was entered. No form was submitted. No identity provider was clicked. No captcha was solved. No channel was connected and no bot was started. `login-extracted` stays `not-started`.

origin/main already had `systems/manychat/` and did not have `systems/manychat/site-tree.md`. This walk adds the site tree and screenshots. It does not remeasure tokens. catalog.json and webapps-manifest.json were left alone.

A Usercentrics "Privacy Information" card covered the first homepage frame. OK was clicked so the card would not cover later shots. No preference was changed beyond that dismiss.

## Where it stopped

Log in opens [https://app.manychat.com/signin](https://app.manychat.com/signin). The wall says "Welcome back" and shows an empty email field, a Sign In button, and Google, Facebook, Telegram, and Apple. None of those were used. The email box paints the placeholder `mrsmith@gmail.com`. That string is the site's placeholder, not a typed address.

Get started opens the signup path and lands on [https://app.manychat.com/signup](https://app.manychat.com/signup). The wall says "Sign up for Manychat" and shows an empty email field, Sign Up, and Google. A first navigation to `/signup` added a `refId` query. That URL was discarded. The saved shot has no query string.

Start for free, checkout, Creatorworld register, status subscribe, video-course enroll, and affiliate apply were not entered. YouTube, Instagram, and TikTok profile links were not followed. community.manychat.com returned a CloudFront 403 for this country, so Community, Webinars, and Changelog were not photographed. The phone-width homepage was not photographed on this pass.
