# Time2book

Fitness studio software (time2book.me). This package records the public marketing site and the signed-out login and signup forms, measured on 2026-11-19. No account was created. No card, phone number or booking was entered. Themes seen live: light only. Widths measured: 1440 and 390 CSS pixels, device pixel ratio 2.

### Principles

1. Ink is the accent.
2. Secondary actions are a 5% ink wash.
3. Auth controls are 12px, marketing controls are pills.
4. The promo bar is the only full-bleed ink strip.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Computed styles were read in the T3 preview tab on `https://www.time2book.me/`, `/pricing`, `/features/class-scheduling`, `https://time2book.me/login` and `https://time2book.me/signup`. Custom properties came from `_astro/base.BIUhdRuW.css`. oklch values were painted to a 1px canvas in that page and read back as sRGB hex. Those readings are in [raw/readings.json](raw/readings.json).

`preview_snapshot` failed with "The browser is not producing screenshot frames". Full-page PNGs and crops were then taken with headless Playwright at the same CSS sizes, after the pages loaded without a Cloudflare challenge. Each PNG has a `.capture.json` sidecar with the measured viewport.

## What to distrust

The `.dark` set is declared in the stylesheet and was not applied on any public page. Treat it as a declared palette, not a captured theme.

Canvas hex for oklch is the browser's sRGB conversion, not a value the stylesheet writes as hex. Alpha fills (`rgba(23, 23, 23, 0.05)`, `0.15`, `0.5`) are stored as rgba because a flattened hex would drop the alpha.

The primary pill's hover crop looks the same as default. The class does not set a hover background. Do not invent a hover ink.

`www.time2book.me/signup` is a marketing 404. The signup form is on the apex host.

Inter Variable was the loaded face. The style guide loads Inter from Google Fonts as a stand-in. The variable file was not copied into the repo.

## Fonts

Inter Variable, weights 100 to 900, loaded by the site. Fallback stack: ui-sans-serif, system-ui, sans-serif. The mono stack is declared as `--font-mono` and was not used on these pages. Inter's licence is the SIL Open Font License. The package does not ship the font file.

## Do and don't

- **Ink is the accent.** Primary actions are `#171717` pills with white type. See [button-primary-default.png](components/crops/button-primary-default.png).
- **Secondary actions are a 5% ink wash.** Log in and the OAuth buttons use that wash, not a second hue. See [button-secondary-default.png](components/crops/button-secondary-default.png).
- **Auth controls are 12px, marketing controls are pills.** The login field and Continue button do not use the 100px marketing radius. See [text-field-default.png](components/crops/text-field-default.png).
- **The promo bar is the only full-bleed ink strip.** It sits above the white nav. See [home-light-default.png](screenshots/home-light-default.png).
