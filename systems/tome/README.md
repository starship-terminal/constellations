## How the values were read

The T3 preview browser opened [https://tome.app/](https://tome.app/) in its own tab. The page had already loaded, with no Cloudflare challenge. Custom properties were read from the inline stylesheet and from `getComputedStyle` on `body`, `h1`, `.description`, `.metadata`, `.primary-action` and `.secondary-action`. Focus-visible was read after calling `focus()` on the documentation link and the copy button. A later `preview_snapshot` failed with "The browser is not producing screenshot frames", so the screenshots were taken with headless Playwright on the same public URL, at 1440×900 and 390×844, device pixel ratio 2, in both color schemes. The headless light capture confirmed `--background: #ffffff` and a body color of rgb(23, 23, 23).

## What to distrust

These tokens describe the host's 404 page. They do not describe Tome's presentations, editor, or marketing site, which this domain no longer serves. Geist and Geist Mono are named in `font-family` and were not loaded, so the painted face is the next fallback. The primary "Go back" button is in the DOM with `hidden` set. Its height, radius, padding and colours are computed, and it is not on screen. Hover colours are the stylesheet's custom properties. A visible control was not hovered. The per-request `sin1::` id under the status line changes on every load and is not a token.

## Fonts

The page asks for Geist, then `-apple-system`, `system-ui`, Segoe UI, Helvetica Neue, Arial, and sans-serif. Metadata and the footer actions ask for Geist Mono, then SF Mono, Consolas, Liberation Mono, Menlo, and monospace. No `@font-face` loaded either family. The tokens keep the requested stack and fall back to the system faces.

## Do and don't

- **Treat this as a shutdown record.** The page says the deployment was not found. [screenshots/home-dark-desktop.png](screenshots/home-dark-desktop.png) is the whole public surface.
- **Keep the two schemes.** Dark is `#0a0a0a` with `#ededed` text. Light is `#ffffff` with `#171717` text. [screenshots/home-light-desktop.png](screenshots/home-light-desktop.png) shows the light page.
- **Use the 6px control radius and the 2px blue focus ring.** The focused documentation link draws a `#0070f3` outline, 2px, offset 2px. [components/crops/secondary-link-focus.png](components/crops/secondary-link-focus.png).
- **Do not invent a Tome editor, a pricing table, or a wordmark from this page.** None of those are on it.
