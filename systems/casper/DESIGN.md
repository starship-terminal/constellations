# Casper

A signed-out capture of the public Casper shop at [https://casper.com](https://casper.com) on 2026-11-22. Desktop 1440 by 900. The page is `#ffffff`, type is Calibre on the shop and NewKansas-Medium on headings, and the announcement bar is `#1e306e`.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

## Colour

| Role | Value | Where |
|---|---|---|
| Page | `#ffffff` | document background |
| Ink | `#1e306e` | body type, announcement bar, footer band |
| Nav | `#1e3063` | department links |
| On ink | `#ffffff` | announcement type, Login button type |
| Sale | `#cb372a` | header Sale link |
| Lime | `#eaffac` | 30% accent, Shop sale fill |
| Button | `#3c619e` | Take the quiz, Login |
| Cart | `#012169` | Add to cart, not clicked |
| Save | `#00706f` | size upcharge |
| Field | `#526699` | login and signup borders |

## Type

Calibre on the body, 18px, weight 400. Department links are Calibre 18px at weight 500. The homepage hero is NewKansas-Medium 56px at weight 500. The One title and the Login heading are 44px at weight 500. Font files are not in this package.

## Controls

Shop mattresses is a 50px white pill with a `32px` radius. Shop sale is the same radius on `#eaffac`. Add to cart, Login, and Create account are 63px pills. Fields are 60px with an 8px radius and a 1px `#526699` border.
