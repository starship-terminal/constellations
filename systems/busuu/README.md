# Busuu design reference

A token set and component reference for Busuu's public surface — for building marketing, course-landing and signup-flow pages in the style of the real thing. It was read from **busuu.com** on **2026-11-11**, signed out, in headless Chromium at 1440 x 900 and 390 x 844: the home page, the /en/premium upsell (12-month and 1-month billing), the Spanish course landing page, the choose-your-language picker, register step 1, the login form and the about page.

Busuu is worth a capture because its language-learning marketing is a tight study in cheerful confidence: a purple `#6e00f8` → `#563ce9` → `#116eee` diagonal gradient hero under a simplified header, one green `#11ee92` `Learn for free` pill everywhere, a `#116eee` action blue that rides on text and 1px borders rather than fills, 16px flag cards that take the blue on hover, an indigo `#221658` paywall surface with `#5438dc` pill CTAs, and two served faces — Nista on marketing, NistaFonts on the app-shell pages. **Boundary:** the product itself lives on app.busuu.com behind login; register step 2 onward, checkout and every signed-in surface were never reached. Everything behind the login is a recorded gap, never inferred.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export busuu` prints them all with aliases resolved.

### Principles

1. Do put ink on white.
2. Do spend the gradient on heroes.
3. Do pill every button.
4. Do reserve green for the one action.
5. Do let the blue ride on borders and text.
6. Don't add card chrome.
7. Don't style the app from this package.
8. Don't ship a dark theme.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out site in headless Chromium:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) captures every stylesheet body (the marketing bundle plus styled-components inline `<style>` blocks re-parsed with `CSSStyleSheet`) and writes every custom property to [raw/css-vars.json](raw/css-vars.json). busuu.com declares almost no design vars — compiled Sass on the marketing pages, styled-components on the app-shell pages — so **every design token is a measured computed value**. [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec, [tools/build_tokens.py](tools/build_tokens.py) the sets.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md).
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route with `.capture.json` sidecars; [tools/capture/public/fixup.mjs](tools/capture/public/fixup.mjs) retook the kebab-menu and billing-tab states after the first pass's nav-dropdown selector navigated away mid-run; [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.

Nothing was signed into, bought or submitted: the register flow's language options were measured, never chosen (a choice starts the account); the login form was never filled; the billing tabs and kebab dropdowns were toggled as local UI state; every Get Premium CTA was measured, never followed; the paywall's X was never pressed. The OneTrust consent stack was hidden, never answered — no consent button was ever clicked.

## What to distrust

- **This is the public shell, not the app.** Lessons, review, streaks, the profile and all signed-in surfaces live on app.busuu.com behind login and are uncaptured. Treat the app's own design system as unknown.
- **One theme only.** The site paints light everywhere; the gradient hero and the indigo upsell are section styles. `tokens.json` ships no dark set.
- **The tokens are measured, not declared.** busuu.com compiles its styles (Sass + styled-components); almost no `:root` design vars exist. Every token cites the measurement it came from — that is the honest provenance.
- **The action blue has no fill.** `core.color.brand.blue` (#116eee) was measured on text and borders — the course CTA is a ghost button and its background computes transparent.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs; read exact colours from tokens or the raw files.
- **Missing components.** `nav-link`, `save-badge`, `m-menu-button` and `m-menu-open` are recorded missing in the measurement file: the kebab is an empty `<a>` with no text for the specs to name, and the save badge/nav-link selectors found no match on the captured loads. The opened menus show in [home-light-menu](screenshots/home-light-menu.png) and [mobile-home-light-menu](screenshots/mobile-home-light-menu.png).

## Fonts

Two served faces do everything. **Nista** runs the marketing pages (home, about, choose-your-language): the 40px hero headline, 16px body, 14px nav/footer. **NistaFonts** runs the app-shell pages (course, register, login, premium): the 48px course display, 32px premium title, 16px picker labels. Both are served from the Busuu CDN; neither is distributed with the package — the style guide falls back to system sans.

## Do and don't

1. **Do put ink on white.** `#252b2f` on a white field is the base; meta text runs `#666e7e`, hairlines `#d6dee6`. See [languages-light-default](screenshots/languages-light-default.png).
2. **Do spend the gradient on heroes.** The purple-to-blue diagonal (`#6e00f8` → `#563ce9` → `#116eee`) marks the home hero and the closing CTA band — and the indigo `#221658` owns the upsell. Body sections stay white. See [home-light-default](screenshots/home-light-default.png).
3. **Do pill every button.** Actions are pills: 45px radii on the green CTAs, 26px on the upsell buttons, the kebab menu's own rail. See [hero-cta](components/crops/hero-cta-default.png).
4. **Do reserve green for the one action.** `#11ee92` is `Learn for free` and nothing else; hover lifts to `#41f1a8`. Secondary actions go `#116eee` on white or ghost. See [cta-signup](components/crops/cta-signup-default.png).
5. **Do let the blue ride on borders and text.** The `#116eee` action blue marks links, ghost-button labels, the hover border on cards and focus rings — it is rarely a fill. See [course-cta](components/crops/course-cta-default.png).
6. **Don't add card chrome.** Cards are borderless whites on 16px (picker) or 8px (plan) radii; a 1px `#116eee` border plus `#f3f8fe` label fill is the whole hover story. See [language-item](components/crops/language-item-hover.png).
7. **Don't style the app from this package.** Every value is the public surface's; app.busuu.com is uncaptured.
8. **Don't ship a dark theme.** None is offered; the indigo upsell is a section style, not a theme.

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/busuu/`):

```sh
python3 tools/build_component_tokens.py        # raw/components-computed.json -> raw/component-tokens.json
python3 tools/build_tokens.py                  # -> tokens.json
python3 tools/build_style_guide.py             # -> style-guide.html
python3 tools/build_components_md.py           # -> components.md
node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir>    # full-colour PNGs -> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.

Live recapture (needs the site; Playwright at `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs`):

```sh
node tools/capture/vars.mjs                    # stylesheet harvest -> raw/css-vars.json
node tools/capture/public/measure.mjs          # computed styles + crops -> raw/components-computed.json
RAW=<scratch> node tools/capture/public/public.mjs   # screenshots -> <scratch>
RAW=<scratch> node tools/capture/public/fixup.mjs    # kebab-menu + billing-tab retakes -> <scratch>
```

busuu.com loads fine headless from this client; the product host app.busuu.com stays behind login.
