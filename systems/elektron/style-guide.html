Palette

The core set carries the monochrome ramp, var-referenced to the --thedock-*/--tdc-* layer where it declares the same value and measured where it does not; the roles alias the palette. There is one painted theme: dark.

Spacing, radius and borders

A 7px rhythm — 3.5/7/10.5/14/17.5/21/35/44/70 — on square corners: every button, field and drawer is 0px; the only rounded control is the 7px header search field. Borders are 2px on the outline actions, 1px self-coloured on the search field.
