# Credo Beauty

Public shop, signed out, 2026-11-22. Values are measured from the live page. Font files are not in this package.

## Colour

| Role | Value | Where |
|---|---|---|
| Page | `#ffffff` | Body background |
| Ink | `#001922` | Utility bar, department labels, prices |
| Ink soft | `#121212` | Body text at 75% |
| On ink | `#ffffff` | Utility links, Add to Bag label |
| Brand | `#023e55` | Wordmark, titles, Add to Bag |
| Link | `#0b788e` | DETAILS, LOGIN |
| Timer | `#cb4b10` | Countdown units |
| Sale | `#c0392b` | Sale price on the grid |
| Hero type | `#f6f7f4` | Holiday deal type on the dark hero |
| Search border | `#00191e` | Search field |

## Type

urw-din carries the chrome: department labels at 14px, weight 500, letter-spacing 0.7px, uppercase. Utility links are 12px, weight 500. Mercury Display carries the display type: the hero "20% off" at 58px, weight 700, letter-spacing -0.58px, and collection and product titles at 38px, weight 700, letter-spacing -0.38px.

## Geometry

Promo strip 40px, white. Utility bar 30px, `#001922`. Search 40px tall, radius 4px, 1px `#00191e` border. Add to Bag 38px tall, 280px wide, radius 4px, fill `#023e55`. Wordmark rendered about 93 by 42.

## What was not captured

Hover, focus, pressed, and disabled states. Phone width. Dark theme. Account, bag, checkout, and subscribe. The 10% popup was closed and not submitted.
