# Kickstarter design reference

A token set and component reference for Kickstarter's public signed-out site. Refreshed from kickstarter.com on 2026-11-21, signed out, in headed Chrome at 1440 x 900 and 390 x 844. Surfaces: home and its category menu, Discover, an Art category, Games, search for "camera", one public project (`/projects/arex/arex-ar-dive-computer-mask-and-marine-life-identification`), the login card, the first step of `/start`, and the public pages for creators, about, rules, trust, press, environment, and the blog. The control map is [site-tree.md](site-tree.md).

Kickstarter ships a real token layer, KDS: `--kds-color-*`, `--kds-elevation-*`, `--kds-shadow-*`, and `--kds-dimension-corner-radius-*` in the atomic stylesheet on `a.kickstarter.com`. The public site paints one light theme. Brand green is `#05CE78`. Actions are near-black (`#171717`, hover `#000000`, pressed `#2C2C2C`). The pledge button is a deeper green (`#028858`, hover `#015738`). Type is Inter.

## Do and don't

1. **Do keep the page white and the wordmark green.** Header, cards, and footer sit on `#FFFFFF`. The wordmark is `#05CE78` (`light.color.brand`). See [home-light-default](screenshots/home-light-default.png).
2. **Do use near-black for account actions and green for a pledge.** "Sign in with Apple" is `#171717` (`light.color.background.action`). "Back this project" is `#028858`, hover `#015738`. See [login-apple-default](components/crops/login-apple-default.png) and [pledge-btn-default](components/crops/pledge-btn-default.png).
3. **Do round controls on the 4 / 8 / 16 scale.** Fields and buttons use 4px (`core.radius.small`). Cards use 8px. The editorial banner uses 16px. See [search-default](components/crops/search-default.png).
4. **Do show funding as a green rule.** Project cards and the campaign meter use the brand green as a progress bar, not as body text. See [progress-default](components/crops/progress-default.png).
5. **Don't invent a dark theme.** The public site paints one light theme. No theme toggle was found. See [raw/css-vars.json](raw/css-vars.json).
6. **Don't press pledge, save, or Continue.** Those controls were measured in every reachable state and never activated. Checkout, save, and the account sit behind sign-in. See [login-light-default](screenshots/login-light-default.png).
7. **Don't treat a live error toast as chrome.** The 2026-11-21 phone Discover shot showed a site error toast. It is not a brand banner. See [mobile-discover-light-default](screenshots/mobile-discover-light-default.png).

## How the values were read

- **Declared, then resolved.** The atomic stylesheet on `a.kickstarter.com` is cross-origin, so the live CSSOM cannot read it. `tools/capture/vars.mjs` downloads the sheet through headed Chrome and parses it in a constructed `CSSStyleSheet`, then reads computed values on `documentElement`. [raw/css-vars.json](raw/css-vars.json) holds the declarations and the resolved `--kds-*` values. `tokens.json` publishes those colours one to one.
- **Computed components.** `tools/capture/public/measure.mjs` reads computed styles and crops in headed Chrome. Hover is a real pointer. Pressed is CDP `forcePseudoState` (`:active:hover`), so no button was activated. The email field was typed into and cleared.
- **Headed Chrome.** Cloudflare challenges headless Chromium on every route except home. The capture uses `channel: 'chrome'`, headless false. Consent (Transcend, "We use personal data") is hidden with CSS. Confirm and Accept all were never clicked.
- **Motion.** `tools/capture/motion-probe.mjs` reads declared transitions from the atomic sheet and computed motion on home, Discover, and the project page, then emulates `prefers-reduced-motion: reduce`. Authored card and nav motion is gated on `no-preference`.

## What to distrust

- The spacing steps are a 4px module typed in by hand at capture time and labelled Reconstruction. 2, 4, 8 and 16 equal declared elevation and radius values, and 48 is the measured search height. The sheet publishes no `--kds-spacing-*` scale.
- `core.typography.display` and `core.fontSize.display` are the measured home hero h1 (34/42, weight 400). The other type roles and sizes were typed in by hand at capture time and are labelled Reconstruction: no reading in raw/ holds them, and the sheet declares no type-token group. Inter is the computed body family. One `@font-face` names Effra and was not the painted body font.
- `core.motion.duration.enter` (300ms) and `core.motion.easing.nav` (cubic-bezier(0, 1, 1, 1)) were typed from the creator-nav submenu rule, which raw/motion.json does not hold; they are Reconstructions. `easing.out` is the CSS `ease-out` keyword, cubic-bezier(0, 0, 0.58, 1).
- The pledge green (`#028858` / `#015738`) is measured on the button. It is not a `--kds-color-*` name. The nearest declared greens are `light.color.background.accent.green.bold` (`#037242`) and `light.color.brand` (`#05ce78`).
- `--kds-shadow-0-foo: bar` is in the sheet and was left out of tokens. Elevation 0 is the transparent rest shadow.
- Screenshots are 256-colour PNGs. Read colours from tokens, not from the images.
- Login's Continue button is mid-load in the viewport shot (a spinner over the label) because Turnstile is present. The full-page shot shows the same card. The widget was not solved.
- A yellow status toast was on the live site. It is not part of the design system.
- Every committed reading and screenshot was taken by scripts that hid `navigator.webdriver` and launched Chrome with `--disable-blink-features=AutomationControlled`. The scripts no longer hide automation (2026-11 audit), so a recapture may meet bot checks this one did not.

## Fonts

Inter, loaded from Google Fonts (`fonts.googleapis.com`, weights 100–900, optical size 14–32). The token stack is Inter, then sans-serif. Kickstarter does not publish a licence for the webfont in the captured pages. Effra appears in one `@font-face` in the atomic sheet and was not the computed body family. Fall back to the system sans when Inter is not available.
