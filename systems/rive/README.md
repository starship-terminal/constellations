# Rive design reference

A token set and component reference for Rive's public site. It was read from **rive.app** on **2026-11-21**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Marketing pages paint one dark theme. The editor app, login, and signup were not entered.

Rive is an agent-native 2D and 3D engine. The public site is a Framer marketing surface: black ground, Orbitron display type, Inter uppercase nav, a white 4px-radius GET STARTED chip, and a Framer `--token-*` palette of ink steps plus amber, red, magenta, blue, cyan, and lime signals.

## How the values were read

Every colour in `core.color` comes from a `--token-*` custom property declared on `body`, resolved in a probe document by [tools/capture/vars.mjs](tools/capture/vars.mjs) and written to [raw/css-vars.json](raw/css-vars.json). Role colours, type, radius, and control sizes come from `getComputedStyle` on the live home and pricing pages, saved in [raw/computed.json](raw/computed.json). [tools/build_tokens.py](tools/build_tokens.py) maps those readings into tokens.json. Screenshots come from [tools/capture/public/public.mjs](tools/capture/public/public.mjs).

Nothing was submitted. Newsletter, search, contact, login, and signup fields were not filled. Google, Apple, and SSO were not clicked. Password was not submitted.

## What to distrust

- **One painted marketing theme.** Semantic colours are under `dark`. Docs use `html.dark` and a theme preference control. A light theme was not applied, so there is no light set.
- **Framer uuid names.** `--token-*` names are build artefacts. tokens.json uses ink and signal names. Each leaf keeps the uuid in `$extensions.source`.
- **Focus is Not captured.** The marketing controls did not yield a stable designed focus colour in this pass.
- **Plan card GET STARTED fill** is `#1d1d1d` on the wrapper that was measured. The visible label colour may sit on a child. Read `dark.surface` as that wrapper's fill.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs after quantize. Read colours from tokens.json.
- **Login screenshot** shows the public wall only. It is not an entered account.

## Fonts

Computed on the home page: **Orbitron** for display headings, **Inter** for nav labels, **PragmataPro VF Variable Regular** (with PragmataPro and ui-monospace fallbacks) for GET STARTED and COPY. The stylesheet also declares Inter Display, Inter Variable, Be Vietnam Pro, Roboto, Roboto Flex, JetBrains Mono, Fragment Mono, Tomorrow, and Zodiak Extrabold (358 faces in raw/css-vars.json). Webfonts are not committed. The guide uses system fallbacks when those families are absent.

## Do and don't

- **Do ground the page in black.** The marketing body paints `#000000`. [home-dark-default.png](screenshots/home-dark-default.png)
- **Do set display type in Orbitron.** The hero is 48px, weight 900. [home-dark-default.png](screenshots/home-dark-default.png)
- **Do use one white chip for the header action.** GET STARTED is white on black text, 4px radius. [home-dark-default.png](screenshots/home-dark-default.png)
- **Do keep nav labels small and tracked out.** Inter 12px, weight 500, 0.08em tracking, uppercase. [home-dark-products-menu.png](screenshots/home-dark-products-menu.png)
- **Don't invent a light marketing theme.** The captured routes paint dark. [pricing-dark-default.png](screenshots/pricing-dark-default.png)
- **Don't follow GET STARTED into the editor.** That host is outside this capture. [site-tree.md](site-tree.md)

## Rebuild

```bash
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/vars.mjs
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/capture/quantize.py
```

Run the commands from `systems/rive`. Screenshots are taken by `tools/capture/public/public.mjs` into `~/.design-systems/rive/raw-shots`, then quantised into `screenshots/`.
