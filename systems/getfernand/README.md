# Fernand design reference

A token set and component reference for Fernand's public surfaces — for building calm, editorial SaaS marketing pages, docs/help centers and signed-out auth forms in the style of the real thing. It was read from **getfernand.com**, **app.getfernand.com** and **help.getfernand.com** on the capture date, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: the home page, /pricing/, /about-us/, /blog/, /updates/ plus one article, /integrations/ plus one integration, /feature/ai-agents, /feature/headless-customer-support, /alternative/intercom, /privacy/, the signed-out /auth/login and /create forms, the docs home and an article in light **and** genuinely-toggled dark, and 390px passes on home, pricing, a docs article and login.

Fernand is worth a capture because three public hosts share one flat `:root` palette — `--white`/`--grey*`/`--black`/`--blue*`/`--orange*`/`--red*`/`--green*`/`--border*` — and resolve it *differently* per host, which the token sets keep honest: the marketing palette (`--grey-light` #f4f5f7, `--grey-medium` #717583), the docs resolution (#f7fafc / #5f667d / #d1d5e6), the SPA's own grey family (`--grey` #e6e9eb, `--grey-medium` #5e6271, `--grey-strong` #9fa3b5) plus its `--fs8`–`--fs18` ramp and component vars, and the docs `body.dark-mode` remap painted by a **real** "Switch to dark mode" link (`--white` #161618, `--black` #f7f8f8). Self-hosted Inter (300–700 + italics) carries everything, from the 38px masthead to the 40px-radius eyebrow pills. The signature look: white fields, `#131e40` navy ink, near-black `#1a2035` buttons, hairline borders and the #00a0ff blue spent sparingly on links and the free-plan card. **Boundary:** everything post-login — the inbox workspace, settings, API keys — was never reached; the login/signup forms were measured and typed into then cleared, never submitted; "Book a demo" is a Cal.com scheduler, never activated; every link and CTA was measured, never followed; no consent banner was observed on any host.

### Principles

1. Do keep the palette flat.
2. Do spend the blue sparingly.
3. Do pair the pill and the radius.
4. Do draw the docs dark surface from the `dark` set.
5. Don't style the signed-in product from this package.
6. Don't fabricate form outcomes.
7. Don't copy the brand.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## What to distrust

- **Captured with the automation flag masked.** The public capture (`tools/capture/public/`) hid `navigator.webdriver` from every page, so the committed readings and screenshots it took were taken past that mask. The scripts no longer hide it (edited, not run); a recapture that meets a bot check records it as a boundary.

## Do and don't

1. **Do keep the palette flat.** One `:root` palette of named neutrals and accents — `white`/`grey`/`black`/`blue`/`border` — resolved per host, no ramps. Take the per-host values from the `light`/`help`/`app`/`dark` sets in [tokens.json](tokens.json); never blend them. ([home-light-default](screenshots/home-light-default.png))
2. **Do spend the blue sparingly.** `#00a0ff` belongs to links, the free-plan card and the widget chrome — the primary action is the near-black `#1a2035` button. ([pricing-light-default](screenshots/pricing-light-default.png), [home-light-default](screenshots/home-light-default.png))
3. **Do pair the pill and the radius.** 40px-radius eyebrow pills and tag chips on top of 6–10px radii on cards and controls. ([section-tag default](components/crops/section-tag-default.png), [price-free default](components/crops/price-free-default.png))
4. **Do draw the docs dark surface from the `dark` set.** The docs site remaps the whole palette under `body.dark-mode` — page `#161618`, ink `#f7f8f8`, hairlines to white-at-10% — reached by its real toggle, not a `prefers-color-scheme` guess. ([help-dark-dark-default](screenshots/help-dark-dark-default.png))
5. **Don't style the signed-in product from this package.** Everything post-login — the inbox workspace, settings, API keys — was never reached; the app set covers only the signed-out forms' palette. ([login-light-default](screenshots/login-light-default.png))
6. **Don't fabricate form outcomes.** The login and signup fields were typed into then cleared, never submitted; validation, error, loading and success states do not exist in this package. ([login-field filled](components/crops/login-field-filled.png))
7. **Don't copy the brand.** The Fernand wordmark, the postman illustration, channel logos and the widget artwork are the product's — borrow structure and tokens, never the artwork. ([signup-light-default](screenshots/signup-light-default.png))
