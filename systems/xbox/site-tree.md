# Xbox public site tree

Mapped 2026-11-21 from the signed-out public site, starting at https://www.xbox.com/. `https://www.xbox.com/` redirected to `https://www.xbox.com/en-US/`. No email, phone, name, password, or code was typed. No form was submitted. Microsoft, Google, and Apple were not clicked as identity providers. Create an account was not opened. Branches that open a login or signup wall stop at that URL.

Desktop captures are 1440 by 900 CSS pixels at 1x. Phone captures are 390 by 844 CSS pixels at 2x (780 by 1688 PNG). Screenshots for this pass live in [screenshots/refresh-2026-11-21/](screenshots/refresh-2026-11-21).

The earlier package (2026-11-19) was the en-SG locale. This pass is en-US.
