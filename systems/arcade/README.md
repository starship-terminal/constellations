# Arcade design reference

A token set and component reference for Arcade's public marketing site (https://www.arcade.software), a Webflow build selling an AI video generator for marketing teams. Use it to build a web page or marketing surface that borrows its look: a pure-white page, black-on-white chrome, Inter Display 56px display lines over Inter Variable UI, black 12px-radius pill CTAs, `#f4f4f4` 24px plan cards, a hairline `#e5e7eb` border system, pastel `--card-bg-*` washes, and a `#2142e7` brand blue kept for the demo pages. It was captured signed out, in headless Chromium at 1440 x 900 (mobile pages at 390 x 844). Tokens were read on 2026-11-10. The public site tree and screenshots were refreshed on 2026-11-21. The auth wall was photographed empty and not entered.

It holds 28 screenshots across nine desktop routes and three phone routes — home, /pricing, /product/interactive-demo, /agents, /enterprise, /ai-video-examples, /blog, /changelog, /contact-sales — plus transient states (prompt suggestion applied, spotlight quote advanced, FAQ open, the mobile menu), and 49 measured components with 126 states and 125 crops. The product itself (the demo editor, agents) sits behind sign-up and was never reached: the app is recorded as a boundary, and nothing here claims its functionality (see [components.md](components.md) > Gaps).

This package contains no Arcade code, and none of its artwork has been redrawn. The screenshots, video stills and visual system they show belong to Arcade ([docs/RIGHTS.md](../../docs/RIGHTS.md)). Borrow structure and proportions, not the logo, artwork or brand assets.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export arcade` prints them all with aliases resolved.

### Principles

1. Do keep the surface black-on-white.
2. Do reserve `--primary-*` blue for demo contexts.
3. Do pair Inter Display headings with Inter Variable UI.
4. Do radius by scale: 12 controls, 16 cards/composer, 24 panels.
5. Do mute with alpha, not a second ink.
6. Don't ship the marketing style as the app.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

- Every component was located on the live page by [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) in headless Chromium: Webflow ships semantic class names, so selectors key off `.btn`, `.nav-btn`, `.arcade-prompt-*`, `.scatter-card-trigger`, `.new-pricing-plan`, `.avfaq-trigger`, `.ds-input`, `.new-footer-*` and stable text. Computed styles were read per state — default, hover, focus-visible, pressed (forced via `CSS.forcePseudoState`), focused/filled on fields — and one 2x crop saved per state.
- CSS custom properties were read from the live stylesheets by [tools/capture/vars.mjs](tools/capture/vars.mjs) into [raw/css-vars.json](raw/css-vars.json): the Webflow `:root` block declares ~40 names (the `--primary-*` ramp, `--neutral-*`, `--gray*`, `--card-bg-*`, `--gold/--green/--red`, `--marginanim`, `--progressive*`), resolved in a probe document at 1440 x 900.
- Screenshots were taken on the same pages by [tools/capture/public/public.mjs](tools/capture/public/public.mjs), quantised to 256 colours by [tools/capture/quantize.py](tools/capture/quantize.py). Full pages taller than one GPU texture were stitched from `.partN` tiles; the changelog's 91,833px scroll is kept whole.
- The Finsweet consent banner (it mounts inside an open shadow root under `[fs-consent-element="root"]`), the Intercom launcher and the site's custom `.am-play-cursor` were hidden before shots, never clicked or answered.

## What to distrust

- **Readings past a masked bot signal.** The committed screenshots and readings were taken with `navigator.webdriver` masked, the flag bot checks read to spot automation. The capture scripts no longer mask it (not run since), so a recapture may record a walled route as a boundary instead of a reading.
- **The app is absent.** Sign up and Log in open `https://app.arcade.software/auth`. That wall was photographed empty on 2026-11-21 and not entered. No editor, agent workspace, or dashboard is in this package.
- **The brand blue is not the site's main action colour.** On the marketing surface every primary CTA is black `ink`; `--primary-*` shows on the demo pages (url-to-demo button, signup pair) and in links. Do not paint primary actions blue.
- **Hover values are mild.** Nav ghosts lift to a 6%-black wash and black CTAs to `#404040`; pressed states shrink ~3% (a Webflow transform). Nothing changes colour.
- **The scatter wall is animated.** Cards drift and scale on hover and scroll; their measured rects are one frame of a moving layout, not fixed geometry.
- **`--opacity` and `--arcade-dark-transparent` are odd names.** Both resolve to real colours (`#111827`, transparent black); `--marginanim*` and `--progressive*` are scatter/player metrics, not spacing.
- **Screenshots are 256-colour PNGs** — read exact colours from tokens.json or the raw JSON, never from a screenshot pixel.

## Fonts

- **Inter Display** — display headings (hero 56px, plan price 36px, page titles), weights 400-700, self-hosted from Webflow's CDN.
- **Inter Variable** — every UI string, field, button and body line (100-900 variable face), self-hosted.
- **Geist Mono Variable** — code and timestamps; **Balig Script** — handwritten marginalia; **Ptserif** — editorial serif. All ship in the bundle.
- Licences: Inter faces and Geist Mono are SIL OFL (Vercel/Philipp Bertheau families); Balig Script is a free script face; verify Ptserif's licence before reuse. The tokens name the measured stacks; the style guide renders with system fallbacks.

## Do and don't

- **Do keep the surface black-on-white.** Page `#ffffff`, ink `#000000`, cards `#f4f4f4`, hairlines `#e5e7eb`; primary actions are black pills, never blue. ([nav-signup](components/crops/nav-signup-default.png), [plan-cta-pro](components/crops/plan-cta-pro-default.png))
- **Do reserve `--primary-*` blue for demo contexts.** It appears on the interactive-demo page (url pill, signup pair) and as link colour — a deliberate product/marketing split, not a second CTA colour. ([url-button](components/crops/url-button-default.png))
- **Do pair Inter Display headings with Inter Variable UI.** Display is 400-weight at 36-56px with tight leading; everything else is Inter Variable 12-16px. Don't set buttons in the display face or headlines in UI weights. ([hero-title](components/crops/hero-title-default.png))
- **Do radius by scale: 12 controls, 16 cards/composer, 24 panels.** The only larger radius is the 72px url-to-demo pill. Nothing under 12px is used on interactive surfaces. ([prompt-box](components/crops/prompt-box-default.png), [plan-card-pro](components/crops/plan-card-pro-default.png))
- **Do mute with alpha, not a second ink.** Secondary text is `rgba(0,0,0,0.7)`, chips `rgba(0,0,0,0.6)`, footer links `#717171`; hovers are a 6% black wash or `#404040` on black. Don't introduce a coloured hover. ([nav-link](components/crops/nav-link-hover.png))
- **Don't ship the marketing style as the app.** Nothing here was measured inside the signed-in product; a screen claiming Arcade's editor from these tokens would be invented. The honest gap is recorded in components.md.
