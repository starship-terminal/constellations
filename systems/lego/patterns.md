# LEGO patterns

How the public shop combines the measured components. Screenshots are in [screenshots/](screenshots).

## Shop chrome

A yellow header bar holds the LEGO mark, Shop / Discover / Help disclosures, a pill search field, Sign Up, wish list and bag. A white promo strip sits above it. The 2026-11-21 refresh shows the same chrome in [home-light-default](screenshots/home-light-default.png), with the Shop panel in [home-light-shop-menu](screenshots/home-light-shop-menu.png).

On a 390 viewport the same bar collapses to a menu button, the mark, account, wish list and bag, with search on its own row. See [home-light-mobile](screenshots/home-light-mobile.png) and the drawer in [home-light-mobile-menu](screenshots/home-light-mobile-menu.png).

## Home hero

The home hero is a full-bleed campaign (Insiders Weekend on 2026-11-18): a dark green field, a white headline, a filled pill and an outline pill. The campaign changes. The chrome does not.

## Listing

Theme and category pages open with an h1, Filters and Sort by, then a grid of product leaves: image, age, piece count, title, price, Add to Bag and a wish-list icon. See [category-light-default](screenshots/category-light-default.png) and [bestsellers-default](screenshots/bestsellers-default.png).

## Product

The product page is a gallery plus a buy column: theme and set number, title, rating, price, availability, a quantity stepper, an emphasis-orange Add to Bag pill, and a wish-list icon. Tabs below cover Overview, Features, Specifications and Customer Reviews. See [product-light-default](screenshots/product-light-default.png) (Tower Bridge 21067, 2026-11-21) and [product-default](screenshots/product-default.png).

## Search

`/en-us/search?q=city` is a public results grid using the same product leaf. See [search-light-results](screenshots/search-light-results.png). A quoted empty query is the miss state in [search-light-empty](screenshots/search-light-empty.png). The header field was focused and not typed into.

## Help and about

Customer Service (`/en-us/service`) opens with a heading and a search field. See [help-light-default](screenshots/help-light-default.png). About Us (`/en-us/aboutus`) is a public editorial page. See [about-default](screenshots/about-default.png). The footer is in [home-light-footer](screenshots/home-light-footer.png).

## Boundaries

Sign-in, the bag, checkout, wish-list contents and membership signup were not entered. Add to Bag was measured and not pressed. The empty walls are [login-light-empty](screenshots/login-light-empty.png) and [signup-light-empty](screenshots/signup-light-empty.png). The map of which control opens which page is [site-tree.md](site-tree.md).
