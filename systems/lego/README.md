# LEGO design reference

A token set and component reference for the public Official LEGO Shop US. Values were read from **lego.com/en-us** on **2026-11-18**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. A public refresh on **2026-11-21** mapped the homepage controls and added shots of the shop, Discover, and Help panels, the Insiders dialog, search, footer, City theme, Tower Bridge, customer service, an empty search, phone width, and the empty login and signup walls. The account was not entered.

The shop ships a declared Skroll token layer (`--ds-color-*`, `--ds-layout-spacing-*`, `--ds-layout-radius-*`, `--ds-shadow-*`) and paints one light theme. The header is yellow. Primary actions are `#005ad2`. The product Add to Bag is emphasis orange `#e96f14`. Type is Cera Pro, which is proprietary and not committed. Icons are CSS masks, not SVG files.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export lego` prints them all with aliases resolved.

### Principles

1. Do keep the header yellow and the page white.
2. Do use the emphasis orange for Add to Bag.
3. Do use the primary blue for links and the Skroll primary.
4. Do set type in Cera Pro.
5. Do keep product cards flat.
6. Don't invent a dark theme.
7. Don't square the buy button.
8. Don't follow Add to Bag, Sign In or checkout for a visual.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

1. `tools/capture/vars.mjs` reads the served stylesheets on `/en-us/themes/city` and resolves every `--ds-*` and `--sk-*` name on a probe document. Output: [raw/css-vars.json](raw/css-vars.json).
2. `tools/capture/public/measure.mjs` opens the public routes signed out and records computed styles plus a crop per state. Output: [raw/components-computed.json](raw/components-computed.json).
3. `tools/capture/public/public.mjs` captures viewport and full-page shots. `tools/capture/quantize.py` writes 256-colour PNGs into [screenshots/](screenshots).
4. `tools/build_tokens.py` and `tools/build_style_guide.py` write [tokens.json](tokens.json) and [style-guide.html](style-guide.html).

The age-gate dialog (`dialog.AgeGate_age-gate__wrapper`) and the consent modal were removed from the DOM. No consent button was clicked. No Add to Bag, Sign In, checkout or email submit was used.

The 2026-11-21 refresh added screenshots and [site-tree.md](site-tree.md). It did not re-read CSS. Token values are still the 2026-11-18 readings.

## What to distrust

Screenshots are 256-colour PNGs. Read colours from the tokens. Cera Pro is not loaded in the style guide, so the guide's type is a fallback. The listing Add to Bag measured `#f47d20` (`--ds-color-brand-bright-orange`); the product Add to Bag measured `#e96f14` (`--ds-color-action-emphasis-enabled`). Both are real. A forced pressed state on the listing button came back as a `lab()` colour and is not tokenised. The filter panel did not open, so its interior is unmeasured.

Known-wrong state readings. `tools/capture/public/measure.mjs` left the pointer on each control from the hover step through focus-visible and pressed, and kept the keyboard focus into pressed. The script now resets the pointer and focus before every state; it was not re-run.

- `nav-shop`: focus-visible carries the hover yellow fill (rgb(250, 196, 0)) beside the 2px focus ring, and pressed carries the focus ring; needs a recapture (the pk-k recapture tracking issue (2026-11 audit)).
- `filter-button`: focus-visible carries the hover grey fill (rgb(203, 203, 203)), and pressed carries the focus ring; needs a recapture (the pk-k recapture tracking issue (2026-11 audit)).
- `sort-button`: focus-visible carries the hover grey fill (rgb(203, 203, 203)), and pressed carries the focus ring; needs a recapture (the pk-k recapture tracking issue (2026-11 audit)).
- `pdp-add`: focus-visible carries the hover fill (rgb(201, 105, 43)), and pressed carries the focus ring; needs a recapture (the pk-k recapture tracking issue (2026-11 audit)).
- `account-button`: pressed carries the focus ring left from the focus-visible step; needs a recapture (the pk-k recapture tracking issue (2026-11 audit)).
- `wishlist-button`: pressed carries the focus ring left from the focus-visible step; needs a recapture (the pk-k recapture tracking issue (2026-11 audit)).
- `bag-link`: pressed carries the focus ring left from the focus-visible step; needs a recapture (the pk-k recapture tracking issue (2026-11 audit)).
- `add-to-bag`: pressed carries the focus ring left from the focus-visible step; needs a recapture (the pk-k recapture tracking issue (2026-11 audit)).

Every committed reading was taken with `navigator.webdriver` masked by the capture context. That mask is removed from `tools/capture/public/lib.mjs`; the readings are kept.

## Fonts

Cera Pro is the computed UI family (400, 500, 700). It is proprietary and is not in this package. The style guide falls back to the system sans. LEGO Typewell is declared as a display face in `@font-face` and is also not committed. Noto Sans KR is a declared fallback.

## Do and don't

1. **Do keep the header yellow and the page white.** The shop bar is a yellow field with black ink and a pill search. See [home-default](screenshots/home-default.png).
2. **Do use the emphasis orange for Add to Bag.** The product buy button is `#e96f14` with black ink and a 999px radius. See [pdp-add-default](components/crops/pdp-add-default.png).
3. **Do use the primary blue for links and the Skroll primary.** `#005ad2` is `--ds-color-action-primary-enabled`. See [tokens.json](tokens.json).
4. **Do set type in Cera Pro.** Body is 16px, the buy button is 18px medium, the price is about 24px bold. See [pdp-price-default](components/crops/pdp-price-default.png).
5. **Do keep product cards flat.** The leaf is image, title and price, with a small yellow badge when the shop shows one. See [product-card-default](components/crops/product-card-default.png).
6. **Don't invent a dark theme.** The shop does not publish one.
7. **Don't square the buy button.** Add to Bag is a pill. The quantity stepper is 4px. See [quantity-default](components/crops/quantity-default.png).
8. **Don't follow Add to Bag, Sign In or checkout for a visual.** Those leave the public surface. The empty walls are in [login-light-empty](screenshots/login-light-empty.png) and [signup-light-empty](screenshots/signup-light-empty.png).
