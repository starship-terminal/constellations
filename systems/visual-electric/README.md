# Visual Electric

Visual Electric is an AI image and video canvas (visualelectric.com). This package covers the public marketing pages that still exist in the Internet Archive, read on 19 November 2026. The live apex has no DNS record. Themes in the token file are the painted marketing surfaces, and the app stylesheet's `[data-theme=dark]` set. Widths are 1440 and 390. Nothing was submitted.

3. The home canvas is black.

## How the values were read

The live host `visualelectric.com` has no A record. `www.visualelectric.com` returns 301 to that apex. `login.visualelectric.com` returns Cloudflare error 1014. `auth.visualelectric.com` returns `{}`.

Computed styles were read in the T3 preview browser on archived public pages:

- `https://web.archive.org/web/20260104182559id_/https://visualelectric.com/` for the app stylesheet. The page body is an empty Next.js shell, build `v4.8.0`. Custom properties were `getComputedStyle` on the document element. Dark values were read after setting `data-theme=dark`, then the attribute was removed.
- `https://web.archive.org/web/20251128161608id_/https://visualelectric.com/pricing` at 1440 by 900, device pixel ratio 2.
- `https://web.archive.org/web/20251108131511id_/https://visualelectric.com/` at the same size.
- `https://web.archive.org/web/20251002173404id_/https://visualelectric.com/whats-new` at the same size.

The preview browser returned "The browser is not producing screenshot frames". Screenshots were taken with headless Playwright of those same public archive URLs, plus the Inspo archive and the 390 by 844 size. The login host was not opened in Playwright.

No email was submitted. No card, phone, or SSO step was entered.

## What to distrust

The January 2026 homepage archive is an empty app shell. Its computed colours are the app token set, not a painted marketing page.

`[data-theme=dark]` was set on the document element to read the dark custom properties. That is not a screen the product showed during this capture. The black home canvas is a painted marketing surface, not that theme switch.

`$0` prices are what the archived pricing page computed. They are not a current price list.

Alpha colours are stored as flattened hex in the tokens because the token check stores hex. The computed `rgba` and `color(srgb …)` forms are in [raw/components-computed.json](raw/components-computed.json).

The plan button's computed border on the anchor was `0px`. The orange stroke is in the screenshot. The token does not invent a border width.

Hero images on the home page and the Inspo gallery did not paint. The grey stage and the blank Inspo page are missing images, not a surface colour.

The 256-colour screenshots band photographs. Read colour from the tokens.

Maison Neue, Visual Electric Sans, and Inter files are not in this package. The style guide falls back to Arial.

## Fonts

Maison Neue Book, Light, Medium, Demi, Ext Demi, and Mono Regular are the faces the browser computed. They are proprietary and are not committed.

Visual Electric Sans (the stylesheet names `VisualElectric`) is the What's New title. The file is not committed.

Inter is the computed face on the home nav labels, the hero button label, and the pricing "per month" suffix.

The app stylesheet also loads Maison Neue at weights 300, 400, 500, 600, and 700 from `/_assets/fonts/Maison/`.

## Do and don't

- **Primary actions are the orange pill.** Get started and Get Started use `#FF3C00`, white type, and a full pill. [components/crops/button-primary.png](components/crops/button-primary.png)
- **Plan actions are an orange outline.** The pricing row does not fill the button. [components/crops/button-outline.png](components/crops/button-outline.png)
- **The home canvas is black.** The header, wordmark, and hero sit on `#000000` under an orange acquisition bar. [screenshots/home-light-default.png](screenshots/home-light-default.png)
- **Headings stay at weight 400, except the news title at 300.** The home display is 60px. The What's New item title computes weight 300. [screenshots/whats-new-light-default.png](screenshots/whats-new-light-default.png)
- **Don't invent a hover colour for the orange buttons.** The nav declares a 200ms colour fade. The buttons were not hovered.
