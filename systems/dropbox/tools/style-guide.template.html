Palette

The light set's color.* roles are the resolved --dig-color__* declarations on the painted vis2023--bright scope; light.dwg.coconut|graphite|navy.* are the --dwg-theme__color__* section roles resolved on each painted scope. The core set's color.brand.* group is the dwg --DWG__TEMP__color__* palette: the coconut and graphite ramps and the named accent hues. The "dark" set is the declared dig-Theme-vis2023--dark palette — shipped in the token layer, never painted on the signed-out surface.

Spacing, radius and layout

The declared scale is an 8px grid (--dig-spacing__dimension__0 through 128); vis2023 radii run 4px to 24px plus the 999px pill (the old dig-Theme declared all-zero radii). Measured: the 72px nav, 16px button radii, 12px plan cards, and the 3px --dig-utilities__focus-ring__thickness ring.
