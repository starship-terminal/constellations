# Urban Outfitters

Handwritten because `make design-md` needs a catalog entry, and this capture left `catalog.json` alone.

## Colors

| Role | Value | Source |
|---|---|---|
| page | `#ffffff` | `--site-background` |
| ink | `#222222` | `--text-dark`, nav |
| muted | `#707070` | `--text-medium`, search border |
| line | `#dddddd` | `--border-default` |
| wash | `#f5f5f5` | `--site-background-secondary` |
| sale | `#d83604` | Extra 40% Off Sale, `--price-sale` |
| promo | `#3a8700` | `--price-promotion` |
| buy | `#222222` | `--button-cart-background` |
| on-buy | `#ffffff` | `--button-cart-text` |
| bar | `#222222` | Promo strip, sampled |

## Typography

Helvetica is the UI face: nav and promo 12px, community heading 30px weight 400. Letter-spacing is 0.5px on nav and 0.2px on the promo strip. Files are not in this package.

## Geometry

Header 207px. Promo strip 45px. Search 45px, radius 0. Buy button is square. Size chips are square.

## Do and don't

Keep the shop white and the ink `#222222`. Use red only for the sale label. Use green only for the offer line. Use black for the buy button. Keep controls square. Stop before sign-in, the bag, and checkout.
