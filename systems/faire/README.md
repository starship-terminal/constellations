# Faire design reference

A token set and component reference for Faire's public signed-out surface — for building wholesale-marketplace pages in the style of the real thing. It was read from **faire.com** on **2026-11-14**, signed out, in headless Chromium at 1440 x 900 and 390 x 844: the home page, category teasers, a brand storefront, supplier listings, the how-it-works/about/news/careers/large-retailers/point-of-sale/markets/support/affiliates pages, the brand application form, the sign-in and sign-up dialogs, the 404, and the terms of service.

Faire is worth a capture because the public surface exposes the real "Slate" design-token layer in its cdn.faire.com bundles: `--slate-color-*` ramps (grey/neutral plus seasonal bsr), the full text/surface/border/icon/action/button/message/tag/toggle semantic roles, the `--slate-typography-*` Graphik/Nantes ramp beside the older `--f_t_*` ramp, the 4px spacing base, and the `.fs-mode-on-surface` inverse scope — all readable as declared variables. **Boundary:** everything past the sign-up/sign-in dialogs — search results, product detail, cart, checkout, account, the brand portal — needs a Faire account; product tiles literally link to `?signUp=product`. The Cloudflare edge intermittently challenges the category/suppliers/brand routes with a Turnstile interstitial; it was waited out and retried, never solved, and the states it ate are recorded missing rather than estimated.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export faire` prints them all with aliases resolved.

### Principles

1. Do put dark buttons on white.
2. Do pill the filters, square the buttons.
3. Do ring focus in blue.
4. Do pair Graphik with the serif display.
5. Do darken the selected pill.
6. Don't invent a second accent.
7. Don't ship a dark theme.
8. Don't style the marketplace from this package.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out site in headless Chromium:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) captures every stylesheet body — the cdn.faire.com sheets are cross-origin to the page, so the harvester reads them from network responses rather than the CSSOM — and writes every custom property to [raw/css-vars.json](raw/css-vars.json), resolved in a probe document at 1440 x 900. faire.com declares a real token layer — the `--slate-*` families, the `--f_t_*` legacy ramp and the Tailwind theme vars — so most tokens resolve declared names; geometry and component measurements are **measured computed values**. Vendor (`--toastify-*`, OneTrust) vars and one-off scoped vars (`--sa-uid`, assistant glow, gradient angles) were harvested but deliberately not tokenised. [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec, [tools/build_tokens.py](tools/build_tokens.py) the sets.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state, plus `focused`/`filled` on the fields, `opened` on the categories menu and mobile drawer, and `toggled` on the show-password buttons. Blocked routes preserve earlier evidence — a Cloudflare challenge never prunes a component. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md).
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route with `.capture.json` sidecars; [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.

Nothing was signed into, registered, bought or submitted: the application and auth fields were filled with sample text and cleared, never sent; the Next and Sign in buttons were measured, never pressed for real; every CTA and link was measured, never followed. The OneTrust consent layer is hidden before every shot, never answered; the Cloudflare Turnstile interstitial is waited out on a fresh context, never solved.

## What to distrust

- **`component.field.borderWidth` 1px has no reading.** The apply text fields measure `borderTopWidth: 0px` and their `fs-form-field` box records no border, so the 1px was typed at capture time; its source says Reconstruction. `component.checkbox.radius` 2px is the painted `fs-checkbox__box` around the input (the input itself measures 0px). Every other component value is read from [raw/components-computed.json](raw/components-computed.json).
- **The marketplace is not in this package.** Search results, product detail, cart, checkout and every signed-in surface are behind the sign-up dialog; the only post-auth UI captured is the dialogs themselves. Treat the marketplace's own components as unknown.
- **Cloudflare ate some states.** Category/suppliers/brand routes intermittently return a Turnstile challenge to a fresh headless client. Components affected carry `recaptureMissed`/`missing` in the JSON and are marked in [components.md](components.md)'s Gaps — their remaining states are earlier-run readings, never fabricated.
- **One theme only.** The site paints light everywhere signed out; `tokens.json` ships no dark set. `.fs-mode-on-surface` inverse roles are real but scoped, under `light.color.onSurface.*`.
- **Slate vars live on cdn.faire.com.** The sheets are cross-origin: css-vars.json was built from response bodies and a probe document, so a few deeply scoped vars (`.fs-mode-*` scopes other than on-surface) are recorded under their selectors but not resolved.
- **Quantised screenshots.** `screenshots/` and `components/crops/` are 256-colour PNGs; read exact colours from tokens or the raw files.

## Fonts

**Graphik** (`Graphik_fix` stack) is the UI face — body, controls, fields, nav — at 14/20 with +0.15px tracking. **Nantes** (`Nantes_fix`) draws the marketing display mastheads at 52/64. **GT Canon** draws category mastheads and dialog titles at 30/38. **GT Standard** carries large CTAs; **GT Standard M** the mono slots. All are served from cdn.faire.com; none is distributed with the package — the style guide falls back to system sans/serif.

## Do and don't

1. **Do put dark buttons on white.** The page field is `#ffffff`; the primary action is the near-black `#333333` `action.surface.default` fs-button at 4px radius, 48px tall. See [cta-primary](components/crops/cta-primary-default.png).
2. **Do pill the filters, square the buttons.** Category/filter controls are 999px pills; buttons and fields stay at 0–4px radius — do not round a fs-button into a pill. See [pill-tab](components/crops/pill-tab-default.png).
3. **Do ring focus in blue.** Keyboard focus draws a 2px `#275ec5` `blue.700` ring at 1px offset on actions and fields — the site's own `component.focusRing` token, not a platform default. See [signin-submit](components/crops/signin-submit-focus-visible.png).
4. **Do pair Graphik with the serif display.** UI text is Graphik 14/20 +0.15px; mastheads go Nantes 52/64 or GT Canon 30/38 — never a sans masthead on the marketing pages. See [hero-h1](components/crops/hero-h1-default.png).
5. **Do darken the selected pill.** Selected filter/tab pills invert to the dark fill with inverse text; unselected stay hairline-bordered on white. See [brand-tab](components/crops/brand-tab-default.png).
6. **Don't invent a second accent.** The public surface is monochrome-plus-blue: `#333333` actions, `#275ec5` links/focus, `#e59700` sparing promo accents; the bsr.* ramps are seasonal slots, not a second brand colour. See [nav-link](components/crops/nav-link-default.png).
7. **Don't ship a dark theme.** None is offered signed out; `.fs-mode-on-surface` inverse roles exist only for controls painted on dark media. See [footer](components/crops/footer-default.png).
8. **Don't style the marketplace from this package.** Product detail, cart and checkout are behind sign-up; every tile's `?signUp=product` link is the boundary. See [signin-dialog](components/crops/signin-dialog-default.png).

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/faire/`):

```sh
python3 tools/build_component_tokens.py        # raw/components-computed.json -> raw/component-tokens.json
python3 tools/build_tokens.py                  # -> tokens.json
python3 tools/build_style_guide.py             # -> style-guide.html
python3 tools/build_components_md.py           # -> components.md
node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir>    # full-colour PNGs -> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.

Live recapture (needs the site; Playwright at `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs`):

```sh
node tools/capture/vars.mjs                    # stylesheet harvest -> raw/css-vars.json
node tools/capture/public/measure.mjs          # computed styles + crops -> raw/components-computed.json
RAW=<scratch> node tools/capture/public/public.mjs   # screenshots -> <scratch>
```

Category/suppliers/brand routes are intermittently challenged by Cloudflare: measure.mjs preserves prior readings on a blocked run, so recaptures should be re-tried route by route until the challenge clears; the challenge is waited out on a fresh context, never solved.

Capture conduct, edited in the 2026-11 audit and not run since:

- The capture scripts no longer hide automation: the `navigator.webdriver` mask is removed. The committed captures were taken with it.
