# Faire design reference

A token set and component reference for Faire, the wholesale marketplace, captured from the public signed-out site at [https://www.faire.com/](https://www.faire.com/) on 2026-11-21. Headed Chrome, 1440 and 390. One light theme. No account was created and no form was submitted.

The public site paints a warm paper page (#fbf8f6), a white header, and one ink (#333333) for text and the primary button. The button goes black on hover. Display type is Nantes. UI type is Graphik. Controls are 4px, except pills. A 2px blue focus ring (#275ec5) appears on keyboard focus.

The control map is [site-tree.md](site-tree.md). Machine-readable copy: [raw/site-tree.json](raw/site-tree.json).

Read this before designing in this style. Take every value from [tokens.json](tokens.json). This section is a stand-in because catalog.json was not edited for this capture, so `make brief` cannot write it yet.

### Principles

1. Do set the page on warm paper and the chrome on white.
2. Do use one ink for the primary button.
3. Do set display in the serif and UI in Graphik.
4. Do keep control corners at 4px, and pills fully round.
5. Do show the blue focus ring on keyboard focus.
6. Don't invent a dark theme for the public site.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

### Using tokens

| Role | light |

Fonts: `core.font.family.display` is Nantes_fix. `core.font.family.ui` is Graphik_fix. Scales: 4 type styles, 4 radius steps, 5 spacing steps.

### Using components

Read [components.md](components.md) for the inventory, [patterns.md](patterns.md) for screens, 7 crops in [components/crops/](components/crops), and [style-guide.html](style-guide.html).

### Accessibility

Focus ring: `light.focus.ring` #275ec5, 2px, 1px offset. Contrast of #333333 on #fbf8f6 and on #ffffff passes 4.5:1. #161616 on white passes. White on #333333 passes.

## What to distrust

- Headless Chromium was challenged by Cloudflare on category URLs. Readings and catalog screenshots are from headed Chrome.
- The page wash #fbf8f6 was read from the painted ancestor of the home heading. The header and footer are white. Do not treat the hero photograph as a token.
- Nantes and Graphik are proprietary. The style guide uses fallbacks.
- Spacing steps of 4px and 8px are derived so the measured 16px, 20px, and 24px paddings have a base. They were not declared as custom properties.
- Toastify status colours are in the page CSS and were not painted as Faire toasts. They are not tokens.
- Pressed, disabled, loading, and error states were not held.
- The sign-in screenshot shows the empty email field and the product's placeholder. No address was typed.

## Fonts

Nantes (display) and Graphik (UI and body) are proprietary. The tokens name the computed families. The style guide falls back to Iowan Old Style and Helvetica Neue.

## How the values were read

Headed Chrome loaded the public site. The OneTrust banner was hidden with CSS and was not accepted. Computed styles were read on the home page, the All categories menu, the sign-in dialog, and the Home decor category page. Custom properties on the page are mostly Toastify vendor variables, so Faire colours were taken from computed styles rather than from a named token layer. Screenshots were taken at 1440 by 900 and 390 by 844.

## Do and don't

- **Do set the page on warm paper and the chrome on white.** The marketing band is #fbf8f6. The header, menu, dialog, and footer band are #ffffff ([home-light-default.png](screenshots/home-light-default.png)).
- **Do use one ink for the primary button.** #333333 fill, white label, black on hover ([header-actions-default.png](components/crops/header-actions-default.png)).
- **Do set display in the serif and UI in Graphik.** The hero is Nantes at 52px. Nav and buttons are Graphik at 14px ([hero-default.png](components/crops/hero-default.png)).
- **Do keep control corners at 4px, and pills fully round.** Buttons and fields are 4px. All filters is a pill ([category-light-default.png](screenshots/category-light-default.png)).
- **Do show the blue focus ring on keyboard focus.** 2px #275ec5, 1px offset, on the primary button.
- **Don't invent a dark theme for the public site.** No theme switch was on the captured pages.
