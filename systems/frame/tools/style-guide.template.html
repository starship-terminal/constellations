Palette

The dark theme is a 19-step neutral ramp — --color-grey-00 #000000 through --color-grey-100 #fcfcfc — with the five brand hues reserved for accents (the cobalt announcement banner, links, badges), the --color-alpha-* ladders for hairlines and washes, and the --overlay-* dims for scrims. Measured roles alias the declared values they match.

Spacing, grid and motion

The spacer scale runs 0.8rem steps from 0 to 48rem; the marketing grid is 12 columns inside a 108rem --global-max-width; the fixed header is 8rem. The default control motion is 0.3s on --ease-default — cubic-bezier(0.25,0.1,0.25,1).

Type

Three served faces: FrameGothic (a 400-600 variable face, --font-main) carries every display heading — the hero runs 80px — NeueMachinaInktrap (--font-secondary) draws labels and kickers, and Inter (a 100-900 variable face, --font-tertiary) sets UI and body copy at the 1.6rem --font-size-base. The stacks are declared on the Next.js font-variable classes, so samples here fall back to system sans.
