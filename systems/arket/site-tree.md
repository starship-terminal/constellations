# ARKET site tree

Mapped on 2026-11-21 from the public homepage `https://www.arket.com/en-ww/` (redirected from `https://arket.com`), signed out, viewport 1440 × 900. Each row is a control that was opened or followed on that page. Login, signup, checkout, and identity-provider buttons were not submitted and not clicked.

The storefront is one light theme. A location bar sits above the header. The header holds the wordmark, a search field, account, wishlist and cart, then a department row.

| Control | Opens |
|---|---|
| Change | Location and language dialog: a shipping-location search and a country list. Closed without choosing a country. |
| Close | Dismisses the location bar. Not pressed. |

## Phone width

At 390 CSS pixels the department row collapses. A menu button in the header opens a drawer: Women, Men, Children, Homeware, Gift shop, ARKET CAFÉ, Customer service, and the locale control. The homepage root `/en-ww/` returned Access Denied on the phone pass, so this drawer was opened on `/en-ww/women/`.

| Surface | Why |

| Sign in / Create account | Identity-provider wall. Google and Facebook were not clicked. No email, password, or code was typed. |
| Proceed to checkout | Checkout. Not pressed. The empty bag drawer is the last public cart state. |
| Newsletter form | A form. Not submitted. |
| Country list in the location dialog | Choosing a country would change the shipping market. Closed without a choice. |
