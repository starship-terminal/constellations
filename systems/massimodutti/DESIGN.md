# Massimo Dutti

A signed-out capture of the public Massimo Dutti shop at [https://www.massimodutti.com](https://www.massimodutti.com) on 2026-11-22. The market picker geo-selected Singapore and English, then Continue opened [https://www.massimodutti.com/sg/](https://www.massimodutti.com/sg/). Desktop 1440 by 900, `devicePixelRatio` 2. The page is white. Body type is Suisse Regular. Labels are Suisse Light, uppercase, widely tracked. The primary shop action is a white 32px button with a 1px black border.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).
