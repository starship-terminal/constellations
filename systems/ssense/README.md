## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export ssense` prints them all with aliases resolved.

### Principles

1. Set storefront type at 11px on 15px.
2. Keep corners square on the store.
3. Use black for the action, not a brand hue.
4. Show a sale as a struck grey previous price.
5. Leave the wordmark as the centred SVG.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The T3 preview browser opened `https://www.ssense.com/` with `reuseExistingTab` false. The first title was a Cloudflare interstitial ("Just a moment..."). The page then settled on `https://www.ssense.com/en-sg` and the storefront painted. Computed styles were read with `preview_evaluate` on the home page, menswear listing, one product page, the login page, search results for the public query `rick`, the search dialog, customer-service FAQ, and one editorial article.

The homepage and the account, FAQ, and editorial pages use Favorit SSENSE Inter and JHA Times Now. The listing, product page, and search results use `interFont` with an `interFont Fallback`. No custom properties were declared on the homepage. The listing declares Tailwind variables; the colour roles came from computed `color`, `background-color`, and `border-color`, not from those variables.

`preview_snapshot` failed twice with "The browser is not producing screenshot frames". Measurements already read were kept. No screenshot was invented, and headless Playwright was not started.

## What to distrust

The viewport is 1169px, not 1440. Phone width was not measured, so editorial type sizes are the desktop rules that won at 1169. The article h1 computed to 49.875px; the declared `.u-font--xlarge-sans` steps are larger and were not the winning size.

Focus on the size select set `outline-color: rgb(229, 151, 0)` with `outline-style: none`. That colour is in the tokens as a focus role, and it did not paint.

`.s-button--disabled` is a declared rule (rgb(182, 182, 182)). It was not seen on a painted button. The sale price is not red. The current price stays black and the previous price is rgb(136, 136, 136) with a line through.

Hover, pressed, loading, and error were not forced. The underline hover treatment is a declared `.background-underline` rule. `transition: all` on the header and Add to bag has no duration in the computed value. Drawer duration 0.2s and main transform 0.35s were read from rules and one computed element. A reduced-motion pass was not run.

## Fonts

Favorit SSENSE Inter, Favorit SSENSE Inter1, Favorit SSENSE Regular, and JHA Times Now are served as woff2 and woff from the site. They are proprietary and are not in this package. `interFont` is the family name the newer storefront computes; its file licence was not read. Tokens name the computed families. The style guide falls back to Helvetica and Arial because those families are not installed here.

## Do and don't

- **Set storefront type at 11px on 15px.** Header, listing, price, and Add to bag all compute to that size. The editorial pages use a second scale.
- **Keep corners square on the store.** Header, cards, fields, the size select, and Add to bag are 0px. The 10px radius belongs to the editorial Shop button only.
- **Use black for the action, not a brand hue.** Add to bag and Continue are rgb(0, 0, 0) with white type. No accent colour was painted on these pages.
- **Show a sale as a struck grey previous price.** The current price stays rgb(0, 0, 0). The previous price is rgb(136, 136, 136) and `line-through`.
- **Leave the wordmark as the centred SVG.** It is 104 by 21.2px, black, in a 55px fixed bar.

## Rebuild

```bash
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/build_components_md.py
```

Run those from `systems/ssense`. Then, from the repo root, `python3 tools/catalog.py design-md ssense`.

`build_components_md.py` writes components.md from text typed in from raw/readings.json at capture time. It does not read raw/, so a recapture must update that text by hand.
