# Reown design reference

A token set and component reference for Reown, the onchain UX platform (the company behind WalletConnect). Captured signed out on 2026-11-21 from the public web, in headless Chromium, at desktop 1440×900 and phone 390×844.

Three public surfaces. The marketing site at reown.com is one Next.js theme: a grey page, a dark rounded hero, pill buttons in KH Teka Mono, and section skins (`theme--blue`, `theme--white`, `theme--black`, and the grey, orange, and green skins) that recolor a block. The docs at docs.reown.com are Mintlify, Inter and Paper Mono, green primary `#008847`, with a real light and dark theme. The demo at demo.reown.com is a dark AppKit playground. The dashboard at dashboard.reown.com/sign-in is a login wall. That branch stopped.

The control map is [site-tree.md](site-tree.md).

## How the values were read

Headless Playwright, signed out. `tools/capture/public/capture.mjs` toured the site tree at 1440×900 (deviceScaleFactor 1) and 390×844 (deviceScaleFactor 2). Cookie banners were hidden, not clicked. The announcement close is a dismiss, not a form. Contact sales, docs search, the status subscribe dialog, and the demo connect modal were opened and closed. No field was filled. No form was submitted. Google and Apple were not clicked.

`tools/capture/vars.mjs` read every custom property the stylesheets declare on reown.com, docs.reown.com (light, then dark from the theme menu), and demo.reown.com. Marketing colours are authored as `R, G, B` triplets and stored here as hex. `tools/capture/public/measure.mjs` read computed styles of the buttons, nav toggle, footer link, heading, card, accordion, newsletter field (focus only), docs heading and nav link, and the demo tabs and checkbox.

`prefers-color-scheme: dark` did not change the marketing body colours. That probe is in [raw/css-vars.json](raw/css-vars.json).

## What to distrust

- The marketing page background computes to `#9a9a9a` (`--p-color-grey-3` / `--s-color-surface`). That is the measured page colour, including under the hero. It is not a washed-out screenshot.
- Root `--s-color-button-text` resolves to the same grey as the page. Painted buttons do not use that root value. The blue Learn button computes to background `#379def` and text `#202020`. Use `light.component.button`, not the root button-text token, for a painted button.
- Section skins override the semantic colours on the block. A token read on `:root` is the default skin, not every section.
- Docs `--background-light` stays `255 255 255` even while the dark theme is on. The dark page colour is `--background-dark` (`#202020`). The builder maps each theme to the variable that theme paints.
- KH Teka is a licensed face. It is named, not shipped. The style guide falls back to the system sans and mono.
- Screenshots are 256-colour PNGs. Read colours from tokens.json.
- The phone nav at 390 clips the Log in label. That is what the viewport showed.
- Pressed states were forced with the site's `is-active` class, not a real mousedown.

## Fonts

- KH Teka Regular (`--p-font-sans`) is the marketing UI face. Licensed. Not in the repo.
- KH Teka Mono Regular (`--p-font-mono`) is the button and field face. Licensed. Not in the repo.
- Inter is the docs UI face (`--default-font-family`). OFL. Not bundled.
- Paper Mono is the docs code face. A Mintlify face. Not redistributed.

## Do and don't

- **Do keep the page grey and the hero dark.** The measured page surface is #9a9a9a. The hero is a dark rounded panel on top of it. [screenshots/home-light-default.png](screenshots/home-light-default.png)
- **Do make the primary action a blue pill in the mono face.** Learn, Docs, and Demo are 48px, 14px radius, KH Teka Mono, blue fill, near-black text. [components/crops/button-primary-default.png](components/crops/button-primary-default.png)
- **Do open navigation as a second row of pills, not a sidebar.** The toggle adds Solutions, Use Cases, Pricing, and Company. A list drops under the open one. [screenshots/home-light-nav-solutions.png](screenshots/home-light-nav-solutions.png)
- **Do treat docs as a second system.** Inter, green #008847, hairline cards, and a real dark theme. Do not paint the marketing grey onto the docs. [screenshots/docs-dark-default.png](screenshots/docs-dark-default.png)
- **Don't invent a marketing dark theme.** The site did not change under prefers-color-scheme. Dark exists on the docs and inside the demo's Design tab.
- **Don't submit the footer mail field.** It is a newsletter, including on the /login 404. [screenshots/login-404-light-default.png](screenshots/login-404-light-default.png)
