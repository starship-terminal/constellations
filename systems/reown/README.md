# Reown

Reown (reown.com) is wallet and onchain app infrastructure. This package records the public marketing site, signed-out docs, and the signed-out sign-in wall, measured on 2026-11-19. No wallet was connected. No transaction was signed. No API key was created. The sign-in form was not submitted.

Computed styles were read in a T3 preview tab at 1169 by 731, devicePixelRatio 2. Marketing pages have no light and dark toggle. Docs do. Docs light was measured after clicking "Switch to light theme", then restored to dark.

## How the values were read

Custom properties were read from the stylesheets on https://reown.com/ and from `getComputedStyle(document.documentElement)`. Component colour, type, radius, padding and size were read with `getComputedStyle` on the live elements. Marketing colours are stored as comma-separated RGB channels (`--p-color-blue` is `9, 136, 240`). Hex in the tokens is that channel triple written as `#0988f0`. Docs colours were read as computed `rgb()` after the theme click.

The preview browser returned "The browser is not producing screenshot frames" on `preview_snapshot`. Screenshots and crops are a later headless Playwright pass of public pages that loaded without a Cloudflare challenge. Headless Playwright was not launched against the sign-in page.

## What to distrust

The CSS viewport for the style readings was 1169, not 1440 and not 390. The screenshots were requested at 1440 and 390 in a different browser, so do not treat a screenshot pixel as the same box as a computed reading. Marketing has one theme. Calling the home screenshot "light" names the file, not a theme toggle. Docs light is a real theme. The sign-in blue (`rgb(9, 137, 241)`) is one channel off the marketing blue (`rgb(9, 136, 240)`). Both are recorded. Focus orange was read after `focus()`, not from a stylesheet hover rule. Button hover, pressed and disabled were not shown.

## Fonts

KHTeka-Regular is the marketing face (`--p-font-sans`). KHTekaMono-Regular is the marketing mono, used on buttons and the newsletter field. Docs body is Inter. Docs code is Paper Mono, then ui-monospace. The sign-in page names KHTeka and KHTekaMono with fallbacks. These families are named as computed. The font files are not in this package. Tokens fall back to sans-serif and monospace.

## Do and don't

- **Use the grey page and the black hero.** Marketing sits on `#9a9a9a` with a `#202020` hero at a very large radius. [patterns.md](patterns.md) shows that shell.
- **Use blue surface for the primary pill and white for Log in.** "Start building" is `#379def` with `#202020` text. "Log in" is white with `#202020` text. [components.md](components.md) lists the sizes.
- **Keep the sign-in wall as a wall.** https://dashboard.reown.com/sign-in offers Google, email and password. Do not invent a signed-in dashboard behind it. [components.md](components.md) records the gap.
- **Use Inter on docs and KHTeka on marketing.** Docs green is `#008847`. Marketing blue is `#0988f0`. [tokens.json](tokens.json) keeps both.
- **Do not treat the 1440 screenshot as the measurement viewport.** Styles were read at 1169. [screenshots/](screenshots/) says which browser took the pictures.
