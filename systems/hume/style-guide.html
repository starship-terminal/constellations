hume.ai, measured

Every value on this page is a CSS custom property generated from tokens.json: the www.hume.ai product layer (--background --foreground, the eleven-pastel --accent-* ramp, the five --gradient-* stops, the --title-* display sizes, the four brand families and the --color-spectrum-* hues), the dev.hume.ai docs layer under light.docs.*/dark.docs.* (the --gray-1..12 ramp, --code-background, --hume-gradient, the --primitive-* decision-model hues), the demo gate's light.demo.* neutrals and the app's light.app.* shadcn roles — plus the core.palette.* literals, the licensed brand faces as names (never shipped) and the measured geometry under component.*. The real pixels are in screenshots/ and components/crops/.

Read from hume.ai's signed-out surfaces in headless Chromium at 1440×900 (mobile pass at 390×844). Three of the four surfaces paint light only — www.hume.ai, demo.hume.ai and app.hume.ai have no theme control at all, and none is invented. The dev.hume.ai docs carry the one real control: the header Theme button’s own Light / Dark / System menu repaints html.dark, so the dark token set holds only the docs’ painted dark (#1c1917 warm-black ground). The brand faces (Martina Plantijn, PP Fraktion Mono / Fraktion, Fellix, M PLUS 1) are licensed and not bundled — samples fall back to system faces; Inter is open-licensed. The app.hume.ai platform past /log-in, the demo.hume.ai playground (invitation-gated) and the retired EVI/Octave line are documented boundaries, not captures.

Palette

core.accent.* is the eleven-pastel brand ramp, core.gradientStop.* the five hero-wash stops and core.spectrum.* the visualisation hues; light.bg.default / light.ink.default are the www ground and ink. light.docs.* and dark.docs.* hold the docs’ Fern layer under html.light and html.dark (the Theme menu’s own repaint — the only dark that exists), light.demo.* the gate’s neutrals, light.app.* the log-in’s shadcn roles, and core.palette.* the literals the surfaces hard-code outside the token layer.

Spacing, radius, layout and motion

The www surface ships Tailwind v4’s default scales — only the pieces the product composes are tokens (core.tailwind.*); the rest is evidence in raw/css-vars.json. Chrome geometry is measured: component.* carries the nav height, the docs rail width, button and field heights, card corners (pills clamp to 9999px). motion.* is the measured set from the reduced-motion probe (docs/decisions/0001).

Type

Five faces, recorded by name only: Inter (open-licensed — the www body/UI face), Martina Plantijn (the licensed display serif), PP Fraktion Mono/Fraktion (the licensed code faces), Fellix (the licensed docs/app body face) and M PLUS 1 (Japanese). core.title.* holds the declared display sizes; the core.typography.* composites carry the measured styles — the hero, section headings, body and code. Samples fall back to system faces.
