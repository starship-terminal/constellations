# Memotron design reference

Memotron is an open-source personal knowledge app (notes, clipping, collections). This package covers the public marketing site at memotron.app and the signed-out web app at web.memotron.app/signup. It was read on 2026-11-19, signed out, in headless Chromium at 1440×900 and 390×844, colour scheme dark. The marketing shell and the signup page both paint `.cs_tidigit_dark_blue`. No account was created. Signup offers Google, Apple, or Continue offline, and offline was not taken.

## How the values were read

The marketing pages are a SvelteKit site on S3/CloudFront. The signed-out web app is a separate host, web.memotron.app, and it redirects `/` to `/signup`. Neither showed a Cloudflare challenge.

Colours are the `--colors-*` custom properties on `.cs_tidigit_dark_blue` and `.cs_tidigit_light_blue` in `memotron.app/_app/immutable/assets/0.CH5IVgSX.css` (3.1 MB, fetched with the page's request context on 2026-11-19). The triplets are 0–255 channels. They were rounded to the nearest sRGB hex. The same dark class is on the signup page, and computed `background-color` / `color` on the live nodes match those hexes (`#151823` surface, `#1f222e` page, `#f2f2f2` text, `#c9c9c9` secondary, `#2c70dd` accent).

Type roles come from applying the utility classes (`text-h1` through `text-b3`) on a probe inside `.cs_tidigit_dark_blue` at 1440 wide. The root font-size computes to 16.702px, so a 1rem utility is slightly above 16px. The hero line "Your memory atlas" / "Exceptional throughout" is an authored `text-[44px]`, recorded separately. The family is the computed stack, with Twenty One Native first and Sen loaded from Google Fonts.

Spacing, radius and control sizes are computed styles on the live nodes (nav link, Go to web app, feature card, Continue with Google), rounded to the authored rem step where the computed px is that step times 16.702.

Screenshots were taken with the kit's `screenshot.mjs` helper. The home page scrolls inside `div.overflow-y-auto` (scrollHeight 8076), so full-page screenshots of the document only show the first viewport. Slices step that scroller by 800px.

## What to distrust

- The light set is declared CSS, not a live theme. No control on these pages switches to light. Computed checks are dark only.
- Root font-size is 16.702px, so a utility labelled 16px in a design tool will not match a computed reading exactly. The tokens keep the computed px.
- Hero type (44px / 66px, weight 500) is a one-off class, not `text-h1` (computed 31.3px / 47px, weight 400).
- The product demo in the hero is a public marketing render. It is not the signed-in app.
- Screenshots are 256-colour PNGs. Read colours from tokens.json, not from the PNG.
- Hover on the nav link and Go to web app was measured. Focus-visible, pressed and disabled were not.
- Other tidigit accent classes (red, iris, violet, pink, orange, oxide) exist in the same stylesheet and were not tokenised. The pages that were open use blue.

## Fonts

The computed stack is Twenty One Native, then Sen, Sen Variable, Space Grotesk, Hanken Grotesk, Nunito, Teachers, Montserrat, Proxima Nova, Poppins, Noto Sans, sans-serif. Twenty One Native is the product face and is not in this package. Sen, Space Grotesk, Hanken Grotesk, Nunito, Teachers, Montserrat, Noto Sans and Poppins are loaded from Google Fonts on the marketing page (SIL Open Font License). The style guide loads Sen as the stand-in. Merriweather is declared as the serif on `:root` and is not used by these pages.

## Do and don't

- **Do use the blue accent only for hover and the early-adopter line.** The filled action is near-white on the dark page, not the accent. See [screenshots/home-dark-default.png](screenshots/home-dark-default.png) and [screenshots/pricing-dark-default.png](screenshots/pricing-dark-default.png).
- **Do keep pills fully round.** Nav, Go to web app, Download for Mac, and the provider buttons are `border-radius: 9999px`.
- **Do keep cards on the darker surface.** Feature cards are `#151823` on a `#1f222e` page. See [screenshots/home-dark-slice2.png](screenshots/home-dark-slice2.png).
- **Don't invent an email field on signup.** The signed-out page is Google, Apple, or Continue offline. See [screenshots/signup-dark-default.png](screenshots/signup-dark-default.png).
- **Don't treat the hero demo as the app.** It is a marketing render with a play button.
