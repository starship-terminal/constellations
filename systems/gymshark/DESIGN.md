# Gymshark

A signed-out capture of the public Gymshark shop at [https://www.gymshark.com](https://www.gymshark.com), region US (USD), on 2026-11-22. Desktop 1440 by 900, `devicePixelRatio` 2. The page is `#ffffff`. Body type is SN Skandia at 14px. Display type is Plaak Gymshark. The promo bar is `#004aa2`. Primary actions are square and filled `#0d1012`.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).
