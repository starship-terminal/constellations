Every value on this page is a CSS custom property generated from tokens.json: the declared --neutral2..98 ramp the whole palette mixes from, the --solar/--darksolar brand accents (the orange #ff640a), the semantic --bg-*/--fg-*/--primary/--border-*/--sidebar-*/--chart-* roles, the --sh-* shiki syntax colours, the xVf/xMono font faces on the --text-xs..5xl type ramp, and the measured geometry (component.*) read off the live DOM. The real pixels are in screenshots/ and components/crops/.

Read from docs.x.ai, signed out, in headless Chromium at 1440×900 (mobile pass at 390×844). The portal paints light by default — the light token set is that painted surface — and the header's "Switch to dark theme" button flips html.dark, which re-points the roles to the dark set; a few names (--border, --input, --ring, --alert, --content-*, --sb-*) exist in dark only. xVf and xMono are served variable faces (weight 200–800) and are not loaded here: samples fall back to system fonts. grok.com and the x.ai app/console surfaces behind Cloudflare were unreachable from the capture host and are documented boundaries, not captures.

The surface

Every docs page is a fixed 80px bar (wordmark, product switcher, section links, the ⌘K search pill, a round theme button) over a two-column shell: a 272px --sidebar-* nav and the scrolling article. Inline code tints --solar and code samples sit in a dark --bg-codeblock panel in both themes, with SDK language tabs above them.

Palette

color.neutral.* is the declared near-achromatic ramp; color.brand.* holds the solar pair and color.shiki.* the code-panel syntax set. The semantic roles under light.* are the painted default (white ground, near-black ink); dark.* resolves the same declarations inside html.dark — including the dark-only border, input, ring, alert and content.* names. sidebar.* and chart.* are their own role sets.

Spacing, radius, layout and motion

Spacing is the Tailwind --spacing unit (0.25rem) plus --spacing-g1; radii run --radius-sm..4xl; layout.* carries the measured chrome — the 4rem topbar height, container widths, the table border width and the cmdk list height. motion.* is the measured set from the reduced-motion probe (docs/decisions/0001): the durations and easing curves elements actually run, the transitions and animations, and what prefers-reduced-motion changes.

Shadows

Type

Two proprietary variable faces: xVf (the body and display face, weight 200–800) and xMono (code). The --text-* ramp runs xs–5xl with paired line-heights; weights are the named --font-weight-* steps. Below that, the ten core.typography.* composites — the display, heading, body, code and control styles measured off the live DOM. Samples fall back to system sans because the faces are not bundled.
