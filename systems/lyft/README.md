# Lyft

Public marketing site for Lyft, the ride-hailing product, captured signed out on 2026-11-21 from https://www.lyft.com/. One theme (light). Desktop 1440×900 and phone 390×844. No account was used. `login-extracted` was left `not-started`.

The header Sign up control is an app deep link. It was not opened. Log in redirects to an empty phone wall at `account.lyft.com/auth`. Nothing was typed there.

## How the values were read

Colour roles, brand scales, the pink, sunset and teal ramps, and elevation shadows were read from `--core-ui-*` custom properties on https://www.lyft.com/ on 2026-11-21. The light declaration (`*-light`) is the value in [tokens.json](tokens.json). The browser's resolved value matched that declaration. `color-scheme` was `normal`.

Button height, pill radius, card radius, padding, and the display and body type styles were read with `getComputedStyle` on the live homepage at 1440×900. The primary "Get a ride" control is 48px tall, 48px radius, padding 0 24px, background `#820076`, text white, Rebel Sans Text 16/22. The h1 is Rebel Sans Display 60/66 weight 600, colour `#1d0c17`.

Screenshots were taken with Playwright at a requested 1440×900 (device scale 1) and 390×844 (device scale 2). Sidecars record the measured viewport. The consent banner was hidden with CSS. It was not dismissed with a click.

## What to distrust

Dark `--core-ui-*-dark` declarations exist in the stylesheets and were not resolved. The public site has no theme switch, so there is no dark set.

Hover on "Get a ride" did not change background, colour, or shadow in the computed style. A pressed state was not held.

The login phone focus shot does not show a focus ring. Focus-visible was not captured.

Rebel Sans is proprietary and is not in this package. The style guide falls back to the system sans.

Screenshots are 256-colour PNGs. Read colours from [tokens.json](tokens.json), not from the images.

The wordmark in [icon.png](icon.png) is the site's own icon, cropped from a 150 px PNG. It is identification, not an asset to reuse.

## Fonts

Rebel Sans Display and Rebel Sans Text loaded on the homepage (`document.fonts`). Both are proprietary. Tokens name them and fall back to `sans-serif`. No font file is committed.

## Do and don't

**Pink is the wordmark. Purple is the action.** The wordmark is `#ff00bf`. Primary buttons are `#820076`. See [screenshots/home-light-default.png](screenshots/home-light-default.png).

**Pages are white, with a warm off-white band.** Page background is `#fff`. The second homepage band uses `#f1f0ec` (`background.secondary`). See [screenshots/home-light-full.png](screenshots/home-light-full.png).

**Controls are pills.** The header button is 48px tall with a 48px radius. Cards use 16px. See [screenshots/home-light-ride-standard.png](screenshots/home-light-ride-standard.png).

**Auth is a phone field, not an email form.** The login wall asks for a phone number and stops at Continue. See [screenshots/login-light-default.png](screenshots/login-light-default.png).

## Rebuild

```bash
cd systems/lyft && python3 tools/build_style_guide.py
python3 tools/test_build_tokens.py
```

`tokens.json` is written from [raw/css-vars.json](raw/css-vars.json) and [raw/components-computed.json](raw/components-computed.json). There is no `build_tokens.py`: the token file was assembled once from those readings and is checked by the test.
