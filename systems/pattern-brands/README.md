# Pattern Brands design reference

Pages read: home, terms of service, privacy policy (the footer href redirects), and a 404. The live viewport was 1169 by 731 CSS pixels, device pixel ratio 2. ## How the values were read

The T3 preview browser opened `https://patternbrands.com/` in a new tab. It landed on `https://www.patternbrands.com/` with no Cloudflare challenge. The same tab then opened terms, privacy, and a missing path.

Colour roles that paint (page, ink, green, white, button, footer, product link) were read with `getComputedStyle`. The rest of the brand scale (blue, pink, neutrals, success, warning, error) was read from `:root` custom properties in the page's own stylesheets, then confirmed with `getPropertyValue` on the document element. A rem in those files is stored as the pixel size the browser computed at a 16px root.

Phone type sizes in the stylesheet (h1 at 2.5rem under max-width 767px) were not confirmed in a 390px viewport. The preview tab stayed at 1169px.

## What to distrust

There are no screenshots. The preview browser returned `The browser is not producing screenshot frames`. Do not treat a missing image as a layout you have seen.

Dark theme was not on the public pages. `color-scheme` was `normal`. There is no dark token set.

Blue (#2d62ff) is `--link-color--link-primary` and `--base-color-system--focus-state`. The links that were open were green (product cards) or ink with an underline (legal copy). Do not paint links blue from this capture.

Pink, success, warning, and error colours are on `:root` and were not painted. The Webflow input focus border rgb(56, 152, 236) is a library default. No field was on these pages.

The button hover circle was 0 by 0 at rest. Its colour is measured. Its expanded size is the hover rule, not a held state.

`icon.png` is the 32px favicon scaled to 128. It is soft.

The stylesheet filename contains `pattern-staging`. The live host was `www.patternbrands.com`.

## Fonts

P22 Mackinac Pro Book is the page face, loaded as woff2 from the Webflow CDN, with Georgia then sans-serif as the fallback the computed style reported. Cadiz Regular is the footer face, with Arial then sans-serif. Both files are licensed type and are not in this package. The tokens name the families the page computed, then those fallbacks.

## Do and don't

- **Green pill, white page.** The action fill is #084935 and the page is #ffffff. See [components.md](components.md).
- **Mackinac for the page, Cadiz for the footer.** Headings and buttons use P22 Mackinac Pro at weight 400. Footer links use Cadiz at 14px.
- **One radius on the home button.** The fill is 24px on a 44px control. The 404 pill uses 1600px. Do not mix them on one control.
- **Do not invent a dark theme.** `color-scheme` was normal and no switch was on the page.
- **Do not send the contact mail or open a checkout.** Contact Us is mailto. The brand stores are other sites. No card was entered.
