# Steel

Steel (steel.dev) is browser infrastructure for AI agents. This package records the public marketing site, docs, brand kit, and the signed-out sign-in page, measured on 2026-11-19 from a live T3 preview tab. The email field on https://auth.steel.dev/sign-in was filled, then cleared. It was not submitted. Google, GitHub, and SSO were not followed. No API key was created. No card was entered.

The live CSS viewport was 1169 by 731 at devicePixelRatio 2. A later freeform resize measured 390 by 844. Marketing pages use `color-scheme: dark` and body background `#141414`. Brand kit has a Light, Dark, and System control. Light was measured, then System was restored. System returned the page to dark.

## How the values were read

Custom properties were read from `getComputedStyle(document.documentElement)` on https://steel.dev/. Component colour, type, radius, padding, and size were read with `getComputedStyle` on the live elements. Display-p3 colours were converted to hex by filling a 1 by 1 canvas in that same page. Auth values were read on https://auth.steel.dev/sign-in after the marketing Sign in link redirected there. Light values were read on https://steel.dev/brand-kit after clicking the Light radio, then System was clicked again.

The preview browser returned "The browser is not producing screenshot frames" on `preview_snapshot`, twice. No screenshots were invented. Headless Playwright was not launched against the login page.

## What to distrust

The desktop CSS viewport was 1169, not 1440. Phone was measured at 390 by 844 after a freeform resize. Do not treat the desktop readings as a 1440 capture. Several borders are translucent display-p3 colours. The token stores the opaque canvas hex painted on black (`--line` became `#3c3b38`). `--surface` at 7.2 percent white painted `#121212` on black. The accent token is `--button-primary` (`#eeeeec`), the near-white face of "START FOR FREE". The header Sign in button computed pure `#ffffff`. Those are different faces. Hover events did not change computed backgrounds, so no hover colour is recorded. The reduce-motion verdict comes from stylesheet rules, not from an emulated reduce pass. `matchMedia('(prefers-reduced-motion: reduce)')` was false in the live tab.

## Fonts

schengenA is the marketing UI face (`--font-sans`). schengenAMono is the button, nav, and code face (`--font-mono`). schengenLine is loaded and was not the computed face of the measured text. Inter is the auth and docs-chrome face. Auth also declares "ABC Schengen A Mono" as `--default-mono-font-family`. These families are named as computed. The font files are not in this package. Tokens keep the measured stacks and fall back to ui-sans-serif and ui-monospace.

## Do and don't

- **Use the dark page and the near-white action.** Home, pricing, and docs sit on `#141414` or `#111110`, with `#eeeeec` text and a `#eeeeec` primary button. [patterns.md](patterns.md) describes that shell.
- **Set buttons in mono, uppercase, at 6px radius.** "START FOR FREE" is schengenAMono 12px, 36px tall. Auth buttons switch to Inter 13px at the same radius. [components.md](components.md) lists both.
- **Keep sign-in as a signed-out form.** https://auth.steel.dev/sign-in asks for GitHub, Google, or an email. Do not invent a dashboard or an API key behind it. [components.md](components.md) records the gap.
- **Let bands carry colour, not a second accent.** The hero is `#99e1e0`, Scale pricing is `#00c6c5`, and the announcement bar is `#05a5ff`. [tokens.json](tokens.json) keeps those as separate colours.
- **Do not invent a screenshot.** The preview browser produced no frames. [screenshots/](screenshots/) says so.
