# Fantastical public site tree

The page title is "Flexibits | Fantastical — The calendar and tasks app you won’t be able to live without." Desktop shots are 1440×900 CSS pixels at device pixel ratio 2, so the PNGs are 2880×1800. The phone homepage is 390×844 CSS pixels at device pixel ratio 2, so that PNG is 780×1688.
