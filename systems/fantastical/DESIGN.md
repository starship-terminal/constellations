# Fantastical

Public marketing site at https://flexibits.com/fantastical. Measured 2026-11-22. Light only.

## Colour

| Role | Value | Where |
|---|---|---|
| Page | `#ffffff` | Body background |
| Text | `#1d1e1f` | Body and hero headline |
| Accent | `#408fff` | Try for Free, Start for Free, Sign In |
| On accent | `#ffffff` | Label on the blue pills |
| Header | `#ffffff` at 0.8 alpha | Fixed bar |

Primary pills use a 24px radius. Start for Free is 44px tall. The header Try for Free control is 32px tall. The header itself is 44px tall and fixed.
