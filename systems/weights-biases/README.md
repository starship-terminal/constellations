# Weights & Biases

Weights & Biases is an MLOps platform. The public site is [wandb.ai/site](https://wandb.ai/site). The app host [wandb.ai](https://wandb.ai/) now redirects to CoreWeave Forge. This package records the signed-out marketing home, the privately hosted pricing page, and the Forge login and signup screens, measured on 2026-11-19. The marketing page is dark. The Forge screens forced light. Widths measured were 1440 and 390 on the marketing home, and 1169 by 731 on the Forge login. Nothing was signed in, typed, or paid for.

## How the values were read

The T3 preview browser opened `https://wandb.ai/` in its own tab. That URL redirected to `https://id.coreweave.com/login?next=%2Fwandb`. `preview_snapshot` returned "The browser is not producing screenshot frames", so measurements continued with `preview_evaluate` on the attached page. The same error came back on the marketing page. No screenshot was invented.

Marketing pages were `https://wandb.ai/site` and `https://wandb.ai/site/pricing-privately-hosted/` (the Pricing link's destination; the requested path `/site/privately-hosted-pricing/` redirected there). Signup was `https://id.coreweave.com/signup`.

After `preview_resize` to 1440 by 900, `window.innerWidth` was 1440, `innerHeight` 900, `devicePixelRatio` 2, and `visualViewport` was 1440 by 900 at scale 1. The phone pass measured 390 by 844 at device pixel ratio 2. The Forge login was read at 1169 by 731, device pixel ratio 2, before the resize. The resize call itself reported a host viewport of 1280 by 800. The CSS viewport above is the one the page computed against.

Custom properties were read from the stylesheets. Component styles were `getComputedStyle` on the live controls. Focus was applied with `element.focus()`. Hover colours for the nav and the LOG IN link were read from the stylesheet rules, because dispatching mouse events did not change the computed colour.

## What to distrust

The marketing site and the Forge login are two products on one brand. Tokens in `dark` are the marketing page. Tokens in `light` are the Forge signed-out screens. Do not paint a Forge form with the marketing ink, or a marketing page with the Forge cobalt, unless the screen you are matching actually did that.

`core.typography.code` line height is 18px, the browser default for 12px, because the computed line height was not stored as its own reading.

The Weave CTA fill is a gradient. `dark.component.button.background` is only the end stop, so a component colour token can exist. Use the gradient stops when you draw the button.

Section greys on the home page include several close values (rgb(32, 34, 38), rgb(32, 35, 40), rgb(33, 36, 41), rgb(39, 39, 42), rgb(40, 42, 47), rgb(52, 58, 66)). The tokens keep two of them. The rest are in [raw/computed.json](raw/computed.json).

WordPress preset colours (`--wp--preset--color--*`) are in the stylesheets and are not product roles. They were left out of the tokens.

The icon PNG is a Quick Look thumbnail of the SVG favicon, then resized to 128 px. It is not a screenshot of the live header.

## Fonts

Source Sans 3 is the UI face on both surfaces. Source Serif 4 is the marketing display face. Source Sans Pro is named on the nav item rule, with Source Sans 3 also present in computed stacks. The code sample uses Consolas, Monaco, Andale Mono, Ubuntu Mono. These are commercial or system faces. The tokens name them. The files are not in this package.

## Do and don't

- **Use the teal gradient for the marketing call to action.** The Weave button is `linear-gradient(270deg, #10bfcc, #0097ab)` with ink text, 8px radius, and uppercase Source Sans 3 at 16px weight 600. See [icons/logo.svg](icons/logo.svg).
- **Use cobalt for the Forge primary button.** Log in and Sign up are `#0541e9` on white, 4px radius, 32px tall. See [icons/mark.svg](icons/mark.svg).
- **Keep the marketing page on ink.** Body background is `#1a1c1f`. Display type is Source Serif 4. Accent links are `#00afc2`. LOG IN is `#ffad33`. See [icons/chevron.svg](icons/chevron.svg).
- **Do not submit the signup form from this capture.** Signup offers Google, GitHub, and Microsoft as well as email. No account was created. See [icons/mark.svg](icons/mark.svg).
- **Do not invent a screenshot.** The frames were not produced. Read the tokens and [icons/logo.svg](icons/logo.svg).

## Rebuild

```bash
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/catalog.py design-md weights-biases
```

Run the last command from the repo root. `tools/build_tokens.py` checks that every token has a source, that every alias resolves, and that every colour labelled Measured is held by a file in [raw/](raw/). It does not regenerate tokens.json: the tokens were written by hand from the readings at capture time.
