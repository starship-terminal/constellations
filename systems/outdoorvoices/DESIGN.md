# Outdoor Voices

Hand copy of the measured public-store tokens. Not written by `make design-md`, because that command needs a catalog.json entry and this pass does not edit catalog.json.

## Theme

Light only. No theme switch was on the public pages. The product column is black. That is a panel, not a second theme.

## Color

| Role | Value | Where |
|---|---|---|
| Page | `#ffffff` | Header and the page below the hero |
| Ink | `#202020` | `--color-black`, department links |
| Muted | `#737373` | `--color-dark-grey` |
| Header | `#ffffff` | Wordmark row |
| Promo | `#2b54ab` | Promo bar and `--color-blue` |
| Promo text | `#ffffff` | Promo paragraph |

## Type

TTCommonsPro at 16px for nav, promo, and the Shop button. NordiquePro at 60px for the homepage heading and 36px for the product title. Display tracking is 0.6px. Button tracking is 0.2px. These files are not in the package.

## Shape

Primary actions are pills, 100px radius, 47px tall. The footer email is 4px on the right corners. The login email and Continue with Shop are 12px. The header bar is 75px. The promo bar is 42px.
