# Tuft & Needle

A signed-out capture of the public Tuft & Needle shop at [https://www.tuftandneedle.com](https://www.tuftandneedle.com), prices in USD, on 2026-11-22. Desktop 1440 by 900. The page is `#ffffff`, the chrome is `#062d31`, and the hero is fields at 44px in `#60edb3`. Add to Cart is a 49px mint pill.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

## Type

Inter on body, nav, and the deals heading. Nav is 14px, weight 500. The deals heading is 32px, weight 400. The homepage hero and the about hero are fields, 44px, weight 700. The product title is fields, 56px, weight 800. The sale price is fields, 40px, weight 700. Font files are not in this package.

## Controls

Start Saving is 49px, sand, radius `42px`. Add to Cart is 49px, mint, radius `42px`, 440px wide. Size chips are 57px with a `40px` radius. The selected Twin chip has a 2px ink border. Search and Cart are 44px icon buttons. The Sale badge is 25px, fill `#ab2210`.
