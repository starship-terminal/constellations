### Principles

1. Keep conditions in field, operator, value order.
2. Keep the expression beside its builder.
3. Put analytics filters above the chart.
4. Separate configuration from the settings index.
5. Reflow the settings table on narrow screens.
6. Keep marketing and dashboard accents distinct.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The capture used read-only DOM computed styles and root custom properties paired with live screenshots. Each token's `$extensions.source` names its raw file, CSS property and element or variable. Per-page use counts in [raw/value-use-counts.json](raw/value-use-counts.json) describe the sampled elements, not every element in the document. One-pixel hidden form inputs are excluded from token selection. No missing color steps, sizes or states are invented.

Every screenshot has actual CSS viewport, visual viewport, DPR, time and image dimensions in [raw/capture-manifest.json](raw/capture-manifest.json). Accepted desktop captures measured 1440 × 1000; mobile captures measured 390 × 844. An initial viewport resize briefly reported another width before settling, so capture-time readings control. The screenshot API returned JPEG bytes, converted without resizing to palette PNG; the source format is recorded. Images are layout evidence only.

The initial account appearance was System, which rendered dark. The owner approved temporarily selecting light, and System was restored and verified at the end. The unsaved custom rule was cancelled; zero custom rules remained. Configuration dialogs were closed without saving. No paid features were activated.

## What to distrust

This is sampled coverage, not full component or theme parity. Raw declarations include legacy Cloudflare and Kumo colors; a declared primitive does not prove it was used on that page. Component tokens use actual computed CSS, while named role tokens retain their declared CSS variable evidence. Functional colors remain in their measured syntax. The public hero and its decorative demonstrations do not prove signed-in dashboard behavior. The 2026-11-22 public shots replace the earlier public home, search, and phone menu. Login and signup walls are empty. The contact-sales page was opened and then discarded because a published phone number was on screen. `login-extracted` stays not-started.

The public full-page attempt had blank scroll-triggered sections and was rejected outside Git. Viewport screenshots intentionally show portions of longer pages, not an entire document. The field dropdown is an internally scrolling list; the crop shows only its visible options. Appearance-menu imagery proves the visible user menu, not an open appearance submenu. Rejected intermediate mobile animation frames are not retained.

The 18 `dark.preview.*`, `light.preview.*` and `marketing.preview.*` colors are Derived 8-bit sRGB previews of the original measured semantic roles. Their sources identify the original token, conversion, rounding and any gamut clipping. Original measured values remain unchanged. No token is Sampled or Reconstruction. The style guide's layout is an illustrative presentation, not a reconstruction of an unobserved Cloudflare screen. Not captured values include a complete spacing scale, all elevation levels, reduced-motion behavior, every breakpoint, icon geometry and complete state palettes.

The identification icon came from [Cloudflare dashboard apple-touch icon](https://dash.cloudflare.com/apple-touch-icon-144x144.png), resized from 144 × 144 to 128 × 128. It is private catalogue identification material, not a reusable brand asset.

## Do and don't

- **Keep conditions in field, operator, value order.** Use the adjacent And/Or controls to extend the same clause; do not hide them in a distant toolbar. [Builder evidence](screenshots/custom-condition-and-dark-desktop.png).
- **Keep the expression beside its builder.** Show the generated expression and matched-traffic estimate together; do not imply an unsaved draft is deployed. [Expression evidence](screenshots/custom-expression-dark-desktop.png).
- **Put analytics filters above the chart.** Keep the time range next to field filters; do not separate those controls from their data. [Filter evidence](screenshots/analytics-filter-dark-desktop.png).
- **Separate configuration from the settings index.** Use a labelled dialog with explicit Cancel and Save; do not turn viewing a configuration into an automatic write. [Dialog evidence](screenshots/challenge-dialog-dark-desktop.png).
- **Reflow the settings table on narrow screens.** Preserve the label and configuration action in a readable card; do not squeeze desktop columns into the phone width. [Mobile evidence](screenshots/settings-search-dark-mobile.png).
- **Keep marketing and dashboard accents distinct.** The public hero uses orange; dashboard security actions use blue. Do not replace operational action colors with marketing artwork. [Public evidence](screenshots/public-home-desktop.png) and [dashboard evidence](screenshots/security-rules-dark-desktop.png).

## Rebuild

From this package directory:

```sh
python3 tools/build_tokens.py
python3 tools/build_components_md.py
python3 tools/build_style_guide.py
```

These read committed sanitized measurements and screenshot pixels. Re-importing new live captures requires `python3 tools/import_capture.py /absolute/path/to/local/cloudflare-captures` after reviewing each image and updating [tools/accepted.json](tools/accepted.json). Raw browser exports stay outside the repository. Run the repository's generation, privacy and validation commands before committing.
