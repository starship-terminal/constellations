# Cloudflare patterns

The public control map is [site-tree.md](site-tree.md). The 2026-11-22 refresh photographs the marketing site signed out. Login and signup stop at empty walls.

## Security-rule editing

The [empty form](screenshots/custom-rule-empty-dark-desktop.png) separates the rule name, matching criteria, expression preview and resulting action into bounded sections. [Field choices](screenshots/custom-field-menu-dark-desktop.png) group request properties; [operators](screenshots/custom-operator-menu-dark-desktop.png) depend on that field. An [And clause](screenshots/custom-condition-and-dark-desktop.png) adds another row. The [expression editor](screenshots/custom-expression-dark-desktop.png) is a separate editable representation. This capture cancelled the draft and never deployed it.

## Analytics exploration

The [chart](screenshots/security-analytics-dark-desktop.png) shares a header with [filters](screenshots/analytics-filter-dark-desktop.png) and a [time-range calendar](screenshots/analytics-date-picker-dark-desktop.png). The filter popup shows AND matching, a disabled Apply action until a clause is supplied, and Cancel. Numeric data is existing account traffic, not synthetic demo data.

## Configuration lookup

The [settings index](screenshots/security-settings-dark-desktop.png) groups tools by risk category. [Text search](screenshots/settings-search-dark-desktop.png) reduces it to matching rows and highlights the match. Configuration opens a [dialog](screenshots/challenge-dialog-dark-desktop.png) with the current value, API references, Cancel and Save. The [mobile version](screenshots/challenge-dialog-dark-mobile.png) retains the explicit footer actions; this capture changed no values.

## Responsive public navigation

The [public desktop hero](screenshots/public-home-desktop.png) combines a short central headline with one primary action. The [mobile hero](screenshots/public-home-mobile.png) stacks the same content. The [mobile menu](screenshots/public-menu-mobile.png) separates section navigation from sign-in and start-building actions. These are public marketing patterns, not dashboard evidence.

## Gaps

No destructive confirmations, first-run onboarding, saved-action feedback, error recovery or full loading sequence were captured. Theme parity is limited to the states named in the package README. Scrolling menus show the viewport of their options, not an assertion that all options fit at once.
