## Tokens

Inputs use `dark.component.input`, links use `dark.component.link`, headings use `core.typography.heading`. Theme colors are in `dark` and, where captured, `light`. The public site is separately labelled `marketing`. Each raw file lists element geometry and computed CSS for the same viewport state.

## Gaps

Not captured: exhaustive hover, held-pressed, loading, invalid-form and error variants; success toasts after writes; destructive confirmations; avatar imagery; light/dark parity for every component. Radio controls are visible in the separately captured light rule footer; the dark initial editor viewport does not establish radio coverage. Hidden one-pixel inputs are excluded from token selection.
