# Scale

A measured reference for Scale AI's public site, captured on 2026-11-21 from https://scale.com/ while signed out. Desktop captures are 1440×900 at 1x. Phone captures are 390×844 CSS at device pixel ratio 2 (PNG 780×1688). Marketing pages paint one light theme. scale.com/docs has its own theme menu, and choosing Dark was captured. The signed-in product at https://dashboard.scale.com/login is a wall: email and password, or Google or GitHub. No password was typed, and those buttons were not clicked.

The control map is [site-tree.md](site-tree.md). It was written before the screenshots.

## How the values were read

Playwright (headless Chromium) loaded the public pages. Custom properties were parsed from stylesheet response bodies with a constructed CSSStyleSheet (`tools/capture/vars.mjs`) and written to [raw/css-vars.json](raw/css-vars.json). Computed styles of the header button, login link, demo heading, and form fields were read in the page (`tools/capture/public/measure.mjs`) and written to [raw/components-computed.json](raw/components-computed.json). `tools/build_tokens.py` maps those readings into tokens.json. Screenshots were quantised to 256 colours after the values were read. OneTrust was hidden with CSS and never clicked.

## What to distrust

The `dark` token set is declared on `[data-theme="dark"] body` in the marketing bundle. Marketing pages did not change under `prefers-color-scheme: dark`. Do not treat that set as a live marketing theme.

Docs dark (`html.dark`, page #090b10) is a different shell from the declared marketing dark tokens (`--background` `hsl(240 10% 3.9%)`). Both are recorded. They are not the same paint.

Hover and focus-visible on Get Started did not change computed fill or text. A motion-only change was not isolated.

Screenshots are 256-colour PNGs. Read colours from tokens.json.

The letter typed into a field during capture was deleted from the package. Forms were not submitted.

The cookie policy page prints a contact address. That line was painted out of [cookies-light-default.png](screenshots/cookies-light-default.png) before commit. The address is not written in this package.

## Fonts

Body and UI use Aeonik, with a fallback stack of ui-sans-serif and system-ui. Aeonik is proprietary and is not in this package. Mono is the site's `mono` face, also not committed. The style guide falls back to the system sans.

## Do and don't

- **Do use black for the primary action.** Get Started is a black pill with white text. [home-light-default.png](screenshots/home-light-default.png)
- **Do keep the header quiet.** Log In is a grey word on a transparent button. The black pill is the only filled action in the bar. [button-secondary-default.png](components/crops/button-secondary-default.png)
- **Do set headlines in Aeonik at a light weight.** The demo title is 40px, weight 400, tight letter-spacing. [demo-light-default.png](screenshots/demo-light-default.png)
- **Don't invent a marketing dark theme from the docs shell.** Docs dark is a separate product. [docs-dark-default.png](screenshots/docs-dark-default.png)
- **Don't treat the login wall as the product UI.** It stops the branch. [login-light-wall.png](screenshots/login-light-wall.png)
- **Don't submit the Get Started form to see validation.** The empty form is the captured state. [demo-light-default.png](screenshots/demo-light-default.png)

## Rebuild

```bash
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  node systems/scale/tools/capture/vars.mjs
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  node systems/scale/tools/capture/public/measure.mjs
python3 systems/scale/tools/build_tokens.py
python3 systems/scale/tools/build_style_guide.py
```

Screenshots: `node systems/scale/tools/capture/public/public.mjs`, then quantise viewport PNGs from `~/.design-systems/scale/raw-shots` with `tools/capture/quantize.py`. Full-page sheets taller than a viewport stay in the scratch folder.
