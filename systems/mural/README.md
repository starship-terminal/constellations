# Mural

Mural is a visual collaboration workspace. This package covers the public marketing site at https://www.mural.co/ and the signed-out login and signup at https://app.mural.co/, captured on 2026-11-19 and refreshed on 2026-11-21. No account was created. No form was submitted. The only theme on these pages is light. Desktop shots are 1440 x 900 CSS px. Phone shots were requested at 390 x 844 CSS px and saved at device pixel ratio 2, so most PNGs are 780 x 1688. The 2026-11-21 phone login shot is 390 x 844 CSS pixels. The map of controls is [site-tree.md](site-tree.md). The login probe is [login-review.json](login-review.json).

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export mural` prints them all with aliases resolved.

### Principles

1. Use the black hero for the marketing headline and the white page everywhere else.
2. Use jade for the marketing start action and red for the auth action.
3. Keep the nav as a floating white pill.
4. Set display type in STK Bureau at weight 300 with negative tracking.
5. Show keyboard focus as a 2px #306ae3 outline.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Custom properties were read from the CSSOM of https://www.mural.co/ in headless Chromium at 1440 x 900. Twelve stylesheets were cross-origin and could not be parsed. The 175 names that did resolve on `:root` are in [raw/css-vars.json](raw/css-vars.json), including the Webflow shared sheet `mural-co.shared`. Component values were read with `getComputedStyle` on the live elements, then cropped. The readings are in [raw/components-computed.json](raw/components-computed.json) and [raw/components-extra.json](raw/components-extra.json).

Cookie and guide overlays were hidden with CSS. They were not accepted. The Product menu click did not open a measurable list. The email typed into the login field was `design@example.com`, and it was deleted before the page closed.

## What to distrust

The hero headline's computed color is #8c8c8c. One span, "Stand out.", is white. A single display token cannot carry both.

The navbar Sign up free link computes its own color as black. The visible label is a child at weight 500. Read the label color from the crop, not from the link's own `color`.

`--mint` on `:root` is #b4f5c8. `--_primitives---color--mint` is #b4f5c0. The jade control is #00c27a, which is `--jade`, not either mint. The tokens keep all three.

The Business card's MOST POPULAR badge text was measured. Its pill fill was not separated from the card, so that fill is not a token.

Phone auth screenshots are full-page 780 x 1688 PNGs. The dimension check rejected them as viewport shots. Use the desktop auth shots for the form.

Screenshots are 256-colour PNGs. Read colours from the tokens.

## Fonts

ABC Social is the UI face, declared as `"ABC Social", Arial, sans-serif`. The auth app computes it as `abcsocial, sans-serif`. STK Bureau is the display face, declared as `"STK Bureau", "Times New Roman", sans-serif`. Both are proprietary and are not in this package. The tokens fall back to Arial and Times New Roman, which the stylesheets already name. Weights seen: ABC Social 300, 400, 500, 700. STK Bureau 300. Inter is also loaded by a third-party widget and is not a Mural text style.

## Do and don't

- **Use the black hero for the marketing headline and the white page everywhere else.** The home hero is a black canvas with a grey-and-white STK Bureau headline. Pricing, product, and the login are a white or near-white page. [home-light-default.png](screenshots/home-light-default.png), [signin-light-default.png](screenshots/signin-light-default.png).
- **Use jade for the marketing start action and red for the auth action.** Get started and the navbar sign-up sit on #00c27a or black. Log in and Sign up on app.mural.co are #e02935. [login-button-default.png](components/crops/login-button-default.png).
- **Keep the nav as a floating white pill.** It is 64px tall, 16px radius, with the two-layer elevated shadow. [navbar-default.png](components/crops/navbar-default.png).
- **Set display type in STK Bureau at weight 300 with negative tracking.** The hero is 80px with -4px tracking. The pricing title is 64px with -3.2px. [display-default.png](components/crops/display-default.png).
- **Show keyboard focus as a 2px #306ae3 outline.** A click into the email field did not paint it. Tab did. [text-field-focus-visible.png](components/crops/text-field-focus-visible.png).

## Rebuild

```bash
cd systems/mural
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
```

The capture scripts live in [tools/capture/](tools/capture/). They need Playwright. They do not submit forms. Each raw file has one writer. Run `harvest.mjs` first (shots, icons, `css-vars.json`, `layout.json`, `pages.json` and its own `components-harvest.json`), then `measure-only.mjs`, the one writer of `components-computed.json` and `dom-map.json`, then `measure-more.mjs` (`components-extra.json`) and `motion-probe.mjs`. Raw full-colour shots from the harvest stay in `~/.design-systems/mural/raw-shots/` and are not part of the package.

## Coverage notes

The signed-in product was not entered. Login asks for a work email and then, only after submit, an SSO redirect or a password. That submit was not made. Signup asks the same, plus a privacy agreement, and was not submitted. No card, phone number, or government ID was requested on the pages that loaded.
