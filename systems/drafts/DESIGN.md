# Drafts public

Hand-written from the readings in [raw/measured.json](raw/measured.json). Not generated by `make design-md`, because that rewrites the catalog and this package is not registered.

## Colour

One painted theme. Page is white. Ink is near-black. The cover is a blue photograph. The footer is a darker blue. The only filled button on a public page is the primary blue on the Oops page.

| Role | Value | Where |
|---|---|---|
| Page | rgb(255, 255, 255) | body |
| Ink | rgb(22, 28, 45) | homepage h1 |
| Muted | rgb(134, 154, 184) | Oops lede |
| Tagline | rgb(128, 128, 128) | "A Different Kind of Notes App" |
| Nav on cover | rgb(255, 255, 255) | Menu link |
| Cover sample | rgb(15, 65, 126) | one patch of the cover photo |
| Footer | rgb(23, 57, 115) | footer background |
| CTA | rgb(51, 94, 234) | Oops button, same as `--bs-primary` |
| On CTA | rgb(255, 255, 255) | Oops button label |

## Type

The stack is the system sans: `-apple-system`, `system-ui`, `Segoe UI`, Roboto, `Helvetica Neue`, Arial, sans-serif.

| Role | Size | Weight | Line height |
|---|---|---|---|
| Display (h1 at 1440) | 48px | 400 | 57.6px, letter-spacing -0.96px |
| Body | 17px | 400 | 27.2px |
| Menu link | 17px | 600 | 27.2px |

## Controls

The Oops buttons are 17px, weight 600, padding 9px 16px, radius 6px, fill rgb(51, 94, 234), type white.

Feature cards are white, radius 6px, shadow `rgba(22, 28, 45, 0.1) 0px 24px 64px 0px`.

## What this file does not cover

Hover, pressed, disabled, loading, a dark marketing theme, pricing, and any signed-in editor. The cover must stay a photograph.
