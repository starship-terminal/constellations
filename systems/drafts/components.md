# Drafts public components

Inventory of what the public site shows. No crops. The shots are the full pages in [screenshots/](screenshots/).

| Component | Where | States captured |
|---|---|---|
| Wordmark | Cover photograph, and the footer `brand-only.svg` | default |
| Menu link | Header, white on the cover | default, menu open |
| Menu panel | Desktop dropdown and phone drawer | open |
| App Store badge | Homepage and footer | default. Store not opened. |
| Feature card | "How Drafts Works" and "Why You'll Love Drafts" | default |
| Icon glyph | Feather icons inside the feature cards | default |
| Link | Award row, footer, menu | default |
| Button | Oops page: Drafts Home, User Guide, Community | default |
| Heading | h1 at 48px | default |
| Screenshot carousel | Product shots under the feature cards | first frame. Next and Previous were not clicked. |
| Empty state | [/error](https://getdrafts.com/error) | default |

Not present on the painted public pages: text field, text area, select, checkbox, radio, switch, tabs, tooltip, dialog (the closed theme modals were not opened), toast, table, avatar, badge, pricing cards.

Not captured: hover, focus-visible, pressed, selected, disabled, loading, error on a field.
