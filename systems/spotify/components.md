# Spotify components

Generated by `tools/build_components_md.py` from its inventory, [tokens.json](tokens.json) and [components/crops/](components/crops). Values are token paths (in the `dark` set for colours, the only theme, and `core` for the rest); take them from tokens.json. Crops are cut from the 256-colour screenshots by `tools/crops.py`, so they show layout and state, never exact colour.
