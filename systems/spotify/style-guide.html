Spotify style guide

Spotify for iOS 26, dark (its only theme), read from stills captured through iPhone Mirroring on 2026-10-23. Every value below comes from tokens.json; points are 1:1 with CSS pixels. The font is not known, so the page uses the platform sans. Glass is drawn as its centre colour: the real material blurs what is behind it. There is no light theme to switch to.
