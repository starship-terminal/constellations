# Refero design reference

A token set and component reference for Refero, the design-research product — for building gallery, research and style-documentation surfaces in the style of the real thing. Two public surfaces, one system, both captured: **refero.design** is the research app (a fixed left rail, the centred research card, rotating screenshot galleries, pricing and MCP marketing); **styles.refero.design** is the public styles gallery (a translucent sticky bar over a near-white page, an index of padded tiles that swap their poster for a scroll-preview video on hover, and a documentation page per style). They share one neutral ramp and one set of semantic names; each adds a display serif (Title on refero.design, kalice on styles) and a UI sans (Base-Variable, neueMontreal). It was read on 2026-11-02, signed out, in headless Chromium at 1440 wide and 390 wide: the refero.design home, the Web and iOS search pages, pricing, MCP, the styles index and one style page, plus the mobile home and styles index.

The reason Refero is worth a capture at all: it is the rare product whose whole identity is restraint — white-on-white surfaces separated by fills and hairlines instead of shadows, one dark pill for the action that matters, two quiet serifs for the display lines — and its signature interaction, a card that plays a video of someone scrolling the real site on hover, is a distinctive idea in itself.

### Principles

1. Do keep the palette monochrome.
2. Do separate surfaces with fills and hairlines, not shadows.
3. Do use the serif for display lines only.
4. Do round the styles tile generously.
5. Do play the video on hover, at rest show the poster.
6. Don't invent gradients or accent colours.
7. Don't expect every control to be a `<button>`.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## Do and don't

- **Do keep the palette monochrome.** refero.design has no brand colour: surfaces are white and `gray.solid.100`–`300`, text is the alpha scale, and the one strong element is the near-black pill — the CTA, the New research button, the submit arrow ([plan-cta](components/crops/plan-cta-default.png), [research-box](components/crops/research-box-default.png)).
- **Do separate surfaces with fills and hairlines, not shadows.** Cards and panels stack #fff on #f7f8fb with 1px `gray.alpha` borders; the only real drop shadow belongs to the floating promo card ([mcp-card](components/crops/mcp-card-default.png), [styles-card](components/crops/styles-card-default.png)).
- **Do use the serif for display lines only.** Title carries refero.design's headings and kalice the styles hero and style titles; body, chips, tabs and labels stay in the UI sans ([hero-title](components/crops/hero-title-default.png), [styles-hero-title](components/crops/styles-hero-title-default.png)).
- **Do round the styles tile generously.** The signature styles-gallery card is a 32px-radius padded tile — the 40px favicon square at 12px radius, the doc tabs' 2px ink underline ([styles-card](components/crops/styles-card-default.png), [entity-tab-active](components/crops/entity-tab-active-default.png)).
- **Do play the video on hover, at rest show the poster.** On the styles index a pointer rest paints the site's screenshot; hover fades the scroll-preview mp4 in over it, opacity 0.5s — the entity frame loads the video straight away ([styles-card-video](components/crops/styles-card-video-video.png), [entity-frame](components/crops/entity-frame-default.png)).
- **Don't invent gradients or accent colours.** The home hero's cycling colourway is the one decorative flourish, and it lives inside the headline text; everywhere else the product stays black, white and grey ([styles-hero](components/crops/styles-hero-default.png)).
- **Don't expect every control to be a `<button>`.** Refero renders the MCP card's Close as a styled `div`, the coach close as a bare `svg`, and the styles chips as `div`s — match the look, keep real semantics ([coach-close](components/crops/coach-close-default.png), [styles-chip](components/crops/styles-chip-default.png)).

## How the values were read

Both surfaces are public, so every page was captured signed out in headless Chromium: a script tours each page in a real browser, dismisses the two home promos (the fixed MCP card and the coach box under the research field) before the clean shots, hovers and focuses each component for its state shots, and reads computed styles rather than trusting stylesheets. `vars.mjs` dumps every custom property each host declares — 357 on refero.design, 455 on styles.refero.design — plus the font faces and the dark-theme checks; `measure.mjs` measures each component live because the home grid re-renders on a rotation timer and styles chips and closes are non-semantic elements; `icons.mjs` lifts every SVG it passes. Values marked `css-var` come from the site's own variables; `measured` values are computed styles of the real element; `declared` values come from stylesheets without a matching painted element.

Two themes are captured: the light set is what both hosts paint by default, the dark set what they paint under prefers-color-scheme: dark (refero.design's `body#dark-theme` is the same palette pinned manually). Aliases in a theme point into the palette only where the value the theme resolves is the same one the palette holds, so the dark greys stay literals — dark `gray.solid` steps invert rather than alias to the light ramp.

## Rebuild

The kit under [tools/capture/](tools/capture) re-reads the live sites; the builders re-derive the package from `raw/`:

```sh
cd systems/refero-design
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  node tools/capture/public/public.mjs        # page screenshots into raw/screens/
PLAYWRIGHT=... node tools/capture/vars.mjs    # raw/css-vars.json
PLAYWRIGHT=... node tools/capture/public/measure.mjs   # raw/components-computed.json + crops
PLAYWRIGHT=... node tools/capture/icons.mjs   # icons/ + INDEX.tsv
PLAYWRIGHT=... node tools/capture/layout.mjs  # raw/layout.json
python3 tools/capture/quantize.py             # screenshots/ from raw/screens/
node tools/capture/public/build-measurements.mjs       # raw/measurements.md
python3 tools/build_tokens.py                 # tokens.json from component-tokens.json + css-vars.json
python3 tools/build_components_md.public.py   # components.md
python3 tools/build_style_guide.py            # style-guide.html
```

Then `make design-md` at the repo root refreshes [DESIGN.md](DESIGN.md), and `make check` re-grades the package.
