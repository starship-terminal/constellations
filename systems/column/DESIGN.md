# Column

Public marketing design tokens for column.com, measured 2026-11-21, signed out, light theme only.

This file is a readable export of [tokens.json](tokens.json). It is not generated by `make design-md`, because that command requires a catalog.json entry and this capture was told not to edit catalog.json. If the catalog later includes Column, regenerate this file and replace it.
