Column, declared and measured

Every value on this page is a CSS custom property generated from tokens.json. column.com ships a real named token layer in its stylesheets: the --color-<family>-<step> ramps (blue, gray, cyan, seafoam, purple, pink, red, orange, yellow, green), the 71-step --space-* scale, the --text-*/--lh-*/--letter-spacing-* type scales, the --font-* stacks and weights (SuisseIntl, SuisseIntlMono, Inter), the --radii-*, --screen-* and --cols-* layers and the --shadow-product elevation — plus a semantic layer (--bg-color-*, --text-color-*, --btn-*, --form-*, --link-*) that .color-palette--primary binds for the light theme and .color-palette-inverted--* rebinds on the dark infrastructure band. Roles are emitted both as declared (with their var() chains) and as measured on the painted chrome: the navy Sign-up button, the launch banner, the grey footer and the sign-in card.

One light theme across the marketing routes, with the near-black navy infrastructure band inside it; dashboard.column.com/login is a separate app surface measured at rest as the sign-in boundary.
