# Column patterns

Public marketing site, signed out, 2026-11-21. Screenshots are 256-colour copies of the live pages.

## App shell

A white page, a fixed header, and a long footer. Header: announcement link, logo, Products and Developers menus, Blog, Company, Sign in, Get started. Phone width replaces the links with an Open menu button. See [home-light-default.png](screenshots/home-light-default.png) and [mobile-home-light-menu-open.png](screenshots/mobile-home-light-menu-open.png).

## Navigation menus

Products, Developers, and Get started are buttons that expand an in-page menu. They do not navigate. Sign in and Sign up leave the marketing host for the login wall. See [home-light-products-menu.png](screenshots/home-light-products-menu.png).

## Hero

Display type in Suisse Intl, a navy primary action, and a product illustration that is published demo art (sample names and a sample API payload). See [home-light-default.png](screenshots/home-light-default.png).

## Product page

Each product route repeats the shell, a product hero, and the same footer. See [ach-light-default.png](screenshots/ach-light-default.png).

## Contact form

A long public form. Fields were photographed empty. Nothing was typed or submitted, so no validation error was captured. See [contact-light-default.png](screenshots/contact-light-default.png).

## Docs

docs.column.com is a separate public surface: sidebar, search dialog, theme toggle. Search was opened and closed with nothing typed. See [docs-light-default.png](screenshots/docs-light-default.png).

## Login wall

dashboard.column.com/login is the signed-out boundary. The capture stops there. A screenshot pass hit a captcha, which was not solved and not kept. The wall is recorded in [login-review.json](login-review.json).
