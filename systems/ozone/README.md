2. https://ozone.pro/ returns HTTP 404 from Framer, title "Site Not Found". Those styles are Framer's empty state and are not in the tokens.
3. The T3 preview browser loaded https://web.archive.org/web/20240506015935/https://ozone.pro/ . The document title was "Ozone - Create Videos Faster with AI." and the h1 was "Supercharge your video creation". `preview_evaluate` read `getComputedStyle`. Viewport was set with `preview_resize` to 1440 by 900, then 390 by 844. The blog replay is https://web.archive.org/web/20240227223658/https://www.ozone.pro/blog , read at the fill viewport 1169 by 731.
4. `preview_snapshot` failed twice with "The browser is not producing screenshot frames." No screenshot was invented. Crops were not cut.

The Wayback toolbar was in the DOM. Readings were taken from `#main` and from nodes with `data-framer-name`, not from `#wm-ipp-base`.

## What to distrust

- This is an archive replay from 2024-05-06 (home) and 2024-02-27 (blog), not the live product. The live product is gone.
- Font files failed to load (`document.fonts` status `error` for PolySans, Inter Soft Medium and Allotrope). The family names are what the computed style reported. Sizes and line heights may be fallback metrics.
- The hero fill at 1280 CSS px was `rgb(6, 86, 226)`. At 1440 it was `rgb(66, 36, 255)`. The token uses the 1440 reading. The 1280 value is in [raw/computed-home.json](raw/computed-home.json) and is not a second theme.
- Anchor elements computed `color: rgb(0, 0, 238)`, the browser default. The visible label is the inner `p` at `rgb(255, 255, 255)`. Tokens use the label.
- `{dark.border}` is not a measured stroke. No control had a non-zero border width. The swatch repeats the secondary button fill so the catalog has a border colour that was on the page.
- The comment panel, tags and feature tiles are a marketing demo, not the signed-in editor.
- The giant footer wordmark was sampled at three close blues. The token keeps the first, `rgb(0, 49, 128)`.

## Fonts

PolySans Bulky Wide, PolySans Slim Wide and PolySans Neutral Wide are the display faces. Inter is the text face. Inter Soft Medium is the nav face. Allotrope Variable Compressed Thin is the footer wordmark. All five are commercial faces. The tokens name them and fall back to `sans-serif`. The files are not in this package. The replay did not load them.

## Do and don't

1. **Use the black page and the blue pill.** The page fill is `#000000` and the primary action is `#1f78ff` with a 100px radius and a 14px semibold Inter label. The evidence is the computed style of `Primary` in [raw/computed-home.json](raw/computed-home.json).
2. **Set display type in PolySans and UI type in Inter.** The h1 is PolySans Bulky Wide at 64px / 72px. Button labels are Inter 14px / 600 / -0.14px. The evidence is the same file.
3. **Treat the comment panel as a picture.** It is a Framer demo on the marketing page, radius 8px, fill `#121314`. It is not the editor.
4. **Do not invent a light theme.** The replay had one theme. A second palette would be a guess.
5. **Do not treat archive type metrics as loaded-font metrics.** The face files failed in the replay. Family names are measured. Rendering is not.
6. **Do not open app.ozone.tech from this package.** The host does not resolve, and this capture did not enter login or register.
