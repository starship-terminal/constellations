# Synthesia.io design reference

A token set for Synthesia's public signed-out marketing site. Read from **https://www.synthesia.io/** on **2026-11-19** in headless Chromium at 1440×900 and 390×844. The T3 preview browser loaded the home page and its computed styles, then returned "The browser is not producing screenshot frames", so screenshots come from the headless pass on pages that had already loaded without a Cloudflare challenge.

Captured: home, pricing, enterprise, video, features/avatars, blog, book-a-demo (fields measured, not submitted), a 404, a 390px home viewport, and the signed-out sign-in wall at login.synthesia.io. One theme. Nothing was typed, signed into, or paid for.

## How the values were read

Custom properties were parsed from the Webflow stylesheets on cdn.prod.website-files.com and resolved with `getComputedStyle` on the home page at 1440×900. Colour tokens use those resolved values. An alias is kept only when the declared `var()` target resolves to the same colour. Component sizes come from the live controls in raw/states.json.

## What to distrust

The preview browser could not produce screenshots. Headless shots are the evidence for layout. Several semantic names resolve to a different colour than their declared `var()` (grey ramps, some link and caption tokens). Those tokens store the painted value and say so. Typography custom properties are fluid and do not match the measured 56px hero, which is stored separately. Sign-in, signup, and checkout were not entered. Book demo asks for a phone number and was not submitted. `tools/capture/harvest.mjs` used to click a cookie banner's Accept all when one showed. The recorded run logged no click on any desktop page (`cookie: null` in [raw/capture-log.json](raw/capture-log.json)); the phone pass did not log it, so `screenshots/home-light-mobile.png` may have been taken after an accept. The script now hides the banner instead and was not rerun. `raw/login-wall.json` matches neither capture script's output and was edited by hand. Type weights in the fluid roles are a rule (500 for headings, 400 otherwise), not a reading.

## Fonts

Basiersquare Webfont, weights 400 and 500, woff2 from the Webflow CDN. Licensed, not shipped. Tokens name the family and fall back to sans-serif.

## Coverage

Captured: home, pricing, enterprise, video, features/avatars, blog, book-a-demo fields, 404, mobile home viewport, signed-out login wall (email and Google, nothing typed).

Not captured: the signed-in app, signup, any paid plan, card entry, the book-demo submit, phone number, company SSO beyond seeing "Continue with Google", dark theme (none on these pages), checkbox/radio/switch/dialog/toast states, full-page tall screenshots.

## Do and don't

1. **Do paint the page white and the action near-black.** The nav "Get started" button is `#090b22` with white text, not the indigo brand fill ([home](screenshots/home-light-default.png)).
2. **Do keep indigo for brand and links.** `#3e57da` is `--indigo-500-main` and the brand semantic, used as text and accent, not as the primary button ([tokens](tokens.json)).
3. **Do use the small radius scale.** Nav buttons are 8px, hero buttons 10px, fields 8px. The sheet also declares a larger radius scale ([button](components/crops/button-primary-default.png)).
4. **Do set body text to `#363636`.** That is the computed body colour. Primary headings are `#090b22` ([hero](components/crops/heading-hero-default.png)).
5. **Don't invent a dark theme.** These public pages expose one colour scheme.
6. **Don't follow Get started into checkout.** Pricing CTAs and the login wall are boundaries ([pricing](screenshots/pricing-light-default.png)).
7. **Don't submit book demo.** It requires a phone number ([book demo](screenshots/book-demo-light-default.png)).
8. **Don't ship the Basier Square font files.** Name the family only.

## Rebuild

```bash
python3 tools/build_tokens.py
python3 tools/catalog.py design-md synthesia-io
```

Capture order, if rerun: `tools/capture/probe.mjs` writes `raw/css-vars.json`, `raw/login-wall.json`, `raw/pricing.json`, `raw/book-demo-fields.json` and `raw/states.json`; `tools/capture/harvest.mjs` writes `raw/measurements.json`, `raw/capture-log.json`, `raw/harvest-css-vars.json` and `raw/harvest-login-wall.json`. Each raw file has one writer. The kit's `tools/capture/vars.mjs`, an unadapted Claude copy that also wrote `raw/css-vars.json` in a shape `build_tokens.py` cannot read, is removed, so each raw file has one writer.
