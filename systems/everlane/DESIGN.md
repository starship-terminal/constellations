# Everlane

Hand copy of the measured public-store tokens. Not written by `make design-md`, because that command needs a catalog.json entry and this pass does not edit catalog.json.

## Theme

Light only. No theme switch was on the public pages.

## Color

| Role | Value | Where |
|---|---|---|
| Page | `#ffffff` | Body |
| Ink | `#000000` | Department links |
| Ink soft | `#121212` | `--color-foreground` |
| Muted | `#737373` | Product breadcrumb |
| Header | `#ffffff` | Wordmark row |
| Announcement | `#c8c0b8` | Shipping slide section |
| Cashmere slide | `#12344b` | Sampled from the homepage PNG top row |
| Sale | `#d0021b` | SALE label |
| Button | `#262626` | Sold Out and selected style |
| Button text | `#ffffff` | Sold Out |
| Field border | `#dedede` | Login email |
| Shop | `#5433eb` | Continue with Shop, not clicked |

## Type

Maison Neue Book at 12px for nav and 16px for body. The hero eyebrow is Maison Neue at 20px. Nav tracking is 0.24px. These files are not in the package.

## Shape

Controls are square. `--buttons-radius` and `--inputs-radius` are 0. The header stack is 73px, announcement bar included in that variable's name only as `--header-height`. The announcement bar itself is 32px.
