# Patterns

Public pages on super.so and the signed-out app on app.super.so. Viewport 1169 by 731. No screenshots.

## Marketing shell

A sticky nav, 80px, background `rgba(255, 255, 255, 0.85)`, blur 4px, shadow `rgba(0, 0, 0, 0.04) 0px 0px 20px`. Items are Templates, Showcase, Features, Pricing, Guides, Blog. The right side is a white Sign in chip and an amber "Get started free" chip. The hamburger `.super-navbar__button` is `display: none` at this width.

The page background is `#fdfdfc`. The hero on home is an h1 at 55.45px, weight 600, letter-spacing -2.5px, line-height 60.995px, colour `#262a2e`, max width about 977px. A yellow chip above it reads "NEW Now with MCP/AI, memberships & a built-in cookie banner": background `#ffbe3c`, text `#111111`, padding `8px 18px`, radius 10px, 17px weight 700.

The footer is `#090909` with white text, padding `48px 96px` at this width. Under 768px the stylesheet sets padding to 40px. That width was not captured.

## Pricing

## Features

https://super.so/features uses the same nav and page colour. The visible title "Features" computed at 24px weight 700, letter-spacing -1px, colour `#b3bac2`. No form.

## Auth
