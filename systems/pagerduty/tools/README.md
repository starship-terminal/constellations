# How this package was captured

2026-11-22. Public pages only.

Headless Chromium (Playwright 1.55 at `~/.design-systems/pw`) opened https://www.pagerduty.com/ and the header and footer destinations. Viewport 1440 by 900 and 390 by 844, device pixel ratio 2. Screenshots were quantised to 256 colours.

Log In and Start for Free were opened and left empty. Next and Continue were not clicked. No identity provider was clicked. No form was submitted. No trial was started. Search was not typed. Pricing Start Free Trial was not clicked.

The OneTrust cookie banner was hidden with CSS and not accepted. Contact Us was discarded because it prints a sales phone number. Privacy policy was discarded because it prints a street address. Request a demo was discarded because it is a contact form. Investor Relations stopped on a Cloudflare verification page and was not photographed. The public status page was not photographed because the first viewport prints a live clock.

`catalog.json` was left alone, so `make design-md` and `make brief` were not run for this package.
