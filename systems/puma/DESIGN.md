# Puma

A signed-out capture of the public Puma shop at [https://us.puma.com/us/en](https://us.puma.com/us/en) on 2026-11-22. `https://us.puma.com` resolved there. Desktop 1440 by 900. The page is white, the nav is `#191919`, type is FFDINforPuma, and the sale price is `#ba2b20`. Add to cart is a 56px near-black button. Empty Login and Create account stay grey.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

## Colour

| Role | Value | Where |
|---|---|---|
| Page | `#ffffff` | body background |
| Ink | `#191919` | body, titles, strikethrough price |
| Nav | `#191919` | main menu |
| On nav | `#ffffff` | department labels, wordmark |
| Hero text | `#ffffff` | homepage heading over the campaign photo |
| Sale | `#ba2b20` | sale price |
| Button | `#191919` | Add to cart |
| Disabled | `#bdc1c5` | empty Login and Create account |
| Disabled text | `#3b4047` | those buttons' labels |
| Field border | `#e5e7eb` | email and password fields |
| Search border | `#676d75` | search pill on the nav |

## Type

FFDINforPuma, then Inter. Body 16px at weight 400. Field labels 12px at weight 700. Hero 40px. Product title 32px. Account title 48px. Font files are not in this package.

## Controls

Hero shop links are 42px, square, white. Search and the account icons are 40px. Add to cart, Login, and Create account are 56px with a 2px radius. The nav is 80px. The promo strip is 44px.
