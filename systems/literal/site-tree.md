# Literal public site tree

Mapped on 2026-11-22 from the public homepage, https://literal.club/. Title: "Literal | Track your reading and discover new books". The first visible heading is "Discover, organise & discuss books". The homepage is a live marketing page, not a parked domain and not a captcha wall. The page painted black. `prefers-color-scheme` was dark, and the site has no public theme toggle.

The map was read in an incognito preview tab. Headless Chromium on this host received a Cloudflare check and no public page, so those frames were discarded. Photographs come from the same incognito preview tab. Desktop shots are 1440 by 900 CSS pixels at 2x (PNG width 2880). Phone shots are 390 by 844 CSS pixels at 2x (PNG width 780). They are the first viewport, not the full page.

Nothing was typed. No email, password, code, phone, or address was entered. No form was submitted. No identity provider was clicked. No captcha was solved. No book was shelved and no review was written. `login-extracted` stays not-started. catalog.json was left alone. webapps-manifest.json was left alone.

origin/main already had `systems/literal/` and did not have `systems/literal/site-tree.md`. This walk adds the site tree and screenshots. It does not remeasure tokens.
