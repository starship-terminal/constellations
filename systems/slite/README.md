# Slite design reference

A token set and component reference for Slite's public signed-out surface. It was read on **2026-11-19** from slite.com in the T3 preview browser, signed out, at a measured **1440 x 900** (devicePixelRatio 2) and **390 x 844**. Captured: the marketing home, pricing, features, the sign-in card at rest, and the create-account card at rest. Nothing was submitted. Google, Apple, Slack, Continue with email, Find your workspaces, Book demo, Get started, Contact Sales, and checkout were not pressed.

Slite's marketing site is a cream page (`#fdfdfd`) with a warmer header (`#fdf9f4`). Display type is **Garnett** at 56px / 500. UI type is **UniversalSans**. The primary action is a near-black pill (`#2d2f34`, radius 999px). The brand accent is saturn orange (`#f67748`) on Talk to us, the New badge, the announcement strip, and the recommended plan frame. **Boundary:** the signed-in workspace, editor, and settings sit behind sign-in and were not entered. The create page offers Google, Apple, and Slack. Those rows were measured and not pressed.

### Principles

1. Do paint the page cream and the header warmer.
2. Do set the hero in Garnett.
3. Do make the primary action a near-black pill.
4. Do use saturn orange for the brand accent.
5. Do keep the sign-in card on moon dust.
6. Don't invent a dark theme.
7. Don't press the OAuth rows from this package.
8. Don't treat the consent dialog as product chrome.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The T3 preview browser loaded slite.com signed out. `preview_evaluate` read `getComputedStyle` on the body, the home h1, the nav controls, the pricing cards, the sign-in field, and the create-account rows. 355 custom properties resolved on `:root`. The readable stylesheets were same-origin (`/assets/static/style-*.css` and the renderer sheets).

`preview_snapshot` failed twice: "The browser is not producing screenshot frames." Headless Playwright loaded the public marketing pages with HTTP 200 and no Cloudflare challenge, and those PNGs are the screenshots. The login pages were not opened in that headless session. The sign-in crop was taken after the public page had already loaded without a challenge, from the same public host. Login was not submitted.

The billing switch was clicked once on the public pricing page so its off state could be read. The price changed from `$10` to `$12`. No plan was purchased.

## What to distrust

The announcement strip's own link computed a transparent background. The orange fill is the strip behind it, read from the screenshot, and it matches `--saturn-orange`. The CookieYes "Do Not Sell" link is `#1863dc`. That is the consent dialog, not a Slite button.

Garnett, UniversalSans, FixEmoji, PolySans, and Geist Mono are proprietary and are not in the package. The style guide uses Georgia for Garnett and the system sans for UniversalSans.

`--focus-outline-color` is `hsl(216, 82%, 60%)`. The focused email label computed a different outline, `rgb(69, 136, 237)`. Both are recorded. The field itself kept `outline: none`.

No dark theme was painted. `prefers-color-scheme: dark` matched the OS, and the page stayed on the light palette. The readable sheets had zero `prefers-color-scheme: dark` rules.

The home h1 stayed 56px at 390. Its box height was 0 until layout settled, so the phone size is the computed font-size, not a measured line box.

## Do and don't

1. **Do paint the page cream and the header warmer.** Page is `#fdfdfd`. Header and hero are `#fdf9f4`. Text is `#3f434a`. See [home-light-default](screenshots/home-light-default.png).
2. **Do set the hero in Garnett.** The home h1 is 56px, line-height 67.2px, weight 500. See [hero-display-light-default](components/crops/hero-display-light-default.png).
3. **Do make the primary action a near-black pill.** Start for free is `#2d2f34` with `#fdfdfd` text, radius 999px, height 38px, padding 0 16px. See [button-primary-light-default](components/crops/button-primary-light-default.png).
4. **Do use saturn orange for the brand accent.** Talk to us, the New badge, and the recommended plan frame are `#f67748`. See [button-accent-light-default](components/crops/button-accent-light-default.png).
5. **Do keep the sign-in card on moon dust.** The auth page is `#f9efe4`. The card is `#fdfdfd`, radius 16px, padding 48px 60px. See [card-signin-light-default](components/crops/card-signin-light-default.png).
6. **Don't invent a dark theme.** The public pages did not paint one. Sidebar tokens on `:root` are not a signed-in capture.
7. **Don't press the OAuth rows from this package.** Google, Apple, and Slack were measured at rest and not entered.
8. **Don't treat the consent dialog as product chrome.** Do Not Sell is CookieYes blue `#1863dc`.
