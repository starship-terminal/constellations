# Oku

Oku is a reading tracker at [oku.club](https://oku.club/). This package records the public signed-out site: the homepage, pricing, explore, one book page, the blog and one post, sign-in, join, reset password, privacy, and a 404. Measured live in the T3 Code preview browser on 2026-11-19, dark by default and light after `prefers-color-scheme: light`. Desktop 1440 by 900 and phone 390 by 844. No account was created. No form was submitted.

## How the values were read

Custom properties were read from the page stylesheets on [https://oku.club/](https://oku.club/). Oku declares `--theme-ui-colors-*` on `html`, again for `html.theme-ui-__default`, and again for `html.theme-ui-dark`. The painted theme follows `prefers-color-scheme`. With the media query dark, `html` has no theme class, milk is `#131314`, and the page background is `rgb(19, 19, 20)`. Setting the preview tab to light resolved the same properties to the light declarations and repainted explore. Setting it back to dark restored the dark paint.

Component values are `getComputedStyle` on the live elements, at the viewport named in [raw/readings.json](raw/readings.json). Colour roles in the tokens use the declared hex when the computed `rgb()` matches it. The book-card link colour does not match a declared name, so it is stored as measured.

## What to distrust

There are no screenshots. `preview_snapshot` returned "The browser is not producing screenshot frames". Coverage of layout is from DOM measurements, not from a picture.

Light was measured on explore only. Pricing cards, fields, and the homepage were not remeasured after the theme switch. Their light semantic colours are the declared custom properties, marked as such in the token source.

`:focus { outline: none }` is in the stylesheet. A focused Join button computed no outline. That is the product, not a missing reading.

The billing switch's unchecked position was not in the accessible stylesheets. Toastify and Nolt colours are declared and were not on screen.

Fabric Serif is not loaded in the style guide. Source Serif 4 stands in.

## Fonts

Inter is self-hosted at `static.oku.club` in weights 300, 400, 500 and 700, roman and italic. The body stack is Inter, then `-apple-system`, `system-ui`, Segoe UI, Helvetica, Arial. The style guide loads Inter from Google Fonts.

FabricSerifWeb is self-hosted, weight 400, file `FabricSerifWeb-Regular-DsB3lky3.woff2`. It is used for display headings, the phone drawer, and the pricing toggle labels. It is not redistributed here.

## Do and don't

- **Display is Fabric Serif, UI is Inter.** Headings from 24px up use Fabric Serif at weight 400. Buttons, fields, nav and body use Inter.
- **The filled action is the ink, not the red.** Join is olive on dark and black on light. Candy `#E32020` is declared and was not the painted button.
- **Quiet links have no underline.** Nav, captions and the legal line set `text-decoration: none`.
- **Cards share an 8px radius.** Book cards, pricing cards, buttons and fields all use 8px. Covers use 3px.
- **Do not follow Subscribe.** The pricing buttons hand off to checkout. This capture stopped at the card.
