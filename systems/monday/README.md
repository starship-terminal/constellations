# monday.com

monday.com's public marketing site and the signed-out login and signup forms, measured on 2026-11-19. No account was created. The marketing home (`monday.com`) is a Webflow page in Poppins on white, with a purple pill as the primary action. Pricing (`monday.com/pricing`) is a Next.js page on the same chrome. Login and signup live on `auth.monday.com` and paint the product token layer (Figtree for UI, Poppins for headings, primary blue `#0073ea`, 4px controls). Desktop captures are 1440×900 at 1x. Mobile captures are 390×844 at 2x. The product declares a dark theme. No signed-out page painted it.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export monday` prints them all with aliases resolved.

### Principles

1. Use the purple pill on marketing pages and the blue 4px button in the product.
2. Set product headings in Poppins at weight 300, and UI text in Figtree at weight 400.
3. Do not paint the declared dark theme as if a signed-out page showed it.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Headless Chromium (Playwright 1.49, from `~/.design-systems/pw`) opened the public URLs. No Cloudflare challenge appeared. Computed styles were read on the live pages at 1440×900. Custom properties were read from the CSSOM of each page and stored in [raw/css-vars.json](raw/css-vars.json). Element measurements are in [raw/components-computed.json](raw/components-computed.json).

The product token layer comes from `https://cdn.monday.com/build/login_monday-8806bd5209647dffbca6.css`, resolved on `:root` of the login page. Light semantic colours are those resolved values. Dark semantic colours are the declared `.dark-app-theme` block in the same sheet. That block was not applied to any page this pass reached.

Marketing colours that the product tokens do not name (the home pill `#6161ff`, nav text `rgb(83, 87, 104)`, the 160px pill radius) were read from computed styles on `a.m_button-primary` and `a.nav_link-full`.

Cookie banners were hidden in the DOM before screenshots. Accept and Reject were not clicked. The login email field was focused, then filled with a throwaway address and cleared. The filled frame was not kept. Nothing was submitted. Google and Microsoft buttons were not followed. The contact-sales form asks for a phone number, so that flow stopped at the empty form.

## What to distrust

The dark set is declared, not painted. The style-guide toggle applies it. It is not a screenshot of a dark monday.com page.

`--font-weight-bold` resolves to 500. The product uses that name for medium. Headings on the login page computed to 300.

The home hero's letter-spacing was `-2.24px` at 1440px. The same heading computed to `-1.68px` in a 1169px preview tab. It tracks the font size. The token records the 1440px reading.

Signup's `body` computed font was `Times` because the page's own font sits on an inner wrapper. The buttons on that page computed to Figtree. Trust the button reading.

Pricing's `html` did not set `data-brand`. The brand custom properties in the pricing sheet are declared. The painted pricing buttons computed to the same purple as the home pill.

Screenshots are 256-colour PNGs. Read colours from the tokens.

The icon in [icons/mark.svg](icons/mark.svg) is a reconstruction of the three-bar mark, not a trace of the logo file.

## Fonts

| Family | Where | Licence |
|---|---|---|
| Poppins | Marketing body and headings, product headings (`--h1-font-family`) | SIL Open Font License. The site serves its own woff2 files. The style guide loads a Google Fonts stand-in. |
| Figtree | Product UI (`--font-family`) on login and signup buttons and fields | SIL Open Font License. The login page loads it from Google Fonts. The sheet is cross-origin, so `@font-face` rules were not readable. The computed family was. |

| Arial, Roboto, Helvetica | Fallbacks in the computed stacks | System fonts. The tokens keep the first family plus Roboto or Arial. |

## Do and don't

1. **Use the purple pill on marketing pages and the blue 4px button in the product.** The home "Get Started" control is `#6161ff` with a 160px radius. The login "Next" control is `#0073ea` with a 4px radius. See [screenshots/home-light-default.png](screenshots/home-light-default.png) and [components/crops/button-primary-default.png](components/crops/button-primary-default.png).
2. **Set product headings in Poppins at weight 300, and UI text in Figtree at weight 400.** The login title computed to 300 32px/40px Poppins. The Next button computed to 400 18px/28px Figtree. See [screenshots/login-light-default.png](screenshots/login-light-default.png).
3. **Do not paint the declared dark theme as if a signed-out page showed it.** `.dark-app-theme` is in the login stylesheet. Every captured page is light. See [screenshots/signup-light-default.png](screenshots/signup-light-default.png).
