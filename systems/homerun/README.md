# Homerun design reference

A token set and component reference for Homerun's public marketing site, for building a hiring-product page in the same style. Captured from www.homerun.co on 2026-11-21, signed out, in headless Chromium at 1440 x 900 and 390 x 844. The site is Webflow. One light theme. The signed-in ATS and HR products were not entered.

The look is a white page, coffee-brown ink, one royal blue for the trial pill, and a near-black pill for Book a demo. Display type is GT Walsheim at 64px weight 900. UI type is GT America. Corners on buttons are 12px. The header is 90px at desktop and collapses to a hamburger sheet at 390.

## How the values were read

Custom properties were read from the live CSSOM on https://www.homerun.co/ at 1440 x 900. The v2 colour names (`--_updated-colors-v2---primary--*`) were resolved on `:root` and stored in [raw/css-vars.json](raw/css-vars.json). Component colours, type, radius and padding were read with `getComputedStyle` on the painted controls and stored in [raw/components-computed.json](raw/components-computed.json). Screenshots were taken with Playwright and quantised to 256 colours. Read colours from the tokens, not the PNGs.

## What to distrust

- Hover on the trial pill measured `#264ddb`. Declared blue-600 is `#254cda`. The token uses the measured hover.
- Focus on marketing links is the browser ring `rgb(0, 95, 204) auto 1px`, not a site token.
- The newsletter field radius is `30px 0px 0px 30px`. A single radius token was not written for that split.
- Hero illustrations are a public demo. They are not the signed-in product.
- Help centre search uses system-ui, not GT America.
- Login-wall type reports `GT-America` without quotes. Marketing pages report `"GT America"`.
- Pressed states on links were not captured.
- No duration was read. `--w-backdrop-animation` resolved to `initial`.

## Fonts

GT Walsheim (display, weight 900) and GT America (UI, weights 400, 500, 700) are proprietary. They are named in the tokens and not committed. The style guide falls back to the system sans. Help centre search uses system-ui.

## Do and don't

- **Do set display in GT Walsheim at 64/64 weight 900.** The hero is that one size on white. [heading-display-default](components/crops/heading-display-default.png)
- **Do use one blue for the trial pill.** `#4f75fe`, white label, 12px radius. [button-primary-default](components/crops/button-primary-default.png)
- **Do pair it with a coffee-black secondary pill.** Book a demo is `#2d2323`, not an outline. [button-secondary-default](components/crops/button-secondary-default.png)
- **Do wash nav hovers in beige.** Links do not turn blue. The wash is `rgba(245, 243, 239, 0.984)`. [nav-link-hover](components/crops/nav-link-hover.png)
- **Don't treat the hero collage as the product.** It is a public illustration. The app starts at the login wall. [login-light-wall](screenshots/login-light-wall.png)
- **Don't invent a dark theme or a pressed colour.** Neither was read.
