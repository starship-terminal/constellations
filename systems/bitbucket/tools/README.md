# How this package was captured

2026-11-22. Public pages only.

Headless Chromium (Playwright at `~/.design-systems/pw`) opened https://bitbucket.org/ and the header and footer destinations. Viewport 1440 by 900 and 390 by 844, device pixel ratio 2. Screenshots were quantised to 256 colours.

Login and signup redirect to id.atlassian.com URLs that carry session state. Those screenshots were discarded. Continue was not clicked. No identity provider was clicked. No form was submitted. No repository was created. The cookie banner was hidden with CSS and not accepted.

`catalog.json` was left alone, so `make design-md` and `make brief` were not run for this package.
