# Disney+

Public marketing design tokens from disneyplus.com, measured 2026-11-22. This file is a copy of the tokens in [tokens.json](tokens.json). It was not written by `make design-md`, because that command needs a catalog.json entry and this pass does not edit catalog.json.

## Type

Inspire is the UI face. It is named in the computed font on the homepage, the login wall, and the plan chooser. The file is not in this package.

The homepage heading is Inspire 40px, weight 700, line height 48px, letter spacing -0.16px.

Body text is Inspire 18px, weight 400, line height 25.2px, color `#c0c0c0`.

## Radius

LOG IN and DISNEY+ ANNUAL use a 1000px pill radius. LOG IN is 36px tall with a 2px `#6f717b` border. DISNEY+ ANNUAL is 48px tall with no shadow.
