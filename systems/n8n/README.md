# n8n

n8n is the workflow automation product at [n8n.io](https://n8n.io). This package records the public marketing site and the signed-out cloud login and register pages, measured on 2026-11-19.

No account was created. Register asks for a company email and was not submitted. Login asks for an instance name and was not submitted. The workflow editor was not opened. The T3 preview browser loaded the pages and computed styles. It did not produce screenshot frames, so this package has no page images.

## How the values were read

The T3 preview tab opened [https://n8n.io/](https://n8n.io/), [https://n8n.io/pricing/](https://n8n.io/pricing/), [https://app.n8n.cloud/login](https://app.n8n.cloud/login) and [https://app.n8n.cloud/register](https://app.n8n.cloud/register). None of them showed a Cloudflare challenge. `preview_evaluate` ran `getComputedStyle` and read resolved custom properties. `preview_snapshot` failed twice with `The browser is not producing screenshot frames.`

The marketing site resolves a `--color-*`, `--radius-*`, `--spacing-*` and `--text-*` set on `:root`. The homepage body is rgb(250, 250, 250) on rgb(22, 22, 22), family `n8n Baumer Uniwidth`. Buttons use `n8n Baumer Mono`, uppercase, 14px, tracking 0.28px. The primary fill is rgb(255, 188, 202), which is `--color-surface-button-primary-default` (`#ffbcca`). The live h1 at 1169px is 64px, not the 80px `--text-heading-3xl` token: the element also has `lg:text-[64px]`.

The console is a different system. Login and register use Geist on a dark page, oklch(0.2046 0 89.88), with pink pills at oklch(0.7807 0.136 5.02). Those match the console custom properties `--color--background--shade-2` and `--background--brand`. The console stylesheet also declares editor, canvas and node variables. Those are in [raw/login-vars.json](raw/login-vars.json) only where they are colour, type, radius, spacing, shadow or motion. The editor itself was not opened, so those variables are stylesheet evidence, not a signed-in screen.

A CookieScript banner covered the homepage. Its buttons and switches were measured, then Decline all was clicked. It is a vendor overlay. Its Inter type and blue switch are not n8n tokens.

Register validation was triggered with the string `not-an-email`. Continue painted `Value needs to be an email address` and a red inset ring. The field was cleared. No email address was submitted.

## What to distrust

There are no screenshots. Do not treat a missing image as a dark or light theme you have seen. The marketing site was light. The console pages were dark. No theme toggle was used, and no second theme was forced.

The marketing h1 size is the computed 64px at 1169px. The token `--text-heading-3xl` is 80px and was not what the h1 painted.

Console hover on Continue did not change the fill. The declared marketing hover colours were not held on a button. Disabled, pressed and loading were not on screen.

Login field focus did not paint a new ring. The register field's rest ring is stronger than the login field's rest ring. They are the same class with different computed shadows.

`documentElement.colorScheme` on the console computed `light` while the page was painted dark, and `data-theme` was null. The dark reading is the computed body background, not a theme attribute.

Console colours in the tokens are sRGB hex derived from the computed oklch values, so the catalog contrast check can read them. The oklch spelling is in each token's source. The page fill `#171717` comes from oklch(0.2046 0 89.88). The button fill `#ff91ac` comes from oklch(0.7807 0.136 5.02).

CookieScript colours are not the product. The blue switch rgb(7, 122, 199) is close to the marketing score-good token and is still the vendor widget.

Phone width was not measured. Nav links at 1169px were `display: none`. That is this viewport, not proof that n8n has no desktop nav.

## Fonts

Marketing text uses `n8n Baumer Uniwidth`, with Helvetica, system-ui, -apple-system and sans-serif as fallbacks. Marketing buttons and nav labels use `n8n Baumer Mono`, with ui-monospace and SF Mono. Both are n8n's own faces. They are not loaded by this package.

The console uses Geist, with -apple-system, system-ui, Segoe UI and Roboto. Geist Mono is declared and was not measured on a visible element. The console ships Geist and Geist Mono as variable woff2, plus Inter Variable and Geomanist. Inter was the computed family on the CookieScript banner, not on n8n's own text. Geomanist was declared and not the resolved family on the elements that were read.

The tokens fall back to the system faces named above. They do not embed the proprietary files.

## Do and don't

- **Use the pink pill for the main marketing action.** `GET STARTED` and `START FREE TRIAL` are rgb(255, 188, 202) with rgb(33, 33, 33) type in n8n Baumer Mono, uppercase. The secondary action is the grey pill.
- **Keep marketing type on n8n Baumer Uniwidth and actions on n8n Baumer Mono.** Body is 16px. The homepage h1 at this width is 64px, weight 500, with negative tracking.
- **Use Geist and the dark page for the signed-out console.** Login and register are oklch(0.2046 0 89.88), with a pink pill button and a 4px field.
- **Do not invent a screenshot.** The 2026-11-19 preview pass did not paint frames. The 2026-11-22 frames are in [screenshots/](screenshots/). Token values still come from the readings.
- **Do not enter a workflow from this package.** Login wants an instance name. Register wants an email. Neither was submitted, and the editor was not opened.
- **Do not copy the cookie banner into the product.** CookieScript uses Inter and a blue switch. n8n's own pages do not.
