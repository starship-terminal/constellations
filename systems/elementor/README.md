# Elementor design reference

A token set and component reference for Elementor's public signed-out surface — for building marketing pages in the style of the real thing. It was read from **elementor.com** on **2026-11-13**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: home, the website-builder product page, pricing, the enterprise solutions page, about, contact (with its popup form opened) and FAQ (with an accordion item opened), plus 390px passes on home and pricing.

Elementor is worth a capture because the world's biggest WordPress site builder eats its own cooking: elementor.com is itself an Elementor site, so the styles read off it are the company's shipped marketing system — Roobert at an 88px display down to 14px lists, a strict Kernel-Black / Blank-Canvas-White axis where nothing coloured rests (every action is black until hover, when it rebounds to Neon-Loop `#ed01ee`), a Syntax-Glow `#fae4fa` tint behind hovered rows, a floating 24px-radius pill header under one soft shadow, and a radius ladder of 4px fields, 8px controls and cards, 16px tiles, 24px chrome. The page paints light but carries `.dark-mode` islands — the photo hero, dark sections and the footer — under which the same named vars re-bind to their opposites, so "dark" here is a surface treatment, not a theme. **Boundary:** the Elementor editor itself is a WordPress admin plugin and lives behind auth at my.elementor.com; nothing signed-in, submitted or purchased was ever reached.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export elementor` prints them all with aliases resolved.

### Principles

1. Do keep it black and white at rest.
2. Do spend the pink on hover, not at rest.
3. Do tint hovered rows with Syntax-Glow.
4. Do outline secondary CTAs in 2px black.
5. Do pill the chrome, square the controls.
6. Do paint dark islands with the same vars.
7. Do ring focus in #005fcc.
8. Do track the display tight.
9. Don't style the editor from this package.
10. Don't reach for the kit accent.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out site in headless Chromium:

- **Tokens.** elementor.com's design system lives in its own stylesheets (`uploads/elementor/css/*.css`, plugin widget CSS, inline `<style>` blocks and the `--e-global-*` kit vars). [tools/capture/vars.mjs](tools/capture/vars.mjs) reads every stylesheet body from network responses plus the CSSOM re-parsed with `CSSStyleSheet`, writes every custom property to [raw/css-vars.json](raw/css-vars.json), and resolves each in a probe document twice — plain (`:root`, the light reading) and inside `<body class="dark-mode">`, the re-binding the dark islands paint. Everything else — the measured component geometry, the field borders, the focus ring, motion — is computed values from [raw/components-computed.json](raw/components-computed.json). [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec, [tools/build_tokens.py](tools/build_tokens.py) the sets.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route (/, /pricing/, /contact/, /faq/ and a 390px home pass) in a fresh context and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state; text fields were focused and sample-filled then deleted, the FAQ accordion and mega-menu were opened by their own toggles, and the contact popup by its card. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md). The script guards the edge: a route that comes back with a bot-check or empty body is marked BLOCKED and its earlier readings are kept instead of erased.
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route with `.capture.json` sidecars, including the local UI toggles: the Products mega-menu on home, the scrolled plan grid on pricing, the popup form on contact, an open accordion row on FAQ and the mobile menu. Full-page shots are capped at eight chunks; pages taller than that stitch from parts (home, builder and both mobile pages needed two). [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.

Nothing was signed into, created, submitted or paid for: Log in and Get started point at my.elementor.com and were measured, never followed; Buy now would open checkout and was never pressed; the contact form's submit was measured, never pressed; the checkbox was toggled as local UI state only. The Cookiebot consent dialog was hidden with CSS per capture — its buttons were never pressed, so no consent was ever posted. The Angie AI-assistant widget (`#elementor-angie-root`) and the promo popup were closed or hidden, never interacted with.

## What to distrust

- **This is the marketing surface, not the product.** The Elementor editor is a WordPress admin plugin reached through my.elementor.com sign-in — uncaptured. `/products/website-builder/` describes the product; nothing here verifies how the editor itself is styled. Treat the product's own design system as unknown.
- **"Dark" is a painted island, not a toggle.** The photo hero, the dark card sections and the footer carry `class="dark-mode"`, under which `.dark-mode *` re-binds `--Kernel-Black` to `#fff`, `--Blank-Canvas-White` to `#000` and `--Grey-800` to `--Grey-200`. Nothing on the public surface switches it — the `dark` token set is that re-binding read as roles.
- **The `--e-global-color-*` kit palette is generic.** `primary #000000`, `secondary #54595F`, `text #7A7A7A`, `accent #61CE70` are Elementor's default kit declarations — the real action colour the site paints is Neon-Loop from the named var layer, not the kit accent. Don't reach for `#61CE70` for an action.
- **Unstyled containers read fallback fonts.** Some wrappers compute `Times 16px`; the text nodes inside carry Roobert. Type tokens cite the text-node readings, not the wrapper's.
- **Resting anchors read `#0000ee`.** Undecorated `a` elements compute the UA link colour at rest and `#ff0000` under forced `:active`; the styled text nodes inside them are the truthful colours.
- **Photography is content.** The hero media and product renders are Elementor's artwork and only appear inside screenshots and crops; carousels keep moving, so two captures of the same view can differ.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs; read exact colours from tokens or the raw files.
- **Automation was masked during capture.** Until 2026-11-20, `tools/capture/public/lib.mjs` hid `navigator.webdriver` in every page it opened, so every committed reading was taken with that mask. The mask is removed (a bot check is now recorded as a boundary, not bypassed); whether any page needed it to load is not known, and a recapture without it is the check.

## Fonts

One family does everything the styled surface paints: **Roobert**, self-hosted under `wp-content/fonts` and referenced as `--Roobert` — 600 display and headings (88/96.8 hero, 72/79.2 FAQ title, 24/31.2 section, 20/32 plan names), 500 buttons and titles (18/25.2 actions with -0.36px tracking), 700 small headings, 400 body and fields. It is licensed and not distributed with the package — the tokens carry the fallback stack (`'Roobert', system-ui, -apple-system, 'Segoe UI', Arial, sans-serif`) and the style guide falls back to system sans. **Roboto** loads from Google Fonts for the editor-side chrome; it barely paints on the public pages.

## Coverage

- **Pages:** `/`, `/products/website-builder/`, `/pricing/`, `/solutions/enterprise/`, `/about/`, `/contact/`, `/faq/` at 1440 x 900; `/` and `/pricing/` at 390 x 844.
- **States:** default, hover, focus-visible and pressed on every interactive component (100 states over 45 components); opened states on the mega-menu, the contact popup, an FAQ row and the mobile menu; focused/filled on the name field; selected on the checkbox.
- **Not captured:** everything behind my.elementor.com (the editor, hosting dashboard, account, billing), checkout (Buy now never pressed), every signup/Login target, the Cookiebot consent response (hidden, never answered), the Angie chat widget and promo popups (closed or hidden), disabled/error/loading states (none exist on the public surface).

## Do and don't

1. **Do keep it black and white at rest.** Text, fills, borders and actions all sit on the Kernel-Black / Blank-Canvas-White axis; no brand colour rests on the page. See [header](components/crops/header-default.png) and [card](components/crops/card-default.png).
2. **Do spend the pink on hover, not at rest.** Neon-Loop `#ed01ee` is the hover and pressed fill of every primary action and the focus fill of all but the form submit, which keeps black under the ring — never a resting colour or a text colour. See [nav-cta](components/crops/nav-cta-hover.png) and [submit-btn](components/crops/submit-btn-hover.png).
3. **Do tint hovered rows with Syntax-Glow.** Menu links and nav triggers take `#fae4fa`, not a grey wash — a desktop pattern; the measured mobile menu row stays white on hover, only its chevron glyph darkening. See [menu-link](components/crops/menu-link-hover.png) and [nav-trigger](components/crops/nav-trigger-hover.png).
4. **Do outline secondary CTAs in 2px black.** Buy now draws a 2px Kernel-Black ring on transparent and floods Neon-Loop with white text on hover. See [plan-cta](components/crops/plan-cta-default.png) and [plan-cta](components/crops/plan-cta-hover.png).
5. **Do pill the chrome, square the controls.** The header and mega-menu float at a 24px radius; buttons and plan cards take 8px; fields take 4px; cards 16px. See [header](components/crops/header-default.png), [field-name](components/crops/field-name-default.png) and [plan-card](components/crops/plan-card-default.png).
6. **Do paint dark islands with the same vars.** `.dark-mode` re-binds Kernel-Black to #fff and Blank-Canvas-White to #000, so the hero's Get-started pill inverts to white on black — one component, two bindings. See [hero-cta](components/crops/hero-cta-default.png) and [footer](components/crops/footer-default.png).
7. **Do ring focus in #005fcc.** Keyboard focus draws a 2px auto `#005fcc` outline offset 2px on every control it could be landed on (16 of 17 attempted — the mobile item's ring lands on its child dropdown button; the nav trigger never took focus) — the one blue in the system. See [nav-cta](components/crops/nav-cta-focus-visible.png).
8. **Do track the display tight.** Display and headings run negative letter-spacing (-0.88px at 88px, -0.72px at 72px, -0.36px on 18px buttons). See [hero-title](components/crops/hero-title-default.png).
9. **Don't style the editor from this package.** Every value is the public marketing surface's; the builder, hosting dashboard and account are behind auth and uncaptured. See [home](screenshots/home-light-default.png).
10. **Don't reach for the kit accent.** `--e-global-color-accent` `#61CE70` is a default declaration, not a colour the site paints on actions; actions rest black and hover Neon-Loop. See [cta-dark](components/crops/cta-dark-hover.png).

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/elementor/`):

```sh
python3 tools/build_component_tokens.py        # raw/components-computed.json -> raw/component-tokens.json
python3 tools/build_tokens.py                  # -> tokens.json
python3 tools/build_style_guide.py             # -> style-guide.html
python3 tools/build_components_md.py           # -> components.md
node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir>    # full-colour PNGs -> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.

Live recapture (needs the site; Playwright at `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs`):

```sh
node tools/capture/vars.mjs                    # stylesheet harvest -> raw/css-vars.json
node tools/capture/public/measure.mjs          # computed styles + crops -> raw/components-computed.json
RAW=<scratch> node tools/capture/public/public.mjs   # screenshots -> <scratch> (incl. the menu/popup/accordion toggles)
```

elementor.com loads headless from this client; an occasional edge check or empty body is marked BLOCKED by the measure script, which keeps that route's earlier readings rather than erasing them. The Cookiebot dialog is hidden per capture, never answered, and the Angie widget is hidden.
