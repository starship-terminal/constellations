Fiverr, measured

fiverr.com is a React app styled with atomic hashed classes: its served sheets declare ~1,290 custom properties on :root, all named by content hash — a token-free layer with no semantic names to alias, so every value on this page is a computed style measured on the live public pages, not a var alias. Macan (self-hosted woff2, weights 400/600/700) carries the type; the dark ink fill drives Join, the hero search submit and the gig Continue, while the brand green (#1dbf73) survives as the accent — the category-nav hover underline. The real pixels are in screenshots/ and components/crops/.

Read from fiverr.com, signed out, in Chromium. The buyer/seller account, checkout and inbox are a documented boundary; the join, login and search fields were measured and typed into then cleared, never submitted. One light theme is painted — the hero's dark band is a component skin, not a site theme. Macan is a served face and is not loaded here: samples fall back to system sans.
