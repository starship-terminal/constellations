Fiverr, measured

fiverr.com is a React app styled with atomic hashed classes and declares no :root custom properties — every value on this page is a computed style measured on the live public pages, not a var alias. Macan (self-hosted woff2, weights 400/600/700) carries the type; the brand green (#1dbf73 family) drives Join, the hero search submit and the gig Continue. The real pixels are in screenshots/ and components/crops/.
