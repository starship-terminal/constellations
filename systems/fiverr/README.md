# Fiverr design reference

A partial capture of Fiverr's public site, stopped at a human-check and an auth wall. It was read from **www.fiverr.com** on **2026-11-21**, signed out, in Playwright Chromium. The homepage painted once (HTTP 200) and its DOM text was recorded. The login page painted once at 1440x900. Every later load painted a PerimeterX "It needs a human touch" page before the site. That check was not solved. No account was created, no form was submitted, and no SSO button was clicked.

Unread token values are Not captured. The four colours in [tokens.json](tokens.json) are sampled from the login screenshot. There is no dark theme in this package because none was observed.

## How the values were read

The first homepage load returned HTTP 200. Its visible text and a slice of header links were read from the DOM. The viewport file for that load was overwritten by a later human-check screenshot of the same path before it was copied here. It is not in the package and was not redrawn.

[screenshots/login-light-default.png](screenshots/login-light-default.png) is the login page as Playwright painted it at a requested 1440x900. `window.innerWidth` was not read. Four flat fills were sampled from that PNG before any quantize step: page white `#ffffff`, Join button `#222325`, wordmark green `#1dbf73`, left panel `#76293b`. No stylesheet walk ran. No custom properties were collected.

A second homepage load, a headed retry, and a second login load returned HTTP 403 and the title "It needs a human touch". The page asked for a press-and-hold. It was not solved. That page showed a client IP and a trace id. Those strings are not in this package, and the challenge screenshot is not in this package.

## What to distrust

- **Most of the site was not opened.** Category pages, search results, menus, filters, the footer, and phone width were not captured. [site-tree.md](site-tree.md) lists the links that were read and the controls that were not clicked.
- **The homepage has no screenshot here.** Do not treat the login page as the homepage.
- **Sampled colours are pixels, not tokens.** The wordmark green and the Join fill are flat samples. They are not proof of a named design token.
- **Muted text, borders, type, spacing, radii, and motion are Not captured.** Do not fill them from memory of Fiverr.
- **No signed-in UI.** `signed_in` is false. Orders, inbox, seller tools, and onboarding were not reached.
- **The screenshot is not quantised.** It is the raw login capture. Do not sample new colours from a later 256-colour copy. There is no 256-colour copy.

## Fonts

The font family is Not captured. Stylesheets and `document.fonts` were not read. The style guide uses the system sans as a stand-in, not as a measured family.

## Do and don't

- **Do treat the login page as an auth wall.** [login-light-default.png](screenshots/login-light-default.png) is where the walk stopped.
- **Do leave unread roles as Not captured.** [tokens.json](tokens.json) already does this for muted, border, and type.
- **Don't invent the homepage from the login screenshot.** The homepage DOM read is in [site-tree.md](site-tree.md), and it has no image in this package.
- **Don't design a signed-in Fiverr from this package.** The app was not captured.
- **Don't solve or describe a bypass for the human-check.** The capture stopped there.
