# B150 design reference

A token set and component reference for B150's public marketing site — for building Gen-AI-community marketing surfaces in the style of the real thing. It was read from **b150.ai** on **2026-11-11**, signed out, in **headless Chrome** at 1440 x 900 and 390 x 844, covering the home page, `/vibeathon`, `/talent`, `/free-resources`, `/about`, `/contact`, and the home and talent pages at phone width.

B150 is worth a capture because it is a clean example of *the Tailwind-era indie-marketing look*: warm-cream ink #fffdf6 on near-black chrome, white pill CTAs (SIGN UP, JOIN THE BETA) whose corners are literally `calc(infinity * 1px)`, mono uppercase labels at 10px (Fragment Mono) under 120px display titles, and a declared `@layer theme` token layer (66 vars: --color-*, --text-*, --radius-*, --spacing, --ease-*) that this export resolves where it can and measures where it can't. The authenticated product lives on app.b150.ai and rate-limits non-browser clients, so this package covers the public signed-out surface only.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export b150` prints them all with aliases resolved.

### Principles

1. Do keep the chrome near-black and the ink warm.
2. Do pill the calls to action.
3. Do label in mono.
4. Do let the display size carry hierarchy.
5. Do answer hover with a tone shift.
6. Don't ship a second theme.
7. Don't invent a spacing scale.
8. Don't round fields like pills.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out site in headless Chrome:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) captured every stylesheet body from the network responses plus inline `<style>` blocks and wrote every custom property to [raw/css-vars.json](raw/css-vars.json) binned `generated`/`app`/`vendor`/`utility`/`tailwind` — the 66-name `app` bin is the site's `@layer theme` block (`--color-*`, `--font-*`, `--text-*`, `--radius-*`, `--container-*`, `--spacing`, `--ease-*`). [tools/build_component_tokens.py](tools/build_component_tokens.py) writes each leaf as a declared var (`var`) where the site declares one and as a *measured* value where it does not — the pill radius, the focus ring, the component dimensions. [tools/build_tokens.py](tools/build_tokens.py) emits the sets.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context, hides any consent or promo layer (never answered), and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state, plus `opened` on the mobile menu. Selectors key off text and the few semantic classes (`.label`, `.vibeathon-link`, `text-ink`). Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md).
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route — the arrival view is captured first, before anything is hidden — with `.capture.json` sidecars recording measured viewport/dpr; [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.

Nothing was joined, submitted, voted on, searched or signed into. The public marketing pages were enough.

## What to distrust

- **Readings past a masked bot signal.** The committed screenshots and readings were taken with `navigator.webdriver` masked, the flag bot checks read to spot automation. The capture scripts no longer mask it (not run since), so a recapture may record a walled route as a boundary instead of a reading.
- **Var-backed plus measured.** The declared `@layer theme` tokens resolve through their names; leaves with a `computed …` source are measurements where nothing declares the value (`component.*`, the pill radius, the focus ring). The accents are declared but rarely painted on the public surface — the chrome stays cream-on-ink.
- **One painted theme.** A `dark` probe resolves every var identically; the site mixes dark chrome (near-black header/footer, cream ink) with warm-cream inner surfaces. `tokens.json` ships no dark set.
- **Roles are verified, not declared.** Every `light` role pairs a measured colour with the component that was measured wearing it; `light.surface.page` was verified on the footer (#000), so name and fill describe that component.
- **The radius is literally infinite.** Tailwind `rounded-full` computes to `calc(infinity * 1px)` — recorded as `3.35544e+07px` in `core.radius.pill`/`cta`. Treat it as "fully round", not a step on a scale.
- **app.b150.ai is a documented boundary, not a gap.** LOGIN and SIGN UP link off-site; the app returned HTTP 429 to the recon probe, so the authenticated product was never reached. The header links are measured, never followed.
- **/legal and /support render but were not captured** — both return 200; they were out of the page set.
- **Card components are structural.** With utility classes only, `talent-card`/`vibe-card`/`res-card` match the first card-ish container; they are representative measurements, not a lifted component API.
- **Focus styles were not systematically captured** beyond focus-visible states on the measured components.
- **`vibe-card` was read from the wrong element.** It is the whole 1440 x 920 vibeathon section, not a card in it. Needs a recapture.

## Fonts

**Fragment Mono** carries the chrome: nav links, buttons, footer links at 10px uppercase. **Geist Variable** carries body and display copy — the 120px hero and page titles are set in it. Both are loaded by the site (Next.js font optimization); the sheets declare no `@font-face` family of their own worth lifting, and no licence is stated on-site.

## Do and don't

1. **Do keep the chrome near-black and the ink warm.** Cream #fffdf6 type on near-black surfaces; inner pages flip to warm-cream grounds — never a cold grey. See [home-light-default](screenshots/home-light-default.png).
2. **Do pill the calls to action.** SIGN UP and JOIN THE BETA are white/cream fully-round pills — radius is infinity, not a token step. See [signup-btn-default](components/crops/signup-btn-default.png).
3. **Do label in mono.** Nav, buttons and footer links run Fragment Mono at 10px uppercase. See [nav-item-default](components/crops/nav-item-default.png).
4. **Do let the display size carry hierarchy.** Hero and page titles hit ~120px; hierarchy is size plus the mono/sans pairing, not colour or weight ramps. See [hero-default](components/crops/hero-default.png).
5. **Do answer hover with a tone shift.** Links fade and pills shift to #f2efe9/#e6e3dd — subtle, never scale or shadow. See [hero-cta-hover](components/crops/hero-cta-hover.png).
6. **Don't ship a second theme.** One painted theme; the dark chrome is the chrome, not a dark mode.
7. **Don't invent a spacing scale.** Spacing is composed in Tailwind utilities; the package records measured boxes only.
8. **Don't round fields like pills.** Inputs and cards sit at 8px; the infinite radius belongs to the pills alone. See [contact-input-default](components/crops/contact-input-default.png).
