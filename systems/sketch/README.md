### Principles

1. Use the black pill for the primary action.
2. Set display type in the serif, body type in Inter.
3. Keep the marketing site light.
4. Leave payment and license forms out.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Marketing colours, type and geometry were read with `getComputedStyle` on the live page in the T3 preview tab at 1440x900, device pixel ratio 2. Declared rules were read from `styles.prism.6d59b49a43.css` and `home.9c6e9f6198.css`. Sign-in colours were read the same way on `https://www.sketch.com/signin/`, from the injected styled-components sheet. Screenshots of the public pages were taken with headless Playwright after those pages loaded without a Cloudflare challenge. The preview browser returned "The browser is not producing screenshot frames", so it was not used for images.

## What to distrust

The marketing body computed line-height is 16px. The body token uses the declared paragraph line-height of 24px, and the source says so. The primary button's computed radius is 24px. The stylesheet says 1rem. The token uses the computed value. Account dark is the sign-in shell, not a dark theme of the marketing site. The marketing page stayed light while the OS colour scheme was dark. Reckless and Inter Variable are not in the package. The style guide uses Georgia and Inter. The pricing ribbon element's computed colour was `#212123` on a `#212123` background. The screenshot shows light text, so that computed colour is not used as the ribbon's text token.

## Fonts

Reckless Medium and SemiBold are self-hosted at `/webfonts/reckless/` and are proprietary. Marfa is the older body face and is also proprietary. Inter Variable is loaded from `rsms.me` on the marketing site. The account shell loads Inter from Google Fonts. Tokens name Inter and a serif fallback. The font files are not committed.

## Do and don't

- **Use the black pill for the primary action.** The home and nav CTAs are `#151515` with white type and a 24px radius. [components/crops/button-primary-default.png](components/crops/button-primary-default.png)
- **Set display type in the serif, body type in Inter.** Hero and plan names are Reckless at weight 500. UI text is Inter. [screenshots/home-light-default.png](screenshots/home-light-default.png)
- **Keep the marketing site light.** A dark colour scheme did not flip the public pages. Dark values belong to the account shell. [screenshots/pricing-light-default.png](screenshots/pricing-light-default.png)
- **Leave payment and license forms out.** Those flows were not opened. [patterns.md](patterns.md)
