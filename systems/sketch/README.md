# Sketch design reference

A token set and component reference for Sketch's public marketing site (https://www.sketch.com/). Captured signed out, in headless Chromium, on 2026-11-21. Desktop 1440×900 at 1x. Phone 390×844 at 2x. One light theme. The Mac app, the web workspace and the iOS app sit behind [the sign-in wall](https://www.sketch.com/signin/) and were not entered. No email was typed. No password was submitted. Apple, Google and SSO were not clicked.

The site is a marketing surface: Reckless display type at 76px, InterVariable for UI, a near-black pill button (`#151515`) on a `#f5f5f5` page, 24px control radii, and an indigo link colour (`#575fff`) that shows up on the auth wall rather than on the marketing CTAs.

This package contains no Sketch code, and none of its artwork has been redrawn. The screenshots belong to Sketch B.V. ([docs/RIGHTS.md](../../docs/RIGHTS.md)).

## How the values were read

- Custom properties were read by [tools/capture/vars.mjs](tools/capture/vars.mjs) from the homepage stylesheets. The site declares `--rotationAmount` and `--swiper-theme-color` (`#007aff`, Swiper's default). Those are not design roles. Colour and type were read from computed styles instead.
- Components were measured by [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs): `getComputedStyle` on the live element, plus hover, focus, and a CDP-forced `:active` where the control allowed it. Crops are in [components/crops/](components/crops).
- Screenshots were taken by [tools/capture/public/public.mjs](tools/capture/public/public.mjs) and quantised by [tools/capture/quantize.py](tools/capture/quantize.py). Viewport sidecars record `innerWidth` 1440 and 390. See [raw/capture/home-light-default.png.capture.json](raw/capture/home-light-default.png.capture.json).
- Cookie overlays were hidden if present. None needed a click. No form was submitted.

## What to distrust

- **The product UI is not here.** The canvas in the homepage hero is a public demo image. The Mac app, web app and iOS app were not opened.
- **Auth and marketing are different type stacks.** Marketing uses InterVariable and Reckless. The sign-in page uses Inter at 14px and a 6px radius. Do not treat the auth field as the marketing field.
- **The indigo is a link colour, not the CTA.** Marketing buttons are `#151515`. `#575fff` is the Create an account link and the disabled Sign In wash.
- **Pressed does not change the fill.** CDP `:active` scaled the primary button. The colour stayed `#151515`.
- **Focus ring was not readable.** focus-visible did not change the computed outline on the controls that were measured.
- **Screenshots are 256-colour PNGs.** Read colours from tokens.json.
- **DESIGN.md and Brief are stubs.** They were not generated by `make design-md`, because catalog.json was not edited.

## Fonts

- **Reckless** (display, 76px, weight 500 on the homepage, 900 on the docs title). Proprietary. Not committed. The tokens name the family. The style guide falls back to a serif.
- **InterVariable / Inter** (UI). The marketing stack is InterVariable, Inter, system-ui, Helvetica Neue, Helvetica, Arial. The auth stack is Inter, system-ui, Segoe UI, Roboto, Helvetica, Arial.
- Also loaded on the homepage, and not used as tokens: Marfa, Marfa Mono, Meshed Display, Caveat. They were not the computed family of the measured roles.

## Do and don't

- **Do keep the page warm-grey and the CTA near-black.** Page `#f5f5f5`, button `#151515`, label white. ([button-primary](components/crops/button-primary-default.png))
- **Do set display in Reckless and UI in InterVariable.** The homepage title is 76px / 500 / -1.5px tracking. ([hero-title](components/crops/hero-title-default.png))
- **Do use a 24px pill for marketing buttons and a 6px radius on the auth form.** They are different surfaces. ([email-field](components/crops/email-field-default.png))
- **Do mute nav hovers by fading the ink to 48% black.** The fill does not change. ([nav-link](components/crops/nav-link-hover.png))
- **Don't treat the homepage canvas as the app.** It is a public demo. The workspace is behind sign-in.
- **Don't use the indigo as a marketing button.** `#575fff` is the auth link and the disabled Sign In wash. ([create-account](components/crops/create-account-default.png))

## Rebuild

```bash
cd systems/sketch
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/public/map-site.mjs
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/vars.mjs
RAW=~/.design-systems/sketch/raw-shots PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/public/public.mjs
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs node tools/capture/public/measure.mjs
python3 tools/capture/quantize.py ~/.design-systems/sketch/raw-shots
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/build_components_md.py
```

`make brief`, `make design-md` and `make grade` need a catalog.json entry. This capture was told not to add one.
