Palette

The core set carries the measured ink/white neutrals and the purple ramp (measured off the actions, var-referenced where a StyleX variable resolves the same value); the declared status hues come from the hashed StyleX layer. Light roles alias the palette; the "dark" set is the translucent-white state set the .theme.dark band paints — a painted surface, not a user toggle.

Spacing and radius

Tabs and the billing switch are 9999px pills; buttons, links, fields and cards take 12px; header controls 10px; the hero CTA 20px; comparison rows 14px; plan cards 16px and the mega-menu column 32px on its left corners. Borders are rare — secondary actions draw a 1px inset hairline as box-shadow instead.
