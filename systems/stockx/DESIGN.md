## Typography

Suisse Intl is the UI face. Gestura Reg is the How It Works display face. The shop title is 24px Suisse Intl 500. Section headings are 18px, weight 500. Body is 16px. Sign Up is 14px, weight 600. Footer links are 12px. How It Works is 60px Gestura Reg 400, line-height 64.98px, letter-spacing -0.64px.

## Geometry

The header is 91px. The category bar is 48px. The logo SVG is 125px wide. Search is 42px tall, radius 8px. Sign Up is 36px, radius 100px, padding 8px 16px. Buy Now is 44px, radius 100px, padding 10px 32px. Size is 40px, radius 8px.

## Components

Sign Up | Login is a white pill with `#0F0F0F` text. Buy Now is a green pill, `#95C0A4`, with the same dark text. Sell Now is a text button in the brand green. Search and Size are dark fields with a `#5F5F5F` border and an 8px radius. Product cards put a white image well on the `#121212` page.
