# Resend

Resend (resend.com) is an email platform for developers. This package records the public marketing site and the signed-out login and signup chrome, measured on 2026-11-19 from a live T3 preview tab. The signup form was filled with an email and a password, then cleared. It was not submitted. Google and GitHub were not followed. No API key was created. No card was entered.

The live CSS viewport was 1169 by 731 at devicePixelRatio 2. Marketing pages ship with `html` class `dark` and `color-scheme: dark`. Docs at https://resend.com/docs/introduction also have a light theme, measured after clicking "Switch to light theme", then restored to dark.

## How the values were read

Custom properties were read from the stylesheets on https://resend.com/ and from `getComputedStyle(document.documentElement)`. Component colour, type, radius, padding and size were read with `getComputedStyle` on the live elements. Display-p3 and oklab colours were converted to hex by filling a 1 by 1 canvas in that same page when the result was opaque. Docs light values were read after clicking the docs button labelled "Switch to light theme". Dark was restored afterwards.

The preview browser returned "The browser is not producing screenshot frames" on `preview_snapshot`, twice. No screenshots were invented. Headless Playwright was not launched against the login page.

## What to distrust

The CSS viewport was 1169, not 1440 and not 390. Do not treat these readings as a 1440 or 390 capture. Docs light was measured and is recorded in raw/foundations.json and components.md. It is not a token set, because the catalog export prefers a light set over the marketing theme, and marketing pages have no light theme. The primary button's computed background is transparent. Its visible face is a `linear-gradient(104deg, rgba(253, 253, 253, 0.05) 5%, rgba(240, 240, 228, 0.1) 100%)` over a 2px `white/5` border. The accent token is the declared `--bg-accent` (`#ffffff`), which is the named accent, not that gradient. Field and button borders are `oklab` white at 5 percent. Canvas hex of that border on black is `#0d0d0d`. The token stores the nearest opaque gray step, `--gray-4` (`#293034`), and the oklab string stays in [components.md](components.md). Disabled submit text is the same oklab white at 50 percent, painted `#808080`, with opacity 0.3. Screenshot folders are empty on purpose.

## Fonts

Inter Website is the marketing UI face (`--font-sans`). aBCFavorit is the section display (`--font-display`). Domaine is the hero face, read from the home `h1` (`font-domaine`). Commit Mono Website is the code face (`--font-mono`). Auth pages compute `appInter`, a local name for the same Inter variable. Docs body is Inter. These families are named as computed. The font files are not in this package. Tokens keep the measured stacks and fall back to ui-sans-serif and ui-monospace.

## Do and don't

- **Use the black marketing page.** Home, pricing, brand, login and signup render on `#000000` with `#f0f0f0` text and `#a1a4a5` secondary text. [patterns.md](patterns.md) describes that shell.
- **Use 16px radius glass buttons for the primary action.** "Get started" is white text on a translucent white gradient, 2px white-at-5-percent border, 40px in the header and 48px in the hero. [components.md](components.md) lists the sizes.
- **Keep signup as a signed-out form.** https://resend.com/signup asks for email and password, plus Google and GitHub. Do not invent a signed-in dashboard or an API key behind it. [components.md](components.md) records the gap.
- **Use Domaine for the hero, aBCFavorit for sections, Inter for UI.** The three faces do not collapse into one stack. [tokens.json](tokens.json) keeps all three.
- **Do not invent a 1440 screenshot.** The preview browser produced no frames. [screenshots/](screenshots/) says so.

## Rebuild

```bash
python3 tools/build_tokens.py
python3 ../../tools/catalog.py design-md resend
```

`tools/build_tokens.py` writes [tokens.json](tokens.json) from [raw/foundations.json](raw/foundations.json). DESIGN.md is generated by the repo catalog tool. Do not edit DESIGN.md by hand.
