# Resend design reference

A token set and component reference for Resend's public site, for building a dark marketing page or a docs page in this style. It was read from **resend.com** on **2026-11-21**, signed out, in headless Playwright at 1440 x 900 and 390 x 844. The marketing site paints dark. The docs paint light by default and dark after "Switch to dark theme".

Login and signup were recorded and not entered. Nothing was typed. Google and GitHub were not clicked. No form was submitted.

### Principles

1. Keep the page black and the headline in domaine.
2. Use one white pill for the primary action.
3. Open desktop menus on hover.
4. Keep docs in its own theme.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Playwright opened the public pages and read the CSSOM. Custom properties were resolved on `html` for the home page (dark) and for the docs in light and dark. Component colours, sizes, and radii were read with `getComputedStyle` on the live elements. Hover was a real pointer. Focus-visible and pressed on the header button were forced with CDP pseudo states so the link could not navigate. Screenshots were quantised to 256 colours after the values were read.

## What to distrust

- The header Get started control's computed `background-color` is transparent. The painted fill is a white gradient the background colour does not report. The hover fill does compute to near-white.
- `light.accent` is the docs link colour (`--twoslash-tag-color`). The docs primary button fill was not computed.
- `light.page` computed to transparent. The painted docs page colour was not isolated.
- `light.muted` is the docs body colour. A separate muted role was not isolated.
- Spacing scale and motion durations were not declared as custom properties on `html`. They are Not captured.
- Full-page shots are the viewport after a lazy scroll. The kit's dimension check rejected a clip whose PNG height did not match `documentSize`.
- The login field's placeholder was a sample address. It was painted out of the screenshots and crops. It is not a value.

## Do and don't

- **Keep the page black and the headline in domaine.** The home hero is 96px domaine on black. [home-dark-default.png](screenshots/home-dark-default.png)
- **Use one white pill for the primary action.** Secondary actions are text links. [button-primary-hover.png](components/crops/button-primary-hover.png)
- **Open desktop menus on hover.** Features, Company, Enterprise, Help, Docs, and AI are hover menus, not click dialogs. [home-dark-features-menu.png](screenshots/home-dark-features-menu.png)
- **Keep docs in its own theme.** Docs is light by default, with an explicit dark switch. Do not paint the marketing page light. [docs-light-default.png](screenshots/docs-light-default.png)
