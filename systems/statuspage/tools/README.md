# How this package was captured

2026-11-22. Public pages only.

Headless Chromium (Playwright at `~/.design-systems/pw`) opened https://www.atlassian.com/software/statuspage and the header and footer destinations. Viewport 1440 by 900 and 390 by 844, device pixel ratio 2. Screenshots were quantised to 256 colours.

Sign in and signup were opened and left empty. Continue and Sign up were not clicked. No identity provider was clicked. No form was submitted. No page was created. Search was not typed. Pricing Get started today was not clicked. The blog Subscribe control was not clicked.

The cookie banner was hidden with CSS and not accepted. Contact us was opened and discarded because it prints a street address. Impressum was not opened.

`catalog.json` was left alone, so `make design-md` and `make brief` were not run for this package. `systems/atlassian` was not touched.
