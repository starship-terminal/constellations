# Stocktwits design reference

Tokens and component notes for Stocktwits, captured **2026-11-19**. Desktop innerWidth was 1440 and innerHeight was 900. Phone innerWidth was 390 and innerHeight was 844. Device pixel ratio was 2. Signed out the whole time. The live theme cookie was `viewMode=lightMode`. Dark values were read from `[data-theme="dark"]` on the same document, then the attribute was removed.

Stocktwits is a public social feed for stocks and crypto. This package covers the signed-out shell, the sign-in and signup forms, a symbol page, the about landing page, widgets, subscriptions, the enterprise sales form, and the privacy policy. Nothing was submitted.

## How the values were read

The T3 preview tab opened `https://stocktwits.com/` without a Cloudflare challenge. `preview_snapshot` then failed with "The browser is not producing screenshot frames." Computed styles and custom properties were read with `preview_evaluate` on that tab. The desktop pass was `preview_resize` freeform 1440 by 900. The phone pass was 390 by 844.

Theme tokens live on `[data-theme="light"]` and `[data-theme="dark"]` in `d9d57e98113aac31.css`. The reading set `data-theme` on `documentElement`, dumped `getComputedStyle`, and removed the attribute. The body background returned to `rgb(255, 255, 255)`.

Headless Playwright was tried only after the public pages had already loaded in the preview tab. Every headless navigation returned the title "Just a moment...". Those shots were discarded. No second headless session was launched against the login page.

## What to distrust

[screenshots/capture-gap-light.png](screenshots/capture-gap-light.png) is a label, not a capture of the site. Do not sample colours from it.

Dark roles are declared custom properties, not a live dark screenshot. The filled shell button "Sign up or log in" computed black, while `--primary-button-background` stayed `#1b66e7`. Both are recorded. The black pill is the one on screen.

The custom-property values were read in the preview tab but not saved: `raw/` holds computed control styles and motion rules, no custom-property dump. The 18 core colours that no `raw/` file holds (the dark greys, `pageDark`, the dark price colours, `blue`, the orange and edge accents) and both `focus` tokens are labelled Reconstruction, entered by hand at capture time. A recapture that dumps `:root` and `[data-theme=dark]` would make them Measured.

The sign-in field's focus computed outline none. `--select-focused` (`#86b7fe` in light) is declared and was not painted on that field.

The home ticker percent inherited black. Price colour was read from the symbol change (`rgb(18, 135, 96)`) and the widgets loss (`rgb(221, 51, 29)`).

OneTrust buttons (`#1d68d7`, radius 2px) are the vendor banner. They are not Stocktwits controls.

Source Sans 3 in the style guide comes from Google Fonts. The site serves its own woff2 from `chunks-prd.stocktwits-cdn.com`.

## Fonts

The computed body family is `"Source Sans 3", "Source Sans 3 Fallback"`. The fallback `@font-face` is `local("Arial")`. Weights seen on the page are 400, 600, 700, and 900. The site files are woff2 on the Stocktwits CDN. This package does not ship them. Tokens fall back to Arial, then sans-serif.

## Do and don't

**Do paint the shell page white and the text black.** The body computed `rgb(255, 255, 255)` and `rgb(0, 0, 0)` in light. See [patterns.md](patterns.md).

**Do use #1b66e7 for the text link and the declared primary button.** Log in to existing account computed `rgb(27, 102, 231)`. `--primary-button-background` is the same hex.

**Do use 9999px pills for Stocktwits buttons.** Continue with Apple, Log In, and Subscribe all computed that radius.

**Do colour a gain #128760 and a loss #dd331d in light.** The AAPL change and the widgets loss computed those RGB values.

**Don't invent a screenshot.** The preview browser returned no frames, and headless Playwright hit Cloudflare.

**Don't treat the black Sign up or log in pill as the blue primary token.** That control computed `rgb(0, 0, 0)`.

**Don't submit signup, a plan, or the sales form to finish a capture.** The first signup screen is email plus Apple. Later steps were not opened.

**Don't copy OneTrust blue into the product tokens.** Those buttons belong to the privacy vendor.
