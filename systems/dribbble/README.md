# Dribbble design reference

A token set and component reference for Dribbble's public signed-out surface — for building community, portfolio and marketplace pages in the style of the real thing. It was read from **dribbble.com** on **2026-11-13**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: the home page and shots feed, a shot detail page, a designer profile, the designers directory, the jobs board, search results, the stories blog, the login and signup cards (measured, never submitted), the Explore header dropdown and the mobile menu opened by their own controls, and a 390px mobile pass.

Dribbble is worth a capture because the signed-out page is the shopfront of the design industry's community product — and because it paints one surface in three CSS eras. The Rails-era mini-master bundle styles most of what the visitor sees: Mona Sans everywhere, a `#0d0c22` near-black ink, white page and cards, the `#ea4c89` Dribbble pink reserved for the primary/search action, the hero accent word, checklist ticks and PRO badges, muted `#6e6d7a` secondary text, 8px card radii and 20px pill buttons. The newer Vite surfaces run Shoelace, whose whole `--sl-*` token layer is declared at `:root` — primary ramp re-bound to the same pink, neutral ramps, radii, spacing, shadows, transitions and a pink focus ring — so a large share of the token set is genuinely declared evidence, not inference; the `--btn-*`/`--input-*`/`--zi-*` and `--site-nav-*` application variables come with it. The third era is vendor: Algolia search and intl-tel-input styles. **Boundary:** the signed-in product — posting shots, following, hiring flows, dashboards — lives behind `/session/new` and was never reached; the signed-out feed itself stops at one shot card plus a sign-up wall, measured as the boundary it is. Nothing was signed into, filled, followed, liked, booked or submitted.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export dribbble` prints them all with aliases resolved.

### Principles

1. Do put the near-black ink on white.
2. Do reserve the pink for action and accent.
3. Do make the main action a dark pill.
4. Do keep cards quiet.
5. Do ring focus in pink.
6. Do use icon-only circles for secondary actions.
7. Don't paint a whole dark page.
8. Don't style the signed-in product from this package.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out site in headless Chromium:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) captures every stylesheet the page loads and writes every custom property to [raw/css-vars.json](raw/css-vars.json), resolved in a light pass and a dark-scope pass. Dribbble declares the full Shoelace `--sl-*` layer at `:root` (primary ramp re-bound to `#ea4c89`, neutrals, radii, spacing, shadows, transitions, focus ring) plus its own `--btn-*`, `--input-*`, `--zi-*` and `--site-nav-*` variables, so most scale tokens are declared variables with `css-var` evidence; the colours, geometry and type the mini-master bundle paints inline are measured leaves labelled `computed … of {component} {state}`. [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec, [tools/build_tokens.py](tools/build_tokens.py) the sets and validates every alias.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context and reads `getComputedStyle`, painted layers, pseudo-elements and boxes per element in default, hover, focus-visible and a CDP-forced pressed state, across home, the feed, a shot, a profile, the directory, jobs, search, stories, the auth cards and mobile — plus real opened states: the Explore dropdown by hovering its own trigger, the mobile menu by its own toggle. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md).
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route, full pages bounded at eight chunks with the truncation recorded; [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours. Full-colour raws stay outside the repository.

Nothing was signed into, filled or submitted: the login and signup forms were captured as surfaces and the email field's `filled` state typed sample text and deleted it before reading, with nothing sent; every Start-Brief, Get-in-touch, Follow, Apply, Sign-up and Get-Started action was measured, never followed; the Explore dropdown and mobile menu were opened only by their own controls. The floating project-brief card, the Google One Tap prompt and any consent overlay were hidden, never answered — no consent button was ever clicked and no OAuth flow was started; the Google GSI button is therefore a documented gap, not a measurement.

## What to distrust

- **This is the public shell, not the product.** Posting shots, following, hiring flows, inboxes and dashboards sit behind sign-in and were never reached. The signed-out feed stops at a sign-up wall — that is where the package stops too.
- **One light surface.** Every captured page paints light. The `dark` token set names only the ink surfaces painted inside the light page (the dark Log-in / Get-in-touch / Continue pills), not a user-selectable theme; the only declared dark CSS scope re-binds the third-party Algolia search dropdown and never paints as a product theme.
- **Two style systems share one page.** Shoelace `--sl-*` variables and the mini-master hardcoded values coexist; a component's painted value is the mini-master one when they disagree — the measured tokens are what you see.
- **The home hero animates.** The accent word, the hero media card and the promo content rotate; the crops catch one frame and later runs may read a different word.
- **Percentages and mega-radii.** `50%` radii are stored under a non-standard `other` type because a percentage is relative to the element, and Chromium serialises pill radii as `1e+07px` — both mean "as round as the element allows".
- **A zero-sized nav link.** The pink `Start Project Brief` nav link exists in the header DOM but paints 0 x 0 at 1440 wide on the home page — it is documented as a gap, not measured.
- **Readings to recapture.** `designer-name` is the "15 Services available" meta line (its name filter matched inside "available") and `m-search` is a tag chip; components.md marks both and no token reads them. The selectors are fixed in `measure.mjs` (edited, not run), as is the reduced-motion probe, which read `header` (absent) instead of the `.site-nav` bar and so recorded nothing.
- **Feeds are third-party content.** Shot cards, designer names, ratings and avatars are public posts by other people; values are read from the first card, so geometry and copy vary between runs.
- **Automation was masked during capture.** Until 2026-11-20, `tools/capture/public/lib.mjs` hid `navigator.webdriver` in every page it opened, so every committed reading was taken with that mask. The mask is removed (a bot check is now recorded as a boundary, not bypassed); whether any page needed it to load is not known, and a recapture without it is the check.

## Fonts

Mona Sans carries the product — headings, buttons, chips and body text, falling back through Helvetica Neue to Arial (the `@font-face` declarations are harvested in [raw/css-vars.json](raw/css-vars.json)). The jobs board sets its display h1 in Source Serif Pro at 72/76, and IBM Plex Mono ships as a served face on newer surfaces. Mona Sans is Dribbble's licensed brand face: use the tokens' fallback stack for anything that ships, never serve the captured font.

## Coverage

Captured at 1440 x 900, signed out: `/` (default, Explore dropdown open, bounded full page), `/shots/popular` (default, full), a shot detail page (default, full), a designer profile `/Moonsight` (default, full), `/designers` (default, full), `/jobs` (default, full), `/search?q=logo` (default, full), `/stories` (default, full), `/session/new` and `/signups/new` (default), plus the 390 x 844 mobile pass over home, shots and the profile including the opened burger menu.

## Do and don't

1. **Do put the near-black ink on white.** Text and buttons read `#0d0c22`/`#060318` on the white page, with `#6e6d7a`-family greys for secondary text and meta. See [designer-card](components/crops/designer-card-default.png).
2. **Do reserve the pink for action and accent.** `#ea4c89` paints the search Go circle, the hero accent word, checklist ticks and PRO/SELECT badges — never a whole surface. See [search-go](components/crops/search-go-default.png) and [hero-accent](components/crops/hero-accent-default.png).
3. **Do make the main action a dark pill.** Log in, Get in touch, Start Your Project Brief and Continue are `#0d0c22` fills with white 13-14px text, 20-24px padding and a full radius. See [login-btn](components/crops/login-btn-default.png) and [continue-btn](components/crops/continue-btn-default.png).
4. **Do keep cards quiet.** White fill, 1px `#f3f3f4` border, 8px radius, a faint `0 1px 10px rgba(18,22,25,.02)` shadow, generous 24-28px padding. See [designer-card](components/crops/designer-card-default.png) and [job-card](components/crops/job-card-default.png).
5. **Do ring focus in pink.** The keyboard focus indicator is a 2px solid `#f3afe4` outline offset 1px on links, buttons and chips. See [nav-trigger focus](components/crops/nav-trigger-focus-visible.png).
6. **Do use icon-only circles for secondary actions.** Save/like/bookmark controls are 40px white circles with a 1px `#e7e7e9` border. See [shot-icon-btn](components/crops/shot-icon-btn-default.png) and [bookmark-btn](components/crops/bookmark-btn-default.png).
7. **Don't paint a whole dark page.** The dark values here are pills, chips and the mobile header inside a light page — not a theme; the only declared dark scope is the Algolia vendor dropdown's. See [m-header](components/crops/m-header-default.png).
8. **Don't style the signed-in product from this package.** Posting, following, hiring and dashboards were never reached; the feed's sign-up wall is the boundary. See [shots-light-full](screenshots/shots-light-full.png).

## Rebuild

From `systems/dribbble/`:

```sh
# harvest stylesheet variables (needs Playwright)
PLAYWRIGHT=<pw>/index.mjs node tools/capture/vars.mjs

# screenshots (needs Playwright + a Python with Pillow): full-colour PNGs go to
# a scratch RAW dir outside the repo, then quantize.py publishes the verified
# captures as 256-colour PNGs into screenshots/
RAW=$(mktemp -d)
RAW=$RAW PLAYWRIGHT=<pw>/index.mjs PYTHON=<py> node tools/capture/public/public.mjs
<py> tools/capture/quantize.py "$RAW"

# component measurements, then the derived artefacts
PLAYWRIGHT=<pw>/index.mjs PYTHON=<py> node tools/capture/public/measure.mjs
node tools/capture/public/build-measurements.mjs
<py> tools/build_component_tokens.py
<py> tools/build_tokens.py
<py> tools/build_components_md.py
<py> tools/build_style_guide.py
```

`make brief`, `make design-md` and `make grade` at the repository root regenerate the Brief, DESIGN.md and Health sections from the catalog entry.
