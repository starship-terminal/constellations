Palette

The core set carries the measured #121722 ink/white neutrals and the #0068f9 blue ramp (measured off the actions, var-referenced where a marketing variable resolves the same value); the declared illustration accents come from the --color-* layer. Light roles alias the palette; the "dark" set is the deep-blue islands the light site paints — the hero band and the signup pane — not a user toggle.

Spacing and radius

Nav controls, CTAs and filter pills are 100px pills; the mega-menu viewport paints 19px, the hero artwork 18.9px, the popular column 12px top corners, mega-menu items 8px, the filter pill 60px, HubSpot fields 6px and Chakra controls/fields 4-6px. Borders are rare — white controls draw a 0.5px inset hairline as box-shadow instead.
