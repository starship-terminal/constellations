# Wikipedia public components

Inventory of what the public site shows. No crops. The shots are the full viewports in [screenshots/](screenshots/).

| Component | Where | States captured |
|---|---|---|
| Wordmark | Header image, "WIKIPEDIA" plus the puzzle globe and the anniversary mark | default |
| Main menu | Hamburger, unpinned dropdown | open on desktop and on the phone |
| Search field | Header, and Special:Search | empty default. Not typed in. |
| Search button | Header, attached to the field | default |
| Personal links | Donate, Create account, Log in | default. Donate not followed. |
| Namespace tabs | Main Page / Talk, and the article / Talk | default. Talk not opened. |
| View tabs | Read, View source, View history | default. View source and View history not opened. |
| Tools menu | Page toolbar overflow | open |
| Appearance panel | Pinned right rail | Light default. Dark selected only in a headless context. hide not clicked. |
| Language button | Footer, "349 languages" | panel open. No language clicked. |
| Article title | Linux Libertine h1 | default |
| Content link | Article body | default |
| Contents | Article contents list | default, collapsed sections not expanded beyond what the page painted |
| Featured card | Main page, today's featured article | default |
| Empty search | Special:Search with no query | default |
| No-results search | Special:Search with a URL query that matches nothing | default |
| Login form | auth.wikimedia.org Special:UserLogin | empty. Not submitted. |
| Signup form | auth.wikimedia.org Special:CreateAccount | empty. Not submitted. Notice only, no captcha widget. |
| Footer | Sister projects and legal links | default. Links not followed. |

Not captured: hover, focus-visible, pressed, selected, disabled (except the disabled Text radios on the auth pages), loading, error on a filled field, edit form, history list, talk page, watchlist, donate page.
