# Wikipedia public patterns

## Main page

Vector 2022. A white header holds the hamburger, the wordmark, a search field with a Search button, and three personal links: Donate, Create account, Log in. Below that, namespace tabs sit on the left and view tabs on the right. The content column is white on a `#f8f9fa` canvas. The welcome heading, a featured article, an improvement prompt, and "In the news" share that column. Appearance is pinned on the right: text size, width, and colour.

The featured article on this visit was Talking to Yourself. The counts painted were 263,142 active editors and 7,267,554 articles in English.

## Article

The same chrome. The title is a serif h1. A contents list sits at the top of the body. Body text is 16px / 26px. Links are `#36c`. Photographs sit in the body at the Codex image sizes (small 180px, standard 250px, large 400px). Edit and View source were not opened.

## Navigation

The main menu is an unpinned dropdown, not a pinned sidebar. It has Navigation and Contribute. Phone uses the same list from the hamburger. Tools is a second unpinned dropdown on the page toolbar. The language control is a footer button that opens the Universal Language Selector. That panel was photographed and not used.

## Search

Empty search is Special:Search. A query with no matches paints "There were no results matching the query." Both were opened by URL. The header field was not typed in.

## Appearance

Three radio groups, pinned. Fresh visit: Text Standard, Width Standard, Color Light. Color Dark restyles the same page: canvas `#202122`, ink `#eaecf0`, links `#88a3e8`. That preference was set only in a headless context for one shot.

## Auth

Log in and Create account leave en.wikipedia.org for auth.wikimedia.org. Both walls use the Wikipedia wordmark and the pinned Appearance panel, with Text radios disabled. Fields were empty. No identity provider was painted. Create account shows an hCaptcha notice and no challenge. Both walls were photographed and left.

## Footer

Sister-project names, a language size list, the 349-languages button, then legal links and the Wikimedia and MediaWiki marks. The footer says the page was rendered with Parsoid.
