# Wikipedia public

Hand-written from the readings in [raw/measured-home.json](raw/measured-home.json), [raw/measured-article.json](raw/measured-article.json), and [raw/measured-dark.json](raw/measured-dark.json). Not generated by `make design-md`, because that rewrites the catalog and this package is not registered.

## Colour

The public default is Light. The canvas is `#f8f9fa`. The content column is white. Ink is `#202122`. Links are `#36c`. The article title is `#101418`.

Color Dark is a client preference on the pinned Appearance panel. It was read in a separate headless context. Body ink became `#eaecf0` on `#202122`. Links became `#88a3e8`.

| Role | Light | Dark | Where |
|---|---|---|---|
| Canvas | `#f8f9fa` | `#202122` | computed body background |
| Content | `#ffffff` | `#101418` | `--background-color-base` |
| Ink | `#202122` | `#eaecf0` | `--color-base` |
| Title | `#101418` | `#f8f9fa` | `--color-emphasized`, article h1 in light |
| Subtle | `#54595d` | `#a2a9b1` | `--color-subtle` |
| Progressive | `#3366cc` | `#88a3e8` | `--color-progressive` |
| Visited | `#6a60b0` | `#a799cd` | `--color-visited` |
| Destructive | `#bf3c2c` | `#fd7865` | `--color-destructive` |
| Border | `#72777d` | `#72777d` | search field border |

## Type

Body and chrome use the system sans. The computed family is `sans-serif`. The page title uses Linux Libertine, then Georgia, Times, Source Serif 4, serif.

| Role | Size | Weight | Line height |
|---|---|---|---|
| Title (article h1 at 1440) | 28.8px | 400 | 39.6px |
| Body | 16px | 400 | normal on body, 26px in the content column |
| Article link | 16px | 400 | 26px |
| Search and personal links | 14px | 400 (Search button 700) | 22px on the field |

## Controls

The search field is 32px tall, 14px, padding `4px 8px 4px 32px`, 1px `#72777d` border, radius `2px 0 0 2px`, fill white in Light. The Search button is 14px weight 700, fill `#f8f9fa`, radius `0 2px 2px 0`, same border.

Links use a 2px radius. The wordmark is an image, 38px tall in the header.

Appearance is a pinned panel: Text Small / Standard / Large, Width Standard / Wide, Color Automatic / Light / Dark. Light, Standard, and Standard width are the fresh-visit selection.

## What this file does not cover

Hover, pressed, disabled, and loading were not clicked. Codex publishes hover and active colour variables; they are in [tokens.json](tokens.json) as declared values. Edit, history, talk, and the signed-in editor were not opened. The login and signup walls were photographed empty and not submitted.
