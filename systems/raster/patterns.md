# Patterns

Public signed-out pages. First read 2026-11-19. Refreshed 2026-11-21. The control map is [site-tree.md](site-tree.md).

## Chrome

A 53px fixed bar: four-tile wordmark, Product, Pricing, Resources, Sign in, a red Start for free, a ghost Book demo. Resources opens a dark menu (Blog, Design, Docs, Changelog). On a 390-wide viewport the wordmark and Start for free stay, and a hamburger replaces the rest.

See [home-dark-default](screenshots/home-dark-default.png) and [home-dark-menu](screenshots/home-dark-menu.png). The phone drawer is [mobile-home-dark-menu](screenshots/mobile-home-dark-menu.png).

## Hero

Black page. One gradient line, then two near-white lines, then a red Get started beside a ghost Onboard your agent chip. A large rounded demo frame sits under the actions. The frame's interior was a dark video surface at capture time.

See [home-dark-default](screenshots/home-dark-default.png), [home-dark-features](screenshots/home-dark-features.png), and [mobile-home-dark-default](screenshots/mobile-home-dark-default.png). The video frame under the hero had not painted when these shots were taken. The feature cards below it did.

## Pricing

A gradient hero ("Built for teams. Priced for everyone.") over three columns. Team and Enterprise use the red action. Personal uses the ghost action. A footer band repeats Get started next to a Work email field. That field was not submitted. Contact Sales was not followed.

See [pricing-dark-default](screenshots/pricing-dark-default.png).

## Journal and product

Blog is a black page, a Raster Neue title, and image cards with a LATEST pill. Product is the same chrome over a long feature page. Changelog is a dated list under the same chrome.

See [blog-dark-default](screenshots/blog-dark-default.png), [product-dark-default](screenshots/product-dark-default.png), [changelog-dark-default](screenshots/changelog-dark-default.png).

## Design playground

`/design` is the public specimen page: accordion, avatar, button, tag, color, form, tabs, glass, icon. It uses the marketing chrome. The gray ramp on that page matches the `--color-gray-*` custom properties.

See [design-dark-default](screenshots/design-dark-default.png).

## Docs

`/docs` loads dark. A public theme control switches it to light. It is not a theme of the marketing page. A sidebar (search, Guides, API Reference, Integrations) and gray cards. Raster Red marks the current row.

See [docs-dark-default](screenshots/docs-dark-default.png) and [docs-light-default](screenshots/docs-light-default.png).

## Auth wall

`/sign-in` is a centered card on a dotted black field: the four-tile mark, "Sign in to Raster", Continue with Google, and Email link to sign in. `/sign-up` lands on the same card. The email field stays hidden until Email link is pressed. It was not pressed.

See [auth-dark-default](screenshots/auth-dark-default.png).
