# Patterns

## Homepage

A fixed header, a news strip, a centered headline, two buttons, then three columns (Fast, Agentic, Collaborative) over a public editor demo. The demo is the site's illustration. The footer is a blue band.

Phone keeps the headline and the two buttons, and replaces the header links with a menu button.

## Download

A version heading, platform rows, and a newsletter card. The Linux row is an install command, not a file button. The binaries were not downloaded.

## Docs

A docs shell, not the marketing header. Left nav, article, on-this-page. Search is empty.

## Auth

Sign in leaves the site for GitHub and stops on an empty form. Sign up stays on a card with two checkboxes, a human check, and one GitHub button. Neither was submitted.

## Empty

The 404 is a drawn 404 and "Page Not Found." The extension search and the docs search were left empty. The command menu was left empty.
