# mymind design reference

A token set and component reference for the public marketing site of mymind, a private bookmark and notes product. Captured from https://mymind.com/ on 2026-11-21, signed out, in headless Chromium at 1440×900 and 390×844. One light theme. The signed-in app on access.mymind.com was not entered.

The public site paints a warm paper page (`#f9fafc`), black and near-black serif display type, and one ember accent (`#ff5924`) used as a pill fill. Links are `#1573dd`. Feature cards use flat pastels. There is no dark theme and no design-token layer: styles.css declares easing curves, and the colours below were read from computed styles.

### Principles

1. Do set display type huge and tight.
2. Do spend ember on one pill.
3. Do keep cards as flat pastels.
4. Don't style the signed-in library from this package.
5. Don't invent a dark theme.
6. Don't treat WordPress preset colours as the brand.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Computed styles in headless Chromium on https://mymind.com/, https://mymind.com/pricing, https://mymind.com/faq and https://mymind.com/mobile, plus the authored rules in https://mymind.com/css/styles.css and https://mymind.com/css/pages/home.css. Link colour `#1573dd` is the `a` rule and the computed colour of Log in. Ember `#ff5924` is the computed background of the TRY IT OUT wrap and the pricing SIGN UP button, and an authored `background-color` in home.css. Page `#f9fafc` is `.transition-wrap`. Display type is the computed style of `h1.mm-title`. Easing curves are the `:root` custom properties in styles.css. WordPress preset colours in that file were not painted by these pages and are not tokens.

## What to distrust

Pricing heading letter-spacing was not read and is omitted. FAQ line height repeats the 28px font size and is Derived. Nav line height uses the 24px box height because the computed line-height was 0px. Hover of the ember fill did not change; do not invent a hover ember. Focus ring width was not painted. Screenshots are 256-colour PNGs. Read colours from tokens.json.

## Fonts

Avenir LT (fonts.net), Louize, Nunito and Inter are the product's faces. They are proprietary and are not in this package. Tokens name the computed family and a fallback. The style guide uses system fallbacks.

## Do and don't

1. **Do set display type huge and tight.** The home heading is 140px with -8.4px tracking. [screenshots/home-light-default.png](screenshots/home-light-default.png)
2. **Do spend ember on one pill.** The filled action is `#ff5924`. Other actions are blue links. [components/crops/button-signup-default.png](components/crops/button-signup-default.png)
3. **Do keep cards as flat pastels.** Feature tiles use sand, blue, green, blush and peach fills, not shadows. [screenshots/home-light-full.png](screenshots/home-light-full.png)
4. **Don't style the signed-in library from this package.** That surface is behind the auth wall and was not measured. [screenshots/notfound-light-default.png](screenshots/notfound-light-default.png)
5. **Don't invent a dark theme.** The public site ships light only. [screenshots/home-light-default.png](screenshots/home-light-default.png)
6. **Don't treat WordPress preset colours as the brand.** They are in the stylesheet and were not painted here. [screenshots/pricing-light-default.png](screenshots/pricing-light-default.png)
