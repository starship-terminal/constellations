# mymind

mymind is a private bookmarking product. This package records the public marketing site and the signed-out access panel, measured on 2026-11-19 from live computed styles. No account was created. The access panel offers Google and Apple only, so the email signup allowed by the capture rule was not available.

The browser viewport measured 1169 by 731 at devicePixelRatio 2 on the desktop pass, and 390 by 844 on the phone pass. A 1440-wide capture was requested and did not land. Screenshot frames were not produced.

## How the values were read

Pages were opened in the T3 Code preview browser, one tab, not shared. `preview_evaluate` read `getComputedStyle` on the live document. Stylesheets on mymind.com were readable. Custom properties there are WordPress presets and a set of easing curves, not a colour system, so colour and type tokens come from computed styles on real elements.

Desktop readings used innerWidth 1169 and innerHeight 731, devicePixelRatio 2, visualViewport scale 1. Phone readings used innerWidth 390 and innerHeight 844 after a freeform resize. Nothing was forced into a theme class. `prefers-color-scheme: dark` was true and the pages still painted light.

`preview_snapshot` failed with "The browser is not producing screenshot frames." Measurements already read were kept. No screenshot was drawn by hand.

## What to distrust

The hero size is fluid. 116.9px was the computed size at innerWidth 1169, and 50.004px at 390. The token rounds the desktop reading to 117px. Do not treat it as a fixed display size.

Several type steps were rounded from fractional computed pixels (41.7737px to 42px, 32.1611px to 32px, 19.08px to 19px). The raw reading is in [raw/computed.json](raw/computed.json).

Louize is stored as `Louize, sans-serif`. The computed family was `Louize-Regular-205TF`. That face is a licensed webfont and is not in this package. Nunito and Inter are the same kind of rename from `Nunito-SemiBold` and `Inter-Regular`.

The reviews hero gradient was truncated in the reader after the 30% stop. It is not a token.

Hover, focus and pressed colours were not read. A transition at rest is not a hover colour.

[tokens.json](tokens.json) is written by hand from [raw/computed.json](raw/computed.json). `tools/build_tokens.py` does not rebuild it. It checks every measured colour against a reading in that file, and it resolves aliases set first, then core, as Tokens Studio does. That check found five light roles that aliased themselves (`light.color.link` was `{color.link}`) and `light.color.chip-text`, which resolved to the chip background. The five core colours they meant are now `color.link-blue`, `color.band-bg`, `color.faq-bg`, `color.signin-panel-bg` and `color.chip-ink`.

The quote line height of 28px is the body line height on the same family, not a separate computed reading on the quote.

## Fonts

Louize (computed `Louize-Regular-205TF`, also italic, medium and bold faces loaded) is the display face. It is a commercial webfont from the page's font stylesheet. The tokens name `Louize` and fall back to `sans-serif`. Do not commit the font files.

Nunito (`Nunito-Regular`, `Nunito-SemiBold`) is the UI face: pills, eyebrows, pricing toggle, sign-in chrome. Inter (`Inter-Regular`, `Inter-Medium`) is body copy. Open Sans is the body element fallback and the 404 headline. Avenir LT (`Avenir LT W01_45 Book1475508`) is the heading element's own family. The painted glyphs are the inner Louize span.

## Do and don't

**Use the orange only for the action.** The sign-up pill, the try button and the price figures are `#ff5924`. Body text stays black or slate.

**Set display type in a serif with tight tracking.** Headlines are Louize, large, with negative letter-spacing. UI labels are Nunito.

**Keep the page off-white.** The marketing canvas is `#f9fafc`, cards are white, and one band is warm `#f6f4f2`.

**Do not invent a dark theme from the OS setting.** The captured pages stayed light while the browser reported a dark colour scheme.

**Do not draw an email field on the access panel.** The signed-out panel is two provider buttons.
