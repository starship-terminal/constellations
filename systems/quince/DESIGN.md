# Quince

Handwritten because `make design-md` needs a catalog entry, and this capture left `catalog.json` alone.

## Colors

| Role | Value | Source |
|---|---|---|
| page | `#ffffff` | Header background |
| ink | `#21201f` | Nav, titles, promo bar, Continue |
| on-ink | `#ffffff` | Promo type, footer links, Continue type |
| cantaloupe | `#ffa273` | Search button, Shop Now, Add to Bag |
| holiday | `#bc5a28` | Holiday Gifts label |
| search | `#eeeeec` | Search field |
| muted | `#717171` | Compare price, savings line |
| footer | `#2d313f` | Footer band |

## Typography

Grosa is the UI face: nav 14px weight 500, titles 20px, prices 16px, Add to Bag 14px weight 500. ivy-headline is the hero face, 24px weight 300. Files are not in this package.

## Geometry

Promo bar 40px. Search 36px, radius 4px. Shop Now 32px, radius 9999px. Add to Bag 52px, radius 9999px. Continue 58px, radius 100px. Size chips 40 by 56px, radius 0. Wordmark 100 by 30px.

## Do and don't

Keep the page white and the type ink. Use cantaloupe for the one loud control. Stop at the empty email wall. Continue with Google was not clicked. Add to Bag was not clicked.
