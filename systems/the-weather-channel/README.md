# The Weather Channel design reference

A token set and component reference for the public weather.com site, signed out, captured on 2026-11-21. Desktop 1440 x 900 and phone 390 x 844. One theme. The editorial news chrome and the maps chrome were both reached. Login was recorded and not submitted.

The root URL redirects to a geolocated forecast. That page, and any forecast that shows a street address, was mapped in [site-tree.md](site-tree.md) and not screenshotted. The location control on the news screenshots is painted over.

## How the values were read

Headed Chrome via Playwright. Headless Chromium was stopped by an interstitial titled Challenge Validation. Custom properties were read from the news page stylesheets into [raw/vars-news.json](raw/vars-news.json). Computed styles of the header, nav, heading, Settings focus ring, Settings dialog, and the selected unit chip were read into [raw/components-computed.json](raw/components-computed.json). [tools/build_tokens.py](tools/build_tokens.py) writes tokens.json from those files.

Consent overlays were hidden with CSS. No consent button was clicked. No form was submitted.

## What to distrust

- The location pill on the news screenshots is painted `#252422`. The label is not in the image.
- Declared semantic variables on the news page (`--background`, `--foreground`) resolve to a dark lab palette. The painted page is white. The light token set uses the computed paints, not those variables.
- Muted text and hairline borders are declared gray steps. They were not read as a separate computed hex.
- Pressed, disabled, loading, and error control states were not shown.
- Screenshots are full colour viewport shots, not 256-colour quantised copies.
- `https://weather.com/` did not clear the interstitial in the screenshot session. The news and maps pages did.

## Fonts

Inter, with an "Inter Fallback" stack, is the computed family on body, nav, and headings. It is not distributed here. The style guide falls back to Arial.

## Do and don't

- **Do use one blue for the selected section.** The sidebar selection is `#3a61cc`. [screenshots/news-light-default.png](screenshots/news-light-default.png)
- **Do keep header actions as quiet pills.** Settings and Sign in on the news chrome are text on white. [screenshots/news-light-default.png](screenshots/news-light-default.png)
- **Do fill the maps Sign in button with ink.** The maps chrome uses a black Sign in. [screenshots/maps-light-default.png](screenshots/maps-light-default.png)
- **Don't invent a dark theme.** Settings changes units, not theme. [screenshots/news-light-settings.png](screenshots/news-light-settings.png)
- **Don't put a street address in a specimen.** Location search and geolocated forecasts were mapped and left out. [site-tree.md](site-tree.md)
- **Don't submit the login form.** The wall is `https://weather.com/login`. [site-tree.md](site-tree.md)
