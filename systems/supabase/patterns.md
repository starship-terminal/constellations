## Public landing

[Desktop hero](screenshots/landing-desktop-hero.png) and [mobile hero](screenshots/landing-mobile-hero.png) show marketing hierarchy. [Mobile menu](screenshots/landing-mobile-menu.png) presents the public navigation. Public demos do not establish app table/editor coverage.

## Expanded dashboard patterns

[Team](screenshots/app-team.png) uses a compact table with row actions and top-level filters. [Invitation](screenshots/app-invite-members.png) opens a right-hand form panel; [mobile](screenshots/app-dark-mobile-invite.png) uses the full viewport. [Logs](screenshots/app-logs-empty.png) combines a filter rail, toolbar, timeline and table; the [calendar picker](screenshots/app-logs-date-picker.png) combines presets and exact times.

[Function editor](screenshots/app-function-editor.png) places files beside code and keeps the deploy action in a bottom bar. The [unsaved-changes dialog](screenshots/app-unsaved-changes.png) protects local edits on exit. No deployment occurred. [Organization settings](screenshots/app-organization-settings.png) groups editable fields in bordered sections. [Plan gates](screenshots/app-organization-security.png) retain navigation while replacing unavailable content with an explanatory callout.

[Account preferences](screenshots/app-account-preferences.png) and [switches](screenshots/app-keyboard-shortcuts.png) expose account configuration. These were inspected without changing settings except the previously approved temporary theme switch. [Feature previews](screenshots/app-feature-previews.png) includes embedded product imagery, not proof of an enabled Explorer.
