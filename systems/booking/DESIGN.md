# Booking.com

Public marketing design tokens from booking.com, measured 2026-11-22. This file is a copy of the light theme in [tokens.json](tokens.json). It was not written by `make design-md`, because that command needs a catalog.json entry and this pass does not edit catalog.json.

## Color

| Role | Value |
|---|---|
| Page | `#ffffff` |
| Surface | `#ffffff` |
| Footer | `#f5f5f5` |

| Muted | `#868686` |

| Yellow | `#ffb700` |

## Type

The UI face is the system stack: system-ui, Segoe UI, Roboto, Helvetica, Arial. Section headings on the homepage are Avenir Next, 24px, weight 700, line height 32px. The sign-in wall heading used Blue Sans. Those files are not in this package.

## Radius

Control radius is 4px. The search frame is 8px. The selected product tab is a pill (`9999px`). Sign in is 36px tall. Search is 50px tall.
