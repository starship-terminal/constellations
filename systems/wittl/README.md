# Wittl design reference

A token set and component reference for Wittl's public marketing site. Wittl is an applicant tracking product ("Make hiring a Wittl more human"). The live hosts `https://wittl.co/` and `https://www.wittl.co/` did not resolve on 2026-11-19. Values were read from the 2025-11-08 Wayback HTML of `https://www.wittl.co/`, rendered locally with scripts removed. Signed out. Light only. Desktop 1440 and phone 390.

No account was created. Login and signup point at `https://app.wittl.co`, which was not opened. No email, phone, card, or company SSO was entered.

## How the values were read

On 2026-11-19 the T3 preview browser returned `ERR_NAME_NOT_RESOLVED` for `https://wittl.co/` and `https://www.wittl.co/`. Cloudflare DNS and Google DNS both returned SERVFAIL. WHOIS names `NS1.HOVER.COM` and `NS2.HOVER.COM`. Both nameservers returned REFUSED for `wittl.co` A, with and without the recursion flag. The domain was updated on 2026-11-07 and expires on 2027-09-26.

The newest public HTML in the Wayback Machine is `https://web.archive.org/web/20251108094303/https://www.wittl.co/` (captured 2025-11-08). That HTML was downloaded and its scripts were removed. Headless Chromium rendered the file at 1440 x 900 (`devicePixelRatio` 1, `visualViewport.scale` 1, scroll height 8909) and at 390 x 844 (`devicePixelRatio` 2, scroll height 9011). Computed styles were read with `getComputedStyle` on that render. Colour, type and radius declarations were also read from the styled-components block inlined in the archived HTML (22832 bytes). The linked Next.js CSS file in the archive holds only two `@font-face` rules.

The T3 preview tab for the Wayback URL showed "Internet Archive: Temporarily Offline". Its snapshot call returned "The browser is not producing screenshot frames". Screenshots in this package are from the local render of the already downloaded HTML, not from a second live session.

## What to distrust

- **The live site was not measured.** `wittl.co` did not resolve. These values are the 2025-11-08 marketing page, not a page served on 2026-11-19.
- **Preview frames failed.** The T3 preview snapshot returned "The browser is not producing screenshot frames". Do not treat a missing preview image as a measurement.
- **Fonts did not load.** `FF More Pro` and `Denim` are declared in `@font-face` and named in computed `font-family`. The woff2 files were not in the archive index, so the render fell through the stacks. Sizes, weights and colours still come from CSS. Letterforms in the screenshots are the fallbacks.
- **Product images did not load.** Asset paths such as `/assets/bg.jpg` were not rewritten to the archive. Photographs in the screenshots are broken-image boxes. Layout sizes of those boxes were still measured.
- **The footer was not on screen.** It is `position: fixed` with computed opacity 0 and `pointer-events: none` until the page scroll reveals it. Its background `rgb(20, 22, 22)` and link colour `rgb(255, 255, 255)` are computed values at rest, not a captured open state.
- **The FAQ did not open.** Clicking "What is Wittl?" left the panel height at 0. The accordion is scripted. Only the closed button was measured.
- **Primary label colour is split.** The button anchor computed `color: rgb(20, 22, 22)`. The span is authored `#fff`. The token `light.text.on-action` follows the authored span.
- **Hover did not change the primary button.** After hover its background stayed `rgb(38, 57, 33)`. Nav links did change to `#F3F3F1`.
- **Focus did not paint a ring.** Focus on "Get started" left `outline: none` and `box-shadow: none`.
- **Reduced motion was ignored.** With `prefers-reduced-motion: reduce` emulated, the button transition stayed `0.2s ease-in-out`.
- **Screenshots are 256-colour.** Read colours from [tokens.json](tokens.json).
- **Content width.** The nav's computed `max-width` was 1024px. The stylesheet also declares `max-width: 1256px` on an inner row. The token uses the computed 1024px.

## Fonts

**Denim** is the UI face. Computed body stack: Denim, -apple-system, Helvetica Neue, Helvetica, sans-serif. The archive CSS declares `/fonts/Denim-Regular.woff2` at weight `regular` (the keyword, not 400). The file was not captured. Licence was not on the page.

**FF More Pro** is the display face for `h1` and the large `h3`. Computed stack: FF More Pro, Georgia, Times, Times New Roman, serif. The archive CSS declares `/fonts/FF-More-Pro-Light.woff2`. FontFont More Pro is a commercial face. It is not committed here.

The style guide uses Georgia and Helvetica Neue as stand-ins so the page still renders. Those stand-ins are not the product faces.

## Do and don't

- **Do use forest for the primary action.** "Get started" is `#263921` at 46px height, 24px horizontal padding, 4px radius. See [components/crops/button-primary-default.png](components/crops/button-primary-default.png).
- **Do use the lime for small marks, not for large fills.** Selection, the 24px check tile and the pill badge are `#C1FA6B`. The feature wash is the lighter `#E7FDBC`. See [components/crops/check-mark.png](components/crops/check-mark.png).
- **Do set the page on `#fcfcfc` and the header on white.** Body text is `#141616`. Muted copy is `#A0A1A1`. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
- **Do set display lines in FF More Pro and UI in Denim.** Display tracking is -0.02em. Body size is 16px with 28px line height.
- **Don't invent a dark theme.** None was declared. The footer ink `#141616` is a scroll-revealed band, not a theme.
- **Don't treat the local screenshots as a 2026-11-19 capture of the live site.** The domain did not resolve. The HTML is from 2025-11-08, and the photographs and webfonts did not load.

There is no product token builder. [tokens.json](tokens.json) was written from [raw/computed.json](raw/computed.json) and the inlined stylesheet. Regenerating DESIGN.md does not reread the site.

## Colors

The page is warm off-white (`#fcfcfc`) with a white header. The action is a deep forest green (`#263921`). Lime (`#c1fa6b`) is used for selection, checks and the update pill. Muted text is `#a0a1a1`. The footer, when the live scroll reveals it, is `#141616` with white links.

## Typography

Display and the large section headings use FF More Pro at a fluid size from 32px to 56px, weight 400, line-height 1 or 1.04, letter-spacing -0.02em. At 1440 that computed to 48.421px. UI text uses Denim at 16px / 28px. Ledes and quotes are 20px. The button label is authored at 18px. Badges are 12px.

## Layout

The nav content width computed to 1024px with 28px vertical padding. Sections use 16px grid gaps and 40px to 100px of section padding. The page shell has a 40px bottom radius and a 100vh margin under it, which is how the fixed footer is meant to show. At 390 the display size computed to 31.842px and a 46px menu button is shown.

## Components

Primary and secondary buttons, the nav link, the feature card, the lime check tile, the pill badge and the closed accordion are in [components.md](components.md). Form controls, the open menu and the signed-in app were not on the captured surface.
