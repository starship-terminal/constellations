# Epic Games design reference

A token set and component reference for the Epic Games Store's public surfaces — for building dark game-storefront pages, card shelves, product pages and auth dialogs in the style of the real thing. It was read from **store.epicgames.com** and **www.epicgames.com** on **2026-11-14**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: the store home (Discover), the legacy Browse grid, the Fortnite product page, Free Games, News, the launcher Download page, the /id sign-in dialog, the /help support centre, the /site marketing home, plus 390px passes on Discover and a product page.

Epic is worth a capture because the store ships its real design system to the browser: the EGS v2 stylesheet declares the hashed **EDS** token layer outright — 784 resolved custom properties (`--color-background-*`, `--color-foreground-*`, `--color-border-*`, `--size-*`, `--typography-*`, `--action-*`, `--gradient*`, `--identity-*`, `--feedback-*`, `--navigation-*`, `--status-*`, `--animation-*`, `--font-*`, `--egs-*`) — plus the older www/help surfaces expose their own shadow-root stylesheets (`:host` rules inside `<egs-navigation>`, `<egs-footer>` and the `epic-wf-*` web components). Every captured surface paints **dark only**: the `#101014` canvas (`--color-background-default`), `#18181c`/`#202024`/`#303034` elevation steps, `#fffffff2`/`#ffffffa6` text, `#ffffff26`/`#ffffff1a` borders and the `#26bbff`/`#33bfff` accent (`--color-background-fill-accent-primary-default`). Inter is the store voice (300-700), Inter Tight the display weight (700/900), OpenSans on www marketing, Recursive Mono for code. **Boundary:** everything behind sign-in was never reached — the sign-in form and both search fields were measured, never submitted; Get, Add to Cart, Wishlist, Download, sort options, filter checkboxes and every provider button were measured, never activated.

### Principles

1. Do let the EDS layer carry the design.
2. Do spend the blue on actions.
3. Do stack elevation, not borders.
4. Do pair Inter with Inter Tight.
5. Do use the 9999px pill for CTAs.
6. Do treat focus as a border.
7. Don't style the signed-in store from this package.
8. Don't fabricate a light theme or a purchase.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## Do and don't

1. **Do let the EDS layer carry the design.** The store ships its token layer: use `color.background.*`, `color.foreground.*`, `color.border.*`, `size.*` and `typography.*` semantics rather than restating hex. See [tokens.json](tokens.json).
2. **Do spend the blue on actions.** `#26bbff`/`#33bfff` (`color.background.fill-accent-primary-default`) fills Download, Get, Continue and the active tab underline; surfaces stay neutral. See [nav-download](components/crops/nav-download-default.png).
3. **Do stack elevation, not borders.** Cards, fields and the filters rail step through `#18181c`/`#202024`/`#303034` (`color.background.elevated-*`); borders only appear subtle (`#ffffff26`) or as the white `#fff` focus border. See [b-card](components/crops/b-card-default.png) and [s-field-email](components/crops/s-field-email-focused.png).
4. **Do pair Inter with Inter Tight.** Inter owns every control and body (300-700); Inter Tight 700/900 owns the display headings; OpenSans survives on the www marketing surface. See [b-h1](components/crops/b-h1-default.png) and [d-h1](components/crops/d-h1-default.png).
5. **Do use the 9999px pill for CTAs.** Pills (Save Now, Get, Continue, View More) go `size.borderRadius.full`; cards and fields keep small radii. See [hero-cta](components/crops/hero-cta-default.png).
6. **Do treat focus as a border.** Fields and buttons draw the `#fff` `color.border.focus-default` border rather than an outline ring. See [search-field](components/crops/search-field-focused.png).
7. **Don't style the signed-in store from this package.** Library, account, billing, cart and checkout were never reached; the public storefront, the sign-in dialog and the support centre are the evidence.
8. **Don't fabricate a light theme or a purchase.** Every public surface painted dark; no light variant was seen, and Get/Add-to-Cart was measured, never pressed.
