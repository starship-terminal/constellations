# Tools

This folder began as a copy of the shared capture kit, and this file was the kit's guide. That
guide described scripts this package never used: the kit's builders and capture routes written for
other products. The 2026-11 audit removed those unadapted copies. What remains is the package's own
builders and tests, where it has any, and the kit's generic capture helpers under `capture/`.

The kit and its guide live at [tools/kit/](../../../tools/kit/README.md) in the repository root.
The package's [README](../README.md) says how its values were read and how to rebuild them.
