### Principles

1. Use FK Display for the big title and Suisse Intl for everything else.
2. Keep the page near-white and the ink at `#212121`.
3. Make the primary action 74px tall with a 4px radius.
4. Do not invent a dark theme.
5. Do not restyle the Shopify account with these tokens.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Live computed styles and the theme stylesheet on `www.pedestal.com`, in the T3 preview browser, tab opened with `reuseExistingTab` false. Start URL `https://pedestal.com/` resolved to `https://www.pedestal.com/`. Title: "Pedestal | Danish Design TV Stands on Wheels and Accessories". No Cloudflare challenge.

The theme sheet is `cdn/shop/t/30/assets/theme.styles.css` (904 rules). Custom properties on `:root` and utility classes (`.bg-off_white-light`, `.text-black-100`, `.fs-title-display-2xl`, `.rounded-md`) were read from that sheet. Component sizes, colours, and fonts were read with `getComputedStyle` on the live elements. The country banner and cookie dialog were dismissed before the resting readings. A search overlay and a mega-menu were closed the same way.

Pages read: `/`, `/products/viva-bubble-gum`, `/collections/all-tv-stands`, `/cart`, `/pages/contact`. Account login redirects to `shopify.com` Customer Account. That host was measured separately and is not in the tokens.

`preview_snapshot` returned "The browser is not producing screenshot frames". No PNG was written. Headless Playwright was not started, because the preview page had already loaded and the failure was frames, not a challenge.

## What to distrust

The 128px icon is the 32px favicon scaled up. It identifies the package. It is not a measured app icon at 128.

Hover fills for blue and ink are the declared `.betterhover:hover` rules, not a computed style with the pointer on the button.

The focus colour is the browser's default outline on a focused contact input (`rgb(229, 151, 0) auto 1px`). The theme sheet has no `:focus-visible` rule.

`--color-error` is `#de4438`. The class that paints error text is `#ff4747`. The text token uses the class.

Rebuy search widgets set their own blue (`#2491C4`) on `:root`. Those names are in the readings and are not Pedestal theme tokens.

Shopify Customer Account uses Helvetica Neue, a `#f6f6f6` page, and 12px fields. Using these tokens to redraw that host will miss.

There is no dark theme. `color-scheme` is `light`. The theme sheet has no `prefers-color-scheme: dark` rule and no `prefers-reduced-motion` rule.

No screenshot backs a coverage row. The CSS readings stand alone.

## Fonts

FK Display, weight 400, `font-display: swap`, file `9cf6bee7d34bec8e574c.woff2` on the shop CDN. Used for display titles. Fallback in the stack: Helvetica, Arial, sans-serif.

Suisse Intl, weights 400, 500, and 600, three woff2 files on the same CDN. Used for UI and body. Same Helvetica fallback.

Both are proprietary. They are not in this package. Body's own computed family, before a Suisse class, is the system sans stack. Tokens name the families the theme applies.

## Do and don't

- **Use FK Display for the big title and Suisse Intl for everything else.** The home hero, collection title, and product title are FK Display. Nav, buttons, fields, and captions are Suisse Intl. [tokens.json](tokens.json) `core.font.family`.
- **Keep the page near-white and the ink at `#212121`.** Body is `#fafafa`. Text is `#212121`. The blue `#0a4afd` is the one action colour. [tokens.json](tokens.json) `light.background.page`.
- **Make the primary action 74px tall with a 4px radius.** Add to cart and Send share that height. Nav chips are 2px radius and short. [components.md](components.md).
- **Do not invent a dark theme.** The sheet has none. The header turns white only because it sits on a dark hero image.
- **Do not restyle the Shopify account with these tokens.** That host is Helvetica Neue on `#f6f6f6`.
