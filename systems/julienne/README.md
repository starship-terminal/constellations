# Julienne design reference

A token set and component reference for Julienne's public signed-out site. Captured from withjulienne.com on 2026-11-18, signed out, in headless Chromium at 1440×900 and 390×844. Light is the boot theme (`html.js.light`). Dark is the header's own Toggle theme control (`html.js.dark`), verified before each dark shot.

Julienne is a recipe cookbook. The public site is a Vite and Tailwind app: a glass header, EB Garamond display type, Inter labels, and a wine-dark brand fill (`#3c1518`) on white paper. The signed-in cookbook, saving a recipe, cook mode, checkout and OAuth were not entered.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export julienne` prints them all with aliases resolved.

### Principles

1. Do set display type in EB Garamond.
2. Do put controls in glass pills.
3. Do use the wine fill for the one primary action.
4. Do keep the page paper-white in light and `#131313` in dark.
5. Don't submit the auth form or press Save, Cook or Buy.
6. Don't invent a status ramp.
7. Don't treat the cookbook line as an empty-state component of the signed-in app.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

Computed styles on the live signed-out pages, plus the product stylesheet `assets/index-19a84fdb.css`. Glass elevation comes from the declared `--glass-rim` and `--glass-lift` custom properties. ## What to distrust

Screenshots are 256-colour PNGs. Read colours from tokens.json. The home hero photos are lazy and can be blank in a viewport shot taken before they paint. The signup page shows "Security verification failed" because the Turnstile widget does not complete in headless Chromium. That banner is the widget's own failure, not a submitted form. Dark muted text `#a3a3a3` was entered by hand from the `dark:text-gray-400` class name, not read: it is Tailwind's neutral-400, not gray-400 (`#9ca3af`), and its source says Reconstruction. EB Garamond and Inter are not shipped in this package, and the style guide does not fetch them.

## Do and don't

1. **Do set display type in EB Garamond.** Home, recipe and team titles are the serif at 32px or 48px, weight 400. See [hero-title-default](components/crops/hero-title-default.png).
2. **Do put controls in glass pills.** Search and the theme toggle are 44px pills with a translucent fill and a hairline edge. See [search-glass-default](components/crops/search-glass-default.png).
3. **Do use the wine fill for the one primary action.** "See more recipes" and a selected filter are `#3c1518` with white type and 20px or pill corners. See [see-more-default](components/crops/see-more-default.png).
4. **Do keep the page paper-white in light and `#131313` in dark.** Dark is a real toggle, not a separate product. See [home-dark-default](screenshots/home-dark-default.png).
5. **Don't submit the auth form or press Save, Cook or Buy.** Those leave the public surface. The form in [signup-light-default](screenshots/signup-light-default.png) is at rest.
6. **Don't invent a status ramp.** The only status paint on the public site is the Turnstile failure banner, and that widget was not solved.
7. **Don't treat the cookbook line as an empty-state component of the signed-in app.** [cookbook-light-default](screenshots/cookbook-light-default.png) is the signed-out gate.
