# Glossier

A signed-out capture of the public Glossier shop at [https://www.glossier.com/en-sg](https://www.glossier.com/en-sg) on 2026-11-22. `https://www.glossier.com` resolved there. Desktop 1440 by 900. The page is white, type is Apercu, and the hero photograph is `#0500f5`. Buttons are 40px grey. Empty login and signup fields are 50px with a `#e8e8e8` border.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

| Role | Value | Where |

## Type

Apercu, then Gill Sans. Body 16px at weight 400. Nav 12px. Wordmark 32px, italic, weight 500. Hero heading 20px. Product title 32px at weight 500. Account title 32px at weight 400. Font files are not in this package.

## Controls

The shipping strip is 24px. The header is 40px. Shop now, Add to bag, Sign in, and Create an account are 40px with a square radius. Login and signup fields are 50px. Size chips are 34px.
