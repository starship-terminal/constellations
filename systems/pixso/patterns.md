# Pixso patterns

Public marketing site. The editor is behind login.

| Pattern | Where |
|---|---|
| App shell | Marketing header: logo, four hover menus, Pricing, Log in, Get started. Phone: logo, Log in, Get started, Open navigation menu. [screenshots/home-light-default.png](screenshots/home-light-default.png), [screenshots/mobile-home-light-menu-open.png](screenshots/mobile-home-light-menu-open.png). |
| Navigation menus | Product, AI design, Resources & learning, Enterprise. Each item is listed in [site-tree.md](site-tree.md). |
| Pricing | `/pricing/` seat comparison and plan comparison. CTAs that start a project go to login. Not followed. |
| Form | `/contact-us/` name, email, OS, browser, file link, upload, message. Shown empty. Not filled. Not submitted. |
| Login wall | `/user/login/` email and password, plus Google, NAVER, or SSO. Recorded and stopped. `/signin` is 404. |
| Search | Help center search field. Not typed into. |
| List | Articles index, tips index, community files, plugin index. One community file and one plugin detail captured. |
| Empty, loading, error, destructive confirm, toast, onboarding | Not captured. Not reached on the public site without submitting a form or signing in. |
