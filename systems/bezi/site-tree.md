# Bezi public site tree

Mapped from [https://www.bezi.com/](https://www.bezi.com/) on 2026-11-21 in headless Chromium (Playwright), desktop 1440×900 and phone 390×844, signed out. The start page is the marketing home. Nothing was typed, submitted, or downloaded. A control that opens a login or signup wall is recorded and that branch stops.

Bezi publishes one dark theme. The desktop header is a floating pill: logo, Studios, Product, Pricing, Blog, Docs, Discord, and Try for free. Hovering those links opens no menu. Phone hides the same links behind a hamburger that expands the pill into a drawer.
