# Rarible design reference

A token set and component reference for Rarible's public signed-out marketplace. It was read on **2026-11-19** from rarible.com in the T3 preview browser, signed out. `https://rarible.com/` redirected to `https://rarible.com/all`. Desktop was a measured **1440 x 900** (devicePixelRatio 2). Phone was a measured **390 x 844** (devicePixelRatio 2). Captured: explore, a collection (Yoodles Ovens), drops, terms, FAQ, the phone nav sheet, the search empty state, and the Login dialog. The dialog was closed. Nothing was submitted. No wallet was connected. Buy Now was not pressed.

Rarible declares a shadcn-style token layer. `:root` is light. `.dark` is the live theme (`body` has class `dark`). Channel triplets paint through `hsl(var(--name))`. UI type is **Geist Mono**. Display type is **Tomorrow**. The brand yellow is `#faff00` (`--brand`, `61.18 100% 50%`). The page is `#0a0a0a`. Login and Buy Now are yellow pills. **Boundary:** wallet methods, email submit, Buy Now, `og.rarible.com`, and `rwa.rarible.com` were not entered.

### Principles

1. Do paint the page `#0a0a0a` and the card `#09090b`.
2. Do set UI type in Geist Mono, and titles in Tomorrow.
3. Do make Login and Buy Now yellow pills.
4. Do use a white rounded button on explore heroes.
5. Do keep the phone nav as a bottom sheet.
6. Don't treat the PNGs as live screenshots.
7. Don't style a connected wallet, a buy, or a listing from this package.
8. Don't treat the Privy dialog as the marketplace chrome.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The T3 preview browser loaded rarible.com signed out. `preview_evaluate` read `getComputedStyle` and the stylesheets. Colour tokens are HSL channel triplets. Each dark name was painted as `hsl(raw)` on a `.dark` probe, and the probe's computed background was recorded as hex. Light names were painted the same way from the `:root` rule. A probe attached under `body.dark` inherits dark, so light was not read by removing the class from a child.

Component boxes were read on the live elements at 1440 x 900 and 390 x 844.

`preview_snapshot` failed once: "The browser is not producing screenshot frames." The PNGs in this package are reconstructions drawn from the measured boxes and colours. They are not live screenshots.

The live theme was dark. A live light theme was not switched. No theme control was on the public pages.

## What to distrust

The screenshots and crops are reconstructions. Positions and colours come from computed styles. The style guide uses the system mono for Geist Mono and uses Tomorrow only if the browser has it. Both families are loaded from rarible.com as woff2 and are not committed.

`:root --card-foreground` is declared `0 0% 100%` (white). On a white `--card` that pair does not read as text. It is the declaration. It is not a live light page.

Login yellow on the marketplace is `rgb(250, 255, 0)`. Privy Terms links computed `rgb(251, 255, 0)`. Both are recorded. Privy is a vendor dialog (system-ui, `#020713`) and is not the marketplace token set.

Focus on the search wrap set the ring colour to brand yellow and left the border at `#27272a`. Phone sheet Close, while focused, showed a `#d4d4d8` outer ring. Those are two different focus readings.

Chain-tab selection is opacity 1 versus 0.6, not a filled pill. Idle collection tabs use `rgba(255,255,255,0.6)`, which is not the same as `--muted-foreground` `#a1a1aa`.

## Fonts

| Family | Where | Licence |
|---|---|---|
| Geist Mono | Body, nav, buttons, search, cards, terms body | Loaded as woff2 from rarible.com. Weights seen: 400, 500, 700. Not committed. Tokens fall back to ui-monospace, SFMono-Regular, Menlo, monospace |
| Tomorrow | Hero titles, terms and FAQ titles, phone nav sheet links | Loaded as woff2, weights 400 and 700. Not committed. Tokens fall back to ui-sans-serif, system-ui, sans-serif |
| system-ui | Privy login dialog only | The vendor dialog's stack. Not the marketplace UI |

`Geist Mono Fallback` and `Tomorrow Fallback` are `local("Arial")` size-adjust faces. They are not the product faces.

## Do and don't

- **Do paint the page `#0a0a0a` and the card `#09090b`.** The live body and the item card computed those fills. [screenshots/collection-dark-default.png](screenshots/collection-dark-default.png)
- **Do set UI type in Geist Mono, and titles in Tomorrow.** Body, Login, and cards are Geist Mono. Hero, terms, and the phone sheet are Tomorrow. [screenshots/home-dark-default.png](screenshots/home-dark-default.png)
- **Do make Login and Buy Now yellow pills.** Both computed `#faff00` on `#18181b`, radius 9999px, height 36px. [components/crops/button-login.png](components/crops/button-login.png)
- **Do use a white rounded button on explore heroes.** Trade Collection is `#ffffff` on `#000000`, radius 8px. [components/crops/button-trade.png](components/crops/button-trade.png)
- **Do keep the phone nav as a bottom sheet.** At 390 it was `#0a0a0a`, radius `12px 12px 0 0`, over an 80% black overlay. [screenshots/home-dark-phone.png](screenshots/home-dark-phone.png)
- **Don't treat the PNGs as live screenshots.** `preview_snapshot` produced no frames. These files are drawn from the measured boxes.
- **Don't style a connected wallet, a buy, or a listing from this package.** Those controls were measured and not used. [screenshots/login-dark-dialog.png](screenshots/login-dark-dialog.png)
- **Don't treat the Privy dialog as the marketplace chrome.** It is system-ui on `#020713`. Marketplace type stays Geist Mono and Tomorrow.
