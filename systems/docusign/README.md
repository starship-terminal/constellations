# DocuSign design reference

A token set and component reference for DocuSign's public marketing site (https://www.docusign.com/). Use it to build a marketing page in that look: white page, ink `#130032`, accent `#4c00ff`, sand surfaces `#f8f3f0`, 8px control radius, and DS Indigo (Helvetica, Arial fallbacks). Captured signed out, in headless Chromium, desktop 1440 x 900 and phone 390 x 844, on 2026-11-21.

The signed-in product, trial, checkout, and account hosts are walls. Log in, Try for free, Buy now, and Plans & Pricing were recorded and not opened. Nothing was typed. No SSO control was used.

This package contains no DocuSign code, and none of its artwork has been redrawn. The screenshots belong to DocuSign ([docs/RIGHTS.md](../../docs/RIGHTS.md)).

## How the values were read

Computed styles were read on the live homepage in headless Chromium. The public site declared no CSS custom properties, so tokens come from `getComputedStyle`, not from a token stylesheet. Screenshots were taken by [tools/capture/public/map-site.mjs](tools/capture/public/map-site.mjs) and quantised with the kit's `quantize.py`.

## What to distrust

- **No signed-in product.** apps.docusign.com, trial.docusign.com, ecom.docusign.com, and account.docusign.com were not used. Buttons on those walls are not in this package.
- **No dark theme was painted.** Do not invent one.
- **Hover and pressed colours are Not captured.** The default, and the focus outline `#005fcc`, were read. Hover and pressed were not held.
- **Body line-height was the keyword `normal`.** The 24px body line height is Derived.
- **Screenshots are 256-colour PNGs.** Read colours from tokens.json.
- **DS Indigo is a commercial webfont.** It is named, not bundled.

## Fonts

- **DS Indigo** is the painted family on body, headings, and buttons, with Helvetica and Arial as fallbacks. It is not loaded here.
- No mono family was measured on the public chrome.

## Do and don't

1. **Do use ink `#130032` on white.** Body text and the Get Started fill share that colour. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
2. **Do use `#4c00ff` for the primary action.** Try for free is that fill with white type. Contact sales is the same hue with no fill. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
3. **Do set controls to an 8px radius.** Nav CTAs and the email field use 8px, not a pill. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
4. **Do set display type light and large.** The homepage h1 is 80px, weight 300, line-height 86.4px. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
5. **Don't style the signed-in product from this package.** Log in, trial, and checkout were walls.
6. **Don't invent a dark theme.** The captured routes painted light.
