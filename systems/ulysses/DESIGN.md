# Ulysses public tokens

Hand-written from measured CSS on https://ulysses.app/en/ on 2026-11-22. `catalog.json` was not edited, so this file was not regenerated by `make design-md`.

## Colour

| Role | Value | Source |
|---|---|---|
| Page | #ffffff | Computed document body |
| Ink | #27272b | Computed body color |
| Footer | #262626 | Computed footer on the pricing page |
| On footer | #ffffff | Computed footer color |
| Accent | #ffcc00 | Computed Log In submit border |
| Field | #f7f7f5 | Computed empty email field |
| Focus | #ffe680 | Computed focused email border |

`:root` also declares a Bootstrap set. `--primary` and `--yellow` are `#fc0`. `--light` is `#f7f7f5`. `--dark` is `#27272b`. Those names are in [raw/home-computed.json](raw/home-computed.json). The tokens use the computed paint, not the unused blues.

## Type

Interstate for marketing UI and headings. The home h2 paints 48px, weight 700, line-height 57.6px, ink on white. The first home h1 paints 48px, weight 700, line-height 49.92px, white over a product photograph. Body is 15px, weight 400, line-height 24px. The login title paints 30px, weight 700. The font files are licensed and are not in this package.

## Radius

Login fields and the Log In submit paint 3px.

## What this file does not claim

Hover, pressed, disabled, and dark theme were not measured. The writing app is native. The volume-licensing wall is a separate host. Checkout was not entered.
