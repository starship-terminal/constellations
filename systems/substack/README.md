# Substack design reference

A token set for Substack's public site, for a dark discovery home or a light marketing page. It was read from **substack.com** on **2026-11-21**, signed out, in headless Playwright at 1440 x 900 and 390 x 844. The logged-out home, Explore, and the sign-in page paint dark (`html.dark-mode`). About, a public post, and Privacy paint light. There is no public theme toggle.

This package already held an iOS capture from 2026-10-24. This refresh replaces that surface with the public web site. The slug on origin/main is `substack`. catalog.json was left alone, so the catalog entry still describes the iOS capture.

Login and signup were photographed empty and not entered. Nothing was typed. No identity provider was clicked. No form was submitted. No subscribe control was followed. The email placeholder is the product's own "Email" or "Your email".

## How the values were read

Playwright opened the public pages. Custom properties were read from the sign-in stylesheet (`css/65979` on substackcdn.com), which declares the pencraft primitives and the `.dark-mode` overrides. Component sizes and colours were also read with `getComputedStyle` on the live elements. The computed colours come back as `color(display-p3 ...)`. The tokens use the sRGB channels the stylesheet names for the same roles (`rgb(22, 23, 24)` for the dark page, `rgb(255, 103, 25)` for orange). Screenshots were quantised to 256 colours after the values were read.

## What to distrust

- `light.disabled` and `light.disabledBg` were not isolated. The disabled Continue was only seen on the dark signup wall.
- Success and warning colours are named in the stylesheet and were not seen on a public control.
- The About hero font, Cahuenga, is a computed family. The file is not in this package.
- A publication Subscribe button uses that publication's colour. The post captured here uses gold (`rgb(186, 160, 73)`), not Substack orange.
- Spacing and motion durations were not declared as a scale on these pages. They are not in the tokens.
- The homepage sign-in dialog's email field showed a blue focus ring because the field was focused when the dialog opened. That is the focus state, not the resting border.
- Crops are 1x. The older iOS crops were 2x.

## Do and don't

- **Use one orange for Substack's own actions.** Start your Substack, Start publishing, and Continue are the same orange. A publication's Subscribe button is that publication's colour. [home-dark-default.png](screenshots/home-dark-default.png)
- **Keep Sign in quiet.** It is text beside the orange pill, on the home and on About. [about-light-default.png](screenshots/about-light-default.png)
- **Paint the logged-out home dark and About light.** The home has no theme toggle. [home-dark-default.png](screenshots/home-dark-default.png)
- **Set marketing headlines in a serif and controls in the system sans.** The About hero is Cahuenga. Buttons are system-ui. [about-light-default.png](screenshots/about-light-default.png)
- **Leave Continue disabled until the terms box is checked.** The signup wall shows that state with the box unchecked. [signup-dark-default.png](screenshots/signup-dark-default.png)
