# 37signals design reference

A token set for the public 37signals marketing site, for a full-bleed colour page set in Lab Grotesque. It was read from **37signals.com** on **2026-11-21**, signed out, in headless Playwright at 1440 x 900 and 390 x 844.

This is a first capture. origin/main had no `systems/37signals/`. catalog.json was left alone. login-extracted stays not-started.

There is no login wall and no signup wall on this domain. `/login`, `/sign-in`, `/signup`, and `/account` render "Page not found". The jobs page has an empty notify form. Nothing was typed. The form was not submitted. No identity provider was clicked. Basecamp, HEY, and Campfire were not captured.

The page colour is random. `theme.js` picks one of twelve `--rgb-theme-*` values per visit. Screenshots pin theme 3 (`139, 119, 255`). The podcast at `/podcast` is a separate white site and was not recolored.

## How the values were read

Playwright opened the public pages. Custom properties were read from `root.css` (`--rgb-theme-1` through `--rgb-theme-12`, `--font-family`, `--spacing`, `--transition`). Component sizes were read with `getComputedStyle` at 1440. Body size is `calc(1em + 1vw)`, so 34.4px at that width. Screenshots were quantised to 256 colours after the values were read.

## What to distrust

- The page colour in a live visit is not theme 3. The twelve values are in tokens.json. The screenshots are pinned so they match each other.
- Quantised PNGs shift the page by about one channel (`138, 118, 255` instead of `139, 119, 255`). Read colours from tokens.json.
- `/podcast` uses Jost and Crimson Pro on white. Those families are not in the tokens.
- The jobs Sign up button fill is the current theme, so it disappears into the page until the white pill frames it.
- Focus on the email field computed no ring. That may be the browser default being suppressed. It was not isolated as a token.
- Spacing is `0.75em`, not a px scale. It moves with the fluid type size.
- The email placeholder `julie.young@hey.com` is the product's sample text. The field was empty.

## Do and don't

- **Paint the page in one theme colour, edge to edge.** Text is white. There is no card chrome around the essay. [home-light-default.png](screenshots/home-light-default.png)
- **Expect the colour to change on the next visit.** Twelve colours, chosen in `theme.js`, skipping the one stored for the session. [tokens.json](tokens.json)
- **Set type in Lab Grotesque, fluid with the viewport.** Body is `calc(1em + 1vw)`. [signal-00-light-default.png](screenshots/signal-00-light-default.png)
- **Keep the header and footer fixed and quiet.** Product names on the left, wordmark on the right, footer links along the bottom. [not-found-light-default.png](screenshots/not-found-light-default.png)
- **Use a white pill for a quiet action and a theme-filled pill for Sign up.** Both use radius 1.3em. [signup-form-empty.png](components/crops/signup-form-empty.png)
- **Open the phone menu as a white drawer.** Desktop has no hamburger. [mobile-home-light-menu.png](screenshots/mobile-home-light-menu.png)
