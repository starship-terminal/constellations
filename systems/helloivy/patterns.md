# Hello Ivy patterns

Public pages only. The control map is [site-tree.md](site-tree.md).

## Marketing shell

Every `www.helloivy.co` page shares a cream page, an SVG wordmark, text links on desktop, a black pill, and a menu icon. Phone keeps the wordmark and the menu icon. A "hi / Try it for free" pill stays at the bottom right. It is a link. See [home-light-default](screenshots/home-light-default.png) and [mobile-home-light-default](screenshots/mobile-home-light-default.png).

The home page is one long article. Product videos play in the page. The play control did not open a dialog.

## Menu overlay

The menu icon opens a full overlay, not a dropdown. Numbered links go to home, features, pricing, about, and blog. A trial pill sits in the overlay. Close returns to the page. See [home-light-menu](screenshots/home-light-menu.png).

## Feature and docs indexes

Features is a card index. Each card is a link to one feature article. Docs is a help index with a sidebar and a search field. Search was not opened. See [features-light-default](screenshots/features-light-default.png) and [docs-light-default](screenshots/docs-light-default.png).

## Pricing

A display headline, then plan cards. "Try for Free" goes to the signup wall. There is no billing toggle and no FAQ accordion on the page that loaded. See [pricing-light-default](screenshots/pricing-light-default.png).

## Login wall

`https://app.helloivy.co/login` asks for email and password, or Google. Forgot password and Sign up are links. The branch stops there. See [login-light-default](screenshots/login-light-default.png) and [mobile-login-light-default](screenshots/mobile-login-light-default.png).

Signup redirects to a teams query on the same host. It was not filled.

## Off-site CTA

Several controls leave for complex.so. That is a hop, not a Hello Ivy screen.

## Not captured

Signed-in app shell, onboarding, empty, loading, and error states of the product, destructive confirmation, and any submitted form.
