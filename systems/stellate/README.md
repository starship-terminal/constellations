# Stellate

Stellate (stellate.co) is a GraphQL edge cache and metrics product, now part of The Guild. This package records the public marketing site, pricing, docs, and the signed-out login and signup chrome, measured on 2026-11-19 from a live T3 preview tab. Signup was an email field. Submitting it sent a magic link. The magic link was not opened. GitHub and GitLab were not followed. No card was entered.

The live CSS viewport was 1169 by 731 at devicePixelRatio 2. Marketing pages stay on a grey page when the system colour scheme is dark. Docs follow the system scheme: dark page `#18181b`, light page `#fafafa`.

1. Use the grey marketing page.
2. Use 8px radius colour buttons for the product actions.
3. Keep signup as an email field.

## How the values were read

Colour classes were read from the Next.js stylesheet `a9a11ad3660297e7.css` on https://stellate.co/. Component colour, type, radius, padding and size were read with `getComputedStyle` on the live elements. Docs `lab()` colours were converted to hex by filling a 1 by 1 canvas in that same page. Docs light values were read after `preview_set_appearance` set `prefers-color-scheme: light`. Dark was set again afterwards. Marketing did not change with that setting.

The preview browser returned "The browser is not producing screenshot frames" on `preview_snapshot`. No screenshots were invented. Headless Playwright was not launched.

## What to distrust

The CSS viewport was 1169, not 1440 and not 390. Do not treat these readings as a 1440 or 390 capture. The cookie banner buttons computed `font-family: Times`. That is the cookie widget, not the marketing face. Marketing type is TT Commons. Docs type is `ui-sans-serif`. The email confirmation prints the address in uppercase. That address is the capture inbox, not a design token. Hover colours are declared in the stylesheet (`#3e6ec1`, `#f3446a`, `#f85b30`) and were not shown. Screenshot folders are empty on purpose.

## Fonts

TT Commons is the marketing face, a variable font from 100 to 950, with a local Arial fallback named `ttCommons Fallback`. Fira Code is the marketing mono face, weights 400 and 500. Docs use `ui-sans-serif` and `ui-monospace`. The magic-link email declares Gotham. These families are named as computed or declared. The font files are not in this package.

## Do and don't

- **Use the grey marketing page.** Home, pricing, login and signup render on `#f8fafc` with `#283448` headings and `#3b4c6a` body text. [patterns.md](patterns.md) describes that shell.
- **Use 8px radius colour buttons for the product actions.** Caching is blue `#608bd8`, Metrics is magenta `#ff6b8b`, Security is red `#ff7752`, and the header start button is gray `#dbdfe7`. [components.md](components.md) lists the sizes.
- **Keep signup as an email field.** https://stellate.co/signup asks for an email, plus GitHub and GitLab. Submitting the email sends a magic link. Do not invent a password form or a signed-in dashboard. [components.md](components.md) records the gap.
- **Use TT Commons on marketing and the system sans on docs.** The two shells do not share a face. [tokens.json](tokens.json) keeps both.
- **Do not invent a 1440 screenshot.** The preview browser produced no frames. [screenshots/](screenshots/) says so.
