# Microsoft Copilot

Public signed-out marketing and product pages for Microsoft Copilot, captured on 2026-11-19 from https://copilot.com/ (https://copilot.microsoft.com redirects there). No account was signed in. The live page set `html[data-cc-theme=dark]` on its own. A second pass used `prefers-color-scheme: light`, which cleared that attribute. Desktop captures are 1440x900 CSS pixels at device pixel ratio 1. The phone capture is 390x844 CSS pixels at device pixel ratio 2 (PNG 780x1688).

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export microsoft-copilot` prints them all with aliases resolved.

### Principles

1. Use the dark page colour `#1f1f1f` and the white pill button.
2. Set hero type in a serif and section titles in a sans.
3. Keep cards at 24px radius and tabs as pills.
4. Do not treat the Microsoft account blue `#0067b8` as a Copilot accent.
5. Do not invent a chat transcript from the marketing cards.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Computed styles were read in headless Chromium (Playwright) on https://copilot.com/ after a probe confirmed the page returned 200 and was not a Cloudflare challenge. The same page was also opened in the T3 preview browser, which redirected to copilot.com and rendered the signed-out marketing page. Stylesheets were fetched from `res.cdn.office.net` (`unauth-copilotcom-164a413b4f.css`, `unauth-eb70fa2b07.css`, `sharedfontstyles-64054f9286.css`). The Microsoft universal-header sheet is cross-origin and was not readable from the CSSOM. Custom properties on the page are mostly header overrides (`--uhf-*`, `--cc-badge-*`), not a full token ramp. Component colours come from computed styles and from `html[data-cc-theme=dark]` rules in the Copilot sheet. Motion was read with `tools/capture/motion-probe.mjs` on copilot.com and copilot.com/download. Pressed state on the primary button used CDP `CSS.forcePseudoState` and did not click the link. Nothing was typed or submitted.

## What to distrust

Screenshots are 256-colour PNGs. Read colours from [tokens.json](tokens.json). The hero font size is `clamp(52px, 5vw, 72px)`; the 1440 capture computed 72px, and an earlier 1169-wide preview computed 58.45px. Page gutters are 5 percent, so the 58px space token is the 1440 reading, not a fixed padding. Light semantic tokens cover only what the light pass or the light sheet declared. The lilac link colour `#9e9eff` was measured on `.module-actions` in dark only. Download and cowork pages did not set `data-cc-theme`, so their screenshots are not the same dark sheet as the home page. The pricing URL redirected to a Singapore Microsoft 365 Copilot pricing page with its own sheet. The sign-in card is Microsoft account chrome (`#0067b8`), not the Copilot marketing buttons.

## Fonts

Segoe Serif Display is the hero face (Georgia fallback). Segoe Sans and Segoe UI are the UI faces (Helvetica, Arial fallback). The Microsoft header uses Segoe UI. These are Microsoft fonts, not committed. The sign-in card uses Segoe UI Webfont.

## Do and don't

- **Use the dark page colour `#1f1f1f` and the white pill button.** The public page paints that pair in [screenshots/home-dark-default.png](screenshots/home-dark-default.png) and [components/crops/button-primary-default.png](components/crops/button-primary-default.png).
- **Set hero type in a serif and section titles in a sans.** The hero is Segoe Serif Display and the section title is Segoe Sans, in [components/crops/heading-hero.png](components/crops/heading-hero.png) and [components/crops/heading-section.png](components/crops/heading-section.png).
- **Keep cards at 24px radius and tabs as pills.** Both are in [components/crops/card-default.png](components/crops/card-default.png) and [components/crops/tab-selected.png](components/crops/tab-selected.png).
- **Do not treat the Microsoft account blue `#0067b8` as a Copilot accent.** That colour is the sign-in Next button in [components/crops/button-next-default.png](components/crops/button-next-default.png).
- **Do not invent a chat transcript from the marketing cards.** The cards are links off the site. The chat was not opened.

## Sign-in gap

https://copilot.com/login redirects to login.microsoftonline.com and asks for a personal Microsoft account, or Google or Apple. The capture did not create an account, type an email, or submit the form. The public page is the package.
