# Wix

Wix's public marketing site and the signed-out login, measured on 2026-11-18. The homepage, the pricing page, and the email login were read in a light theme at 1440 by 900. The login page was also read at 390 by 844. No account was created. The email form was not submitted.

The public Wix Design System docs (v1.352.0) were read for the foundation palette and the motion guide. Those docs describe the app UI, and the marketing site paints a different blue. Both are stored, and the README says which is which.

Screenshots were not taken. The preview browser returned "The browser is not producing screenshot frames" on both attempts. No image was invented.

### Principles

1. Paint the header button at 42px radius.
2. Keep the marketing page light.
3. Use black for marketing text and `#000624` for the account form.
4. Leave the email form unsubmitted in a capture.
5. Do not mix the three blues.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Computed styles were read in the T3 preview browser on the live pages. Custom properties on `:root` were resolved with `getComputedStyle`. The header Product menu was opened with a click. Focus was read from `document.activeElement` after `focus()`.

The Wix Design System colour table was read from the public Colors page as name and value cells. Semantic tokens that alias a foundation name are stored as aliases. Transparent steps and gradients were read and left out of `tokens.json`.

## What to distrust

The header "Start for free" button paints `#166aea`. The token `--wst-button-color-fill-primary` resolved to `#1a6aff` on the same page. Both are stored. Use the painted value for the marketing header.

The login button paints `#2f5dff`. The design-system blue-100 is `#116dff`. They are different products. The login page is the account form. The design-system page is the app kit.

Font-weight 530 on Continue with Email is the computed value. It is not a CSS keyword.

Motion easings stored as cubic beziers are the CSS keywords `ease`, `ease-in-out`, and `linear` expanded to their control points. The page's own `cubic-bezier()` values were truncated by the reader and are not stored.

There is no dark set. A dark preference left the homepage light.

## Fonts

The marketing page computed `wix-madefor-display-v2` and `wix-madefor-text-v2`. The header chrome computed `Madefor-Display` and `Madefor-Text`. The login page computed `Madefor` and `Madefor Display`. Wix publishes Madefor as an open-source family. The files are not in this package. Fall back to Helvetica Neue, Helvetica, Arial, sans-serif, which is the rest of the login stack.

## Do and don't

- **Paint the header button at 42px radius.** "Start for free" is a pill, 8px by 30px, `#166aea` with white type. The black "Get Started" pill is a different control, 50px radius and 20px type.
- **Keep the marketing page light.** A dark preference did not switch the homepage. Do not invent a dark marketing theme.
- **Use black for marketing text and `#000624` for the account form.** The login h1 and the email input computed `rgb(0, 6, 36)`. The homepage h1 computed `rgb(0, 0, 0)`.
- **Leave the email form unsubmitted in a capture.** Continue with Email is a submit. This package stopped on the empty field.
- **Do not mix the three blues.** Header `#166aea`, token `#1a6aff`, login `#2f5dff`, plans `#101585`, design-system `#116dff`. Each was measured on a different surface.
