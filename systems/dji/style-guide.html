DJI, measured

Every value on this page is a CSS custom property generated from tokens.json: the declared token layer in DJI's v3 bundles (the --grey-0..12, --black-*, --white-* and --brand-1..10 scales, the :root .light-theme/:root .dark-theme semantic roles, and the --spacing-*/--zindex-*/--grid-* layout vars), the measured type ramp, and the #0070d5 DJI blue. The real pixels are in screenshots/ and components/crops/.

Read from dji.com's geo-locale /sg site on 2026-11-15, signed out, in headless Chromium. Sections opt into light or dark paint through the product's own .light-theme/.dark-theme classes — nav, listings and support paint light; the hero, product dark panels and footer paint dark, so both themes are real paint. The store and member services gate on a DJI account — the Store, Buy Now and search controls were measured, never pressed. Open Sans and the Dji icon face are served faces and are not loaded here: samples fall back to system fonts.

Palette

The declared layer carries the hue scales under color.* (brand, grey, black, white, bg, green, orange, red, background) and the section-scoped semantic roles (--primary/--secondary/--tertiary, --bg/--light-bg, --border/--divider/--disabled, the inverted --reverse-* pair, --brand-primary-*/--brand-text-* and the status roles) resolved per section theme — .light-theme on the listings, .dark-theme on hero/product/footer sections, both measured paint. Measured roles alias the declared values they match.

Spacing and radius

The declared radius is a single 16px --radius; the CTAs are true pills (60px ghost, 64px hero, 1408px Store — the last is height*44, i.e. fully rounded). Dividers are black@6% on light and white@12% on dark; borders black@15% / white@20%. The grid is 1200px wide with a --grid-gap and --col-width/--column-count pair.
