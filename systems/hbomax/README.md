# HBO Max design reference

A token set and component reference for HBO Max's public marketing site — for building dark, cinematic streaming surfaces in the style of the real thing. It was read from **www.hbomax.com** on **2026-11-17** (see the capture sidecars for the exact times), signed out, in headed Chromium under Xvfb at 1440 x 900 and 390 x 844: the home page in the `/sg/en` locale (consent modal, hero carousel advanced by its own Next arrow, the yearly billing toggle, an open FAQ item and the full page), the movies and series browse pages, a channel hub, series and movie detail pages, a genre collection, the sitemap, corporate information and the privacy policy, plus the mobile captures of home, movies and the series page.

HBO Max is worth a capture because it is a current reference for the streaming-marketing surface: a near-black ground under a translucent gradient navbar, a full-bleed autoplay hero carousel with white pill CTAs, low-alpha plan cards behind a billing toggle, a hairline-ruled FAQ accordion, and — unusually — the product's own design-token stylesheet (`/dotcom/generated/css/ds/hbomax/design-systems.*.css`) declaring the whole system in the open: 379 `--color_*` semantic colour roles (action, card, captions, component, general, indicator, input, scrim, surface, tile, utility), 528 `--spacer-*` spacing dimensions, 448 `--border-*` corner/stroke widths and a 434-name `--font_*` type scale, each redeclared across seven breakpoints (`-bp-01..07`, the 440/600/800/1100/1400/1800px steps).

## Brief

### Principles

1. Do ground on pure black.
2. Do use the monochrome action recipe.
3. Do let backdrop art carry the page.
4. Do set everything in Max Sans.
5. Don't invent a light theme.
6. Don't spread colour.
7. Don't flatten the chrome.
8. Don't read the legal pages for palette.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

`hbomax.com` redirects to `www.hbomax.com`, which serves the marketing site in the visitor's locale — the capture host resolved to Singapore, so every page here is `/sg/en` (title "HBO Max | Stream Series and Movies", canonical www.hbomax.com, geo headers `countryCode=SG`). Akamai's edge returns a 403 "Access Denied" page to headless Chromium, so every capture ran **headed Chromium under Xvfb** — the standard headed route, not a workaround; no other client shape was tried. All values came off the running signed-out site:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) captured every stylesheet body from the live load (the `/dotcom/generated` bundles arrive same-origin), re-parsed them, and wrote every custom property to [raw/css-vars.json](raw/css-vars.json) binned `theme`/`app` — the token sheet declares on `:root` (the 379 `--color_*` roles), `.spacer-tokens` (528 `--spacer-*`), `.border-tokens` (448 `--border-*`) and `.font-english-like-slate3` (434 `--font_*` size/line-height pairs), each name redeclared per breakpoint media query. Each name is resolved in a probe carrying the real sheets and the live page's own `<html data-theme="max">` classes at 1440px. [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec [raw/component-tokens.json](raw/component-tokens.json) that [tools/build_tokens.py](tools/build_tokens.py) renders — `--color_*` under `dark.color.*` (the only painted theme), the scales under `core`.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state, plus `opened` on the carousel Next arrow, billing toggle, FAQ chevron, language selector and mobile menu. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md).
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and bounded full-page shots per route — the consent modal left up for `-promo`, then hidden without accepting or rejecting — with `.capture.json` sidecars; [tools/capture/quantize.py](tools/capture/quantize.py) stitches the tall pages and posterises to 256 colours for the repo.
- **Icons.** [tools/capture/icons.mjs](tools/capture/icons.mjs) collects every distinct inline `<svg>` across the pages into [icons/](icons) with the index in [icons/INDEX.tsv](icons/INDEX.tsv).
- **Layout.** [tools/capture/layout.mjs](tools/capture/layout.mjs) measures the shell geometry — sticky elements, grids, max-widths, inner scrollers — at 1440/1920/1024/390 into [raw/layout.json](raw/layout.json).
- **Fonts.** The token sheet's `@font-face` is **Max Sans** (woff2, weights 300/400/600, `font-display: swap`), recorded in [raw/css-vars.json](raw/css-vars.json) `fonts` — proprietary to Warner Bros. Discovery and not committed; the body computes `Max Sans,Inter,sans-serif,-apple-system,…`.

Nothing was signed into, bought, subscribed or submitted. The only presses were local UI toggles the page's own chrome provides: the hero carousel's Next arrow, the monthly/yearly billing toggle, an FAQ chevron, the language selector and the phone's menu button. "Sign In", "Start Subscription" and every plan "Choose" button point at `auth.hbomax.com` and were measured, never followed.

## What to distrust

- **One painted theme.** Every captured route ships `<html data-theme="max">` — a dark surface is the only variant the bundle declares, and there is no theme control anywhere. The semantic colour set is emitted under `dark` (the bezi/spotify convention for a single painted dark surface); no light set is inferred.
- **The locale is Singapore.** `www.hbomax.com` geo-resolves; from this host that is `/sg/en`. Plan names, prices (S$) and catalogue rails are the SG catalogue — the token architecture is locale-independent, the content is not. `max.com` (the U.S. branding) was never probed from this host.
- **Breakpoint variants.** Every scale token exists seven times (`-bp-01..07`); the resolved values in tokens.json are read at 1440px — bp-05. Steps that differ per breakpoint keep all seven declarations in [raw/css-vars.json](raw/css-vars.json); tokens.json emits each as its own `*.bpNN` token.
- **`component.*` tokens and `dark` role anchors are measured**, not site variables — the `--color_*` set is the site's own semantic layer, the page/nav/accent roles beside it are cross-check anchors measured on the painted chrome.
- **Akamai blocks headless.** The 403 to headless Chromium is an access constraint, documented — it means the capture ran headed under Xvfb; it does not mean the site requires a workaround.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs; read exact colours from tokens or the raw JSON.
- **Roles the builder maps but the capture never produced.** The builder read the `borderRadius` shorthand, which the capture never records, so `component.control.radiusCta` was missing; it now reads the corners (8px). These mapped rows still yield no token, and the build prints them: `dark.page` (the navbar records no painted ancestor), `dark.link` (footer-link was not captured), `dark.focus` (header-nav-link was not captured), `component.footer.height` and `component.card.radius` (footer and plan-card were not captured), `component.dialog.radius` (the consent dialog measures 0px), and `dark.measured.ctaPress` (the hero CTA's pressed reading is an error, so no pressed fill was read).

## Fonts

Declared in `raw/css-vars.json` (`fonts`): **Max Sans** in weights 300, 400 and 600 — the only family the token sheet serves. The webfonts are proprietary and not committed; the style guide renders the system fallback.

## Blocked surfaces (boundaries, never faked)

- **auth.hbomax.com** — sign-in, account creation, plan checkout. Every CTA pointing at it (Sign In, Start Subscription, Choose) was measured, never followed.
- **play.hbomax.com** — the streaming app requires an account; never opened.
- **help.hbomax.com** — a separate help-centre site linked in the footer; never opened.
- **Headless Chromium** — Akamai's edge answers 403 "Access Denied"; documented as the access constraint that pushed every capture onto the headed Xvfb route.
- **Other locales** — only `/sg/en` loaded from this host; other region/locale pairs were not probed.
- **`mobile-movies`** — the first mobile pass lost the default shot to a screenshot timeout; an incremental rerun retook it and the `-full` shot, so both are present.

## Do and don't

1. **Do ground on pure black.** The page is `#000000` (`dark.color.surface.low`); raised surfaces step to `#0f0f0f`/`#191919`, never gray-on-gray. See [home-dark-default](screenshots/home-dark-default.png).
2. **Do use the monochrome action recipe.** The primary button is a white pill (`#ffffff`, `dark.color.action.primary.fill.high`) with black text — Sign In, Start Subscription, Choose and Accept all share it. See [hero-cta-default](components/crops/hero-cta-default.png) and [plan-choose-default](components/crops/plan-choose-default.png).
3. **Do let backdrop art carry the page.** Heroes and detail pages are full-bleed imagery with text laid over a scrim; chrome is translucent (`rgba(0, 0, 0, 0.7)` navbar). See [detail-hero-default](components/crops/detail-hero-default.png) and [header-bar-default](components/crops/header-bar-default.png).
4. **Do set everything in Max Sans.** One family, weights 300/400/600, across the whole marketing surface — the `--font_*-slate3` scale is the type ramp. See [faq-item-default](components/crops/faq-item-default.png).
5. **Don't invent a light theme.** `<html data-theme="max">` paints dark on every route and there is no theme control; the token sheet ships one colour set. See [shows-dark-default](screenshots/shows-dark-default.png).
6. **Don't spread colour.** The painted palette is monochrome — saturated hues live only in indicator roles (`color.indicator.*`: commerce blue `#71b8f2`, live, sport), not on surfaces or CTAs. See [home-dark-plan-yearly](screenshots/home-dark-plan-yearly.png).
7. **Don't flatten the chrome.** The navbar stays translucent over art and the language selector is a `rgba(62, 62, 62, 0.75)` glass pill — alpha, not solid fills. See [lang-selector-default](components/crops/lang-selector-default.png).
8. **Don't read the legal pages for palette.** `/privacy` is a separate light Arial surface (white on `#f1f1f1`, `rgb(32,33,36)` text) with its own stylesheets — its values are component evidence, not token-sheet evidence. See [privacy-dark-default](screenshots/privacy-dark-default.png).
