# Orchids design reference

Tokens and component notes for Orchids, captured **2026-11-19**. Desktop shots are 1440×900. Phone shots are 390×844. The docs site has light and dark. Signed out the whole time.

Orchids is an AI app builder. On this date `orchids.app` and `www.orchids.app` return Vercel's paused-deployment page (`DEPLOYMENT_PAUSED`, HTTP 503) for home, login, signup, pricing, blog, and careers. The live designed surface is the public docs at docs.orchids.app, a Mintlify site. Nothing was signed into. No email was submitted. Start a Project was not followed, because it points at the paused host.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export orchids` prints them all with aliases resolved.

### Principles

1. Do paint docs on `#ffffff` in light and `#0e0c0c` in dark.
2. Do use `#fcaa26` as the only accent.
3. Do keep the primary action as amber text, not a filled button.
4. Do draw Copy page as a 12 px split control, 34 px tall.
5. Don't invent a marketing homepage.
6. Don't treat the Vercel 503 colours as the product accent.
7. Don't follow Start a Project into a signup.
8. Don't ship Paper Mono.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

docs.orchids.app declares RGB triplets on `:root`: `--primary` (252 170 38), `--primary-light` and `--primary-dark` (the same triplet), `--background-light` (255 255 255), `--background-dark` (14 12 12), and `--gray-50` through `--gray-950`. `html` carries `dark` or `light`. Those names were read as computed custom properties on `/` in both themes. Light was read after clicking Switch to light theme.

Component colours were read with `getComputedStyle` on `/` (Start a Project, search, current sidebar link, Copy page, theme switch, feature card) and on `/plans-and-token-usage` (plan cards, table, code). The search dialog was opened empty and closed. Screenshots were taken in headless Chromium at 1440×900 and 390×844, device pixel ratio 2, then quantised to 256 colours. The public docs loaded without a Cloudflare challenge.

The T3 preview browser opened orchids.app, www.orchids.app, the joining-Figma blog URL, and docs.orchids.app, and could read the DOM. It did not produce screenshot frames (`The browser is not producing screenshot frames`). The shots in this package are from headless Chromium on the same public URLs.

The paused page at www.orchids.app was measured in the preview browser. Its colours are Vercel's, stored under `core.color.paused`, and are not the product accent.

## What to distrust

The marketing site and the signed-out login are not in this package. orchids.app is a paused Vercel deployment, so home, pricing, blog, login, and signup were not the product's UI.

Start a Project is an amber text link, not a filled button. There is no filled primary control on the captured pages.

The plan cards use `bg-white/5` and `border-white/10`. In the light theme that fill is nearly invisible. The screenshot shows the type. The computed background is still `rgba(255, 255, 255, 0.05)`.

Search-dialog measurements were taken after a click, with an empty field. No query was typed.

oklab() and oklch() values are the computed colours the browser returned. They are not converted.

The header pixel sample on the light screenshot is `#f8f7f7`. The nearest declared token is `--gray-50` (`#faf8f4`). `light.raised` uses the declared token.

Focus on the current sidebar link computed as `outline: rgb(252, 170, 38) none 3px`. The outline style was `none`, so a visible ring was not painted in that read.

## Fonts

Inter is the docs sans, named in `--font-inter` and loaded from the site's own woff2. The tokens fall back to `ui-sans-serif, system-ui, sans-serif`. Paper Mono is named in `--font-paper-mono` and was computed on the pricing code sample. It is not shipped here. The paused page uses SF Pro Text. That face belongs to the Vercel error page.

## Do and don't

- **Do paint docs on `#ffffff` in light and `#0e0c0c` in dark.** The page background is those two computed values. [screenshots/docs-home-light-desktop.png](screenshots/docs-home-light-desktop.png)
- **Do use `#fcaa26` as the only accent.** Start a Project and the current sidebar link are that amber in both themes. [components/crops/link-accent-light.png](components/crops/link-accent-light.png)
- **Do keep the primary action as amber text, not a filled button.** The captured site has no filled primary face. [components/crops/link-accent-dark.png](components/crops/link-accent-dark.png)
- **Do draw Copy page as a 12 px split control, 34 px tall.** [components/crops/button-copy-light.png](components/crops/button-copy-light.png)
- **Don't invent a marketing homepage.** orchids.app is paused. [screenshots/paused-light-desktop.png](screenshots/paused-light-desktop.png)
- **Don't treat the Vercel 503 colours as the product accent.** The paused link is `#0070f3`.
- **Don't follow Start a Project into a signup.** It points at the paused host. No email was entered.
- **Don't ship Paper Mono.** It is named and not included.
