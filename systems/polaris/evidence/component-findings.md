# Polaris component styling findings

Source: archived `Shopify/polaris-react-archive` at [`3f7954ae42fabf26d63cee68c23ceebfd7ef0972`](https://github.com/Shopify/polaris-react-archive/tree/3f7954ae42fabf26d63cee68c23ceebfd7ef0972). These are source rules for that commit, not a claim that a gallery using another published React package version renders identically. Token names below are the exact CSS variables or component prop values in the archive. Component CSS contains PostCSS mixins, so the authored CSS is not a standalone stylesheet.

## Actions and status

**Button.** `secondary` is the default variant and `medium` the default size; the other variants are `primary`, `tertiary`, `plain`, and `monochromePlain`, with `success` and `critical` tones. Primary uses the brand fill gradient, brand on-fill text, and primary button shadows; secondary uses `--p-color-bg-fill` plus its hover/active tokens and `--p-shadow-button`; tertiary is transparent until hover; plain uses link text colors and underlines on interaction. Success/critical override the corresponding text or primary fill/shadow tokens. The CSS resolves base, hover, active/open, pressed, disabled, and focus-visible states through component variables. Focus-visible gets a `--p-border-width-050` solid `--p-color-border-focus` outline offset by `--p-space-025`; disabled loses shadow and pointer events. See [props/defaults](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Button/Button.tsx#L23-L49), [variant and tone CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Button/Button.module.css#L73-L212), and [state/focus CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Button/Button.module.css#L3-L115).

Button sizes `micro`, `slim`, `medium`, `large` use `--p-height-700/800/900` minimum heights on narrow screens and `--p-height-600/700/800` at `md` and above. `slim` and `medium` have the same authored minimum height and padding. Icon-only buttons use tighter token padding; plain icon-only buttons remove padding and set `--p-height-500`/`--p-width-500` minima. SVG fills are controlled separately by variant/state, with secondary icon colors for tertiary/plain icon-only cases. An icon sits left of text; disclosure sits right. Loading hides the normal content, shows a small Spinner with a translated accessibility label, and disables activation. Text uses `bodySm` except large or non-micro plain buttons (`bodyMd`); primary is semibold on narrow screens and medium at `md` and above. See [sizes and icon rules](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Button/Button.module.css#L214-L325), [icon/state CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Button/Button.module.css#L43-L70), and [rendering](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Button/Button.tsx#L118-L246).

**Badge.** Base badge is inline-flex with `--p-space-050` block and `--p-space-200` inline padding, `--p-border-radius-200`, secondary transparent fill, secondary text, and medium weight. `large` changes block padding to `--p-space-100`; `small` and `medium` share the base CSS. Tone families are `info`, `success`, `attention` (caution tokens), `warning`, `critical`, their `-strong` counterparts, plus `new`, `magic`, `read-only`, and `enabled`. Regular tones use the matching secondary fill and semantic text/icon; strong tones use solid fill and on-fill text/icon. `new` is bold, `read-only` has transparent fill, and `enabled` uses a success icon. Badge text is `bodySm`. `progress` uses a pip icon and accessible progress/tone label; a caller `icon` and `progress` are mutually exclusive. See [CSS tones and size](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Badge/Badge.module.css#L1-L184), [tone/size types](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Badge/types.ts#L1-L42), and [render/accessibility](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Badge/Badge.tsx#L63-L120).

**Tag.** Base fill is `--p-color-bg-fill-tertiary`, radius `--p-border-radius-200`, text `--p-color-text`, with `bodySm` truncated label. Clickable/linkable tags use tertiary hover/active fills and a focus-ring mixin; disabled uses disabled fill/text/icon. The remove button is a separate accessible button with `XSmallIcon`, a literal 18 by 18 px box and 7 px radius, plus its own hover/focus/active rules. The sole size prop is `large`: minimum height 24 px; its 20 by 20 px remove button appears on hover or focus, while touch devices keep it visible. See [Tag CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Tag/Tag.module.css#L1-L245) and [separate link/remove semantics](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Tag/Tag.tsx#L57-L119).

## Inputs and selection

**TextField.** Native input sits over a tokenized backdrop: `--pg-control-height` minimum, `--p-space-150` block and `--p-space-300` inline padding, `--p-font-size-400`/`--p-font-line-height-600` on narrow screens and `--p-font-size-325`/`--p-font-line-height-500` from `md` upward. The surface is `--p-color-input-bg-surface` with a `--p-border-width-0165` `--p-color-input-border` border and `--p-border-radius-200`; the top border is explicitly `#898f94` for the cited accessibility issue. Hover, active/focus, error, read-only, disabled, and `magic` have separate semantic tokens. Focus moves to the backdrop with active input border/background plus a `--p-border-width-050` focus outline. Borderless minimum is `--p-space-800`; slim minimum is a literal 28 px. Prefix/suffix text is secondary, and icons use secondary icon color until disabled or magic overrides it. A clear button appears only on focus within; number input native spinners are suppressed for custom controls. See [base and states](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/TextField/TextField.module.css#L1-L194) and [input/backdrop/sizes](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/TextField/TextField.module.css#L253-L420).

**Checkbox and RadioButton.** Both use `Choice`'s 18 px control at desktop and 20 px at `md` and below, with label/description space managed by `Choice`. Checkbox keeps the native input transparent above its visible backdrop; checked and indeterminate use brand-selected fill, and the check/line icon uses brand on-fill text. It supports error, magic, disabled, and `aria-checked="mixed"` for indeterminate. RadioButton visually hides its native input; its round backdrop has `--p-border-width-0165` input border, full radius, brand-selected checked fill, and a literal 8 px dot (10 px at `md` and below). Both draw a `--p-border-width-050` focus outline with `--p-space-025` offset; hover and disabled colors use control-specific semantic tokens. See [Choice sizing](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Choice/Choice.module.css#L110-L129), [Checkbox CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Checkbox/Checkbox.module.css#L1-L220), [Checkbox semantics](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Checkbox/Checkbox.tsx#L126-L201), and [RadioButton CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/RadioButton/RadioButton.module.css#L1-L147).

**Select.** A visually transparent native `<select>` covers the control, preserving native option behavior and keyboard access; a content layer shows selected text and icon above a backdrop. Content uses `--pg-control-height`, `--p-space-150` block and `--p-space-200` end/`--p-space-300` start padding, and the same responsive input font pair as TextField. Backdrop uses input surface/border and `--p-border-radius-200`. Hover, active, focus, error, disabled, and magic each change backdrop/text/icon tokens; focus-visible draws a `--p-border-width-050` focus outline around the backdrop. The real select receives `aria-invalid`, `aria-describedby`, and required semantics; decorative content is `aria-hidden`. See [Select CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Select/Select.module.css#L1-L220) and [native select markup](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Select/Select.tsx#L182-L220).

## Surfaces, navigation, and overlays

**Card.** Current `Card` has no component CSS module. It composes `ShadowBevel` and `Box`, defaults to `bg-surface` and `xs: '400'` padding, uses shadow `100`, and applies radius `300` from the `sm` breakpoint upward (zero below). It clips X/Y overflow and creates `WithinContentContext`, which changes descendant Banner presentation. The prop comment mentions a different padding default; the function default is the executable value. See [Card implementation](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Card/Card.tsx#L17-L65) and [ShadowBevel token mapping](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/ShadowBevel/ShadowBevel.tsx#L29-L71).

**Banner.** Tones are success, info (default), warning, critical. Page banners use solid semantic fill with on-fill text/icon and `--p-shadow-200` bevel; embedded banners use semantic surface/text colors and `--p-border-radius-200`. Default icons are Check, Info, AlertTriangle, and AlertDiamond; custom icons are documented as major icons. Warning/critical set `role="alert"`, while success/info use `role="status"`; the wrapper is keyboard focusable and can show a `--p-border-width-050` focus outline. Dismiss is a tertiary icon button with an accessible label. See [tone map](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Banner/utilities.ts#L30-L83), [surface/focus CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Banner/Banner.module.css#L1-L37), and [role/dismiss rendering](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Banner/Banner.tsx#L58-L164).

**Tabs.** The tab row has `--p-space-100` gaps. Tabs use transparent fill, brand text, `--p-border-radius-200`, `--p-space-100` by `--p-space-300` padding, and `--p-height-700` height. Selected state uses transparent-selected fill and normal text; hover, focus, active, disabled, and focus-visible have distinct token colors/focus-ring mixins. Tab SVG paths inherit current text color; disabled icons use `--p-color-icon-disabled`. Tabs expose `tablist`/`tab`/`tabpanel`, `aria-selected`, and panel relationships, so the gallery should keep real tab markup. See [Tabs CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Tabs/Tabs.module.css#L40-L155), [tab markup](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Tabs/components/Tab/Tab.tsx#L275-L299), and [panel/row roles](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Tabs/Tabs.tsx#L542-L578).

**Modal.** Dialog is bottom anchored on small screens; from `md` upward it centers and gets `--p-border-radius-400`. Surface is `--p-color-bg-surface`, shadow `--p-shadow-600`; regular max width is 620 px, small is 380 px, large reaches 980 px at `lg`, and fullScreen fills height on narrow screens. The dialog has `role="dialog"`, `aria-modal`, title labeling, focus handling, and an assertive live region. See [size/surface CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Modal/components/Dialog/Dialog.module.css#L1-L89), [dialog accessibility](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Modal/components/Dialog/Dialog.tsx#L60-L117), and [size API](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Modal/Modal.tsx#L23-L54).

**Popover.** Surface uses `--p-color-bg-surface`, `--p-shadow-300` bevel, and `--p-border-radius-300`; default content maxes at 400 by 500 px, while fluid/full-height options remove those limits. Entry shifts by a literal -5 px and fades using `--p-motion-duration-100`. A subdued pane uses `--p-color-bg-surface-secondary`; adjacent sections get a secondary border. The activator gets `aria-controls`, `aria-owns`, `aria-expanded`, optional `aria-haspopup`, and `data-state`, which Button styling also reads for open/active appearance. See [Popover CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Popover/Popover.module.css#L1-L147) and [activator attributes](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Popover/set-activator-attributes.ts#L3-L29).

**Tooltip.** Overlay uses surface/text tokens, `--p-shadow-300` bevel, `--p-shadow-400` shadow, token radius/padding passed as scoped CSS properties, and a 19 by 11 px SVG tail. Width is 200 px by default or 275 px for `wide`; default padding is `--p-space-100` by `--p-space-200`. Animation uses appear-above/below motion tokens and is removed for reduced motion. Tooltip content has `role="tooltip"`; its activator receives `aria-describedby` and a focus-ring attribute. An optional activator underline is a dotted `--p-border-width-050` border. See [overlay CSS](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Tooltip/components/TooltipOverlay/TooltipOverlay.module.css#L1-L118), [padding/radius/tail and role](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Tooltip/components/TooltipOverlay/TooltipOverlay.tsx#L98-L130), and [activator accessibility](https://github.com/Shopify/polaris-react-archive/blob/3f7954ae42fabf26d63cee68c23ceebfd7ef0972/polaris-react/src/components/Tooltip/Tooltip.tsx#L120-L132).

## Focus-visible, measured (2026-10-17)

Read from the live gallery (published 13.9.5) in headless Chromium at 1440 px, light theme, after a Tab key press put the page in keyboard modality; every control below matched `:focus-visible`. The colour is `--p-color-border-focus` (`#005BD3`, `rgb(0, 91, 211)`), the width `--p-border-width-050` (2 px) and the offset `--p-space-025` (1 px) unless the row says otherwise. Raw computed changes are in [focus-states.json](focus-states.json); crops in [screenshots/focus/](../screenshots/focus/).
