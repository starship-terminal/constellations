# LottieFiles design reference

A token set and component reference for the public LottieFiles marketing site. Captured from [lottiefiles.com](https://lottiefiles.com/) on 2026-11-21, signed out, in headless Chromium at 1440x900 and 390x844. The product app on app.lottiefiles.com and the login host login.lottiefiles.com were not entered.

LottieFiles paints one light theme. The page is white, text is near-black, and the primary control is a teal button. Display type is DM Sans LF at 96px. Controls are Inter LF. Header buttons are 36px with a 6px radius. Hero buttons are 48px with a 12px radius.

**Boundary.** Header Log in opens `https://login.lottiefiles.com/login` in a modal. Sign up opens `https://login.lottiefiles.com/register`. `https://lottiefiles.com/login` is a 404. `https://accounts.lottiefiles.com/login` asks for an organization email and password. Those branches were recorded and stopped. No form was submitted. Google and Apple were not clicked.

The site tree, written before the screenshots, is [site-tree.md](site-tree.md).

## How the values were read

Custom properties were read from the live homepage stylesheets with [tools/capture/vars.mjs](tools/capture/vars.mjs) and stored in [raw/css-vars.json](raw/css-vars.json). Component sizes, weights, radii and shadows were read with `getComputedStyle` on the real controls and stored in [raw/components-computed.json](raw/components-computed.json).

Colour tokens keep the oklch strings the CSS declares (`--color-primary` is `oklch(62.6% 0.11 185.333)`). `core.color.brand.primary-srgb` is `#28aca2`, sampled from the raw screenshot of the Get started for free button before quantize. Screenshots are 256-colour PNGs. Read colours from the tokens.

The cookie banner was hidden in CSS. Got It was not clicked. Search text "loader" was typed into the search field and not submitted.

## What to distrust

Hover on the primary button is the computed `oklab(... / 0.9)` string, not a second hex. The sRGB sample is one pixel on one button, so it is Sampled, not the token.

`--color-accent` in the CSS is a near-white wash used on nav hover. The teal brand is `--color-primary`. The catalog swatch, when this package is registered, should point accent at `core.color.brand.primary`.

Inverse colour tokens exist. They are not a dark theme. No dark capture was taken.

Focus-visible did not land on the hero CTA through Tab in the probe. The focus ring is Not captured.

## Fonts

Inter LF and DM Sans LF are the product's own webfonts. They are not committed. The tokens name the stacks. The style guide falls back to Inter and DM Sans from the system, then ui-sans-serif.

## Do and don't

**Do use one teal for the primary action.** Sign up and Get started for free share `--color-primary`. Quiet actions are white with a hairline border. See [home-light-default.png](screenshots/home-light-default.png).

**Do set display in DM Sans and controls in Inter.** The 96px headline is DM Sans LF at weight 500 with tight tracking. Buttons are Inter LF. See the same screenshot.

**Do keep header controls smaller than hero controls.** Header is 36px and 6px radius. Hero is 48px and 12px radius.

**Don't invent a dark theme from the inverse tokens.** The public site is light. Inverse colours paint bands, not a second theme.

**Don't style the signed-in app from this package.** The app and the login modal were not captured.

**Don't read the teal from the 256-colour PNG.** Use the oklch token, or the sampled `#28aca2` when a tool cannot paint oklch.

## Rebuild

```bash

  node tools/capture/vars.mjs
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  node tools/capture/public/public.mjs
python3 tools/capture/quantize.py ~/.design-systems/lottiefiles/raw-shots
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/build_components_md.py
```

Run the commands from `systems/lottiefiles`. Register the package in catalog.json in a follow-up, then run `make design-md` and `make grade`. This capture does not edit catalog.json.
