# On design reference

A token set and component reference for On's public storefront (on.com, the Swiss running brand), for building in the style of a signed-out retail marketing site. It was read from www.on.com/en-sg/ on 2026-11-19, signed out, at 1440 x 900 and 390 x 844. The pages are the home page, women's shoes, a Cloudtilt product page, the about page, the size list, and the added-to-bag card. Nothing was bought, checked out, or signed into. The newsletter form was not submitted.

On's public site is a white page with black type, pill buttons, and a transparent header that turns white over photography. Headlines are On Diatype, tight and bold. Prices, breadcrumbs, and small labels are On Mono. There is no dark theme on the public storefront. Dark fills are local: a primary button, the added-to-bag card, and type sitting on a photograph.

## Brief

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export on` prints them all with aliases resolved.

### Principles

1. Do keep the page white and the type black.
2. Do pill the buttons.
3. Do set headlines in On Diatype bold with a tight negative tracking.
4. Do set prices, breadcrumbs, and small labels in On Mono.
5. Do let the header sit on the photograph.
6. Don't add a second accent.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Values were read from the live page in the T3 preview browser, signed out, on the Singapore storefront.

- Custom properties were read from the same-origin Nuxt stylesheets (`www.on.com/_nuxt/*.css`). The root only publishes four variables. Component colours live as variables on the component classes (`--field-background-color`, `--nav-text`, `--product-information-label-color`).
- Component values were read with `getComputedStyle` on the home page, the women's shoes grid, a Cloudtilt product page, the size list, the added-to-bag card, the footer, and the same home page at 390 x 844.
- The preview browser returned "The browser is not producing screenshot frames", so the page screenshots were taken in headless Chromium against the same public URLs, which had already loaded without a challenge. Screenshot pixels are not the source of the tokens.
- What was touched: the newsletter dialog was closed, the filter column was opened, a size was chosen, and Add to bag was pressed so the confirmation card would mount. Checkout was not opened. The newsletter form was not submitted. Account, order status, and store locator were not entered.

## What to distrust

- Screenshots are 256-colour PNGs. Read colours from tokens.json.
- The hero headline size (49.584px) and the shop title (63.248px) are fluid. They were read at 1440 CSS pixels. A different width will not match them.
- Nav link colour flips with the photograph behind the header. On the home hero it is white. On the shop and product pages it is black. Both are measured. Neither is a theme.
- `text.link` is the browser default blue on the skip link and the logo link before paint. Styled links are black.
- The disabled Add to bag uses opacity 0.25 on the same black fill. There is no separate disabled colour.
- Suisse Works is declared as a font-face and was not used on any measured element.
- The added-to-bag screenshot also shows the newsletter dialog, because that dialog returned on the second product load. The card's values come from the live computed styles, not from that overlap.

## Fonts

On ships its own faces from `cdn.on-running.com/on-running-webfonts/`: **On** (On Diatype Standard) at 400, 500, 700 and 900, **On Mono**, and **On Semi Mono**. None is on Google Fonts. The style guide falls back to the system sans and ui-monospace. Noto Sans JP and Noto Sans KR sit in the body stack for those scripts and were not exercised.

## Do and don't

1. **Do keep the page white and the type black.** The ground is `#ffffff` and the ink is `#000000`. See [shop-light-default](screenshots/shop-light-default.png).
2. **Do pill the buttons.** Default, outlined, and icon buttons are fully rounded. Fields and size tiles are not. See [button-add-to-bag](components/crops/button-add-to-bag.png).
3. **Do set headlines in On Diatype bold with a tight negative tracking.** Shop and hero titles are fluid and slightly tighter than the body. See [heading-shop](components/crops/heading-shop.png).
4. **Do set prices, breadcrumbs, and small labels in On Mono.** The product price and the SHOP / WOMENS / SHOES trail are mono. See [product-light-default](screenshots/product-light-default.png).
5. **Do let the header sit on the photograph.** On the home hero the nav is white on a transparent bar. On a light page it is black. See [home-light-default](screenshots/home-light-default.png).
6. **Don't add a second accent.** The only chromatic UI colour on the captured pages is the amber product label (`#995c00`) and the blue focus ring. Buttons are black or white.

```sh
python3 tools/catalog.py design-md on
python3 tools/fetch_icon.py on
python3 tools/package_tests.py on
```
