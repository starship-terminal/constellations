# Polaroid design reference

A token set and component reference for Polaroid's public signed-out store. Read from www.polaroid.com on 2026-11-19, signed out. polaroid.com redirects to www.polaroid.com/en_sg. That Singapore English storefront is what this package captures. Currency on the home page is €. Some product prices computed as $.

Surfaces: home, cameras, film, the Now camera hub, the MoMA Now product page, contact, and the public log-in page. Desktop 1440 x 900. Phone 390 x 844. One light theme on the page.

The page is white (`#ffffff`). Text and the buy button are `#151515`. The announcement bar is the same black. The current nav section is `#d60026`. Type is Real Head for titles and nav, Commit Mono for buttons. Corners are square, except Product Finder, which is a pill.

## Do and don't

1. **Do keep the page white and the wordmark in currentColor.** On a photograph the logo is white. On a listing it is `#151515`. See [home-light-default](screenshots/home-light-default.png) and [logo-default](components/crops/logo-default.png).
2. **Do use a black square for the commit action.** Continue and Add to Bag are `#151515`, white Commit Mono 12px uppercase, 45px tall, radius 0. See [button-continue-default](components/crops/button-continue-default.png).
3. **Do put a white square and a white outline on photography.** Shop Bundles is filled white. Get Inspired is a 1px white border. Both are 42px. See [home-light-default](screenshots/home-light-default.png).
4. **Do set the current nav item in red.** Holidays on the cameras page computed `rgb(214, 0, 38)`. Other nav items are `#151515` at 13px. See [cameras-light-default](screenshots/cameras-light-default.png).
5. **Don't invent a dark theme.** `html.dark-mode` is declared. The live page had no dark class and no theme toggle. `color-scheme` computed `normal`.
6. **Don't press Add to Bag or Continue.** Those controls were measured and never used to buy or join. No card, phone, or password was entered.
7. **Don't round the buttons.** Radius on Shop Bundles, Continue, Add to Bag, and the email field is 0. Product Finder is the pill (`100px`).

## How the values were read

Custom properties were read from the live stylesheets and from computed style on `documentElement` at `https://www.polaroid.com/en_sg` in the T3 preview browser, then confirmed on the same URL in headless Chromium. Component colours and sizes were read from computed style on the live DOM: the announcement bar, nav, Shop Bundles, Get Inspired, Product Finder, the email field, Continue, and Add to Bag. Screenshots are viewport captures. Desktop shots are 1440 x 900 at 1x. The phone shot is 390 x 844 CSS pixels at devicePixelRatio 2, so the PNG is 780 x 1688.

The T3 preview browser returned "The browser is not producing screenshot frames" after the style readings. Screenshots were taken in headless Chromium only after each public page loaded there without a Cloudflare challenge.

## What to distrust

`light.muted` is `#e9e9e9`, the same grey as `light.surface` (`--color-grey-200`). No separate muted text colour was computed. The catalog requires a muted swatch, so the grey fill is reused. Do not treat it as secondary text.

The outline button's hover is a declared rule (black fill, white label), not a live hover. A synthetic mouseover did not change the fill, and Playwright's hover was intercepted by the nav.

Add to Bag on the MoMA Now page sat below the first viewport (`y` 940). Its crop is the control. The product screenshot is the top of that page, so the button is not in the viewport image.

The email field's focus computed `outline: none` and `box-shadow: none`. That is the reading, not a missing capture.

Real Head, Commit Mono, and Saol Text are proprietary and are not in the package. The style guide falls back to Arial and a monospace face. Saol Text is declared and was not computed on a visible specimen.

`prefers-reduced-motion` rules exist in the stylesheets. The reduce emulation was not run, so the page verdict is not recorded.

The "New" tag on the cameras listing looks red. The computed background on the node that held the word was transparent, so that red is not a token.

## Fonts

Real Head Demibold (`REAL_HEADER_OFFC_DEMIBOLD`, weight 600) is the title face. Real Head Regular is the nav, price, and field face. Commit Mono is the button face. Saol Text is a declared display face with no computed specimen on these pages. All are proprietary. The tokens name them, then Arial. They are not committed. The wordmark is the header SVG in [icons/logo.svg](icons/logo.svg).
