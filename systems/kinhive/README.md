# Kinhive design reference

A token set and component reference for Kinhive's public site, for building marketing pages, pricing cards, auth edges, and directory indexes in this style. It was read from **kinhive.com** on **2026-11-18**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: home, pricing, about, blog and one article, two feature pages, templates, funding, resources, shop (with the cart drawer open), contact, join, sign-in, privacy, terms, accessibility, plus 390px passes on home, pricing, join, and sign-in.

Kinhive is a free AI introduction app for women founders. The public site is a Next.js and Tailwind v4 marketing surface. The declared layer is a real palette: ink #111111, body #4b4b50, canvas #f6f6f4, line #e6e6e3, cobalt #2448e3, chartreuse #d4e31f, tomato #f0532c, butter #f8f2cf, chocolate #33190d. Type is Figtree for UI and Affairs for headlines. Controls are 8px-radius ink fills. A second palette is declared under `prefers-color-scheme: dark` on `html[data-app-theme=system]`. The live document does not set that attribute, so the painted theme is light. **Boundary:** the product behind sign-in (`/home`, `/matches`, `/chat`, `/cowork`, `/profile`, `/settings`, and the other paths robots.txt disallows) was not opened. Join, sign-in, contact, subscribe, and the hero email were measured at rest and never submitted. LinkedIn and the store badges were not followed. Checkout was not started.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export kinhive` prints them all with aliases resolved.

### Principles

1. Do spend chartreuse on the accent, not the page.
2. Do keep ink for actions.
3. Do set headlines in Affairs and UI in Figtree.
4. Do use 8px radius on controls.
5. Do keep the butter card on the photograph.
6. Don't style the signed-in app from this package.
7. Don't invent form outcomes.
8. Don't treat the dark screenshot as the live theme.
9. Don't copy the wordmark.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

| Step | What ran |
|---|---|
| Screenshots | `tools/capture/public/public.mjs` at 1440 x 900 and 390 x 844. Consent overlays are hidden, never answered. The only presses are the Features and Use Cases menus, the mobile Open menu button, and the shop cart |
| CSS harvest | `tools/capture/vars.mjs` reads the `_next/static` stylesheets and resolves every custom property. The dark pass sets `data-app-theme="system"` and emulates `prefers-color-scheme: dark` |

| Guide | `tools/build_style_guide.py` writes style-guide.html |

Every token leaf names its source in `$extensions.source`. A `css-var` source was read from the stylesheet. A `measured` source is a computed style from the 2026-11-18 probe.

## What to distrust

- **The signed-in product.** Nothing behind the auth wall was opened. Marketing photographs of the app are published images, not the product.
- **The dark screenshot.** [home-dark-default](screenshots/home-dark-default.png) paints only after the capture sets `data-app-theme="system"`. A visitor does not get that page from a toggle. The dark token values are still the declared ones.
- **The forms.** Join, sign-in, contact, subscribe, and the hero email were not submitted. Error, loading, and success colours were not observed. Declared `--color-destructive` and `--color-alert` are unused on these pages.
- **Hover.** `light.action.fill-hover` is the authored `hover:bg-[#2a2a2c]` literal, not a forced-state measurement.
- **Quantised screenshots.** `screenshots/` and crops are 256-colour PNGs. Read colours from tokens.json.
- **The promo strip colour.** The strip is a dark brown band. It was not isolated as its own computed fill, so it is not a token.

## Fonts

- **Figtree** is the UI face, loaded as a next/font variable (`--font-figtree`) with a Figtree Fallback metrics face. `--font-sans` points at it.
- **Affairs** is the heading face (`--font-heading` is `var(--font-affairs), Georgia, serif`), with an Affairs Fallback face. The home h1 computes to `affairs`.
- Neither family is bundled here. The style guide falls back to system faces. The `@font-face` rules are in [raw/css-vars.json](raw/css-vars.json).

## Do and don't

1. **Do spend chartreuse on the accent, not the page.** #d4e31f paints the free-plan card, the mega-menu chips, and the pricing eyebrow. The page stays white. See [price-card-default](components/crops/price-card-default.png).
2. **Do keep ink for actions.** #111111 fills Join free, Continue, and Send message. White is the label. See [nav-join-default](components/crops/nav-join-default.png).
3. **Do set headlines in Affairs and UI in Figtree.** The 44px hero and the $0 are Affairs. Nav, fields, and buttons are Figtree. See [hero-h1-default](components/crops/hero-h1-default.png).
4. **Do use 8px radius on controls.** `rounded-lg` is 8px on nav links, CTAs, fields, and chips. Cards go wider. See [join-field-default](components/crops/join-field-default.png).
5. **Do keep the butter card on the photograph.** The hero card is #f8f2cf over the photo, not a white panel. See [home-light-default](screenshots/home-light-default.png).
6. **Don't style the signed-in app from this package.** Matches, chat, cowork, and profile sit behind sign-in and were not captured. Add to cart was not pressed. See [product-light-default](screenshots/product-light-default.png).
7. **Don't invent form outcomes.** Continue, the sign-in code, Send message, and Subscribe were not pressed. See [join-continue-default](components/crops/join-continue-default.png).
8. **Don't treat the dark screenshot as the live theme.** The site does not set `data-app-theme`, so visitors see light. The dark tokens are the declared palette. See [home-dark-default](screenshots/home-dark-default.png).
9. **Don't copy the wordmark.** The Kinhive mark, the photographs, and the chartreuse are the product's. Borrow the structure.

## Rebuild

From `systems/kinhive`, with Playwright at `PLAYWRIGHT` and Pillow on `python3`:

```sh
PLAYWRIGHT=$PW node tools/capture/public/public.mjs
python3 tools/capture/quantize.py ~/.design-systems/kinhive/raw-shots
PLAYWRIGHT=$PW node tools/capture/vars.mjs
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
```

Then `make brief && make design-md && make grade && make check` from the repo root.
