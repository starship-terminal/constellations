## How the values were read

The homepage was opened signed out in an incognito preview tab at 1440. `getComputedStyle` was read on the body, the visible hero heading, the Pricing link, Login, Sign Up, and Get Started. `:root` resolved 1067 custom properties. The named `--Core-*` roles were copied. Product-screen and motion colours that only paint the marketing illustration were left in the page and not copied into tokens.json.

Screenshots are the first viewport from headless Chromium at device pixel ratio 2. A cookie overlay was hidden with CSS. Its allow and confirm buttons were not clicked.

## What to distrust

Body background computed transparent. The page colour `#ffffff` is `--Core-Background-Main`, not a painted body fill.

The hero computed weight 700. The declared `--text-display-2xl` weight is 650. Both are recorded. The token uses the computed weight.

Sign Up computed `rgba(32, 32, 32, 0.8)`. The token stores the opaque ink `#202020` from Get Started and `--Core-Button-Primary`.

Purple `#6647f0` is `--Core-Accents-Purple`. The primary marketing button is ink, not purple.

The homepage product panel is a marketing illustration. Names in it are sample copy. It is not a signed-in inbox.

No dark theme was painted. `color-scheme` on the homepage was `normal`.

The login button fill `#bbbbbb` is the disabled state while both fields are empty.

## Do and don't

1. **Do paint the page white and the text near-black.** Page is `#ffffff`. Text is `#202020`. See [home-light-1440](screenshots/home-light-1440.png).
2. **Do set the hero in Plus Jakarta Sans.** The heading is 60px, weight 700, letter-spacing -2.1px. Same shot.
3. **Do make the primary action an ink button.** Get Started is `#202020` with white text and a 12px radius. Same shot.
4. **Do keep Login as a light grey pill.** Login is `#f0f0f0` with black text and an 8px radius.
5. **Don't treat the purple accent as the primary button.** `#6647f0` is a named accent. The photographed primary action is ink.
6. **Don't treat the homepage workspace as the product.** The Mango Inc. panel is marketing art. The workspace was not opened.
7. **Don't submit the email field from this package.** It was empty. Login and signup were stopped.

