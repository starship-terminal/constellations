# Kitchen Stories design reference

A token set and component reference for Kitchen Stories' public, signed-out magazine. It was read from [www.kitchenstories.com](https://www.kitchenstories.com) and [pages.kitchenstories.com](https://pages.kitchenstories.com) on 2026-11-18, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: the German home page, the recipe index, a category, a recipe, stories, search results, partners, team, an author page, contact, impressum, and the marketing pages for about, the app, Plus and careers. Phone passes cover home, the recipe, the recipe index and Plus.

The live public magazine is German. English `/en` returns 410. The site is WordPress Newspack. It paints one light theme: a white field, `#111111` ink, a `#fff5ea` footer and a `#dd3333` call to action, set in Plus Jakarta Sans. Checkout, the account profile, the recipe cart and rating submit were not followed. The consentmanager overlay was hidden, never answered.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export kitchenstories` prints them all with aliases resolved.

### Principles

1. Do keep the field white.
2. Do put the warm band only in the footer.
3. Do spend the red on the call to action.
4. Do set the magazine in Plus Jakarta Sans.
5. Do keep the desktop nav as links.
6. Don't follow checkout from this package.
7. Don't invent a dark theme.
8. Don't submit the recipe cart or the rating form from this reference.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## What to distrust

The desktop header has a `button.desktop-menu-toggle` in an off-canvas track (about x 2775, visibility hidden). It is not a painted control at 1440. The painted desktop nav is the inline links. The phone hamburger is the real menu.

`article` on the phone home matches a huge page wrapper. That crop was dropped. Use the desktop recipe card and the phone screenshots for card shape.

Screenshots are 256-colour PNGs. Read colours from [tokens.json](tokens.json).

Plus Jakarta Sans is not shipped. The style guide falls back to system faces.

## Fonts

Plus Jakarta Sans is the body and header preset the magazine paints. Barlow, Spectral, ttcommons, aime and Font Awesome are also served as `@font-face`. None of those files are in this package.

## Do and don't

1. **Do keep the field white.** The page, header and cards sit on `#ffffff`. Ink is `#111111`. See [home-light-default](screenshots/home-light-default.png).
2. **Do put the warm band only in the footer.** `#fff5ea` is the footer, not a page wash. See [footer](components/crops/footer-default.png).
3. **Do spend the red on the call to action.** `#dd3333` is the Plus start link and the "Alle anzeigen" links. Body text stays black. See [plus-cta](components/crops/plus-cta-default.png).
4. **Do set the magazine in Plus Jakarta Sans.** Body and headers share that preset. See [recipe-h1](components/crops/recipe-h1-default.png).
5. **Do keep the desktop nav as links.** At 1440 the header is wordmark plus Rezepte, Artikel, App, Plus and Unsere Partner. The hamburger is the phone control. See [header](components/crops/header-default.png) and [mobile-home-light-menu](screenshots/mobile-home-light-menu.png).
6. **Don't follow checkout from this package.** Plus "Jetzt kostenlos starten" points at `/de/checkout`, which was not captured. See [plus-light-default](screenshots/plus-light-default.png).
7. **Don't invent a dark theme.** The site paints one light theme. The `#333333` dark token is a surface inside that theme, not a second mode.
8. **Don't submit the recipe cart or the rating form from this reference.** Those controls were left at rest. See [recipe-light-default](screenshots/recipe-light-default.png).
