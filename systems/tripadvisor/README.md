# Tripadvisor design reference

A token set for Tripadvisor's public signed-out site. Read from tripadvisor.com on 2026-11-19 in the T3 preview browser, signed out. Surfaces: home, Kyoto tourism, the Fushimi Inari attraction, Kyoto hotels (the date dialog was opened and closed), the Kyoto forum and one public topic, and the sign-in and join cards. The join card shows first name, last name, email, and password. It was not submitted.

Tripadvisor paints a light theme on these pages. The stylesheets also declare a dark set on `:root[data-dark-theme-supported="true"]` inside `prefers-color-scheme: dark`. The attribute was absent, so those values were not painted. Brand green is `#00EB5B`. Body text is `#002B11`. The type family is Trip Sans VF.

## Do and don't

1. **Do keep the page white and the text pine green.** Page background is `#FFFFFF`. Body and headings are `#002B11` (`light.color.text.primary`).
2. **Do use the bright green only for the search and ticket action.** Search and See tickets are `#00EB5B` with a `#00AB42` border (`light.color.action.brand.background`). Sign in and Book now are the pine fill, `#002B11`.
3. **Do round the search and the header pills fully.** The search shell at rest and Sign in use `1000px` (`core.radius.full`). Cards use `8px`. Login fields use `4px`.
4. **Do set type in Trip Sans.** Body is 16px. The home heading is 900 / 54px at a wide viewport and 900 / 28px at 390px. Weight 700 is the file Tripadvisor names Medium.
5. **Don't invent a painted dark theme.** The dark custom properties exist and were not applied. `html` had no `data-dark-theme-supported`.
6. **Don't submit sign-in, join, or a booking.** The email field was left empty. Continue with Google was not followed. See tickets and the hotel search were not submitted.
7. **Don't redraw the owl or the bubble rating as a new icon set.** Those marks are Tripadvisor's artwork and are not in this package.

## How the values were read

Computed styles were read in the T3 preview browser on the live page. Custom properties were read from `getComputedStyle(document.documentElement)` and from the CSSOM of the `static.tacdn.com` stylesheets. `accounts.google.com/gsi/style` was cross-origin and was not read. Hover and pressed states were not forced. A search suggestion list opened once when the field received the text Kyoto, then closed. The query was cleared and was not submitted from the home form. `/Search?q=Kyoto` loaded an empty results shell.

The desktop fill viewport measured `innerWidth` 1169 and `innerHeight` 731 at device pixel ratio 2. A requested 1440 by 900 size did not change `innerWidth`. A requested 390 by 844 size did: `innerWidth` 390, `innerHeight` 844, scale 1.

## What to distrust

- Dark colours are declared, not painted. The machine reported `prefers-color-scheme: dark`, and the page still painted light because the dark rule also requires `data-dark-theme-supported="true"`.
- The focused search shell's border computed as `2px solid #f7f7f7` on a white field. That reading is what the browser returned. It is a poor edge against the page.
- Forum topic links computed `#006699`. Header links computed `#002B11`. Both are in the tokens. They are not one link colour.
- `--trip-sans-medium` is 700, and the 700 `@font-face` file is `TripSans-Medium.woff2`. The name and the weight do not match the usual meaning of medium.
- No screenshot was saved. `preview_snapshot` returned "The browser is not producing screenshot frames" twice. Headless Playwright received HTTP 403 from a captcha page, so it was not used to invent images.
- Spacing tokens are the declared scale. Not every step was confirmed as a painted gap.

## Fonts

Trip Sans VF, then Trip Sans, then Arial, then sans-serif. Computed on `body`. `@font-face` loads Trip Sans Regular (400) and Trip Sans Medium (700) from `/css2/webfonts/TripSans/`. Trip Sans Mono is declared. Editorial roles declare Georgia. The webfonts are Tripadvisor's and are not in this package. Fall back to Arial.
