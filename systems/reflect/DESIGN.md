# Reflect

Public marketing site at https://reflect.app/, captured 2026-11-21, signed out. One dark theme. Values are measured computed styles and CSS rules. This file was written by hand because catalog.json was left alone and the DESIGN.md generator was not run.

## Geometry

Radius 8px on buttons and the auth field. 32px on the Meet Reflect Open pill. 9999px on blog tags. Button padding 8px 16px. Button height 36px. Auth field height 50px. Continue height 44px.

## Motion

Button hover fades `::before` out and `::after` in over 200ms, cubic-bezier(0.6, 0.6, 0, 1).
