Fibery, measured

Every value on this page is a CSS custom property generated from tokens.json: the site's declared --fibery-* token layer — the milk/cream/soup/peach-soup/tea warm neutrals and the rust family, the four-tier --fibery-basic/secondary/tertiary/quaternary-* hue ramp, the --fibery-page-*/--fibery-text-*/--fibery-gray-* semantic roles and --fibery-shadow-m — plus the measured type steps, radii, control transitions and component sizes the CSS layer does not declare. The real pixels are in screenshots/ and components/crops/.

Read from fibery.com and fibery.io, signed out, in headless Chromium. The public site paints one light theme — there is no theme toggle and no dark scope on the marketing pages, the sign-up wizard or the sign-in, so this guide has no dark mode and tokens.json ships core + light only (the signed-in app's dark/system theme is behind sign-in and was not captured). The sign-up and login forms were measured, never submitted. Suisse Intl and Fraunces are served faces and are not loaded here: samples fall back to system fonts.

Palette

The declared --fibery-* palette: the warm named neutrals and rust family, the four-tier hue ramp (basic saturated, secondary mid, tertiary light, quaternary lightest), and the page/text/gray/menu/form/business semantic roles. Measured roles alias the declared values they match; two declarations ship the literal undefined and resolve to nothing.

Spacing, radius and motion

The CSS layer declares no spacing or radius scale — corners and control transitions are measured on the real components: full pills on the FiberyButton variants, rounded cards and fields, and the hover transitions on pills and nav items.

Type

Served faces: Suisse Intl (100–900 static weights) carries every control, nav item and body line; Fraunces Var draws the serif display headlines and quotes; Casuar and Inter Var are declared for special and embedded surfaces. The ramp is measured, not declared. Samples fall back to system fonts.
