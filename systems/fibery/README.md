# Fibery design reference

Public marketing site for Fibery, the work platform at fibery.com. Captured 2026-11-21, signed out, in headless Chromium. Desktop shots are 1440x900. Phone shots are 390x844 for the home page, the burger menu, and the login wall. `https://fibery.io/` redirects to `https://fibery.com/`. The walk stopped at `https://fibery.io/login`. No account was created and no form was submitted.

One theme on the public pages: light. Page ground is soup `#faebd6`, text is ink `#251d1a`, type is Suisse Intl. There is no dark-theme switch on the pages that were opened.

## How the values were read

Custom properties were read from the stylesheets on `https://fibery.com/` in headless Chromium on 2026-11-21. Computed styles were read on the header signup link, the login link, `h1`, `h2`, `h3`, a `TabPillButton`, and the Continue with Email button on `https://fibery.io/login`. The body background matched `--fibery-soup` (`#faebd6`). No theme class was present on `html`. `color-scheme` was `normal`.

## What to distrust

Hover on the header signup link did not change its computed background, so there is no measured hover colour. The first Tab stop outline was `rgb(0, 95, 204) auto 1px`, the browser default, not a product focus ring. `--fibery-page-secondary-color` and `--fibery-text-selection-color` were declared as the literal `undefined` and are not tokens. Status colours are the named `--fibery-basic-*` ramps. They were not seen as status badges on the public pages. Screenshots are full colour. Read values from tokens.json.

## Fonts

Suisse Intl is the computed family on body and headings. It is proprietary and is not in this package. The tokens name `Suisse Intl, sans-serif`. The style guide falls back to the system sans.

## Do and don't

- **Do set the page on soup.** The body background is `#faebd6` and the text is `#251d1a`. See [home-light-default](screenshots/home-light-default.png).
- **Do use one filled control for the primary action.** Sign up is ink on soup text, 40px tall, 6px radius. Log in is cream. See [login-light-providers](screenshots/login-light-providers.png).
- **Do keep menus as hover panels.** Solutions, Platform, and Support open in the header. Pricing is a link. See [home-light-menu-solutions](screenshots/home-light-menu-solutions.png).
- **Don't invent a dark theme.** None was on the public pages.
- **Don't treat the login wall as the app.** Google, Microsoft, email, and Workspace SSO were not followed past an empty field. See [login-review.json](login-review.json).
- **Don't accept the cookie banner to open Cal.com.** Book a demo stopped on that banner. See [home-light-cookie-banner](screenshots/home-light-cookie-banner.png).
