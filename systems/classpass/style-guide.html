ClassPass, measured

Every value on this page is a CSS custom property generated from tokens.json. classpass.com declares no design-token CSS variables (its four custom properties are carousel-dot colours and framework internals), so the whole palette is measured on the painted chrome: the ClassPass blue accent ramp, the near-black ink ramp, the neutral greys, the promo yellow and the translucent scrims. Palette
