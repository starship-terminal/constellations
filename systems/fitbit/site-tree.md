Mapped signed out on 2026-11-22 from [https://www.fitbit.com](https://www.fitbit.com). The browser landed on [https://store.google.com/sg/category/watches_trackers](https://store.google.com/sg/category/watches_trackers). Title "The official site for Fitbit activity trackers and smartwatches". Desktop width measured 1440 by 900 CSS pixels, `devicePixelRatio` 2. Visual viewport scale 1. Screenshots are 2880 by 1800. The shared preview browser redirected the same way, then failed to produce screenshot frames twice: "The browser is not producing screenshot frames. For a desktop tab, show or restore the T3 Code window and try again." The shots in this package are from a later headless Chromium pass of the same public URLs. That pass was signed out. Nothing was typed. No email, password, code, phone, or address was entered. No form was submitted. No identity provider was clicked. No captcha was solved. Sign in, Buy, cart, and Google apps were not opened. `login-extracted` stays `not-started`.

`catalog.json` and `webapps-manifest.json` were left alone. origin/main had no `systems/fitbit/`. Tracking query strings (`utm_source`, `utm_medium`, `utm_campaign`, `hl`, `pli`) are not recorded as destinations.
