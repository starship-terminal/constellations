# Tools

This capture was read live in the T3 preview browser with `preview_evaluate`.
The kit's Playwright scripts were not adapted. Headless Playwright against
stocksy.com returned a Cloudflare challenge, so those scripts would not have
measured the page.

Tokens were written from the computed styles in [../raw/readings.md](../raw/readings.md).
`DESIGN.md` is generated by the repo catalog tool:

```bash
python3 tools/catalog.py design-md stocksy
```

Run that from the repository root, not from this folder.
