# Sana public site tree

Mapped on 2026-11-22 from the public homepage, [https://sana.ai/](https://sana.ai/). Title: "Sana Agents". The first heading is "Superintelligence for work". The page is a live marketing site. It is not parked and it is not a captcha wall. The footer line reads "Sana Labs © 2026".

Desktop shots are 1440 by 900 CSS pixels at device pixel ratio 2 (PNG 2880 by 1800). Phone shots are 390 by 844 CSS pixels at device pixel ratio 2 (PNG 780 by 1688). They are the first viewport, not the full page. `prefers-color-scheme` was light. The homepage painted white.

Nothing was typed. No email, password, code, phone, or address was entered. No form was submitted. No identity provider was clicked. No captcha was solved. No workspace was started. No checkout was opened. `login-extracted` stays `not-started`. catalog.json and webapps-manifest.json were left alone.

origin/main already maps sana.ai to [systems/sana-ai](../sana-ai). `systems/sana/` did not exist. This walk adds the site tree there. It does not open a second package.
