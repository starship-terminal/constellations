# Gauth design reference

A token set and component reference for Gauth's web product, for building self-learn's courses, lessons and tutor in the style of a real AI learning app. It was read from www.gauth.com on 2026-10-04, signed out, in headless Chromium at 1440 wide and 390 wide: the Homework home, the Gauth Academy catalogue (Science Labs, Math Curriculum, History Signature, My Course and the Create a Course dialog), a math unit page, three lesson players (a science canvas, a math lesson and a history lesson), Atlas with a story page, and Insights. It was refreshed on 2026-10-17, again signed out, to close the gaps in the library's scorecard: the Sign in and Gauth PLUS dialogs, the plans page and its table, the footer's language select, the blog's pagination, the science lesson's tooltip, Playback speed menu and answered check-in, disabled states, z-index layers, reduced motion, and the patterns in [patterns.md](patterns.md). The science lesson, the Atlas landing and the new pages were measured again on that date; the rest keeps its 2026-10-04 readings.

The earlier references (Duolingo, Brilliant, NotebookLM, Coursera) each cover part of what self-learn does. Gauth covers most of it in one product: a course catalogue with an AI course builder, unit pages with a path of topics, narrated lessons with a tutor beside them, AI-generated visual stories, and a question-first home.

### Principles

1. Do keep the near-black fill for Sign in and the one action that moves the learner on.
2. Do let each course bring its own colour and keep the chrome neutral.
3. Don't carry the brand red into the learning pages.
4. Do keep the serif for titles.
5. Do drop the app shell inside a lesson.
6. Don't copy the missing focus ring.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Gauth's pages are React with CSS modules: a class reads `catalog_card__Xyz12`, so the kit selects by the stable `catalog_card` part. The stylesheets come from a CDN, which the CSSOM will not read cross-origin, so [vars.mjs](tools/capture/vars.mjs) keeps every stylesheet response and parses it in the page with a constructed `CSSStyleSheet`. The pages declare about 3,700 custom properties, and most are not Gauth's: 2,211 are Ant Design's CSS-variable theme (`--ant-*`, including its stock `#1677ff` primary that Gauth never paints), 244 are TikTok's TUX theme (`--Primary: #fe2c55` and friends, under `:root, [data-theme="light"]`), and the science lesson brings Astryx, a separate design system with its own "stone" theme. All of these are recorded in [raw/css-vars.json](raw/css-vars.json) by owner and none is promoted unless Gauth paints it, with one exception: Gauth declares no warning colour, so `status.warning` takes Astryx's, as the science player's stone-themed Astryx container resolves it ([raw/foundations.json](raw/foundations.json), `astryxResolved`), labelled as not seen painted.

Gauth's own 750 declarations are mostly the lesson system: the lesson palette (`--lesson-primary-*`, `--lesson-gray-*`, `--lesson-blue-*`, `--lesson-right-*`, `--lesson-wrong-*`, which the Academy pages also paint), the lesson type scale (`--lesson-font-size-*`, `--ugc-lesson-*`), a few layout widths, Atlas's `--aw-*` and the math player's `--gauth-*`. The token file uses these wherever one matches what a page paints, and otherwise takes the computed style of the real element, citing the component entry it was read from. So the palette is grouped by place (ink, paper, sand, slate, blue, green, red, brand, gold, indigo for Homework, astryx for the science lesson, atlas, and two small groups, lesson-math and antd) rather than as ramps, because Gauth declares none. The one numbered run, `palette.ink.900` to `400`, is this package's numbering of six text greys; see What to distrust.

Component values are computed styles read per state with Playwright ([measure.mjs](tools/capture/measure.mjs)). Hover used the pointer, focus-visible a real keyboard Tab, and pressed was forced through DevTools (`CSS.forcePseudoState`), so no button was clicked for real. Text fields were typed into and cleared again, and Enter was never pressed. The only presses were dismissals (the promo dialog's close button, the audio dialog's Not now), the math player's Continue (which starts playback), tabs, Show more, the sidebar's collapse button, the second unit in the unit rail, the lesson's own Play, Pause, Settings and chapters buttons, Create Course (which opens a dialog), and a story card (which opens a video preview) and its Explore (which opens a published story). Nothing was signed into, created, sent or uploaded.

A second pass the same day closed more gaps: the brand-red Sign in measured enabled (with `name@example.com` typed, never submitted), a field's error state forced from Gauth's own `form_error` class, the sign-up password field focused (never typed into), the check-in answered right on a second visit, warning resolved from Astryx's stone theme in the science player, and the code role and the Atlas delete dialog read from Gauth's stylesheets, with every rule cited recorded verbatim in [raw/foundations.json](raw/foundations.json) (`declaredRules`). The 2026-10-17 refresh added three readings. [foundations.mjs](tools/capture/foundations.mjs) parses every rule Gauth's stylesheets put under `prefers-reduced-motion: reduce` (about 60, in the lesson players, the course pages and Astryx) and compares what the components paint with reduced motion emulated and without: the lesson controls' transitions go from 125ms to none, entrance animations, skeleton pulses and loading dots stop, and the lesson-complete confetti is hidden, while the shell and Academy transitions do not change (`core.duration.reduced`). The same script reads the z-index of every layer on each page and with each dialog open (`core.zIndex`), and the brand colour evidence: one `<meta name="theme-color" content="#ffffff">`, no mask icon and no web manifest, so the brand red is confirmed only by where it is painted. The new components were reached by opening the Sign in dialog, the Gauth PLUS dialog and the footer's language select and closing them again; a throwaway string was typed into the Sign in email field and deleted, and no plan card was chosen. Beyond dismissing them, the only presses inside a dialog were the Sign in dialog's Sign up link and the science lesson Settings popover's Speed row, which opens the Playback speed menu. To see the lesson's feedback colours, the science lesson's practice check-in was answered twice, on two visits: its last option once (wrong) and the option naming lift, thrust and climb cost once (right). Those are the only answers the capture gave.

Gauth paints one light theme. Its stylesheets declare dark values (TUX under `[data-theme="dark"]`, the lesson palette under `[data-lesson-style="dark"]`, Astryx as `light-dark()` pairs), but no page captured applies any of them, no control offers a switch, and every page painted the same with `prefers-color-scheme: dark` emulated. So the token file has a light set only, and the dark declarations stay in the raw file.

Screenshots are stored as 256-colour PNGs to keep the folder small. Flat UI colours are exact; read values from the tokens, not the images.

## What to distrust

- **Status colours.** `status.danger` and `status.success` are painted (the check-in's result card, answered wrong and right). `status.info` is Gauth's declared `--gauth-semantic-blue-*`, and `status.warning` is Astryx's yellow as the player's stone theme resolves it (the stone scope stays on a container after the audio dialog closes; the page root's Astryx yellow differs); neither was seen painted, and Gauth's own CSS has no warning. Gauth also declares a danger and a success trio (`--lesson-wrong-*`, `--lesson-right-*`) that differ from the painted ones.
- **Forced and declared states.** The field error is Gauth's `form_error` class added in DevTools; the error message text, the code role and the delete dialog are read from Gauth's CSS and never seen on a page.
- **The spacing scale is a reading, not Gauth's.** Gauth declares no spacing scale. `core.spacing` lists the measured values on a 4px grid, which 63% of the 1,020 measured paddings and gaps fall on; `core.spacing-offgrid` keeps the rest (10px alone is used 131 times).
- **The elevation levels are a grouping.** `elevation.level-1` to `level-4` point at measured shadows chosen by use (resting card, hovered card, popover, dialog). The measured components paint 39 different visible shadows (Ant Design's and the focus rings among them); 17 are kept as tokens under `light.elevation`, and the rest stay in [raw/components-computed.json](raw/components-computed.json) or are written raw in their component entries.
- **The ink steps are this package's numbering.** `palette.ink.900` to `400` are six text greys put in order of lightness and numbered here: `900`, `600` and `400` are Gauth's `--lesson-gray-text-1` to `-3`, `800` and `700` its `--lesson-neutral-gray-text-2` and `-3`, and `500` (`#757c88`) is measured and matches no Gauth variable. It has no light end, and the step numbers are not Gauth's.
- **Three background roles share a value.** `background.surface`, `.raised` and `.overlay` are all white: Gauth separates them by shadow, not by fill.
- **Disabled text** (`text.disabled`, `#9ca2ac`) is read from one control, the Atlas Send button's icon while the box is empty. The Sign in button's disabled state is a pale fill with white text instead (`action.primary-disabled`).
- **Pressed** was forced with DevTools, so `action.primary-pressed` is the hover fill held under `:active:hover`; Gauth sets no separate pressed colour.
- **Third-party controls.** The language select is Ant Design and keeps Ant's own colours (`rgba(0, 0, 0, 0.88)` text, a `#1677ff` border and a pale blue ring on focus). The blog pagination is Ant's component restyled in Gauth's ink (`#21252e` text, a near-black current page), but its keyboard focus is still Ant's 3px `#91caff` outline. Both are measured as Gauth shows them; the Ant values are not Gauth's palette.
- **The Atlas Video badge and play disc** were not on the landing page on 2026-10-17; their entries keep the 2026-10-04 readings.

## Do and don't

1. **Do keep the near-black fill for Sign in and the one action that moves the learner on.** Start, Create and Share are `#21252e`; tabs, Show more and Generate Video are outlined on the ground or on white, and Create Course, the AI entry point, is the pale blue gradient button. See [unit-light-default](screenshots/unit-light-default.png), [academy-my-light-default](screenshots/academy-my-light-default.png), [atlas-light-story](screenshots/atlas-light-story.png) and [academy-math-light-default](screenshots/academy-math-light-default.png).
2. **Do let each course bring its own colour and keep the chrome neutral.** Physics covers are pale blue, Biology green, Chemistry violet and Algebra 2 terracotta; on the unit page Algebra 1's green tints the banner (`#ecf4e5`), the current unit's 5px bar and text (`#3c6b26`) and the topic coins, while the sidebar, tabs and buttons stay warm grey. See [academy-science-light-full](screenshots/academy-science-light-full.png), [unit-light-default](screenshots/unit-light-default.png) and [course-banner-default](components/crops/course-banner-default.png).
3. **Don't carry the brand red into the learning pages.** `#ff013e` paints the marketing home (the gradient headline words, the Step-by-step row) and, as its near twin `#f00039`, the current Insights tab, but in the Academy, the unit page and the lessons it appears only in the logo and the mascot. See [home-light-full](screenshots/home-light-full.png), [news-light-default](screenshots/news-light-default.png) and [academy-math-light-default](screenshots/academy-math-light-default.png).
4. **Do keep the serif for titles.** The page title, the lesson title and the chapter titles are Playfair Display or Libre Baskerville; section headings, card titles, body text and every control are sans. See [academy-science-light-default](screenshots/academy-science-light-default.png), [lesson-science-light-quiz](screenshots/lesson-science-light-quiz.png) and [lesson-math-light-default](screenshots/lesson-math-light-default.png).
5. **Do drop the app shell inside a lesson.** The players have no sidebar or top bar: an exit cross at the top left, transport controls as 32px ghost icons, and in the science and math players the tutor field stays docked on screen (the Ask Tutor pill at the bottom, the Ask gauth field in the 360px column). See [lesson-science-light-default](screenshots/lesson-science-light-default.png), [lesson-math-light-default](screenshots/lesson-math-light-default.png) and [lesson-history-light-default](screenshots/lesson-history-light-default.png).
6. **Don't copy the missing focus ring.** 42 of the 57 controls given keyboard focus show no change, Create Course and Start among them; use the 2px `#0064e0` ring 3px out that the science lesson's own controls draw. See [create-course-button-focus-visible](components/crops/create-course-button-focus-visible.png), [start-button-focus-visible](components/crops/start-button-focus-visible.png) and [quiz-option-focus-visible](components/crops/quiz-option-focus-visible.png).

## Rebuild

```bash
python3 tools/build_tokens.py
```

```bash
python3 tools/build_style_guide.py
```

```bash
python3 tools/build_components_md.py
```

`build_tokens.py` reads `raw/css-vars.json` and `raw/component-tokens.json` and writes `tokens.json`; it refuses a value that is not the DTCG type it claims and an alias that points at nothing. `build_style_guide.py` renders `style-guide.html` from `tokens.json` and `tools/style-guide.template.html`, turning every token into a CSS variable so the page cannot drift from the file. `build_components_md.py` writes `components.md` from `raw/components-computed.json`, `raw/layout.json`, `tokens.json`, the screenshots and `icons/INDEX.tsv`. All three are deterministic: re-running them on this commit reproduces their files byte for byte. Edit the raw inputs or the builders, never the generated files.

`tools/capture/` holds the kit the captures came from. The Playwright scripts take `PLAYWRIGHT` as the path to a Playwright install's `index.mjs` when `playwright` is not resolvable from where they run.

```bash
PLAYWRIGHT=/path/to/playwright/index.mjs node tools/capture/measure.mjs academy unit
```

`measure.mjs` takes page names (`promo home academy create unit science math history atlas story news mobile signin trial plus footer blog forms quizright`) and merges into `raw/components-computed.json`, dropping the entries a re-run page no longer produces; then `node tools/capture/build-measurements.mjs` rewrites `raw/measurements.md`. `public.mjs` takes the screenshot names to re-take (`RAW=<scratch dir> node tools/capture/public.mjs academy-math,mobile-atlas`), and `python3 tools/capture/quantize.py <scratch dir>` stores them. `vars.mjs`, `foundations.mjs`, `icons.mjs` (with `icon-names.tsv` naming icons by geometry hash) and `layout.mjs` rewrite their raw files whole. The science lesson takes about four minutes to reach its quiz, so `measure.mjs science` is slow. `lib.mjs` holds the shared helpers.
