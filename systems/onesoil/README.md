# OneSoil

OneSoil is a precision-agriculture product. This package records the public marketing site at https://onesoil.ai/en and the public help center at https://help.onesoil.ai/en/, signed out, on 2026-11-19. No account was used. The site paints one light theme. Desktop readings are 1440 by 900 CSS pixels. The phone reading is 390 by 844 CSS pixels.

### Principles

1. Use the cream page and the green pill for the primary action.
2. Keep headlines in Geologica at a tight negative tracking.
3. Use the black pill for the secondary nav action.
4. Treat the help center as a different surface.
5. Do not invent a dark theme.
6. Do not submit the contact form to learn validation.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

The T3 preview tab opened https://onesoil.ai/ and landed on https://onesoil.ai/en without a challenge. Computed custom properties, button, type, and field styles were read in that tab at 1440 by 900. The preview browser then returned "The browser is not producing screenshot frames", so screenshots were not taken there.

The same public URLs were loaded again in headless Playwright after that probe also returned no challenge. Screenshots, crops, hover, focus, the Products menu, the help center, and the 390px home came from that session. app.onesoil.ai was opened once, returned an empty Graphik page, and was not measured further.

Colours and sizes in tokens.json are those computed values. A rem is converted to px at the measured 16px root and marked Derived. The pill radius is Derived from a computed full-circle value.

## What to distrust

Screenshots are 256-colour PNGs. Read colours from tokens.json, not from the photos in the shots. The green hover is an oklab alpha, not the flat #27AE60. The glass nav is white at 0.4, not #FFFFFF. Help center green #30BF3C is a different product. `--error` was declared and never painted. The app shell was empty, so Graphik in that response is not a marketing font.

## Fonts

Geologica is the marketing face, self-hosted as woff2 from onesoil.ai, with a local Arial fallback named "geologica Fallback". The token stack is `geologica, system-ui, sans-serif`. The font files are not in this package. The help center uses Noto Sans and is not the marketing stack. Mono is the Tailwind default and is not used for body text.

## Do and don't

- **Use the cream page and the green pill for the primary action.** The home page sits on #F6F4EF and the only filled green control in the nav is Try Free. See [home-light-default.png](screenshots/home-light-default.png).
- **Keep headlines in Geologica at a tight negative tracking.** The 72px hero uses -0.04em and weight 400, with one span in #1E9852. See [home-light-default.png](screenshots/home-light-default.png).
- **Use the black pill for the secondary nav action.** Schedule a demo is #151515, not an outline. See [button-secondary-default.png](components/crops/button-secondary-default.png).
- **Treat the help center as a different surface.** It is Noto Sans on #30BF3C, not the marketing cream. See [help-light-default.png](screenshots/help-light-default.png).
- **Do not invent a dark theme.** None was on the page.
- **Do not submit the contact form to learn validation.** It asks for a phone number, and this capture did not enter one.
