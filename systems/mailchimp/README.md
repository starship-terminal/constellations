# Mailchimp design reference

A token set and component reference for Mailchimp's signed-out public surfaces, for building marketing and log-in pages in the style of the real thing. It was read from **mailchimp.com** and the signed-out card at **login.mailchimp.com** on 2026-11-18, in headless Chromium at 1440 x 900 and 390 x 844. Captured: home, pricing (`/pricing/marketing/`), features, about, and the log-in card, plus 390px passes on home, pricing, features and log-in. Refreshed 2026-11-21: the same public pages were photographed again, and [site-tree.md](site-tree.md) maps which homepage control opens which page, menu, or dialog. The empty login and signup walls were photographed and not entered. [login-review.json](login-review.json) records what was offered and what was not submitted.

Mailchimp ships one light marketing system on its Plums/CXP CSS. The home hero is a dark band with white Means Web at 64px. Primary actions are yellow `#ffe01b` with caviar ink `#231e15` and a 1px caviar stroke. UI and body on the marketing site are Tally, then Graphik Web. The log-in card is a separate Graphik Web surface: a teal submit `#017e89` and ink `#21262a`. It does not share the marketing token layer.

The account and campaign builder behind log-in were never reached. Signup was not started. Plan trial links were measured and never followed. Checkout was not started. OneTrust and the home survey were hidden and never submitted.

## Brief

### Principles

1. Do spend yellow on the trial.
2. Do put the home hero on the dark band.
3. Do keep the two faces apart.
4. Do use the pill radius on marketing controls.
5. Don't style the signed-in product from this package.
6. Don't invent a dark theme.
7. Don't follow a trial link and call it captured.
8. Don't copy the wordmark or the photography.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every colour, radius, length and font on this package is one of two kinds, and `$extensions.source` on each token says which:

- **Declared.** `css-var --name (light)`: a custom property in mailchimp.com's stylesheets, harvested by `tools/capture/vars.mjs` from the live home page's network sheets plus inline style blocks, re-parsed with CSSStyleSheet, and resolved on a probe document at 1440 x 900. The site declares no painted theme scope, so the dark token set is left empty on purpose.
- **Measured.** `computed …` or `measured …`: a computed style or bounding box read from the live DOM by `tools/capture/public/measure.mjs`, with a matching crop in `components/crops/`.

Consent overlays were hidden in CSS and never answered. Nothing was signed into, submitted, purchased, or followed through an OAuth flow. The log-in username field was typed into with a placeholder address and then cleared. Log in was never clicked.

## What to distrust

- **The home page embeds a Navattic demo.** Its sheets (`capture.navattic.com`) declare Tailwind `--color-*`, `--radius-*`, `--ease-*` and `--spacing`. Those values are not Mailchimp's and are not in [tokens.json](tokens.json). The harvest now drops any sheet whose host is not mailchimp.com.
- **The log-in card is a different surface.** It uses Graphik Web without Tally, ink `#21262a`, a white field, and a teal submit `#017e89` at 36px tall. Do not mix those literals with the yellow marketing CTA. There is no `component.login.*` group in the token file. The measured values live in [components.md](components.md).
- **The plan card root paints nothing.** `.singlePlan__planCardCell` measured 370 x 508.25 with a transparent background. The white card look is painted by children. The trial link inside it is [price-cta](components/crops/price-cta-default.png), 338 x 43.5, yellow `#ffe01b`, radius 26px.
- **The Resources panel root is transparent.** `section.iaNav__panel.expanded` measured 1440 x 507.5 with no box-shadow on the section itself. Read the open menu from [home-light-menu-resources](screenshots/home-light-menu-resources.png).
- **The announcement reading is the link, not the strip.** `announce-bar` is the "Start today." link, 64.83 x 16, white 13px type. The strip around it is visible in [home-light-default](screenshots/home-light-default.png).
- **Presses are forced.** `pressed` states were read with `CSS.forcePseudoState`. A script-driven mousedown look is uncaptured.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs. Read exact colours from the tokens or `raw/`, not from the pixels.
- **Display type is computed, not a `:root` custom property.** Means Web is the computed face of the home hero (64px/400, line-height 76.8px, letter-spacing -1.2px). `--copy-jumbo-size` is 80px and is not what the home hero paints.

- **Viewport-relative custom properties in [raw/css-vars.json](raw/css-vars.json) were resolved at 1280 x 720, not 1440 x 900.** Their notes say 1440 x 900, but the probe page had Playwright's default viewport. `--display-text-size` (`4.5vw`) reads 57.59px where 1440 gives 64.8px, the five heading sizes are low by the same 11%, and `--nav-height`, a calc on `100vw`, is low too. No token is built from them. `tools/capture/vars.mjs` now gives the probe the 1440 x 900 viewport; the values need a recapture.

## Fonts

- **Means Web** is the display face. It draws the home hero at 64px/400 (white on the dark band), the features and about mastheads at 48px/400 in caviar, and the phone hero at 36px/400. The computed fallback is Georgia, Times, Times New Roman, serif.
- **Tally**, then **Graphik Web**, is the marketing UI stack (`--typeface--base`). Nav labels and the trial pill are 13px/700. Body copy declares 16px.
- **Graphik Web** draws the log-in card, without Tally. The username field is 17px/400. The submit is 14px/500.
- None of these faces is bundled here. The style guide falls back to system sans. Licences were not published on the pages that were read.

## Do and don't

1. **Do spend yellow on the trial.** `#ffe01b` marks Start Free Trial, with caviar type and a 1px caviar stroke. See [nav-trial](components/crops/nav-trial-default.png) and [hero-cta](components/crops/hero-cta-default.png).
2. **Do put the home hero on the dark band.** The masthead is white Means Web at 64px/400, not caviar on white. Interior pages such as features invert that: caviar Means Web at 48px on a light field. See [home-light-default](screenshots/home-light-default.png) and [features-light-default](screenshots/features-light-default.png).
3. **Do keep the two faces apart.** Means Web is display only. Tally, then Graphik Web, is every marketing control. Graphik Web alone belongs on the log-in card. See [hero-h1](components/crops/hero-h1-default.png) and [login-submit](components/crops/login-submit-default.png).
4. **Do use the pill radius on marketing controls.** `--cta-border-radius` is 32px. The measured Standard trial link is 26px. The `--radius-*` scale belongs to the embedded Navattic demo and is not a Mailchimp token. See [price-cta](components/crops/price-cta-default.png).
5. **Don't style the signed-in product from this package.** Audiences, the email designer, automations and reports need sign-in and were never reached. The log-in card is the boundary. See [login-light-default](screenshots/login-light-default.png).
6. **Don't invent a dark theme.** Mailchimp's public pages paint light only. The empty `dark` set is a file shape, not a palette. See [home-light-full](screenshots/home-light-full.png).
7. **Don't follow a trial link and call it captured.** Plan and signup URLs were measured and never opened. Checkout was not started. See [price-cta](components/crops/price-cta-default.png).
8. **Don't copy the wordmark or the photography.** The Mailchimp mark and the product photography are Mailchimp's published artwork. Borrow structure and proportion. See [nav-logo](components/crops/nav-logo-default.png).

## Rebuild

From the repo root. Playwright is `~/.design-systems/pw/node_modules/playwright/index.mjs`. Scratch stays in `~/.design-systems/mailchimp/` and never enters git.

```sh
cd systems/mailchimp
export PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs
export PYTHON=python3
export CAPTURE_DATE=2026-11-18
node tools/capture/vars.mjs
node tools/capture/public/public.mjs
node tools/capture/public/measure.mjs
node tools/capture/motion-probe.mjs --urls https://mailchimp.com/,https://mailchimp.com/pricing/marketing/,https://login.mailchimp.com/
python3 tools/capture/quantize.py ~/.design-systems/mailchimp/raw-shots
python3 tools/build_tokens.py
python3 tools/build_style_guide.py
python3 tools/build_components_md.py
node tools/capture/public/build-measurements.mjs
```

`make brief`, `make design-md`, `make grade` and `make check` run from the repo root.
