# Bloomberg design reference

A token set and component reference for Bloomberg's public news surface — for building financial-news surfaces in the style of the real thing. It was read from **bloomberg.com** on **2026-11-10/11**, signed out, in headless Chromium at 1440 x 900 (with a 390 x 844 mobile pass attempted): the Asia home front, the markets and economics fronts, a public article discovered at run time, the S&P 500 quote page, the gated Live TV page and the WordPress subscription-offers pages.

Bloomberg is worth a capture because it is a current reference for dense editorial chrome: an all-black header suite (utility strip, logo bar, section nav), a live securities ticker of dark pills, BWHaasGrotesk headlines with a tight story grid, the `#3523ff` CTA blue on its offer pages, and honest paywall furniture — the "Get unlimited access" band, the Claim This Offer button and the gated live player, all measured at rest and never crossed.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export bloomberg` prints them all with aliases resolved.

### Principles

1. Do keep the chrome black.
2. Do run the ticker as dark pills.
3. Do reserve the #3523ff blue for the buy action.
4. Do let the paywall be furniture.
5. Don't invent a second accent.
6. Don't ship a dark theme.
7. Don't round the chrome.
8. Don't treat throttled or gated surfaces as failures.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out site in headless Chromium:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) captures every stylesheet body (the site inlines its CSS-module sheets; response bodies plus inline `<style>` blocks are re-parsed with `CSSStyleSheet`) and writes every custom property to [raw/css-vars.json](raw/css-vars.json) binned `theme`/`app`/`vendor`/`utility`/`tailwind`. bloomberg.com declares almost no token layer — `:root` carries no custom properties and PerimeterX thinned this pass further — so every design token in tokens.json is a **measured computed value** read from the components below, not a var alias. [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec, [tools/build_tokens.py](tools/build_tokens.py) the sets.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context, hides the media-ui privacy-preferences modal where it mounts (never answered), and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state, plus `opened` on the sitemap/sign-in sheet/mobile drawer. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md).
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route with `.capture.json` sidecars; [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.
- **The article is discovered.** The first `/news/articles/` link on the home front is followed at run time and its URL recorded (`article` in [raw/components-computed.json](raw/components-computed.json)); a different run lands on a different story.

Nothing was subscribed, bought, signed into or submitted. The privacy modal was hidden, never answered. The paywall fence was never crossed.

## What to distrust

- **Readings past a masked bot signal.** The committed screenshots and readings were taken with `navigator.webdriver` masked, the flag bot checks read to spot automation. The capture scripts no longer mask it (not run since), so a recapture may record a walled route as a boundary instead of a reading.
- **One theme only.** The site paints light on every captured route; `tokens.json` ships no dark set. The /subscriptions offer hero is near-black by design, still light theme.
- **Measured, not declared.** bloomberg.com declares almost no `:root` custom properties; every colour/size token is a computed-style reading with the component it came from in `$extensions.source`.
- **PerimeterX throttled parts of this pass.** After a run of automated loads the site serves an "unusual activity / PRESS & HOLD" challenge for a while: the article route's screenshots and every 390px mobile load were challenge-gated on every retry, and [raw/css-vars.json](raw/css-vars.json) came back thin for the same reason. Those are recorded as gaps, not fabricated.
- **The sign-in sheet screenshot shows the challenge.** [home-light-signin](screenshots/home-light-signin.png) is the `/account/iframe/login` sheet mounted by the Sign In button — under PerimeterX throttling it renders the verification card inside the sheet. That is the honest surface this client saw.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs; read exact colours from tokens or the raw files.
- **The article is a sample**, not a fixed story.
- **`offer-header` was read from the wrong element.** It is the corporate utility bar at the top of /subscriptions ("Bloomberg the Company & Its Products ..."), not the offers page header. Needs a recapture; the script now targets the offers header class only (not run since).

## Fonts

**BWHaasHead** is the licensed headline face — the lead and article headlines. **BWHaasGroteskWeb** (Haas Grotesk for Bloomberg) is the licensed workhorse — nav labels, body text, ticker text and deks. **Avenir Next for Bloomberg** (AvenirNextPForBBG) is the licensed utility face — the thin top strip and its links. None is distributed; the style guide falls back to Helvetica/system. Two `@font-face` rules for BWHaasGroteskWeb (400/700, woff2+woff on assets.bwbx.io) are recorded in [raw/css-vars.json](raw/css-vars.json).

## Do and don't

1. **Do keep the chrome black.** The utility strip, logo bar and section nav run as one #000 stack; the page below is white paper with #000 ink. See [home-light-default](screenshots/home-light-default.png).
2. **Do run the ticker as dark pills.** Index chips sit in `#1c1c1c` rounded-8 pills with white text and a gain/loss marker; the strip is an edge-to-edge rail. See [ticker-pill-default](components/crops/ticker-pill-default.png).
3. **Do reserve the #3523ff blue for the buy action.** The electric blue appears on the offer Continue and nothing else in chrome — subscribe-adjacent controls on the news pages stay black-on-white. See [offer-cta-default](components/crops/offer-cta-default.png).
4. **Do let the paywall be furniture.** The fence is a `#1c1c1c` band with white copy and a white Claim button, placed inside the article flow — measured at rest, never crossed. See [paywall-default](components/crops/paywall-default.png).
5. **Don't invent a second accent.** Bloomberg's news surface is near-achromatic: black bars, white paper, one blue. Market gain/loss colour lives inside the pills, not as theme accents.
6. **Don't ship a dark theme.** None is offered on the captured surface; the dark offer hero is a layout block, not a theme.
7. **Don't round the chrome.** Bars, nav and the paywall band are square-edged; rounding (8px) is reserved for pills, buttons and cards. See [plan-card-default](components/crops/plan-card-default.png).
8. **Don't treat throttled or gated surfaces as failures.** The PerimeterX challenge, the paywall fence and the gated live player are the real signed-out surface; document them rather than styling past them.

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/bloomberg/`):

```sh
python3 tools/build_component_tokens.py        # raw/components-computed.json -> raw/component-tokens.json
python3 tools/build_tokens.py                  # -> tokens.json
python3 tools/build_style_guide.py             # -> style-guide.html
python3 tools/build_components_md.py           # -> components.md
node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir>    # full-colour PNGs -> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.

Live recapture (needs the site; Playwright at `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs`):

```sh
node tools/capture/vars.mjs                    # stylesheet harvest -> raw/css-vars.json
node tools/capture/public/measure.mjs          # computed styles + crops -> raw/components-computed.json
RAW=<scratch> node tools/capture/public/public.mjs   # screenshots -> <scratch>
```

PerimeterX throttles repeated loads: blocked routes log `BLOCKED` and keep earlier readings; wait and retry rather than forcing through.
