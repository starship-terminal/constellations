# Patterns

The public site is a dark marketing page with a floating navbar, a full-bleed hero, and a long footer. The signed-in app is behind Log in and Sign up. Those walls were photographed empty and not passed.

## App shell

The navbar is a pill, 1204px wide and 76px tall, inset 16px from the top of a 1440 page. The mark sits on the left. Store, Pro, AI, iOS, Windows, Teams, Enterprise, Blog, and Pricing sit in the middle. Log in is a quiet text link. Download is the only filled control in the bar.

At 390 the same links wrap in the bar. There is no hamburger and no drawer.

## Hero

The headline is "Your shortcut to everything." at 64px. Under it, one sentence, then Download for Mac, a requirement line ("macOS Tahoe and Apple Silicon required"), and two text buttons: Install via Homebrew and Download V1. An announcement link, "Introducing Raycast MCP", sits under those.

The red slash graphic behind the headline is a marketing illustration. It is not a token.

## Pricing

https://www.raycast.com/pricing is public. The page offers plan columns and a model list. Select Plan was not clicked, so checkout was not entered.

## Store

https://www.raycast.com/store is a public catalog. Search is a field. Share controls sit on listings. No listing was installed.

## Download

There is no download page. Download and Download for Mac point at `/download/mac`, which starts a file. That navigation was cancelled. Homebrew opens a dialog with a terminal command. Download V1 opens a confirm dialog. Neither confirm control was used.

## Forms

Feedback at `/feedback` is a public form: category, email, version, details, and a file input. It was photographed empty and not sent. The footer newsletter field was left empty.

## Auth wall

Log in and Sign up are on `www.raycast.com`, not a separate app host. Both show four identity buttons and an empty form. The signed-in product was not opened.

## Empty

A path that does not exist returns 404 and the heading "Page not found". The title of that response was "Profile Not Found".
