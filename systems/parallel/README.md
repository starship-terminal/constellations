# Parallel

Parallel is the job marketplace at [useparallel.com](https://www.useparallel.com/). This package records the public marketing pages and the signed-out login and signup, measured on 2026-11-19. Desktop shots are 1440×900. Phone shots are 390×844. The site paints one light theme. Signed out the whole time.

This is useparallel.com. parallel.ai was not opened.

Signup is a LinkedIn button. No email was entered. LinkedIn was not clicked. The pricing trial was not started. No card, phone, or company SSO was entered.

### Principles

1. Paint the page `#fbfaf9` and the auth card white with a 32px radius.
2. Use `#1f1f1f` for the primary action and white for its label.
3. Set display type in Advercase Demo.
4. Use the orange gradient for the trial action and the search arrow.
5. Leave the theme light.
6. Use Advercase Demo for the headline.
7. Leave LinkedIn, the trial, and employer signup unfollowed.
8. Keep this package on useparallel.com.

## How the values were read

The T3 preview tools were not registered in this session. `search_tool` stayed partial, and `use_tool` on `preview_status` returned `preview_status is not a valid MCP tool name`. The public pages were then opened in headless Chromium. `/`, `/pricing`, `/login`, `/signup`, `/employers`, `/manifesto`, `/app/candidate/search`, `/blog`, and `/about/privacy` returned HTTP 200 with no Cloudflare challenge. A made-up route returned the product's own 404.

Computed styles were read with `getComputedStyle` at 1440×900 and, for the phone shots, at 390×844 with device pixel ratio 2. Declared custom properties (`--color-black`, `--color-yellow`, `--color-orange`, `--app-background`, `--shadow-primary`, `--font-family-primary`, and the rest in [raw/measured.json](raw/measured.json)) were read from the stylesheets. Screenshots were quantised to 256 colours. Read colours from the tokens, not the PNGs.

Login validation was triggered with the string `not-an-email` and a one-character password. The page painted `Password must be at least 8 characters long` in rgb(239, 7, 7). The fields were cleared. No account was submitted.

## What to distrust

The button element's own `color` on Sign in computed rgb(0, 0, 0). The painted label is a child at rgb(255, 255, 255). The token uses the painted label.

`--app-background` is declared `#f4f3f1` and resolves to `#fbfaf9`. The body fill is the resolved value.

`--font-family-primary` names Work Sans and `--font-family-secondary` names Termina. The homepage headline computed Advercase Demo. Login type computed Inter. The price figure computed the Next font `__rulesFont_d96771`. Work Sans and Termina were not the faces on the captured controls.

`--shadow-primary` and `--shadow-secondary` are declared hard offsets. The login card's computed shadow is a soft stack. The hard offset was not on a captured control.

The homepage hero is a photograph. Its colours are not tokens. The orange search arrow and the pricing trial button share a gradient from rgb(239, 110, 7) to rgb(255, 183, 125). That is separate from the declared `--color-orange` `#fe8a11`, which is the "7 day trial" text.

Phone shots are 780×1688 pixels because the device pixel ratio was 2. The CSS viewport was 390×844.

Reduced motion was not emulated. The 150ms colour transition is the computed duration at rest.

## Fonts

Advercase Demo is the display face, loaded from `/font/AdvercaseDemo-Regular.woff2` and `AdvercaseDemo-Bold.woff2`. It is not shipped here. Inter is the UI face, loaded as a Next font. The price figure uses a Next font whose id is `__rulesFont`. The tokens call that face Rules. Work Sans, Cousine, and DM Mono are declared and loaded. They were not the faces on the captured controls. Fallbacks in the tokens are `system-ui` and `arial`.

## Do and don't

- Paint the page `#fbfaf9` and the auth card white with a 32px radius. [login-desktop.png](screenshots/login-desktop.png)
- Use `#1f1f1f` for the primary action and white for its label. [button-primary-default.png](components/crops/button-primary-default.png)
- Set display type in Advercase Demo. [home-desktop.png](screenshots/home-desktop.png)
- Use the orange gradient for the trial action and the search arrow. [pricing-desktop.png](screenshots/pricing-desktop.png)
- Leave the theme light. The captured site has no dark theme.
- Use Advercase Demo for the headline. Work Sans and Termina were declared and were not the computed face.
- Leave LinkedIn, the trial, and employer signup unfollowed. Those were not entered.
- Keep this package on useparallel.com. parallel.ai was not captured.
