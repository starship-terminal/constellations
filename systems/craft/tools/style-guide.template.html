Palette

The core set carries the declared Tailwind --color-* primitives plus the brand entries; the light roles alias the shadcn-style semantic layer (--background/--card/--popover/--primary/--accent/--muted/--destructive, the --sidebar-* set, --border/--ring/--input). There is no dark theme — the only painted dark surface is the footer.

Spacing and radius

Craft is a pill system too: rounded-full (the measured 3.36e7px maximum) on every CTA, the billing toggle and the platform buttons; a 26px radius floats the nav pill; the declared ramp runs --radius 10px through --radius-4xl 32px (16px cards, 24px team card + footer). Borders are a 9% ink hairline plus the 12% ink focus ring.

Type

Two families: Untitled Serif carries every display heading at 400 (66px hero, 70px learn, 54px page titles and prices, 48px mobile); Untitled Sans carries UI (16px 400 body/links, 500 on pills and FAQ rows, 14px footers). The declared ramp runs --text-xs 12px through --text-7xl 72px. Samples fall back to system fonts.
