# Craft Docs

Public marketing site at https://www.craft.do/. One light theme. Hand-written from measured tokens on 2026-11-22. The catalog generator was not run. `catalog.json` was left alone.

## Color

Page `#fcf9f7`. Card and popover `#ffffff`. Ink, primary, and footer `#030302`. Muted text `#030302` at 50% (`#03030280`). Border `#030302` at 9% (`#03030217`). Focus ring `#030302` at 12% (`#0303021f`). Declared accent `#427e8a`. Destructive `#bb433a`.

The docs login wall is a different system. Its Continue button is `#2e6de9`. Its text is `#1a1c1e`.

## Type

Untitled Serif for display. Homepage h1 is 66px, weight 400, line-height 66px, tracking -1.98px.

Untitled Sans for marketing UI. Body is 16px / 24px, weight 400. Pills use weight 500.

The login wall uses Inter. The email field is 13px medium. Continue is 14px semibold.

Neither family is shipped.

## Radius

Nav 26px. Footer 24px. Pills are fully round (computed CSS maximum, written as 9999px). Declared steps: 0.625rem, 1rem, 1.5rem, 2rem. Auth Continue is 10px.

## Space and size

Spacing unit `0.25rem`. Header CTA 36px tall, padding 8px 14px. Hero CTA 48px tall, padding 16px 32px. Nav height 52px at 1440. Auth controls are 40 by 320.

## Elevation

Nav shadow: `0 12px 12px 2px rgba(0,0,0,0.1), 0 2px 4px -1px rgba(0,0,0,0.06)`. Declared drop shadow: `0 25px 25px #00000026`.

## Layout

Breakpoint large is 64rem. Widest declared container is 80rem. Desktop captures are 1440 by 900. Phone captures are 390 by 844 at devicePixelRatio 2.
