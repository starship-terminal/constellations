# Kith

Hand copy of the measured public shop tokens. Not written by `make design-md`. This pass does not edit catalog.json.

| Role | Value | Source |

## Typography

Proxima Nova is the UI face. Georgia is the display face. The hero and About are 28px Georgia 400. Product and collection titles are 18px Georgia 400. Nav is 12px Proxima Nova 500, uppercase, letter-spacing 3px. Body is 12px, weight 300.

| Style | Size | Weight | Line | Tracking |
|---|---|---|---|---|
| display | 28px | 400 | 37.324px | 1.4px |
| title | 18px | 400 | 23.994px | 0.9px |
| nav | 12px | 500 | 15px | 3px |
| button | 12px | 500 | 15px | 1.2px |
| body | 12px | 300 | 15px | 0.6px |
| footer heading | 10px | 700 | 15px | 0.5px |

## Geometry

The header is 66px, padding 18px 24px. The logo is 54 by 23. Shop now, size chips, and Select a size are 41px tall with a 0 radius. Size chips are 79px wide.

## Components

Shop now on the hero is a white outline, uppercase 12px, padding 12px 24px. Select a size is a gray bar, `#828282`, white label, same height, square corners. Size chips are square, 1px `#d9d9d9` border, on the black buy column.
