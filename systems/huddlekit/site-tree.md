# Huddlekit public site tree

Mapped 2026-11-21 from [https://huddlekit.com/](https://huddlekit.com/) while signed out, before the refresh screenshots. Desktop readings are 1440 CSS pixels wide. The page title is "Huddlekit | Visual annotation tool for website feedback". The marketing site paints light: `html` has no theme class, no `data-theme`, and `color-scheme` is `normal`. There is no theme switch on the homepage.

A control that opens a login, signup, or identity-provider wall stops that branch. Nothing was typed. No form was submitted. Google, Apple, and other identity providers were not clicked. Cookie Decline and Accept were not pressed while mapping this tree.

Shots of opened states live in [screenshots/site-tree/](screenshots/site-tree/).

## Login wall

Sign in, Get started, Get started for free, and Login / Sign up all go to `https://app.huddlekit.com/login` with campaign query parameters. Opening that URL without those parameters shows "Sign in to Huddlekit", "Continue with Google", and "Continue with email". That is the anonymous login wall. The branch stops there. No email, password, or code is entered. Continue with Google is not clicked. Continue with email is not clicked on this pass.
