# Clipchamp design reference

A token set and component reference for Clipchamp's public surface — for building clean light marketing pages and a purple-accented control language in the style of the real thing. It was read from **clipchamp.com** on **2026-11-17**, signed out, in headless Chromium at 1440 x 900 and 390 x 844: the marketing routes (home, pricing, features, products, for-work, education, templates, company, blog, what's new, stock and the screen-recorder page), plus the public sign-in card on **app.clipchamp.com** as a boundary.

Clipchamp is worth a capture because Microsoft's video editor runs a server-rendered React build that carries **two declared token layers at once**: the marketing sheet's own `--color-*` ramps (a purple brand ramp, blue and pink accents, grey ink steps, link roles and social colours on `:root`) and a full **Fluent UI v9** layer on `.fui-FluentProvider` (colorBrand*/colorNeutral*, the borderRadius*/spacing*/duration*/curve*/shadow* scales, fontSize*/fontWeight*/lineHeight* steps, fontFamilyBase = Segoe UI) — with the Fluent brand slot already themed to Clipchamp purple (`colorBrandBackground` = purple-80 `#6453e4`). It paints a **single light theme**: white `#ffffff` ground, `#fbfbfc` off-white bands and `#313242` dark content bands inside it. The marketing face is `segoeVariableFont` (Segoe UI Variable); the sign-in app uses plain Segoe UI — two stacks, both measured. The signature micro-motion is a **1.05 hover scale with a 0.2s ease** on every button. **Boundary:** the editor itself, checkout and every OAuth/account action sit behind sign-in; the app.clipchamp.com/login card was measured at rest and the email path — where the only credentials field lives — was never crossed; nothing was typed, submitted or authenticated.

## How the values were read

Every number in [tokens.json](tokens.json) and [raw/measurements.md](raw/measurements.md) is either a **declared** CSS custom property harvested from the live stylesheets (`tools/capture/vars.mjs` — `:root` marketing vars plus the `.fui-FluentProvider` scoped layer, read as a fallback when a name is not on `:root`) or a **measured** computed style read off the painted DOM (`tools/capture/public/measure.mjs`). Screenshots come from `tools/capture/public/public.mjs`, a bounded Playwright shooter at 1440 x 900 and 390 x 844 that tiles pages over the GPU-texture cap into `.partN` files (whatsnew ~15.6k px, mobile-home ~7.2k px at DPR 2). Component crops are element screenshots taken at measurement time. States: `hover` is a real pointer hover, `focus-visible` a real keyboard focus (or `el.focus()` where noted), `pressed` a `CSS.forcePseudoState` CDP call — each state's `via` field in the JSON says which. The nav dropdown is hover-held: it was re-opened inside the measurement reset so each state reads the painted panel; a submenu link's focus/pressed states close the panel under the pointer and are honestly absent. The cookie banner and promo overlays were hidden without answering them; consent controls were never clicked.

## What is not here

- **Captured with the automation flag masked.** The public capture (`tools/capture/public/`) hid `navigator.webdriver` from every page, so the committed readings and screenshots it took were taken past that mask. The scripts no longer hide it (edited, not run); a recapture that meets a bot check records it as a boundary.
- **The editor.** app.clipchamp.com's editing surface, templates' interactive previews, export and every OAuth/account action sit behind sign-in — never crossed. The sign-in card was measured at rest; the email path (the only field) was not entered.
- **Dark theme.** The site paints one light theme; dark bands inside it are measured as `light.surface.dark`, not a second theme.
- **Checkout.** The Premium plan's purchase flow was never entered; pricing was read signed-out.
- **Challenge-blocked passes.** Cloudflare intermittently serves a security check on marketing routes; blocked attempts were retried and only real paints were kept — any route that could not be captured cleanly is absent rather than faked.
