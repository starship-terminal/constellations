# Ride with GPS public chrome

Signed-out capture of [https://ridewithgps.com](https://ridewithgps.com) on 2026-11-22. Values are the live computed styles. The token file is [tokens.json](tokens.json).

## Colour

The page shell is ink `#0b1c1c`. The header sits on that ink at 80% opacity, `rgba(11, 28, 28, 0.8)`. Primary actions are orange `#fa6400` with white type. Inline links on the dark fold are yellow `#ffd771`. A later homepage band uses pistachio `#ebeed7`. A later heading uses purple `#96aaff`. Those two were measured and not photographed.

The hero heading's computed color is transparent. The letters are filled by the topo image `bg-topo-white`, and they read white on the photograph.

## Type

Body, nav, and buttons use aktiv-grotesk. Nav links are 15px, weight 700. Body copy is 16px, weight 400, line-height 24px. Headings use a hashed display family, weight 400. The homepage and Route Planner headings are 116px with line-height 104.4px. The next heading step on the homepage is 51.2px. Font files are not in this package.

## Controls

Get Started is 148 by 48, padding 12px 32px, radius 3px. Join for free and Plan a Route are 159 by 43, same padding, same radius, same orange. Log In is a text link, white, 15px, weight 700, no fill.

## What this file does not cover

Login, signup, and the new-route page were not opened. Hover, focus, dark theme, and phone width were not captured. `catalog.json` and `webapps-manifest.json` were left alone.
