# Mapbox design reference

A token set and component reference for Mapbox's public surface. It was read from **www.mapbox.com** and **docs.mapbox.com** on **2026-11-18**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. The capture covers the marketing home, Maps, Navigation, pricing, the public contact page, and the public docs index, GL JS guides, and style-spec layers page.

Mapbox paints a white page, near-black text (`#0e1012`), and one blue (`#007afc`) for pills, links, and the sign-up control. Type on the marketing site is Cera Pro. The docs site uses Open Sans. The nav carries `color-mode-light`. The captured docs pages set `data-theme="light"`. No dark theme was switched on.

**Boundary:** the account console, token creation, and Studio sit behind sign-in on account.mapbox.com and studio.mapbox.com. Those surfaces were never opened. No token was created. The contact form was focused and its request-type list was opened. It was not submitted. The OneTrust banner was hidden, never answered.

### Principles

1. Do paint the page white and the primary action `#007afc`, with white text on the pill.
2. Do use a full pill radius (100px) on nav and hero buttons.
3. Do set marketing headlines in Cera Pro at weight 700.
4. Do keep secondary text at `#333943` and muted text at `#566171`.
5. Don't follow the sign-up or log-in links when reproducing this surface.
6. Don't invent a dark theme from these tokens.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every colour ramp came from Webflow custom properties on www.mapbox.com (`--_colors---blue--blue50` and the rest), read through the CSSOM and resolved in a probe document by [tools/capture/vars.mjs](tools/capture/vars.mjs). Two stylesheets were cross-origin and unreadable. Their values were not guessed. Component sizes, hovers, and focus came from `getComputedStyle` in [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs). Pressed states are a CDP `:active` force, not a real navigation. Screenshots came from [tools/capture/public/public.mjs](tools/capture/public/public.mjs). Each sidecar records `innerWidth` 1440 or 390.

## What to distrust

- The signed-in console, tokens, and Studio were not captured. Do not infer them from the marketing maps.
- The marketing site and docs.mapbox.com are different stacks. Docs type is Open Sans. Marketing type is Cera Pro.
- Screenshots in [screenshots/](screenshots) are 256-colour PNGs. Read colours from [tokens.json](tokens.json).
- The hero CTA fill lives on `.button_inner`. The anchor itself is transparent. The token uses the painted fill.
- `pricing-number` is a `display: none` input beside the visible range. Its box is 0 x 0. The slider is the visible control.
- The contact page has no text area. The request type is a HubSpot combobox, not a native select.
- No dark theme was captured. The nav class is `color-mode-light`. Docs `data-theme` was `light`.

## Fonts

The marketing bundle declares **Cera Pro** (300, 400, 500, 700, plus italic) and **Open Sans** (400, 700). The home h1 computes to `"Cera pro", "Trebuchet MS", sans-serif` at 56px / 70px, weight 700. Docs body computes to Open Sans. No font file is in this package.

## Do and don't

- Do paint the page white and the primary action `#007afc`, with white text on the pill. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
- Do use a full pill radius (100px) on nav and hero buttons. See [components/crops/nav-signup-default.png](components/crops/nav-signup-default.png).
- Do set marketing headlines in Cera Pro at weight 700. The home h1 is 56px / 70px. See [components/crops/hero-h1-default.png](components/crops/hero-h1-default.png).
- Do keep secondary text at `#333943` and muted text at `#566171`. See [screenshots/pricing-light-default.png](screenshots/pricing-light-default.png).
- Don't follow the sign-up or log-in links when reproducing this surface. They leave for account.mapbox.com. See [components/crops/nav-signup-default.png](components/crops/nav-signup-default.png).
- Don't invent a dark theme from these tokens. The captured pages are light only. See [screenshots/docs-light-default.png](screenshots/docs-light-default.png).
