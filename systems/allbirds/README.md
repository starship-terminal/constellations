# Allbirds design reference

A token set and component reference for Allbirds' web storefront (allbirds.com, a Shopify store), for building in the style of a real sustainable-footwear retail product. It was read from www.allbirds.com on 2026-11-08, signed out, in headless Chromium at 1440 x 900 and 390 x 844: the home page, the Men's collection grid with its filter sheet, a product page (Men's Tree Runner NZ) through Add to Cart into the session cart drawer, the cart, search and account-login pages, and the Our Story, Materials, Help and Blog content pages. A public refresh on 2026-11-21 mapped the homepage controls in [site-tree.md](site-tree.md) and re-photographed those states. Nothing was bought, checked out, signed into or submitted.

Allbirds is the first retail commerce capture in the library. Its design is a clean Shopify theme on a warm undyed-wool ground: a black announcement strip, a rounded white nav bar, serif Self Modern headlines over Geograph UI, pill-shaped everything (buttons, fields, chips), and near-black ink rather than pure black.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export allbirds` prints them all with aliases resolved.

### Principles

1. Do keep ink, not black, on dark surfaces.
2. Do pill everything interactive.
3. Do pair Self Modern headlines with Geograph UI.
4. Do strike through unavailable options.
5. Do float the nav bar.
6. Don't introduce a second accent.
7. Don't sell the takeover cheap.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Everything was read from the running page, signed out, in headless Chromium.

- **Theme variables.** `tools/capture/vars.mjs` walked the live CSSOM and resolved every custom property the stylesheets declare (same-origin `theme.css` is readable; cross-origin sheets are read via `getComputedStyle`). Allbirds builds on Tailwind v4: the whole token palette sits in `@layer theme` on `:root`, and the 138 resolved entries land in `raw/css-vars.json` next to the `@font-face` rules and the per-selector transition index.
- **Component measurements.** `tools/capture/public/measure.mjs` opened each route, dismissed the geofencing dialog ("Where are we shipping to?", a `bg-black/50` `z-takeover` modal that scroll-locks the page) by choosing US and removing the section, then read computed styles, rects and paint layers for each component in each state (default, hover, focus-visible, pressed, open, filled, focused) and cropped them at 2x into `components/crops/`. Results merge into `raw/components-computed.json`; re-running a single page updates only its entries.
- **What was touched.** Region set to US once per page; the mega-menu, search overlay, filter sheet, size chips, Add to Cart, accordions and the mobile hamburger were pressed. Nothing was checked out, signed into or submitted; the cart stayed a session cart.
- **The cart drawer chain** was the flaky part: the Shopify buy box re-renders after geo resolution, so the runner clicks DOM-side (`domClick`) instead of through Playwright's actionability, picks a non-`.disabled` size chip, and finds the open drawer by geometry (the closed one stays mounted off-canvas at x=1440).
- **Generated from those readings.** `tools/build_tokens.py` writes `tokens.json` from `raw/component-tokens.json` (the token tree spec, each leaf naming its `var` or measured source) with `raw/css-vars.json` resolving the vars. `tools/capture/public/build-measurements.mjs` writes `raw/measurements.md`. `tools/build_style_guide.py` and `tools/build_components_md.py` write the guide and the inventory from `tokens.json`, `screenshots/` and the crops. `tools/capture/quantize.py` re-encodes screenshots to 256-colour PNGs.

## What to distrust

- **The checkout footer.** The checkout pill and the express-wallet row (PayPal, Shop Pay, G Pay, Amazon Pay) render inside the cart drawer but live on Shopify-hosted surfaces the page DOM cannot introspect — they are visible in [cart-drawer-open](components/crops/cart-drawer-open.png) yet carry no computed styles. `checkout-button` and `express-button` are flagged missing in `components-computed.json` for that reason, not because they are absent.
- **Intermittent mounts.** The PDP gallery tooltip pill and the mobile "Shop with AI" chip mount media-load dependent; their measurements come from runs where they rendered. The geofencing dialog mounts on first visits only and was removed before other captures, so it has screenshots from early runs but no entry.
- **Hydration windows.** The buy box, nav bar and filter markup hydrate late and differ between loads; a measurement flagged `missing` with no states means it was not on the page that run, not that it does not exist.
- **Screenshots are 256-colour PNGs.** Read exact colours from tokens.json or the raw files, never off a PNG.
- **The cart drawer was reached by pressing Add to Cart.** The committed `cart-drawer` reading and the `*-cart-drawer` screenshots show a one-item session cart the capture created on the live store. The capture scripts no longer press Add to Cart (they open the header cart instead, so a recapture shows the empty drawer); not run since.
- **`size-tab-active` was read from the wrong element.** Both size tabs were read from the same "WOMEN'S SIZES" tab, so the active tab (MEN'S SIZES, underlined) has no reading; it needs a recapture. The script now targets each tab by its exact label (not run since).
- **`accordion` hover was read on the expanded row**, because the open state ran before hover and nothing collapsed the row. `size-button` has no selected state, though an older description said it was measured after a click. The script now orders the states and says so (not run since).

## Fonts

Three families, all Allbirds' own woff2 served from theme assets (`fonts` in [raw/css-vars.json](raw/css-vars.json), ten `@font-face` rules): **Geograph** for all UI text, **Self Modern** for headlines and product titles, **Akkurat Mono** for small labels. None is on Google Fonts; the style guide falls back to the system sans, Georgia and ui-monospace. The Shopify-hosted login uses Shop's own faces (GTStandard, lBKuE1Nf), which are not part of the theme's tokens.

## Do and don't

1. **Do keep ink, not black, on dark surfaces.** The promo bar, primary pill fill and footer bands are `#212121` `ink`, never pure black; text on them is `#ffffff`. See [home-light-default](screenshots/home-light-default.png).
2. **Do pill everything interactive.** Buttons, the subscribe field, chips and swatches are fully rounded (`radius.pill`); only size chips and small squares use the 2-12px steps, and photo cards take the 20px `radius.card`. A rectangular button is wrong. See [cart-drawer-open](components/crops/cart-drawer-open.png).
3. **Do pair Self Modern headlines with Geograph UI.** Serif for hero, section and product titles; Geograph everywhere else; nav links and buttons are uppercase `xs medium` with `tracking-widest`. See [product-light-default](screenshots/product-light-default.png).
4. **Do strike through unavailable options.** Sold-out sizes keep the chip shape but render `status.sold-out` grey with a line-through at reduced opacity — never hide them. See [size-button-disabled](components/crops/size-button-disabled-default.png).
5. **Do float the nav bar.** The header is a white rounded card (`component.header` 12px radius, `elevation.header` shadow) sitting over the `natural-white-25` page, not a full-bleed bar. See [home-light-default](screenshots/home-light-default.png).
6. **Don't introduce a second accent.** CTAs are ink-on-white or white-on-ink; the palette's reds, greens and ambers are status-only (errors, badges, warnings). Colourful buttons are off-brand. See [collection-light-default](screenshots/collection-light-default.png).
7. **Don't sell the takeover cheap.** Drawers, sheets and dialogs all ride the same `z-takeover` layer over a `bg-black/50` dim and slide on `easing.snappy`; nothing else sits above `zIndex.header` 80. See [collection-light-filter](screenshots/collection-light-filter.png).

## Rebuild

```sh
# from the package root (systems/allbirds); Playwright comes from ~/.design-systems/pw
node tools/capture/public/public.mjs        # the screenshot tour into raw/full/ (full colour)
node tools/capture/public/measure.mjs       # component readings into raw/components-computed.json
                                          # (or a page list: home,collection,product,search,account,mobile)
node tools/capture/vars.mjs                 # CSSOM variables into raw/css-vars.json
node tools/capture/public/build-measurements.mjs   # raw/measurements.md
python3 tools/capture/quantize.py raw/full  # 256-colour screenshots into screenshots/
python3 tools/build_tokens.py               # tokens.json from raw/component-tokens.json + css-vars.json
python3 tools/build_style_guide.py          # style-guide.html from tokens.json + the template
python3 tools/build_components_md.py        # components.md from the readings, crops and screenshots
cd ../.. && python3 tools/fetch_icon.py allbirds   # icon.png (repo-root tool)
```

Then from the repo root, `make design-md` regenerates `DESIGN.md` and this README's Brief, `make grade` refreshes Health, and `make check` verifies all three.
