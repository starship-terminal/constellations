# aaply design reference

A token set and component reference for aaply's public marketing site (https://aaply.app), the website of a mobile-app wireframing tool — "design mobile apps" screens, user flows and exports to Figma. Use it to build a web page or marketing surface that borrows its look: a `#f2f2f2` field, a floating white pill nav bar, pure-black text in Poppins 700, one signature `#e6e51e` lime for primary actions and held states, coral icon accents, and a full-width black footer band. It was captured signed out, in headless Chromium at 1440 x 900 (mobile pages at 390 x 844) on 2026-11-08.

It holds 23 screenshots across eight routes — home, /features, /value, /pricing, /reviews, /our-story, /team, /figma_plugin, plus mobile variants and the pricing Yearly/Monthly toggle — and 51 measured components with 90 states and one crop each. The product itself lives on go.aaply.app, which returned the bare body "Not found" on /login, /sign, /signup and /workspace/demo: the app is recorded as an unreachable boundary, and nothing here claims its functionality (see [components.md](components.md) > Gaps).

This package contains no aaply code, and none of its artwork has been redrawn. The screenshots, the 3D character renders and the visual system they show belong to aaply ([docs/RIGHTS.md](../../docs/RIGHTS.md)). Borrow structure and proportions, not the logo, characters or brand lime.

## Brief

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export aaply` prints them all with aliases resolved.

### Principles

1. Do use the lime sparingly — it is the only primary accent.
2. Do pair Poppins 700 display with Inter UI.
3. Do invert dark pills to lime on hover
4. Do keep pills at radius 30 and cards at 36–40.
5. Do put the footer on black.
6. Don't ship the marketing style as the app.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

### Using tokens

| Role | light |
|---|---|
| page | #f2f2f2 `light.page` |
| surface | #ffffff `light.surface` |
| text | #000000 `light.text` |
| muted | #c4c4c4 `light.text-muted` |
| accent | #e6e51e `light.accent` |
| border | #cccccc `light.border` |

Fonts: `core.font.family.display` is Poppins, then 2 fallbacks; `core.font.family.ui` is Inter, then 2 fallbacks. Scales, counted as [DESIGN.md](DESIGN.md) holds them: 3 type styles (`core.typography`), 4 radius steps (`core.radius`), no spacing steps under `core.spacing`.

## How the values were read

- Every component was located on the live page by [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) in headless Chromium: Tilda has no semantic classes, so selectors key off `data-elem-type`, `.tn-atom` text and measured geometry; text-less cards and bands were marked with `data-m-mark` attributes via `page.evaluate`, and the painted surface read from the `.tn-atom` inside (the `data-elem-type` wrapper is transparent). Computed styles were read per state — default, hover, focus-visible, pressed (forced via `CSS.forcePseudoState`) — and one 2x crop saved per state.
- CSS custom properties were read from the live CSSOM by [tools/capture/vars.mjs](tools/capture/vars.mjs) into [raw/css-vars.json](raw/css-vars.json). Tilda declares almost no design tokens — the resolved map is the `--w*` layout widths and `--anim-nav` — so the token file is built almost entirely from measured values in [raw/component-tokens.json](raw/component-tokens.json).
- The billing toggle's Monthly position was reached by pressing the segment (a client-side state swap, nothing posted) and measured open, then Yearly was restored.
- Screenshots were taken on the same pages by [tools/capture/public/public.mjs](tools/capture/public/public.mjs), quantised to 256 colours by [tools/capture/quantize.py](tools/capture/quantize.py). Elements that reveal on scroll were given time to mount before reading.

## What to distrust

- **The app is absent.** go.aaply.app returned "Not found" on every route, so nothing in this package describes the product's own screens, flows or states — only the marketing site that links to it. The footer reads ©2024 and the app host looks retired or down; treat the product's live state as unknown.
- **The billing segment's held state** paints its lime fill on a sibling shape, not the text atom — the segments measure transparent in both positions; the lime chip is visible in the screenshots.
- **Hover-measured values are sparse.** Tilda applies most hovers through `--t396-*hover*` custom properties on the element, many of which read as unchanged at the atom level; the real swaps that were measured (black pills inverting to lime, link grey fades) are in the state rows.
- **Prices are split across atoms.** A plan price is a `$` atom plus a `.1 /month` numeral atom; the price tokens cite the numeral atom.
- **Screenshots are 256-colour PNGs** — read exact colours from tokens.json or the raw JSON, never from a screenshot pixel.

## Fonts

- **Poppins** — every display heading (700) and the 500-weight sub-display, loaded from Google Fonts. SIL Open Font License.
- **Inter** — buttons, links, badges, chat bubbles and body text at 400/500, plus 300 on the Log in ghost; Google Fonts, SIL OFL.
- The tokens name the measured stacks (`Poppins, Arial, sans-serif` / `Inter, Arial, sans-serif`); the style guide renders them with the system fallback.

## Coverage

- **Pages captured:** /, /features, /value, /pricing, /reviews, /our-story, /team, /figma_plugin — desktop default and full page, plus the pricing Yearly-selected state; mobile 390px variants of home, pricing and features.
- **States captured:** default on all 51 components; hover, focus-visible and pressed on the links, pills and buttons; the Monthly-selected billing state.
- **Not captured:** go.aaply.app in full (returns "Not found" — login, signup and the demo workspace alike), the reviews carousel's later slides, any legal page beyond the footer links, and any form interaction (nothing was ever typed or submitted).

## Do and don't

- **Do use the lime sparingly — it is the only primary accent.** Primary CTAs, the held billing segment, the Plus card and the featured review slide paint `lime`; everything else is black, white or page grey. Don't add a second brand colour. ([cta-signup-free](components/crops/cta-signup-free-default.png), [plan-card-plus](components/crops/plan-card-plus-default.png))
- **Do pair Poppins 700 display with Inter UI.** Headings are one 57px size at −1px tracking; body/buttons are Inter 16–18px. Don't set buttons or links in Poppins, and don't set display copy in Inter. ([hero-title](components/crops/hero-title-default.png), [nav-link](components/crops/nav-link-default.png))
- **Do invert dark pills to lime on hover**, not to a darker grey: the black Sign up/demo pills fill lime with black text. Don't fade primary actions with opacity. ([nav-signup hover](components/crops/nav-signup-hover.png))
- **Do keep pills at radius 30 and cards at 36–40.** Buttons, links, badges and the billing segments are 30px pills; plan/member cards 36px; the nav bar, review cards and the feature table 40px. Don't use small radii — nothing on the site is under 30px except square media. ([plan-card-free](components/crops/plan-card-free-default.png))
- **Do put the footer on black.** The footer is a full-bleed black band with white Poppins headings, lime mail links and coral social icons — the site's one dark surface. Don't render it on the page grey. ([footer](components/crops/footer-default.png))
- **Don't ship the marketing style as the app.** Nothing here was measured inside the product; a screen claiming aaply's app UI from these tokens would be invented. The honest gap is recorded in components.md.

## Rebuild

```sh
cd systems/aaply
PLAYWRIGHT=/path/to/playwright/index.mjs node tools/capture/public/public.mjs      # screenshots -> raw/full/
PYTHON=<venv>/python tools/capture/quantize.py raw/full screenshots                # 256-colour PNGs
PLAYWRIGHT=/path/to/playwright/index.mjs PYTHON=<venv>/python node tools/capture/public/measure.mjs   # raw/components-computed.json + components/crops/
node tools/capture/public/build-measurements.mjs                                 # raw/measurements.md
PLAYWRIGHT=/path/to/playwright/index.mjs node tools/capture/vars.mjs              # raw/css-vars.json
python3 tools/build_tokens.py                                                    # tokens.json
python3 tools/build_components_md.py                                             # components.md
python3 tools/build_style_guide.py                                               # style-guide.html
python3 tools/fetch_icon.py aaply                                                # icon.png
```

then `make design-md && make grade && make check` from the repository root. Edit the raw inputs and the builders — never the generated files by hand.
