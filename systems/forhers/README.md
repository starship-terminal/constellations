# forhers design reference

A token set and component reference for the signed-out public surfaces of **forhers.com**, the Hims & Hers women's telehealth product. Refreshed 2026-11-21 from the live homepage, signed out. Which control opens which page, menu, or dialog is in [site-tree.md](site-tree.md). The public review is [login-review.json](login-review.json).

The T3 preview tab loaded the live homepage (title "Hers | Women’s Healthcare, Online | Hers") but would not emit frames. A separate Playwright load hit a Cloudflare interstitial that was not solved. The new screenshots are renders of that live DOM and its live stylesheet, with scripts stripped. Desktop CSS viewport was 1440x900 at 1x. Phone CSS viewport was 390 at devicePixelRatio 2. Older screenshots in this package are Wayback renders from 2026-11-17 and are not live evidence.

forhers.com is worth a capture because its marketing stack ships **almost no named token layer**: the styled-components sheets inline every value and keep custom properties only for the fluid-type machinery (`--base-font-size`, `--scale`, the breakpoint redeclarations), while the archived /shop bundle declares the `--unit-u*`, `--spacing-s*`, `--grid-*` and `--*Height` scales this package tokenises under `core.space` and `core.layout`. Everything else is a *measured* reading with provenance in `$extensions.source`. Two families carry the surface: **CareSans** display (fluid headings, `letter-spacing: -0.0625em`) and **sofia-pro/SofiaProWeb** UI type (IvarSoft faces are declared in `@font-face` but no SSR rule applies them — recorded as declared-only). The palette is a near-black `rgba(0,0,0,.89)` ink on white with sage (`#e4eee6`–`#f5faf6`) and cream (`#faf8f2`, `#f4f1e6`) washes, the `#338585` Hers teal ramp, the `#d5ff5d` promo lime (the BMI submit paints `#b6dd64`) and the black `9999px` action pill that pins itself to the phone viewport. **Boundary:** www.forhers.com answers every automated request from this network with a Cloudflare managed challenge (HTTP 403), so the DOM evidence is recent Wayback Machine SSR snapshots served locally — real markup, archived sheets, scripts stripped. Hydration-owned surfaces (the slide menu, login menu, accordion expansion, carousels, the quiz/intake flow, `Read more`) are recorded gaps, not reconstructions; sign-in, the member account, consultation, prescriptions, orders and checkout were never opened; no form was submitted; ~79 archived asset URLs never resolved and stay visibly missing.

### Principles

1. Do set display type in CareSans and UI type in sofia-pro.
2. Do keep the field white with sage and cream washes.
3. Do reserve the teal for brand moments.
4. Do make the phone's primary action the black pill.
5. Do use the lime for promo and tool submits.
6. Don't sign in, start a consultation or buy from this package.
7. Don't invent a dark theme.
8. Don't treat measured values as a published variable layer.
9. Don't expect hydration-owned states.
10. Don't read missing imagery as design.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## Do and don't

1. **Do set display type in CareSans and UI type in sofia-pro.** Headings run the fluid `CareSans` face at `letter-spacing: -0.0625em`; body, nav, controls and prose run `sofia-pro/SofiaProWeb`. IvarSoft is declared in `@font-face` but nothing applies it — do not spec it. See [hero-heading](components/crops/hero-heading-default.png) and [page-heading](components/crops/page-heading-default.png).
2. **Do keep the field white with sage and cream washes.** Sections alternate `#ffffff` with the sage steps (`#e4eee6`, `#f2f9f4`, `#f5faf6`) and cream (`#faf8f2`, `#f4f1e6`); the footer is the `#e8eae8` slab. See [home-light-full](screenshots/home-light-full.png).
3. **Do reserve the teal for brand moments.** `#338585` is the Hers teal; it and its ramp (`#13262e`–`#9cccbc`) paint accents, selected states and brand surfaces, not every accent. See [treatment-card](components/crops/treatment-card-default.png).
4. **Do make the phone's primary action the black pill.** Mobile pages pin a `9999px`-radius black CTA to the viewport foot; on desktop the same actions sit inline as square-cornered controls. See [mobile-product-light-default](screenshots/mobile-product-light-default.png) and [cta-primary](components/crops/cta-primary-default.png).
5. **Do use the lime for promo and tool submits.** The promo strip paints `#d5ff5d` and the BMI Calculate submit `#b6dd64`; lime is a highlight, not a surface. See [bmi-calculator-light-default](screenshots/bmi-calculator-light-default.png).
6. **Don't sign in, start a consultation or buy from this package.** Log in, the slide menu, the quiz/intake flow, prescriptions, orders and checkout are gated destinations — captured at rest, never opened. See the Gaps in [components.md](components.md) and the resting [login-button](components/crops/login-button-default.png).
7. **Don't invent a dark theme.** The observed surface paints one light theme — no theme control, no dark selector, `colorScheme: "normal"` in every `.capture.json` theme block. The `dark` token set ships empty; the dark pass in `raw/css-vars.json` re-read root values because nothing dark applies. See [home-light-full](screenshots/home-light-full.png).
8. **Don't treat measured values as a published variable layer.** Outside the /shop scales, the sheets declare no colour or radius tokens — two components sharing `rgba(0,0,0,.89)` share the *value*, not a named upstream token. See [header-default](components/crops/header-default.png).
9. **Don't expect hydration-owned states.** Accordions, carousels, the slide menu, the login menu and `Read more` never expand on the archived pages — their open states are recorded gaps, not readings. See [accordion-toggle](components/crops/accordion-toggle-default.png).
10. **Don't read missing imagery as design.** ~79 archived asset URLs never resolved; blank plates in a screenshot are archive gaps, and the Cloudflare block means none of this is current live evidence — it is archived evidence, dated in the sidecars. See [weight-loss-light-full](screenshots/weight-loss-light-full.png).

## How the values were read

Every colour, radius, length and font on this package is a **measured** value — `measured/computed <what> of <component> <state>` in `$extensions.source` — a computed style or bounding box read from the archived DOM by `tools/capture/public/measure.mjs`, with a matching crop in `components/crops/`. The exceptions are the `core.space` and `core.layout` scales: custom properties the archived /shop bundle declares (`--unit-u*`, `--spacing-s*`, `--grid-*`, `--*Height`, `--promoHeight*`), harvested by `tools/capture/vars.mjs` and resolved in a probe document carrying the real sheets, emitted as `css-var <name>` provenance. `raw/css-vars.json` keeps the full harvest verbatim — the `@font-face` list, per-selector declaration counts, the resolved `:root` values and the sheet census — as the evidence that the marketing stack publishes no variable layer beyond the fluid-type machinery.

## What to distrust

- **One ink step was typed in.** `core.palette.ink.a33` `rgba(0, 0, 0, 0.33)` appears in no raw file; its source says Reconstruction. The other ink steps cite the reading that paints them, the sans stack cites the article card (nav and footer paint CareSans), and the rule-body declaration counts on palette swatches were counted by hand in sheets that are not committed, which their sources now say.
- **Live origin unreachable.** www.forhers.com serves this network a Cloudflare managed challenge (HTTP 403) on every route; nothing here is current live evidence — every value is an archived reading, dated in the sidecars and `raw/css-vars.json`.
- **Nothing dark paints.** No theme control, no dark class or attribute, no applied `prefers-color-scheme: dark` rules on any captured page. The token file ships an empty dark set.
- **Scripts are stripped.** Wayback SSR markup hydrates nothing — menus, accordions, carousels, the quiz/intake flow and `Read more` were captured closed, and their open states are recorded gaps.
- **Presses are forced.** `pressed` states were read with `CSS.forcePseudoState` — any script-driven mousedown look is uncaptured.
- **Forms are empty.** `focused` was a real click into the field; `filled` states were typed and deleted again, with nothing sent. Success, validation-error and post-submit appearances are uncaptured by design.
- **Full pages are bounded.** `-full` screenshots tile a bounded number of chunks; the tallest pages (birth-control ~53k px, bmi-calculator ~23k px) truncate from the bottom and their sidecars note the document height.
- **Archived assets are missing.** ~79 asset URLs never resolved from the archive — blank or broken imagery in a screenshot is a recorded gap, not the design.
- **Screenshots are 256-colour PNGs.** Read exact colours from the tokens or the raw files, never from a screenshot pixel.
