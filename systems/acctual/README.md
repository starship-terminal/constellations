# Acctual design reference

A token set and component reference for Acctual's public marketing site, for building an invoicing/fintech marketing page in the style of a real payments company. It was read from acctual.com on 2026-11-10 and recaptured on 2026-11-21, signed out, in headless Chromium at 1440x900 and 390x844. The 2026-11-21 pass mapped the public site tree first ([site-tree.md](site-tree.md)), then captured every reachable marketing page, the footer-linked posts, the public help centre at guides.acctual.com, and the phone menu. The look is a quiet `#fafafa` ground with ink text, a single `#0098f2` blue accent on links and check bullets, and every action inside a `#0d111b` capsule. A frosted nav pill floats on top.

Acctual's product (the invoicing app at app.acctual.com) is a different surface. The interactive invoice in the home hero is a marketing demo, not the app. Nothing was signed into, sent or submitted. `https://app.acctual.com/sign-in` was opened only far enough to record the wall (email, password, Continue with Google) and that branch stopped: nothing was typed and Google was not clicked. The phone menu and one FAQ question were the only controls pressed (both local disclosures). No consent banner rendered.

### Principles

1. Do keep the ground quiet and let one blue work.
2. Do put every action in the same dark capsule.
3. Do fade links instead of recolouring them.
4. Do set type in Open Runde semibold with negative tracking.
5. Don't add borders or shadows to cards.
6. Do keep chrome frosted.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

acctual.com is a Framer site: it inlines its stylesheets and carries semantic `data-framer-name` attributes on components. Its palette lives in hashed `--token-<uuid>` custom properties on `:root`, which [vars.mjs](tools/capture/vars.mjs) resolved live into [raw/css-vars.json](raw/css-vars.json); token leaves that alias one read `css-var <name>` in `$extensions.source`. Everything else is a literal measured off a real element's computed style, and each leaf's source names the measurement.

Component values are computed styles read per state with Playwright ([measure.mjs](tools/capture/public/measure.mjs)). Hover used the pointer, focus-visible a real keyboard Tab, and pressed was forced through DevTools (`CSS.forcePseudoState`), so no button was clicked for real. The only presses were the mobile nav trigger and one FAQ question, both local disclosures. Elements parked outside the document or at opacity 0 (Framer keeps ghost copies of some components) are skipped by the selectors. No CMP banner ever rendered on the site; the tour's overlay sweep ([lib.mjs](tools/capture/public/lib.mjs)) still hides any generic cookie/subscribe overlay so a shot is never blocked.

Screenshots were lazily scrolled to settle lazy content, then stored quantised to 256 colours; the unquantised originals and per-capture metadata stay in `raw/full/`, uncommitted. A page taller than the GPU texture limit is tiled by `public.mjs` (capped at 8 chunks; terms and mobile-home tiled) and stitched by `quantize.py`.

## What to distrust

- **Screenshots are 256-colour PNGs.** Gradients and photography band slightly; read exact colours from tokens.json or the raw files.
- **Focus rings are the browser's.** Where the site declares no `:focus-visible` style, the measured 1px `#005fcc` auto ring is headless Chromium's default, not a product choice.
- **`pressed` is forced `:active`,** not a real mousedown; Framer's sheet paints links `#ff0000` under it.
- **Motion is unmeasurable here.** Every component computes `transitionDuration 0s`; Framer runs hovers, reveals and the menu in JavaScript springs. `core.duration.instant` records that fact, not a speed.
- **The fee-item crop is the demo's fee chip,** the small "Cards 2.7%" label inside the invoice mock, not a table row; the comparison rows live in `fee-row` (pricing).
- **Declared tokens are not all exercised.** The `--token-*` green, purple, red, magenta and navy sit in the site's design-token sheet; only the blue (and green inside demo artwork) was seen on a measured component.
- **Blog at 390 is 24,915px tall** (cards go single-column); the `-full` shots are honest but long.

## Do and don't

1. **Do keep the ground quiet and let one blue work.** `#fafafa` carries the page, `#1e1e1e` the text, and `#0098f2` is the only saturated colour — links, check bullets, the announcement strip and the count pill. See [home-light-default](screenshots/home-light-default.png) and [announcement-default](components/crops/announcement-default.png).
2. **Do put every action in the same dark capsule.** Buttons are 40px pills: `#0d111b` fill, white 16px medium label, a 1px `#242628` inner ring plus a hairline `#000` edge and a soft drop. See [nav-cta-default](components/crops/nav-cta-default.png) and [plan-cta-default](components/crops/plan-cta-default.png).
3. **Do fade links instead of recolouring them.** Nav links rest at ink-70 and darken to black on hover, the Log-in link sits a step dimmer at ink-60, footer links run muted→black-90 — never blue. See [nav-link-hover](components/crops/nav-link-hover.png) and [footer-link-hover](components/crops/footer-link-hover.png).
4. **Do set type in Open Runde semibold with negative tracking.** Display 64/72 at -1.92px, titles 48/56 at -1.44px, card titles 20/28, body 16/24 medium; landing pages swap to Selecta. See [hero-title-default](components/crops/hero-title-default.png) and [stablecoin-invoicing-title-default](components/crops/stablecoin-invoicing-title-default.png).
5. **Don't add borders or shadows to cards.** Cards borrow the page colour at 16px radius with a 24px inset; separation comes from alternating fills and `#d8d8d8`/`#dbdbdb`/`#eee` hairlines only. See [persona-card-default](components/crops/persona-card-default.png) and [fee-row-default](components/crops/fee-row-default.png).
6. **Do keep chrome frosted.** The floating nav bar is a 60% grey-white fill over `blur(10px)` with a 0 1px 2px drop and 20px bottom corners. See [nav-bar-default](components/crops/nav-bar-default.png).

## Rebuild

```bash
python3 tools/build_tokens.py
```

```bash
python3 tools/build_style_guide.py
```

```bash
python3 tools/build_components_md.py
```

`build_tokens.py` reads `raw/component-tokens.json` and writes `tokens.json`; it refuses a value that is not the DTCG type it claims and an alias that points at nothing. `build_style_guide.py` renders `style-guide.html` from `tokens.json` and `tools/style-guide.template.html`, turning every token into a CSS variable so the page cannot drift from the file. `build_components_md.py` writes `components.md` from `raw/components-computed.json`, `raw/layout.json`, `tokens.json`, the screenshots and `icons/INDEX.tsv`. All three are deterministic: re-running them on this commit reproduces their files byte for byte. Edit the raw inputs or the builders, never the generated files.

`tools/capture/` holds the kit the captures came from. The Playwright scripts take `PLAYWRIGHT` as the path to a Playwright install's `index.mjs` and `PYTHON` as the interpreter holding Pillow.

```bash
PLAYWRIGHT=/path/to/playwright/index.mjs node tools/capture/public/public.mjs
PLAYWRIGHT=/path/to/playwright/index.mjs node tools/capture/public/measure.mjs home pricing mobile
```

`public.mjs` re-takes the screenshot set into `raw/full` (full-page shots tile at 8 chunks max); `python3 tools/capture/quantize.py raw/full` stitches and stores the quantised copies in `screenshots/`. `measure.mjs` takes page names and merges into `raw/components-computed.json`; `node tools/capture/public/build-measurements.mjs` then rewrites `raw/measurements.md`. `vars.mjs`, `layout.mjs` and `icons.mjs` rewrite their raw or icon files whole. `lib.mjs` holds the shared helpers, including the overlay sweep, the offscreen-element filtering and the `navigator.webdriver` masking.

## Use in Figma

Import `tokens.json` with Tokens Studio and choose the Light theme. Set type to Open Runde (Selecta Medium for landing display, Selecta Regular for legal body, Inter only for the announcement strip) and keep every corner at 0, 16, 20 or 100.
