# Oysho

Handwritten, because generation needs a catalog entry. `catalog.json` was left alone.

## Colour

| Role | Value | Source |
|---|---|---|
| page | `#fefefe` | Measured body background. Token `--color-primary-white` |
| ink | `#000000` | Measured body and title. Token `--color-primary-black` |
| on ink | `#f5f4f1` | Measured Add to basket text. Token `--color-primary-ultra-light` |
| muted | `#3d3d3d` | Measured Sign in. Token `--color-primary-super-dark` |
| line | `#e5e5e5` | Measured size-chip border. Token `--color-primary-super-light` |
| promo token | `#ff5ea0` | Token `--color-terciary-promo`. The photographed bar is black |

One theme. The public shop is light.

## Type

`Oysho-font`, then Roboto. Body 16px. Product title 18px, weight 500. Price 16px. Button and nav 14px. Footer links 12px. The wordmark is `oysho-icon-font`. The font files are not in this package.

## Geometry

Radius 0px on Add to basket and on size chips. Add to basket is 56 by 424. A size chip is 56 by 116. The header, with the promo bar, measured 104px. Spacing base token is 8px.
