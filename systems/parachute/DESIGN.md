# Parachute Home

A signed-out capture of the public Parachute Home shop at [https://parachutehome.com](https://parachutehome.com), prices in USD, on 2026-11-22. Desktop 1440 by 900. The page is `#ffffff`, body type is Suisse Intl at `#353331`, and the hero is Canela at 112px. Add to bag is a 44px ink button with a `4px` radius.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

## Colour

| Role | Value | Where |
|---|---|---|
| Page | `#ffffff` | document background |
| Ink | `#353331` | body type, Add to bag, product title |
| On ink | `#ffffff` | Add to bag type, promo type, hero |
| Cream | `#f1eee9` | footer, Shop the Sale, size field |
| Muted | `#696663` | sale badge type |
| Accent | `#5b2831` | `--cv-color--accent--onSurface`, not a photographed fill |
| Promo | `#000000` | announcement bar |
| Wordmark | `#080808` | header SVG fill |

## Type

Suisse Intl on body, department links, buttons, and the footer. Department links are 14px, weight 400. The homepage hero is Canela, 112px, weight 300, white. The about heading is Canela, 40px. The product title is Canela, 28px, weight 300. Font files are not in this package.

## Controls

Add to bag is 44px with a `4px` radius and an ink fill. Shop the Sale is 44px with a `2px` radius and a cream fill. The size select is a cream field, 44px, radius `4px`. The sale badge is 10px on cream. The announcement bar is 37px, black.

## Where it stopped

Log in opened an empty email wall on the account host. Continue was not clicked. The URL carried OAuth state, so that page has no screenshot. Cart, Add to bag, search, the store locator, and the footer subscribe form were not opened.
