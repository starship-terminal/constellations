# The Athletic design reference

A token set for The Athletic's public signed-out web surfaces. Read on **2026-11-19** from the T3 preview browser, signed out. `theathletic.com` redirects to `https://www.nytimes.com/athletic/`. The painted theme was `html[data-theme=legacy]`. The viewport that was measured was **1169 x 731**, devicePixelRatio **2**, visual viewport scale **1**. A 1440 and a 390 pass were not measured: `preview_snapshot` returned "The browser is not producing screenshot frames", so the page shots in this package are reconstructions.

Captured, signed out: the home, one public article, the about page, the NFL league page, the subscription marketing page, the login shell (iframe not entered), search opened with nothing typed, and a made-up path's 404. Nothing was submitted. No card, phone, or account form was filled. Continue to checkout was not followed.

The Athletic is worth a capture because the signed-out site still ships a named token layer. `:root[data-theme=legacy|light|dark]` sets the `--Gray*` and brand scales. The painted legacy page is white (`--Gray10` `#fff`) with a near-black nav (`#1a1a1a`) and a red trial button (`#b72424`, radius 2px). Display type is **nyt-cheltenham**. UI type is **nyt-franklin**. Story body is **nyt-imperial** at 20px / 30px. About titles use **RegularSlab**. **Boundary:** checkout, the NYT account iframe, and the signed-in product were not entered.

## How the values were read

The T3 preview browser opened `https://www.theathletic.com/`, which landed on `https://www.nytimes.com/athletic/`. `preview_evaluate` read `getComputedStyle` and the CSSOM. Theme sets were taken from the selectors `.legacy, :root[data-theme=legacy]`, `.chalkLight, :root[data-theme=light]` and `.chalkDark, :root[data-theme=dark]`. A probe painted with `var(--Gray10)` resolved to `rgb(255, 255, 255)`, matching the legacy set, while `matchMedia('(prefers-color-scheme: dark)')` was true. Component boxes were read on the visible elements. `preview_snapshot` failed with "The browser is not producing screenshot frames", so no live PNG was saved.

## What to distrust

The PNGs in [screenshots/](screenshots) and [components/crops/](components/crops) are drawings from the measured boxes. They are not photographs. The dark semantic set was declared in CSS and was not the painted theme. The search field's focus outline computed as `none`. Hover, pressed and disabled were not forced. The 390px screenshot is a redraw at a checklist width, not a measured phone viewport. Prices on the offer page (`$12.50/year`, `$1/month`) are what the page showed on 2026-11-19 and will move.

## Fonts

nyt-franklin, nyt-cheltenham and nyt-imperial are New York Times webfonts served from `g1.nyt.com`. RegularSlab and RegularSlabInline are Athletic files at `/athletic/static/fonts/`. SohneMono is declared and was not used on the measured elements. None of these files is shipped here. The style guide falls back to Georgia and Helvetica. The tokens name the families that computed.

## Do and don't

- **Do paint the page from the legacy pair.** The signed-out site uses white ground, `#121212` text and a `#1a1a1a` nav. See [screenshots/home-light-default.png](screenshots/home-light-default.png).
- **Do set the story headline in nyt-cheltenham and the body in nyt-imperial.** 40px / 44px and 20px / 30px. See [screenshots/article-light-default.png](screenshots/article-light-default.png).
- **Do make the trial action the red 2px-radius button.** `#b72424`, 14px weight 700. See [components/crops/button-default.png](components/crops/button-default.png).
- **Do keep about titles in RegularSlab.** 42px, letter-spacing -0.21px. See [screenshots/about-light-default.png](screenshots/about-light-default.png).
- **Don't treat the PNGs as live screenshots.** The preview browser returned no frames. The drawings are labelled in [screenshots/README.md](screenshots/README.md).
- **Don't style the signed-in app from this package.** Login is a cross-origin iframe and was not entered.
- **Don't follow the checkout button from this package.** The offer page was measured. No card was entered.
