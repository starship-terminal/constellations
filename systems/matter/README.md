# Matter design reference

A token set and component reference for Matter's public surface. It was read from **getmatter.com** on **2026-11-18**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: the marketing home, web extension, newsletters, privacy and terms pages; the Words That Matter subscribe gate; one published article that loads signed out; the public docs home; and the web reader sign-in card. The email field was focused and never filled. Nothing was signed into, purchased or submitted.

Matter is worth a capture because the marketing site is a small declared system painted once. The stylesheet names `--mr-*` colours (page `#0d0d0d`, surface `#1e1f22`, gray `#969698`, blurple `#6d7eec`), two radii (8px, 30px) and a system stack, then paints display type in **MR-Camphor** and the primary action as a 100px blurple pill. **Boundary:** the reader app sits behind the sign-in card at web.getmatter.com and was never reached.

### Principles

1. Do paint the marketing page near-black.
2. Do make the primary action a blurple pill.
3. Do set marketing type in MR-Camphor.
4. Do keep the header at 62px.
5. Do use 8px and 30px where the sheet names a radius.
6. Don't style the reader from this package.
7. Don't submit from this package.
8. Don't treat the light set as a painted marketing theme.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

### Using tokens

| Role | dark | light |
|---|---|---|
| page | #0d0d0d `dark.page` | #ffffff `light.page` |
| surface | #1e1f22 `dark.surface` | #f4f4f4 `light.surface` |
| text | #ffffff `dark.text` | rgba(0, 0, 0, 0.95) `light.text` |
| muted | #969698 `dark.muted` | #969698 `light.muted` |
| accent | #6d7eec `dark.accent` | #6d7eec `light.accent` |
| border | #2f3034 `dark.border` | #dfdfdf `light.border` |

Fonts: `core.font.family.camphor` is MR-Camphor, then 10 fallbacks; `core.font.family.system` is -apple-system, then 9 fallbacks. Scales, counted as [DESIGN.md](DESIGN.md) holds them: no type styles under `core.typography`, 3 radius steps (`core.radius`), 6 spacing steps (`core.spacing`).

## Do and don't

1. **Do paint the marketing page near-black.** The field is `#0D0D0D`, text is white, nav text is `#969698`. See [home-dark-default](screenshots/home-dark-default.png).
2. **Do make the primary action a blurple pill.** Get Matter is `#6D7EEC` at a 100px radius. See [nav-cta-default](components/crops/nav-cta-default.png).
3. **Do set marketing type in MR-Camphor.** The hero, the body paragraph, the navigation, and the buttons were measured in Camphor. The system stack is the sign-in card. See [hero-h1-default](components/crops/hero-h1-default.png).
4. **Do keep the header at 62px.** Wordmark, gray links, Sign In, then the pill. See [header-default](components/crops/header-default.png).
5. **Do use 8px and 30px where the sheet names a radius.** The pill is the measured 100px exception. See [tokens.json](tokens.json).
6. **Don't style the reader from this package.** Library, highlights and settings sit behind sign-in. See [signin-light-default](screenshots/signin-light-default.png).
7. **Don't submit from this package.** Google, Apple, the email arrow and Subscribe were measured, never pressed. See [email-field-default](components/crops/email-field-default.png).
8. **Don't treat the light set as a painted marketing theme.** Marketing paints dark. Light is the sign-in card and the declared content colours. See [signin-light-default](screenshots/signin-light-default.png).

## How the values were read

Headless Chromium (Playwright) at 1440 x 900 and 390 x 844. CSS custom properties were harvested from the live stylesheets and resolved on a probe. Component styles and crops were read from the live DOM. Consent overlays were hidden, never clicked. The docs theme toggle was clicked as local UI. No form was submitted.
