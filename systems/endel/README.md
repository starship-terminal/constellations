# Endel design reference

A token set and component reference for Endel's public surface — for building quiet, near-black wellness pages and audio-app chrome in the style of the real thing. It was read from **endel.io** and **app.endel.io** on **2026-11-13**, signed out, in headless Chromium at 1440 x 900 and 390 x 844: the sixteen marketing routes (home, the Focus/Sleep/Relax/Activity/ADHD product pages, Soundscapes, Science, Technology, Streaming, Community, About, Blog, Newsroom, Privacy Policy and Impressum), the signed-out web app's explore page and public player, and the sign-in card the app's own Sign In button opens.

Endel ("personalized soundscapes to help you focus, relax and sleep") is worth a capture because it is a study in monochrome restraint: a pure `#000000` ground, a five-step grey ramp doing all the structural work — `#191919` cards, `#262626` button fills, `#808080` field borders and hover fills, `#bfbfbf` muted text, `#e0e0e0` faint — with white for text and strong borders and a single white-glow CTA, all set in apercuPro on a strict 1280px/12-column grid (declared `--cols-*` vars the components snap to exactly: a card is 3 columns, a field 5 or 6, a row 10). The signed-out web app reuses the same system and adds the player chrome: mode icons, 56px round transports, a 20px-top-corner Explore sheet and the Set Timer bottom sheet. **Boundary:** everything behind an account — library, sync, settings, purchase, the premium Unlock — sits inside app.endel.io and was never crossed; audio was never started.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export endel` prints them all with aliases resolved.

### Principles

1. Do paint on pure black.
2. Do build surfaces from the grey ramp.
3. Do corner controls at 12px or 100px.
4. Do let white be the strong signal.
5. Do keep type at 400.
6. Don't repaint hovers.
7. Don't invent an accent.
8. Don't ship a light theme or style the app from the marketing pages.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

Fonts: `core.font.family.sans` is apercuPro, then 1 fallback. Scales, counted as [DESIGN.md](DESIGN.md) holds them: no type styles under `core.typography`, 5 radius steps (`core.radius`), no spacing steps under `core.spacing`.

## How the values were read

Every value came off the running signed-out site in headless Chromium:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) reads every stylesheet through the CSSOM on the live home and explore pages (the linked `/_next/static/chunks/*.css` bundles) and re-parses them in a probe document per host, writing every custom property plus its resolved value to [raw/css-vars.json](raw/css-vars.json). Both bundles declare named design vars — the `--color-*` neutrals and accents, the `--cols-1..12`/`--gap`/`--gutter`/`--max-width`/`--max-cols` grid and the `--title-*`/`--line-height-*`/`--text-*` type scale — so palette, layout and type tokens resolve through the real declarations (`var` leaves); semantic roles and component metrics are measured computed values. [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec, [tools/build_tokens.py](tools/build_tokens.py) the sets.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state, plus `focused` on the fields and `opened` on the More flyout, the mobile menu, the FAQ row and the timer sheet. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md).
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route with `.capture.json` sidecars; [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.

Nothing was signed into, created, submitted or consented to: the More flyout, the FAQ accordion, the mobile menu and the player's Set Timer sheet are local toggles, each opened once for the reading and closed again; no audio was played; the sign-in card's email field was focused but never filled, and Continue, Unlock and the OAuth buttons were never pressed.

## What to distrust

- **The signed-in app is uncaptured.** app.endel.io beyond explore, the public player and the sign-in card — the soundscape library, account, sync, settings and every purchase flow — sits behind sign-in or checkout and is a boundary, never inferred. The declared `--color-accent-green(-hover)` greens are almost certainly premium/live accents, but nothing on the captured routes paints them: they are tokenised from the bundle's own declarations with that caveat.
- **One theme only.** Both hosts paint dark on every captured route and declare no light variant; `tokens.json` ships a single `dark` set.
- **The tokens mix declared and measured.** Palette, grid and type steps resolve the bundle's own `:root` vars; roles and component metrics are computed-style readings. Each token's `$extensions.source` says which.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs; read exact colours from tokens or the raw files.
- **Two readings are recorded as misses, not values.** The home page's mid-page newsletter row (`input-email`, `btn-subscribe`) was not on the page at capture time — the footer's own newsletter field was painted instead. `button-mode` could not be driven to a real keyboard focus.
- **Automation was masked during capture.** Until 2026-11-20, `tools/capture/public/lib.mjs` hid `navigator.webdriver` in every page it opened, so every committed reading was taken with that mask. The mask is removed (a bot check is now recorded as a boundary, not bypassed); whether any page needed it to load is not known, and a recapture without it is the check.

## Fonts

**apercuPro** is the face for everything — the 60px wordmark hero, the 22px buttons, the 10px microtext — but the two hosts declare **separate stacks** (`fonts` in [raw/css-vars.json](raw/css-vars.json)): the marketing bundle serves `apercuPro` (Regular woff2) plus a metric-matched `"apercuPro Fallback"` built on local Arial (ascent/descent/line-gap overrides and 98.51% size-adjust), while app.endel.io declares its own pair — `apercuProRegular` at weight 400 and `apercuProMedium`, whose face carries weight **500** (the carousel banner's promo text is set in it even though its computed `font-weight` reads 400), each with its own fallback descriptors. The three stacks are tokenised under `core.font.family.*` (`sans`, `appSans`, `appMedium`). No font file is distributed with the package — the style guide falls back to Arial, which is what the product itself falls back to.

## Do and don't

1. **Do paint on pure black.** `#000000` is the whole ground; the header itself is a black-to-transparent scrim over it. See [home-dark-default](screenshots/home-dark-default.png).
2. **Do build surfaces from the grey ramp.** Cards `#191919`, controls `#262626`, borders and hover fills `#808080`, muted text `#bfbfbf`, faint `#e0e0e0` — no other hue needs inventing. See [accordion-title](components/crops/accordion-title-default.png).
3. **Do corner controls at 12px or 100px.** Buttons, fields and accordion rows take the 12px basic radius; pills, transports and the mini-player take the 100px full radius. See [scenario-pill](components/crops/scenario-pill-default.png).
4. **Do let white be the strong signal.** White is text, the focused field border, the Unlock/Continue borders and the play button's fill — and the one special effect, Try Today's 15px glow. See [btn-try](components/crops/btn-try-default.png).
5. **Do keep type at 400.** The whole product speaks apercuPro Regular; hierarchy comes from the 60/44/36/28 title and 22/18/16/14/10 text steps, never weight. See [hero-title](components/crops/hero-title-default.png).
6. **Don't repaint hovers.** Links keep their colour and only underline on hover — the one exception is the footer's legal line, which also steps its muted `#bfbfbf` text up to white. Fills climb the grey ladder on a 200ms ease — buttons `#262626` to `#808080`, the FAQ rows a notch quieter at `#191919` to `#262626`. See [btn-signin-hover](components/crops/btn-signin-hover.png).
7. **Don't invent an accent.** The declared greens and orange never paint on this surface — the product's colour lives inside the signed-in app, so reach for the greys. See [footer](components/crops/footer-default.png).
8. **Don't ship a light theme or style the app from the marketing pages.** The surface is dark-only; the signed-in product is uncaptured. See [app-explore-dark-default](screenshots/app-explore-dark-default.png).

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/endel/`):

```sh
python3 tools/build_component_tokens.py        # raw/components-computed.json + raw/css-vars.json -> raw/component-tokens.json
python3 tools/build_tokens.py                  # -> tokens.json
python3 tools/build_style_guide.py             # -> style-guide.html
python3 tools/build_components_md.py           # -> components.md
node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir>    # full-colour PNGs -> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.

Live recapture (needs the sites; Playwright at `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs`, Pillow on `PYTHON` for the crop quantize):

```sh
node tools/capture/vars.mjs                    # stylesheet harvest -> raw/css-vars.json
node tools/capture/public/measure.mjs          # computed styles + crops -> raw/components-computed.json
RAW=<scratch> node tools/capture/public/public.mjs   # screenshots -> <scratch>
```

endel.io and app.endel.io load fine headless from this client; no consent overlay mounts on the captured routes.
