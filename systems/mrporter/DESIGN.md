## Typography

Georgia is the UI face. SackersGothicStd is the display face on the homepage hero, the category chips, and the footer headings. Neither file is in this package. The style guide falls back to Georgia.

| Style | Size | Weight | Line |

| meta | 10px | 400 | 16px |

## Geometry

Controls use a 2px radius. The promo ribbon is 32px. The header, including the ribbon, logo row, and department row, is 183px. A department link is 52px. Add to Bag, Wish List, and a size chip are 40px. The homepage Shop now button is 42px by 240px.

## Components

Add to Bag is ink with white type, 40px, 2px radius. It was measured and not clicked. Wish List is a white button with an ink border. A size chip is a 90 by 40 box. An unavailable size is `#838383`.
