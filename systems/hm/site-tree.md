# H&M public site tree

Mapped signed out on 2026-11-22 from [https://www2.hm.com](https://www2.hm.com) in an incognito preview at 1440 by 900 CSS pixels, `devicePixelRatio` 2. The first load geo-routed to Singapore: title "H&M | Women's, Men's & Kids' Fashion | H&M SG", URL [https://www2.hm.com/en_sg/index.html](https://www2.hm.com/en_sg/index.html). The page is a live shop, not a parked domain and not a captcha wall. Page background `rgb(0, 0, 0)`. Body type is HM Slussen, 13px, color `rgb(242, 242, 242)`.

A cookie dialog titled "Before you start shopping" covered the first paint. "Only required cookies" was clicked so the homepage could be photographed. Accept all was not clicked. The shipping notice "We've set your shipping location to Singapore" stayed on the homepage shot and was not used to change region.

Nothing was typed. No email, password, code, phone, date of birth, or address was entered. No form was submitted. No identity provider was clicked. No captcha was solved. No bag, favourite, or checkout was started. `login-extracted` stays `not-started`.

`catalog.json` and `webapps-manifest.json` were left alone. origin/main had no `systems/hm/`.

Tracking query strings are not recorded. The public entry is the path without that query.
