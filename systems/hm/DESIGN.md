# H&M

A signed-out capture of the public H&M shop at [https://www2.hm.com](https://www2.hm.com), geo-routed to Singapore, on 2026-11-22. Desktop 1440 by 900. The page is black, type is HM Slussen at weight 100, and the wordmark is `#e50010`. Primary actions are square 56px buttons filled `#f2f2f2`.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).
