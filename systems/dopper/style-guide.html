Palette

The core set carries the declared brand ramps — darkBlue, deep-sea, sand, yellow, darkTeal, carribean and glowing-coral, each with three tints — resolved from the marketing stylesheet's :root layer, plus the Magento shop's compiled colours measured off real elements. Light roles alias the palette; there is no dark set — the darkBlue menu and deep-sea bands are painted surfaces of the one light theme.

Spacing and radius

The declared scale runs --border-radius-xs 4px to --border-radius-l 20px; pills, CTAs, cards and fields all measure the 20px step round. Fields sit at 54–56px high (a declared --touch-target-min of 44px); the colour swatches are the only circles (a 100% radius).

Type

Two served families: Dopper for the display faces and wordmark, Gilroy (400 body, Medium/500 links, Bold/600–700 controls and headings) for everything else — nav labels, buttons, prices and body copy. The ramp runs the ~90px hero display down to 14px control text. Samples fall back to system sans.
