# Hitchd design reference

A token set and component reference for Hitchd's public signed-out surface — for building honeymoon-registry and wedding-adjacent surfaces in the style of the real thing. It was read from **hitchd.com**, signed out, in Chromium at 1440 x 900 (with a 390 x 844 mobile pass): the closure home page, the /login, /signup and /forgot-password auth shells at rest, the /blog index and a full article, /terms, /privacy, a /trips/<destination> landing, a /guides/<guide> page, the public demo registry /zoeandnoah (with its Sort by filter opened, the list filtered, and a gift card's modal at rest), and a not-yet-live registry's countdown page at /avaandbenjamin.

Hitchd is worth a capture because it is three small, honest systems in one product: a server-rendered marketing site on Foundation's grid under self-hosted DDNR serif + Inter Variable, an Angular couple app for the auth surfaces, and an Angular guest app for registries. It declares almost no custom properties (~10 radio-control display flags in the registry app), so the token layer is measured — every value is a computed style or bounding box on a real element, labelled with where it was read. The honest edges: **Hitchd announced it is closing on 31 December 2026** — the home page is a one-viewport closure notice, the old marketing routes redirect to it, and no dark theme exists anywhere, so the package ships a single light set.

### Principles

1. Do set display type in the product's own display faces.
2. Do keep the field warm and quiet.
3. Do pill the submit and round the field.
4. Do let the registry sell with restraint.
5. Don't invent a dark theme.
6. Don't enter the money path or sign in.
7. Don't treat the demo registry as live.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## Do and don't

1. **Do set display type in the product's own display faces.** The home hero is hairline DDNR (weight 100) at 88px over photography; the registry couple names are the `classic` registry face at 96px white — neither is a bold grotesque. See [hero](components/crops/hero.png) and [registry-hero](components/crops/registry-hero.png).
2. **Do keep the field warm and quiet.** White paper, the cream `#f6f3ef` announcement strip, near-black ink, hairline borders — the site's only loud surface is a photo. See [announcement](components/crops/announcement.png).
3. **Do pill the submit and round the field.** The auth Continue and Give buttons are full 50px pills; text fields keep 8px corners and a 1px `#d2d2d7` line at 48px high. See [auth-button](components/crops/auth-button.png) and [auth-card](components/crops/auth-card.png).
4. **Do let the registry sell with restraint.** The sample banner is a quiet sentence plus a black "Try It Free" pill; gift tiles are photography, a name, a price and a thin progress line. See [registry-light-default](screenshots/registry-light-default.png).
5. **Don't invent a dark theme.** No stylesheet, page or app surveyed declares a dark variant and no theme control exists; the token file ships a single light set. See [raw/css-vars.json](raw/css-vars.json).
6. **Don't enter the money path or sign in.** The gift modal's Give button, every contribution and payment step, and all three auth forms were measured at rest and never pressed, typed or submitted. The registry's owner routes (`/zoeandnoah/contributions`, `/payment-methods`, `/ask`, `/quick-thanks`) bounce a signed-out guest to `/` — documented boundaries, not captures.
7. **Don't treat the demo registry as live.** /zoeandnoah and /avaandbenjamin are the public sample registries Hitchd itself publishes; their couple names and gift content appear only inside screenshots and crops.

## How the values were read

All of it runs from `systems/hitchd/` with a Chromium that Playwright drives and `PYTHON` pointing at an interpreter with Pillow:

```sh
# screenshots -> raw-shots in scratch (RAW=/home/kaichen/.design-systems/hitchd/raw-shots)
node tools/capture/public/public.mjs                # every surface, both widths; filters by name
# evidence
node tools/capture/vars.mjs                         # raw/css-vars.json — declared vars + @font-face
node tools/capture/public/measure.mjs               # raw/components-computed.json + components/crops
node tools/capture/layout.mjs                       # raw/layout.json
node tools/capture/motion-probe.mjs --urls <urls>   # raw/motion.json
node tools/capture/icons.mjs                        # icons/ + icons/INDEX.tsv
# build
python3 tools/capture/quantize.py <raw-shots-dir>   # 256-colour PNGs into screenshots/
node tools/capture/public/build-measurements.mjs    # raw/measurements.md
python3 tools/build_component_tokens.py             # raw/component-tokens.json
python3 tools/build_tokens.py                       # tokens.json
python3 tools/build_style_guide.py                  # style-guide.html
python3 tools/build_components_md.py                # components.md
```

Nothing was signed into, typed into, submitted or paid: the only presses are local UI toggles — the Sort by select, a gift card's own tap that opens its modal, and the documented absence of a menu toggle on the demo registry.
