# How this package was captured

2026-11-22. Public pages only.

Headless Chromium (Playwright at `~/.design-systems/pw`) opened https://ghost.org/ and the header and footer destinations. Viewport 1440 by 900 and 390 by 844, device pixel ratio 2. Screenshots were quantised to 256 colours with the kit's `quantize.py`.

Sign in and signup were opened and left empty. Continue was not clicked. No form was submitted.

`catalog.json` was left alone, so `make design-md` and `make brief` were not run for this package.
