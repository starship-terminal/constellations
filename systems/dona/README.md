# Dona design reference

A token set and page map for Dona's public marketing site. Read from **dona.ai** on **2026-11-21**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. The product app at app.dona.ai was opened only as far as the login wall.

Dona is a to-do product whose marketing site is a small Gatsby page: Inter, a blue `#008ffd` pill, quiet grey pills, a 64px display, and one video modal. The signed-in app, its light/dark/black themes, and onboarding were not reached.

## How the values were read

The marketing site is styled-components. It declares no CSS custom-property token layer. [tools/capture/read.mjs](tools/capture/read.mjs) read the theme object off the React fiber of a home button (`id: "light"`) and `getComputedStyle` of the visible controls. Those readings are [raw/readings.json](raw/readings.json). [tools/build_tokens.py](tools/build_tokens.py) writes [tokens.json](tokens.json) from that file.

Screenshots come from [tools/capture/public/public.mjs](tools/capture/public/public.mjs). The site keeps a `.preload` veil for about three seconds. The shooter waits until that veil is `display: none`, then hides the cookie bar with CSS. Accept was not clicked.

## What to distrust

- Status colours (`success`, `warning`, `danger`) are on the theme object. They were not painted on the public pages.
- `light.focus` is Not captured. Keyboard focus on About did not draw a designed ring in this pass.
- Dark and black are described in the marketing copy and shown inside a demo video. They are not a theme of this site.
- Screenshots are 256-colour PNGs. Read colours from tokens.json.
- The hero and feature blocks are recorded product demos, including a sample greeting. They are not the signed-in app.

## Fonts

Inter, then sans-serif. Declared on `body` in the shared layout chunk and confirmed by `getComputedStyle`. The webfont file is not in this package. The guide falls back to the system sans.

## Do and don't

1. **Do use one blue pill for the primary action.** Try for free is `#008ffd` on white, 52px, 32px radius. See [home-light-default](screenshots/home-light-default.png).
2. **Do keep secondary actions as quiet grey pills.** Watch video and Login are `#eceff2` with ink text. See the same shot.
3. **Do set display type in Inter at 64px, with the first line muted.** The headline splits ink `#19191b` and muted `#a8b0b8`. See [home-light-default](screenshots/home-light-default.png).
4. **Don't style the to-do app from these pages.** Lists in the hero are a demo. The app stops at the login wall. See [login-light-default](screenshots/login-light-default.png).
5. **Don't invent a dark marketing theme.** The site paints Light. Dark and black are product copy, not a captured theme.

## Rebuild

```sh
cd systems/dona
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  RAW=~/.design-systems/dona/raw-shots \
  node tools/capture/public/public.mjs
PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs \
  node tools/capture/read.mjs
python3 tools/capture/quantize.py ~/.design-systems/dona/raw-shots
python3 tools/build_tokens.py
```

`make design-md` regenerates DESIGN.md and the Brief. Do not edit those by hand.
