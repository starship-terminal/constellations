# PamPam design reference

Tokens and component notes for PamPam, captured **2026-11-19**. Desktop is 1440×900. Phone is 390×844. One theme, light. Signed out the whole time.

PamPam (pampam.city) is a public map maker. The capture covers the marketing home, pricing, about, features, blog, and the signed-out login. Login is a Google button. There is no email field, so nothing was signed up for. No plan button was followed. No card, phone, or government ID was entered.

### Principles

1. Do set display type in nineties at 80px, colour `#1b1917`.
2. Do paint UI text in Inter at weight 550, and mute it with `#9894a8`.
3. Do draw Make map as a black 40px face with 8px radius.
4. Do draw the paid plan button as `#4b72f3`, 64px tall, 12px radius, with a `#2b3ea7` border.
5. Do keep the page white and the use-case cards `#faf2ec`.
6. Don't invent a dark theme.
7. Don't restyle the Google button.
8. Don't follow Get Explorer, Get Business, or Contact us into checkout.
9. Don't ship nineties.

## How the values were read

The T3 preview browser opened https://www.pampam.city/ in its own tab. `preview_evaluate` read `getComputedStyle` on the home page, `/pricing`, and `/login`. Viewport was 1440×900, device pixel ratio 2, visual viewport scale 1. A second pass at 390×844 confirmed the phone hero (48px headline, icon-only Make map, no text nav).

`preview_snapshot` failed twice with "The browser is not producing screenshot frames". The page itself had loaded, with no Cloudflare challenge. Screenshots were then taken in headless Chromium at the same URLs and viewports, device pixel ratio 2, and quantised to 256 colours. Crops were clipped from that same browser.

Fonts come from two `@font-face` rules: Inter (variable, 100–900) and nineties, both woff2 under `/_next/static/media/`. The body class sets `--font-inter` and `--font-nineties`. Panda CSS also declares a full preset on `:where(:root, :host)` (a Tailwind-like colour ramp, spacing, radii, durations). Those names were not the colours on the painted controls, so they are not tokens.

## What to distrust

The FAQ answer computed to 16px black through the system font. The screenshot shows it muted. Both are recorded. The screenshot is the visual. The computed colour is the reading.

Class names such as `nineties_80` and `font-md_20` do not match the computed size. The h1 is 80px. The section heading class `nineties_44` computes to 48px. The lede class `font-md_20` computes to 19px. Tokens use the computed size.

The Google button is a cross-origin iframe. Its label, blue, and radius are Google's. Only the iframe box was measured.

The yearly switch was already on. Its off colour is the declared `rgba(0,0,0,0.08)`, not a computed off state. The control was not toggled.

Headless shots and preview readings are the same URLs. They are not the same browser. A rotating hero placeholder can differ between the two.

Nineties is not in the style guide. The display specimens there are a serif stand-in.

## Fonts

Display is nineties, a self-hosted woff2, with a local Arial fallback named "nineties Fallback". UI is Inter, variable, with "inter Fallback" also pointing at local Arial. Neither file is shipped. The style guide loads Inter from Google Fonts and leaves nineties unloaded.

## Do and don't

- **Do set display type in nineties at 80px, colour `#1b1917`.** That is the home headline at 1440. [screenshots/home-light-default.png](screenshots/home-light-default.png)
- **Do paint UI text in Inter at weight 550, and mute it with `#9894a8`.** Nav, ledes, and footer links use that pair. [components/crops/nav-link.png](components/crops/nav-link.png)
- **Do draw Make map as a black 40px face with 8px radius.** [components/crops/button-primary.png](components/crops/button-primary.png)
- **Do draw the paid plan button as `#4b72f3`, 64px tall, 12px radius, with a `#2b3ea7` border.** [components/crops/button-accent.png](components/crops/button-accent.png)
- **Do keep the page white and the use-case cards `#faf2ec`.** [screenshots/home-light-default.png](screenshots/home-light-default.png)
- **Don't invent a dark theme.** The site has one. [screenshots/login-light-default.png](screenshots/login-light-default.png)
- **Don't restyle the Google button.** It is an iframe. [components/crops/google-button.png](components/crops/google-button.png)
- **Don't follow Get Explorer, Get Business, or Contact us into checkout.** Those were not entered. [screenshots/pricing-light-default.png](screenshots/pricing-light-default.png)
- **Don't ship nineties.** It is named, not included. [components/crops/display-title.png](components/crops/display-title.png)
