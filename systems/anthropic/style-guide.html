Anthropic, measured

Every value on this page is a CSS variable generated from tokens.json, read from www.anthropic.com, claude.com and docs.claude.com on 2026-11-09: the sites' own --color-*/--cds-* variables where one matches what the page paints, and computed styles of the real elements everywhere else. Each token's source is in the tables. Toggle Dark for the docs' dark theme.

Three surfaces, one type system: the marketing site (ivory #faf9f5 ground, ink #141413, pill nav, serif headlines), the claude.com product pages (same palette plus a --theme-* semantic set), and the docs (a cooler cds-* system, the only surface with a dark theme). anthropicSans, anthropicSerif and anthropicMono are commercial faces; Lato, Newsreader and IBM Plex Mono stand in here. Component mock-ups are drawn with the tokens; the real components are the crops in components.md.

Palette

A warm 21-step gray ramp does nearly all the work — ivory #faf9f5 down to ink #141413 — plus one clay orange (#d97757, interactive #c6613f) for brand moments and a pictogram palette that rarely touches the UI. The docs run their own cooler cds-gray ramp with a blue accent (#184f95) and a #2a78d6 focus/link blue.

Roles

The semantic layer: page grounds, text levels, borders, the clay accent and the button/tab/field slots in the current theme — aliases into the palette where the chain ends on a scale step. The dark set is the docs' theme only.

Typography

anthropicSerif carries display headlines (64-72px, weight 500, tight ~1.1 leading) and anthropicSans carries everything else (15px working text on the product pages, 14px on the docs, 13px letterspaced nav pills). anthropicMono is 13/19 code on the docs. claude.com scales its steps fluidly with clamp(), so measured sizes land between the marketing scale's steps.

Space and shape

Spacing

The --sp-* scale runs 2-200px; --section-space-*, --card-padding-* and --gap-* name the same steps for their jobs. Fields pad 16/24, buttons 12/24, cards 32-48, page margins 64-80.

Radius

Pills are fully rounded (999999px) — nav chrome, radios, the switch. Fields run 16, tab tracks 16 on tabs 12, cards 19-24, docs controls 7-8-12.

Elevation

Shadows are rare and soft: a barely-there 4/20 (claude.com --shadow-md/lg) lifts the nav dropdown, the docs dialog gets a two-layer drop plus a 1px ink ring. Everything else separates by fill and hairline.

Motion

Hover changes ride 0.15-0.25s on the site's quart/expo curves; menus and sheets take up to 0.5s. Click a track to play its curve.

Focus

Four measured rings: the marketing pills draw a deliberate 2px #154c92 periwinkle ring offset 4px, the product pages draw a 2px #c46849 clay-dark ring offset 2-4px, the docs outline in #2a78d6, and text links take the browser's ring. Keep the offset ring — it is the signature.

Layout

Read at 1440 x 900. The marketing and product sites run a 12-column grid on 80px margins inside a 1920 cap (1400px container), with an 84px sticky nav of ivory pills; the docs are a 56px topbar over a 264px sidebar and a fluid reading column. On a phone the nav collapses to a 28px menu button and a full-screen ink sheet.
