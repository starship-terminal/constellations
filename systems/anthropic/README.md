# Anthropic design reference

A token set and component reference for Anthropic's public site, for building a marketing or research page in the style of the real lab site. Refreshed on 2026-11-21, signed out, in headless Chromium at 1440 wide and 390 wide, on **www.anthropic.com** only. The look is quiet and literary: ivory #faf9f5 ground, ink #141413, anthropicSerif display headlines, pill nav chrome, and one clay orange used only for brand moments.

The control map is [site-tree.md](site-tree.md), written from the homepage before the new screenshots. The login stop is [login-review.json](login-review.json). claude.ai, platform.claude.com, claude.com, and docs.claude.com were not captured in this refresh. Try Claude opens a menu whose two items leave this host, and that branch stops. Nothing was typed. No form was submitted. The footer's Privacy choices dialog was not opened.

## Brief

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export anthropic` prints them all with aliases resolved.

### Principles

1. Do keep the ground warm and quiet.
2. Do set headlines in the serif — the home hero is the exception.
3. Don't waste the clay.
4. Do round pills fully, cards moderately.
5. Do invert pills on hover.
6. Don't add shadows or borders the site doesn't draw.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

All three hosts share one build: CSS modules with hashed prefixes (`X-module-scss-module__hash__Name`), so the kit selects by the readable suffix and by text. The sites declare a real token system on :root — the `--color-*` warm gray ramp and pictogram palette, `--sp-*`/`--spacer-*` space, `--radius-*`/`--br-*`, the type scale and easings — and claude.com adds a `--theme-*` semantic layer plus fluid `clamp()` type. The docs run the cds-* Tailwind system: `--cds-*` semantics on `.cds-root` resolving to `--cds-gray-*`/`--cds-blue-*` ramps on `:where(:root, :host)`, with a real dark theme under `.cds-dark-scope[data-mode="dark"]`.

[vars.mjs](tools/capture/vars.mjs) read every stylesheet's declarations into [raw/css-vars.json](raw/css-vars.json) (the dark-theme checks per page included). Component values are computed styles read per state with Playwright ([measure.mjs](tools/capture/public/measure.mjs)): hover used the pointer, focus-visible a real keyboard Tab, and pressed was forced through DevTools (`CSS.forcePseudoState`), so no button was clicked for real. Text fields were clicked into and left empty. The pricing plan tab and batch switch were clicked once for their states — local UI, no request. The nav dropdown opened on a real hover. The docs search dialog opened from its field; nothing was typed. Tokens whose leaf names a `var` are resolved from css-vars.json inside their owner (site or docs); the rest are literal measurements.

Screenshots were lazily scrolled to settle lazy media, then stored quantised to 256 colours; the unquantised originals and per-capture metadata stay outside the repository in `~/.design-systems/anthropic/raw-shots/`. The docs dark pass used emulated prefers-color-scheme: dark (the site sets `data-mode="system"` on html), labelled a reconstruction of what the browser would show.

## What to distrust

- **Screenshots are 256-colour PNGs.** Gradients and photography band slightly; read exact colours from tokens.json or the raw files.
- **Fluid type lands between steps.** claude.com redeclares the marketing scale as `clamp()` values, so measured sizes (hero 40.78px, links 16.69px) sit between the px steps in `font.size`.
- **`submit-button` reads transparent.** The measured node is the button's row container on /contact-sales; its inner label is the 15/500 medium text shown. The button itself is the same ink-fill style as the other primary CTAs.
- **Research cards sit on moving media.** Their text colour is the overlay ivory; the card surfaces shift frame to frame.
- **Some hover rows read "same".** Anthropic's pills and tabs genuinely restyle on hover, but several links and cards measure identical; the entries are not missing a state.
- **`docs-*-dark-*` shots are emulated.** The docs dark theme was captured under `page.emulateMedia({colorScheme:'dark'})` against `data-mode="system"`, which is what a dark-mode visitor sees, not a hand-set dark mode.
- **`--theme-*` values are per-component scopes.** They re-declare on panels (a dark `--theme-background-primary` on dark sections); the light semantic set uses the :root defaults resolved on the product pages, as raw/css-vars.json's `resolved` map records.
- **`plan-card` and `plan-cta` were read from the wrong elements.** The capture switched the pricing page to its API tab before probing the plan card, so `plan-card` is a row of the API usage table ("Opus 5 Prompt caching Read $0.50 / MTok ..."), and the unscoped CTA search caught the header's Try Claude pill at y=24, not a button in a plan card. Both need a recapture; the script now probes them on the default tab, inside the card (not run since).

## Do and don't

1. **Do keep the ground warm and quiet.** The page is ivory #faf9f5, fills step down the gray ramp (#f5f4ed, #f0eee6, #e8e6dc) and text is near-black #141413. See [home-light-default](screenshots/home-light-default.png) and [policy-light-default](screenshots/policy-light-default.png).
2. **Do set headlines in the serif — the home hero is the exception.** Display titles are anthropicSerif at weight 400-500, ~1.1 leading, slightly tight tracking; body and chrome stay in anthropicSans. The home hero's heading mixes the two: the h1 is serif while its lead line inside renders anthropicSans at weight 600 and the same size (the mobile entry reads the same way). See [hero-title](components/crops/hero-title-default.png) and [faq-item](components/crops/faq-item-default.png).
3. **Don't waste the clay.** Clay #d97757/#c6613f is a brand accent, not a UI colour: primary buttons are ink fills and links are ink or underlined. The clay shows up on the footer send, pictograms and badges. See [footer](components/crops/footer-default.png).
4. **Do round pills fully, cards moderately.** Nav chrome and radios are 999999px pills; buttons run 8-10px, fields 16, cards 19-24. See [nav-cta](components/crops/nav-cta-default.png) and [plan-card](components/crops/plan-card-default.png).
5. **Do invert pills on hover.** The signature hover is the ivory pill flipping to ink with a 1px ink ring; pressed steps to #e8e6dc. Keyboard focus is a 2px #154c92 ring offset 4px. See [nav-cta-hover](components/crops/nav-cta-hover.png) and [nav-cta-focus-visible](components/crops/nav-cta-focus-visible.png).
6. **Don't add shadows or borders the site doesn't draw.** Depth is a rare soft drop on the open nav panel; everything else separates by fill and a 1px hairline. See [nav-research](screenshots/home-light-nav-research.png) and [nav-company](screenshots/home-light-nav-company.png).

## Rebuild

```bash
python3 tools/build_tokens.py
```

```bash
python3 tools/build_style_guide.py
```

```bash
python3 tools/build_components_md.py
```

`build_tokens.py` reads `raw/component-tokens.json` (with `raw/css-vars.json` for `var` leaves) and writes `tokens.json`; it refuses a value that is not the DTCG type it claims and an alias that points at nothing. `build_style_guide.py` renders `style-guide.html` from `tokens.json` and `tools/style-guide.template.html`. `build_components_md.py` writes `components.md` from `raw/components-computed.json`, `raw/layout.json`, `tokens.json`, the screenshots and `icons/INDEX.tsv`. All three are deterministic: re-running them on this commit reproduces their files byte for byte. Edit the raw inputs or the builders, never the generated files.

`tools/capture/` holds the kit the captures came from. The Playwright scripts take `PLAYWRIGHT` as the path to a Playwright install's `index.mjs` when `playwright` is not resolvable from where they run; set `PYTHON` to an interpreter with Pillow for the inline quantize calls.

```bash
PLAYWRIGHT=/path/to/playwright/index.mjs node tools/capture/public/public.mjs
PLAYWRIGHT=/path/to/playwright/index.mjs node tools/capture/public/measure.mjs
PLAYWRIGHT=/path/to/playwright/index.mjs node tools/capture/vars.mjs
PLAYWRIGHT=/path/to/playwright/index.mjs node tools/capture/icons.mjs
python3 tools/capture/quantize.py ~/.design-systems/anthropic/raw-shots
node tools/capture/public/build-measurements.mjs
```

`public.mjs` re-takes the screenshot set into `RAW` (defaults to `~/.design-systems/anthropic/raw-shots`, outside the repository); `quantize.py` stores the 256-colour copies in `screenshots/`. `measure.mjs` merges per-state readings into `raw/components-computed.json`; `build-measurements.mjs` rewrites `raw/measurements.md`. `vars.mjs` and `icons.mjs` rewrite their raw/icon files whole. `lib.mjs` holds the shared helpers, including the consent-overlay sweep and the `navigator.webdriver` masking.

## Use in Figma

Import `tokens.json` with Tokens Studio and choose the Light theme (Dark covers the docs surface only). Set UI text to a neutral geometric sans and headlines to a literary serif as stand-ins for anthropicSans/anthropicSerif, keep nav chrome fully rounded, and leave clay to brand moments.

## The screen to get right

The home page is the screen to get right. An 84px bar carries the serif wordmark, 15px section links, and two ivory pills (a ⌘K search and the 28px "Try Claude" CTA) over the ivory ground. Below, a ~41px serif hero line reads "AI research and products that put safety at the frontier." beside an ink CTA, then an #f5f4ed feature card and the news card list. The footer is a full-bleed #141413 ink panel: link columns, a #262624 prompt bar with a clay Send, and the legal row. On a phone it all collapses to a menu button and a full-screen ink sheet. Everything the capture could not reach is listed under Gaps in [components.md](components.md#gaps).
