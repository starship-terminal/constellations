Palette

The core set carries the measured ink/eggshell/white neutrals and the black-pill action ramp (measured off the real buttons, var-referenced where a custom property resolves the same value) plus the declared shadcn/status hues. Light roles alias the palette. Every public surface painted light — no dark theme was captured.

Spacing and radius

Controls are pills (9999px); cards take the declared --rounded-card radius; fields a smaller radius. Layout rides on --spacing-inset (1.25rem) and the --section-py-* scale (5rem at md on desktop).
