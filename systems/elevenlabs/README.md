# ElevenLabs design reference

A token set and component reference for ElevenLabs' public signed-out surface — for building marketing pages, docs shells and auth cards in the style of the real thing. It was read from **elevenlabs.io** on **2026-11-13**, signed out, in headless Chromium at 1440 x 900 and 390 x 844. Captured: home (with the Products mega-menu, the ElevenAgents hero tab and the TTS playground toggled, and the Play pressed once), pricing (with the Monthly billing dropdown open), the product pages (text-to-speech, conversational-ai, sound-effects, api), docs, about, enterprise, blog, the /app/sign-in and /app/sign-up cards, plus a 390px pass on home, pricing and text-to-speech.

ElevenLabs is worth a capture because the voice-AI category leader paints a deceptively quiet public system: Waldenburg display at 48/52 (36 at phone width) over a `#FDFCFC` eggshell field, Inter UI text, pure-black pill CTAs at 9999px that take the same `#44403b` warm-dark step on hover and pressed, a 5% warm-ink wash on nav ghosts, `#2b7fff` blue kept for links, gradients and the 1px focus ring, and white cards on `#e5e5e5` hairlines. The auth cards change register entirely — 12px radii, `#0f0f10` ink and a disabled `#a3a3a3` submit — so the marketing chrome and the account surface are two related dialects. **Boundary:** everything behind the auth card — the Studio, agents platform, voice library, API keys and billing — was never reached and is never inferred; /app redirects to /app/sign-in.

## Brief

<!-- brief:start. Generated by tools/brief.py from catalog.json, the tokens file and this README; `make brief` rewrites it. Do not edit. -->

Read this before designing in this style. Take every value from [tokens.json](tokens.json), never from the screenshots; `python3 tools/catalog.py export elevenlabs` prints them all with aliases resolved.

### Principles

1. Do spend the ink on actions only.
2. Do walk the warm step.
3. Do wash the ghosts.
4. Do pill the marketing controls.
5. Do keep blue for links, gradients and focus.
6. Do lay white on eggshell.
7. Don't style the workspace from this package.
8. Don't read a dark theme into the orbs.

Each rule links the screenshot or crop that shows it, under [Do and don't](#do-and-dont).

## How the values were read

Every value came off the running signed-out site in headless Chromium:

- **Tokens.** [tools/capture/vars.mjs](tools/capture/vars.mjs) captures every stylesheet body — elevenlabs.io's Tailwind 4 bundles are served cross-origin from eleven-public-cdn.elevenlabs.io (invisible to the CSSOM), so bodies are read from network responses plus inline `<style>` blocks — and writes every custom property to [raw/css-vars.json](raw/css-vars.json), resolved on a probe document in the one light theme the public surface ships (188 resolved vars). The layer is real — the `--f-*` type ramp, `--spacing-*/--section-*/--rounded-*` layout vars, `--eggshell`, `--page-background-color`, the font stacks and the shadcn HSL triplets — so tokens var-reference it where it declares a value, and everything else — the ink/eggshell/white neutrals, the warm-grey muted, the ink action ramp, the state washes, the radii and the type ramp — is measured computed values from [raw/components-computed.json](raw/components-computed.json). [tools/build_component_tokens.py](tools/build_component_tokens.py) writes the spec, [tools/build_tokens.py](tools/build_tokens.py) the sets.
- **Components.** [tools/capture/public/measure.mjs](tools/capture/public/measure.mjs) opens each route in a fresh context and reads `getComputedStyle`, painted layers and boxes per element in default, hover, focus-visible and a CDP-forced pressed state — 71 components over home, pricing, text-to-speech, api, docs, the sign-in/sign-up cards and the 390px mobile pass. Results in [raw/components-computed.json](raw/components-computed.json) and [raw/measurements.md](raw/measurements.md).
- **Screenshots.** [tools/capture/public/public.mjs](tools/capture/public/public.mjs) takes viewport and full-page shots per route with `.capture.json` sidecars (kept in the capture scratch, not committed), including the local UI toggles: the Products mega-menu and the ElevenAgents hero tab on home, the TTS playground with Play pressed once, the Monthly billing dropdown on /pricing, and the mobile menu. Full-page shots are capped at eight chunks; mobile-home's full page and text-to-speech's overflowed the GPU texture limit and stitched from three / two chunks. [tools/capture/quantize.py](tools/capture/quantize.py) posterises them to 256 colours.

Nothing was signed into, created, submitted or paid for: the auth cards were measured as surfaces — the email and password fields were focused and given sample text that was deleted again, leaving the submits disabled and never pressed; every Sign up, Subscribe, Get API key, Contact Sales and OAuth action was measured or screenshotted, never followed; the voice-chat launcher was measured, never opened. The home playground's Play was pressed once — a public affordance that generates without an account. The Cookiebot consent layer was hidden per capture, never answered — no consent was ever posted.

## What to distrust

- **This is the public surface, not the product.** The Studio, agents platform, voice library, API keys, billing and account sit behind the auth card and are uncaptured. Marketing pages describe the product; nothing here verifies how it behaves.
- **Light only.** Every public surface paints the #FDFCFC eggshell field; the bundles declare no `.dark` scope or `prefers-color-scheme` rebind and no dark island was captured. The export holds `core` + `light` only — don't invent a dark theme from it.
- **The gradient voice orbs are media, not CSS.** The orbs, card artwork, blog imagery and the ElevenLabs wordmark in the screenshots are painted image/SVG-art layers — no flat-colour token claims to be them.
- **The auth card is a different register.** Marketing controls are 9999px black pills; the sign-in/sign-up cards are 12px-radius white cards with #0f0f10 ink, #2e2e2e OAuth labels and a disabled #a3a3a3 submit. Don't mix the dialects.
- **Pressed equals hover on the ink pills.** The measured pills take the same #44403b step on hover and pressed — the pressed states were CDP-forced, so any mousedown-only styling a script adds is invisible here.
- **The mega-menu auto-closes.** It dismisses a few seconds after opening; flyout-child readings re-opened it with the Products trigger first, so hover/focus values are real but the panel is ephemeral by design.
- **The promo strips are live.** The V4 bar on home and the $1-credits countdown on product pages carry real countdown timers — the captured values are point-in-time.
- **Readings to recapture.** `feature-row` is the whole pricing page body (1440 x 5508), kept from the first run after the re-run missed it; `voice-card` is an FAQ row; `menu-link`'s default and pressed states caught a same-href link far down the page, so `core.color.neutral.muted` says so in its source. components.md marks the three entries.
- **One screenshot was taken past a server-side action.** `home-light-playground-play.png` was shot after the capture pressed the playground's Play, which asks the server to generate speech. `public.mjs` no longer presses it (edited, not run); the shot is kept as evidence.
- **Quantised screenshots.** `screenshots/` are 256-colour PNGs; read exact colours from the tokens or the raw files.
- **Automation was masked during capture.** Until 2026-11-20, `tools/capture/public/lib.mjs` hid `navigator.webdriver` in every page it opened, so every committed reading was taken with that mask. The mask is removed (a bot check is now recorded as a boundary, not bypassed); whether any page needed it to load is not known, and a recapture without it is the check.

## Fonts

Three families do everything the surface paints: **Waldenburg / WaldenburgFH** on display and nav (the hero, page titles and headings), **Inter** on UI and body text, and **Geist Mono** on code. The `@font-face` blocks live in the cross-origin eleven-public-cdn.elevenlabs.io bundles — the harvest lists the srcs in [raw/css-vars.json](raw/css-vars.json). The fonts are licensed and not distributed with the package — the tokens carry the stacks (`Waldenburg, "Waldenburg Fallback"`, `Inter, "Inter Fallback"`, `"Geist Mono","Geist Mono Fallback"`) and the style guide falls back to system faces. Every measured weight is 400 — the site's medium/semibold roles resolve to the regular face.

## Do and don't

1. **Do spend the ink on actions only.** `#000000` is the Sign up pill, every plan CTA, the hero CTA, the Play button, the API-key CTA — never a background or a text colour outside the auth card. See [signup-cta](components/crops/signup-cta-default.png).
2. **Do walk the warm step.** The ink pills darken `#000000 → #44403b` on hover and keep it on pressed; no side steps. See [plan-cta](components/crops/plan-cta-hover.png) and [signup-cta](components/crops/signup-cta-pressed.png).
3. **Do wash the ghosts.** Nav items and triggers paint a 5% warm-ink wash (`rgba(41,37,36,0.05)`) on an 18px inner chip; OAuth buttons take `rgba(0,0,0,0.02) → 0.043`. See [nav-link](components/crops/nav-link-hover.png) and [oauth-google](components/crops/oauth-google-pressed.png).
4. **Do pill the marketing controls.** Buttons, tabs, the billing select and the header actions are 9999px pills — but the auth card squares up at 12px and the docs search at 8px. See [tool-tab](components/crops/tool-tab-default.png) and [email-field](components/crops/email-field-default.png).
5. **Do keep blue for links, gradients and focus.** `#2b7fff` never fills a marketing button; it paints links, the orb gradients and the 1px focus ring at 2px offset. See [hero-cta](components/crops/hero-cta-focus-visible.png).
6. **Do lay white on eggshell.** The page is `#FDFCFC`, cards and the flyout panel are `#ffffff` with `#e5e5e5` hairlines. See [pricing-light-full](screenshots/pricing-light-full.png).
7. **Don't style the workspace from this package.** Every value is the public surface's; the product behind the auth card is uncaptured.
8. **Don't read a dark theme into the orbs.** The gradient voice orbs are painted media; the surface itself is light only, and every token set here is light.

## Rebuild

Everything derived regenerates offline from the raw readings (run from `systems/elevenlabs/`):

```sh
python3 tools/build_component_tokens.py        # raw/components-computed.json -> raw/component-tokens.json
python3 tools/build_tokens.py                  # -> tokens.json
python3 tools/build_style_guide.py             # -> style-guide.html

node tools/capture/public/build-measurements.mjs  # -> raw/measurements.md
python3 tools/capture/quantize.py <raw-dir>    # full-colour PNGs -> screenshots/
```

Then `make brief && make design-md && make grade && make check` from the repo root refreshes the generated sections and validates the catalog.

Live recapture (needs the site; Playwright at `PLAYWRIGHT=~/.design-systems/pw/node_modules/playwright/index.mjs`):

```sh
node tools/capture/vars.mjs                    # stylesheet harvest -> raw/css-vars.json

```

elevenlabs.io loads headless without challenge pages; each route gets its own context. The Cookiebot layer is hidden per capture, never answered. The workspace stays behind the auth card.
