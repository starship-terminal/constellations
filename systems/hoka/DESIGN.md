# HOKA

A signed-out capture of the public HOKA shop at [https://www.hoka.com](https://www.hoka.com), on 2026-11-22. The region picker was set to United States and English. Visit Site opened [https://www.hoka.com/en/us/](https://www.hoka.com/en/us/). Prices read USD. Desktop 1440 by 900. The utility bar is `#000000`. The wordmark is `#009dff`. Sale copy is `#e10f00`. Body type is the-future. Search and Shop Now are pills with radius 52px.

`catalog.json` was left alone, so this file is handwritten. Values come from [tokens.json](tokens.json) and [raw/readings.json](raw/readings.json).

## Colour

| Role | Value | Where |

| Ask | `#efefef` | Ask HOKA button |

## Type

the-future for body, nav, prices, buttons, and the category title. sans-serif is the fallback. Body 14px, weight 400. Nav labels 14px, weight 500. Category title 32px, weight 900. Sale price 16px, weight 500. Struck price 16px, weight 400. Font files are not in this package.

## Controls

Shop Now is a white pill, 125 by 48, 16px, weight 500, radius 52px. Search is 178 by 36, radius 52px, white fill, 1px black border, placeholder "Search…". Ask HOKA is 187 by 40, fill `#efefef`, radius 52px. The utility bar is 48px, full width, black. The wordmark is an inline SVG, viewBox `0 0 94.5 26.9`, fill `#009dff`.
